## 当前核心

> 修炼决定你有没有资格到下一境；破境决定你准备怎样把自己带过去。

破境分为：

> **积 → 悟 → 续**

只有“续”阶段才分为：

- 正破：全部自己带过去
- 借载：借外物托住完整自我
- 舍破：主动不带走一部分自己

而本书真正的第二轴是：

> **凡有所舍，必有所归。**

被舍弃的东西并没有消失，它们进入余世。
