## 当前核心

修炼不是舍弃的附属品。

大境突破统一理解为：

> **修积 -> 明悟 -> 续我**

只有“续我”阶段才出现不同实现：

- **完整续我**：完整把当前自己带过去；社会俗称可称“正破”。
- **借载**：借外物托住部分续我压力，本人保持完整。
- **舍破**：以舍契永久切离部分真实我相，减少本次续我负担。

舍破不生产力量，也不能跳过修积和明悟。

舍破设计遵守作者侧三问：

> **真不真？切不切得开？切了够不够？**

而世界的第二轴仍是：

> **凡有所舍，必有所归。**

被真正舍掉的部分形成弃相；本人留下不可恢复的**缺位**；弃相进入余世，并可能形成余痕、余灾、余器等现象。
