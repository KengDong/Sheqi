# Corrected A3 design law

A3 must have TWO scales:

## Shelf fantasy / distant horizon
Can be huge:
- eventually send off Heaven;
- uncover why the world is dying;
- obtain world-level handling authority.

## First 20–50 chapter engine
Must be small:
- one concrete object;
- one immediate personal gain;
- one social relationship;
- one understandable next desire.

Do NOT make Heaven / ascension / previous era the daily premise from chapter 1.

# A3 required expansion slope

## Ch1–3
Only prove:
> protagonist has a strange advantage around things that are worn out / terminal / "should have ended".

No Heaven.
No world death.
No ascension conspiracy.

## Ch4–20
Use advantage for:
- study / work / cultivation;
- money / resources;
- relationships;
- first social revaluation.

Reader should think:
> this ability is really useful.

Not yet:
> this ability saves the universe.

## Ch20–50
Expand target scale:
> low-grade tool → technique / field / beast / formation.

Reveal:
> many things seem to be dying earlier than expected.

Still no full answer.

## Ch50–100
First institutional recognition:
> sect / school / company / local authority needs protagonist for a problem.

First persistent clue:
> this is not isolated.

## 100+
Only then unlock:
> regional cycle issue / old history / Heaven-scale mystery.

# New design question

Do NOT ask:
> "How does protagonist eventually bury Heaven?"

First ask:
> **What is A3's equivalent of "take one medicine and get one useful reversed effect" or "cross once and gain one practical advantage"?**

This early loop must be:
- concrete;
- repeatable;
- useful to protagonist's current life;
- scalable later;
- thematically compatible with send-off / return.

# Candidate early-engine zone (not final concepts)

Possible forms to benchmark next:
1. terminal object can perform one final peak-state action before true ending;
2. correct send-off releases one concrete "legacy use" that changes protagonist's immediate life;
3. protagonist can tell "worth repairing / truly dead" and exploit that information in an existing high-attention environment;
4. protagonist can convert waste / end-of-life cultivation resources into a usable but bounded personal advantage;
5. each proper ending restores something nearby, creating practical value before cosmic meaning appears.

These are research directions only.
