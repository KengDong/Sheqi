# Diagnosis

V3 corrected expansion gradient but kept the wrong early engine:
> old cultivation item → terminal-state diagnosis → last use / repair / retire.

This is still fundamentally:
> maintenance / appraisal / recycling.

The world therefore lacks the title-level novelty of current strong concepts such as:
- side-effects become benefits;
- low-value root becomes high-value across worlds;
- create real-world game characters and grow them through fame;
- fungus consumes corpses and expands its ecology.

# New design law

Do not make "dead thing" mean:
> old / broken equipment.

Make death / legacy / ending a **civilization-level consumable, identity system, education system or cultivation substrate**.

A qualified world concept must create:
1. a strange social normality visible in chapter 1;
2. a protagonist action readers have not just seen as generic repair/recycling;
3. a small repeated loop;
4. a direct route to relationships/status;
5. a latent path back to A3's return / proper-ending theme.
