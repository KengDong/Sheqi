# Dual Narrative Aperture & Macro-Promise Review
## 两本当前共同问题：情景剧化 + 未来天花板不可见

status: completed
date: 2026-09-23
authority: author-read + total-editorial

## 0. Author evidence

作者明确反馈：
- 两本都像在一个画面里频繁对话；
- 像台上演小品/小型情景剧；
- 场景变化小；
- 信息摄入不像电影那样有大开大合；
- 视角窄；
- 没有感觉未来会有更大的看点。

该反馈与D-0075“Novelty Bandwidth不足”一致，但比它更精确。

## 1. Root diagnosis

### 1.1 不是“对白比例高”本身
热门连载也可以对白很多。

问题是对白功能：
- 当前两本大量对白承担流程、权限、风险、价格、账户、方案解释；
- 强样本对白更常顺带完成：
  - 新世界事实；
  - 新阶层；
  - 新关系；
  - 新笑点；
  - 新目标；
  - 新威胁。

### 1.2 场景是“功能布景”，不是“活动中的社会”
当前常见结构：
> 到一个地方 -> 2—3人说话 -> 把本章问题说清 -> 离开。

医院、交易所、会展、诊室、教室等经常只是标签。
背景社会很少自己运动。

### 1.3 地点变化不等于镜头变宽
即使换了医院/会展/教室，
如果叙事模式一直是：
> 主角 + 对话对象 + 手机/UI + 解释，
读感仍是同一个舞台。

### 1.4 两本都缺“远景Promise”
C01读者目前容易推断后面是：
> 更多订单 -> 更复杂履约 -> 团队 -> 公司。

C12读者目前容易推断后面是：
> 更多风险项目 -> 更复杂暴露 -> 更高资格 -> 更大项目。

这都属于“同一种玩法变大”，不是：
> **“原来这本书后面还能打开那样一个世界。”**

## 2. New editorial concepts

### Narrative Aperture｜叙事镜头口径
衡量的不是地图大小，而是：
- 一个场景里有多少独立运行的人/事；
- 人是否在空间中移动；
- 环境是否会反过来改变行动；
- 是否存在并发/切换/远处影响；
- 是否看到主角不知道的世界痕迹；
- 是否有宽镜头、群体、城市/行业/社会面。

### Scene Ecology｜场景生态
一个场景不能只有为主线服务的两个人。

至少有一部分场景需要：
- 第三方正在做自己的事；
- 背景制度正在运行；
- 空间有阻力；
- 物体/交通/人群/天气/设施参与因果；
- 非主线细节让世界感觉早已存在。

### Macro Promise｜更大看点的可见远景
前10章必须让Reader亲眼感到：
> 后面不只是“同类问题更复杂”。

不是靠作者解释或Canopy承诺。
必须通过场面/事件/人物/社会现象露出。

## 3. Stage-Play Test

每个重点场景都问：

> 如果拿掉所有布景，只剩两把椅子、一张桌子、两个人和手机，这一场是否几乎还成立？

如果YES：
- 若本场权力关系/情绪张力极强，可以保留；
- 否则说明场景生态太薄，需重做。

禁止为了过测试机械加路人和风景。

## 4. Cinema Intake Test

每2—3章至少应出现一次：
- 大空间移动；
- 人群/群体事件；
- 多方同时行动；
- 远处事件影响近处；
- 跨地点因果；
- 新社会层第一次实体出现；
- 主角只看到一角但Reader感到世界更大。

目标不是“像电影分镜”，
而是提升：
> **单位阅读时间里的新空间、新关系、新社会信息、新可能性。**

## 5. C01 specific problem

Ch1—3最强，因为连续扩张：
> 卖自己 -> 买别人 -> 自己撮合。

Ch4以后新鲜感主要变成：
> 授权 / 适配 / 争议 / 账户 / 披露 / 交付。

这是同一系统内部专业化。

C01需要的不是更多时间产品，
而是让“时间可以出售”撞进更多真实社会系统，并且这些系统互相冲突。

必须探索但不立即锁：
- 普通工作场所如何被未来时段合同改变；
- 招聘/晋升/婚恋/家庭/教育/保险/居住等如何与已售未来冲突；
- 长期卖出的未来如何在“本人变了”以后反咬现在；
- 大型机构如何使用未来执行权；
- 城市中真实存在什么规模更大的时间基础设施/阶层差异；
- 哪些现象只需一瞥，就能让Reader知道后面远不止撮合小单。

## 6. C12 specific problem

C12场景比C01多，但认知镜头仍经常只有：
> 安全 / 暴露 / 项目 / 医院 / 报价。

需要让Reader更早看到：
- 整个现代修仙城市怎样围绕突破运行；
- 高境界突破在交通、电力、建筑、学校、公司、家庭里留下什么公共痕迹；
- 劫工之外还有哪些普通修士生活；
- 周野同龄人的修炼/消费/阶层/求职；
- 城市规模的劫务基础设施；
- “风险不会消失”未来可能如何超出一个项目，作用到设备、场地、街区甚至城市。

不能靠一章世界观介绍。
必须通过场面让Reader看到。

## 7. Macro-Promise Ladder

两本重构时都必须满足：

### By Ch3
Reader知道：
> 这不只是一个聪明小机制。

### By Ch6
Reader第一次看到：
> 这个机制正在改造一块更大的社会生活。

### By Ch10
Reader至少获得一个真实远景：
> 未来将打开一个比当前职业/订单大一个数量级的冲突。

不要求解释答案。
要求看得到天花板。

## 8. Scene-description correction

不要增加装饰性描写比例。

需要增加：
- 具体空间；
- 人的运动；
- 物体使用；
- 感官状态；
- 背景人群；
- 同时发生的旁支动作；
- 场景对决策的限制。

描述必须产生至少一种功能：
- 信息；
- 气氛；
- 因果；
- 阶层；
- 人物；
- 预兆。

## 9. Editorial consequence

- C01当前Ch4—20继续降为experiment/history。
- C12当前Ch1—20保留为有效样本，但不允许继续Ch21。
- 两本先做Narrative Aperture + Macro Promise重构。
- 不允许“多加风景、多切地点”式表面修复。
- 不允许“每章塞一个新设定”式信息轰炸。

第一性原理：
> **Reader需要感觉自己正在进入一个越来越大的世界，而不是在看同一张舞台换道具。**
