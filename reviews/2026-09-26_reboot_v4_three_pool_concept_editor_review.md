## 审查口径

本轮只做结构合规审查，不做市场排名，不选赢家，不比较三个方向谁更好。

判定只有三种：

- PASS
- REVISE
- DROP FOR STRUCTURAL FAILURE

这里的 PASS 只表示“目前结构上允许进入下一轮”，不表示市场胜率更高。  
本轮没有越界读取旧 Sheqi 候选，因此“是否复活旧思路”按本轮已经明确禁止的旧失败模式检查：奇怪职业/行业、公共流程喧宾夺主、经营管理替代题材、复杂规则替代核心爽点、把新设定当长期发动机。不能据此声称和某个旧候选做了逐字比对。

# Pool 1｜现代民俗玄学：本土术法专业权威

## 方案一｜爷爷走后，我接下了村里的香火事

**判定：PASS**

### 为什么通过

1. **题材母体清楚。**  
   乡土民俗、家族传承、香火、看事、熟人社会，这些一眼就能让读者知道自己在看什么，没有为了原创发明陌生行业或世界观。

2. **前三章已经兑现核心爽点。**  
   大家把异常理解成“老人不肯走”，主角却指出真正问题在活人，并给出可以被现实验证的判断。核心不是法术炫技，而是“别人看错，主角看懂，现实证明”。

3. **第20章留下的东西不是只有实力。**  
   老宅/香堂、父子关系、第一户长期关系、同行旧友、爷爷留下的人情债都能继续改变后续故事。

4. **人物关系可以自己制造剧情。**  
   父亲不是反派，他是真的想把儿子拉出这一行；堂兄/旧友也不是负责衬托主角，而是有自己的判断、客户和名声。没有新鬼出现时，这两条关系本身也能制造冲突。

5. **100章后核心仍能保持。**  
   扩大的只是熟人圈、责任和判断难度，不需要改写成修仙或打怪升级。

### 必须守住的红线

- 爷爷的旧事不能越来越像答案库，否则主角会重新变成“继承祖辈答案的人”。
- 新民俗规则不能无限增加，必须让旧规矩、旧人情和旧判断反复回返。
- “第一户长期关系”后面必须真的回来改变局面，不能只停留在设定表。

### 与热门母体的相似边界

目前相似停留在乡土民俗、家族传承、看事与社会重估这些成熟功能层面，没有出现具体人物组合、标志性桥段或固定事件顺序的复制迹象。

---

## 方案二｜我在县城守一家风水铺

**判定：PASS**

### 为什么通过

1. **仍是非常清楚的风水先生母体。**  
   固定风水铺、看宅看坟、客户、同行、本地社会，读者不需要先理解一个新职业。

2. **前三章付款够快。**  
   第一案不是“主角法术更强”，而是主角先发现问题根本不在房子，客户继续按错误方向处理后，现实马上验证他的判断。

3. **固定门店不只是场景。**  
   老客户、叔叔留下的客户关系、家人/合伙人、资深同行都可以不断回到同一个地点，形成真正的社会记忆。

4. **人物关系有独立目标。**  
   负责经营的人要让店活下去，资深同行要守自己的判断和职业位置，他们不会只在主角出手时出现。

5. **长期方向没有换题材。**  
   后面扩大的是店铺信誉、责任和同行关系，而不是突然开系统、修炼境界或进入另一套世界。

### 必须守住的红线

这个方案最天然的危险就是：

> 新客户上门 → 听故事 → 主角判断 → 解决 → 收钱 → 下一位。

现有设计已经给了防线，但下一轮必须实际验证：在没有新客户上门的情况下，旧客户、家人或同行能不能单独撑起一段值得看的故事。做不到的话，纸面上的“旧人回返”不算真正解决流水线。

### 与热门母体的相似边界

目前借用的是风水铺、先生、客户、同行这些成熟母体元素，没有看到具体案件、人物或开篇桥段的照搬。

---

## 方案三｜同门都说我看错了

**判定：PASS**

### 为什么通过

1. **仍然属于正统师承 + 风水/民俗先生。**  
   “被逐出师门”只是身份入口，没有把题材改成门派经营或行业会议。

2. **前三章核心体验明确。**  
   师兄的判断并不蠢，主角靠一个关键反例看出问题，现实随后验证。这个爽点比“外行不懂我懂”更难写，但仍然是专业判断被证明。

3. **第20章已有多条不会清零的关系。**  
   师兄、师父、原师门同辈、个人落脚点、同行名声和人情债都会继续工作。

4. **关系本身能制造剧情。**  
   师兄重规矩、师父重门派信誉，主角重证据。这三者不需要每次等一个新鬼出现才会产生冲突。

5. **100章后仍然能保持同一个商品。**  
   后期不是主角境界更高就碾压同行，而是所有人都更专业以后，主角仍要靠判断质量建立权威。

### 必须守住的红线

- 不能写成“同行每次都错，主角每次都对”。
- 不能把故事写成先生们坐着争理论，所有专业冲突都必须落到具体异常、具体风险和具体后果。
- 主角公开认错必须真的发生过，否则“允许别人也看对”会变成口头承诺。

### 与热门母体的相似边界

目前相似的是师承、同行、民俗处理、被低估后建立名声，没有出现明显的具体热门人物或事件模板复制。

---

## 方案四｜出事以后，他们先来问我

**判定：REVISE**

### 为什么不能直接通过

这个方案前三章其实能工作，第20章也能列出长期状态，问题不在“开局不爽”，而在**长期发动机已经开始被现代调查流程抢走**。

目前的长期结构越来越依赖：

> 公共事件发生 → 固定调查人员把信息发给主角 → 主角判断 → 现实处理流程改变 → 下一次再来问。

这和本池要防的“新客户—新鬼流水线”只是换了入口，很容易变成“新怪案—新咨询—新处理”的灵异刑侦/顾问文。

更严重的是，方案自己在第100章的保证是：

> 只要坚持不变成超自然特工，仍然是民俗文。

这属于“靠作者以后别写歪”维持，而不是当前结构已经自动保证不会写歪。

### 哪些东西是成立的

- “最不信玄学的人也因事实改变行动”这个社会重估非常贴本池核心。
- 固定调查人员和师门长辈都可以形成长期关系。
- 前三章“先别动这里 → 现实验证”足够直接。

### 需要怎么改，改完再测

不生成新方案，只修当前结构：

1. 现实机构只能是**固定关系和约束者**，不能成为主要的事件派发入口。
2. 第20—100章必须证明：没有新公共案件时，师门、旧当事人、熟人社会和既有民俗关系也能自己发动主要剧情。
3. “被认可”不能继续主要表现为权限、合作入口、先来问他，而要落实到旧人物长期改变选择、信任和责任。
4. 至少设计出一种长期冲突，完全不依赖“又发生一宗解释不通的公共事件”。

完成以上修正后再进入下一轮。

### 与热门母体的相似边界

没有发现具体热门作品桥段复制的问题。这里的问题恰恰不是“太像”，而是长期结构开始从民俗先生母体向灵异调查/机构合作偏移。

# Pool 2｜都市医武神医：低位身份强势翻身

## 方案一｜下山神医回城：从“当年最没出息的儿子”到这个名字能调动一座城

**判定：PASS**

### 为什么通过

1. 高手下山、神医、医武、都市回归、隐藏实力，这个母体非常清楚。
2. 开局低位有现实理由：多年离家、没有社会履历、家庭真正困难时不在场，不是全世界无理由降智。
3. 前三章母亲急变就能完成第一次“真正出事只有他能解决”。
4. 第20章留下家庭、医生见证、第一位高位欠情、旧同学口碑、稳定社会入口，后面都有实际用途。
5. 医生、家人、早期高位人物都带着自己的责任和利益，不是一次性震惊者。
6. 到100章是认可范围扩大，不是把前面的社会位置全部清零。

### 必须守住的红线

- 新圈层可以不知道主角，但不能每进一个新圈子就机械重演“穿得穷 → 羞辱 → 救人 → 下跪”。
- 早期高位人情必须有成本和立场，不能变成无限通行证。
- 家庭亏欠不能三章治好，也不能压过医武主商品。

### 与热门母体的相似边界

目前相似停留在下山、神医、医武和都市身份上升这些成熟功能，没有出现具体人物配置或经典桥段的直接复制。

---

## 方案二｜赘婿医武：从“靠老婆吃饭”到所有人必须先问他愿不愿意出手

**判定：PASS**

### 为什么通过

1. 赘婿 + 豪门婚姻 + 神医医武，是非常成熟、读者一眼可识别的母体。
2. 不靠开局离婚把最有价值的旧关系直接用完，妻子和岳家会长期记住每一次身份变化。
3. 前三章家族生死局能让“最没资格说话的人”第一次变成必须听的人。
4. 第20章留下夫妻关系、家族决策权、长期利益对手、独立人脉和外部称呼变化。
5. 同一人物见过真本事后，后续冲突升级成利益、控制和立场，而不是重复怀疑“你会不会医术”。
6. 到100章仍围绕“他到底只是某家的赘婿，还是本人就是一个社会身份”推进。

### 必须守住的红线

- 岳家不能反复失忆。
- 妻子不能变成“永远站主角这边”的奖品，也不能为了持续低位强行无脑冷脸。
- 新圈层的误判必须有新的合理理由，不能把“赘婿废物”台词跨地区复制。

### 与热门母体的相似边界

目前借用的是成熟的赘婿、豪门、神医、婚姻低位和身份翻身功能，没有看到具体热门桥段改名重写。

---

## 方案三｜被逐出医院的年轻医生：所有人都知道他“出过事”，但真正的急症还得找他

**判定：PASS**

### 为什么通过

1. 主角仍然是医生，核心仍是神医式的不可替代，不是发明冷门职业。
2. “公开负面记录”让新人物不信他有合理原因，比单纯看衣服、看工资更稳。
3. 前三章突发急症能马上完成“知道黑历史的人仍被事实迫使改口”。
4. 第20章已有专业见证人、长期患者、旧案动摇、有限会诊入口、旧同事利益冲突。
5. 旧同事和新合作医生都能在没有新病例时制造责任、规则和名誉冲突。
6. 100章后身份问题能从事故污点自然升级为“地方实战名医能否进入更高权威体系”。

### 必须守住的红线

这个方案最危险的不是流水线，而是写成：

> 医疗事故调查 + 程序翻案 + 医院职场争论。

旧事故只能是主角低位的根，不能成为小说真正的主商品。每一次身份改变仍必须优先由“关键时刻主角能解决别人解决不了的医疗问题”来兑现。

### 与热门母体的相似边界

目前是都市神医和职业污名入口的组合，没有发现具体热门人物、病例或事件顺序的复制。

---

## 方案四｜中医世家旁支：他们可以不认我这个人，但病人只认谁能把命救回来

**判定：PASS**

### 为什么通过

1. 都市神医、中医世家、旁支低位、针灸医武、高位病人，这些都在成熟母体里。
2. 前三章就能完成“家族最不承认的人反而救下最重要病人”。
3. 第20章留下独立病人口碑、家族派系、长期同辈竞争、家族外社会关系、父辈旧事。
4. 同一个家族会记账，主角每次证明都会真正改变病源、品牌、利益和行业位置，不需要每次换一个豪门重开。
5. 父亲、嫡系同辈、掌权长辈都有自己的目标，关系能持续制造剧情。
6. 到100章仍然是“谁才是真正值得被承认的神医”，只是范围从家族、本地扩大到更高医道圈。

### 必须守住的红线

- 不能写成“嫡系名医每次都诊错，主角每次一针治好”。
- 家族会议、传承名分解释不能比患者和现实结果更重。
- 父辈旧事不能升级成抢走整本书的家族阴谋。

### 与热门母体的相似边界

目前使用的是中医世家、旁支、名医、病人口碑和社会上升这些成熟元素，没有看到具体热门桥段照搬。

---

# Pool 3｜诡异降临反猎杀：收容 / 吞噬 / 驾驭异常

## 方案一｜诡异复苏：第一只诡成了我的影子

**判定：PASS**

### 为什么通过

1. 都市诡异复苏、普通人先被猎、收容异常、自身怪谈化、机构持续介入，母体清楚。
2. 前三章完成“影诡从外部猎手变成主角长期异常状态”的所有权翻转。
3. 第一只影诡不会被下一只异常替代，真正留下来。
4. 第20章除了影诡本身，还有妹妹关系、机构身份和更高异常对主角的重新分类。
5. 妹妹和观察员都有自己的目标，不只是任务发布器。
6. 100章后的问题仍是“这个人和这道影子最后会变成什么”，没有必须换世界才能续。

### 必须守住的红线

最大风险是把“一条影子”写成隐藏技能栏：

> 新诡 → 影子学会新功能 → 下一只。

“新异常改写旧状态”本身还不够。下一轮必须验证至少有一段主要剧情，是由影诡已有的自主性、妹妹已有的怀疑或机构已有的处置压力主动发动，而不是先来一只新诡才有故事。

### 与热门母体的相似边界

目前相似停留在诡异复苏、收容和自身怪谈化，没有出现具体热门异常、人物组合或事件序列的复制。

---

## 方案二｜诡异复苏：我每吞一只诡，就少像一点人

**判定：PASS**

### 为什么通过

1. 吞诡、肉身融合、异常进化、机构忌惮，是非常清楚的成熟母体。
2. 前三章直接完成“饿诡吃我 → 我把饿诡吞进身体”的反转。
3. 第一只饿诡永久成为所有后续吞噬的核心，不是一次性能力。
4. 第20章留下身体重组、正常饮食失效、家庭变化、机构档案和一次永久失败后果。
5. 母亲和机构医生都能独立制造“你还是不是人、还能不能自由行动”的冲突。
6. 100章仍然追“这具身体最后会变成什么”，核心体验没有换。

### 必须守住的红线

- 吞诡不能变成“杀怪掉技能”。
- 身体异化不能为了刺激不断往恶心、猎奇方向加码。
- “旧能力被消化掉”必须真的发生，否则所谓重组最后还是能力收藏。

### 与热门母体的相似边界

目前是成熟吞诡/肉身异化功能上的变化，没有看到具体异常能力或桥段的复制。

---

## 方案三｜诡异复苏：我和第一只诡共用一条命

**判定：PASS**

### 为什么通过

1. 开局被诡猎杀、快速驾驭、异常进入长期身体状态，仍然站在成熟母体里。
2. 前三章“替死诡拿主角顶命 → 反过来必须保主角活着”完成了非常明确的猎物反转。
3. 第一只诡本身就是长期关系，不会被更强异常替代。
4. 第20章留下共享生死、控制权变化、妹妹识别方式和机构双重收容判断。
5. 第一只诡、妹妹、机构负责人三条关系都有独立目标，可以不靠新副本自己制造冲突。
6. 100章后仍然追“这一条命到底属于谁、两者会变成什么”，主商品没有换。

### 必须守住的红线

这个方案只有一个非常致命的写歪方式：

> 第一只诡变成会吐槽、会护主、迟早洗白的脑内搭档。

只要它失去独立求生和争夺控制权的目标，长期发动机就会瞬间变成宠物系统。现有方案已经意识到这一点，后续必须用实际情节证明，而不是只写在设定里。

### 与热门母体的相似边界

目前创新停留在“第一只异常成为敌对共生关系”这一层，没有出现具体热门人物或桥段照搬。

---

## 方案四｜诡异复苏：我的名字成了禁忌

**判定：DROP FOR STRUCTURAL FAILURE**

### 为什么是结构性淘汰，而不是小修

这个方案的前三章并不弱，问题也不是“名字设定不够新”。

真正的问题是：**它的中心商品已经从诡异反猎杀，慢慢换成了“真名、传言、档案、社会认知如何塑造一个怪谈”。**

到第20章，最重要的长期状态包括：

- 真名触发规则；
- 家庭昵称；
- 机构档案处理；
- 危险代号；
- 城市禁忌传言。

到第20—100章，主要发动机又变成：

> 新异常进入 → 改写关于主角的怪谈规则 → 机构决定压制还是利用传言 → 家人和朋友重新适应身份。

这已经非常接近本轮明确要防的两类老问题：

1. **复杂规则替代题材爽点；**
2. **信息传播 / 档案 / 机构处理流程变成主要故事发动机。**

表面上它把所有规则都压进“同一个怪谈”，但结构上依然很容易变成：

> 新诡 → 新禁忌 → 新解释 → 新传播问题。

只是把多个技能栏换成了一个不断加条款的“主角怪谈说明书”。

### 为什么不判 REVISE

如果只是把机构戏减一点、关系戏加一点，核心问题仍然存在。

要真正回到本池，需要改变“真名 + 社会认知是核心异常承载体”这一中心设计本身；那已经不是小修，而是在重做小说核心。按本窗口规则，不能在这里生成替代方案，所以直接判结构性淘汰。

### 与热门母体的相似边界

没有看到具体热门作品桥段复制的问题。这里的失败点不是模仿过度，而是为了做出独特承载体，反而把读者体验推向了抽象规则和身份传播。

# 跨方案共同检查

## 1. 最常见的结构问题：把“写在设定表里的永久状态”当成真的永久状态

12个方案大多能列出3—5项长期状态，但下一轮不能只看有没有名字。

真正有效的永久状态必须做到：

> 后面有人因为前面的事，真的改变了行动、利益、关系或选择。

“建立档案”“有人记住”“有了口碑”“形成信任入口”如果不改变后续行为，都不能算。

---

## 2. Pool 2 普遍存在“更高圈层重新评价”的重置风险

四个方案都用到了某种：

> 本地已经承认 → 更高圈层仍然只知道一部分 → 再次证明。

这个结构本身可以用，但必须保证前一层成绩真的跟着主角走。

新圈层可以质疑：

- 能力能否在更高层成立；
- 是否依赖原有家族/地区资源；
- 是否有资格进入新的专业位置。

但不能再次质疑已经公开证明过的最低层事实，否则就是“全世界失忆”的换皮版本。

---

## 3. Pool 3 普遍存在“新异常改写旧异常”仍然可能是假反流水线

“不是新增技能，而是改写旧状态”比技能栏好，但它仍可能机械化：

> 新怪出现 → 吞/收/驾驭 → 旧状态改版 → 下一只。

真正通过长期测试，必须证明旧异常、旧关系、旧机构判断会在**没有新异常输入时主动制造故事**。

方案三目前这点最明确；方案一、二也具备关系基础，但下一轮要用实际测试证明。

---

## 4. 机构角色是目前最容易偷走主商品的工具

民俗池的固定调查人员、诡异池的观察员/医生/档案负责人都有长期价值。

但机构一旦同时承担：

- 发任务；
- 分级；
- 给权限；
- 解释世界；
- 调配资源；
- 评价主角；

就会把题材变成机构文。

本轮只有 Pool 1 方案四已经严重到需要 REVISE；Pool 3 方案四则和抽象规则问题一起构成结构性淘汰。其他方案仍可保留机构人物，但必须把他们限定为关系和压力来源，而不是万能故事接口。

---

## 5. 目前没有明显的具体桥段复制迹象

12个方案文本里没有直接使用具体热门作品的专名，也没有看到明显的“把某部热门前三章换名重写”的事件序列。

当前相似主要停留在：

- 题材母体；
- 身份入口；
- 核心爽点；
- 长篇状态积累方式。

这符合本轮允许学习的范围。

后续真正写开篇时仍要重新做一次桥段级检查；本轮只能证明核心方案层面暂未发现明显越界。
