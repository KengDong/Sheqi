# 3. C01｜阻断 Prototype 的四个具体修改

## BLOCKER A｜Ch4—5 不得连续两章“会展适配 / 救单”

当前：
> Ch4 有证也进不了门
> Ch5 两个人才拼成一个人

问题：
- 两章都主要在处理交付；
- 时间Concept不是不可替换；
- 紧跟Ch1—3后，极容易再次进入“职业专业化”。

Required:
1. Ch4—5最多只允许**一章**主要处理会展失败；
2. 保留“真钱亏损 / 真人受伤 / 身份不等于技能”中的最贵一个果实；
3. 另一章必须提前进入一个**非业务型社会 / 生活冲突**；
4. 新场面必须满足：
   > 若把“未来时间真实缺席”替换成普通劳务，整场就不成立。

建议由 architect 提供至少2个 Ch4—6 替代 spine，再选择一个。

---

## BLOCKER B｜Ch11—13 不能再是普通创业三连

当前语义：
> 不接大单 -> 漏掉卖家 -> 找协作者。

即使Scene Mode不同，Reader仍可能读成：
> 小团队升级。

Required:
1. Ch11—13里**最多一章**以组织扩容 / 工作容量为Primary；
2. 至少一章必须由固定人物自己的生活目标先启动；
3. 至少一章必须让沈峥暂时不是“解决业务的人”，而是被别人的人生反过来迫使重新定义自己的做法；
4. 方栀 / 韩驰 / 陈美兰 / 罗晴中至少两人要在这一段体现：
   > 他们不围着沈峥的事业活。

---

## BLOCKER C｜Ch20 不能主要是“机构级大客户来了”

可保留：
> 一百个人的周末。

必须改变：
> **场景发动机。**

Required:
1. “百人未来”必须已经在真实生活中发生冲突，而不是只在名单上；
2. 场面至少有三类独立利益方同时存在；
3. 空间 / 人群 / 组织制度必须直接改变沈峥的决策；
4. 沈峥不是只回答“接不接这单”，而是第一次真正站在：
   > 被定价者 -> 替别人定义未来边界的人
   的位置上；
5. 章尾Reader想到的必须是社会天花板，而非合同规模。

---

## BLOCKER D｜Recurring Character 必须从“独立欲望”产生事件

设计文档已经写了独立欲望，但下一版map必须再证明一层：

至少两条 recurring character 线满足：
> **即使沈峥今天不做时间生意，这个人今天也会遇到这件事。**

然后这件事反过来撞进时间经济 / 沈峥人生。

优先候选：
- 陈美兰自己的康复 / 工作 / 生活安排；
- 方栀自己的轮岗与职业边界；
- 韩驰的住房 / 成家 / 职业选择；
- 罗晴收入稳定后对周日的重新定价。

这不是加支线。
这是为了让小说真正有：
> **旁边一直有人。**

> **换一个地点、换一种职业名词以后，这一章的故事形状是否仍然完全一样？**

如果答案YES：
> 仍然可能是“舞台换景”。

# 7. D-0078 Selfcheck 的关键漏项

Selfcheck最重要的漏项不是少写一个风险，而是：

> **把Rolling-3主要按“场景模式 / 接口 / 人组”检查，却没有充分检查“语义发动机”。**

以后Rolling-3必须多问一题：

> **这三章虽然发生在不同地方、由不同人说话，但是不是仍然都在完成同一种职业成长任务？**

例如：
- 拒单；
- 处理容量错误；
- 招人；

外表不同，仍可能是普通创业同一个动作。

此判据写入后续 Prototype / Architecture Gate。
