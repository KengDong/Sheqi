# 为什么通过

1. 调查人员不再拥有稳定案源、顾问职位、常规资料推送或“解释不通就找主角”的制度入口。
2. 主要故事入口改为：
   - 旧当事人的后续选择；
   - 熟人社会在事情发生前的询问与误用；
   - 家庭利益变化；
   - 师门 / 外公旧人情；
   - 主角名声产生的现实后果。
3. 没有新公共案件时，方案已经明确给出四种不同故事发动方式，而且不是“新熟人上门”的简单替代流水线。
4. 固定调查人员保留为：
   - 现实校验者；
   - 反驳者；
   - 普通原因排查者；
   - 主角越界时的限制者；
   - 双向求证关系。
   他不再是任务发布器。
5. Ch20 的长期状态已经落实到行为变化，而不只是“存了号码 / 建了档案 / 有了合作入口”。
6. Ch100 的连续性由结构保证：
   - 无机构职位；
   - 无稳定案源；
   - 故事优先从旧关系发生；
   - 结果必须回写到人；
   - 公共系统只能碰上主线，不能持续生产主线。
