# Benchmark findings

## A1 benchmark
Primary:
> 《苟在初圣魔门当人材》

Observed strong mechanism:
- finite reset creates both safety and pressure;
- death/failure leaves usable information;
- replay is valuable because old causality is reinterpreted;
- repeated pleasure is failure → knowledge → replay → changed outcome → portable gain;
- strong warning: if restart becomes optimal-solution farming, the loop turns mechanical.

Therefore A1 must prioritize:
> **fear / causal discovery / changed second encounter / old pressure becoming controllable**

not:
> death-as-loot-table.

## A2 benchmark
Primary:
- 《从水猴子开始成神》
- 《玄鉴仙族》
- 《全民大航海，我开局一条幽灵船》
- 《末日逃亡：开局苍穹列车车长》

Observed strong mechanisms:
- ownership is visible and persistent;
- old investments keep changing future choices;
- growth expands what the protagonist can do, not just numbers;
- same core asset accumulates scars, facilities, people, roles, vulnerabilities and history;
- weak controls can also have beds/fridges/modules/upgrades, but if the engine becomes “next module / next reward”, ownership thins.

Therefore A2 must prioritize:
> **one persistent inner sect whose old parts keep gaining new use and relationships**

not:
> collectible micro-buffs for their own sake.

## A3 benchmark
Primary:
- 《1984：从川菜馆开始》
- 《全民大航海，我开局一条幽灵船》
- asset-compounding evidence from Pool 4

Observed strong mechanisms:
- low-stakes daily pleasure works when sensory / practical reward is immediate;
- repeated pleasure changes actual life;
- old customers / facilities / assets return and matter again;
- “small reward” is meaningful because it changes tomorrow’s choices or relationships;
- abstract warmth / abstract lore is weak.

Therefore A3 must first define:
> **a repeatable daily transaction whose payoff is concrete, useful, memorable, and later reusable**

before inventing individual funeral rewards.

# New hard rule

For every specific mechanic revision:
1. name the nearest strong references;
2. state exactly what their repeated pleasure loop is;
3. state which part is being borrowed at the structural-function level;
4. state what is being changed for originality;
5. only then propose the mechanism.

No mechanism may be accepted because it merely sounds clever.
