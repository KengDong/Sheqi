# 第一卷功能级阶段纲 Proposal｜开篇专项批准后重写版

> 本文件把已批准的第一卷故事发动机与已批准的开篇阅读合同，转成可供后续前三章事件卡 / 前10章章卡使用的功能级阶段纲。
>
> 不修改 Canon，不修改 approved Outline，不拆100章详细章纲，不写正文。
>
> 本轮不再竞争驿货行、两级现实目标、人物三圈结构、尝余误判原则、曹闻川灰度、中转流程长期叠加、三次正常修炼兑现，以及 C主结构 + A轻量舍备核验。

# 0. 总体状态机

第一卷不是：

> 事故 -> 获得特殊感知 -> 查怪货 -> 查仓库 -> 打余灾。

而是：

> 我快拿到资格了
> -> 我主动付出永久代价筑基，却因漏舍失去资格
> -> 我要证明自己还能正常工作
> -> 我靠正常筑基本事把资格拿回来
> -> 但有资格仍然没有自己的位置
> -> 我的缺位后遗症开始有用，也开始被别人安排、定价
> -> 我把真实信号解释错，伤到钱与信用
> -> 单件问题升级成流程问题
> -> 我拿到固定席位，也第一次必须为别人的安全、钱和自己的判断负责

四阶段功能区间：

- Phase A｜想转正，事故把路打断：约0%—18%
- Phase B｜限制复工，证明“我还能做”：约18%—50%
- Phase C｜有资格还不够，我要有自己的位置：约50%—78%
- Phase D｜固定位置意味着责任：约78%—100%

比例只控制功能密度，不锁具体章数。

Phase A的前三章默认硬测试：

> 第1章：人 + 文明 + 现实目标  
> 第2章：普通工作成立后事故打断  
> 第3章：主动舍味 + 筑基稳定离体 + 永久代价

第3—5章最多只允许不可控、未确认、可被解释为漏舍幻感的异常味。

前30章必须至少一次由事实证明：

> 有些东西就该舍。

# 1. Phase A｜想转正，事故把路打断

## 1.1 阶段开头状态

### 职业
陆野是驿货行短途杂役 / 押货杂役，已经进入正式押货资格的现实候选。

石小庚是同层竞争者。

### 修炼
- 炼气；
- 修积完成；
- 明悟完成；
- 已进入炼气 -> 筑基真实续关；
- 已在正规舍务体系主动完成味觉舍备；
- 货行只核验既有凭证，不重新定相、不替他选舍项；
- 尚未真正舍味。

### 关系
- 乔九知道陆野能干、便宜、肯补位，但更关心运力和空转；
- 石小庚与陆野有真实职业竞争，不是恶意对手；
- 生活锚点仍维持事故前普通合租生活；
- 罗槐、唐禾、周照、曹闻川不必前三章同时报到。

## 1.2 陆野最具体想要什么

> 保住正式押货候选位置，并拿到一次能提升评价或收入的高价值班次。

第一章读者必须知道：

> 他今天不是来参观舍弃制度，而是来争一个能多挣钱、往上走的位置。

## 1.3 谁最直接阻止

- 陆野尚未筑基；
- 石小庚正常基本功更稳；
- 正式押货本身有安全门槛。

没有反派。

## 1.4 配角自己的目标

乔九要：

> 减少夜间空车、压缩等待、把零散货次尽量拼满。

因此他会主动调整班次和人手。

这既给陆野机会，也为后续线路扩张建立因果。

# 1A. Phase A前三章硬结构

## 第1章功能｜人 + 文明 + 现实目标

### 人
陆野必须先有一个普通、低风险、无主线价值的惜物动作。

功能标准：

> 货场一个廉价运输小件被判该报废；陆野多检查一步，确认主用途不能再承担，但仍可安全拆下一个小零件或转作非承重用途。

硬边界：
- 不成为事故原因；
- 不变宝；
- 不救命；
- 不成为余器；
- 不承担后续伏笔；
- 不让人物围着它讨论“你怎么这么惜物”。

它只证明：

> 陆野不接受一个“废”字替代判断。

### 文明
工作核验中轻量确认：

> 陆野自己早已在正规舍务体系办理的味觉舍备仍有效。

货行只做：
- 看凭证；
- 验有效状态；
- 确认本班次是否允许其进入候选 / 高风险工作范围。

货行不做：
- 人格扫描；
- 候选推荐；
- 定相；
- 重新判断味觉值不值；
- 强迫陆野临场交出一块自己。

### 现实目标
陆野今天要：
- 班次；
- 候选评价；
- 更高工钱。

### 正常味觉基线
第1—2章之间必须有一个极短自然基线。

只需让读者知道：
> 陆野现在还能分辨咸淡、苦涩或难吃。

不做最后一顿美食式煽情。

---

## 第2章功能｜普通工作成立后事故打断

事故不能一开章就吞掉职业线。

先让读者看到：
1. 陆野确实会干普通货运活；
2. 正常炼气能做什么；
3. 石小庚不是摆设；
4. 陆野惜物不等于乱留危险物；
5. 乔九的排班 / 周转目标正在现实推进。

然后事故进入。

事故必须与第1章陆野留下的普通破件完全无关。

---

## 第3章功能｜主动舍味 + 筑基新权限 + 永久代价

必须视觉上分清：

> 舍味 = 降低本次续我负担。  
> 筑基 = 获得稳定离体。  
> 漏舍 = 封位失败留下的后遗症。

第3章完成：
- 陆野知情、主动启用既有味觉舍备；
- 舍味成功；
- 筑基成功；
- 稳定离体完成炼气阶段无法持续完成的救援；
- 封位不全；
- 高危资格被冻结或进入安全复核；
- 味觉不可恢复至少得到事实确认。

第3章不必同时塞满所有后果。

只保证三条债成立：

1. 工作债：筑基了，资格反而被冻结；
2. 生活债：味觉永久消失；
3. 异常债：漏舍后遗症仍有未知部分。

---

# 1B. 第3—5章异常味边界

第3—5章最多允许一次：

> 短促、不可控、无法稳定复现的异常味。

陆野与医生 / 事故处理人员可以合理理解为：

> 封位不全后的幻味 / 神魂残感。

禁止：
- 某箱子一靠近就稳定有味；
- 靠近 / 离远做对照；
- 随机换箱；
- 闭眼定位；
- 确认异常来自外界；
- 暗示被舍掉的味觉跑到外面；
- 暗示弃相没有消失。

外界来源确认继续服从秘密释放梯。

---

## 1.5 私人生活损失落地

事故以后不能马上开始第二个神秘事件。

至少有一段真实生活：

> 陆野第一次面对吃东西真的没有味道。

生活锚点因此进入。

重点是：
- 买什么；
- 谁做饭；
- 为什么还要为味道花钱；
- 原本共享生活习惯怎样变得不再对称。

## 1.6 陆野Phase A的判断错误 / 成本

他的错误不是：
> 味觉其实特别强，所以不该舍。

味觉对这次续关确实：
- 真实；
- 可切；
- 足够；
- 比痛觉、嗅觉、睡眠等更舍得起。

他的错误在于：

> 早期过度按是否影响挣钱、搬货、活命衡量自己的一部分，低估了普通生活价值。

成本：
- 味觉永久缺位；
- 漏舍；
- 资格冻结；
- 工资 / 班次受影响；
- 私人生活习惯改变；
- 石小庚获得更稳定竞争窗口。

## 1.7 Phase A结束时永久改变什么

- 职业：候选上升期 -> 资格冻结；
- 修炼：炼气 -> 筑基；
- 自我：味觉永久缺位；
- 特殊状态：漏舍者；
- 私人生活：至少一项日常无法恢复事故前状态；
- 读者合同：这个世界真的把舍掉自己当现实选择，陆野真的付了代价。

## 1.8 为什么成功制造Phase B

陆野成功筑基。

按他原本理解，这应该让正式押货更近。

实际：

> 力量条件通过了，安全适任性反而出现新问题。

所以下一阶段自然变成：

> 我要证明自己还能做这份工作。

## 1.9 Phase A只盯3件事

1. 资格；
2. 主动舍味的现实选择；
3. 永久损失进入生活。

# 2. Phase B｜限制复工，证明“我还能做”

## 2.1 阶段开头状态

### 职业
- 停岗 / 医疗观察后；
- 正式押货资格冻结；
- 最多先进入限制性复工。

### 修炼
- 新筑基；
- 已获得稳定离体；
- 控制、经验、普通法器使用仍处新境初段。

### 关系
- 石小庚更像稳定候选；
- 乔九想恢复可用运力；
- 周照进入安全复核；
- 罗槐成为现实安全标尺；
- 唐禾逐步进入赔偿、货损与客户线；
- 生活锚点已经承受陆野失味后的生活变化。

## 2.2 陆野想要什么

前半：
> 先恢复能挣钱的限制性工作。

后半：
> 通过真实试岗，拿回正式押货资格。

Phase B不是等结果，而是陆野主动：
- 争取可做任务；
- 练新筑基本事；
- 证明适任；
- 处理事故后现实后果。

## 2.3 谁阻止

### 周照
安全条件不到，不能放。

### 罗槐
制度允许不等于他愿意带刚漏舍的新筑基跑高风险线。

### 石小庚
用正常基本功证明：
> 没有陆野的特殊性，货行也有可靠候选。

## 2.4 配角目标

- 罗槐要保住长期安全记录与现场判断权；
- 乔九继续拼零散夜线；
- 唐禾开始保护自己的客户信用。

这些目标不因陆野停岗而暂停。

## 2.5 Phase B关键事件功能

### 功能1｜限制复工
对应骨干节点4前半。

任何复核节点只有在改变以下至少一项时才值得单独占戏：
- 工钱；
- 可接任务；
- 谁愿意带他；
- 安全责任；
- 修炼机会；
- 异常认知。

否则压缩。

### 功能2｜异常逐步走向外界确认
对应骨干节点4后半。

Phase B早段仍可反复出现无法稳定解释的异常味。

到秘密梯允许窗口后，才进行：
- 离远 / 靠近；
- 换位；
- 重复；
等受控验证。

最终只确认：

> 少数外界旧物 / 区域确实会触发陆野的异常味。

此时仍可误解为：
> 舍务污染 / 外界残留。

不能直接确认人的弃相。

### 功能3｜前30章“该舍就舍”正确判断
对应骨干节点5。

必须让罗槐或同类现实人物做一次：

> 弃货 / 弃风险源。

而且事实证明：
> 他是对的。

最好完全不依赖余世谜团。

功能是反证：

> 惜物不是作者正确答案。

陆野真正该成长为：

> 先验证，再决定保留、利用、隔离还是放弃。

### 功能4｜纯传统修仙试岗
对应骨干节点6。

必须有一次：
> 尝余 = 0。

靠：
- 筑基稳定离体；
- 普通法器；
- 路线经验；
- 队伍配合；
- 安全判断。

石小庚至少有一个关键操作：
> 陆野做不到，他能做到。

推荐仍以御器精度 / 稳定控制作为强候选，但不锁具体招式。

这次任务成为：

> 陆野拿回正式资格的主要证据。

## 2.6 可容纳的弹性功能
最多再加1—2项：
- 窄用途异常旧物 / 余器第一次极窄验证；
- 唐禾客户线第一笔现实选择；
- 乔九线路扩张的小成功。

不能全部做成独立大单元。

## 2.7 陆野判断错误 / 成本

错误1：
> 我都筑基、还救了人，为什么不能直接恢复？

现实答案：
> 高危岗位不仅评价够不够强，也评价别人能不能预测你。

错误2：
外界来源开始被确认后，他会滑向：
> 我尝到了 = 这东西就是问题源头。

Phase B只埋这个错误，真正付大代价留给Phase C。

成本：
- 工资只部分恢复；
- 工作权限受限；
- 必须接受陪同和复核；
- 石小庚持续构成正常职业压力；
- 英雄救人不能抵消安全判断。

## 2.8 Phase B结束时永久改变什么

- 职业：限制复工 -> 正式押货资格恢复；
- 修炼：刚筑基 -> 已证明能用筑基本事完成真实工作；
- 能力认识：幻感 -> 少数外界对象确实能稳定触发；
- 人际：罗槐认可“能做”，石小庚成为长期标尺，周照成为可重复碰到的监管接口。

## 2.9 为什么成功制造Phase C

陆野成功拿回资格。

但资格只意味着：

> 能做。

乔九前半卷自己的线路扩张成功，又制造出：

> 有限的固定路线 / 固定小队席位。

陆野第一次看见：

> 有牌，不等于有位置。

所以下一步自然是：

> 我要一个不会随时被换掉的位置。

## 2.10 Phase B只盯3件事

1. 复工 / 拿回资格；
2. 正常筑基本事；
3. 尝余只是一条有限信息。

# 3. Phase C｜有资格还不够，我要有自己的位置

## 3.1 阶段开头状态

### 职业
陆野已经拿回正式押货资格，但仍可能：
- 按缺口排班；
- 收入波动；
- 被同境散工替代；
- 对路线无稳定话语权。

### 修炼
筑基能用于工作，但传统基本功仍有短板。

### 关系
- 石小庚继续竞争固定席位；
- 乔九线路扩张开始兑现；
- 唐禾客户信用进入主线；
- 生活锚点感受到陆野收入 / 作息变化。

## 3.2 陆野最具体想要什么

> 拿到固定路线 / 固定小队席位。

他真正要的是：
- 稳定收入；
- 可预测排班；
- 固定资源；
- 有话语权；
- 不再随时被替掉。

## 3.3 谁阻止

### 石小庚
正常基本功更稳。

### 乔九
他要的是对线路最合适的人，不是照顾主角。

### 陆野自己的特殊性
尝余开始被现实认为有价值。

这会帮他，也会让他的职业价值越来越容易被缩写成：

> 那个漏舍后能尝异常的人。

## 3.4 配角目标

- 乔九要把试跑线路做成长期线；
- 唐禾要维护自己的长期客户信用；
- 石小庚要证明固定席位不能只看谁特殊；
- 生活锚点至少一次为自己的工作 / 住处 / 钱做决定。

## 3.5 Phase C关键事件功能

### 功能1｜尝余进入现实价值
对应骨干节点7前半。

可以表现为：
> 有事故旧货 / 退货的任务更愿意排陆野，或出现小额异常风险补贴。

陆野初期应真实高兴。

同样上工，多拿钱，本来就是好事。

### 功能2｜一次窄用途拾余验证
若保留弹性槽，只做到：

> 某件别人认为没有正常用途的异常旧物，在一个非常具体条件下有极窄用途。

必须先处理：
- 产权；
- 风险；
- 谁能用。

不能进入：
- 卡牌收集；
- 余器库；
- 行业发明。

### 功能3｜感知真实、归因错误
对应骨干节点7后半。

推荐仍采用：

> 可复用普通运输衬垫 / 捆扎物沾有真实余痕。

陆野感知到的信号是真的。

错的是：

> 把余痕现在在哪里，当成源头就是眼前货物。

现实损失：
- 无辜时效货被临时封 / 延误；
- 货主损失；
- 唐禾长期客户信用受伤；
- 货行承担赔偿；
- 陆野职业信誉下降。

误判后不能升级新扫描模式。

他只学到：

> 有信号 ≠ 知道源头。

## 3.6 必须有真正开心的奖励段

误判前至少允许一次：
- 正式资格带来的明显收入提升；
- 更稳定排班；
- 买 / 修普通实用法器；
- 队伍顺利分钱；
- 生活条件稍微改善。

读者必须有时间感受：

> 努力确实有用。

## 3.7 陆野错误 / 成本

最大错误：

> 把感知到余痕当成找到余痕源头。

能力没变规则，证据理解错了。

成本：
- 钱；
- 客户信用；
- 唐禾职业信任；
- 团队不能再把“陆野有味”当直接判据；
- 固定席位评议时，特殊能力同时成为优势和风险。

## 3.8 Phase C结束时永久改变什么

- 尝余：从有用特殊信息 -> 必须被验证的信息；
- 唐禾与陆野形成未清信用债；
- 组织明确：尝余不能独立作证；
- 陆野第一次明显感到缺位正在被定价；
- “为什么普通共享运输材料也会有余痕”成为现实问题。

## 3.9 为什么成功制造Phase D

Phase C真正的成功是：

> 陆野的异常感知已经有用到足以进入任务安排。

正因为组织开始依赖它：

> 错误归因才会造成真实组织成本。

误判又逼出问题：

> 如果当前货物没有问题，真实余痕为什么会出现在普通共用材料上？

于是问题自然从：

> 哪件货有问题

升级成：

> 哪些共享环节正在传播 / 积累问题。

## 3.10 Phase C只盯3件事

1. 固定席位；
2. 配角自己的利益线；
3. 特殊能力从有用走到误判有代价。

# 4. Phase D｜固定位置意味着责任

## 4.1 阶段开头状态

### 职业
- 有正式资格；
- 正在争固定席位；
- 一次误判让特殊能力同时成为优势和隐患。

### 修炼
筑基稳定，但不足以单人处理大型余灾。

### 能力
尝余有价值，但已经被证明不能独立下结论。

### 关系
- 队伍开始真正信任陆野干活；
- 唐禾、石小庚、周照对其证据边界有明确保留；
- 曹闻川与周照风险阈值冲突进入前台。

## 4.2 陆野想要什么

前半：
> 别让一次误判彻底毁掉固定席位机会。

余灾真正爆发以后：
> 先把人和这条线安全处理掉。

此时不能还只算升职分。

## 4.3 谁阻止

没有单一反派。

- 曹闻川：证据不足时反对整线停运；
- 周照：安全无法证明时反对继续把风险往下游送；
- 环境：余痕已经从单件货迁移到共享材料、载具、节点并发生复合。

## 4.4 配角目标

- 曹闻川要保住业务和几十人的生计；
- 周照要阻断风险扩散；
- 乔九要保住自己扩成的线路；
- 唐禾要弄清客户货流在哪些环节被影响；
- 罗槐要判断什么必须舍、什么绝不能随便往外扔。

## 4.5 Phase D关键事件功能

### 功能1｜确认问题不是单件货
对应骨干节点8前半。

只需3—4类现实证据：
- 共用运输材料；
- 多批交叉货流；
- 高周转旧节点；
- 单件检查解释不了整体分布。

不要把完整流程因果一次讲成报告。

### 功能2｜风险阈值冲突
曹闻川与周照都必须至少一次：

> 从自己的责任出发说得通。

尝余只能证明：
> 这里确实有异常信号。

不能证明：
- 整条线必须停；
- 哪个环节一定是源头；
- 风险等级到底多高。

### 功能3｜复合余灾
对应骨干节点8后半。

高混杂环境中：

> 到处都是味。

尝余接近失效。

最终依靠：
- 陆野正常筑基；
- 普通法器；
- 石小庚传统基本功；
- 罗槐风险判断；
- 乔九人车调度；
- 唐禾货流记录；
- 周照封控；
- 曹闻川设备与人手；
共同解决。

这是正常修炼第三次硬兑现：

> 个人修炼进入团队系统。

### 功能4｜流程整改 + 固定席位
危机后再结算。

不能：
> 封一个仓库，第二天恢复原样。

至少一项：
- 复用；
- 暂存；
- 混运；
- 待检；
发生真实变化。

同时留下：
- 效率下降；
- 成本上升；
- 谁承担成本未完全解决。

陆野获得固定席位。

这个位置第一次真正意味着：

> 别人会依赖他的决定，也会追责他的判断。

## 4.6 Phase D成本

不需要再制造一个新主角错误。

前一阶段误判继续存在：

> 卷末救人不能把客户损失和唐禾信用债清零。

同时陆野第一次看清：

> 一种能力一旦进入岗位价值，就会出现使用义务、拒绝权、赔偿责任和价格。

第一卷只打开，不建立完整制度。

## 4.7 Phase D结束时永久改变什么

> 陆野终于得到别人不容易替掉他的位置，也因此第一次变成别人会依赖、会追责的人。

## 4.8 为什么成功制造下一阶段问题

固定席位给他：
- 钱；
- 稳定；
- 资源；
- 话语权。

同时给他：
- 安全责任；
- 判断责任；
- 临时杂役责任；
- 任务依赖；
- 尝余是否属于岗位能力的问题；
- 流程整改新成本；
- 未清客户信用债。

下一阶段无需更大怪物。

因为：

> 他终于得到想要的东西，现在必须负责它。

## 4.9 Phase D只盯3件事

1. 单件问题变流程问题；
2. 正常修炼 + 团队主解余灾；
3. 真奖励带来责任，但不清空旧债。

# 6. 弹性单元筛选

## 6.1 乔九线路扩张独立事件｜保留

删除会导致：

控制：
> 只做一次具体成功：乔九把零散夜运做成长期试跑 / 扩容线。

决定：
> 保留。

## 6.2 唐禾客户线｜保留，合并进骨干7

解决：
> 误判代价不能只有公司赔钱，要伤到配角多年积累的信用。

前置：
> 唐禾曾为了长期客户放弃一次更高短期收益。

后果：
> 误判真的伤到这条关系。

决定：
> 保留功能，不独立开大单元。

---

解决：
> 私人生活不能只在无味饭出现一次。

第二次冲突最好来自：
- 房租；
- 作息；
- 工具占地；
- 对方自己的工作目标；
- 陆野工作稳定后的生活变化。

决定：
> 保留。

解决：

只做到：
> 某件被判无正常用途的异常旧物，在一个具体条件下有极窄用途。

第一卷只允许一个真正被读者记住的窄用途验证。

若章卡解释负担过高，优先砍。

决定：
> 保留弹性槽，不锁具体器物。

# 8. 第一次事故动作链候选A｜固定中转台绞架 / 导向件事故【推荐】

## A1. 为什么陆野当天在场
他在做自己争取来的：

> 夜间高价值 / 高风险普通转运班。

这班次影响：
- 工钱；
- 正式候选评价。

## A2. 他原本在做什么
第2章先正常工作：
- 搬运；
- 固货；
- 查绳扣；
- 用炼气做短时灌力 / 辅助操作；
- 与石小庚形成真实基本功差异。

## A3. 什么先异常
固定中转台一处：

> 绞架主锁 / 导向件 / 承重转向件

发生普通机械或低阶法器故障。

首先只是：
> 重载架偏斜、滑移。

## A4. 为什么升级
偏斜货架 / 支件撞伤一件：

> 按现有规则允许外围转运的低风险封存退件 / 舍务废件。

异常泄出。

同时撞击 / 波及附近应急舍台：

> 封位外环。

第1章陆野留下的普通破件与此完全无关。

## A5. 为什么不能第一秒全撤
同时发生：
1. 一名普通装卸工 / 临时工被卡在偏斜承重架下；
2. 货架继续滑落会撞向更多人 / 货；
3. 异常区域不适合人员长时间直接进入。

## A6. 为什么筑基后才可能完成
救援需要从安全线外：

> 持续稳定控制普通牵引扣 / 制动锁 / 御器钩，让偏斜重载架保持固定角度。

炼气能短时灌力，但做不到：

> 力量离体后仍在数丈外持续稳定、精细受力。

筑基稳定离体刚好提供新权限。

## A7. 为什么能当场舍破
陆野已经：
- 修积完成；
- 明悟完成；
- 处于真实续关；
- 味觉舍备事前有效。

现场只能调用既有舍备。

## A8. 为什么主动启用
值守人员明确告知：

> 封位外环受损，启用存在漏舍风险。

但：
- 被困者时间不足；
- 专业救援正在来；
- 陆野是时间窗口内能通过真实筑基完成救援的人。

他主动决定。

## A9. 为什么切离 / 导余主体仍工作
舍台核心：
- 既有定相记录调用；
- 舍契执行；
- 切离 / 导余主体；
位于更深保护层。

损坏主要落在最终封位外环。

所以：
- 切离成功；
- 筑基成功；
- 封位不完整；
- 漏舍。

## A10. 谁执行封余抢救
当班未命名舍务安全 / 急救值守人员。

负责：
- 封余针；
- 隔余布；
- 临时封具。

乔九只做：
- 清人；
- 调救援；
- 调车；
不变舍务专家。

## A11. 筑基稳定离体完成什么
陆野从安全线外：

> 持续御使普通牵引 / 制动结构，使偏斜货架稳定在可救援角度。

其他人：
- 拉出被困者；
- 上副支撑；
- 切断危险连接。

读者一眼看到：

> 不是更大力，而是力量出去以后还能稳稳做事。

## A12. 为什么资格冻结
- 刚漏舍；
- 适任性未知；
- 新筑基本身需适应；
- 事故仍需调查；
- 英雄功劳不能替代安全复核。

所以：
> 功劳归功劳，资格照冻。

## A13. 事故信息预算

当场明确：
- 舍备早就办好；
- 味觉是陆野自己备案选择；
- 舍味是主动决定；
- 筑基给稳定离体；
- 封位外环坏；
- 漏舍是已知事故类型。

当场不解释：
- 泄漏物具体深层来源；
- 余世；
- 弃相去向；
- 为什么以后会幻味；
- 中转流程长期叠加风险。

# 9. 事故动作链候选B｜装卸坡道承重车架侧倾

## B1. 当天在场

## B2. 普通工作

# 11. 开篇修籍 / 验章 / 舍备核验

## 11.1 谁看
推荐：

> 乔九在排班时顺手核验。

理由：
- 他本来就决定谁上哪班；
- 核验直接改变陆野能否进入高价值班次；
- 不新增修籍管理员抢前三章记忆位。

乔九不是舍务人员。

## 11.2 载体
阶段纲层推荐：

> 纸质 / 薄册式修籍凭证 + 正规舍务机构有效印证。

不锁美术形式。

避免发光面板、数字条、人格列表。

## 11.3 为什么要看
因为陆野在争：
> 高风险 / 高价值候选押货班次。

又已处于真实续关。

货行只需要确认：
- 修籍有效；
- 本人既有应急舍备有效。

不自动推出所有岗位都必须舍自己。

## 11.4 读者只看到3项
最多：
1. 炼气；
2. 筑基积、悟已验 / 已到续关；
3. 既有味觉舍备有效。

不显示：
- 百分比；
- 舍值；
- 候选菜单；
- 天赋；
- 战力；
- 最优推荐。

## 11.5 一句现实对话
功能上可以是：

> “积、悟都过了，续还没成；你那份味觉舍备还有效？”

读者只需要知道：

> 陆野不是修为没练够，他卡在突破最后一步。

## 11.6 防止公司强制献人格
语义必须强调至少一项：
- 你自己办的舍备；
- 舍务那边的章还有效；
- 这班只核验你现有预案。

不出现：
> 公司给你选了味觉。

## 11.7 只展示一次
第一章以后不反复讲修籍。

事故时只回收：

> 那份已存在的舍备现在真的可以调用。

事故后周照看的是更新后的事故 / 资格状态，不是第二堂世界观课。

# 12. 生活锚点版本A｜规整型手艺学徒【推荐】

姓名、性别、具体手艺暂缓。

## 性格
- 讲秩序；
- 不爱欠人；
- 不做温柔治疗型；
- 对贫穷现实，但不接受穷就什么都凑合；
- 觉得生活空间应该有边界。

## 当前生活目标
> 完成第一单真正由自己独立负责的手艺活，攒自己的基础工具。

## 为什么合租这么久
- 房租可承受；
- 陆野会修屋里小东西；

- 两人都不是会跑路欠租的人；
- 比重新找陌生室友省心。

## 谁更会做饭
> 旧友明显更会。

陆野只要求能吃、顶饱、便宜。

## 谁更爱占地方
> 陆野。

他总觉得修下来的旧零件以后也许有用。

## 钱的关系
不设大债。

只保留：
> 房租 / 柴米偶尔互相垫，月底再算的小账。

## 对陆野真实反应
- 认可他可靠；
- 真烦他“这个也留、那个也修”；
- 嘴贫好笑时好笑，赶活时只想让他闭嘴；
- 不崇拜修士身份。

## 失味后第一处冲突
陆野开始按：
> 最便宜、最顶饱

选伙食。

旧友不接受：
> 你没味，不代表我也没味。

结果可能是：
- 伙食钱重新分；
- 共锅频率下降；
- 谁做饭重新分配。

不锁“同屋各灶”为唯一结局。

## 第一卷至少一次独立选择
为自己的独立手艺活：

> 连续占用住处最平整 / 最亮的工作位置，并要求陆野清掉一部分占地旧件。

这场冲突完全不服务余世。

## 为什么不会变安慰NPC
对方首先关心：
> 自己的手艺、工具、钱和空间。

陆野心情不好，对方也可能先问：
> 你今晚到底腾不腾桌子？

## 卷末可能变化
仍合租，但伙食 / 工具 / 空间边界已与事故前不同。

# 16. 四阶段秘密释放表

## Phase A｜只有漏舍异常，没有外界答案

### 读者能知道
- 舍破是成熟现实；
- 陆野舍味成功；
- 漏舍成立；
- 漏舍后可能出现异常感受。

### 陆野能知道
同上。

### 暂时错误理解
> 封位不全后神魂会乱放旧味 / 产生幻味。

### 绝不能解释
- 异常来自外界；
- 某旧物与异常稳定相关；
- 人的弃相残留；
- 余世；
- 弃相没有消失。

### 新信息改变谁的行动
- 货行冻结资格；
- 周照 / 医疗复核；
- 生活锚点调整日常。

---

## Phase B｜从可能是幻觉到外界确实有对应

### 读者能知道
Phase B前段：
> 异常味会重复，但仍不稳定。

到秘密梯允许窗口：
> 少数旧物 / 区域可以重复定位。

### 陆野能知道
> 不是所有怪味都只来自自己的脑子。

### 暂时错误理解
> 舍台污染 / 类似灵气泄漏 / 舍后工业残留。

### 绝不能解释
- 明确“人的弃相”；
- 弃相统一去向；
- 余世；
- 截流。

### 新信息改变谁的行动
- 乔九偶尔让陆野顺手提示异常；
- 周照要求只能作风险提示；
- 陆野第一次觉得后遗症可能有现实价值。

---

## Phase C｜从污染走到可能是人的残留，并建立证据边界

### 读者能知道
在秘密梯允许的更后窗口：
- 不同异常味有稳定差别；
- 某些差异与不同舍修经历有关；
- 真实余痕可附着在普通承载物；
- 某些异常旧物有极窄现实效用；
- 感知位置 ≠ 真正来源。

### 陆野能知道
> 自己感知的东西可能与人舍下来的东西有关。

### 暂时错误理解
> 舍弃留下的脚印 / 工业残留。

### 绝不能解释
- 统一余层；
- 正规舍台完整知识；
- 大规模截流；
- 若秘密梯尚未到对应窗口，不提前宣布“弃相没有消失”的完整结论。

### 新信息改变谁的行动
- 尝余进入排班；
- 误判迫使唐禾、乔九、周照改变证据标准；
- “陆野有味”不能直接判货。

---

## Phase D｜确认残留会迁移、混杂、积累并反向影响现实

### 读者能知道
到第一卷允许上限：

> 一份有效舍后残留可以离开原位置、附着别处、聚集并重新表现某些性质。

官方长期存在封存 / 清理 / 处理实践。

### 陆野能知道
基本同层。

### 暂时错误理解
> 归根到底仍是复杂污染。

### 绝不能解释
- 完整余世结构；
- 弃相统一去向的完整机制；
- 导余网络全貌；
- 截流产业；
- 余世主体性。

### 新信息改变谁的行动
- 曹闻川接受流程整改；
- 周照调整局部监管；
- 乔九承担效率损失；
- 唐禾调整客户承诺；
- 陆野尝余被定义为有价值但不能独立作证。

## 石小庚
- 从资格竞争者变成长期同队 / 同路线竞争伙伴；
- 至少一项传统基本功明显强于陆野；
- 不降格成小弟。

## 乔九
- 线路扩张成功；
- 同时承担效率、人员、风险压力；

## 唐禾
- 长期客户 / 信用线存在；
- 误判损失不因卷末功劳清零；
- 开始从算一单走向算长期责任边界。

## 周照
- 继续是外部监管；
- 与陆野 / 货行形成更成熟的信息协作；
- 不加入固定队。

## 曹闻川
- 不黑化；
- 风险证实后主动调人、停损、承担运营损失；
- 仍会与周照争成本和风险阈值。

## 生活锚点
- 与陆野至少一项事故前生活习惯永久改变；
- 有自己的工作和选择；
- 不变安慰NPC。

## 队伍
- 信任形成；
- 分成、风险、判断仍不完全一致；
- 固定席位代表别人真的会依赖陆野。

## 谜团
- “余味只是纯幻觉”被否定；
- 残留可附着 / 迁移 / 混杂 / 积累得到局部验证；
- 完整余世仍未知。

## 流程
- 旧中转流程不能完全恢复；
- 至少一处复用 / 暂存 / 混运规则变化；
- 新流程带来真实成本。

# 21. 20—30章复盘模板

每写约20—30章，用12问：

1. 陆野现在最具体想得到什么？
2. 他的社会位置与20—30章前有什么实际不同？
3. 他新增了什么责任，而不只是奖励？
4. 哪个旧结果回来咬他或帮他？
5. 至少一个常驻配角自己的目标有没有推进？
6. 如果尝余连续10章不能用，故事还能不能动？
7. 正常修炼有没有至少一次改变解决问题的方法？
8. 最近一个谜团有没有给真答案，而不是只加更大秘密？
9. 私人生活有没有显示陆野已不是事故前状态？
10. 未来3章以内陆野有什么今天能做的即时欲望？
11. 陆野惜物最近有没有退化成“什么都不扔”？
12. 最近是否把异常味写得比秘密梯允许的更聪明？

若6题以上答不清，先修结构。

# 22. 砍支线条件

章卡阶段，一个弹性单元若大多符合以下条件，直接砍：

- 不改变人物关系；
- 不改变职业 / 组织状态；
- 不改变陆野做事方法；
- 不留下钱、信用、责任或承诺；

- 需要新地图 + 新角色 + 新规则；

- 只在重复证明舍弃文明很有趣。

研究阶段设计得漂亮，不构成保留理由。

# 23. 自我红队｜16问

1. 第一章是否太像主题作文？  
   若“破件 -> 舍备 -> 有人直接说你连东西都舍不得却舍自己”，失败。

2. 第一件破物是否变成隐形伏笔？  
   必须不事故、不救命、不变宝、不成余器。

3. 舍备核验是否被读成公司强迫献人格？  
   必须明确是陆野本人事前在正规舍务体系办好的。

4. 修籍是否变系统面板？  
   一旦出现百分比、舍值、候选列表、推荐、战力，失败。

5. 前三章信息是否过多？  
   主动不讲余世、余器、三问技术、借载百科、乔九舍眠完整规则。

6. 三章舍味是否太快？  
   这是章卡硬测试，不是Canon。先删解释、压角色、压手续，最后才考虑顺延。

7. 舍味前是否有极短正常味觉基线？  
   必须有，但不能煽情预告。

8. 第3—5章是否过早把异常绑到旧物？  
   此时只能未确认、不可控。

9. 前30章“该舍就舍”是否真的发生？  
   罗槐判断必须被事实证明正确。

10. 第一场事故是否仍太巧？  
    A方案章卡前必须画空间图。

11. 为什么没有现成筑基高手立刻救？  
    必须由夜间外围岗位结构、专业救援到场时间、被困者可承受时间共同解释。

12. 石小庚是否只有竞争功能？  
    中段纯修仙试岗必须有一项陆野做不到、他能做到的传统操作。

13. Phase B是否手续连续剧？  
    不改变钱 / 任务 / 人际 / 修炼 / 安全责任的复核节点就压缩。

14. 尝余误判是否像作者削外挂？  
    信号始终真实，只是陆野误解证据意义。

15. 卷末是否靠查出流程就解决？  
    不能。真正解决依靠修炼、封控、救人、调度和风险判断。

16. 卷末是否又把奖励拿走？  
    固定席位必须真实带来钱、稳定、资源和认可；新增责任不能让奖励变假。

# 28. 最终判断

本阶段纲真正需要保护的是六次状态换挡：

> 我快有资格了  
> -> 我主动舍掉味觉、真的筑基，却失去资格  
> -> 我证明自己靠正常本事也能做这份工作，拿回资格  
> -> 我发现有资格仍没有自己的位置  
> -> 我的缺位开始变得值钱，也第一次因为错误解释伤到别人  
> -> 我拿到固定位置，同时开始为别人负责。

开篇专项批准以后，Phase A最重要的新要求不是：

> 再加一个更炸的钩子。

而是：

> 第一章就让读者看到，陆野和这个文明都在做“什么该留、什么该舍”的现实判断；第三章让陆野真的付掉其中一笔成本。

然后用第一卷剩下的篇幅证明：

> 判断“该不该舍”从来不能只靠一个标签。

这既服务开篇辨识度，也服务：
- 尝余证据边界；
- 罗槐安全判断；
- 拾余方法化；
- 缺位被定价；
- 第一卷到中段的自然衔接。
