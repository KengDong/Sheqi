# Process Postmortem After A02 P0 Failure
## 我们研究清楚了什么，没研究清楚什么，为什么垃圾还能到作者面前

# 0. Bottom line

Current system has learned:
> **how many successful web novels avoid dying.**

It has NOT yet learned with sufficient fidelity:
> **why a specific hit is actually pleasurable, memorable and hard to stop reading.**

That distinction caused A02.

We extracted too much:
- legible promise;
- fast premise;
- repeatable engine;
- recurring social arena;
- compounding state;
- production sustainability.

These are mainly:
> survival floor / production floor.

They are not enough to generate:
- appetite;
- surprise;
- voice;
- emotional voltage;
- protagonist magnetism;
- scene-level pleasure;
- memorable specificity.

# 1. What was genuinely learned

Useful and retained:
- unknown-author packaging matters;
- premise must work early;
- recurring reward and social arena matter;
- old state should compound;
- characters cannot be pure function;
- direct voluntary continuation outranks architecture;
- production burden matters for a first-time author;
- benchmark features need causality / negative-control thinking.

These reduce obvious failure probability.

# 2. What was NOT sufficiently learned

## A. Hit-specific pleasure
The Market Dossier mostly operated at:
> title / premise / engine / payoff / long-run / reader-comment summary level.

It did not deeply reconstruct enough:
- first-screen micro-questions;
- protagonist appetite;
- scene turns;
- information withholding;
- emotional rhythm;
- memorable action/image;
- why one ordinary sentence makes the next sentence necessary.

## B. Difference versus ordinary same-category books
We asked this in principle, but did not operationally require:
> hit opening vs matched ordinary/non-hit opening.

Without matched controls, genre baseline gets mistaken for hit causality.

Example:
> “concrete problem -> decision -> payoff”
appears in many competent but forgettable stories.

## C. Execution premium
We underweighted:
- sentence-level selection;
- protagonist attitude;
- surprise;
- social embarrassment/desire;
- emotional asymmetry;
- scene texture;
- non-obvious human behavior.

These are execution, not architecture.

## D. Taste / anti-AI failure
We knew “checklists become generators” historically,
but repeated it:
> Commercial-Mirror card became a checklist generator.

A02 is a repeat failure, not a new category.

# 3. Pipeline mistake

Even REBOOT-V3 still delayed real prose too long:

Market
-> Concept
-> Packaging
-> Reservoir
-> Character Benchmark
-> Character Collision
-> Minimal Horizon
-> P0

This allowed:
> large amounts of low-level design evidence
to accumulate before any real proof that the book was enjoyable.

That creates false confidence and author waiting cost.

# 4. New evidence allocation

For FUTURE candidate funnels:

Market
-> Concept + Package
-> Direct Opening Benchmark
-> P-1 internal micro-prose
-> P0 internal behavioral gate
-> Author sees only internally strong 1–2
-> THEN Reservoir / Character / Minimal Horizon
-> P1 / P3
-> later structural gates.

Structural design no longer earns the right to reach P0.
> P0 earns the right to receive structural investment.

# 5. AI-suitability demotion

AI suitability remains important,
but it becomes:
> constraint / veto / production warning.

It must NOT be a positive winner function early.

Reason:
early selection for:
- stable engine;
- compressible state;
- bounded research;
- fixed social arena

systematically favors:
> management / operation simulators.

Reader desire must dominate before AI convenience.

# 6. Benchmark upgrade

Every P0 benchmark must include:
1. ONE named Primary Hit;
2. actual First Screen / Ch1 deep read;
3. at least ONE matched ordinary/non-hit control if accessible;
4. Difference Audit;
5. ablation;
6. reader-level mechanism;
7. what is signature skin and prohibited;
8. what remains free in our project scene design.

Generic benchmark labels are not enough.

# 7. Internal pre-author gate

Author should NOT be the first person to discover:
> “this is boring / mechanical / AI.”

Before a draft is shown to author, internal gate requires:

## Behavior
At least two clean readers:
- voluntary continue / stop;
- exact stop;
- next-screen desire;
- spontaneous memory.

## Anti-mechanical QA
Reject if:
- scene can be summarized as a work procedure;
- protagonist mainly explains/diagnoses/allocates;
- every beat is predictable from the input card;
- conflict exists only to exercise the premise;
- no memorable non-functional human action;
- no surprise or emotional asymmetry;
- prose reads like a demonstration of the concept.

## Benchmark gap
Ask:
> compared with the named Primary Benchmark, what reader desire is our draft still missing?

Do not show author merely because all checklist boxes are checked.

# 8. Author exposure rule

Default:
> author sees only the top 1–2 P0s that already survived internal behavioral testing.

If author says:
- boring;
- mechanical;
- AI;
- no desire;
- would stop;

that is immediate ROOT REOPEN.
No extra AI readers to argue against it.

# 9. Current batch consequence

Existing Reservoir / Character / Horizon work is not deleted.
It becomes:
> structural evidence already paid for.

But it gives ZERO entitlement to survive P0.

A02:
> P0 root reopen.

A01/A04/B10:
> paused until direct opening benchmarks are real.

# 10. One sentence
