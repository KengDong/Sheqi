# Fresh Book Prototype Blind Read｜Clean-Room Report

日期：2026-09-22
角色：fresh_book_blind_reader / Clean-Room Popular Fiction Reader
输入边界：仅阅读 blind brief 与 Prototype A / B / C / D 匿名正文；未读取映射、Concept、Benchmark、Writer Selfcheck、总评审、Canon、Outline 或旧 history。

## 先给结论

这一轮没有因为“四篇必须选一个”而强行制造冠军。

Absolute Read Test 的真实结果是：

- Prototype A：PASS。会主动点第二章，但目前更强的是案件/职业入口，不是“我已经非跟顾砚不可”。
- Prototype B：PASS，而且是强烈的主动点击。读完不是只觉得设定聪明，而是已经想看沈桥下一步怎么从卖方变成买方。
- Prototype C：PASS，但只是“我愿意继续试读”的通过，不等于我已经愿意押整本。它是四篇里最容易让我意识到“作者正在展示这个设定能怎么用”的一篇。
- Prototype D：PASS，而且是强烈的主动点击。读欲同时挂在周野这个人、劫工这份生活和他突然提前到来的个人劫上。

所以：四篇都过了“我会不会点第二章”这一道门槛，但通过强度并不相同。

如果问题升级为“这些样本里是否已经出现值得继续押整本书的作品”，答案是：有。就这次匿名正文给我的真实读欲，B 与 D 已经出现了整本级继续下注的感觉；A 目前更像值得继续读几章验证，C 则还没有从“好看的高概念样章”完全跨到“我想长期追这个人”。

下面先按要求逐篇做 Absolute Read Test，不先拿它们互相排位。

# 第一层｜Absolute Read Test

## Prototype A

### 我会不会主动点第二章？
会。

而且不是因为最后硬塞了一个悬念，而是因为这篇已经建立出一种我愿意再吃一单的阅读口味：死人还要处理活着时没处理完的荒唐现实，顾砚和桑禾靠替死人办事挣钱。

第一句“陈默死了十七天，仍然因为迟到被扣五十块”就足够让我停下来。它不是单纯怪，而是怪得立刻能懂，且自带现实刺感。

### 哪个瞬间开始真正想看？
真正从“这个设定有意思”变成“我想把这一单看完”，是在陈默说：

> “我要辞职。帮我辞职。我活着的时候他们不批。”

到这里，死人三十天的规则不再只是世界观，而是变成了一个具体人的委屈。

后面“我昨天看见他们把下个月排班也发给我了”和“我活着的时候，为什么不给？”继续把荒诞往人的生活上压，不只是抖设定包袱。

### 哪个瞬间开始掉兴趣？
中段规则说明和辞职流程开始以后，读欲有一小段从“陈默这个人”滑向“我想看看这个世界还能出现什么奇葩死后劳动案例”。

不是明显无聊，而是我开始意识到这一篇很可能采用案件/委托驱动。对我来说，这会天然产生一个疑问：以后如果每一章都是“新死人 + 一个现实问题 + 顾砚嘴贫解决”，会不会很快变成单元剧。

结尾第二个电话能让我点下一章，但它强化的也正是这个预期。

### 我现在在乎的是人/生活，还是点子？
陈默这一单里，我在乎人。

但对长期主角而言，目前我对顾砚与桑禾的兴趣还没有超过“这家死后事务代理所会遇到什么事”。

顾砚的分寸感是加分项：他不替死人决定什么值得、会算六百块代理费、嘴很损但不冷。他是好读的主角，不过还没有出现一个让我必须追他本人命运的私人钩子。

### 如果后三章没有更大的 Concept 奇观，我还愿不愿意跟？
愿意再跟几章。

前提不是世界继续升级，而是案件仍然像陈默这单一样，荒诞后面真有人生。

所以 A 不依赖马上放出更大奇观才能活，但它对“每一单是否都有人的东西”依赖很高。

### 它更像哪一种？
介于两者之间，偏向“真正可追的小说”。

它已经不是单纯把一个高概念演示一遍，因为人物对白、六百块生意、房东催租、妹妹答辩这些东西让世界落地了。

但如果问我现在是否已经愿意押 50—100 章：还没有。当前我愿意点第二章，和我愿意长期追书，不是同一个强度。

### Absolute Verdict
PASS。

---

## Prototype B

### 我会不会主动点第二章？
会，而且会马上点。

这篇最关键的不是“明天可以买卖”本身，而是结尾把沈桥从一个为了母亲手术费卖掉明天的人，推成了一个主动问“你教我怎么买”的人。

到这里，故事不再只是一次惨烈选择，而是一个新生活真正开始。

### 哪个瞬间开始真正想看？
开头已经抓，但真正让我想追是在他醒来之后。

白衬衫、固定板、泥、剪短的头发、三千八赔偿，这几样东西让我第一次产生很强的“昨天到底发生了什么”的身体性好奇。

紧接着成交记录揭开：他五万八卖掉的一天，被拆成四段转手卖到十二万六。

而最强的一下是：

> “不是卖。买。”

这一句把主角从被规则压的人，转成了准备学习规则、反过来参与规则的人。

这是我会点第二章的直接原因。

### 哪个瞬间开始掉兴趣？
前半段母亲拒绝手术、朋友劝他别卖，这种场景本身并不新。如果“卖明天”只用来包装一遍“穷人为了亲人牺牲自己”，我会担心情节太标准。

但这段很快过去，而且母亲那句“你小时候一块橡皮都不肯借人，现在敢把自己借出去”，以及沈桥“我后天还有”，把俗套风险压住了。

我真正没有明显掉兴趣的段落。

### 我现在在乎的是人/生活，还是点子？
两者已经绑在一起。

我想知道明天市场怎么玩，但更重要的是我相信沈桥会真的去学、去算、去找价差。他不是被动等待设定砸事的人。

他的穷、母亲手术、对价格的敏感、醒来第一反应嫌赔偿少、看到差价后立刻想做买方，这些东西是同一个人，不像作者为了启动剧情临时给他的动作。

方栀也不是纯解释员，她和沈桥的熟人感够自然。

### 如果后三章没有更大的 Concept 奇观，我还愿不愿意跟？
愿意。

哪怕后三章只是沈桥去交易所，学习怎么买一天、怎么拆风险、第一次做一笔很小的交易，我也愿意看。

因为我现在想看的已经不是“还有什么更离奇的未来商品”，而是“他怎么从一个只有四百块余额的人进入这个市场”。

### 它更像哪一种？
真正可追的小说。

这篇已经给了我明确的主角方向、即时生活压力、可持续的行动目标，以及一个天然会不断制造选择的市场。

### Absolute Verdict
PASS，强通过。

## Prototype C

### 我会不会主动点第二章？
会。

但这是四篇里最接近“我会再试一章，看看它到底是不是一本书”的那种点击，而不是已经形成追更冲动。

### 哪个瞬间开始真正想看？
“九十九块买三十年经验”足够清楚，但我真正进入阅读，是二楼男人要跳、季川发现他一直在看 214 号倒计时以后。

“他不是在等人劝，他在等倒计时”这一判断，让继承来的职业经验第一次变成具体能力，而不是抽象外挂。

谈判里不许诺做不到的事、只先争一分钟，也确实有可读性。

### 哪个瞬间开始掉兴趣？
男人被劝回来之后。

因为到这里我已经基本看懂这一篇的展示闭环：

九十九块买职业遗产 → 突发一个完美适配该职业的危机 → 主角凭继承直觉处理 → 死者旧搭档出现认证 → 死者旧委托顺势成为下一单。

整个链条太顺，顺到我开始从“正在经历故事”切换成“我知道这段样章正在证明这个设定可以运转”。

许昭出现以后，信息都有效，但“前搭档认出死者习惯”“最后一笔委托压着预付款”连续落下来，让样章感更明显。

### 我现在在乎的是人/生活，还是点子？
主要还是点子和能力。

季川穷到只剩二十八块四、嘴上有点贫，这让他不空，但目前我还没有形成很强的“我想看季川以后会变成什么样”的欲望。

我更想知道职业遗产能带来什么判断、贺长风过去是谁、下一次谈判是什么。这些都能驱动继续试读，却还不是对主角本人的黏性。

### 如果后三章没有更大的 Concept 奇观，我还愿不愿意跟？
愿意读第二章，甚至可能再读几章；但如果接下来只是“遇到新谈判场景 → 贺长风经验浮现 → 季川靠正确话术解决”，我会很快开始疲劳。

这篇不需要更大的世界奇观，但它需要尽快证明读点不只是专业能力演示。就本次盲读，我不替它设计怎么证明，只记录这个真实疲劳点。

### 它更像哪一种？
目前更像“写得不错的高概念样章”。

它已经具备小说化人物和场景，不是设定说明书；但这段正文的结构完成度太像一次完整 demo，我暂时还没有忘记作者在演示机制。

### Absolute Verdict
PASS，但属于弱通过/继续试读，不属于整本下注。

## Prototype D

### 我会不会主动点第二章？
会，而且会马上点。

开篇富家少爷在玻璃房喝茶，外面十二个劫工淋雨分雷，这个画面第一眼就成立。

但真正让我确认要追的，是结尾那块跟着夜班车走的乌云，以及周野在发现自己十一天后有个人劫以后，第一反应问：

> “个人劫能分包吗？”

这不是单纯悬念，而是整篇里已经建立起来的周野会做出的反应。

### 哪个瞬间开始真正想看？
第一道雷以后，“十二号，活着，记七百”让我开始喜欢周野。

第二道雷前他发现七号桩松动、冲出去排险，再到事故后反问“第三道谁站”，这段把他的人立起来了：爱算钱，但不是只认钱；会怕死，但不是只顾自己；敢顶管事，但不是为了发表道德宣言，而是因为线路真有问题、工友真会死。

从这里起，我追的已经不只是“替有钱人分雷”这个点子。

### 哪个瞬间开始掉兴趣？
几乎没有明显掉点。

中段排险、停工、谈补贴、复工的流程稍长，但它一直在同时推进三件事：工作危险、周野的性格、这个世界的阶层和职业规则，所以没有让我感觉在听设定课。

### 我现在在乎的是人/生活，还是点子？
已经在乎周野这个人和他的生活。

十万离职目标、老薛、六千一结算、副测岗位、风险和工资的换算，都让“劫”不只是奇观，而是工作。

我也想知道他为什么提前起劫，但即使暂时不揭这个谜，我仍然愿意看他继续上班、学副测、算钱怎么活过去。

### 如果后三章没有更大的 Concept 奇观，我还愿不愿意跟？
愿意。

就算后三章只写副测工作、下一单劫程、周野研究自己那场个人劫要多少钱，我也愿意。

原因是职业生活本身已经有持续读点，个人倒计时又把长期压力压在他身上。

### 它更像哪一种？
真正可追的小说。

它的世界很新，但正文没有停下来向我展示“你看这个设定多新”。规则基本都从干活、出事故、谈钱、接下一班里长出来。

### Absolute Verdict
PASS，强通过。

# 第二层｜Relative Read Test

这一部分是在四篇 Absolute Read 都完成以后才比较。

## 1. 哪篇最自然地让我继续往下读？
Prototype B。

因为结尾不是单纯抛谜，而是主角主动改变了自己的位置：从“卖掉明天筹钱”到“我要学怎么买”。

第二章该干什么非常自然，我不用等作者重新找故事。

## 2. 哪篇第一屏最抓？
Prototype A。

“死了十七天还因为迟到被扣五十块”是四篇里最立刻、最省解释、同时最带情绪的一句开场。

我几乎瞬间知道这世界哪里不对，也瞬间知道这件事为什么好笑又憋屈。

## 3. 哪篇主角最像一个我愿意继续跟的人？
Prototype D 的周野。

不是因为他最“正确”，而是因为他的每个反应都很统一：钱要算，命也要算；能多挣就多挣，真出危险也会冲；救完人先问补贴，自己要渡劫先问能不能分包。

我已经能预期他遇到新事会怎么说、怎么做，但又不会觉得他只有一个梗。

B 的沈桥也很接近，尤其“嫌赔偿少”和“我想学买”这两下很稳。

## 4. 哪篇读完后最想立刻点第二章？
Prototype B。

D 也很强，但 B 的“明早九点交易所后门”和“教我怎么买”给了我非常明确的下一步欲望：我想马上进入这个市场，看第一笔买方操作。

## 5. 哪篇世界最有新鲜感，但又不像作者在展示设定？
Prototype D。

“渡劫”本来是极熟的词，但被写成劳务、分包、接地桩、伤险、风险补贴、工牌与夜班车以后，陌生感来自生活本身。

我读到的是人在上班，不是作者站在旁边讲一个“渡劫产业化”的创意。

A 也做得很好，尤其死后履约、考勤和离职流程很自然，但它仍有一小段明确的规则说明；D 更彻底地把规则藏进动作里。

## 6. 哪篇最容易想象自己追 50—100 章？
Prototype D，其次 B。

D 同时有职业成长、挣钱目标、工友关系、阶层摩擦和个人劫倒计时，单看这段就能想象“下一班工作”也能成立，不需要每次都换一个更大的世界奇观。

B 的市场也有明显长线空间，而且主角主动性很强。我对它唯一还没被正文证明的地方，是这个市场连续几十章后是否还能一直制造不重复的生活选择；但这不是当前扣分，只是尚未读到。

## 7. 哪篇读到后面最容易疲劳？为什么？
Prototype C。

不是因为它不好看，而是因为这一章把“继承职业判断 → 进入高度适配的专业危机 → 用专业直觉纠正所有人的话 → 获得旧关系与新委托”展示得过于完整。

如果后续反复给我这种满足，我很容易从“跟季川过日子”变成“看这周又出一道什么专业题”。

A 也有单元案件疲劳风险，但陈默这一单里的生活情绪比纯能力演示更重，因此我暂时更愿意相信它能靠人而不是靠题目续航。

## 8. 如果只看真实读欲，我会留下哪些？
如果“留下”指的是：不是只点第二章，而是此刻愿意把候选继续往整本方向押——

我会留下：

- Prototype B
- Prototype D

Prototype A：我会继续读，但目前是“再给我几单看看”的状态，还没到整本下注。

Prototype C：我会点第二章，但目前更像一次成功试读；我还没有形成长期追季川本人的冲动。

这不是冠军排序。B 和 D 给我的上瘾来源不同：B 是“一个穷人开始学会进入时间交易市场”的向前冲力；D 是“一个劫工的工作生活突然和自己的劫撞在一起”的人物/职业黏性。仅凭这次样章，我不需要强行把二者压成一个唯一赢家。

# 最终 Blind Read 结论

这批样本不是“四篇里勉强挑最好的一篇”的情况。

四篇都足以让我主动点第二章，但只有“点下一章”还不够说明整本已经成立。

真正跨过我这一轮整本级读欲门槛的是 Prototype B 与 Prototype D。

Prototype A 的开场钩子极强，第一单也有人情，但我目前更追案件引擎而不是主角命运，所以会继续试读，不直接押整本。

Prototype C 的专业展示顺畅、好读，第二章也会点，但目前“聪明的点子/能力 demo”仍然强于“我非看这个人的人生不可”。

因此，对 brief 中最重要的问题：

> 这些样本里是否真的已经出现“值得继续押整本书”的作品？

我的回答是：

**有。Prototype B 与 Prototype D 已经给出了这种真实读欲。**

这并不等于宣布最终赢家，也不等于其他样本应被修改或淘汰；本报告只记录 clean-room 首轮文字本身造成的阅读反应。

停止于此。不揭盲，不查询真实映射，不修改 Prototype，不写续章，不提出 Concept 修补方案。
