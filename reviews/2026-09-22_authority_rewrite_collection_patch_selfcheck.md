# 1. PATCH A｜第一收藏作者侧来源

## 锁定来源

当前正式作者侧来源：

> **一份有效舍契真正切出的“痛觉”我相残留。**

不再写“更接近痛觉相关弃相”。
不再允许后续随意换来源。

## 为什么符合我相边界

锁的是：
> 第一人称实际体验到的痛觉。

不是：
- 神经末梢；
- 伤害感受器；
- 某个器官模块；
- 纯生理报警机制。

痛觉长期参与：
- “这一下在伤我”的感知；
- 避害；
- 动作中止；
- 身体边界与风险调节。

这符合 `canon/03_abandonment_system.md`：
> 某些感知天然持续以第一人称参与主体运行，可成为真实我相。

同时 `canon/05_characters.md` 已有：
> 陆野当初在味觉 / 痛觉 / 睡眠 / 嗅觉等候选之间做过现实比较。

因此本PATCH没有新增“痛觉可以成为我相”的规则。

## 余器语法

正式归类：
> **回声。**

当前可见效果：

> 当旧护角皮带自身遭到局部、尖锐、不均匀的挤压 / 折压，并且使用者直接接触它时，会回响一瞬“像被夹了一下”的主观痛感。

它没有：
- 预测危险；
- 读取结构；
- 制造真实伤害；
- 控制他人痛觉。

所以没有超出原弃相抽象层级。

## 结论
> **PASS。**

# 2. PATCH B｜携带 / 被动余扰 / 退余闭环

## 未封存被动余扰
现在明确：

> 裸露时即使不主动测试，也会缓慢产生很弱的“无伤压痛”余扰。

前10章读者侧只允许看到：
- 陆野放下皮带后手指仍偶尔假酸 / 假痛；
- 裸着放不合适。

作者侧知道：
> 长时间直接贴靠的近处表面 / 物件也可能吃一点余。

但S5以前不让陆野验证传播路径。

## 前期携带
当前采用：
> **普通低等级隔余布单独包住 + 硬质小袋 / 小盒分开携带。**

这是低成本减扰方式，
不是高级安全封存。

## 封存状态不可用
当前明确：
> 包着时效果被明显压住；要使用必须单独打开。

符合：
> `canon/08_artifacts.md` “封存不可用”。

## 使用后退余
现在明确：
- 手指会残留假酸 / 麻；
- 测试表面可能有短时余扰；
- 低强度可隔开静置自然消散；
- 若需要立即继续高精度工作，则必须停用 / 做已有低风险余扰处理。

不再是：
> 魔法工具用完直接塞回口袋。

## 为什么不能一直开
双成本：
1. 人的真假痛感越来越难分；
2. 隔余布 / 测试接触面会逐渐吃余，需要停用 / 隔离。

## 结论
> **PASS。**

# 5. PATCH C｜Ch9去“专用教学关”

旧版问题：
> 新发现“局部夹压假痛”
> -> 两章后刚好“隐藏尖锐夹点”
> -> 一试命中。

新版现实问题：

> **同一侧普通护带比预期磨得快。**

这不是“夹点题”。

普通经验先提出多个候选：
1. 护带老化；
2. 上一趟扭过；
3. 边缘 / 垫片吃力不均；
4. 普通装配偏差。

无咬手带：
> 一样能解决，只是要多拆、多试。

## 第一次使用
- 普通检查先缩到两三处；
- 第一个怀疑点：无反应，不能证明没问题；
- 第二个怀疑点：轻微、不稳定假痛，只决定“先拆这里”。

## 真正原因
最后普通拆检发现：

> **垫片轻微移位 + 护带曾扭过，两件普通小问题叠加。**

咬手带没有给：
- 故障名称；
- 原因；
- 安全等级；
- 完整答案。

它只改变：
> 检查顺序。

## 满足Brief至少两项
实际满足：
- [x] 第一次使用不是一试就中；
- [x] 只缩小部分可能；
- [x] 普通经验先提出多个候选；
- [x] 有条件盲区；
- [x] 无它也能解决，只是更慢；
- [x] 问题本身不再与能力同义。

## 结论
> **PASS。**
