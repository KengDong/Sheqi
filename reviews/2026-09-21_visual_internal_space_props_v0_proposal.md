# 第一阶段内部空间 / 器物资产包 V0｜审议稿

> 身份：视觉连续性工程师 / Internal Reference Designer
>
> 本文件只解决：
>
> **长什么样、摆在哪里、手怎么拿、身体怎么用。**
>
> 不负责正式命名，不生成角色脸，不生成公开插图，不修改剧情，不修改 Canon / approved Outline / chapter cards。
>
> Reader-Language Editor 负责：
> - 正文叫什么；
> - 正式语 / 行话 / 口语如何分层；
> - 哪些工程占位词降级；
> - 哪些词最终需要改名。
>
> 本文件对器物只给：
> **likely-no / maybe / likely-yes**
> 三档“是否真的需要稳定专名”的视觉侧判断。
>
> 所有尺寸均为 **V0 比例校准范围**，只用于内部空间与动作可行性，不自动成为正文数字或 Canon。

# 0. 本轮总裁决

## 0.1 视觉语言方向

第一卷前10章的普通世界应优先让人看到：

> **木、金属、织物、绳、纸、旧漆、磨损、补过的边角，以及被很多手长期使用过的工具。**

不是：

> 每件劳动工具都长得像仙器。

低阶修仙首先进入：
- 人能把普通工具用得更远；
- 能持续控制某个本来就存在的机械件；
- 普通法器帮助劳动；

而不是把货场画成：
> 自动飞行、满屏阵光、无人搬运的高魔工厂。

## 0.2 普通器物设计原则

每个普通器物先过四问：

1. **不用灵力，一个普通工人能不能理解它怎么用？**
2. **人手到底抓哪里、压哪里、拉哪里、插哪里？**
3. **坏掉以后，哪些部分还能单独留下？**
4. **如果删掉所有仙侠光效，它还像真实劳动现场里的东西吗？**

四问不过：
> 不进入第一卷普通器物板。

## 0.3 视觉“专名必要性”判断规则

### likely-no
- 一次性或极普通；
- 现实描述已经足够；
- 不需要读者长期记忆；
- 现场也不需要统一喊它才能协作。

### maybe
- 会重复出现；
- 有职业层区分价值；
- 可能需要行业短称；
- 但普通描述仍能完成叙事。

### likely-yes
- 行动高潮中反复被喊 / 操作；
- 多人必须对同一个部件建立稳定指向；
- 若每次都长描述会拖慢动作；
- 需要稳定短称，但不代表要造华丽世界观名词。

本文件不给名称候选。

本 V0 推荐：

> **F 的主承重轮负责承重；导向轮只负责限制横向跑偏。**

- 货架没有整台掉进沟；
- 主承重轮仍然着地、仍然能滚；
- 只是某一侧失去横向约束；
- 另一侧 / 另一端仍受约束；
- 原本直行的长架开始偏航并形成大角度侧摆。

这是目前最能同时满足：
- 单一主故障；
- 事故后仍有短暂运动窗口；
- 左右两端同时产生后果；
- 不需要第二次机械爆炸
的形态。

# 2. 固定中转台 NORMAL｜俯视空间规格

## 2.1 比例校准带｜V0，不进正文

建议用人身高做比例，不先锁精确“丈 / 尺”。

### F
内部绘图先按：
- 长：约 2.7—3.2 个成年人身高；
- 宽：约 0.8—1.0 个成年人身高；
- 台面：约膝上至大腿中段高度。

换算成现代比例只是为了画图校准：
> 大约 4.5—5.5m 长、1.35—1.65m 宽、0.5—0.7m 高。

不是 Canon 数字。

### 正常侧向余量
建议：
- F 正常外缘到 P/W 工作口袋：至少留一段明显人行余量；
- F 正常外缘到 O 外沿：同样留明显缓冲；
- 普通小偏移仍不能触碰任一侧。

### A'侧摆
内部几何测试可先按：
> 约 15°—20° 的异常偏航

检查双端是否能同时扫入：
- 左端 P/W；
- 右端 R/O。

角度只用于工程草图，不写进故事。

# 4. A' ACCIDENT OVERLAY｜同一底图只改变运动状态

## 4.1 推荐旋转方向

本 V0 推荐将事故侧摆画成：

> **顺时针偏航。**

视觉结果：

- 左端向北侧扫；
- 右端向南 / 东南侧扫。

因此：

- 左端把 W 压向 P；
- 右端带着 R 所在角部扫向 O；
- S 仍在更深处，不成为第一接触面。

## 4.3 A'唯一变化清单

从 NORMAL 到 A' 只允许：

1. 一只单侧导向小轮从导槽 / 导边脱开；
2. F围绕仍受约束的一侧发生偏航；
3. W从正常站位变成被左端扫压；
4. R随右端进入O接触区；
5. O受撞；
6. S保持原位且不被第一下直接撞毁；
7. 人员撤向南侧安全线；
8. B从普通定位用途变成事故临时制动 / 保持用途。

不得：
- 让P突然移动；
- 让O突然伸出来；
- 让R自己飞出；
- 让B临时出现；
- 让W事故前站进禁区。

# 5. A'几何证明｜内部 hard-gate 用

## 5.1 为什么正常撞不到 O

V0 几何应让：

> F0右侧外缘与O入口外沿之间存在“明显大于日常跑偏”的侧向净距。

视觉上不要只留一掌宽。

应让读者 / 审图者一眼判断：

> 正常走偏一点，也到不了那里。

## 5.2 为什么异常能碰到 O

长架的危险不是平移，而是：

> **长杆式端部扫掠。**

只要中段 / 一侧仍受约束，长架一偏航：
- 中间横移不大；
- 两头的横向位移明显放大。

因此右端能跨过正常缓冲，扫入 O 外沿。

## 5.3 为什么 W 合法却仍可能被夹

W不是站在车道里。

V0 推荐把W画在：

> P旁边一个“正常情况下有足够净距”的导向工作口袋。

正常：
- F直行；
- W能观察侧边间隙；
- 手能处理小导向 / 护角 / 货边问题。

A'：
- 长架左端横扫进入这个正常口袋；
- W后侧又有P / 护柱；
- 形成挤压。

这比“工人本来就站在车轮旁边”更合理。

## 5.4 为什么 R 和 O 同时受损

R必须：

> 位于F右端、靠外侧，但仍在自己的独立加固格里。

A'时：
- 不是R自己甩飞；
- 是F右端整体扫过去；
- R所在角部先受挤压；
- R外封壳与O入口构件在同一个接触区受损。

## 5.5 为什么 S 没被撞坏

O与S必须存在明显前后层级：

> O = 入口第一道结构  
> S = 再向内缩的一整套操作主体

V0人高视角必须看出：
- 货架角部可以擦 / 压到O；
- 但要直接撞S还需要继续深入一段；
- A'第一下不够。

## 5.6 图一旦出现以下情况即判失败

- O为了“方便撞”凸到货道里；
- S和O几乎在同一平面；
- W站在正常车体外缘以内；
- R离F边缘太远，碰O时R根本碰不到；
- F要先撞别的东西，那个东西再撞R/O；
- B没有任何机械承力路径；
- 必须画成F悬空漂移才成立。

失败：
> Reject 图，不改章卡。

# 6. F｜重货长架形态候选 V0

## 6.1 推荐主形态

不是封闭车厢，也不是现代叉车。

更接近：

> **低矮、狭长、开放式重货底架。**

视觉结构：

- 长矩形承载面；
- 两侧低矮护边，不做高围栏；
- 下方数个主承重轮组；
- 端部与侧边有固定绳 / 扣的挂点；
- 右端留一个独立加固小格给R；
- 前后端有方便人推、牵、校正的实体抓位；
- 可见反复修补和更换过的木 / 金属护边。

## 6.2 主承重轮与导向轮必须分开

### 主承重轮
- 较大；
- 在架体下方；
- 负责重量；
- 数量可以多于四只，避免“一只轮坏全车倒”。

### 导向轮
- 更小；
- 不承担主要垂直重量；
- 靠近侧边或端部；
- 贴着浅导槽 / 导边运行；
- 只负责不让长架横着跑。

这样一只导向轮脱槽后：
> 车还在地上，但方向失控。

## 6.3 人体动作

普通工人对F的动作应包括：
- 推；
- 拉；
- 扶正；
- 挂绑扎件；
- 检查轮边；
- 看护角；
- 盯两侧净距。

不要让所有操作都变成“隔空御物”。

## 6.4 是否需要专名
> **likely-yes**

理由：
- 第1—3章反复出现；
- 事故中必须快速指向同一对象；
- 现场工人一定会有短称。

这里只判断需要，不提供名字。

# 7. 导向机构形态 V0

## 7.1 推荐形态

采用：

> **浅导槽 / 低导边 + 小导向轮**

而不是让整台F像铁路车一样完全卡死在深轨里。

视觉可以是：
- 地面两侧一条低矮金属 / 硬材导边；
- F侧下方的小轮贴着导边滚；
- 或小轮落在很浅的U形槽中；
- 槽深只够限制横移，不承担重量。

## 7.2 “脱槽”应怎么画

不要：
> 轮子整只飞掉。

建议：
- 导轮仍连在架体上；
- 因磨损、侧向冲击或短瞬受力，轮缘爬出浅槽 / 越过导边；
- 立刻出现一个肉眼能懂的错位：
  > 小轮在导边外侧，架体开始斜。

故障原因正文尚未要求详细追责，因此V0不要画：
- 明显人为破坏；
- 螺栓被割断；
- 神秘力量推轮。

## 7.3 人体动作

正常：
- 工人看轮边是否贴正；
- 必要时用短撬具帮空架对位；
- 不把手伸到承重轮下。

## 7.4 是否需要专名
> **likely-no**

普通机械描述足以。
若 Reader-Language 最终保留行业短称，由语言侧决定。

# 8. P｜固定导向 / 护柱 V0

## 8.1 形态

推荐：
- 成人腰至胸口高度；
- 粗壮直立；
- 下端牢固嵌地；
- 朝货道一侧有可更换的磨损护面；
- 顶部不过度尖锐；
- 明显是“长期被擦碰、用于限定边界”的现场件。

不做：
- 装饰石柱；
- 阵法图腾；
- 发光法柱。

## 8.2 W与P关系

W正常位：
- 在P偏外侧；
- 面向F；
- 背后 / 侧后不是完全封死；
- 正常车流有足够空间。

事故时才因F左端横扫被压向P。

## 8.3 是否需要专名
> **likely-no**

# 9. O｜舍台入口第一道物理结构 V0

## 9.1 视觉目标

必须首先像：

> **成熟、安全、可维护的技术设施。**

不先像法阵。

## 9.2 推荐形态

采用：

> **略呈门框 / 圆角框的厚实外部结构**

而不是一只漂浮发光圆环。

可以有：
- 两侧厚边；
- 上方连接；
- 下部防撞底件；
- 可拆护板；
- 少量规整刻线 / 嵌件；
- 检修接缝。

它位于：
> 内凹服务位入口线的里面一点。

不伸入正常货道。

## 9.3 为什么它能被撞坏

右下 / 右侧靠货道方向的入口构件是第一接触面。

A'中F右端进入异常扫掠区：
- 先撞 / 挤 O；
- O局部变形、裂损或错位；
- S因为后缩仍完整到“能执行，但最后封不一定完整”的程度。

## 9.4 不定稿内容

V0不确定：
- 是完整闭环还是视觉上接近闭环；
- 材质；
- 阵纹；
- 颜色；
- 是否有活动件。

以上都留给后续视觉 / Reader-Language 与舍务制度审查。

## 9.5 是否需要专名
> **likely-yes**

理由：
- 第2—3章安全值守必须快速指向它；
- 它直接决定“切得成、封不一定合”的事故状态；
- 需要一个稳定短称，但不代表正文第一次就讲正式术语。

# 10. S｜舍台后缩操作主体 V0

## 10.1 形态目标

不要“神秘核心”。

视觉上更像一整套：
- 半人高至胸高的操作主体；
- 供人站 / 坐 / 扶的位置；
- 两侧工具 / 接口；
- 后方或下方有固定结构；
- 周边留维护空间。

重点是：
> 人真的能在这里接受一次正规、重复执行的舍务操作。

## 10.2 O/S层级

从货道看进去：

1. 先看到入口外部防护 / 封位构件O；
2. 再看到里面的工作位；
3. S主体在更深处。

必须看出：
> O可以坏，S不必一起碎。

## 10.3 不允许

- 单颗发光水晶承担全部功能；
- 悬空祭坛；
- 血槽；
- 人骨；
- 十几层神秘UI；
- 一眼就告诉读者余世结构。

## 10.4 是否需要专名
> **likely-no**

视觉侧判断：

# 12. B｜机械制动 / 牵引装置 V0

## 12.1 设计目标

B必须一眼说明：

> **重货的力进机械里，不进陆野身体里。**

## 12.2 推荐主形态

采用：

> **固定在地面 / 低墙基座上的卷轮 + 拉索 + 摩擦制动带 / 压合件 + 人工控制长柄。**

四部分：

### A. 固定基座
- 粗壮；
- 与地面 / 墙基固定；
- 真正把拉力传给建筑结构。

### B. 卷轮 / 鼓轮
- 拉索绕在其上；
- 拉索另一端接F；
- 可辅助把F慢慢牵入 / 校正位置。

### C. 摩擦制动件
- 压上卷轮后增加阻力；
- 真正消耗 / 承受F想继续走的力。

### D. 控制长柄 / 压杆
- 人靠近时能用手 / 身体压住；
- 也可以被灵力推动；
- 它本身不吃几吨载荷，只改变制动件是否压合。

## 12.3 为什么需要“持续控制”

V0只做形态解释，不新增剧情规则：

- 普通定位时，控制件是人手短时调节；
- 事故后需要在副支撑完成前保持在某个制动状态；
- 控制柄有回弹 / 回位趋势；
- 人不能长期站在泄漏与侧摆风险区；
- 陆野筑基后可在线外持续把灵力留在控制柄上。

重点：
> 陆野维持的是控制动作，不是制动力本身。

## 12.4 人体动作

正常近身：
- 一手扶柄；
- 身体侧站，不站拉索正后方；
- 通过压 / 拉改变制动状态；
- 另一人可看F与轮边。

事故后：
- 人退到安全线外；
- 陆野手不必一直做夸张法诀；
- 视觉上可表现为他视线 / 身体朝向B，灵力作用点始终在柄 / 控制件；
- 拉索、卷轮、基座显示真实受力。

## 12.5 不允许

- 一块按钮按下就“魔法刹车”；
- 没有拉索 / 机械传力；
- 陆野灵力直接包住F；
- 装置突然在事故时才出现；
- 画成现代电动绞盘控制面板。

## 12.6 是否需要专名
> **likely-yes**

原因：
- 第2章章尾到第3章救援会高频指向；
- 现场口令必须短；
- 这是 Reader-Language 最值得优先处理的“需要短称，但不需要高概念命名”的对象之一。

# 18. 第一章小夹具 V0｜重点候选

## 18.1 首选形态

推荐：

> **两片短木 / 硬竹夹体，中段共用一枚可拆的弯折金属弹簧件。**

不是现代塑料夹。

大致：
- 全长约一掌内；
- 尾部可捏；
- 前端夹口略宽；
- 中间有穿簧的小孔 / 槽；
- 金属弹簧件既提供回弹，也兼作转轴。

## 18.2 为什么特别适合第一章动作

章卡要求：

> 坏一边夹体 -> 拆下可用簧针 -> 装到另一只夹体完好但簧针坏的旧夹 -> 真坏夹体丢掉。

这个形态可以让动作非常直观：

1. 陆野从废料筐拿起旧夹；
2. 捏一下，发现一边夹口裂到受力会继续张；
3. 用指甲 / 小钳把中段弹簧脚退出来；
4. 两片夹体散开；
5. 弹簧件仍直、回弹仍好；
6. 换到另一只旧夹；
7. 捏一下，新组合能正常闭合；
8. 裂掉的木片重新丢回去。

视觉上自然体现：

> **他不是舍不得扔整个东西，而是先判断哪一块真的废。**

## 18.3 裂纹位置

裂纹建议：
- 在夹口受力端；
- 沿木纹裂开；
- 不能靠再绑一下继续安全夹货牌。

避免：
- 裂在无关装饰处；
- 明明还能用，却为了主题硬说报废。

## 18.4 簧件

建议：
- 简单弯折金属线 / 片簧；
- 体积小；
- 不贵；
- 但可重复用。

不做：
- 灵纹；
- 小型法器；
- 特殊材料。

## 18.5 是否需要专名
> **likely-no**

视觉侧强烈建议：
> 把它当普通夹具，而不是世界观名词。

# 26. 排班板 / 记录方式 V0

第10章锁定视觉动作：
> 陆野的名字重新写进 / 放回真实班表。

## 26.1 推荐形态

采用“可移动 + 可写”的混合方式最灵活：

- 墙上一块大板；
- 横向分成几条当日 / 班次区域；
- 人名可以是小纸条 / 薄片插入浅槽；
- 路线、时段、临时变更可直接写在旁边；
- 乔九能一边看工作区一边调整。

这样既支持：
> “写进”

也支持：
> “放回”。

不必现在决定最终是哪一种。

## 26.2 乔九动作

应该是：
- 伸手取一条；
- 换一个槽；
- 添一小笔；
- 转头继续叫人。

不是：
> 站在巨大官府榜前郑重宣读。

## 26.3 是否需要专名
> **likely-no**

普通工作物，不建议高概念化。

# 27. 修行 / 舍务凭证载体 V0

## 27.1 目标

第一章只需要支持：
- 陆野随身携带；
- 乔九快速核验；
- 不是面板；
- 不是完整人格档案；
- 有“这次筑基相关记录仍有效”的物理可信度。

## 27.2 推荐形态

可探索：
- 手掌稍大的薄册；
- 两片薄硬封皮；
- 内页少；
- 边缘耐磨；
- 有一处正规印记 / 验记；

携带：
- 衣内袋；
- 腰侧贴身小袋；
- 不挂在外面炫耀。

## 27.3 不允许

- 全息页面；
- 自动浮字；
- 数值栏；
- “最佳舍项推荐”；

## 27.4 是否需要专名
> **maybe**

理由：

- 但 Reader-Language Gate 已要求重新审“修籍”是否真的值得读者早期记。

# 28. 合租屋共用空间 V0

## 28.1 设计原则

本轮不锁房间总数。

只设计：

> **两人会反复碰面的共用核心空间。**

私人睡眠区只用“通向各自私人区域”的出口表示。

这样不会通过平面图偷偷决定：
- 性别；
- 睡眠安排；
- 私密关系；
- 房间总数。

## 28.2 共用空间必须同时容纳四种活动

1. 吃饭；
2. 简单做饭；
3. 陆野修小工具 / 摆旧零件；
4. 生活锚点做手艺小单。

矛盾来自：
> 面积有限、平整工作面有限。

不是谁故意欺负谁。

# 30. 陆野旧零件 / 工具区 V0

> 收起来 / 清开。

非常具体。

# 36. Reader-Language接口｜视觉侧交付

Reader-Language Editor 可以直接从本文件取以下信息，但命名权仍在语言侧。

## 36.1 第一章

### 小夹具
视觉已经具体到：
- 两片短木 / 硬竹；
- 一枚可拆金属弹簧件；
- 单手捏开；
- 夹口裂后主用途不安全；
- 弹簧件可换到另一只旧夹。

语言侧不需要再面对：
> “货签夹究竟是什么东西？”

只需决定：
> 读者第一次怎么叫最自然。

### 热食
视觉已经确定：
- 大锅；
- 碗；
- 热水容器；
- 陆野能直接兑热水。

但具体吃什么：
> 仍归 Reader-Language。

### 凭证
视觉已经确定：
- 小薄册 / 折叠页方向；
- 可随身；
- 快速翻一两页；
- 有正规印记区域；
- 无UI。

“修籍”是否保留：
> 仍归语言侧。

## 36.2 第二—三章

### F
语言侧不再需要解释抽象“长型重载转运架”。

视觉实际是：
> 低矮、狭长、开放、下面是承重轮、旁边另有小导向轮的重货底架。

### 导向故障
读者动作可以建立在：
> 小导向轮爬出浅槽 / 越过导边 -> 长架开始斜着甩。

不需要写：
> “越出正常安全包络”。

### O/S
读者视觉可以建立：
> 墙边一处内凹舍台；入口那道厚框先挨撞，真正操作的主体还缩在里面。

### R
读者视觉可以建立：
> 右端单独绑紧的一只硬壳封件，撞后角部和壳缝受损。

### B
读者视觉可以建立：
> 地上/墙边固定的一套卷轮、拉索和制动柄；真正吃力的是卷轮和基座，陆野只是在远处一直把控制柄压在需要的位置。

这样能直接帮助：
> 工程版 -> 读者动作版 -> 现场口令版

三层翻译。
