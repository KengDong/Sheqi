# 第一阶段内部空间 / 器物资产包 V0｜总评审终审

## 0. 总裁决

**通过，作为内部 V0 Reference Specification。**

这轮最有价值的不是“画得好不好看”，而是把此前的功能占位还原成：

> 手能摸、身体能操作、空间里能摆得下的东西。

正式支持：
- NORMAL / A' 同底图；
- 主承重轮与小导向轮分工；
- 内凹舍台，正常货路够不到；
- R在右端独立固定；
- O前、S后；
- 普通驿货行材质与器物；
- 旧木/硬竹夹具；
- 共用长桌；
- 陆野有限、分类过的旧零件；
- 先空间与器物，后人物脸。

但B机械做一处物理修正。

---

# 1. F｜主承重轮 + 小导向轮｜PASS

接受为本次事故 V0 主形态：

> 主承重轮吃重量，小导向轮只限制横向跑偏。

这能合理支持：
- 导向轮脱槽但整架不翻；
- 长架仍能发生偏航；
- 一次侧摆同时影响左右两端。

但以下仍是内部V0，不进正文数字：
- 4.5—5.5m；
- 15°—20°；
- 具体轮数。

真正出图仍需过 geometry hard-gate。

---

# 2. A'空间｜PASS

支持：
- W合法工作位；
- P在正常工作口袋后侧；
- O/S在墙边内凹；
- 正常小偏差撞不到O；
- 只有异常侧摆端部扫掠才越界；
- S不处于第一接触面。

这一点解决了此前最危险的视觉逻辑洞：

> 舍台不是站在货道旁等事故撞它。

本布局只锁：
> 这一处中转台 / 这一场事故。

不得外推成全国中转台规范。

---

# 3. B机械｜通过方向，但修掉“必须一直按着才不失控”的安全疑点

原V0：
> 绞盘 + 拉索 + 摩擦制动 + 控制长柄。

总体方向正确：
> **机械吃载荷，陆野只操作控制部件。**

但正文/视觉都不要形成：

> 一个成熟货场的安全制动器，只要人一松手就自动完全放开几吨重货。

这会产生新的工程漏洞。

正式 V0 改成：

> **固定牵引绞盘 / 卷轮 + 摩擦制动 / 张力控制机构。**

事故里陆野需要持续做的不是“替安全机构一直按住唯一刹车”，而是：

> **在副支撑尚未吃住之前，持续维持 / 微调一个中间制动或牵引状态，防止架体继续吃角或回摆。**

机械结构承担载荷。

陆野承担：
- 小幅控制；
- 持续性；
- 稳定性。

炼气：
> 能隔线碰一下，无法把控制持续留在那里。

筑基：
> 能让离体灵力持续维持该控制状态。

这样同时保留：
- frozen chapter-card功能；
- 筑基的新行动维度；
- 机械承担重载；
- 成熟设施不至于显得荒唐。

正文现场可以仍简称：
> 绞盘 / 闸 / 闸柄。

具体内部锁止结构暂不进入读者层。

# 4. 第一章旧木夹｜PASS

批准 V0：

> 两片短木/硬竹夹体 + 可拆小金属弹性件。

但语言侧按Reader-Language终审：

这是普通器物，不升级世界观资产。

# 5. 夜班热食位｜PASS

批准空间功能：
- 一锅热食；
- 粗碗；
- 热水；
- 五分钟能吃完；
- 靠近出班区但不挡货道。

正文具体食物由Reader-Language决定。

当前第一章 Working Default：
> 咸菜豆腐汤。

# 6. 修行凭证载体｜PASS AS V0

批准：
> 小薄册 / 折页式凭证方向。

要求：
- 无UI；
- 无完整人格档案；
- 乔九几眼能核当前筑基与舍备记录。

“修籍”是否正式名：
> 继续OPEN。

视觉不能因为画了册子就倒逼制度正式名称。

---

# 7. 合租屋共用长桌｜PASS

接受：
> 一张多用途共用长桌。

原因：
- 小租屋自然；
- 饭、账、工具、手艺工作面能在同一空间碰撞；
- 不必再创造独立工作室。

但它只锁：
> 共用空间骨架。

不锁：
- 房间总数；
- 生活锚点性别；
- 正式手艺；
- 朝向；
- 城市住宅通则。
