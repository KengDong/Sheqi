# Fiction R&D Process Postmortem
## 为什么多轮PASS仍被作者真实阅读推翻

# 0. Conclusion

当前最主要的问题不是C01或C12还缺一个局部技巧，而是研发流程长期把：

> **“满足被认为会导致好看的条件”**

误当成：

> **“真实读者会自愿一直读下去”。**

Git证据链：
- D-0064：六章Fresh Blind，C01/C12均STRONG PASS；
- D-0065：Ch7—10 Internal Quality双PASS；
- D-0067：十章Dual Evidence，C01 STRONG PASS并被判Head-Tier Ready；
- D-0069：后续Arc继续PASS TO PROSE；
- D-0070：正文继续PASS；
- D-0071：Returning Reader两本最终均到STRONG PASS；
- D-0075：作者真实连续阅读时，C01 Ch7开始明显自愿弃读，Ch8—9已不想继续；两本共同暴露情景剧化、视角窄、新鲜感带宽不足。

因此：
> **旧Gate能够降低硬伤，却不能可靠证明“好看”。**

# 1. Root Failure

## 1.1 Evaluation-mode ≠ Consumption-mode

旧Fresh Reader通常接受任务：
> 读完6章/10章，再判断是否愿意继续。

真实读者行为：
> 任何一页无聊都可以离开。

强制完整阅读会产生严重偏差：
- 后续优点可以反向补偿中途弃读；
- Reader会进入“理解作者设计”的评审模式；
- 结构完整度会替代即时阅读欲。

D-0075作者自愿弃读比此前多轮STRONG PASS具有更高行为证据价值。

## 1.2 Checklist Accretion

项目为修复每次发现的问题持续增加：
- Canopy；
- Long Horizon；
- Reader Desire；
- Benchmark Parity；
- Scene Ecology；
- Novelty Bandwidth；
- Macro Promise；
- Rolling-3；
- Signature Scene；
- Semantic Rolling-3。

这些均有诊断价值。

错误在于：
> **诊断工具逐渐变成了小说生成器。**

Writer开始执行设计文件，而不是让人物与欲望自然制造下一件最好看的事。

## 1.3 Designed Causality Over Character Causality

危险形态：
> “Ch7需要新社会接口，所以安排招聘会。”
> “Ch20需要Macro Promise，所以安排百人未来池。”

这能完成架构任务，却容易产生：
> 作者安排的事件，而非人物非做不可的事件。

## 1.4 Benchmark Cargo Risk

Benchmark能很好发现Retention Floor，但无法直接制造Breakout Premium。

若将热门作品拆成特征后再组装：
> 容易得到“像成熟热门作品的结构”，却失去真正让某一本爆开的独特动力。

# 2. What Remains Valuable

旧工作不废弃。

保留为诊断资产：
- HIT FICTION OS V2；
- BENCHMARK CAUSALITY STANDARD；
- HEAD TIER READER DESIRE STANDARD；
- Scene Ecology；
- Macro Promise；
- Five Growth Curves；
- Long-Horizon；
- Canopy；
- Signature Scene；
- Rolling-3 / Semantic Rolling-3。

但统一降级：
> **Diagnostic / Failure Analysis only.**

它们不再作为Writer逐项施工清单。

# 3. New First Principle

唯一目标：

> **让陌生目标读者在没有任务压力的情况下，自愿继续下一页、下一章，并随着阅读投入越来越舍不得离开。**

所有中间指标都只能回答：
> 为什么可能做到 / 为什么没做到。

不能替代：
> 读者事实上有没有继续。

# 4. New Evidence Hierarchy

从高到低：

1. **真实自愿阅读行为**
   - 作者真实弃读；
   - clean-room reader exact stop；
   - 是否主动索要下一章。
2. **实际正文连续体验**
3. **未提示的读后记忆 / 人物依恋 / 下一期待**
4. **Story Reservoir对“想不想看这场”的直接欲望**
5. **Benchmark机制证据**
6. **Architecture / Checklist**
7. **Writer / Architect Selfcheck**

低层证据不得推翻高层行为证据。

# 5. Process Reset

后续不再：
> Concept -> 大架构 -> 完整章节图 -> Writer施工 -> 强制读完 -> 评分。

改为：
> **Concept/Desire Thesis -> Story Possibility Reservoir -> Character Collision -> Minimal Horizon -> Short Prose -> Voluntary Stop -> Diagnostics -> Iteration/kill。**

第一性原理：
> **先制造真的想看的故事，再用工具解释为什么它能持续。**
