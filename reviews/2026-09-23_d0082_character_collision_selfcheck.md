## 2. Character-Collision Gate

### Gate A｜至少两个核心人物同时主动想要不同的东西
**PASS：78/78 events。**

没有把非主角写成只来阻碍主角的按钮。关键反证包括：
- R1 伴侣与旧买家即使主角不推动，也会争共同未来与持仓边界；
- R2 两位伴侣可以直接谈身体边界；
- R3 家人会主动联系年轻卖家，老承受者会主动要求自己的价值判断被尊重；
- R5 新骑手主动争独立网络，老店主主动决定退出；
- R7 母亲、女友、活同事分别有不兼容的遗属/劳动欲望；
- R8 伴侣与自由女人可以绕过主角直接形成关系。

### Gate B｜事件后必须留下不可逆关系后果
**PASS：78/78。**

残留物不是“下次再吵”，而是：
- 共同日历、直接联系方式、公开边界；
- 身体永久痕迹、双账本、照护交接；
- 已接受的补偿、错过的突破、共同熬过的旧劫；
- 独立路线协作边界、退出期限、稳定照护关系；
- 模型认可记录、共同保留/删除的训练内容、第二次死亡共同历史；
- 家庭协议分层、职业底线、双轨工作身份、双方都记得的“第二次认识”。

## 3. Character Cut Questions｜Forge-side Evidence Only

> 本节不替 editor_in_chief 做 Character Cut，只检查是否有足够证据进入其判断。

### Q1｜这些人不靠新 Case 还会不会有事？
- **R1:** 会。核心是伴侣 / 买家 / 老卖家 / 同事围绕未来所有权持续重写关系。
- **R2:** 会，而且最直接。两个自我本身每天就在争有限生命资源。
- **R3:** 会。已有五个人围绕同一批旧风险、家庭成本、自主与责任还能连续冲突。
- **R5:** 会。已有路线一旦成为资产，维护、共享、退出、责任与去中心化都会制造新冲突。
- **R7:** 会。一个死者前辈模型就足以把竞争、哀悼、训练自己的死后版本和三年终点全部串起。
- **R8:** 会。伴侣、自由女人、同行、家庭分别想把失踪日正常化、保留自由、职业化或安全化，天然互撞。

### Q2｜有没有至少两个非主角值得继续看？
六本均有至少两个：
- R1：伴侣 / 关键旧买家（另有老卖家、同事）
- R2：出售时段沈峥 / 两位伴侣 / 老朋友
- R3：老承受者 / 年轻风险卖家（另有家人、原雇主）
- R5：新骑手 / 老骑手 / 安保主管
- R7：死者母亲 / 活同事 / 女友
- R8：伴侣 / 自由女人 / 合法同行

### Q3｜关系变化会不会反过来制造下一事件？
**PASS。** 六本输出都刻意使用上一事件形成的边界、债、信任、秘密或身份作为后续燃料，而不是每次从零触发。

### Q4｜主角消失一天，世界里仍有事情发生吗？
**PASS。**
- R1：伴侣与旧买家仍会谈边界，同事仍争位置，老卖家仍维护过去选择。
- R2：任一沈峥不在时，另一沈峥与伴侣/家人仍有完整生活。
- R3：家人、年轻卖家、老承受者、原雇主都能主动决定各自风险/钱/名誉。
- R5：骑手群体、安保、店主与老人之间仍有共享、退出与照护问题。
- R7：模型会继续工作，母亲会继续哀悼，活同事会继续争职业空间。
- R8：伴侣、自由女人、同行与上司均有独立生活与决策。

### Q5｜是否出现真正难以逆转的关系代价？
**PASS。** 不是“误会解释开”式冲突。包含错过突破、职责正式转移、接受补偿、永久身体痕迹、直接联系方式、第二次死亡、公开职业边界、关系从师徒/债主/客户身份永久改写等。

### Q6｜普通生活场面是否也能成立？
**PASS。** 每本至少保留一个明确 ordinary-life proof：
- R1：完全自由的一天如何浪费；
- R2：没有合同的普通星期天如何与“缺席的另一人”相处；
- R3：钱、照护、家庭协商持续承接突破后果；
- R5：夜里不接单，三名骑手走同一座不同的城；
- R7：模型停机后的普通工作日；
- R8：两人同时上榜却不接任务，只重新认识彼此。

## 4. Exhaustion Honesty

本轮没有任何候选在 10 个事件前自然枯竭，因此未触发 DROP。

但续航强度不是完全同质：
- R3 / R5 的 Character Collision 已证明它们**不必立刻依赖新劫 / 新路**，但其关系发动机仍更依赖已有资产持续产生责任与价值争议；继续无限扩展时仍应警惕回到原 Reservoir 的模板诱惑。
- R1 / R2 / R7 / R8 在完全关闭新增 Case 后，关系本身更容易继续产生下一事件。

这不是排名，也不是 Character Cut，只是对自然枯竭点与风险来源的如实记录。
