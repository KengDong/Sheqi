# Reader-Language Naturalization｜总评审终审

## 0. 总裁决

**通过。**

这轮真正补上了此前最缺的一层：

> 作者能精确理解，不等于读者读起来顺；读者能猜懂，也不等于像真人小说语言。

58项全量扫描有效，五层转换：
> 作者工程语 -> 世界正式语 -> 行业口语 -> 人物日常语 -> 读者首次体验语言

建议正式采用。

但总评审不原样冻结全部具体候选，做6项编辑修正。

---

# 1. 修籍｜DOWNGRADE，前三章不要求落正式名

同意报告判断。

前三章：
- 可以有薄册 / 凭证 / 记录；
- 乔九可以翻到陆野当前筑基状态与舍味那份记录；
- 人物可说“册子”“记录”。

**不要求读者前三章记住“修籍”。**

“修籍”是否成为后续制度正式词，等它真正有复用价值再决定。

---

# 2. 货签夹 / 簧针｜普通化再多一步

视觉侧“旧木/硬竹夹具 + 可拆金属弹性件”通过。

正文：
- 首次：“夹货牌的旧木夹”；
- 后续：“木夹 / 夹子”。

但总评审不同意把“簧针”视为普通读者天然熟悉词。

正文优先：
- 小铁簧；
- 铁簧；
- 里面那根弹簧件（按最终视觉形态）。

只有工作现场后续确实需要稳定叫法，才考虑“簧针”。

原则：
> 第一章的目标是让陆野动作立人，不是教夹具零件名。

---

# 3. 押手｜可以保留行业味，但不是读者第一入口

“押手”可作为驿货行内部短称候选。

但第一次先让读者理解：
> 押货 / 跟货走 / 真正负责货路的人。

等语境建立后，再自然出现“押手”。

这样既保留职业世界感，也不在第一章额外占一个认知槽。

---

# 4. 封位外环｜正文降级，但现在不正式改Canon/实现名

报告建议：
> 封位环 / 封环 / 外环。

总评审接受：
- 现场：**封环 / 外环**
- 读者首次：**舍台最外面那圈**

但暂不正式锁“封位环”。

理由：
> “封位环”仍然偏设备BOM词，而前三章没有必要让读者记正式构件名。

因此当前状态：

> **正式实现名 OPEN；正文短称可用“封环/外环”。**

避免现在改一次名，后续舍务制度展开又再改一次。

---

# 5. “舍味 -> 筑基”新增一条真正的硬门

报告A+B+C组合正确，但还缺一条最关键的前置条件：

> **在事故发生前，读者必须已经知道陆野本来就处在筑基最后阶段。**

不能只存在于作者Bible。

第一章或第二章事故前必须通过非常自然的一拍，让读者得到：

> 该练的已经练到这里，陆野不是今天第一次准备筑基；他只是一直卡在最后那关。

不要求出现：
- 修积；
- 明悟；
- 续我

三个正式词。

但这个事实必须在“舍味”之前成为读者已知信息。

否则无论第三章怎么解释，戏剧体验仍会自动压缩成：

> 舍味 -> 换筑基。

这是 Ch1—3 Reader-Language 的硬门。

---

# 6. 第一章食物｜允许先锁一个 Working Default

为避免正文前还留“便宜热汤”占位，第一章正式试写首选：

> **咸菜豆腐汤**

理由：
- 普通；
- 便宜；
- 咸得过头合理；
- 兑热水后仍能喝；
- 不抢世界设定。

这只是第一章生活实现，不升级世界Canon。

若Scene Spine发现具体货场生活与“豆腐汤”冲突，可在总编批准下换同功能具体食物；不得退回“便宜热汤”。

---

# 7. 封余针 / 隔余布 / 临时封具｜不在本轮强行造三套正式名

第三章需要：
> 人能递、铺、压、卡、收紧的真实工具。

当前策略：
- 封针：可作为现场短称候选；
- 封布：可作为现场短称候选；
- “临时封具”仍是作者占位，正文前必须具体成一个可操作实物。

是否正式叫“封余针 / 隔余布”延后到第三章 Scene Spine 前决定。

避免为了一个救援段一次性制造三条新术语。

---

# 8. 前10章结构风险暂不追加PATCH

Phase B提出：
- 第3章后职业恢复链偏单一；
- 神秘线预算窄；
- 许可阶梯感。

当前仍维持：

> **不因结构摘要的机械感新增第二次异常味、第二场事故、新余器或新反转。**

先用真实第一章、前三章文本验证。

---

# 9. 正式通过项

批准：
1. 五层语言转换框架；
2. 58项风险扫描作为语言红队基线；
3. Ch1—3 Reader-Language Sheet总体结构；
4. 事故“工程版 / 读者动作版 / 现场口令版”三层翻译；
5. A+B+C解决“舍味=换筑基”误读；
6. 普通物件具体化；
7. 实现词KEEP / DOWNGRADE / OPEN机制。

经上述6项编辑修正后，可以进入：

> **第一章 Scene Spine。**

不需要再开一轮Reader-Language研究。
