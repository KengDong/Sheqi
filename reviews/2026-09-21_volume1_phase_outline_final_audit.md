这版阶段纲**结构上已经通过**。

>
> **第二，必须在开篇回答：既然味觉舍备已经有效，陆野为什么不在事故前主动舍味筑基？**

这两个如果不补，真正写前三章时会直接冒出来。

# 1. 第一处必须修：Phase A 不应按 0%—18% 冻结

Proposal 当前给：

> Phase A 约0%—18%。

但它同时又规定：

> 第3章默认已经完成事故、舍味、筑基、漏舍与资格冻结。

这两件事放在一起，会产生明显结构问题。

## 为什么

Phase A 的核心问题是：

> **“我快转正了。”**

事故完成以后，主角的新问题已经变成：

> **“我要恢复工作 / 证明自己还能做。”**

这实际上已经进入 Phase B。

如果一卷约80—120章，18%意味着事故后的十来章仍然被算在：

> “想转正，事故把路打断”

这一阶段。

这会给第一次写长篇一个错误执行信号：

> 第4章以后可以慢慢处理事故后果，等到十几章再正式进入复工目标。

而我们前一轮刚刚把“高开低走”列为最大风险之一。

## 最终建议

不要冻结 Phase A 的18%。

改成状态边界：

> **Phase A = 从第一章到“事故即时结算 + 陆野重新确立主动目标”为止。**

默认应很短。

功能上大致：

> **约0%—8%/12%上下，甚至更短。**

真正换挡条件：

1. 舍味已完成；
2. 筑基已完成；
3. 资格冻结已明确；
4. 味觉永久损失第一次落到普通生活；
5. 陆野主动决定：
   > “我要尽快恢复能挣钱的工作 / 证明自己还能干。”

满足这五项，立即进入 Phase B。

### 重要
秘密释放梯仍按阅读时间推进。

Phase B提早开始，
**不代表第6章就可以做外界来源控制变量确认。**

Phase 与 mystery ladder 是两套坐标。

# 2. 第二处必须修：为什么陆野事故前不直接舍味筑基？

这是当前开篇最大的潜在逻辑洞。

Canon 已经锁定：

- 陆野已完成修积；
- 已完成明悟；
- 已进入真实筑基续关；
- 味觉真实、可切；
- 对他这一次续关足够；
- 舍备已经有效。

第一章又会让读者知道：

> 他想争更好的押货机会。

那么一个非常自然的问题会出现：

> **“既然味觉已经能让你筑基，你又想要正式押货资格，为什么不昨天就把味觉舍了？”**

目前 Proposal 只说：

> 味觉是他相对“舍得起”的候选。

这还不够。

“舍得起”不等于“平时就值得舍”。

## 必须补成清晰的人物决策阈值

建议冻结的功能逻辑：

> **舍备是陆野的应急保险，不是他的日常晋升方案。**

事故前：
- 他仍然优先希望完整续我 / 继续自然适应完成筑基；
- 味觉虽是他认为最能承受的永久损失，但永久损失仍然是损失；
- 多挣一份工钱、快一点转正，不足以让他主动立刻切掉味觉；
- 真正跨过阈值的是：
  > **现场有人等不起，而只有他筑基后才可能完成救援。**

这会让“主动舍味”更有重量。

同时还能避免把陆野写成：

> 为升职随手切自己一块。

### 这并不削弱开篇的人格矛盾

他的早期问题仍然可以是：

> 他过度按“是否影响挣钱、活命、工作”评估味觉价值。

但必须区别：

> **“这是我最能承受的应急损失”**

和

> **“为了升职现在就切了吧”。**

前者成立。

后者会让人物与世界迅速滑向纯资本剥削寓言。

### 第一章只需极轻表达

不需要解释一整套完整续我方案。

只需让读者明白：

> 他有这份预案，但正常情况下并不打算今天就用。

具体台词留章卡。

# 3. 第三处必须修：事故A目前仍有“弹珠机式巧合”风险

Proposal 推荐：

> 固定中转台绞架 / 导向件故障  
> -> 重载偏斜  
> -> 撞伤低风险封存退件  
> -> 异常泄漏  
> -> 又波及应急舍台封位外环  
> -> 同时有人被困。

功能都对。

但如果正文空间图处理不好，会变成：

> 作者为了同时得到“被困者 + 异常泄漏 + 舍台外环损坏”，让一块货架连续撞三个剧情按钮。

这正是 Canon 当初要避免的“天降雷劈刚好坏一半”另一种版本。

## 最终要求

事故章卡必须做成：

> **一个主物理失效链，同时产生三类后果。**

不是三个独立巧合。

更理想的几何是：

> 同一台重载转运架 / 吊运单元发生导向失效或侧摆  
> -> 一侧夹住装卸工  
> -> 同一载荷中的低风险封存退件受冲击泄漏  
> -> 失控单元的另一侧 / 摆臂撞到紧邻的应急封位外环。

也就是说：

> **一个东西失控，一次空间事件，三种后果。**

不要：
> A坏 -> A撞B -> B又炸C -> C再碰D。

## A / B 的最终建议

仍然允许 A 为首选。

但它只是：

> **A'：单一几何因果版**

而不是当前文字版直接冻结。

章卡前必须画一个极简空间图。

如果空间图无法让：
- 货架；
- 被困者；
- 封存退件；
- 舍台外环

自然处在同一工作区域，

直接改 B 坡道车架。

不要为了保住研究阶段首选硬凑空间。

# 4. 第四处必须修：Phase D 的秘密结论略微过头

Proposal 在 Phase D 写：

> “一份有效舍后残留可以离开原位置、附着别处、聚集并重新表现某些性质。”

这基本已经接近 `canon/10_mystery_ladder.md` 约120章的第一阶段结论。

如果第一卷最终接近100—120章，它可以成立。

但我们现在明确**没有冻结第一卷总章数**。

因此不能把“第一卷=必须拿到120章结论”写死。

## 最终建议

阶段纲只锁**事件事实**，不锁普遍理论结论：

第一卷卷末可以明确观察到：

> **本次中转事故相关的异常残留，确实出现在多个共享材料 / 载具 / 节点上，并发生混杂、积累与现实影响。**

陆野 / 周照可以据此做流程整改。

但不要强制所有人得出：

> “所有有效舍后残留都具有统一的迁移—聚集规律。”

更不能提前推出：
- 统一去向；
- 完整弃相理论；
- 余世。

如果第一卷最终长度与秘密梯自然抵达约120章结论，再在章卡阶段升级认知。

### 核心区分

> **可以看到一个事故中的规律。**

不等于：

> **已经建立普遍世界理论。**

# 5. 第五处建议修：弹性单元不要“4个都默认会进”

Proposal 的选择是：

- 乔九线路扩张｜保留
- 唐禾客户线｜保留并合并
- 生活锚点第二次现实冲突｜保留
- 窄用途余器 / 异常旧物｜保留一个弹性槽

前三项我支持。

第四项只支持：

> **保留槽位，不承诺第一卷一定使用。**

原因：

第一卷已经同时承担：
- 舍味；
- 漏舍；
- 外界异常确认；
- 纯修仙试岗；
- 固定席位；
- 唐禾客户信用；
- 尝余误判；
- 流程余灾。

如果章卡阶段再为了“拾余线也得露一下”硬塞一件正式余器，很容易开始出现：

> 设定库存展示。

## 最终建议

正式阶段纲锁三项弹性功能：

1. 乔九线路扩张；
2. 唐禾客户信用；
3. 生活锚点第二次现实冲突。

第四个：

> **“窄用途异常旧物 / 余器”只作为第一优先可删槽。**

只有它同时完成至少两个功能时才进：
- 推进人物关系；
- 改变职业状态；
- 建立产权 / 风险问题；
- 为误判或流程因果留下后果。

如果只是：
> “看，我们余器设定也很好玩”，

直接砍。

# 12. 第一卷真正值得冻结的六次状态换挡

> 我快有资格了  
> -> 我主动舍味、筑基，却失去资格  
> -> 我靠正常本事拿回资格  
> -> 我发现有资格仍然没有自己的位置

这六次换挡比“12个事件”重要得多。

正式阶段纲应该优先冻结：

> **状态改变**

而不是：

> **事件库存。**
