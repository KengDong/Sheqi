# 结论

本轮失败不是“题材又选错了”这么简单。

作者匿名点击测试显示：
- Pool 1 四案在书名+钩子阶段全部无兴趣；
- Pool 2 四案、Pool 3 三案在书名+钩子阶段全部能留下；
- 但作者读完这7本简介后，反馈统一为：兴趣都不大。

因此当前不能从7本里硬选一本进入正文。

# 根因一｜把“能写长”放到了“想不想看”前面

五方向综合曾明确提醒：
> 前面赢来的东西继续改变下一轮，只是共同结构观察，不是已证明的成功公式。

但三方向 Concept 协议把它硬化成：
- Ch20至少3–5个永久状态；
- 两条关系必须自己造剧情；
- Ch20–100必须证明不流水线；
- Ch100仍是同一本书。

结果模型首先优化“连续性和防退化”，再优化吸引力。

# 根因二｜Reader Fantasy 被误当成完整 Premise

“低位被重新评价”“猎物变猎手”“看懂隐藏因果”是读者体验，不是一本具体小说的完整吸引物。

本轮多数 Concept 只完成了：
> 成熟母体 + 核心爽感 + 合理长期结构

缺少：
> 只有这一本才有的中心欲望 / 大问题 / 大危机 / 大秘密 / 明确终局牵引。

# 根因三｜过度防套路，连强刺激一起被削掉

协议反复要求：
- 不全场跪；
- 不新豪门排队；
- 不技能槽；
- 不机构派任务；
- 不奇怪设定；
- 不快速清零低位；
- 不复杂世界观。

这些防线本身正确，但本轮没有同步要求“删掉套路后必须补回同等强度的正向刺激”。

结果成为：
> 不低智、不流水线、不乱加设定，但也不够狠、不够大、不够想马上看。

# 根因四｜主角大多只有“正确性格”，没有强烈人生欲望

多数主角的主要性格是：
- 谨慎；
- 讲边界；
- 不装懂；
- 不爱解释；
- 不愿被安排；
- 责任感强。

这些适合长期写人，但很少形成：
> 我非得做到某件事，否则我不会停。

所以读者能理解主角，却不一定会被主角拖着往前跑。

# 根因五｜缺少长程磁铁

Pool 2 的长期承诺多是：
> 名声、人脉、社会位置越来越高。

Pool 3 多是：
> 主角越来越不像人 / 和第一只诡关系越来越深。

这些是“变化方向”，不是足够具体的悬念终点。

简介一旦从第一爽点进入长期介绍，就开始泄气。

# 根因六｜包装也在解释“不会写烂”，而不是只卖欲望

典型句式：
- “不是全院下跪”
- “这不是多一个影子技能”
- “但这不是收服”
- “不是靠一次翻案”
- “不是每次都……”

这些是给编辑看的防守语言，不该成为消费者文案的重心。

包装 QA 重点检查了忠实、清楚、公平，却没有设置同强度的：
> 非看不可感 / 中心悬念 / 想知道下一步的冲动。

# Pool 层结论

Pool 1：
> 对当前作者本人，四种包装入口均无第一眼吸引力。先 HOLD，不再继续烧概念轮次。此结论是作者偏好，不是市场强弱结论。

Pool 2：
> 母体和第一眼身份反转仍有吸引力；问题主要出在“第一次翻身以后有什么非看不可”。

Pool 3：
> 吞诡 / 影诡 / 共命三个首钩都能吸引作者；问题同样是长期展开变成机制解释，缺少更大的方向性牵引。

# 流程纠正

下一轮不再先生成完整14项 Concept。

正确顺序：

1. 只在 Pool 2 / Pool 3 内先做极短“点击磁铁”实验；
2. 每个原始想法只允许给：
   - 一句核心 premise；
   - 前3章第一次兑现；
   - 一个具体长程牵引（目标 / 秘密 / 危机 / 倒计时 / 必须抵达的终点）；
3. 作者直接人工快筛；
4. 只有作者真正想看的少数想法，才进入 Ch20 / Ch100 / 关系复利 / 防流水线审查；
5. 长篇结构只能验证和保护吸引力，不能反过来改造成“正确但没欲望”的方案。

# 新硬 Gate

一个想法在进入结构设计之前，必须先回答：

> 除了“它属于热门题材、结构能写长”，陌生人为什么会对这一本产生明确的“我想知道接下来会怎样”？

如果这句话答不出：
> 不进入 Concept 架构阶段。
