# Rule-Reality Failure Synthesis｜为什么连续改了很多次，仍然反复“不好看”

# 0. Executive Conclusion

过去的问题不是单个副本、单个人物或某条规则没设计好。

根因是创作流程反复发生同一类替代：

> **用“逻辑完整 / 架构安全 / 功能齐全 / Checklist通过”替代“具体、好看、有欲望、有人味”。**

典型症状：

- 作者说“平淡” -> 系统补更完整逻辑；
- 作者说“副本太低级” -> 系统把环境做得更大；
- 作者说“主角没魅力” -> 系统再加人格形容词；
- 作者说“要智慧爽” -> 系统给普通准备/录音/报警；
- 作者说“副本要可怕” -> 系统叠加坍塌/虚空/消失/多次濒死；
- 作者说“有伏笔” -> 系统埋路牌/日期/符号。

这些都可以“正确”，但仍然没有小说味。

---

# 1. Root Cause A｜AI先设计，热门成品后背书

过去多轮先由模型闭门生成方案，
然后才去找：
> “热门作品里也有类似功能。”

这会导致：
- 第一版审美锚点已经被AI默认分布锁死；
- Benchmark只能装饰，不能推翻；
- 最后得到“成熟功能平均值”，而不是头部成品的真实强度。

Correction:
> Benchmark必须发生在创意方案之前。

Authority:
> FIRST_PRINCIPLES_FICTION_RND_OS Section 2.

---

# 2. Root Cause B｜Rule-First，误把Returned Rule当Field

错误心智：
> Field #1 = 真名规则的来源。
> Field #2 = 门规则的来源。

结果：
- 整个副本围着一条规则展示；
- 人物像测试员；
- 场景像规则实验室；
- Reader记住“这个机制”，而不是“发生过一场可怕的故事”。

Correction:
> Field先是一部完整恐怖/悬疑/生存故事。
> Returned Rule只是最终从中带走的一小块残留。

但注意：
> 这也不能反向变成“环境灾难先行”。
> 故事事件 / 人物欲望 / 特定陷境必须先成立。

---

# 3. Root Cause C｜规模膨胀替代戏剧强度

作者说：
> “低级 / 不够疯 / 不够可怕。”

错误响应：
- 城市重叠；
- 楼层掉出世界；
- 虚空；
- 世界剥离；
- 更大地图。

这些是“量级词”，不等于戏剧。

一个副本可以全球级，
仍然很无聊。

Correction:
> 不先问“多大”，先问：
> **Reader此刻具体怕什么？谁要什么？什么正常选择会让事情变坏？谁会因此做出痛苦决定？**

Scale只能放大一个已经有生命的事件。

---

# 4. Root Cause D｜Checklist Assembly / AI模块拼装

典型旧设计：

> 环境威胁A
> + 人类背叛B
> + 规则C
> + 4次濒死
> + 中段反转
> + 主线伏笔
> + 一个Icon

功能全了，
但没有一个不可拆的“故事核心”。

如果把：
- 地点换掉；
- 怪物换掉；
- 规则名换掉；

整个方案仍然大致成立，
说明不够专属。

Correction:
> 先找到“只有这个故事才能这样发生”的主事件，
> 再让规则、人物、空间、恐怖都从同一个事件因果里长出来。

---

# 5. Root Cause E｜抽象机制代替具体邪性

过去方案常出现：
- “身份绑定”；
- “空间重叠”；
- “inside/outside”；
- “现实兼容”；
- “规则累积”。

这些适合后台Architecture，
不适合承担Reader第一印象。

Reader记忆来自更具体的东西：
- 一个行为；
- 一个地方；
- 一个死人；
- 一件物；
- 一句误解；
- 一个关系；
- 一个让人不敢做的正常动作。

Correction:
> 前台先具体，后台再抽象。
> Reader第一次绝不能先理解taxonomy。

---

# 6. Root Cause F｜人物用形容词塑造，不用关系与行为塑造

旧程野：
> 稳 / 负责 / 低攻击性 / fallback / cost has a name。

逻辑没错，
但像高级项目经理。

作者真正要的是关系反差：

## 对敌人
> 冷酷 / 谨慎 / 果断 / 确认威胁后不给愚蠢第二次机会。

## 对队友家人
> 幽默 / 暖 / 松弛 / 可靠 / 可以被损。

更重要：
> 这第二张脸必须由Field #1中的具体事件“长出来”。

Correction:
> Character Bible必须记录：
> pre-event baseline + origin scar + enemy mode + ally mode + failure mode。
> 不能只写3–5个形容词。

---

# 7. Root Cause G｜“聪明”写成普通理性行为

旧智慧爽候选：
- 报警；
- 录音；
- 留证；
- 找出口；
- 做备份。

现实里当然正确，
小说里不够独有。

真正有用的突破：
> Rule Experience Gap。

现实第一次遭遇Returned Rule时，
程野已经在它成熟生态里活过。

所以智慧爽要来自：
- 成熟规则经验；
- 奇怪但有因果的工具；
- 环境利用；
- 对手误判胜利条件；
- 已知“聪明办法”为什么会死人；
- 对手学习以后第二层再反制。

Correction:
> “聪明”必须形成Reader能复述的场面，
> 不是作者评价。

---

# 8. Root Cause H｜过度保护旧架构，自动选择最收敛方案

模型长期倾向：
> 少改旧设定；
> 不新增冲突；
> 选最容易自洽的版本。

结果：
> 安全，但不炸。

作者多次反馈：
- 太平淡；
- 太收敛；
- 没降维感；
- 不好看。

Correction:
> 大改问题至少先看热门成品后生成：
> - 高商业冲击路线；
> - 怪/高上限路线；
> - 稳健路线。
> 不能默认最稳版本为首选。

---

# 9. Root Cause I｜过早扩写，核心没过作者口味就建Arc

多次发生：

> 一句话核心还没让作者觉得“想看”
> -> 已经扩成完整Field架构
> -> 又加伏笔
> -> 又加人物
> -> 又写QA。

这是高成本放大错误。

Correction:
> 新重大创意分四级：
> 1. Taste Match；
> 2. One-Sentence Desire；
> 3. Scene Trailer；
> 4. Micro-Prose；
> 只有前三个作者/证据通过，才Arc Card。

---

# 10. Root Cause J｜AI Reader / Selfcheck权重过高

Git历史已经证明：
> 多轮Fresh Reader / Selfcheck STRONG PASS，
> 最终作者真实连续阅读仍在Ch7开始弃读。

原因：
- Reader任务常要求读完；
- 会进入评审模式；
- 后续优点能补偿前面无聊；
- AI容易理解作者意图后给“设计合理”加分。

Correction:
> 最重要Reader测试：
> **voluntary stop**。

Reader必须：
- 随时可以停；
- 一停就停；
- 不要求完成；
- 先记录想不想继续，再分析。

作者真实阅读：
> 权重高于AI评分。

---

# 11. Root Cause K｜Benchmark本身也可能AI化

即使先搜热门，
仍可能失败：

> A学一个威胁
> + B学一个人物
> + C学一个反转
> = AI拼盘。

Correction:
> Benchmark不做“特征购物”。

每轮只提炼：
> **为什么Reader在那个具体场景继续读的因果链。**

必须回答：
- 人物当时想要什么？
- 为什么不能不做？
- 威胁怎么逼选择？
- 哪一步改变了Reader理解？
- 如果删掉哪一个环节，戏就死？

借“因果”，不借零件。

---

# 12. Root Cause L｜伏笔太“设计师”

旧式伏笔：
- 路牌；
- 日期；
- 市政标记；
- 远处建筑。

可以存在，
但只是世界线索。

作者要的“后面爆出来”更接近：

> 第一遍把一个人/行为/死亡/物件理解成A，
> 后面揭示其实是B，
> 回看时整个场景意义改变。

Correction:
> 主线伏笔优先埋在：
- 人；
- 决定；
- 误解；
- 已经解释过的死亡；
- 看似生活化的行为；
- 一件当时“已经有答案”的东西。

World-map clue只做辅层。

---

# 13. Root Cause M｜项目Authority没有及时死亡

Current repo曾同时保留：
- D-0114候选；
- D-0115候选；
- “Character Lab NEXT”；
- “D-0112 paused”；
- ACTIVE_WORKSTREAMS还停在D-0111。

这会导致：
> 新窗口读Git仍可能沿失效任务继续。

Correction:
> 每次作者明确否决，
> 旧路线必须从CURRENT/NEXT移到：
> REJECTED / HISTORY / EVIDENCE ONLY。

CURRENT_AUTHORITY只保留：
- 现在有效的原则；
- 当前唯一Gate；
- 当前唯一下一步；
- 仍有效的已锁资产。

不要把项目历史堆在CURRENT里。

# 14. What Is Actually Working

以下不应因重构而一起丢掉：

## A. Core Book Premise
> 每次活着回来必须带一条规则进入现实。
仍有明显独特性。

## B. Rule Experience Gap
> Field里程野是新手，现实里世界是新手。
这是目前最有商业兑现感的新资产。

## C. Cheng Ye Duality
> 敌人冷酷谨慎，自己人幽默暖松弛。
微原型已经证明方向比旧人格明显更有生命。

## D. Family / Reality Contrast
回到普通生活后形成巨大反差，
仍是本书差异化资产。

## E. Second Reality / Failed Future
可作为后台长线候选，
但不要再拿它强迫每个早期副本“服务世界观”。

## F. Voluntary Reader Principle
应继续成为高权重证据。
