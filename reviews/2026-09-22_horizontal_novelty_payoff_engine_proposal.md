# 高频横向新鲜感 + 纵深秘密 + 爽感回报｜第一卷发动机提案 V0

## 0. 作者方向

作者明确要求：
- 第一卷从头开始就要有爽感和新鲜感，不能把真正好看的东西押到后期；
- 不能只靠余世大秘密低频释放；
- 需要“高频横向新鲜感 + 纵向深秘密”并行；
- 惜物本身没有足够商业爽感，必须转化为可见收益：捡漏、收集、养成、工具、意外收入、身份/资源增长；
- 读者需要反复产生：
  > **“原来这个设定还能这么用。”**

本提案不修改Canon，先定义新的第一卷故事发动机方向。

---

# 1. 核心修正：惜物不再作为“文学主题”，而转为价值发现能力

旧表现：
> 别人扔，陆野多看一眼。

商业化后应变成：
> **别人判废 -> 陆野判断仍有价值 -> 低成本拿到 -> 修/试/用 -> 产生具体收益 -> 收入/工具/关系/秘密继续升级。**

内部暂称：
> **价值回收循环**

不是外挂鉴宝。

陆野的优势由四部分组成：
1. 普通职业经验：会判断损耗、修复、可复用性；
2. 正常修炼与工程能力；
3. 舍味后的有限异常感知：只能提示“这里可能有东西”，不提供名称/价格/结论；
4. 愿意对别人已判废的东西多做一次验证。

爽点必须是可见的：
- 少花钱拿到；
- 修好；
- 解决任务；
- 卖钱；
- 换资源；
- 收进自己的工具箱；
- 后面再次派上用场。

---

# 2. 第一卷新增四条并行发动机

## Engine A｜修炼/行动爽
正常修炼、筑基新权限、战斗/救援/押运能力成长。

## Engine B｜舍弃文明横向新鲜感
同一舍弃规则不断撞上不同现实领域：
- 工作；
- 借载；
- 赔偿；
- 保险；
- 排班；
- 宗门资助；
- 家庭；
- 黑市；
- 缺位适岗；
- 高危舍备。

原则：每次必须绑定人物当前利益，不写制度百科。

## Engine C｜价值回收/收集养成/意外收入
从普通废件逐步走到舍后残留物、窄用余器、特殊工具。

进度不是数值面板，而是：
> **工具箱更丰富 + 眼界更强 + 资源更厚 + 赚钱渠道变多 + 人脉/市场准入提高。**

## Engine D｜秘密递进
大秘密余世不直接早揭。
但增加中秘密/中大秘密，形成：
> 小确认 -> 中秘密 -> 可利用 -> 官方层 -> 统一去向 -> 余世大秘密。

---

# 3. 中秘密梯｜不等余世大揭秘

## M0｜公开常识
> 舍成功以后仍要收尾、封闭、清理。

普通人知道有后处理，但不知道真正去向。

## M1｜舍后残留不是完全随机事故
> 某些旧封具/退件/场地会稳定出现可重复异常。

只确认“有东西留下”，不确认是什么。

## M2｜残留有分类差异
> 不同舍后残留表现不同，而且这种差异可重复。

第一次给主角“可研究/可判断”的东西。

## M3｜残留可以产生窄用价值
> 某些被当危险废物处理的东西，在严格条件下有实际用途。

这是第一轮收集/捡漏/变现大爽点。

## M4｜有人已经在买/处理这类东西
> 官方、灰市或特定工坊存在分类、回收、封存、再利用。

世界从“怪事”升级成“产业/利益”。

## M5｜处理不是销毁，而是转运/导走
> 大量舍后残留最终有共同的流向或处理网络。

这是指向余世的大中秘密。

## M6｜利用与安全并存
> 截流/利用残留可能既有利益，也承担现实安全功能。

避免变成简单“上层偷走穷人的东西”。

## Big Secret｜余世
> 被有效舍掉的自我结构长期积累、迁移、聚合，甚至可能形成新的结构/主体。

注意：M1—M6都必须带来现实行动/收益/损失，不能只做Lore揭晓。

# 4. 价值回收循环｜从文学惜物变成商业爽感

建议阶段：

### Stage 1｜普通修复收益
陆野对普通废件/退件的判断带来小额实际收入或降低自己的装备成本。

作用：
> 先证明“多看一眼”能赚钱，不靠超自然。

### Stage 2｜第一次异常捡漏
舍味后，他对某个被判低价值/需处理物件出现异常信号。
他不知道是什么，只知道值得验证。

结果必须是：
> **小成本拿到 -> 后来证明确实有窄用价值。**

### Stage 3｜第一件真正收藏物
获得一件“一器一奇用”的窄用物。
不是数值加成，而是一个非常具体、以后还能回收利用的工具。

### Stage 4｜第一次变现
不是只收藏。
至少一次：
> 买/领得便宜 -> 处理/修复/证明用途 -> 卖出或换资源。

收益要能换成读者看得见的东西：
- 练功资源；
- 装备；
- 住房/生活改善；
- 押货资本；
- 下一次收集本金。

### Stage 5｜小型工具箱形成
陆野不追求“万宝库”。
保持少量高辨识度物件，后面回用，形成养成满足感。

### Stage 6｜市场与监管出现
当他开始赚钱，才自然撞上：
- 谁能收；
- 谁能卖；
- 什么必须封；
- 什么算危险品；
- 为什么有人愿意高价买。

此时社会横向线与余世秘密线合流。

# 5. Taste anomaly 的商业用法边界

尝余不能变成：
> 看一眼就知道名字/价格/来历的鉴宝外挂。

它只允许提供：
> **值得查的信号。**

爽点来自：
> 信号 + 陆野自己的职业判断 + 试验 + 修复 + 风险承担。

必须保留：
- 会错；
- 会串味；
- 高混杂环境会失效；
- 无UI；
- 无来源标签；
- 无市场价格提示。

因此“捡漏爽”是earned payoff，不是系统发奖。

# 6. 第一卷爽感结构建议

不是章章高潮，但每个小弧必须有可见兑现。

建议第一卷反复轮换：

### Action Payoff
修炼/专业行动解决别人解决不了的问题。

### Money Payoff
真正拿到钱、减少成本、扩大本金。

### Collection Payoff
得到一个新工具/奇物，并明确知道它能干什么。

### Knowledge Payoff
中秘密被确认一层，不只是多一个疑问。

### Status Payoff
别人对陆野的定价改变，但不能只是“责任+1”。

### Reversal Payoff
别人认为废/风险/没用的东西，后来被陆野证明有另一种价值。

原则：
> **一次小弧至少要结算一项读者能数得出来的收益。**

不是只得到“经验”。

# 7. 第一卷现Story Engine需要重审的地方

当前：
> 资格冻结 -> 限制复工 -> 恢复资格 -> 固定席位竞争

现实感有，但爽感与新鲜感不足。

未来Outline Change Proposal应检查：
1. 哪些“许可/复工”章节可压缩；
2. 哪些位置插入真实赚钱/收集/工具成长；
3. 哪些位置插入不同领域的舍弃文明冲突；
4. 哪些位置给中秘密明确结算；
5. 卷末除了固定席位，还应有一个可见资产成长：
   - 工具箱；
   - 本金；
   - 稳定副收入；
   - 市场入口；
   四者至少一个形成明显台阶。

# 8. 与外部成熟作品应借鉴的功能

只借结构功能，不模仿文风：

## 《你们修仙，我种田》
> 高频“培育/收获 -> 不同具体奖励”的正反馈。

借：
> **每个小循环有具体东西落袋。**

不借：
> 重复种植模板/系统奖池。

## 《我有一座冒险屋》
> 每次任务既带来新场景/新资产/扩建，又持续指向父母失踪的大纵线。

借：
> **横向收集与纵向谜团同时推进。**

## 《苟在初圣魔门当人材》
> 每次小循环都能带回宝物、修为、寿命或天赋，失败也形成积累。

借：
> **每一弧都要留下可见资产，而不是只留下“知道更多”。**

## 《亏成首富从游戏开始》
> 同一核心机制不断进入不同业务领域，产生新的冲突与笑点。

借：
> **核心规则横向撞不同社会模块。**

## 《修真聊天群》
> 同一修真设定不断进入现代日常的不同场景，靠人物和场景变化维持高频新鲜感。

借：
> **熟悉生活模块不断被核心设定重新解释。**

# 9. 需要避免

- 不做舍项图鉴；
- 不做每件废物都是宝；
- 不做鉴宝UI；
- 不做无限背包；
- 不让“余器收集”取代正常修炼；
- 不把保险/婚姻/法律轮流写成设定百科；
- 不把每个中秘密只写成“又多了一个问题”；
- 不把“惜物”继续当纯文学性格就算完成；
- 不把第一卷爽点押到卷末。
