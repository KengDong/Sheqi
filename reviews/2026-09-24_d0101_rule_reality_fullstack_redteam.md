# D-0101｜Rule-Reality Full-Stack Red Team

# Verdict

> **PASS WITH PRE-PROSE BLOCKERS.**

V2 is materially broader than V1 and now has plausible head-tier breadth.

It has credible lead axes competitors do not naturally combine:
- permanent public rules;
- reward-as-externality;
- future-fragment mirror;
- old-rule compounding;
- final crisis built from prior rewards.

But V2 now has the opposite danger:
> **over-architecture.**

If all concepts become visible early, the book will become the exact “设计得很完整但不好读” failure the project is trying to escape.

# 1. Major Win｜The Candidate Is No Longer Narrow on Paper

V1 vertical:
> rule -> consequence -> social adaptation -> next rule.

V2 horizontal ledgers:
- protagonist;
- family;
- returner ensemble;
- Fang Cen/public world;
- hub;
- money/gear/info;
- access authority;
- field variety;
- other-returner conflict;
- future mystery;
- terminal crisis.

This solves the “只有几个点比肩/领先，其它窄” diagnosis at architecture level.

# 2. BLOCKER｜First 100 Chapters Can Carry Too Many Concepts

V2 contains:
- R1;
- new rules;
- black plaque;
- countdown;
- mirror anchors;
- access authority;
- other returners;
- 無名店;
- information economy;
- failed futures;
- reality overlap;
- branch weights;
- broken present.

Too much if exposed as terminology.

Hard reveal budget for first ~100:
ONLY four supernatural concepts may be consciously named:
1. returned public rule;
2. next-entry countdown;
3. black plaque / return choice;
4. other returners / familiar future-place evidence.

Everything else is observation.

Do NOT name:
- branch weight;
- mirror anchor;
- rule ecology;
- broken present;
- convergence.

# 3. BLOCKER｜Second Field Arrives Too Late in V2 Draft

Author's 92-point reaction explicitly includes:
> wanting to see the next dungeon.

Waiting until Ch20 to enter risks frustrating the strongest existing desire.

Revision:
- Ch1–4 current reality arc;
- Ch5–8 fallout;
- Ch9–11 preparation + outside anomaly;
- Ch12–15 second field BEGINS;
- Ch20 reader is inside the new field, not still waiting outside.

This keeps Reality equal without turning it into delay.

# 4. BLOCKER｜Field Quality Supply Is Still Unproven

The old 31-situation reservoir mostly proved:
> reality consequences and rule compounding.

It did NOT prove:
> 10+ genuinely different high-quality rule fields.

Before full Opening/P20:
> run a field-mode reservoir stress.

Requirement:
- at least 12 field premises;
- at least 6 dominant modes;
- no more than 3 relying on written-rule sheets;
- each has a human conflict and present-world mirror;
- no duplicate “spot the loophole” grammar.

# 5. BLOCKER｜Cheng Ye's Personality Is Architecture-Strong, Prose-Unproven

“谁先倒霉 / 普通人能不能过日子” is a good behavioral bias.

But it can become:
> responsible, sensible protagonist again.

Voice Lab must force actual distinctive behavior:
- embarrassing practicality;
- dry humor;
- one petty flaw;
- one choice that a generic heroic MC would NOT make.

If reader still describes him as:
> “冷静负责聪明,”
FAIL.

# 6. WATCH｜无名店 Can Become Management Fiction

The hub is one of V2's strongest improvements.

Hard:
> it must be a stage for people, not an upgrade menu.

No:
- floor plans;
- staff charts;
- “hub level”;
- procurement logs.

Use:
- recurring faces;
- objects;
- nicknames;
- one returned-rule argument;
- one human coming for help.

# 7. WATCH｜Personal Growth Still Less Visceral Than Score/Combat Books

Access Authority is conceptually elegant but not physically powerful.

That is acceptable for suspense IF:
- each authority immediately changes a field choice;
- preparation gear improves;
- social status changes;
- protagonist gets tactical wins.

Do not add generic combat stats just to imitate Global Death Exam.

# 8. WATCH｜Failed-Future Secret Could Become Generic Multiverse

The phrase “failed future” is useful architecture shorthand but risky prose.

Differentiator must be:
> **these futures are defined by SURVIVAL RULES that returners physically import into the present.**

Do not drift into:
- alternate-universe tourism;
- “every choice creates a timeline” lectures.

# 9. WATCH｜Broken Present Is Over-Commitment

The late idea:
> current reality is itself losing laws

is powerful because it prevents “just stop returning”.

But it is not required to sell Ch1–200.

Decision:
> **downgrade Broken Present from hard canon to LATE-CANON HYPOTHESIS.**

Keep only if mid-book evidence makes it necessary.

The hard canon terminal spine for now:
> returned rules pull failed futures closer; unchecked convergence can overwrite present reality.

# 10. WATCH｜Return Choice Ownership

Black plaque is excellent iconography.

Need simple rule:
> any surviving participant can take the plaque; only one selected line can cross; the return door does not fully open until someone carries the consequence.

This allows:
- persuasion;
- theft;
- sacrifice;
- rivalry.

Do NOT create a complex “who is qualified to hold plaque” subsystem.

# 11. COMPETITOR FLOOR AFTER V2

V2 now plausibly reaches:
- shelf: strong;
- reality engine: lead;
- macro spine: strong;
- hub: strong concept;
- growth: adequate concept;
- ensemble: designed but unproven;
- dungeon supply: still unproven;
- protagonist voice: still unproven;
- horror/atmosphere: still unproven.

Therefore next investment should NOT be another architecture layer.

Next:
1. field supply stress;
2. breakout surface / character voice;
3. P3.

# 12. Final Red-Team Rule

> **Do not add another engine until prose proves one of the existing engines is insufficient.**

The book is now broad enough on paper.
Its next risk is execution density, not conceptual thinness.
