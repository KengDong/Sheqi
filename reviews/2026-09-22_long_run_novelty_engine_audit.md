# 《舍弃》长期新鲜感发动机｜总评审审计

## 0. 核心判断

作者的感觉成立，但原因不是简单的“核心设定不够新”。

更准确地说：

> **《没钱修什么仙？》拥有高频、横向、可组合的新鲜感发动机；《舍弃》当前拥有较强的纵向深挖潜力，但横向表面积和实际剧情利用率都不足。**

如果《舍弃》只写成：
> 舍味 -> 换一个新舍项 -> 再来一个新舍项，

它会迅速退化成“删属性合集”。

如果只写成：
> 漏舍 -> 余痕 -> 余器 -> 余世，

它会变成低频谜底升级，中间大量普通职业剧情容易显得与核心概念无关。

真正需要建立的是多发动机并行的新鲜感结构。

---

# 1. 与《没钱修什么仙？》的根本差异

《没钱修什么仙？》的第一层高概念并不只是“修仙要花钱”。

它真正高频的是：
> **现代社会熟悉系统 × 修仙。**

学校、面试、贷款、兼职、竞赛、广告、平台、排名、赞助、大学、工作等熟悉模块，都可以与修仙重新组合。

因此它天然具备：
> **横向组合新鲜感。**

每换一个日常领域，都能得到一个新场景，而不必揭开更深世界秘密。

《舍弃》目前表面Pitch更像：
> **突破时可以永久舍掉一部分自己。**

这句话单独看确实比“整个现代社会都被修仙改造”窄。

但当前Canon真正拥有的不止这一层。

---

# 2. 《舍弃》实际拥有四个新鲜感发动机

## Engine A｜Personal Cost / 自我代价

核心问题：
> **我愿意永远不要什么？**

不是靠不断换猎奇舍项，而是探索：
- 什么真的属于“我”；
- 哪些东西能切开，哪些会牵连别的自己；
- 同一代价在不同人生里价格完全不同；
- 缺位以后如何生活、工作、相爱、承担责任。

这是情绪和人物发动机。

## Engine B｜Civilization / 舍弃文明

核心问题：
> **当一个社会知道“完整的自己可以被拿来承担突破风险”，社会会怎么运行？**

当前Canon已允许自然生长：
- 正破 / 借载 / 舍破的现实差异；
- 高危职业舍备；
- 宗门/家族资源分配；
- 家庭、婚姻、就业、保险、法律；
- 军方与职业管理；
- 社会对缺位重新定价。

这是最接近《没钱修什么仙？》高频横向新鲜感的发动机。

当前第一卷利用明显不足。

## Engine C｜Backflow / 被舍掉的东西没有消失

核心问题：
> **人不要的自己去了哪里，又会怎样回来？**

它天然可以逐层升级：
> 幻觉？ -> 外界残留？ -> 人的残留？ -> 余器？ -> 余灾？ -> 统一去向？ -> 截流？ -> 主体性？

这是世界谜团与大主线发动机。

## Engine D｜Lu Ye Lens / “你不要？给我看看”

这是当前项目最被低估的一层。

陆野的核心不是“喜欢捡垃圾”。

而是：
> **社会已经判断为废、缺、弃、风险的东西，他会多看一眼：真的没价值了吗？**

这个视角可以统一：
- 普通坏件该不该扔；
- 缺位者是不是低价值员工；
- 余痕是不是只有污染价值；
- 余器是不是只有危险；
- 被舍掉的自己是不是仍有权利/用途/代价；
- 最终“余世是不是垃圾桶”。

它能把人物、职业、主题和余世大线绑成同一个长期阅读合同。

---

# 3. 当前真正的问题

不是“Canon没有东西”。

而是：

## 3.1 第一卷发动机目前过度压在职业恢复

当前Story Engine里，大量中前段篇幅是：
> 资格冻结 -> 限制复工 -> 试岗 -> 恢复资格 -> 争固定席位。

这条现实线合理，但如果没有不断与Engine B/C/D交叉，读者会觉得：
> “高概念开头过去了，现在开始看物流职场文。”

## 3.2 Mystery Ladder太单线

20/40/60/80/120章的余世梯很清楚，
但如果每次“新鲜感升级”都只能等下一层余世谜底，频率太低。

必须用文明层、人物层在两次大谜底之间持续提供新东西。

## 3.3 社会层写在Canon里，但还没有转成剧情生产器

保险、家庭、就业、军方、婚姻、宗门等目前主要还是设定潜力。

只有进入人物目标、钱、关系和冲突，才会变成读者感受到的新鲜感。

---

# 4. 建议的长期“新鲜感梯”

以下不是固定章数，只是层级顺序。

| 阶段 | 新鲜感来源 | 读者得到的新东西 |
|---|---|---|
| Opening | 人真的可以永久舍掉自己的一部分 | “修仙还能付这种代价？” |
| Early 1 | 舍备是成熟高危社会工具 | “这不是主角特例，文明真的这样运转” |
| Early 2 | 完整续我/借载/舍破存在现实价格差 | “完整的自己居然也有成本结构” |
| Early 3 | 缺位进入工作/关系评价 | “失去的东西不会只在战斗里有后果” |
| Mystery 1 | 舍后还有清理/封闭 | “舍掉不是简单删除” |
| Mystery 2 | 外物能携带人的残留 | “人的一部分能留在世界里？” |
| Social 1 | 保险/赔偿/招聘围绕缺位发生真实争议 | “社会已经学会给缺位定价” |
| Artifact | 余器不是宝物，而是人的残留形成的窄用怪东西 | “法器也能来自被舍掉的自己？” |
| Error | 陆野把真实信号归错来源，伤到无辜者 | “主角特殊性不是答案机” |
| Institutional | 官方早有封、分、清除流程 | “原来文明早就在处理这些东西” |
| Ownership | 一份弃相/余器到底算谁的 | “舍掉以后还属于你吗？” |
| Restoration Trap | 有人试图用外来残留补回缺位，只得到代偿/侵入 | “缺位真不能恢复，而且替代更危险” |
| Scale Reveal | 海量舍弃存在统一去向/分流 | “这些东西根本不是零散垃圾” |
| Reversal | 截流/利用一部分弃相可能同时有剥削与安全价值 | “事情不是简单上层作恶” |
| Civilization | 余世中的相容弃相开始结构化 | “被丢掉的部分会不会已经不是‘物’？” |
| Endgame Question | 如果形成主体，人类还有没有权利把它们当废物/资源 | “整本书最早的‘不要了’被反过来审判” |

---

# 5. 读者“一新再新”不能靠不断加新规则

真正稳定的模式应是：

> **同一条规则 -> 第一次看见个人代价 -> 第二次看见社会制度 -> 第三次看见意外用途 -> 第四次看见反噬 -> 第五次发现之前的理解只对了一半。**

这是《舍弃》最适合的升级方式。

不要变成：
> 每20章再发明一个新舍弃规则。

---

# 6. 第一卷需要补的不是更多谜底，而是“横向文明新鲜感”

第一卷最需要补的是Engine B/D。

在不改余世秘密释放梯的情况下，至少应让前40—60章自然见到若干不同侧面，例如：
- 舍备为什么会进入高危岗位；
- 有人为什么宁愿借载欠债也不愿舍；
- 有人为什么反过来觉得某项舍掉更划算；
- 缺位如何进入排班/客户信任/赔偿；
- 同样“舍过”的人彼此并不构成一个统一群体；
- 陆野开始发现别人会因为他的缺位改变对他的使用方式。

这样读者会感到：
> “原来这设定还能长到这里。”

而不是等40章才拿到下一块余世谜底。

---

# 7. 需要警惕的三个退化方向

## 7.1 舍项图鉴
> 每隔一段介绍一个人舍了什么。

很快会变成猎奇卡牌。

## 7.2 社会制度百科
> 保险、婚姻、法律、学校全部轮流介绍。

必须绑定具体人物利益，否则就是设定集。

## 7.3 余世侦探
> 陆野靠尝余每章找一个异常物。

会把正常修炼、团队、职业和选择全部挤掉。

---

# 8. 总评审当前判断

> **《舍弃》的核心不是明显弱于《没钱修什么仙？》，而是“新鲜感的形态不同，且当前Outline只开发了其中一部分”。**

更具体：

- 《没钱修什么仙？》：横向组合型，第一眼就显得大，日常每换一个领域都能新；
- 《舍弃》：个人代价 + 文明后果 + 隐藏回流的三层递进型，第一眼更容易被误读成“一个舍属性机制”；
- 当前版本真正短板：文明横向层没有进入足够多真实剧情，导致中间段的新鲜感密度不够。

所以现在不建议改Bible。

但在正式重做Ch1—10以后，必须增加一个独立的：
> **Long-Run Novelty Engine Pass**

专门检查每一阶段是否至少由不同发动机提供新的阅读体验。

当前#36 Commercial Prose Calibration不被打断。
