- 双世界 / 跨世界修仙作品为什么能持续产生爽点；
- 信息差、资源差、身份差、制度差怎样从前期一次性新鲜感升级为长期发动机；

# 1. Executive finding

## 最高结论

双世界长期有效的核心，不是“有两个地图”，也不是“两个世界物价不同”。

真正耐写的是：

> 每次接触另一个世界，都能改变主角此刻对问题的判断、选择、身份或可进入的关系 / 制度入口；而且这种差异会从“物品差”升级成“知识生产方式差、验证方式差、身份认定差、制度分配差、关系网络差”。

因此：

### 最短命的差异
- 商品价格差；
- 灵石 / 黄金 / 古董等货币差；
- 普通消费品差；
- 一次性配方 / 技巧；
- 静态“现代一定比古代先进”。

这些很容易被资本积累、规模化采购或熟悉机制耗尽。

### 最耐写的差异
- 什么知识公开、什么知识被垄断；
- 谁能验证一套方法是否有效；
- 什么才算“天才 / 合格 / 正统”；
- 学校、宗门、公司、家族如何分配机会；
- 同一种能力在两边对应什么身份；
- 一边缺“方法”，另一边缺“条件”；
- 一边的制度优化解决了某类瓶颈，却因为本地环境产生另一类盲区；
- 两边各自拥有无法被另一边直接抹平的关系、地位、历史与风险。

这类差异不会因为主角“知道答案”就自动消失，反而会随着主角进入更高层级而放大。

# 3. Mandatory deep read A｜《原来我是仙道天骄》

## 3.1 市场事实

起点2026下半年“新晋万订”公开书单记录：
- 万订时间：2026-09-10；
- 现代线起点是太清市炼丹职业技术学院、人造灵根、流水线就业预期；
- 主角可肉身进入另一个古老修仙世界；
- 同一个人在现代线是低潜力、低预期，在古修世界却被视作天灵根级“仙道天骄”。

另一起点新书汇总记录：
- 2026-09-01上架；
- 收藏3.37万；
- 首订6691；
- 三江吸量2.50万，当期第二。

这使它成为当前窗口最重要的 CURRENT DIRECT。

## 3.2 Actual opening / early engine

公开目录显示前20章的推进不是“先把两个世界百科讲清楚”，而是连续用具体差异改变当前决策：

- Ch2：异界；
- Ch3：“古法修仙已经落伍了！”——第一次不是商品差，而是方法 / 标准差；
- Ch4：仙道潜力；
- Ch6：打针——现代技术 / 工业化修行进入；
- Ch7：网课收费——知识获取制度进入；
- Ch8：符箓是否落伍；
- Ch9：金甲符与剑气符；
- Ch10：生死搏杀；
- Ch14：废丹品鉴；
- Ch15：凝气丹；
- Ch18：炼气三层；
- Ch19：云津坊；
- Ch20：实验。

Reader 前20章拿到的不是单一“搬货赚钱”，而是反复观看：
> 同一件修仙事物，被两套知识体系重新定价 / 重新解释。

## 3.3 First concrete payoff

最早的 concrete payoff 不是“世界观真相”，而是：
1. 第二世界确认他在另一套标准下拥有高价值；
2. 现代知识 / 技术让古修事物的价值与风险可被重新判断；
3. 古修世界的材料 / 方法又能立即作用于现代线的修炼与处境。

即：
> crossing/contact → 新解释 → 立即改变行动。

## 3.5 What accumulates

至少四类资产同时增长：

1. 资源资本：药、符、灵物、资金 / 贷款等；
2. 知识资本：现代训练、药物、验证方法与古修传承互相解释；
3. 身份资本：大专生 / 法赛选手 / 剑道天骄 / 天灵根 / 道子；
4. 关系与制度资本：学校导师、比赛体系、宗门、真人 / 长老、市场网络。

重要的是：
> 前一次跨界得到的不是“用完就没”的奖励，而会改变下一次别人如何对待主角。

## 3.6 What changes socially

“被认为是什么人”不断发生变化，而且是两边分别变化：
- 现代社会：从低前景职业教育学生，进入更高训练、比赛、学历与专业评价；
- 古修世界：从陌生人，变成天灵根 / 剑道天骄 / 宗门核心身份。

这比物资差耐久，因为身份会带来：
- 新权限；
- 新期待；
- 新敌意；
- 新义务；
- 新信息入口。

## 3.7 What is deliberately delayed

标题承诺“仙道天骄”，但前几章没有一次性把完整身份红利给完。

早期先让 Reader 看到：
- 两界标准不一致；
- 小范围方法差；
- 第一次修炼效率差；
- 第一次生死验证。

真正的宗门级天骄待遇、道子级身份被推迟到中段逐步兑现。

因此“大身份”不是开局一次性礼包，而是一条可累计的社会证明链。

## 3.8 Shallow imitation failure

最危险的浅抄不是“也写双穿”，而是复制：
- 现代修仙职校 / 人造灵根 / 债务或流水线低位；
- 古修界立刻认定天灵根天骄；
- “现代科技证明古法落伍”的固定桥段；
- 高考 / 专升本 / 法赛 ↔ 宗门 / 道子两条完全同构的身份梯子。

可学功能：
> 同一个人的能力在两套评价制度中产生不同地位，并且每次地位变化反过来改变后续资源与关系。

不可学具体实现。

## 4.4 信息差到底是什么

这个样本最值得研究的地方，是它把“先进 / 落后”拆成了多个互相冲突的维度。

### 仙门更强的维度
公开教育、理论整理、网络检索、标准化、仪器 / 设备、制度化训练。

### 仙门更弱的维度
长期开发导致某些资源 / 灵气 / 高阶材料受限，很多知识即使知道，也缺现实条件直接兑现。

### 天河界更强的维度
灵地 / 灵物 / 原始资源、古老传承、真实高风险环境、某些仙门本土已经缺失的对象。

### 天河界更弱的维度
知识更容易被宗门 / 师承封闭；经验碎片化；验证与普及成本更高；地方秩序更危险。

因此它不是：
> A先进，B落后。

更准确是：
> A把“知识与制度”做得更强，却被环境资源约束；B保留更丰富的现实条件与对象，却缺少A那种知识生产 / 普及 / 标准化体系。

## 4.5 最强的“不同维度强”证据

公开章节信息甚至给出更深层的制度因果：

在仙门，因为资源长期稀缺，传统的“前中后圆满”四层境界划分造成太大瓶颈，于是历史上把筑基 / 结丹 / 元婴进一步细分为九层，以降低每次突破难度。

这说明差异不是皮肤：
> 环境约束 → 制度 / 功法工程改变 → 形成另一套修炼实践。

同样，后期章节仍出现：
- 从天河界取得高阶功法后，考虑在仙门进行简化、普及；
- 仙门的知识工程反过来处理天河界高门槛传承；
- 仙门功法在本土缺少对应邪魔对象，但在天河界面对真实邪魔时显出被遗忘的用途。

这是长期信息差比“价格差”更耐用的原因：
> 一个世界会保留另一个世界已经失去的“问题”；另一个世界会保留前者没有的“解决问题的方法”。

## 4.6 What repeats

长期重复不是同一种买卖，而是：
1. 在A遇到瓶颈；
2. B中出现不同条件 / 样本 / 方法；
3. 带回A的知识去重新解释；
4. 得到新身份 / 新权限；
5. 这个身份又让主角在B进入更深层机构；
6. 新层级暴露更高级的互补缺口。

也就是说：
> gap 本身会升级。

## 4.7 What accumulates socially

主角在两边都不是匿名采购员：
- 仙门有学校、道院、导师、竞赛、制度身份；
- 天河界有坊市、宗门、弟子 / 长老体系、地方势力、后来的组织建设。

这使“我今天从另一边拿回来什么”逐渐变成：
> “我现在在两边分别是什么人，谁会因此给我什么、要求我什么、怕我什么、依赖我什么？”

这才是长篇复利。

## 4.8 Long-run survival proof

目录到千章后仍可看到：
- 仙门大劫、仙门化神资源分配；
- 随后“回天河界”；
- 天河界继续有五行宗、开荒、东陵仙城等独立议题。

这至少证明作品没有在几十章后把其中一界完全废弃。

需要同时记录一个限制：
起点社区长评提到，后续进入星界 / 新地图后有一部分读者感觉口碑下降。不能由此证明“新地图导致成绩下降”，但它是一个有价值的结构警报：
> 当原本清楚的两界互补被更多世界 / 地图稀释，Reader 可能失去最初可辨识的对照关系。

# 5. Additional current / mature evidence

## 5.1 《集群重炮轰杀修仙者》｜CURRENT / NEAR

截至2026-09：
- 约624万字；
- 2860+章；
- 仍在连载；
- 简介明确“高武 / 武道 / 修仙 / 两界”；
- 前期目录已经出现高中、异界、枪械 / 导弹、商会、文字、图书馆、药业等两套要素。

起点社区2025长评将其概括为：
- 本土修仙文明知识普及但资源稀缺；
- 外域资源为主角提供成长条件；
- 仙门知识反过来让主角利用外域资源；
- 双线持续。

价值：
> 它证明“现代修真知识体系 + 异界资源”并非只有《我有一个修仙世界》能跑长。

但它也提供警告：
同一长评认为“集群重炮”更多成为背景，而主角的个体剑修成长才是长期核心。

因此：
> 高概念的“世界差异”如果不能持续介入人物选择，可能退化成包装 / 背景美术。

这条只能作为评论者观察，不能当成绩因果。

## 5.2 《天命皆烬》｜NEAR / DIFFERENT-DIMENSION

起点荣誉：
- 2024-05-28 万人追捧；
- 2026已完本，约376万字。

主站要素直接写：
- 武道乱世；
- 赛博修仙；
- 两界门。

起点社区长评把两边概括为：
- 一个高武 / 乱世世界；
- 一个仙侠赛博世界；
- 两个世界各有特色；
- 时空交易存在，但不是唯一故事内容。

它对本窗口最重要的不是具体外挂，而是证明：
> 双界不需要“一边现代科学、一边古代落后”；可以是两套都高能、但文明形态、力量体系、社会问题不同的世界。

同时该长评批评：
- 设定可能压过故事；
- 幕间中转时节奏变平。

这正好构成反证：
> “两个世界设定都很酷”不等于 Reader 每次跨界都有当场收益。差异必须进入具体选择和冲突，否则只是说明书。

---

## 5.3 《苟在妖武乱世修仙》｜MATURE CONTROL

平台信息：
- 354万字；
- 1109章完本；
- 标签包含种田 / 无限流 / 凡人流；
- 简介直接承诺“修仙界唯唯诺诺，异世界重拳出击”。

早期第二世界除了资源，还提供另一套气血武道，因此最初并不只是市场套利。

但它后期转向“无限流 / 多世界”非常有研究价值：
> 如果原本的第二世界已经无法继续提供新关系、新制度、新知识矛盾，作者可以通过新增世界刷新差异。

这是一条成熟商业路径，但对于“坚持两界长期互相影响”的目标，它恰好是 CONTROL：
- 长篇可续；
- 但续航方式变成“换世界”，而不是把原有两界差异越挖越深。

本窗口不判断这种写法优劣，只把它视作不同发动机。

## 5.4 《天师，我有一个异世界》｜MATCHED TRADING CONTROL

完本320章。

前期公开目录：
- Ch3 穿越；
- Ch4 异界；
- Ch5 黄金；
- Ch8 再穿；
- Ch10 武功；
- Ch11 法门；
- Ch12 翡翠；
- Ch13 发财；
- Ch14 入门；
- Ch20 神打；
- Ch23 千万；
- Ch24 真传。

这份目录非常适合作为“交易重力”观察：
Reader 在最初二十多章会连续被明确训练成期待：
> 去另一边 → 带回可变现 / 可修炼的东西 → 财富跳升。

这并不是错；它是非常清楚、非常快的即时回报。

问题在于它天然会遇到规模上限：
- 黄金 / 翡翠第一次很爽；
- 一旦“有钱”不再是主角最强压力，同一价差就不能继续提供同强度爽感。

所以作品后续必须转向：
- 武功；
- 法门；
- 师承；
-案件 / 冲突；
-术法关系。

这说明：
> trade 可以是 ignition，但很难单独成为 long-run engine。

# 6. 对用户八个问题的直接回答

## Q1. 每次跨界 / 接触第二世界，Reader 当场得到什么爽点？

强样本共有的不是“开门”，而是至少一种 immediately decision-changing payoff：

1. 重新估值：原本垃圾 / 普通 / 无用的东西，在另一体系里变得关键；
2. 重新判断：原本以为必须做A，因为另一边的新知识改成做B；
3. 突破本地瓶颈：本地知道方法却缺条件，另一界提供条件；或反之；
4. 身份翻转：本地低位，在另一套评价体系中被认成高价值；
5. 风险揭示：另一边的信息让主角提前知道“这东西其实危险 / 这条路其实错”；
6. 社会可见回报：同学 / 导师 / 宗门 / 商人 / 长老开始改变行为。

弱样本常停在：
> “又拿到一件值钱东西”。

强样本则是：
> “因为这次接触，主角下一步不得不 / 可以做出之前做不到的新选择”。

---

## Q2. 信息差到底是什么？不能只写“资源不同”。

可观察到至少八类：

### ① 知识公开度差
公开教材 / 网络 / 标准化教育
vs
师承 / 宗门 / 秘传 / 碎片化经验。

### ② 验证能力差
是否能检测：
- 成分；
- 功效；
- 风险；
- 灵根 / 资质；
- 工艺稳定性；
- 战术效果。

知道“有这个东西”与知道“为什么有效、什么时候无效”是两种信息资产。

### ③ 制度 / 资格差
同一种能力：
- 在一边可能要学历、考试、积分、认证；
- 在另一边可能靠血脉、师承、宗门身份、实战证明。

### ④ 身份解释差
同一个人：
- 一边是普通 / 低位；
- 另一边可能是稀缺天才；
而这种身份又改变别人提供的资源、信任和风险。

### ⑤ 技术路线 / 生产方式差
一边擅长标准化、工业化、普及；
另一边擅长个体极限、特殊材料、古老传承或极端环境。

### ⑥ 历史 / 档案差
一边保存的知识在另一边可能已经断代、被误解、被改写。

### ⑦ 风险 / 法律 / 秩序差
同样一项资源：
- 一边受制度严格配置；
- 另一边可能靠暴力、黑市、宗门、家族获得。

### ⑧ 市场价格差
最直观，但也是最容易被耗尽的一层。

结论：
> “信息差”真正耐写时，是“世界如何认识事物”的差，而不只是“世界拥有多少东西”的差。

---

## Q3. 哪些差异前期好用？哪些可以长期升级？

### 前期强、长期易耗尽
- 黄金 / 古董 / 灵石的价差；
- 普通工业品跨界；
- 一次性现代常识碾压；
- 一张秘方；
- 单一稀缺药材；
- 静态“一个先进一个落后”。

优点：
- 易懂；
- 第一次回报很快；
- 适合 Ch1–10 证明金手指真有用。

缺点：
- 很快可规模化；
- 主角一旦脱贫 / 有渠道，边际爽感下降。

### 可长期升级
- 教育 / 师承体系；
- 资格认证；
- 组织地位；
- 知识生产 / 验证体系；
- 不同环境塑造出的功法 / 技术路线；
- 社会信任与名声；
- 两边各自独占的关系网络；
- 两套历史与叙事；
- 两边各自无法自行解决的高阶瓶颈。

它们可以从：
个人小技巧
→ 专业能力
→ 公共身份
→ 组织权限
→ 制度 / 文明层冲突

自然扩大，而不用不断换新外挂。

---

## Q4. 两个世界如何同时保持剧情生产能力？

证据支持六条“功能条件”：

1. 两边都有独立 pressure，而不是一边只等主角来收货；
2. 两边都有独立 status ladder；
3. 两边都有固定人物 / 组织对主角产生持续要求；
4. 另一界带来的优势不会直接解决本界全部问题；
5. import 之后必有 local consequence——别人会重新评价、争夺、监管、依赖或反制；
6. 两边的问题类型不同，因此切回某一界不是休息，而是进入另一种未完成压力。

《我有一个修仙世界》前100章最清晰：
- 现代线一直有高考 / 集训 / 学校 / 道院入口；
- 天河界一直有坊市 / 宗门 / 妖兽 / 真传 / 交易 / 风险。
两边都能在“不跨界的那一刻”单独发生故事。

《原来我是仙道天骄》前100章则体现为：
- 现代学历 / 法赛 / 药物与贷款环境；
- 古修剑门 / 天灵根 / 真人 / 道子身份。
跨界不是替代某条线，而是在两条线之间不断改变筹码。

## Q5. 为什么有些双界文很快退化成倒爷、倒货、资源搬运？

典型因果链：

### 第一步：把差异压成“可交易商品”
A便宜，B贵。

### 第二步：所有跨界行动都变成同一道题
带什么过去？
带什么回来？

### 第三步：资本积累消除最初压力
第一块黄金能救穷；
第一百块黄金只是在账户上加零。

### 第四步：第二世界没有独立社会资产
没有固定关系、身份、义务、敌人、声望。
于是第二世界只剩“采购地图”。

### 第五步：知识差被一次性攻略
现代人知道的常识 / 古人拥有的秘法被拿完以后，没有新的结构性缺口。

### 第六步：作者只能抬高货值或换地图
更贵药材 → 更稀有法宝 → 更高世界。
核心体验不再是“双界互相重新解释”，而是升级版仓库。

《天师，我有一个异世界》前期目录是极清楚的 matched control：
黄金 → 翡翠 → 发财 → 千万。
它必须很快加入武道、师门、术法与现实冲突，才能避免纯经济曲线耗尽。

## Q6. 热门作品如何让身份、关系、势力、知识差一起积累？

最有效的不是四条独立升级线，而是一条互相增益的循环：

> 信息 / 知识优势
→ 解决一个本地人解决不了的问题
→ 得到可见成绩
→ 身份被重新评价
→ 进入更高层关系 / 组织
→ 获得原本接触不到的资源 / 秘密
→ 暴露更高级的信息差
→ 再次证明能力

因此“跨界所得”真正复利的不是库存，而是 access。

《原来我是仙道天骄》：
- 学历 / 比赛身份与剑门 / 道子身份同时上升；
- 每次身份上升都给下一层资源 / 导师 / 传承入口。

《我有一个修仙世界》：
- 学校 / 道院身份；
- 坊市 / 宗门身份；
- 技能 / 制符 / 传承；
- 组织建设；
长期互相喂养。

可抽象为四种累计资产：

1. Resource capital；
2. Knowledge capital；
3. Identity capital；
4. Relationship / institution capital。

只积累第1种，很容易倒爷化。
四种一起积累，双界会越写越深。

## Q7. Ch1–20 与 Ch20–100 的双界爽点分别发生了什么变化？

### 《原来我是仙道天骄》

#### Ch1–20
核心是：
- 发现异界；
- 发现两套修炼标准不同；
- 小规模方法 / 药物 / 符箓 / 实验；
- 第一轮生存、战斗、修为收益；
- Reader 学会期待“下一次两界互相打脸 / 重新估值”。

爽点句式：
> “原来这东西在另一边不是这么理解的。”

#### Ch20–100
开始明显升级：
- Ch22 倒爷只是一个节点；
- Ch25 学历被认可；
- Ch35–37 专升本 / 最强大专生 / 法赛；
- Ch46–48 天灵根 / 天骄待遇；
- Ch54–56 剑门真传 / 剑道天骄；
- Ch60 / Ch76 方法论与科技差；
- Ch89–90 道子；
- Ch93 主角开始反过来指出本地高手方法错误。

爽点从：
> “我能搬什么？”

升级为：
> “两边分别把我当成谁？我因此能进入哪里？我掌握的两套解释体系能推翻什么旧判断？”

---

### 《我有一个修仙世界》

#### Ch1–20
核心是：
- 水府 / 第二世界是否安全；
- 基础资源 / 功法 / 灵物的第一次获益；
- 现代网络 /知识帮助主角低成本识别价值；
- 第一轮修炼改善。

爽点句式：
> “本地卡死我的东西，在另一边有解。”

#### Ch20–100
明显转为双线社会化：
- 现代：灵根、积分、真传知识、高考、斗法、全校第一、集训；
- 天河：坊市、摆摊、灵石、神木宗、店铺、召集令、妖兽攻岛、筑基丹。

爽点升级为：
> “两个世界都开始认识我、需要我、约束我；我在两边获得的身份和知识互相增加下一次 access。”

# 7. 哪些功能值得后续框架参考？

以下只冻结“功能”，不提供 A3 实现：

## SAFE FUNCTION 1｜多维差异，而非单轴先进 / 落后
参考功能：
> 两个世界应该在不同维度拥有比较优势，并各有无法自行解决的瓶颈。

来源：
- 《我有一个修仙世界》最强；
- 《天命皆烬》提供另一种“两边都高能”的近邻证明。

## SAFE FUNCTION 2｜每次接触都必须改变当前选择
参考功能：
> crossing/contact 本身不算 payoff；“回来以后做法变了”才算。

《原来我是仙道天骄》前期对此尤其强。

## SAFE FUNCTION 3｜差异要升级
参考梯度：
> 物品 / 价格
→ 方法 / 验证
→ 身份 / 资格
→ 关系 / 组织
→ 制度 / 历史层

不是要求以后照此设计，只是 Evidence 显示长期作品通常不会停在第一层。

## SAFE FUNCTION 4｜双边独立剧情生产
参考功能：
> 两边即使暂时没有跨界，也都有本地 pressure / status ladder / recurring cast /未完成问题。

## SAFE FUNCTION 5｜跨界所得必须社会化
参考功能：
> 新知识 / 资源如果没有改变别人对主角的行为，就很容易沦为背包数值。

## SAFE FUNCTION 6｜两边保留互相无法抹平的 exclusive bottleneck
参考功能：
> 主角变强后，早期价格差可以消失，但结构性缺口必须继续存在，否则第二世界会死。

## SAFE FUNCTION 7｜扩大的是同一种快乐，不是不断加世界
成熟 CONTROL 显示：
新增世界确实可以刷新新鲜感，但那是另一种发动机。
如果目标是“两界长期互相影响”，更关键的是让原有差异变深，而不是变多。

# 8. Anti-copy boundaries｜过于接近，后续必须规避

以下不能因为“功能有效”就照搬：

1. 《我有一个修仙世界》的 exact pair：
   - 现代修真文明知识高度普及 / 科学化；
   - 本土资源枯竭；
   - 传统修仙世界资源丰富；
   - 功法 / 知识被宗门垄断。
   这是其高辨识度世界组合，不能整体复制。

2. 《原来我是仙道天骄》的 exact identity inversion：
   - 现代修仙职校 / 人造灵根 / 低就业前景；
   - 到古修界直接对应天灵根 / 宗门天骄。
   不能换名复用。

3. exact crossing device：
   - 龟壳；
   - 破界珠；
   - 可自由肉身双穿的同类表层实现。
   本窗口不提出替代规则。

4. exact dual status ladder：
   - 高考 / 大道院 / 专升本 / 法赛
   对应
   - 坊市 / 剑门 / 真传 / 道子。
   后续不能机械做“双梯子换皮”。

5. exact scene pattern：
   - “现代科技一测，古修全部落伍”；
   - “古代资源拿回来维持现代天才人设，现代教育拿过去维持古代天才人设”。
   可学“身份由不同评价体系产生”，不能复制这套事件语法。

6. 用新增第三 / 第四世界解决双界枯竭。
   这会改变当前概念要验证的核心问题，本阶段不应默认。

# 9. 证据限制

1. 《原来我是仙道天骄》仍是2026新作，本报告对 Ch1–100 的判断强，对真正数百章长跑能力不能提前下结论。
2. 《我有一个修仙世界》是长期控制，但其成功不能单因果归结为“双界结构”；作者执行、更新、人物、种田 / 组织经营等也会影响成绩。
3. 《天命皆烬》《集群重炮轰杀修仙者》的部分机制评价来自起点社区长评，只能视作外部观察，不是平台事实。
4. matched control 的“退化 / 风险”是结构分析，不等于说作品商业失败。
5. 本报告没有合法全文逐字访问全部作品，因此主要依赖：
   - 官方简介；
   - 平台荣誉；
   - 公开目录 / 章节标题；
   - 可公开检索章节片段；
   - 读者 / 推书社区的明确归纳。
   对无法直接核实的细节没有作为硬结论使用。

# 10. Phase 2 synthesis input｜冻结结论

交给 benchmark synthesis editor 的 7 条最高置信输入：

1. **双界长期爽点的最小单位不是“穿一次”，而是“另一界信息使当前决策发生变化”。**
2. **资源差是最直观、也最易衰减的差异；知识生产、验证、资格、身份、制度、关系差更耐久。**
3. **强双界不是“一先进一落后”，而是两个世界各自拥有比较优势与 exclusive bottleneck。**
4. **Ch1–20 可以靠可见资源 / 方法差快速证明机制；Ch20–100 必须转向身份、关系、组织与制度 access 的复利。**
5. **两界都必须拥有独立 pressure / status ladder / recurring consequences，才不会出现“主世界 + 仓库世界”。**
6. **热门长跑样本积累的不只资源资本，还同时积累 knowledge / identity / relationship-institution capital。**
7. **倒爷化的根因不是出现交易，而是所有差异都可被价格表示；一旦主角有钱，核心机制就失去继续改变选择的能力。**
