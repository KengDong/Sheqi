## 2. Correction conclusion

Modern cultivation != martial arts + apps.

The modern layer must normalize genuine cultivation:
- 炼气 / 筑基 / 金丹 / 元婴 are ordinary public concepts;
- 灵气 / 丹田 / 经脉 / 神识 / 护体灵力 are real body rules;
- 丹 / 符 / 器 / 阵 / 御剑 / 洞天 / 雷劫 etc. exist in the civilization even if not all appear in Ch1;
- money buys cultivation access: 聚灵场、丹药、经脉诊断、法器维护、私教、功法授权;
- technology/platform standardizes cultivation; it does not replace cultivation with sports science.
