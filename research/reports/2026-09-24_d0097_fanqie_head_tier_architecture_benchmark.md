# D-0097F｜Fanqie Head-Tier Architecture Benchmark

# Executive Conclusion

Fanqie head-tier high-concept books are strongest when:

> **one-line Premium is instantly legible, early chapters pay quickly, but each payoff changes permanent state and opens a larger mode.**

Fast is not the opposite of deep.

The best pattern is:
> easy premise -> immediate use -> concrete settlement -> new state -> larger social/mystery layer.

# 1. Current Official Evidence

## 《十日终焉》
Official page:
- complete;
- 320.1万字;
- 1496 chapters;
- official cached page ~174.3万人在读;
- 2024 Fanqie annual peak #1.
Synopsis itself exposes recontextualization:
> ordinary day -> death games -> supernatural awakening -> “god-making place” -> annihilation-scale layer.

Function:
> the current game is never framed as the entire book.

## 《时停起手，邪神也得给我跪下！》
Official/current page:
- ~244万字;
- ~93万 current readers;
- 1100+ chapters;
- one-line power: one minute time-stop per day, unused time accumulates.
Synopsis also sells a loud protagonist attitude.

Function:
> the ability contains its own visible future ladder.

## 《全球死考》
Official page:
- ~81万字;
- ~112.9万人在读;
- 300+ chapters.
Synopsis makes reward ladder explicit:
> score -> money -> stronger genetic/power reward -> much larger endpoint.

Function:
> first exam is visibly rung 1, not an isolated case.

# 2. What a Fanqie First 20 Chapters Need

The reader should repeatedly receive:

- premise proof;
- immediate payoff;
- visible next target;
- personality;
- recurring relationship;
- one larger question.

High speed does NOT mean:
> constant new nouns.

It means:
> low translation cost + high state change.

# 3. Avoiding Dungeon/Case Fatigue

Top high-concept long-form does not rely only on:
> new arena -> new puzzle.

It rotates what changes:

1. survival;
2. information;
3. power;
4. team;
5. trust;
6. public status;
7. organization;
8. world-state;
9. interpretation of prior events.

A new dungeon is healthy when it changes the book.
A new dungeon is weak when it is only another container for a clever rule.

# 4. Permanent State After Each Arc

Strong settlement should leave at least two:
- new recurring person;
- changed alliance;
- new ability/resource;
- score/rank;
- public reputation;
- access;
- new obligation;
- altered world rule;
- answer that revalues old clues.

This creates:
> “I cannot reset to before this arc.”

# 5. Macro Mystery

《十日终焉》 demonstrates:
> answers must enlarge/recontextualize the model of the world.

Do not use mystery only as withheld lore.

Good answer:
> changes what earlier scenes mean and what choices are now possible.

Bad answer:
> “there is an even bigger organization.”

# 6. Mode Rotation

High-concept long-form should deliberately shift dominant activity.

Possible cycle:
- trapped survival;
- preparation;
- social adaptation;
- team conflict;
- public/organizational conflict;
- large-scale crisis.

This is not “random variety”.
Each mode must grow from previous permanent state.

# 7. Recurring Cast as Compounding Asset

A fresh clever stranger each arc is expensive and forgettable.

Recurring characters allow:
- old trust to matter;
- debts to return;
- inside jokes;
- betrayal;
- role specialization;
- emotional stakes;
- autonomous offscreen movement.

Fanqie consecutive reading benefits heavily from:
> “I want to see these people again.”

# 8. Book Contract / Visible Runway

An unknown reader should see a ladder early.

Examples of functions:
- score;
- time balance;
- countdown;
- next exam;
- next entry;
- power tier.

Not every book needs numbers.
But it needs a nameable next rung.

First mini-climax should hand off:
> “now I have X, next I must reach/do Y, and I just saw Z larger layer.”

# 9. Reward Rotation

Do NOT pay every arc in the same currency.

Rotate:
- combat/power;
- money/resource;
- information;
- relationship;
- status;
- access;
- world change.

When the reward grammar changes, the same Premium stays fresh.

# 10. Fanqie Head-Tier Architecture Requirements v1

PASS only if:

1. One-line premise is immediately understandable.
2. First useful payoff arrives early.
3. Protagonist attitude/personality is visible.
4. Opening shows a larger shadow than the first incident.
5. At least one tangible ladder exists.
6. Each arc leaves permanent state.
7. Reward currencies rotate.
8. Recurring cast compounds.
9. Macro answers recontextualize prior material.
10. Ch100 is a different story mode from Ch20.
11. Ch300 has changed mode at least twice.
12. Old rules/assets remain useful without re-explaining them.
13. The book can run 30–50 chapters without requiring a brand-new gimmick.
14. Chapter-end pull is usually a changed state/choice, not only a cliffhanger.

# 11. Rule/Infinite Specific Red Flags

- rule encyclopedia;
- puzzle-of-week;
- “smartness” without state gain;
- every arc introduces disposable people;
- protagonist has no visible growth except experience;
- reality/world between dungeons is dead;
- macro mystery only says “there are more layers”;
- too many focal rules at once.

# 12. Anti-Sitcom Handoff

After first payoff:
- give next date/entry/score/target;
- keep one unresolved social consequence;
- show one larger outside event;
- preserve one recurring person.

The reader should feel:
> “this arc closed, but my life is now different.”
