# D-0089｜FNL2《把整座城市当成超能力》Direct Competitor Deep Read

## 0. Executive Verdict

本轮没有重扫“都市高武什么火”，只回答一个问题：

> **FNL2 真放进当前都市高武 / 都市超凡 Reader 池以后，第一轮“城市活起来”的奇观退潮，靠什么继续赢到 Ch3 / Ch7 / Ch20？**

最终保留 4 本直接竞品：

1. **《我在精神病院学斩神》** —— Fanqie，最接近“都市超凡 + 城市守护 + 官方组织 + 长期队伍”的 Reader 合同；
2. **《异兽迷城》** —— Fanqie，最有价值的是“秘密生存 -> 身份暴露 -> 组织入口”的早期接力；
3. **《从前有座镇妖关》** —— Fanqie，最有价值的是“主角行为 / 人族信念 / 机构共同体”比能力解释更早接管；
4. **《灵境行者》** —— Qidian / 阅文体系 secondary benchmark，最有价值的是“人物缺陷与能力成本 -> 高危试炼 -> 现实组织 / 案件”的分层接力。

结论不是“FNL2 应该模仿其中一本”。

结论是：

> **强都市高武并不靠持续发放“新能力名词”维持前 20 章。它们会尽快把 Reader 的问题从“主角还有什么能力？”迁移成“这个人会怎么选？他和谁绑在一起？这个组织要他付什么代价？这座城市 / 这个世界下一步会怎么反咬？”**

FNL2 的真正 P0/P1 readiness 条件因此非常明确：

> **第一奇观必须是门，不是商品目录。**

如果 P0-P3 的主要章级差异仍可概括成：
- 路灯；
- 消防栓；
- 地铁；
- 电网；
- 再来一个设施；

那么即使每个设施都很酷，仍然是 **FACILITY-OF-WEEK FAIL**。

## 3.1 Reader Contract / First Screen

官方简介不是先解释修炼等级。

它先完成三件事：
1. 把 Reader 熟悉的现代城市改造成“神话怪物潜伏”的陌生空间；
2. 把“守望 / 肃清”写成超凡者存在的社会职责；
3. 抛出更大世界问号：人、神、禁区、大夏神明在哪里。

Function：

> **都市不是换皮地图，而是“正常生活下面藏着另一套秩序”。**

这与 FNL2 的同池竞争非常直接：
- FNL2：城市设施突然有超凡功能；
- 《斩神》：正常都市突然暴露神秘秩序。

两者都必须让“熟悉城市发生不正常行为”迅速可视。

## 3.2 Ch1 / Ch3 / Ch7 / Ch20 Retention

官方目录 verified：
- Ch1《黑缎缠目》
- Ch3《敲门》
- Ch7《我想活》
- Ch17《我的家》
- Ch18《欢迎回来》
- Ch20《我好了》
- Ch32《守夜人》
- Ch35《我们是正规军》

### Ch1 function
TOC-level可确认：
> 第一章先给一个极强的人物视觉标记，而不是“守夜人组织说明书”。

BODY-LEVEL EVIDENCE GAP：
> 本环境无法可靠读取番茄 Ch1 正文，因此不声称精确拆出每个 beat。

### Ch3 function
《敲门》意味着早期就把异常压力推入日常边界。

可学 function：
> **超凡不是介绍出来，而是来敲主角生活的门。**

### Ch7 function
标题直接落在：
> **“我想活”。**

无论具体桥段如何，章级 foregrounding 已从神秘设定落到主角最基础的人类欲望。

这对 FNL2 极关键：
> Ch7 不能只剩“我还能调用什么”；必须已经有一个不用任何设施名也成立的“我为什么非做这件事不可”。

### Ch20 function
Ch17–20 的目录连续出现：
- 我的家；
- 欢迎回来；
- 星夜舞者；
- 我好了。

STRUCTURAL INFERENCE：
> 第一阶段不是单纯用“更大招”结算，而是在生存 / 超凡推进中插入“家、回来、恢复”这类生活和情绪结算。

尤其值得注意：
> “守夜人”这个明确组织名在官方章节标题到 Ch32 才被前景化。

这不能证明组织此前完全没出现；
但足以证明前 20 章的章级卖点没有被“组织权限 / 编制 / 规则”统治。

## 3.3 Protagonist Magnetism

VERIFIED at structural level:
- Ch1 是人物视觉；
- Ch7 是第一人称生存欲望；
- Ch17 是“我的家”。

因此其早期至少持续把：
> **人本人 / 生存 / 家**

放在大世界和组织之前。

BODY-LEVEL EVIDENCE GAP：
> 不在本报告虚构更细性格结论。

### FNL2 function clone
FNL2 的主角应让 Reader 在设施全部暂时失效时，仍知道：
- 他首先会看谁；
- 他会先救什么；
- 他会因为什么犯错；
- 他为什么会在战斗结束后仍做一件“小得不值一提”的城市工作。

这与 HG4 已冻结的“打完大战还去确认普通生活恢复”完全相容。

## 3.4 Team / Organization

目录从 Ch32《守夜人》、Ch35《我们是正规军》后，才明显把组织身份前景化。

Reader-level function：

> **先让 Reader 认识一个人，再让这个人属于一个组织；组织是扩张他的责任和关系，不是给他发 UI 权限。**

FNL2 不该让“更高权限”本身成为情节高潮。

权限真正有戏的条件是：
> 拿到权限 = 多了必须保护的人 / 多了会质疑他的同僚 / 多了不能随便按下去的按钮。

## 3.5 Reward Cadence

从官方章节标题看，前 20 章并非连续“能力 A -> 能力 B -> 能力 C”：
- 生存；
- 眼 / 刀 / 神秘元素；
- 家；
- 回来；
- 恢复；

多种 reward grammar 交替。

最重要的功能不是具体能力，而是：

> **Power fruit 与 Life fruit 交错。**

FNL2 的早期果实也应至少交替：
- 城市能力果实；
- 人际 / 身份果实；
- 普通生活恢复果实；
- 责任 / 代价果实。

## 3.6 Emotional Rhythm

官方早期目录能确认的情绪标题跨度：
- 我想活；
- 我的家；
- 欢迎回来；
- 对不起；
- 大雨；
- 笨蛋。

说明章级包装并不允许“持续紧张 + 持续讲能力”单色情绪占满。

### FNL2 implication
最强的城市级奇观之后，
应该允许：
> 一个红绿灯恢复、一位居民回家、一名维修工吐槽、一次被追责、一次队友争执

来接住情绪，而不是下一章立刻更大设施。

## 3.7 Scene Expansion

官方第一卷目录很快从早期家庭 / 生存，扩到：
- 守夜人；
- 补习；
- 校园；
- 集训；
- 各类案件 / 任务。

Function：
> **场景扩张靠社会接口，不靠“换一个地图皮肤”。**

## 3.8 Opponent Learning

BODY-LEVEL EVIDENCE GAP for Ch1–20 adaptive opponent behavior.

本书不作为 FNL2“对手如何学习城市系统”的主要证据。

## 3.9 Permanence around Ch20

可验证的章级永久性方向：
- 主角已经不再只是 First Screen 的神秘视觉；
- 生存欲望、家与恢复被反复前景化；
- 组织线在其后接管扩大世界。

不安全声称：
> 不根据不可读正文虚构 Ch20 的精确战力 / 关系 ledger。

## 3.10 Learn / Do Not Copy

### Learn the function
- 第一大奇观后迅速落回“我要活 / 我的家”；
- 人物欲望先于组织说明；
- 组织出现后变成归属与责任；
- 能力果实与生活果实交错；
- 城市超凡与正常生活同时存在。

### Do not copy
- 神话体系；
- 守夜人设定；
- 黑缎 / 特定武器；
- 精神病院结构；
- 任何具体人物、事件顺序、台词、标志桥段。

## 4.1 Reader Contract / First Screen

官方简介先交付：
> **最熟的人可能不是人。**

系统〖幸运〗虽然被写进简介，但它不是唯一合同。

真正强的 Reader 问题是：
- 谁可信？
- 温馨生活是真是假？
- 主角暴露后能不能活？
- “活得越久越强”到底迫使他如何生存？

这比“还有什么新天赋”更耐连载。

### FNL2 lesson
FNL2 第一屏“还能调用什么？”必须尽快长出第二问：

> **“当整座城市是他的身体，他最不能失去什么？”**

否则 Reader 只会追设施目录。

### Ch1
不是“系统说明第一章”。

### Ch3
系统在 Ch3 才被标题前景化，
而 Ch4 立刻进入囚徒困境。

Function：
> **解释完一条机制，马上让机制进入人际风险 / 生存决策。**

### Ch7
Ch5–7 是：
> 身份暴露 -> 灭口 -> 灭口2。

Function：
> 早期能力不是消费品，而是暴露成本。

FNL2 对应：
> 新设施调用不应该只有“更强”；它最好同时暴露一个城市弱点、组织争议、公众后果或对手情报。

随后仍有挑战、苦战、生日聚会；
到 Ch32 才明确《十二生肖》；
到 Ch68 才《正式入职》。

Function：

> **组织不是“第一页发证件”，而是一个需要穿过风险、测试、关系与生活后才真正进入的长期空间。**

这直接反对 FNL2 的“权限升级 UI 化”。

因此即便拿掉“新天赋”：
> **主角每天如何和最熟的人共处，仍天然有压力。**

BODY-LEVEL EVIDENCE GAP：
> 不虚构高阳前 20 章具体语气、幽默和关系 beat。

### FNL2 function clone
给主角一个“每个普通城市日常都能触发”的人格 / 责任矛盾。

FNL2 已有的最佳方向不是：
> 他懂基础设施。

而是：
> **他看到“大系统”时会先看谁在修、谁会被断掉、谁声音最小。**

这是日常也能生戏的磁力。

- Ch32 十二生肖；
- Ch33–34 继续测试；
- Ch66 欢迎会；

- 测试；
- 新关系；
- 新生活；
- 新资源；
- 新暴露面。

> 组织同意 -> 主角多一块地图。

至少应同时改变：
- 谁能命令他；
- 谁必须和他一起值班；
- 谁承担他的误判；
- 谁开始防他；
- 哪些普通市民被他的决定真实影响。

- 后续生日聚会。

Function：

## 4.7 Scene Ecology

早期从：
> 家庭 / 身份秘密 -> 追踪与混战 -> 面试 / 测试 -> 生日聚会 -> 村落 / 凶宅类空间 -> 组织正式入职。

即使不读取 body，
目录已证明前几十章不会困在一个“能力实验场”。

### FNL2 implication
场景扩张的单位应是：
> **新的生活接口 / 社会接口**

而不是：
> 新设施类别。

医院有价值，不因为它有“医疗设施”；
而因为：
- 病人；
- 医护；
- 电力；
- 调度；
- 家属；
- 谁先救；
同时纠缠。

## 4.8 Opponent Learning

BODY-LEVEL EVIDENCE GAP：
> 仅凭前 20 章目录不足以证明某个稳定对手如何学习 / 反制。

本书主要用于：
> **secrecy-pressure + organization-entry + mixed-fruit cadence** benchmark。

## 4.9 Permanence around Ch20

Verified:
- 超凡身份 / 系统已进入叙事；
- 身份暴露压力持续存在；
- Ch20 打开组织入口。

谨慎：
> 正式“入职”由官方目录到 Ch68 才出现，因此不能把 Ch20 “面试”伪写成已永久加入组织。

这反而是一个重要功能：
> **Ch20 不一定要把所有成长兑现完；但必须打开一个比 First Screen 更大的长期社会结构。**

## 4.10 Learn / Do Not Copy

### Learn
- 能力出现后立刻付身份 / 生存成本；
- 信息、关系、战斗、组织果实混排；
- 组织入口有摩擦和过程；
- 普通生活与危险反复互相污染；
- Ch20 打开第二发动机而不是关闭所有悬念。

### Do not copy
- “身边人全是兽”的世界规则；
- 幸运系统；
- 十二生肖组织；
- 纸条连续桥段；
- 具体测试、角色、事件排列。

Official current evidence:

Accessed:

## 5.1 Reader Contract / First Screen

它最重要的反设施说明书证据就在官方简介：

First Screen 不问：
> 主角觉醒什么？

而问：
> **什么样的人愿意守住身后的万家灯火？**

于是能力天然被降级为：
> 完成这个人物 / 群体使命的手段。

# 8. Facility-of-Week Failure Test

Prototype 阶段可直接用以下硬检查。

## RED FLAG 1
连续两个主要 pull 都能写成：
> “这次看看 X 设施怎么超凡化。”

## RED FLAG 2
删掉设施名后，
两章的因果结构完全一样：
> 出事 -> 解锁 -> 说明 -> 使用 -> 赢。

## RED FLAG 3
旧设施只在首次展示时有用，
之后必须靠新设施维持新鲜感。

## RED FLAG 4
主角的最好场景全发生在“操作系统”时，
离开设施就没有人格戏。

## RED FLAG 5
队友的价值 = 帮主角操作不同设施，
而不是他们自己想要不同东西。

## RED FLAG 6
组织的价值 = 发权限 / 任务 / 奖励，
换一个系统 UI 也成立。

## RED FLAG 7
对手升级 = 换一只更强怪物，
而不是学会攻击城市依赖、公众信任、维修链、离线冗余、主角的责任感。

## RED FLAG 8
换场景只等于：
> 医院 -> 地铁 -> 水厂 -> 学校

但每个地方没有带入真正不同的人群、日常、伦理、资源争用与关系。

最好至少重新激活一个旧东西：
- 老队友；
- 老节点；
- 旧争议；
- 旧维修债；
- 旧公众后果；
- 旧对手情报。

否则是 collection。

## Function B｜Permission = Relationship Change

权限升级必须回答：
> **谁因此更相信他、谁更怕他、谁能追责他、谁被迫依赖他？**

否则权限只是数值。

## Function C｜City Knowledge Comes From People

不要让主角像后台管理员凭空知道城市。

重要知识尽量由：
- 一线维修；
- 调度；
- 医院；
- 司机 / 站务；
- 消防；
- 社区；
- 普通市民；
带入。

于是：
> 人不是设施附件，人本身就是城市能力的一部分。

## Function D｜Opponent Attacks the Grammar

真正高级的反制不是：
> “怪物抗消防水”。

而是：
- 让主角不敢调用；
- 逼他在两个区域中选择；
- 污染告警；
- 切断维修链；
- 制造公众不信任；
- 诱导过度集中；
- 用主角的责任感逼他犯错。

这样 opponent 在学习主角，而不是作者在换 Boss。

## Function E｜Reward Type Rotation

前 20 章至少要轮换：
- spectacle；
- competence；
- relationship；
- status；
- moral choice；
- ordinary-life restoration；
- mystery / opponent reveal；
- responsibility / cost。

不要让 spectacle + new facility 垄断 dopamine。

## Function F｜Scene = Society Interface

换一个城市空间必须同时换：
- 谁在这里生活；
- 谁负责；
- 什么不能停；
- 谁承担损失；
- 主角和谁发生新关系。

这样医院 / 地铁 / 老社区才不是皮肤包。

# 10. Prototype Readiness Gate for editor_in_chief

## PASS conditions

FNL2 可以进入 P0 / P1 isolated prose，
前提是原型计划能证明：

1. **First Screen**  
   路灯奇观无需技术说明就成立，且主角本人同时被看见。

2. **Ch1 function**  
   第一次设施调用不仅展示能力，还留下一个人 / 城市后果。

3. **Ch3 function**  
   阅读欲已至少有一个非“下一设施”的问题。

4. **Ch7 function**  
   一个关系 / 责任 / 对手反制已变成持续 pull；旧资产开始复用。

5. **Ch20 function**  
   story ledger 里人、组织、城市残留、对手信息的永久状态，至少和设施能力同等重要。

6. **Organization**  
   核心成员有独立欲望；把组织替换成权限 UI 会让故事严重损失。

7. **Opponent**  
   已经能学习一次主角解法并改变策略。

8. **Scene Ecology**  
   城市空间扩张同时扩大普通生活 / 社会认知，而不是设施百科。

## HOLD / REDESIGN EXECUTION conditions

不改 Concept，
但如果 Prototype 设计出现以下任一组合，应暂停写正文：

- Ch1 / Ch3 / Ch7 的主 pull 三次都来自新设施；
- 前 20 章非主角没有形成不可逆关系；
- 组织只负责授权；
- 对手只负责升等级；
- 旧设施不回流；
- 城市场景没有普通人的功能 / 代价；
- 解释设施的字数比人物做决定更重要。

# 11. Final Direct-Competitor Finding

FNL2 现在的最大优势仍成立：

> **“整座城市变成超能力”比普通个人异能更可视、更有公共情绪，也更天然拥有广阔场景。**

但直接竞品证明了一件更重要的事：

> **Reader 可能因为 Premium 点进来，却不会因为“第 17 种 Premium 用法”长期爱上一部长篇。**

真正强的迁移路径是：

> **奇观点击  
> -> 主角行为  
> -> 具体关系  
> -> 组织归属 / 冲突  
> -> 城市后果  
> -> 会学习的对手  
> -> 更大的共同体问题。**

FNL2 如果做到这条迁移，
“设施”会从每周要换新的烟花，
变成：

> **人物关系、公共责任、组织冲突和城市历史反复复利的旧资产。**

这才是避免 facility-of-week 的核心。

Current structural verdict:

> **FNL2 remains Prototype-viable. No structural inferiority established.**
>
> **But P0/P1 must explicitly prove Desire Transfer from “还能调用什么？” to “这个人和这座城市接下来会付什么、守什么、失去什么？”**

交回：
> **editor_in_chief / Prototype Readiness Gate**

No Primary.
No Concept mutation.
No prose.
