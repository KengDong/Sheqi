# REBOOT-V3｜Live Shelf Controls

Purpose:
Put the six unknown-author project packages beside real strong/recent platform books so “best of six weak options” cannot masquerade as genuine acquisition strength.

Rules:
- real public titles only;
- strong/current/recent books, not strawmen;
- author names are omitted from clean-room shelves;
- control hook/blurb is factual paraphrase, not copied official blurb;
- no control is intentionally weakened.

---

# Selection note

The control set is intentionally hard:
- Qidian includes 100k-average-subscription titles, Twelve Kings, and active/recent high-recognition works.
- Fanqie includes a current high-reader title, multi-million-character long runners, and direct topical competitors for livestream/apocalypse/supernatural hooks.

No author names, awards, subscription counts, reader counts or bestseller labels appear inside the anonymous shelf itself.
The reader must react to package content, not prestige badges.
