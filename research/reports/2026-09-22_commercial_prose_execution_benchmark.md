# Commercial Prose Execution Benchmark｜成熟商业网文正文执行标尺 V1.1

> 研究对象不是“它们为什么Hook强”，而是：
>
> **成熟商业小说的实际公开正文，怎样让第一次读者先站稳、再接陌生信息；怎样让专业内容清楚而不说明书；怎样让人物、动作、段落像小说，而不是设计文档转写。**
>
> 本报告只借功能实现，不模仿任何作者的标志句法、比喻、口癖或具体桥段。

# 1. 九部正文Reference Cards前置拆解

# 1.1 《没钱修什么仙？》｜熟悉社会框架先承载高概念

### P1 Scene Anchor
公开第1章先给手机里的母亲消息、候场、叫号、进入面试教室、三位面试官。读者几乎无需理解任何修仙设定，就知道：
> **张羽在参加一场会改变升学前途的面试。**

### P2 Object First Mention
开头不依赖陌生幻想器物。它证明：
> **高概念作品完全可以让第一屏主要由现实熟悉物组成。**

### P3 Fantasy Term Onboarding
异常规则不是先用体系名出现，而是从一个任何人都懂的问题进入：
> 学生每天睡多久。

读者先理解“睡眠竞争”，再理解这个世界的修仙教育已经卷到怎样的程度。

### P4 Dialogue Naturalness
面试官问、学生答，天然存在真实信息权力差，因此较完整的信息对白合理。不是两个圈内人互相复述双方都知道的制度。

### P5 Action Continuity
动作非常简单：候场 -> 叫号 -> 进教室 -> 坐下面试。因为空间负担低，读者有认知容量接高概念。

### P6 Narrative Texture
母亲兼职、手术费、练过的礼貌笑容、被打断的场面话都不是“修仙系统说明”，却让经济压力和人物状态先活起来。

### P7 Paragraph Rhythm
短消息、短动作、对白与相对完整的解释段交替；核心规则出现时并不回避稍长说明。

### P8 Exposition Boundary
当前冲突真正依赖的规则直接讲清；没有顺手讲完整教育制度、修炼史或城市运行。

**功能结论：**
> 核心新奇若直接决定当前选择，清楚比“藏”更重要。

# 1.2 《夜无疆》｜先身体和空间，再给幻想物件正式名

### P1 Scene Anchor
先给永夜、暴雪、村庄规模、秦铭的饥饿、寒冷和火炕。读者先知道：
> 人在哪、冷到什么程度、缺什么。

### P2 Object First Mention
“太阳石”是本轮最清楚的正例之一：
- 先看见一个发光的携带物；
- 再看见石块被倒入容器并提供照明；
- 再落正式名；
- 之后才逐步补来源和使用规则。

即：
> **可见物 -> 当前功能 -> 名字 -> 额外规则。**

### P3 Fantasy Term Onboarding
“浅夜”等词都挂在天气、光照、出门时机这些生活后果上，不要求读者先学定义。

### P4 Dialogue Naturalness
邻里话题主要是病、食物、天气、人情。世界信息从生活需求里漏出来，不让熟人互背世界观。

### P5 Action Continuity
屋内、院子、雪地、器皿按视线/身体移动进入。一次只亮一个新焦点。

### P6 Narrative Texture
馍、白气、旧被子、饥饿反应、邻居争执等细节很多不承担机关因果，却稳定提供生活质感。

### P7 Paragraph Rhythm
环境可较长，身体感受可短，对话再切入；高压/恶劣环境不等于全用单行短句。

### P8 Exposition Boundary
太阳石当前用于照明，所以功能可直接说；但作者不在第一次出现时解释整个永夜能源体系。

**功能结论：**
> 陌生物的“名字”可以晚半拍，读者先要知道它现在在干什么。

# 1.3 《捞尸人》｜Human Texture可以先于“设定任务”

### P1 Scene Anchor
第一屏直接是饭桌/开饭动作：围裙、碗、勺、粥缸、水烟袋、孩子涌进来。读者在几句内就能复述：
> 一个大家庭正在开饭，家里很挤、很能吃。

### P2 Object First Mention
大多是现实熟悉物。它提醒《舍弃》：
> **普通世界不需要为了仙侠感不断造专名。**

### P3 Fantasy Term Onboarding
公开开头先不急着丢幻想词，先建立家庭关系、粮食压力和人物口气。

### P4 Dialogue Naturalness
有打断、骂人、顺嘴接话、不完整句。人物不是为了把信息说全，而是在一起生活。

### P5 Action Continuity
碗、粥、桌边、门口反复作为锚点，新人物从门口/加筷子等动作进入，而不是另开人物介绍模块。

### P6 Narrative Texture
孩子抢食、装傻、长辈舍不得吃席、米缸快空等细节并非每个都对应后续机关，但一起构成阶层、关系与生命力。

### P7 Paragraph Rhythm
短对白和连续叙述都可以存在；话题会自然拐弯，不是每个信息点后都做作者总结。

### P8 Exposition Boundary
家庭背景可以直接说不少，因为它立刻解释“为什么现在这么多人吃、为什么钱粮紧”。

**功能结论：**
> 直接说明并不天然像AI；“没有人物当前理由的说明”才像说明书。

# 1.4 《仙工开物》｜专业机制可以连续解释，但必须有明确观察对象

### P1 Scene Anchor
第1章先给宁家议事堂、族长/家老、玉简和正在复盘的一次家族大考。读者知道：
> **一群掌权者正在评估后辈表现。**

### P2 Object First Mention
玉简先作为“拿在手里、里面记录考核影像、能被查看”的物件出现；功能很快可懂。

悬丝木偶也不是只报名字，而是紧接：
- 法力如何通过悬丝；
- 木偶如何因此行动；
- 考生能做到哪些动作。

### P3 Fantasy Term Onboarding
“机关术”“悬丝木偶”属于专业幻想词，但作者允许直接讲当前考核机制，因为人物正是在复盘这一项。

### P4 Dialogue Naturalness
家老的对白围绕现实责任：为什么后辈表现差、家族为什么需要机关师。制度背景不是脱离利益的百科。

### P5 Action Continuity
本段并非复杂动作场，而是“看玉简里的考核动作”；每个动作都围绕同一个木偶对象。

### P6 Narrative Texture
族长摩挲玉简、闭眼回放、家老感到压力等细节，让“设定说明”仍然有权力关系和人物状态。

### P7 Paragraph Rhythm
允许一段连续解释机关考核机制，然后马上回到族长评价和家老回应；说明不会无限悬空。

### P8 Exposition Boundary
作者讲清“当前为什么机关术重要”，但没有在同一章一次讲完机关术所有分支、材料和历史。

**功能结论：**
> 专业解释可以连续出现，前提是读者始终知道“谁正在用这信息判断什么”。

# 1.5 《诡秘之主》｜复杂空间不是少写，而是按相机顺序写

### P1 Scene Anchor
先头痛、无法控制身体、逐渐醒来。读者先进入一个身体问题。

### P2 Object First Mention
睁眼后从书桌、笔记、文字、墨水、枪等熟悉物逐项展开。即使房间信息量高，也不是同一拍同时亮五个陌生组件。

### P3 Fantasy Term Onboarding
陌生文字/世界信息进入时，先通过“看见 -> 记忆逐渐接上 -> 能理解”的体验链，而不是作者直接扔定义。

### P4 Dialogue Naturalness
开头不强行找解释者。角色自己能观察的部分让内心与动作承担。

### P5 Action Continuity
书桌是第一锚；视线扩到房间、窗外、镜子，镜头方向可跟踪。

### P6 Narrative Texture
头痛、上班念头、椅子磕碰等现实反应并不只为神秘谜题服务，使角色不像“设定摄像头”。

### P7 Paragraph Rhythm
短促内心可以连续出现；进入空间扫描时又允许较长段。段落长度随认知任务换挡。

### P8 Exposition Boundary
人物当前正在接收的身份/记忆可直接说明；还没必要理解的超凡体系不提前讲。

**功能结论：**
> “空间清楚”不等于“描写少”，而是新焦点进入有顺序。

---

# 1.6 《道诡异仙》｜陌生名字可以先出现，只要动作类别足够熟

### P1 Scene Anchor
第一句就是“捣药”。读者先掌握一个非常熟悉的动作，再认识溶洞/料房。

### P2 Object First Mention
“流光青石”虽然直接报正式名，但它此刻只是药罐里被碾的材料。读者不需要知道矿物学定义，也能跟上场景。

### P3 Fantasy Term Onboarding
作者允许读者暂时只知道“这是炼丹材料”，不急着解释来源、等级、性质。

### P4 Dialogue Naturalness
早段冲突对白短、粗、直接。人物不是用专业术语给读者讲世界。

### P5 Action Continuity
工作位 -> 旁侧骚扰 -> 起身 -> 抄起药罐 -> 砸过去。空间节点少，动作链清晰。

### P6 Narrative Texture
潮湿、粗布、身体缺陷、无聊捣药、恶臭等感官/生活质地很多并不承担后续机械逻辑。

### P7 Paragraph Rhythm
前面可有环境与工作说明，冲突一来迅速短化；之后又进入新的感官/认知变化。不是全章一个节拍。

### P8 Exposition Boundary
“流光青石”完整定义不重要，所以不讲；真假世界真正改变角色认知时才升级解释。

**功能结论：**
> **不知道精确定义 ≠ 看不懂。**
>
> A-T1的问题不是每个术语都没定义，而是没定义的词同时承担空间与因果。

# 1.7 《谁让他修仙的！》｜有真实知识差，解释型对白可以成立

### P1 Scene Anchor
雨、泥路、鞋、马车先站住，读者知道陆阳在赶路而且被雨折腾。

### P2 Object First Mention
先看见老马无人驾车、额头有鳞片，再判断它是异种妖兽；视觉事实先于体系分类。

### P3 Fantasy Term Onboarding
正式修仙信息后续由“第一次出门、第一次去宗门”的人物位置承接。陆阳真的不知道，孟景舟真的有理由知道。

### P4 Dialogue Naturalness
较完整解释能够成立，是因为角色之间有真实知识差，而且当前目标就是去参加考核。

### P5 Action Continuity
路上 -> 马车靠近 -> 上车。空间简单，让读者有余力听规则。

### P6 Narrative Texture
泥水、拔脚、怕弄脏车、买不起好马等反应把世界过滤成陆阳自己的生活尺度。

### P7 Paragraph Rhythm
动作段与说明型对话换挡明显，解释之后会回到继续赶路/接人，不形成无止境百科。

### P8 Exposition Boundary
对当前宗门选择有用的规则能讲；与眼前无关的更深修炼知识不一次塞完。

**功能结论：**
> 解释型对白不是禁区；“角色双方都知道却为了读者互背规则”才是伪对白。

# 1.8 《大医凌然》｜专业人物说短话，叙述承担行业翻译

### P1 Scene Anchor
第1章先给系统提示、凌然记笔记、测试、确认自己是否精神异常。即使有系统，高概念也是挂在“医学生在做谨慎验证”这个人物动作上。

### P2 Object First Mention
新界面/图标用熟悉视觉类比帮助定位；真正医学工具在角色需要使用时进入，不先堆医院器械表。

### P3 Fantasy / Professional Term Onboarding
系统功能不需要完整产品说明，先知道：
> 它会发任务，凌然不信，他要验证。

### P4 Dialogue Naturalness
公开职业场景中，关键话可以很短，例如“我能不能去某科”。为什么这个选择对实习生重要，由叙述补行业结构。

### P5 Action Continuity
职业信息围绕一个明确目标串联：怎样真正获得动手机会/完成任务。读者不需要先懂医院组织图。

### P6 Narrative Texture
凌然会记录、测试、担心毕业证、按自己的逻辑做选择。专业世界始终经过人格过滤。

### P7 Paragraph Rhythm
作者可以连续解释医院训练结构，但前后都有角色正在做决定，不像单独贴一张百科卡。

### P8 Exposition Boundary
当行业知识是理解“为什么去这里、不去那里”所必需时，直接叙述解释反而最自然。

**功能结论：**
> 《舍弃》的值守不该承担全部机制翻译；专业人说现场话，叙述替第一次读者补真正必要的知识。

# 1.9 《全职高手》｜专业世界先靠可见实物和人物权力关系站住

### P1 Scene Anchor
键盘、鼠标、屏幕、烟头先出现。读者先知道：
> 一个非常熟练的玩家正在操作。

### P2 Object First Mention
账号卡是能从登录器拔出来、拿在手里的具体东西；它先成为“交不交、拿不拿”的权力对象，行业历史意义后补。

### P3 Professional Term Onboarding
“荣耀职业联盟”等词进入时，俱乐部、会议室、战绩屏已经可见，词不是悬空数据库字段。

### P4 Dialogue Naturalness
高权重关系可以只靠极短对白推进；人物并不为了证明关系而说完整背景。

### P5 Action Continuity
房间 -> 走廊 -> 会议室；每次转场给一个明显空间锚。

### P6 Narrative Texture
长烟灰不掉这类细节不解释制度，却同时表现熟练、气质和生活感。

### P7 Paragraph Rhythm
操作段、短对白、走路转场、会议室群像节奏明显不同。

### P8 Exposition Boundary
职业背景只讲到足以理解当前被替换/离队的利益冲突，不先讲完整联赛史。

**功能结论：**
> 专业感可以来自人物“做得像熟手”，不需要人物不断说专业词证明专业。

# 2. 跨样本：Scene Construction正常区间

## 2.1 Scene Anchor的三种高频入口

### 身体
- 痛、冷、饿、呼吸、失控。

### 熟悉动作
- 捣药、操作电脑、记笔记、吃饭。

### 熟悉社会情境
- 面试、家庭开饭、会议复盘。

共同点：
> **读者先有一个可以复述的现实动作，再被要求接陌生世界。**

A-T1当前第一拍“长架还在往下吃”没有做到：
- “长架”未建立；
- “往下吃”又是行业化隐喻。

---

## 2.2 Object First Mention的四种可靠路径

1. **先可见功能，后名字**  
   发光物照亮 -> 再记“太阳石”。

2. **熟悉动作包住陌生名字**  
   陌生材料只是“被捣碎的东西”。

3. **先成为利益对象，后补行业意义**  
   账号卡先是被拿走/交出的实物。

4. **当前专业任务允许直接解释机制**  
   悬丝木偶正被用来复盘考核，所以其操控原理可以直接讲。

A-T1不该统一套一种“先功能后名字”模板，而应先问：
> **这个东西第一次出现，读者当前到底需要知道哪一层？**

---

# 3. 跨样本：Prose Execution正常区间

## 3.1 句子与段落不是“越短越商业”

公开样本里可以同时看到：
- 短对白；
- 连续短内心；
- 较长空间描写；
- 一段直接专业解释；
- 突然的一行动作。

成熟感来自：
> **形式随当前认知任务变化。**

AI感常来自：
> 每段长度不同，但“功能模板”相同。

例如A-T1多次出现：
> 动作 -> 对白 -> 作者解释 -> 防误读 -> 下一动作。

---

## 3.2 主语省略与恢复

成熟正文常在同一主体连续动作中省略主语，
但在以下情况会恢复：
- 焦点切人；
- 转场；
- 新动作可能有歧义；
- 连续对白后重新锁视角。

A-T1下一版不应把“主语省略”当风格KPI。
真正目标：
> 读者任何时候都知道是谁在做关键动作。

---

## 3.3 对白 / 动作 / 内心 / 旁白的职责分工

### 对白
做当前人际动作：
- 问；
- 拒；
- 下指令；
- 试探；
- 确认。

### 动作
证明：
- 空间；
- 能力；
- 后果；
- 人物熟练度。

### 内心/近距叙述
承担：
- 当前判断；
- 人物个人尺度；
- 第一次读者真正需要、但现场人不会互相解释的核心信息。

### 作者说明
可以出现，
但必须和当前决定绑定。

A-T1当前最大职责错配：
> “舍味不产力量”这种第一次读者必须懂、但值守与陆野都早就懂的事实，被塞进双方对白。

# 4. 跨样本：Human Texture正常区间

成熟商业正文不要求“每个细节都有用”。

有效的非纯功能细节通常至少完成一项：
- 身体习惯；
- 人际熟悉度；
- 生活阶层；
- 情绪气压；
- 人物偏好。

例如：
- 饭桌上的抢食；
- 烟灰；
- 饿到想到馍；
- 泥水弄脏鞋；
- 医学生先记笔记验证系统。

它们不是“无意义废笔”，
但也不是Scene Spine里的机关节点。

A-T1当前相反：
> 大多数细节都能追溯到事故设计、Canon防误读或动机补丁。

这就是设计稿感的重要来源。

---

# 5. 跨样本：Exposition Boundary第一原则

## 5.1 应直接讲清的
当前选择若不理解就无法判断角色是否合理的核心。

对A-T1包括：
- 陆野本来就到筑基最后一步；
- 舍的是味觉；
- 永久；
- 为什么这是他早就准备的应急代价；
- 为什么这次到阈值了；
- 舍味本身不会直接增加力量；
- 为什么它仍可能帮助他把最后一步续过去。

## 5.2 只给当前功能的
- 长货架内部机械分类；
- 导向结构正式名；
- 制动链各零件；
- 舍台外圈内部技术；
- 借载完整制度。

## 5.3 当前可完全不讲的
- 余世；
- 弃相；
- 漏舍终极解释；
- 借载基础设施经济；
- 舍台掌握多少真相。

> **成熟感不是“少解释”，而是信息优先级正确。**

# 6. 对A-T1最重要的外部校准结论

把A-T1放在九部实际公开正文旁边，差距不在“词藻”。

而在信息组织：

## 成熟正文倾向
> 人物身体 / 当前欲望 / 视线 / 行动  
> 决定读者按什么顺序知道东西。

## A-T1当前倾向
> 事故设计依赖 / Canon防误读 / 后续伏笔  
> 决定句子按什么顺序出现。

因此：
> **A-T1不能只做词汇自然化。必须重排信息归属、相机顺序、解释渠道与段落节奏。**

# 7. Commercial Comparator最小使用方式

下一版重要正文不需要每次重新研究9本书。

Writer先选2—4张功能Reference Card。

Comparator只拿当前500—1200字与功能相邻公开样本比较：

1. 谁更早知道人在哪？
2. 谁的新名词更少依赖解释？
3. 谁的对白更像人在当前场景说话？
4. 谁的动作后更少重复总结？
5. 谁的空间锚更稳定？
6. 谁有更自然的非纯功能纹理？
7. 谁更看不出Scene Spine骨架？

只要《舍弃》明显更像：
> “作者在确保设计正确传达”

而不是：
> “人物正在经历一件事”，

就继续返工，不送作者。

# 8. 结论

本轮真正建立的不是某种“热门文风”。

而是一个外部正常分布：

> **先让人和场景成立；  
> 新东西第一次只承担它此刻必须承担的信息；  
> 核心规则该讲就讲；  
> 专业人说现场话；  
> 叙述替外行补必要知识；  
> 空间按相机顺序展开；  
> 允许人物有不为机关服务的生活纹理；  
> 段落随认知任务换挡。**

这套标尺是后续Human Prose Gate与A-T1补丁的外部依据。
