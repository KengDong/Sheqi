# 中段发动机与跨题材结构研究｜50—300章阶段衔接

> 本报告只研究**第一阶段成功以后，故事怎样继续繁殖状态**。
>
> 不修改 Canon，不修改 Outline，不覆盖当前第一卷 V2，不写第二卷正式大纲，不写正文。
>
> 研究重点不是“再找二十个任务”，而是：
>
> **上一阶段的成功，怎样成为下一阶段问题的原因。**

## 核心结论先行

对《舍弃》最重要的，不是提前设计第二卷会去哪、遇到谁，而是保证第一卷结束时留下足够多的**可继续变化的状态变量**。

本轮研究得到的核心公式是：

> **阶段结算 = 真奖励 + 新权限 + 新依赖 + 新责任/债务。**

其中“新依赖、新责任/债务”不是为了惩罚主角，而是让已经得到的奖励开始具有现实重量。

最危险的伪衔接则是：

> 赢了 -> 数值更高 -> 地图更大 -> 敌人更强 -> 再赢。

这种结构可以短期爽，却不会自然产生新的生活、关系、职业和组织问题，只能靠不断加码维持。

对《舍弃》而言，当前第一卷强候选本身已经具备一个优秀的第一次换挡：

> **争资格 -> 获得资格 -> 争固定席位。**

真正需要为100—300章准备的，不是第三张更大的“资格证”，而是：

> **固定席位一旦拿到，陆野的判断开始影响别人；他的缺位一旦被证明有用，就会被定价、被排班、被要求验证，也会产生拒绝权和责任归属问题。**

这才是“第一卷成功制造下一发动机”。

# 1. 四层样本池与选择理由

## 1.1 研究口径

本轮不研究前三章，也不以“设定有多新”作为选样标准。

主要观察：

- 约50—300章；
- 或第一卷结束到第三、第四个完整功能阶段；
- 第一目标完成以后，下一目标从哪里长出来；
- 哪些旧人物、旧关系、旧制度、旧错误继续产生后果；
- 新地图是否真正承接旧状态；
- 修炼/职业升级是否改变“做事方式”，而不只是数字；
- 作品何时开始露出模板疲劳。

章节号来自公开目录时，仅作为定位锚点。不同平台存在卷内编号、正文编号、修订版编号差异，因此本报告以**功能阶段**为主，不把某一章号当精确历史事实。

## 1.2 A层｜头部仙侠男频：6部

| 样本 | 为什么选 | 50—300章最值得借的功能 | 不该机械模仿的部分 |
|---|---|---|---|
| 《没钱修什么仙？》 | 2026年起点“十万均订”，且多月男频月票前列；现实社会位置与修仙高度耦合 | 考试/资格/学校阶段的成功，会直接打开更高层的合同、项目、大学、产业和制度入口；“通过”不是结局，而是获得进入更危险体系的权限 | 不复制现代金融/校园外壳，也不把《舍弃》写成修仙学历职场讽刺文 |
| 《夜无疆》 | 2026年起点“十万均订”、荣耀五星 | 突破、秘地、名声、阶段大战以后，主角的位置和可接触世界随之改变；新空间往往伴随旧名声与旧敌友的继续作用 | 不学连续大秘境、大天才战；《舍弃》不能靠更大的天骄舞台续命 |
| 《玄鉴仙族》 | 长期高讨论度、家族群像代表性强，起点书单持续可见；核心结构与“人物不等主角才行动”高度相关 | 婚姻、迁徙、筑基、家族会议、盟约和旧怨形成长期状态；人物离场以后，家族仍继续承担其决定的后果 | 不复制跨代家史规模；《舍弃》第一阶段仍需保持陆野的即时欲望 |
| 《仙工开物》 | 起点十二天王、万人追捧、精品；“技艺/产业/组织”相关度高 | 技术/标准/试炼成功会改变身份、资源和竞争关系，工艺不是一次性解谜工具 | 不把“拾余”迅速做成完整产业科技树 |
| 《光阴之外》 | 2026年起点“十万均订”，长期头部 | 底层生存能力升级后，主角进入宗门、职司、序列、跨峰利益；约200章已出现“名气+职司+利益”使他能协调其他组织的状态变化 | 不把社会位置升级等同于“官越来越大”；《舍弃》应先保留小人物职业尺度 |
| 《赤心巡天》 | 起点荣耀五星、月票第一、千盟、长期男频月票前列 | 地域变化常携带旧国、旧人、旧债、身份和价值选择；世界扩大但人物过去仍在追赶他 | 不复制超大国家政治盘和极密人物网；第一次写长篇很容易失控 |

### A层共性

头部作品最强的地方通常不是“每个阶段都有更大的Boss”，而是：

1. **成功改变主角可进入的社会层级；**
2. **过去的人和债仍然有效；**
3. **名声本身会制造新的行动后果；**
4. **能力增长会改变角色可以承担的任务类型。**

但头部样本存在很强的“不可复制优势”——详见第2节。

## 1.3 B层｜稳定次热门 / 腰部长期：8部

这一层采用**宽口径**：既包含起点“万人追捧”的稳定次头部，也包含体量更接近腰部、能持续写到数百章的作品。

目的不是证明“腰部比头部高级”，而是找：

> **普通作者也能重复执行的阶段结构。**

| 样本 | 为什么对新作者更有参考价值 | 可迁移结构 |
|---|---|---|
| 《阵问长生》 | 起点万人追捧、精品，但发动机很大一部分来自可见的小目标：阵法、产业、坊市、人际、地方事件 | 技艺进步 -> 产业/身份 -> 地方关系；技能不是孤立升级 |
| 《我在修仙界万古长青》 | 起点万人追捧；数百章跨度中明显依赖时间、旧友、迁徙、势力变化 | 成功后允许时间流逝，旧关系和地缘变化自然制造新阶段；不是每次都靠强敌硬切 |
| 《法力无边高大仙》 | 起点万人追捧；常用“功法/资源/法器/关系”多轴推进 | 资源成功改变Build和交往半径；适合作为“多发动机轮转”的样本，同时也是“战斗/法器重复”风险样本 |
| 《叩问仙道》 | 超长连载，长期靠资源需求、功法需求、地域和旧因果换挡 | “上一个资源问题的解法”经常就是“为什么必须去下一个地方”的原因，地图切换具有因果 |
| 《长生从炼丹宗师开始》 | 起点万人追捧；职业技能与组织位置结合明显 | 炼丹做成以后，不只是赚更多钱，而会改变堂口、资源、组织责任和竞争 |
| 《从赘婿开始建立长生家族》 | 长篇家族经营；主角每次成功都会新增家人、产业、资源和治理对象 | **成功增加被你负责的人**，这是《舍弃》“固定席位以后开始负责别人”的高相关结构 |
| 《长生修仙，从画符开始》 | 非超级头部，更接近稳定长线执行；数百章能持续依靠技艺、坊市、旧人、迁移 | 低烈度职业发动机 + 人际/资源轮换，适合观察普通作者怎样避免一直打大高潮 |
| 《长生从抚养徒弟开始》 | 数百章长期推进，师徒与地域变化共同驱动 | 配角成长本身能改变下一阶段任务；主角不是唯一状态变化源 |

### 为什么B层重要

这些作品不一定都比头部作品结构更好，甚至有的同样会重复。

它们真正的研究价值是：

> 很多阶段不依赖极强文风、超级大谜团、大神品牌或史诗级世界观，也能靠“可见目标 -> 位置变化 -> 新责任”继续写。

对第一次写长篇尤其重要。

## 1.4 C层｜跨题材高相关：10部

本层借**功能**，不借职业皮肤。

| 样本 | 题材功能 | 重点借什么 |
|---|---|---|
| 《诡秘之主》 | 悬疑 / 组织 / 身份 / 私人生活 | 第一阶段结束后换身份、换城市，但旧组织、家人、秘密、经济压力和长期网络继续有效；新地图不是清档 |
| 《大医凌然》 | 职业 / 医疗 Procedural | 会做手术 -> 能上台 -> 能主刀 -> 要带人/决策/承担复杂病例；专业权限自然转成责任 |
| 《亏成首富从游戏开始》 | 商业 / 组织喜剧 | 每次“成功”反而改变下一阶段约束；公司变大后，员工、品牌、制度会自行产生主角无法完全控制的新行为 |
| 《全职高手》 | 电竞 / 竞技成长 | 对手是标尺而非一次性反派；技术被认可后会形成口碑、资源、战术、队伍与职业舞台入口 |
| 《第一序列》 | 公路 / 生存 / 家庭群 | 一路换地点，但家庭成员、旧关系、安家需求反复回来；“家”使地图扩张不等于换书 |
| 《无限恐怖》 | 团队任务 / 行动 | 队员能力差异、死亡、失败和资源选择会改变下次团队结构；任务地图重置，但队伍状态不重置 |
| 《异常生物见闻录》 | 单元事件 / 日常关系 | 外出处理异常后反复回到稳定家庭/住处；新成员加入会永久改变日常关系，因此单元不是纯案件清零 |
| 《绍宋》 | 组织 / 战争 / 系统治理 | 军事成功会增加地盘、人口、官僚、后勤和决策难度；胜利本身就是下一阶段治理负担的来源 |
| 《赘婿》 | 家族 / 商业 / 群像 / 灾难 | 家庭与商业关系可跨过城市灾难和政治阶段；空间升级时旧关系仍然继续作用 |
| 《大奉打更人》 | 刑侦 / 组织 / 朝堂 | 破案不是“案件归零”，而会改变主角在衙门、朝堂、同僚和大谜团中的位置；案件结果进入长期网络 |

### C层给《舍弃》的最直接启示

跨题材研究把一个问题看得更清楚：

> **职业升级的真正奖励不是工资，而是“你被允许做什么、别人开始依赖你做什么”。**

这比单纯研究修仙升级更适合解决陆野100章以后“固定席位拿到了，然后呢？”

## 1.5 D层｜中段失速 / 模板疲劳风险：5部

这一层**不是给作品下总评**，更不是说以下作品“失败”。

部分判断来自读者长评、书单评论和个人阅读反馈，只作为：

> “哪些结构会被读者感知为疲劳”的信号。

不同读者对同一作品存在明显分歧，报告只提取风险模式。

| 样本 | 读者常见疲劳信号（非统一结论） | 对《舍弃》的警告 |
|---|---|---|
| 《神秘复苏》 | 规则怪谈/灵异事件非常强，但有读者认为部分中后期人际关系更像连接副本的NPC；战力和事件规模上升后，生活与关系弱化更显眼 | “余灾/余器规则够怪”不能代替长期人物网络 |
| 《灵境行者》 | 有评论认为副本创意在长期重复后显出模板，海外阶段疲劳，人际角色易工具化 | 尝余绝不能变成“每20章一个怪单元”的案件钥匙 |
| 《我有一座恐怖屋》 | 长评既高度肯定氛围和结构，也指出后期角色过多、部分人物工具化、线索收束压力大 | “捡到很多特殊人/东西”会迅速形成角色库存债 |
| 《全球高武》 | 有评论认为后期持续战斗和战力膨胀弱化了早期学校、金钱、家庭等生活质感 | 六境不能只变成伤害倍率；每次境界应改变行动语法 |
| 《大王饶命》 | 部分读者对后期新地图阶段节奏与旧线回收有意见，但也有读者始终高度认可人物温度 | 新地图若丢掉原有日常关系、幽默和生活锚点，会出现“像换了一本书”的感受 |

### D层反面共性

中段疲劳通常不是“缺新点子”，而是以下五种状态之一：

1. **单元有结果，但长期状态不变；**
2. **主角更强，但做事方式没变；**
3. **地图扩大，但旧关系失效；**
4. **谜团只新增，不结算现实利益；**
5. **配角越来越多，却没有自己的连续目标。**

# 2. 头部 vs 次热门 vs 跨题材 vs 失速样本的差异

## 2.1 四层最核心差异

| 层 | 最强能力 | 最容易误学 | 对第一次长篇作者最该拿走什么 |
|---|---|---|---|
| 头部仙侠 | 大世界、长伏笔、强文风、强人物、超长铺垫仍能维持读者信任 | 以为“只要设定够深，100章以后慢慢解释就行” | 社会位置变化、旧债延续、升级改变权限 |
| 次热门/腰部长线 | 可见目标密度高、资源/职业/关系状态清楚、阶段换挡更直接 | 以为“普通、稳定”就一定更值得学，忽略其模板重复 | 可复制的目标阶梯、状态记录、低烈度发动机轮换 |
| 跨题材 | 把“责任、团队、案件、职业权限”拆得非常清楚 | 直接换皮：把医生主刀/公司晋升硬改成修仙职位 | 功能逻辑：权限->责任、团队角色、单元状态残留 |
| 失速样本 | 提供“读者何时开始看见模板”的反证 | 把主观评论当成作品定论 | 识别疲劳征兆，提前设置防线 |

---

## 2.2 为什么新作者不能只学头部爆款？

### 1. 大神品牌会购买“读者耐心”

已经建立作者信用的作品，可以：

- 用几十章铺一座新城；
- 让一个谜团很久不解释；
- 临时把镜头给大量配角；
- 用很长的过场酝酿一个大阶段。

第一次写长篇如果只学表面节奏，很容易把：

> “读者相信作者以后会收”

误学成：

> “我可以暂时不给当前故事理由。”

---

### 2. 强文风可以暂时掩盖弱衔接

一个极强作者哪怕阶段之间连接较松，人物对话、场景、情绪、世界奇观本身也可能撑住阅读。

新作者更需要问：

> **上一阶段结束后，为什么主角明天必须继续行动？**

而不是：

> “我下一卷还有一个更酷的世界。”

---

### 3. 极端高概念未必可复制

《诡秘之主》《玄鉴仙族》这类作品的一部分能力来自：

- 超大组织网络；
- 极复杂人物谱系；
- 极长谜团；
- 独特叙事视角。

它们可以借功能，但若第一次写长篇直接复制规模，维护成本会远大于收益。

---

### 4. 头部作品有更大的试错空间

长期读者积累、作者品牌、平台曝光会允许：

- 某段节奏慢；
- 某条支线暂时没有结算；
- 某个阶段需要更长预热。

新人通常没有同样的缓冲区。

因此《舍弃》的中段要更早让读者看见：

> **“第一卷拿到的东西，现在开始产生新的后果。”**

---

## 2.3 腰部稳定作品哪里反而更容易迁移？

不是因为它们“更普通”，而是部分作品依赖这些可执行机制：

1. 一个阶段有清楚的现实目标；
2. 达成后社会位置或资源入口变化；
3. 常驻人物重复出现；
4. 技艺进步可以被看见、被使用；
5. 地图变化由资源/工作/关系需要推动；
6. 每几十章至少有一次真实结算。

这些东西不要求作者必须拥有“白金级文风”。

---

## 2.4 但也不能反过来迷信次热门

“次热门”不等于“结构更健康”。

很多稳定长线作品也会依赖：

- 重复副本；
- 重复炼丹/画符；
- 重复换地图；
- 重复抢资源；
- 重复打脸。

所以正确方法是：

> **头部看上限，腰部看可执行性，跨题材看功能，失速样本看代价。**

四层互相校验。

---

# 3. 50—300章发动机矩阵

## 3.1 中段不是“填充区”，而是发动机交接区

研究中最稳定的模式不是：

> A阶段彻底结束 -> 休息 -> 作者发布B阶段任务。

而是：

> **A发动机还剩20%—40%未结算时，A的成功已经开始给B发动机供油。**

例如：

- 资格还没完全拿稳，别人已经开始考虑让你带人；
- 项目还没结束，名声已经传出去；
- 案件还没结算，受害人/同僚关系已经改变；
- 技艺还在验证，市场/组织已经开始询价；
- 战斗还没结束，胜利后的地盘和人口已经成为治理问题。

---

## 3.2 通用50—300章功能阶段

> 下表不是《舍弃》的第二卷章纲，只是对样本的“功能槽位”总结。

| 功能阶段 | 常见主发动机 | 必须完成的状态变化 | 下一发动机何时预热 | 最常见失速 |
|---|---|---|---|---|
| 约50—100 | 第一现实目标 + 第一能力兑现 | “我能不能进入这个位置/体系”得到答案 | 当前目标约六七成时，就让新责任/新关系出现 | 第一目标拖太久，读者一直等同一张证 |
| 约100—160 | 社会位置 / 团队 / 职业责任 | 权限开始影响别人；固定人物利益分化 | 主角第一次真正承担错误成本时 | 把“升级”当第二目标，社会位置不变 |
| 约160—230 | 方法化 / 组织 / 关系债 | 经验从个人技巧变成可被别人复用、质疑、定价的东西 | 方法刚显出稳定性就让产权、责任、制度进入 | 单元剧：每次都是同一技能解决新案例 |
| 约230—300 | 地域/制度/系统风险 + 新修炼方法 | 局部经验被放到更大环境验证；旧债跨地点生效 | 新地图之前必须已经存在“为什么非去不可” | 换城=换书；旧人、旧债、旧职业全部失效 |

---

## 3.3 七类发动机怎样轮换

| 发动机 | 它在强作品中的作用 | 什么时候该退居二线 | 谁应该接棒 |
|---|---|---|---|
| 职业发动机 | 给主角钱、资格、权限、日常任务来源 | 主角获得稳定身份后 | 责任/组织/关系 |
| 修炼发动机 | 改变行动权限和解决问题的方法 | 一次突破兑现完成后 | 职业应用/关系后果 |
| 人物关系发动机 | 让同一事件对不同人产生不同成本 | 如果只剩谈心、没有现实选择 | 职业/利益/灾难 |
| 组织/制度发动机 | 把个人行为变成规则、责任、资源分配 | 如果开始变成制度说明书 | 人物和具体任务 |
| 地域/旅行发动机 | 换资源、阶层、人物和危险 | 如果只是景点打卡 | 旧债/旧职业/新责任 |
| 谜团发动机 | 改变读者对现状的解释 | 如果连续只问不答 | 现实利益与行动结果 |
| 灾难/压力发动机 | 强迫不同角色同时表态和行动 | 每次危机都只“更大”时 | 修复/制度/关系结算 |

### 最佳轮换原则

> **主发动机只负责“现在为什么必须动”。**
>
> 其他发动机负责让这次行动产生长期后果。

不需要七个发动机同时抢戏。

---

## 3.4 “发动机接棒”最低标准

一个阶段结束时，下一阶段至少应从以下状态中继承**两项**：

- 身份/权限；
- 责任/风险承担；
- 关系债；
- 资源入口；
- 名声/公开度；
- 组织约束；
- 路线/地理；
- 对手从敌对变成竞合；
- 能力定价；
- 流程规则。

如果只继承：

> 等级 + 装备 + 一个新敌人，

通常不算真正的中段桥梁。

# 4. 18种中段桥接机制

以下全部是结构机制，不是建议《舍弃》逐条照搬。

| # | 上一阶段成功 | 怎样变成下一阶段问题 | 真正改变的状态 |
|---:|---|---|---|
| 1 | 拿到资格 | 资格允许独立判断，于是错误不再由上级全兜底 | 权限 -> 责任 |
| 2 | 获得固定席位 | 别人的工资、安全、行程开始依赖你的到岗和判断 | 奖励 -> 依赖 |
| 3 | 一次救援成功 | 被救的人、其家属/组织形成长期人情或期待 | 成功 -> 关系债 |
| 4 | 一次判断正确 | 管理者开始更频繁征询你，个人经验被组织依赖 | 能力 -> 岗位化 |
| 5 | 特殊能力被证明有效 | 出现“该不该加钱、是否必须用、错判谁负责” | 特殊性 -> 定价/责任 |
| 6 | 名声建立 | 更多邀约和求助出现，同时拒绝会产生信誉成本 | 名声 -> 选择负担 |
| 7 | 对手被击败 | 对方不消失，而可能成为同行、客户、合作方或长期标尺 | 反派 -> 竞合网络 |
| 8 | 团队磨合成功 | 分成、风险、优先级出现真实冲突 | 合作 -> 利益共同体 |
| 9 | 赚到第一桶金 | 能买资源，也必须决定再投资、分配、承担固定成本 | 钱 -> 资产/承诺 |
| 10 | 一次错误被补救 | 赔偿结束了，但客户信用、队友信任、流程验证仍留下 | 失败 -> 长期债 |
| 11 | 事故整改成功 | 新流程制造新岗位、记录、成本和盲区 | 修复 -> 制度负担 |
| 12 | 技艺被验证 | 别人开始复制、询价、争产权，主角失去对方法的独占解释权 | 技巧 -> 社会产品 |
| 13 | 发现多个相似现象 | 问题从“这件怪事”变成“不同地点为何重复” | 个案 -> 模式比较 |
| 14 | 获得新境界权限 | 以前不能接的任务变得可接；问题类型随权限变化 | 战力 -> 任务语法 |
| 15 | 固定路线跑熟 | 认识沿线人物和流程，因此能够看见“长期变化”而非单次异常 | 地图 -> 时间纵深 |
| 16 | 扩展到新地域 | 旧客户、旧组织、旧债提供非去不可的理由 | 扩图 -> 因果旅行 |
| 17 | 放弃局部利益保住整体 | 上级认可可靠性，却因此给主角更难的责任 | 正确损失 -> 更高信任 |
| 18 | 阶段危机被压住 | 事实证明旧系统还能运转，但必须有人长期维护新边界 | 胜利 -> 维护责任 |

---

## 4.1 一条非常重要的反向提醒

“成功必须产生问题”不能写成：

> 主角每赢一次，作者就惩罚一次。

成功必须是真成功：

- 钱真的多了；
- 地位真的升了；
- 朋友真的更信任；
- 技能真的更强；
- 生活真的改善。

下一问题应来自：

> **“因为这个奖励现在真实存在，所以它开始要求维护。”**

这和“奖励是假货”完全不同。

# 5. 单元剧疲劳与关系债分析

## 5.1 防疲劳的核心不是“每次换怪物”

一个单元是否值得存在，先问：

> **结束以后，长期世界有哪一项再也不是原样？**

至少应留下一个“状态残留”：

- 某人欠某人；
- 某人不再信某个判断；
- 某条路线被禁/被开放；
- 某客户转向别家；
- 某种方法得到验证；
- 某个岗位开始要求新流程；
- 某件普通法器损坏；
- 某人获得新权限；
- 某个秘密得到一个真实答案；
- 某个生活习惯永久改变。

如果十个单元结束后可以随意调换顺序，通常说明状态积累不够。

---

## 5.2 单元目标必须换“动词”

《舍弃》最危险的模板是：

> 尝到异常 -> 找源头 -> 证明余痕 -> 处理 -> 下一件货。

哪怕每次余器效果不同，本质仍是一集同一个案子。

中段应轮换目标动词，例如：

- 护住；
- 赶上；
- 拒绝；
- 赔偿；
- 谈价；
- 改线；
- 证明；
- 放弃；
- 救人；
- 训练；
- 带新人；
- 选边；
- 承认判断错；
- 保住客户；
- 替别人承担；
- 不使用自己的特殊能力。

**换对象不算换结构；换欲望和决策类型才算。**

---

## 5.3 核心能力必须定期“0作用”

强单元剧常故意安排：

> 主角最招牌的能力，在这一单元并不是答案。

对《舍弃》尤其重要。

尝余可以轮换为：

- 0作用；
- 辅助；
- 提示但无法归因；
- 真实感知却误导判断；
- 环境太混杂而接近失效；
- 有用但使用代价/责任不值得；
- 主角主动决定不用。

这比给它持续升级精度更耐写。

---

## 5.4 关系债比“好感度”更适合长篇

建议作者维护一个极简单的关系债表：

| 人物 | 他现在最想要什么 | 陆野欠他什么 | 他欠陆野什么 | 两人最近一次真正分歧 | 下次最可能在哪类现实问题冲突 |
|---|---|---|---|---|---|

关系的长篇生命力来自：

> **双方都有未结算的现实东西。**

而不是“友情值越来越高”。

---

## 5.5 配角要有“离屏时钟”

每个高频配角至少有一件：

> 即使陆野20章没找他，他也会自己往前走的事。

例如不是具体剧情，而是功能：

- 自己的客户；
- 自己的升职；
- 自己的家庭；
- 自己的欠款；
- 自己的训练目标；
- 自己的线路扩张；
- 自己的安全判断。

这样主角再次遇到他时，人物状态会改变。

《玄鉴仙族》、家族文和职业群像的长篇感，很大一部分就来自：

> 世界不会等主角按按钮。

---

## 5.6 私人生活不是“喘口气专用”

生活段落至少承担一种功能：

- 显示永久代价；
- 显示工作成功如何侵入生活；
- 显示角色关系已经变了；
- 显示主角现在有钱/没钱以后怎么过；
- 显示修炼时间与工作时间冲突；
- 显示别人并不关心主线秘密。

否则“日常”只是可删的缓冲章节。

对《舍弃》而言，味觉永久缺位最适合承担这类**长期生活刻度**。

---

# 6. 世界扩张而不“换一本书”

## 6.1 新地图至少要带走“三个旧锚”

从旧区域进入新区域时，至少保留三类东西中的三项：

1. **旧人物/旧组织；**
2. **旧债务/旧承诺；**
3. **旧职业身份；**
4. **旧技能的现实价值；**
5. **旧生活习惯/私人关系；**
6. **旧错误留下的流程约束。**

如果换地图后：

- 老人全没了；
- 钱重新算；
- 身份没价值；
- 名声没人知道；
- 职业不用了；
- 主角只剩境界；

读者很容易感觉“开新书”。

---

## 6.2 “为什么非去不可”必须来自旧阶段

强旅行/公路结构很少靠：

> 听说远方有个秘境，所以去看看。

更耐写的是：

- 固定路线本来就延伸过去；
- 老客户/旧友把需求带过去；
- 前阶段资源必须在那里验证；
- 旧错误在另一节点出现同类后果；
- 组织协作天然要求跨区；
- 过去救过/得罪过的人已经在那里。

即：

> **新地图不是新内容仓库，而是旧状态的下一块受力面。**

---

## 6.3 固定基地/回返点非常有价值

《第一序列》《异常生物见闻录》《诡秘之主》等不同类型作品反复证明：

> 世界再大，也需要某种“关系记忆点”。

它可以是：

- 家；
- 住处；
- 固定小队；
- 固定路线；
- 组织会议；
- 某个常去地点。

它的作用不是限制扩图，而是让读者不断看见：

> **同一批人已经不是上次那样了。**

《舍弃》的固定路线/固定小队非常适合承担这个功能，不应太快被抛弃。

---

## 6.4 新地图审查五问

进入新地区前问：

1. 为什么现在必须去？
2. 去了以后旧职业还有没有用？
3. 至少哪个旧人物/旧债会一起生效？
4. 主角回来时，原地点有没有因为他离开而变化？
5. 如果把新地名替换掉，这个阶段因果是否仍成立？

第五问若答案是“完全成立”，说明新地图可能只是换皮景点。

---

# 7. 修炼升级怎样改变事件结构

> 以下是对已冻结六境“读者可见新动词”的叙事推演，**不是新增 Canon**。

Canon 已锁定：

> 炼气 -> 筑基 -> 金丹 -> 元神 -> 法相 -> 洞天

关键不在数值，而在每一境给故事增加什么新“动作语法”。

| 境界 | Canon读者侧动词 | 事件结构可以怎样变化 | 最差写法 |
|---|---|---|---|
| 炼气 | 用灵气 | 主角第一次进入修士问题空间，能主动使用法器/术法解决局部问题 | 只当“攻击力1级” |
| 筑基 | 稳定离体 | 可持续进行离体操作、控制、护运和更稳定协作；任务可以从“我够不够强”转向“我能否把动作稳定做到” | 只是火球更大 |
| 金丹 | 持久 / 自循环 | 连续行动、长期守护、远途任务、资源耐力、独立值守成为可能；事件问题可以从“爆发能不能赢”变成“能不能持续承担” | 只增加蓝条/伤害 |
| 元神 | 离体 / 多线控制 | 同一事件可以出现多目标、并行观察、远近协同；失败点变成带宽、优先级、主体连续性 | 把多线控制写成多几个分身打人 |
| 法相 | 显道 / 道路外显 | 角色的修炼道路公开进入现实；战斗/行动同时影响名声、组织、他人判断，“你是什么样的修士”变成公开事实 | 只换一张巨型特效立绘 |
| 洞天 | 立界 / 改变战场环境 | 主角不再只是环境使用者，而会成为环境规则的提供/维护者；冲突可转向边界、依赖、治理和长期后果 | 只把领域当更大AOE |

---

## 7.1 对《舍弃》最重要的原则

每一次境界升级以后，至少有一个故事问题必须变成：

> **以前根本不能这样解决，现在可以；但因此也必须承担以前不用承担的东西。**

这才叫升级改变故事。

---

## 7.2 关于约100章附近“完整续我/正破”

当前 Canon 只要求：

> 后续应有一次标志性的完整续我/正破，用剧情证明陆野不是靠持续拆自己升级。

本报告不提前锁：

- 具体章数；
- 具体境界；
- 具体任务；
- 具体资源。

但若未来确实把一次完整续我放在约100章附近，它至少应该兑现两个功能：

### 功能A｜力量观证明

> 陆野可以靠正常修积、明悟、续我继续成长。

不能让读者形成：

> 每个大境都要再舍一块自己。

### 功能B｜社会方法变化

突破以后，不只是“打得更强”，而要让：

- 可接任务；
- 持续时间；
- 队伍角色；
- 风险责任；

至少一项发生真实变化。

否则这次“正破”只是主题声明，没有中段发动机价值。

---

# 8. 《舍弃》第一卷后必须留下的状态变量

> 本节不是第二卷大纲，只定义第一卷成功以后“哪些东西必须已经不是0”。

假设当前第一卷强候选大体成立：

> 临时杂役 -> 正式押手 / 固定路线成员  
> 漏舍异常被有限范围确认有实用价值  
> 小队形成  
> 中转流程暴露长期积累风险

那么100章以后至少需要以下状态变量。

---

## 8.1 职业变量

### 1. 身份
陆野已经不是“有没有工作资格”的人，而是：

> **拥有固定位置的人。**

### 2. 权限
他开始有有限的现场判断权。

不是领导，但不能再把所有决定推给别人。

### 3. 责任
他的错误会：

- 影响货；
- 影响同伴；
- 影响客户；
- 影响临时杂役。

这就是职业发动机第一次真正升级。

---

## 8.2 队伍变量

固定队伍至少要留下四个未完全同解的问题：

1. 分成怎么认定？
2. 谁承担高风险？
3. 什么任务值得接？
4. 尝余是否应该进入任务安排？

队伍不能在卷末变成：

> “大家终于成为永远意见一致的好伙伴。”

真正耐写的固定队是：

> **互相信任，但利益与判断仍然不同。**

---

## 8.3 能力定价变量

第一卷后别人至少已经知道：

> 陆野的缺位在某些场合有实用价值。

但以下问题**不要在第一卷彻底解掉**：

- 它算不算正式岗位能力？
- 使用是否必须加钱？
- 他是否有权拒绝？
- 错判由谁负责？
- 谁负责验证？
- 组织能不能专门为此排班？

这是一组天然的中段发动机，不需要新增世界观。

---

## 8.4 尝余认识变量

第一卷后陆野应该学到的不是：

> “我的雷达升级了。”

而是：

> **感知对象、承载位置、真正来源、当前风险是四件不同的事。**

这使尝余从“答案工具”变成：

> **需要普通证据配合的异常提示。**

它越不万能，越能长写。

---

## 8.5 拾余成熟度变量

第一卷后最多推进到：

> 偶然发现 -> 有一次窄用途验证 -> 知道可以记录和复核。

可以逐渐形成极简方法，例如功能上的：

- 发现；
- 隔离；
- 普通手段验证；
- 记录。

但绝对不能直接跳成：

> 拾余工业 / 余器公司 / 弃相交易平台。

否则明线会过早烧掉。

---

## 8.6 余灾变量

第一卷只证明：

> 单件风险可以沿中转、复用、环境形成积累。

第一卷后自然出现的问题应是：

> **别的地方会不会也出现“局部合理、长期积累”的相似模式？**

注意这不是：

> “全国有一个巨大阴谋。”

它首先只是一个比较问题。

---

## 8.7 制度变量

陆野与舍务/监管的关系应该从：

> 被检查的人

变成：

> **偶尔需要互相提供信息、但权力和证据标准并不相同的人。**

他不需要进入核心机构，也不需要获得秘密权限。

这能保留制度距离。

---

## 8.8 关系变量

### 石小庚
从一次名额竞争者变成：

> 同队长期标尺。

他在某项传统修炼基本功上继续能压陆野。

### 乔九
陆野的成功帮助线路/效率，但乔九仍有独立商业目标。

### 罗槐
安全优先原则不消失，只是判断边界变复杂。

### 唐禾
第一卷误判造成的客户/信用后果不宜完全“一次赔完归零”。

### 周照
继续是制度接口，不成为队友百科。

### 曹闻川
如果保留，他更适合作为长期“不同风险阈值”的外部经营者，而不是第一卷Boss尸体。

### 生活锚点
味觉缺位已经永久改变至少一项生活习惯或私人关系。

---

## 8.9 路线与地点变量

固定路线的价值不是“以后天天跑同一地图”。

它提供：

- 重复客户；
- 重复地点；
- 同一流程的时间变化；
- 对照不同地区的机会；
- 旧人自然再次登场。

这是观察系统性变化的天然尺子。

---

## 8.10 修炼变量

第一卷必须已经证明：

> 筑基才是真正力量升级，尝余只是信息优势。

后续完整续我如果出现，应继续这个方向，而不是重新强化“舍得越多越强”的错觉。

---

## 8.11 谜团变量

约100—120章附近最多推进到 Canon / mystery ladder 已允许的层级：

- 被舍掉的部分能留下真实残留；
- 残留可迁移、附着、聚集；
- 官方长期处理它们；
- 进一步追问它们去了哪里。

不提前打穿：

- 余世历史；
- 大规模截流全貌；
- 人工利用全体系；
- 余世主体性。

---

# 9. 五类中段发动机家族

至少三类即可，本报告建议保留五类作为“轮换库”。

它们不是五卷大纲，也不要求顺序固定。

---

## 家族A｜职业责任升级

### 基本链

> 有资格 -> 有固定位置 -> 有判断权 -> 别人依赖你的判断 -> 需要协调/承担

### 能撑多久

可稳定支撑2—3个功能阶段。

### 什么时候疲劳

当主要冲突变成：

- 审批；
- 表格；
- 升职；
- 组织架构；

而人物没有私人代价时，会迅速变成修仙职场文。

### 谁接棒

- 关系利益；
- 组织风险；
- 修炼方法。

### 对《舍弃》的适配

**高。**

因为第一卷卷末已经自然产生固定席位。

---

## 家族B｜拾余方法化

### 基本链

> 偶然拾到 -> 可验证 -> 小规模重复 -> 别人开始询问/模仿 -> 产生定价与责任

### 能撑多久

3—4个阶段，但必须非常慢。

### 疲劳点

最危险的三种漂移：

1. 鉴宝文；
2. 宝可梦式余器收集；
3. 工业化创业文。

### 谁接棒

- 产权；
- 监管；
- 关系利益；
- 余灾。

### 对《舍弃》的适配

**很高，但必须慢。**

第一卷后只够开始“方法”问题，不够开始“产业”。

---

## 家族C｜余灾治理 / 系统风险

### 基本链

> 单点风险 -> 相似模式 -> 不同组织阈值冲突 -> 局部治理 -> 治理本身产生新成本

### 能撑多久

2—3个阶段。

### 疲劳点

如果每次只是：

> 这次余灾半径更大、怪象更怪。

就会立刻退化成灾难副本。

### 谁接棒

- 制度；
- 职业责任；
- 谜团；
- 关系。

### 对《舍弃》的适配

**高。**

因为第一卷已经有“局部合理决策长期叠加”的因果种子。

---

## 家族D｜固定队利益与关系

### 基本链

> 合作成功 -> 形成共同收益 -> 分配风险/收益 -> 判断分歧 -> 信任模式变化

### 能撑多久

它更适合作为**持续低火发动机**，而不是单独撑整卷。

### 疲劳点

如果所有队友：

- 都只围着陆野的特殊性；
- 都没有自己客户/前途；
- 所有冲突最终都靠友情解决；

很快会工具化。

### 谁接棒

它本身可以反复给职业、灾难和方法化发动机提供人物后果。

### 对《舍弃》的适配

**极高。**

---

## 家族E｜修炼方法换挡

### 基本链

> 新境界 -> 新行动权限 -> 新任务结构 -> 新责任/失误方式

### 能撑多久

每次突破适合做阶段换挡器，不适合长期单独连续燃烧。

### 疲劳点

如果：

> 境界 = 伤害数字。

则对中段几乎没有结构价值。

### 谁接棒

- 职业；
- 组织；
- 战斗；
- 地域。

### 对《舍弃》的适配

**必须存在。**

否则全书会越来越像特殊设定文，而不是仙侠。

---

## 9.1 推荐的轮换原则

不要安排：

> A卷职业，B卷拾余，C卷余灾，D卷制度。

更自然的是：

> **一个主发动机 + 一个正在升温的副发动机 + 一个长期低火关系发动机。**

例如只谈功能，不谈具体卷：

- 职业责任主燃；
- 拾余方法开始升温；
- 队伍利益持续低火。

当职业目标暂时稳定时：

- 方法/余灾接手；
- 职业留下责任后果继续作用。

这样才不会“每卷换类型”。

---

# 10. 第一卷当前强候选的中段兼容性审查

> 审查对象是当前 V2 强候选：
>
> **驿货行短途杂役 + 两级现实目标 + 固定货路群像 + 中转流程长期积累风险。**
>
> 本节不修改 V2，只判断它是否能自然向100—300章生长。

---

## 10.1 中段兼容性强的地方

### 优势1｜“资格 -> 固定席位”已经是第一次成功后果化

资格解决：

> 我能不能做？

固定席位解决：

> 我有没有真正的位置？

这是比“一卷一个Boss”更健康的中段基底。

---

### 优势2｜固定席位天然能变成责任，而不是再发第三张证

只要卷末让读者真正意识到：

> 固定位置意味着别人会等你、依赖你、被你的判断影响，

下一阶段就已经存在。

不需要另造大任务。

---

### 优势3｜尝余被V2限制成“真实信号、错误归因”

这非常重要。

它意味着能力的长期成长可以来自：

> 证据边界和判断模型，

而不是：

> 雷达等级从Lv1升到Lv10。

这能显著降低单元剧疲劳。

---

### 优势4｜流程积累比“邪恶仓库”更能繁殖状态

一座坏仓库炸完就结束。

一套长期流程被证明有盲区以后，会留下：

- 谁负责；
- 怎么验证；
- 多花多少钱；
- 谁愿意停；
- 谁承担错判；
- 别处是否类似。

这正是中段最需要的“后果库”。

---

### 优势5｜固定队已经具备差异化利益

如果V2当前方向保持：

- 乔九：效率/扩线；
- 罗槐：安全判断；
- 唐禾：客户/长期信用；
- 石小庚：传统能力竞争；
- 周照：外部监管；
- 曹闻川：经营风险阈值；

那么中段并不缺人物冲突。

真正要防的是作者后来把他们都写成：

> “陆野说有问题，所以大家帮陆野。”

---

### 优势6｜私人生活锚点已经补上

这让世界扩张后仍有“回返点”。

也是味觉缺位长期保持疼感的最低成本办法。

---

### 优势7｜正常修炼线被重新扶正

V2三次传统修仙兑现能够避免：

> 尝余 = 主角真正的力量系统。

这对后续六境行动语法非常关键。

---

## 10.2 中段最需要提前防的10个风险

### 风险1｜固定席位只作为工资奖励

若卷末只有：

> “以后收入稳定了。”

那100章以后仍会清零。

必须至少让“别人依赖这个位置”成为可见事实。

---

### 风险2｜所有异常都必须经过陆野鼻子/嘴

即便尝余有限，只要所有重要问题都：

> 先由陆野发现，

他仍会成为剧情扫描器。

后续必须存在：

- 别人先发现；
- 普通记录先发现；
- 同伴判断先发现；
- 陆野完全尝不到；

的事件。

---

### 风险3｜“异常货物周刊化”

如果路线只是为了不断给陆野送新余器/怪货，驿货行就退化成单元传送带。

---

### 风险4｜余器库存膨胀

“每阶段一件很酷的窄余器”听起来克制，写几十个阶段以后仍会变成卡牌库。

余器必须继续是少量任务型工具。

---

### 风险5｜流程问题迅速升级成“大制度阴谋”

第一卷证明：

> 局部合理选择会叠加风险。

这比“高层故意害人”高级，也更耐写。

不要为了中段刺激立刻把它翻译成：

> “整个舍务体系都在偷穷人的弃相。”

mystery ladder 已经明确禁止过早打穿。

---

### 风险6｜固定路线变成固定地图

固定路线应提供：

> 时间纵深和重复人物，

不是强迫所有事件发生在同一条路。

---

### 风险7｜配角只剩岗位标签

如果乔九只谈效率、唐禾只谈钱、罗槐只谈安全、周照只谈监管，人物再合理也会功能卡化。

必须让离屏目标继续走。

---

### 风险8｜陆野太快变专家/顾问

第一卷结束时他只是：

> 有一种罕见后遗症 + 一次事故经验 + 一些局部判断。

不能因为“读者知道他是主角”，就让整个行业突然让他设计新制度。

---

### 风险9｜中段只做组织责任，仙侠感再次变弱

职业线越成功，越需要用普通修炼和普通法器不断提醒：

> 这是修仙世界里的职业责任，不是现代物流案例。

---

### 风险10｜正破只做主题证明，不改变做事方法

未来完整续我如果只是：

> “看，我没有舍第二次。”

主题上正确，结构上仍然不足。

必须让境界变化真实改变能承担的任务。

---

## 10.3 第一卷真正值得“埋”的不是第二卷剧情，而是六个接口

这些是**中段兼容接口**，不是要求修改V2的具体剧情：

1. 固定席位 = 收益 + 对他人负责；
2. 尝余 = 有价值但不能独立形成证据；
3. 误判 = 赔偿可以结，信用债不能瞬间清零；
4. 固定队 = 信任形成，但分成/风险/职责仍未统一；
5. 流程整改 = 问题压住，但新办法仍有成本；
6. 生活锚点 = 工作成功会继续改变下班后的生活。

只要第一卷结束时这六个接口成立，中段就不需要硬开新主线。

---

# 11. 给第一次写长篇作者的执行检查表

## 11.1 现在应该提前锁什么？

锁“状态边界”，不要锁未来剧情。

建议提前锁：

1. 第一卷结束时陆野的职业身份；
2. 固定队核心角色各自的长期欲望；
3. 尝余的证据边界；
4. 一次误判留下的真实债；
5. 私人生活锚点；
6. 第一卷结束时哪些问题**明确已经解决**；
7. 哪些问题只是刚变成“新的责任”；
8. mystery ladder 允许知道到哪一层；
9. 正常修炼必须继续是主力量线；
10. 100—300章最多准备哪2—3类发动机，而不是具体故事。

---

## 11.2 哪些只知道方向，不要锁死？

只需要知道：

- 下一阶段主发动机大概率偏职业责任、拾余方法还是余灾治理；
- 哪个角色最可能成为下一阶段的重要利益冲突方；
- 下一次境界升级应改变哪类行动方法；
- 世界可能向哪类区域扩展；
- 谜团大约推进一层。

不要现在决定：

- 哪一天；
- 哪座城；
- 哪个怪物；
- 哪件余器；
- 哪个具体大事件。

---

## 11.3 最容易写着写着失控的内容

第一次长篇最危险的不是不会想点子，而是：

### 1. 人物越来越多
每个新阶段都加3—5人，旧人不结算。

### 2. 谜团越来越多
每次结尾都“还有更大的秘密”，但很少给答案。

### 3. 余器越来越酷
想保持新鲜，于是不断设计新规则物品。

### 4. 地图越来越大
误以为扩世界就是扩地名。

### 5. 修炼越来越像数字
境界升级没有改变事件方法。

### 6. 研究比正文更完整
作者知道世界怎么运行，但每场戏里没人“今天必须得到一个具体东西”。

---

## 11.4 每写完20—30章检查一次什么？

固定问这10题：

1. 陆野这20—30章最具体想得到什么？
2. 他现在的社会位置和30章前有什么不同？
3. 他新增了什么责任，而不只是奖励？
4. 哪一个旧结果在本阶段回来咬人/帮人？
5. 至少一个常驻配角自己的目标有没有推进？
6. 如果尝余连续10章不能用，故事还能不能动？
7. 正常修炼有没有真实改变一次解决问题的方法？
8. 谜团有没有**回答一个问题**，而不是只加一个问题？
9. 私人生活有没有显示陆野已经不是原来的状态？
10. 接下来3章主角有什么即时欲望，而不是“继续调查大主线”？

若其中6题以上答不清，应先修结构，不要继续加设定。

---

## 11.5 怎样判断支线该继续、收束还是砍？

### 继续
满足至少两项：

- 改变人物关系；
- 改变职业/组织位置；
- 改变资源入口；
- 改变谜团认识；
- 产生未来必须兑现的承诺；
- 改变主角做事方法。

### 收束
核心问题已经回答，只剩：

- 氛围；
- 回味；
- 人物余波。

用一两个短回收即可，不必强行升级。

### 砍掉
如果一条支线需要：

- 新地图；
- 新角色；
- 新规则；
- 新余器；

但几乎不继承旧状态，它很可能只是“另一个好点子”。

---

## 11.6 怎样避免“大纲漂亮，正文没有即时欲望”？

每个场景先写一句：

> **“此刻这个人具体要什么？”**

只能用可行动的词：

- 赶上；
- 拿钱；
- 保住货；
- 让某人答应；
- 不被扣工资；
- 证明自己；
- 回家；
- 拒绝；
- 隐瞒；
- 找到人。

不能写：

- 推进主线；
- 展示世界观；
- 埋伏笔；
- 表现主题；
- 让读者知道制度问题。

后面这些只能是作者效果，不能是人物动机。

---

## 11.7 最简单的四张维护表

不要做复杂数据库。

### 表1｜人物状态
| 人物 | 当前目标 | 当前资源 | 当前压力 | 最近一次主动选择 | 下次自然动作 |

### 表2｜关系债
| A | B | 谁欠谁什么 | 未解决分歧 | 最近变化 |

### 表3｜承诺/谜团
| 问题 | 读者知道 | 陆野知道 | 错误理解 | 下次最晚何时应有推进 |

### 表4｜长期状态变化
| 事件 | 身份变化 | 关系变化 | 流程变化 | 资源变化 | 是否已回收 |

这四张表足够支撑第一次长篇的中段维护。

---

# 12. 红队：哪些建议听起来高级，实际上会让《舍弃》更难写？

## 12.1 “七大发动机每卷都要同时运行”

错。

会导致：

- 每章都在换线；
- 读者不知道当前最急的事；
- 作者维护成本爆炸。

更好的做法：

> 一主、一副、一条低火关系线。

---

## 12.2 “每个核心配角都做完整30章个人篇”

听起来群像，实际会拖垮新人。

配角真正需要的是：

> 自己有目标 + 能主动改变主线 + 状态会离屏推进。

不需要人人开外传。

---

## 12.3 “第一卷后立刻把拾余做成可复制产业”

这是目前最危险的“高级感”。

一旦工业化：

- 需要市场；
- 需要技术标准；
- 需要供应链；
- 需要监管；
- 需要大批新角色；
- 需要回答弃相来源和制度真相。

这会一次烧掉三四百章的潜力。

应慢到：

> 个人经验 -> 简单验证 -> 极小规模复用 -> 别人开始注意。

---

## 12.4 “中段要升级，所以赶快离开驿货行去大宗门/大城市”

未必。

如果固定路线、小队、客户、监管关系刚建立就全部抛弃，相当于把第一卷积累清空。

世界可以扩大，但旧职业身份应继续有用。

---

## 12.5 “每次阶段成功都必须产生严重坏后果”

会让读者觉得：

> 努力没有意义。

中段需要的是“奖励有维护成本”，不是“奖励都是诅咒”。

必须允许真正的：

- 开心；
- 涨收入；
- 变强；
- 被认可；
- 关系改善。

---

## 12.6 “流程系统风险很好，所以把整条行业制度提前设计完整”

不该。

作者只需要知道：

- 第一卷那条因果链为什么成立；
- 后续还有哪些接口会产生现实冲突。

不需要现在写：

- 全国分类标准；
- 余痕法规大全；
- 货运监管组织图。

这会把小说变成设定工程。

---

## 12.7 “每个境界都绑定一个主题性舍弃”

直接违反 Canon 风险。

Canon 已明确禁止：

> 先决定角色舍什么，再倒推境界刚好需要它。

未来境界必须先有真实修积、明悟和续我问题。

---

## 12.8 “为了保持神秘，余世到300章都不回答任何问题”

同样错误。

mystery ladder 的正确用法是：

> 每一层给一个真答案，同时这个答案改变现实利益。

谜团不能只加不解。

---

## 12.9 “关系债越多越长篇”

债过多就是库存爆炸。

每个阶段应主动：

- 还掉一些；
- 放弃一些；
- 让一些关系自然结束。

“无清零”不等于“永不结案”。

---

## 12.10 “把中段300章全部提前排完，最安全”

对第一次长篇反而危险。

它会逼作者：

- 为了执行旧计划无视正文中真正好用的人物；
- 让已经失效的支线继续活；
- 提前锁死谜团答案和制度细节；
- 产生大量返工。

现在更应该锁：

> **接口、边界、状态变量、检查方法。**

而不是锁事件。

---

## 12.11 现在绝对不该提前定的东西

1. 第二卷12个具体故事单元；
2. 第二卷详细章纲；
3. 100—300章每次突破的精确章数；
4. 陆野下一次具体舍什么；
5. 全国舍务组织结构；
6. 完整拾余产业链；
7. 余器分类百科；
8. 未来十座城市/宗门名单；
9. 每位配角的完整百章人生；
10. 余世终极来源；
11. 导余体系全部历史真相；
12. 300章以后弃相是否形成完整主体。

这些都属于：

> **现在设计得越漂亮，未来越容易绑架正文。**

# 13. 最终三分类

## 13.1 现在就该给第一卷埋的

> “埋”指建立状态，不是新增伏笔台词。

| 项目 | 第一卷结束前至少做到什么 |
|---|---|
| 固定席位的责任性 | 让读者看到这个位置不只是加钱，别人会依赖它 |
| 队伍真实分歧 | 信任形成，但风险、分成、判断不完全一致 |
| 尝余证据边界 | 明确“有信号 ≠ 知道源头/风险” |
| 一次真实误判债 | 赔偿可结，信用/客户/队友记忆不瞬间清零 |
| 特殊能力被初步定价 | 出现“这能力值钱”的现实动作，但不建立完整制度 |
| 流程整改成本 | 危机解决后，旧流程不能完全恢复原状 |
| 普通修炼主轴 | 至少三次证明正常修炼才是力量基础 |
| 石小庚等传统标尺 | 主角不能因特殊性全方位压过同行 |
| 私人生活锚点 | 味觉缺位永久改变至少一项普通生活 |
| 小范围职业名声 | 有人记住这支队/这个人，但不是全城天才 |
| mystery ladder边界 | 只确认当前允许的余痕/弃相层级 |
| 乔九/唐禾等人的独立目标 | 证明主角不在场时世界会继续走 |

---

## 13.2 第一卷后再决定的

1. 下一阶段到底职业责任还是拾余方法先当主发动机；
2. 固定路线是否扩成多路线；
3. 陆野是否需要带临时杂役/新人；
4. 尝余是否正式计入岗位补贴；
5. 第一套最简单的“发现—验证—记录”方法何时稳定；
6. 是否出现第二处相似流程风险；
7. 周照与陆野的合作距离如何变化；
8. 唐禾的客户债怎样回流；
9. 曹闻川是否继续成为长期外部经营方；
10. 下一次完整续我/正破落在什么阶段；
11. 新区域从哪一个旧关系自然长出来；
12. 哪个发动机在约150—200章开始接棒；
13. 约200章 mystery ladder 中“统一去向/截流”具体以什么事件进入；
14. 固定队是否发生第一次真正的分成/拒绝任务冲突。

这些应根据第一卷正文里：

> 哪些人物真的活起来、哪些冲突真的好写

再决定。

## 13.3 坚决不要提前设计的

1. “第二卷必须打某个Boss”；
2. “第三卷必须去某个宗门”；
3. “每50章必须升一个境界”；
4. “每个境界必须舍一种人格”；
5. 大量新余器清单；
6. 完整弃相市场；
7. 拾余工业革命时间表；
8. 全国统一异常货运制度；
9. 余世终极地图；
10. 最终反派身份；
11. 所有制度高层到底知道多少；
12. 所有弃相是否最终形成文明；
13. 200万字完整卷纲；
14. 为了“未来有用”而提前塞十几个配角。

# 最终研究结论

《舍弃》现在最不需要的是：

> “第二卷再想一个比旧中转流程更大的事故。”

它真正需要保护的是一条更稀缺的结构链：

> **临时工为了不被替代而争资格  
> -> 资格让他进入固定队竞争  
> -> 固定席位让别人开始依赖他的判断  
> -> 缺位被证明有用，于是开始被定价  
> -> 被定价以后出现责任、拒绝权、验证和分成  
> -> 个体经验逐渐出现可复用性  
> -> 可复用性才逐步撞上组织与制度  
> -> 制度处理的结果再反过来改变余灾与现实生活。**

这条链最关键的地方不是“越来越大”，而是：

> **每一步都由上一步的成功亲手制造。**

因此，当前第一卷V2的中段兼容性总体是好的。

它已经有：

- 两级现实目标；
- 固定队；
- 特殊能力的证据边界；
- 一次真实误判；
- 流程型系统风险；
- 私人生活锚点；
- 正常修炼兑现。

下一步不应写第二卷详细大纲。

对总编最有价值的动作是：

> **在第一卷 Final Story Engine Audit 时，额外检查“卷末奖励有没有同时生成责任、关系债和能力定价接口”。**

只要这三种接口真实存在，100章以后就不必靠：

- 更大的敌人；
- 更怪的余器；
- 更深的秘密；

强行续命。

中段真正的长篇发动机不是“下一件事”。

而是：

> **你终于得到了想要的东西。现在，你得负责它了。**
