# Purpose

Before redesigning A / D world models, inspect what strong current works actually prove.

# 1. Modern cultivation｜《没钱修什么仙？》

Current public evidence frozen 2026-09:
- 十万均订 badge (2026-04-01);
- 2026-08 male monthly-ticket #4;
- persistent top ranks across 2025–2026.

What actually works:
> modern vocabulary is not the core. The core is that money / qualification / education / employment / debt continuously set protagonist's price, and cultivation competence lets him reverse that pricing.

Function for A3:
- modern cultivation society must create protagonist pressure every day;
- cultivation infrastructure must affect ordinary life;
- "world is being drained" must appear through useful institutions people genuinely depend on;
- protagonist's send-off ability must change his social action rights, not merely solve technical cases.

Wrong imitation:
> smartphones + cultivation university + qi-company vocabulary without daily pressure / reversal.

# 2. Current two-world cultivation｜《原来我是仙道天骄》

Current public evidence:
- 2026.09 new work;
- official Qidian book-list data records 2026-09-01 launch, 3.37w collection, first order 6691;
- current Qidian community book-list records "万订" on 2026-09-10.

Package:
> low-value artificial-root student in a modern/capitalized cultivation world gains a world-crossing pearl and becomes a valued heavenly-root genius in an ancient cultivation world.

What actually works:
1. immediate status gap:
   > same protagonist is low-value in world A and high-value in world B.
2. immediate information / resource gap:
   > each world contains things the other values differently.
3. every crossing changes options now:
   > not just lore access.
4. both worlds produce plot pressure:
   > not one main world + one encyclopedia.

Function for A3 D:
> A3 dual-world version must give protagonist repeatable, immediate cross-world value difference every time he crosses.

Wrong imitation:
> second world only stores lost funeral lore / old records.

# 3. Traditional long-form｜《天渊》

Current public evidence:
- Fanqie public page ~120.8w current readers;
- ~618.3w chars;
- ~2987 chapters.

Package:
> protagonist returns alive from a forbidden region after being presumed dead, but cultivation / spiritual root are ruined; broken engagement and a mysterious red-dressed woman immediately create personal stakes.

What this proves:
> traditional cultivation does not need institutional novelty, but first-screen conflict must be concrete and personal.

Function for A3:
> even with huge Heaven-death premise, Ch1–3 must give protagonist an immediate life / status / survival conflict.

Wrong imitation:
> opening with ten pages explaining Heaven-Earth ecology.

# 4. Dedicated underpriced arena｜《从水猴子开始成神》

2025 Twelve-King sample.

Package:
> land resources are crowded; deep-water resources are underpriced; protagonist gets a water-specific growth engine and a clear water-god-like endpoint.

Function:
> world setting must create a specific advantage lane for protagonist.

For A3:
> "death / end-of-life things" must be a concrete underpriced resource / access lane, not merely a moral responsibility.

# 5. Cultivation + public authority｜《以神通之名》

Current evidence:
- 万人追捧;
- 2026 monthly-ticket top 6–9 range for multiple months.

Function:
> competence becomes institutionally recognized handling power; larger position = larger real-world consequences.

For A3:
> protagonist's growth should visibly expand what scale of "death" he is authorized / capable to close.

Wrong imitation:
> bureaucracy / meetings / title collection.

# 6. Mythic scale｜《剑烛大荒》

Current evidence:
- 首订过万;
- 万人追捧;
- 2026-06/07/08 monthly-ticket top 10.

Function:
> mythic curiosity, power acquisition and life-level elevation move together.

For A3:
> death subjects must rise in mythic scale together with protagonist:
tool → place → vein → lineage → region → ascension → Heaven.

# Benchmark conclusions for A vs D

## A single modern world must prove:
- protagonist is personally trapped by modern cultivation structure;
- everyday infrastructure makes the world crisis visible;
- his unique ability gives immediate professional / social leverage;
- ancient / mythic scale must still enter later.

## D two-world must prove:
- every crossing gives immediate status / resource / action asymmetry;
- second world generates plot, not just answers;
- both worlds are incomplete in complementary ways;
- same send-off mechanic behaves differently in each world;
- cross-world gains must deepen Heaven mystery without turning into pure trading.
