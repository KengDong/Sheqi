# REBOOT-V4｜Fanqie Pool 02 都市医武神医 Direct Hit + Matched-Failure Deep Read

## 1. Exact Reader Pool definition

本报告只研究：

> 被轻视 / 身份低 → 真正出事时只有我能解决 → 对方被迫重新评价我 → 社会位置持续上升。

这里的“身份反转”不等于“有人震惊”。

本报告把一次反转定义成三个层级：

1. **Reaction｜反应**：旁观者惊讶、后悔、害怕、道歉。
2. **Revaluation｜重新定价**：具体人物改变对主角的判断，并在后续做出不同选择。
3. **Compounding Social Asset｜复利社会资产**：这次证明永久改变后续起点，例如获得可持续的信任、求助权、邀请、保护、转介绍、情报、资源、公开头衔、机构位置，或者让同一社会圈以后不能再把主角当回原来的“无名小卒”。

Pool 2 真正需要验证的是第 2、3 层，而不是 Reaction 数量。

### 样本调整说明

起始 WEAK 《都市之神医下山》虽然包装高度匹配，但正文访问不足且时代差过大。本轮没有强行把它伪装成第二个“干净 CORE WEAK”。

搜索中发现《重生男护士，开局就是绝活》：它与《凤流高手》共享非常罕见的“男护士低位 + 医疗不可替代 + 专业身份被重新定价”，且 2025-09 起章、169章完结、当前未满1000，在时间和 delivery vehicle 上更接近，因此加入 CORE MATCHED WEAK。

这一步很重要，因为它直接推翻了“弱书只是反转不够快”的简单解释。

## 3. Shelf / Package analysis

### 3.1 《凤流高手》

Package 不是抽象“神医下山”，而是把低位写进职业伤口：

- 主角本来想学临床医学；
- 因竞争者动用关系，被调到护理；
- “男护士”成为外界直接可见的低位标签；
- 低位不是开局随机穷，而是和四年前的受辱、职业理想、旧情敌绑定；
- 简介明确承诺“曾经被嘲笑的男护士，不再任人欺凌”。

因此陌生 Reader 在打开前已经知道：
> 我不是要看一个神医随机救人，而是要看“被压进低位的人”把职业评价体系掀回来。

这是 acquisition 层的重要区别。

### 3.2 《高手下山，我家师姐太宠我了》

它表面属于“高手下山”，但 Reader 从 Ch1 就知道主角并不低能力：

- 99个师父本身就是顶级权力/医学/武道/财富网络；
- 主角已经超越多位师父；
- 真正的“低位”不是无能，而是叶家被灭后的社会身份坍塌：家没了、名字曾被压下去、五年前的受害者重新回来。

因此它卖的不是“我真的弱”，而是：
> 世界把我当五年前那个可以被灭门的人，但 Reader 知道这个定价已经严重失真。

这使武力证明可以极早发生而不需要长成长线。

### 3.3 《重生男护士，开局就是绝活》

Package 也有强低位：

- 医学博士穿越成1985年的男护士；
- 同事和患者对男护士的精细护理能力有先验怀疑；
- 简介承诺靠“高级医学护理技能系统”惊艳医学界，成为医院招牌。

但它同时把读者预期导向：
> 医疗技术展示 / 护理职业正名 / 系统技能升级 / 医院日常。

也就是说，“社会身份翻身”只是四个卖点之一，并非唯一的主情绪。

### 3.4 《医武天下》

Package 是高度标准化的 Pool 2 商品组合：

- 五位顶级师父；
- 下山相亲；
- 金针、神拳、风水、毒术；
- 多女、无敌、打脸；
- 明说“既然不能低调，那就高调”。

它几乎不缺类别元素。它的弱信号因此尤其有价值：
> 类别关键词齐全，本身并不能保证 Reader 得到“社会位置持续上升”。

## 4. Ch1–3 First-screen conversion

### 《凤流高手》

**Ch1**
- 先给具体职业受损史，而不是先报境界。
- 旧对手杨伟用现实可理解的权力关系压过主角，主角被当作“未来男护士”羞辱。
- 低位与前女友、大学四年、职业理想同时绑定。
- 第一屏先制造“这个人被错误定价”的长期情绪债。

**Ch2–3**
- 家庭核心关系“小姨/养育者”与其闺蜜进入。
- 身世和养育义务建立，使主角以后不是纯自由爽文接口。
- 医武传承尚未立刻把所有社会问题清零。

**第一次真正不可替代证明**
- Ch5：用针灸让白洁的严重病痛出现明确改善。
- 这是私人空间里的重新评价，不是全场公开打脸。

因此它的 Promise-to-payoff 不是最快，但“低位为什么痛”建立得更具体。

### 《高手下山，我家师姐太宠我了》

**Ch1**
- Reader 先知道主角已经强得离谱；
- 随后把他扔回“灭门五年后的旧社会关系”；
- 退婚看似羞辱，但周若妤的动机很快被写成保护，不把最亲近关系简单低智化。

**Ch2**
- 旧婚约关系不是一次性反派；她有独立风险判断与保护意图。

**Ch3**
- 主角直接在高压冲突中用武力摧毁对方对他的旧定价；
- 第一轮 PUBLIC revaluation 已经发生。

它的第一次身份反转非常早，但关键不是“早”本身：
> 这次冲突同时接上灭门案与更高层势力。

### 《重生男护士，开局就是绝活》

**Ch1**
- 医院里多名护士都无法给危重幼儿建立静脉通道；
- 护士长甚至明确认为秦臻只适合干重活，不适合精细操作；
- 主角一针完成，患者家属和护士长马上改口；
- 第一章就同时完成“低位 → 不可替代 → 赞赏”。

也就是说，这本 WEAK 控制的核心付款速度比两本 HIT 都不慢。

**Ch3**
- 文本明确说明：1985年男护士被同事、患者歧视，很多患者会直接拒绝他的护理。
- 但主角本人对“做护士”并无强烈身份创伤，只要能脱离农村、吃国家粮就接受。
- 因此低位标签更像“可被技能打破的障碍”，不是一条长期未结算的人生债。

### 《医武天下》

**Ch1**
- Reader 已经知道五位师父把武、医、风水、毒术等能力塞满；
- 主角入城几乎没钱、不会现代支付，被当土包子；
- 但他立刻用小聪明反戏弄富少，低位更偏喜剧伪装。

**Ch3**
- 已经与富裕女总裁唐玥进入契约婚姻；
- 外人马上针对“她怎么会嫁这种人”制造身份错配。

它的低位建立也并不慢，但“低”主要来自外观/贫穷/城乡信息差，而不是需要长期翻盘的具体身份损失。

| 《重生男护士…》 | Ch1 | Ch1 | 是；Ch7医院已将其机构化为“品牌” |
| 《医武天下》 | Ch8 | Ch8 | 是，但局部化；Ch10核心关系仍未同步 |
| 《都市之神医下山》 | 目录暗示Ch2/Ch18附近有医疗兑现 | 无法用正文可靠核定 | 证据不足 |

**结论：Promise-to-payoff delay 不是主要分界。**

两个 WEAK 都能非常早付款：
- 男护士 control 在 Ch1；
- 《医武天下》在 Ch8。

因此“前三章一定要打脸”“越早越爽就越强”不是本轮证据支持的因果结论。

## 7. Repeatable Reader Fantasy loop

真正可重复 20+ 次的不是：

> 新反派看不起 → 主角亮能力 → 全场震惊 → 换下一批。

更强的可重复单元是：

> 某个社会节点按旧身份给出错误决策  
> → 现实问题把“能力是否真实”变成不可逃避的检验  
> → 主角解决  
> → 该节点改变未来行为  
> → 节点留下可调用资产 / 债 / 关系 / 头衔  
> → 新冲突从更高的默认起点开始。

四个 CORE 样本证明了三个不同结果：

1. **《高手下山…》：Vertical Causal Ladder**
   - 每次胜利都向上揭出灭门链/权力链；
   - 因而“打脸”和“主线升级”是同一件事。

2. **《凤流高手》：Relationship-Carried Revaluation**
   - 医疗证明嵌在白洁、小姨、洛青禾、前女友等会回返的人际关系里；
   - 反转可留下秘密、信任、求助、情报和口碑；
   - 但当前仍频繁利用“男护士”让新人物低估他，复利还未完全压过 reset。

3. **《重生男护士…》：Professional Skill Accumulation**
   - 身份重估很快成功，医院真的记住他；
   - 但后续发动机更像“下一个护理技能/病人/任务计数”；
   - status fantasy 被专业成长 fantasy 替代。

4. **《医武天下》：Compartmentalized Revaluation**
   - 每个圈子可以单独把他重新定价；
   - 但资产传播不足，新圈子频繁从“你是谁”重新开始；
   - 容易把城市切成许多局部打脸房间。

## 8. Medicine / Martial / Network / Identity：各自承担什么功能

### 医术｜Irreplaceability Engine
医术最适合制造“只有我能解决”，因为：
- 病情有时间压力；
- 高位人物的钱/权力在此刻可能无效；
- 治疗成功天然形成感谢、债务、长期健康追踪与转介绍。

但如果每次都写成：
> 名医说没救 → 主角一句庸医 → 一针救活 → 全场震惊

它会迅速退化成相同证明题。

医术真正的复利价值不是“又救一人”，而是“这个被救的人以后改变了什么”。

### 武力｜Hierarchy Reclassification Engine
武力能最快让外界停止把主角当低位：
- 不需要漫长解释；
- 可直接打断羞辱/控制；
- 非常适合开局快速建立“世界低估了他”。

缺点也最明显：
- 敌人死得太快时，旧关系无法复用；
- 如果每个敌人只是下一只更大的血包，身份上升会变成境界数字上升。

《高手下山…》早期的 premium 在于：对手死亡仍能留下上层线索与机构后果。

### 人脉｜Conversion Engine
人脉决定一次 proof 会不会跨场景：
- 邀请；
- 转介绍；
- 调用资源；
- 情报；
- 保护；
- 背书。

但“师父早就安排好所有大佬”会削弱 Reader 对“社会位置是我自己赚上去的”的因果感。

《医武天下》Ch16 已经出现既有长辈联系人解决问题，这就是典型混杂：
> Reader 难以判断眼前待遇是刚才的医术挣来的，还是开局就预装的。

### 身份 / 头衔｜Memory Compression Engine
这是最容易被“打脸”讨论漏掉的一层。

一个公开身份的功能是：
> 把几十章的证明压缩成一个以后所有人都能识别的先验。

《高手下山…》的“叶家回来”“少帅”“龙帅”“昆仑墟之主”等，本质上都在减少同一层级的 reset：
- 认识这个身份的人不能再合理地把他当普通无名者；
- 想继续制造低位，就必须进入新的地域、机构或世界层级。

这就是“身份反转”能走长篇时最重要的放大器之一。

## 9. Character / Relationship engine

### HIT：旧关系不是鼓掌机器

《凤流高手》
- 白洁第一次被医术帮助后，并未消失；她的婚姻/秘密/与小姨关系继续约束主角。
- 小姨同时是养育者、职业榜样、道德边界，不只是“给主角介绍女角色”。
- 洛青禾的治疗在后续回返。
- 旧对手/认识者到 Ch87 已能转化为“峰哥”式追随和情报来源。

《高手下山…》
- 周若妤的退婚动机不是简单嫌贫爱富，而是风险保护。
- 灭门家庭、母亲谜、师父/师姐网络给冲突提供长期理由。
- 到数百、上千章仍能看到旧婚约、师姐、师父、子女回返。

但必须保留反证：
- 官方相关帖子里有 Reader 明确抱怨多个师姐和女性角色后期戏份少、消失；
- 另一位 Reader 甚至总结“不必记反派，很多活不过20章或变小弟”。

这说明它的 **institution/status engine 很强**，但 **character continuity 并非同样强**。

### WEAK：关系并非完全没有，但更容易变成功能槽

《重生男护士…》
- 护士长、院长、富裕患者确实会根据能力改变行为；
- Ch7医院甚至建立品牌化使用方式。
- 但 Ch20 后可见发动机越来越以技能任务/病例供给组织，关系常成为“给下一项专业展示提供入口”。

《医武天下》
- 唐玥作为核心妻子关系持续存在；
- 但高位人物对主角的重新评价常局部封闭；
- 下一社会圈仍可以重新运行“不知道他是谁”的流程。

## 10. Compounding State：什么必须留下来

从 HIT 与 WEAK 对照，本 Pool 最值得追踪的不是“打脸次数”，而是以下 ledger：

### A. Knowledge State
谁已经知道主角真实能力？
谁仍然不知道？
这个信息为什么没有传播？

### B. Relationship State
谁欠过命/人情？
谁曾经保护过主角？
谁能再来求助，且第二次求助的义务是否更重？

### C. Access State
以前进不去的医院、家族、机构、圈子，现在能否直接进入？
是否仍要每次从门口被保安/前台羞辱重新开始？

### D. Reputation State
“某某神医”“某家的人”“少帅”等称号有没有真实传播范围？
一个头衔影响哪个 jurisdiction？

### E. Resource State
重估以后是否变成：
- 情报；
- 人；
- 钱；
-医疗资源；
-保护；
-位置；
-选择权。

**Reaction shot 不在 ledger 里。**
如果一章结束后只留下“他们震惊过”，状态等于没变。

## 11. Pairwise Hit-vs-Weak Deltas

### Pair A｜《凤流高手》 vs 《重生男护士，开局就是绝活》

#### 两本都有
- 男护士这个显性低位身份；
- 社会对男性护理工作的先验怀疑；
- 真实医疗难题；
- 主角用专业能力完成不可替代证明；
- 医院/患者会改变评价；
- 先前证明都能形成一定 reputation。

#### WEAK 甚至做得更快的地方
- 《重生男护士…》Ch1 就完成第一次证明；
- Ch7 医院已经考虑把他做成品牌；
- 机构记忆明显，不存在“完全不复利”。

#### HIT 的 execution premium
不是“打脸更快”，而是 **低位身份仍然持续有未结算的社会与情感含义**：
- 《凤流高手》的男护士身份源自被竞争者动关系毁掉临床路径；
- 它和旧情敌、前女友、职业理想、养育者榜样一起长期存在；
- 医术证明不会在 Ch1 就把这个问题彻底解决；
- 证明被嵌进会反复回返的人际关系，而不是主要被系统任务吸收。

#### WEAK 的分叉
《重生男护士…》在 Ch7 其实已经把最核心的职业歧视大幅解决：
- 院长要做品牌；
- 别科抢着借人；
- 富裕病人想长期占用他。

Ch20 后主角自己把急救机会理解为“又一单业务”，目标是完成100例任务解锁下一技能。
Ch40 则非常直观地进入：
> 治好一个公认难治病例 → 同科七个相似病人排队。

也就是：
> **身份反转过早结算 → 专业 case / skill loop 接管。**

#### 最早可见分叉
- Ch1–3：两者都建立男护士被低估，但《凤流高手》的低位与长期个人债绑定；control 的原主对护士身份本身并不强烈反抗。
- Ch7–20：control 已大面积获得机构认可，低位矛盾开始退场；HIT 仍在处理旧关系、职业标签和新的社会传播。

#### 到 Ch20 是否持续
是，且方向相反：
- HIT：社会身份问题仍在；
- WEAK：专业技能任务已成为显性发动机。

#### 混杂
- control 是1985年代医疗职场 + 系统文，目标 Reader 有一部分是在吃“医疗专业爽”；
- HIT 同时有多女、都市修真、旧情敌清算；
- 当前在读差不能单独归因于上述机制。

**Pair A confidence：HIGH for mechanism, LOW/MEDIUM for causal performance attribution.**

---

### Pair B｜《高手下山，我家师姐太宠我了》 vs 《医武天下》

#### 两本都有
- 下山；
- 开局已隐藏满级/高能力；
- 医术 + 武力 + 人脉；
- 多女；
- 高位人物；
- 都可以极快完成“你们看错我了”。

#### WEAK 不缺爽点
《医武天下》Ch8：
- 高位秦家出现紧急救命需求；
- 现场普通方案来不及；
- 主角救下人；
- 秦三爷几近下跪，并明确许以“最尊贵客人”等待遇。

这已经是标准、完整、强烈的 Reader Fantasy 付款。

#### HIT 的 execution premium
《高手下山…》Ch3–20 的每次胜利，都不只是获得另一个人的敬畏：
- Ch3打破第一层旧定价；
- Ch7进入江南王层级；
- Ch10打赢后得到更高幕后信息；
- Ch20灭门线已经指向战神级节点。

也就是：
> **身份反转 = 主线因果升级 = 对手层级升级。**

Reader 不需要在“打脸”和“查真相”之间切频道。

#### WEAK 的分叉
《医武天下》Ch8 虽赢得秦家，但：
- Ch10回到唐氏核心环境，唐玥仍不认可其医术；
- 新商务圈仍可从低位看他；
- Ch14对手依旧把他理解成没背景的小人物；
- Ch16又可以调用开局既有长辈关系解决问题。

于是身份资产呈“分区存档”：
> 在秦家很值钱，不代表在妻子/唐氏/江家自动升值。

这会制造大量“新圈层重新证明”的机会，却不一定形成同一社会世界整体上升。

#### 最早可见分叉
**Ch8–10。**
两本都已经证明实力，但：
- HIT 的证明把故事推上同一因果梯子；
- WEAK 的证明更像完成一个局部社会节点，随后返回另一节点重新开始。

#### 到 Ch20 是否持续
- HIT：明确持续，灭门因果仍在上升；
- WEAK：核心婚姻/公司/新家族冲突仍多节点并行，传播有限。

#### 混杂
- 《医武天下》最后更新停在2024，2026 current-read weakness受停更强烈影响；
- 两本作者信用、曝光时代、算法环境不可完全匹配；
- 不能把“1140 vs 31万级”当作机制的因果证明。

**Pair B confidence：HIGH for Ch1–20 structural delta, LOW for performance causality.**

---

### Pair C｜《高手下山…》 vs 《都市之神医下山》

两本 package 极像：
- 下山；
- 神医；
- 未婚妻；
- 都市医武/修真；
- 早期目录都承诺快速证明与身份错配。

但《都市之神医下山》的 Ch1–20 正文当前网页访问不完整，且作品是2021-era完结样本。

只能确认：
- 目录前20章已经出现金针、巨额诊费、不能得罪的人、未婚夫、能打、会治病等典型付款标记；
- 但不能可靠验证这些付款是否留下关系资产、是否传播、是否在Ch20后退化。

因此：
> **它只能证明“相似包装可以弱”，不能证明“为什么弱”。**

不得用它替代 Pair A/B 的因果机制。

## 12. Ch20 后：是不是只剩同一种打脸？

### 《高手下山…》
不是单纯同一种，但有明显重复风险。

变化来源：
- 城市豪门 → 军政/武道机构 → 家族名号 → 昆仑/修炼世界 → 更高世界；
- 母亲/灭门/师父线持续提供因果；
- 头衔与 jurisdiction 逐步扩大。

重复来源：
- “新高位看不起/规则压主角 → 主角杀穿/压服”仍长期存在；
- Reader 评论也直接指出大量反派生命周期很短。

所以它不是消灭了反派队列，而是：
> 用 **世界层级扩张 + 公开身份升级 + 长主线** 把同一种 dominance beat 包进不断变大的 jurisdiction。

### 《凤流高手》
到当前 88章仍是混合状态：
- 有持续关系、口碑、人脉；
- 也会在 Ch50 用“实习男护士”重新让新人物低估他；
- Ch60/63/71 等标题继续保留“治好/一鸣惊人/前女友吃惊”式强反转。

当前证据只能说：
> 它已经出现复利，但还没有证明能摆脱“换陌生人重新低估”的依赖。

### 《重生男护士…》
Ch20 后的风险不是“低智反派排队”，而是：
> **病例 / 技能任务排队。**

它说明 Pool 2 的失败不只有一种：
- 可以退化成打脸流水线；
- 也可以在把低位解决后，退化成专业 case-of-week。

### 《医武天下》
Ch50 再次出现医疗权威认为无解、主角提出不同判断的结构。
这说明“医学不可替代”仍在用，但此前身份资产并未让新专家自动调整先验。

## 13. Reader reaction evidence

Reader 评论只作定性支持，不当代表性样本。

### 《高手下山…》
官方相关帖子中同时存在：
- 强沉浸反应：有 Reader 表述连续阅读后高度代入叶北辰；
- 模式识别：有 Reader 直接总结“反派很多活不过20章或变小弟”，说明敌人快速 churn 是可感知结构；
- 关系投诉：有 Reader 抱怨多个师姐和女性角色后期戏份少、人物消失。

这组反馈与文本观察一致：
> dominance / revenge / status ladder 很强，但人物关系连续性并不自动同强。

### 《重生男护士…》
相关帖子和评论集中称赞：
- 医疗/急诊/护理专业感；
- 男主技术过硬；
- 护理技能展示“引人入胜”。

这反过来支持本报告的 fantasy-drift 判断：
> Reader 实际在消费的显性优势更接近“专业医疗能力展示”，不只是“低位身份被翻转”。

### 《凤流高手》
当前新书，公开可检索的 Reader reaction 样本不足，不做代表性推断。

### 《医武天下》
可检索评论稀少且夹杂搜索推荐污染；不以评论建立结论。

## 14. Failure signatures

本轮证据支持的 failure signature 不是一个，而是至少五个。

### F1｜Local Revaluation, Global Reset
一个家族知道主角牛，但核心妻子/公司/下一个家族仍完全不知道。
每换圈层就归零。

可观察信号：
- 旧高位人物不转介绍；
- 旧声誉不传播；
- 主角还得反复解释自己是谁。

### F2｜Premature Status Resolution → Fantasy Drift
主角很快被医院/机构认可，低位问题在十章内已经实际解决。
后面只能靠：
- 新技能；
- 新病例；
- 新系统任务；
继续制造内容。

这不是“节奏慢”，而是 **太快把本 Pool 的核心社会矛盾吃完了**。

### F3｜Preloaded Network Cannibalizes Earned Rise
师父/长辈一通电话就能解决权力问题。
Reader 看见的是“我本来就有后台”，而不是“我通过前一轮证明赚到了新的社会权力”。

预装背景可以做 acquisition premium，但如果它解决太多问题，会吃掉“社会位置持续上升”的因果满足。

### F4｜Reaction Without State
全场震惊、专家脸黑、美女后悔很多，但：
- 没有新访问权；
- 没有新义务；
- 没有新关系；
- 没有新资源；
- 没有公开身份；
下一章世界状态和之前几乎相同。

这才是最纯粹的“低智反派排队送脸”。

### F5｜Vertical Escalation Without Character Memory
哪怕地位一直抬升，如果旧人物不断消失，关系层仍会变空。
《高手下山…》的 Reader 评论已经给出这一风险反证。

因此“社会位置越来越高”不能完全替代人物关系复利。

## 15. Long-run status ladder：长篇到底靠什么越抬越高

当前最完整的长程样本《高手下山…》显示，长篇身份上升不是靠无限加“更有钱的人”。

更稳的状态变化是：

1. **Personal Name｜名字被重新认识**
   - 从“当年漏掉的叶家幸存者”变成“叶北辰”。

2. **Family / Relationship｜家族名号恢复**
   - “叶家，回来了”。

3. **Institutional Title｜机构头衔**
   - 少帅、龙帅等。

4. **Resource Mobilization｜资源动员**
   - 社会关系开始直接兑现为资金、人力、军政访问权。

5. **Jurisdiction Expansion｜身份适用范围扩大**
   - 一个城市承认 → 更大机构承认 → 新世界/新地域重新定价。

6. **Identity Becomes Premise｜主角本人变成别人必须响应的事件**
   - 后期不再是“证明我不是废物”，而是“这个名字出现会改变各方决策”。

这个 ladder 的核心不是每一层都更夸张，而是：
> **上一层身份会留在账本上，下一层冲突必须解释为什么仍有资格挑战他。**

## 16. Newcomer execution burden

不做打分，只记录实际负担。

### Domain research burden
- 医疗场景如果完全魔法化，Reader 很快只看 reaction；
- 如果写得太专业，又会漂移成医疗案例文；
- 必须能判断“哪些医疗细节用于证明不可替代，哪些只是术语”。

### Logic-consistency burden
最重的是“谁知道什么”：
- A家已经见过主角救人；
- A家与B家是什么关系；
- 为什么B家还能合理地不知道；
- 主角已有某头衔后，保安/医生/富少为什么还敢用旧先验判断他。

### Character burden
每次被救/被压服的高位人物如果下一章消失，社会资产无法复利。
需要让旧关系继续有：
- 自己的利益；
- 自己的风险；
- 对主角的新要求；
- 反过来制约主角的能力。

### Antagonist-intelligence burden
“看不起”必须有信息依据。
如果 Reader 明明知道主角公开身份已经全城皆知，而新反派仍只因衣服便宜就极端羞辱，世界智商会坍塌。

### Long-run escalation burden
必须升级“身份适用范围/jurisdiction”，而不只是：
- 100万富二代；
- 1000万富二代；
- 1亿富二代；
不断加零。

### Scene-generation burden
医术、武力、人脉、身份四个引擎需要换功能，不只是换皮：
- 医术负责不可替代；
- 武力负责边界；
- 人脉负责传播与调用；
- 身份负责记忆与抬高默认起点。

## 17. Substitution space｜只谈市场功能，不生成 Concept

### 已高度饱和的 delivery patterns
- 高手下山；
- 多份婚书；
- 多师姐/师父全是顶级大佬；
- 未婚妻退婚；
- “神医+无敌+多女+杀伐”标题/简介堆叠；
- 名医先否定、主角一针、全场跪服；
- 新豪门不知道前一豪门刚刚已经认主。

### HIT 反复证明 Reader 真正需要的功能
- 一个可以立即理解的 **低位先验**；
- 一个现实压力迫使所有人承认“只有他能解决”的时刻；
- revaluation 必须改变未来行为；
- 社会资产需要可调用；
- 旧关系要带着“我已经知道你是谁”的记忆回来；
- 当 status 已经公开，后续必须换 jurisdiction / institution / stakes，而不能让同层世界失忆。

### 当前供应相对弱的功能
- 反转后真正改变机构流程；
- 被救高位人物在几十章后仍承担义务，而不是只负责一次感谢；
- 声誉跨关系网传播的可观察过程；
- 反派根据合理信息低估，而不是集体失智；
- 旧伴侣/家人/同事在主角升位后自身利益发生变化；
- 医术、武力、人脉、身份之间形成因果接力，而非四套外挂并列。

以上仅是市场功能空间，不推导人物、设定、系统、标题或情节方案。

## 18. Evidence limitations

1. Fanqie current-reader 数据动态变化明显。《凤流高手》V2冻结23.2万，而09-26第三方 tracker约19.6万；只能当动态 performance signal。
2. 《高手下山…》已超2700章，其 current success 同时包含多年积累、算法、作者信用与长尾，不是 newcomer clean proof。
3. 《医武天下》2026页面仍标“连载中”，但最后章节实际停更于2024；当前在读弱不能和2026新书直接做纯执行因果。
4. 《都市之神医下山》正文访问不足且年代过旧，只保留弱包装控制。
5. 《重生男护士…》Ch1–50可深读，但Ch100+正文网页访问受限；只能确认169章完结，不能伪造长程机制。
6. 《全村只有傻子在修仙》官方正文入口未稳定获得，因此只作 SUPPORT signal。
7. Reader 评论是自选择小样本，只用于验证“某种结构确实被读者感知”，不代表总体读者。
8. 当前研究不能证明任何单一机制“导致”某书 20万、30万或低于1000；只能证明机制层的可观察差异与可疑失败路径。

## 19. Pool-only conclusions

### 现在可以证明什么

**P1｜第一次打脸有多早，不是 HIT / WEAK 的充分分界。**
- CORE WEAK 《重生男护士…》Ch1 就完成不可替代证明；
- 《医武天下》Ch8 完成豪门级重估；
- 所以“更快打脸”不能解释 performance delta。

**P2｜社会位置复利的最小单位不是“震惊”，而是未来行为改变。**
真正留下来的东西包括：
- 信任；
- 求助权；
- 转介绍；
- 情报；
- 保护；
-资源；
-机构位置；
-公开头衔。

**P3｜身份反转最危险的两种退化是不同方向。**
- 方向一：每个新圈层世界失忆，主角重复证明；
- 方向二：低位问题十章内被彻底解决，随后漂成病例/技能 case-of-week。

**P4｜HIT 的关键 execution premium 更接近“反转如何连接下一轮”，而不是“这一轮有多响”。**
- 《高手下山…》把胜利、灭门调查、对手层级、公开身份绑成一条 vertical ladder；
- 《凤流高手》把证明塞进会回返的旧关系与职业伤口中。

**P5｜医术、武力、人脉、身份承担的 Reader Fantasy 功能不同。**
- 医术：不可替代；
- 武力：即时层级重分类；
- 人脉：把一次证明跨场景兑现；
- 身份：让世界记住前几十章已经证明过的东西。

**P6｜真正的“长篇社会位置上升”需要 jurisdiction expansion。**
不是永远让同一城市的人失忆，而是：
> 同一层级逐渐承认主角 → 主角获得公开身份 → 进入更高/更大的社会系统 → 新系统有合理理由重新定价。

**P7｜高位人物重新评价以后，是否真实影响后续，是本 Pool 最有区分度的检查项之一。**
如果“救了某首富/大人物”之后：
- 他不再出现；
- 不转介绍；
- 不提供信息；
- 不改变任何机构行为；
那次救人主要只是 reaction scene，不是 status asset。

### 仍然不能证明什么

1. 不能证明《凤流高手》能在 Ch100、Ch300 以后维持当前 relationship compounding；它只有88章。
2. 不能证明《高手下山…》后期2700章的留存仍主要来自“低位身份反转”；后期已经显著变成世界级修炼 dominance。
3. 不能证明《医武天下》或《重生男护士…》弱是由单一文本机制造成；停更、时代、平台流量、作者信用、包装差异都可能显著影响。
4. 不能证明“男护士”本身是高需求题材；本报告只证明同一低位 vehicle 下 execution 可以走向完全不同 fantasy。
5. 不能从少量评论证明 Reader 普遍讨厌/喜欢某一种关系结构。
6. 不能把这些结论外推成其他 Reader Pool 的排序或推荐。

> **What is now proven about this Reader Pool, and what is still not proven?**

现在最稳的结论是：

> Pool 2 的商业核心不是“持续有人看不起主角”，而是“错误社会定价被现实强制纠正，而且纠正结果要写进世界状态”。

真正能把这个 fantasy 从 10章写到长篇的，不是更多打脸对象，而是：
> **social memory + reusable relationships + public identity + jurisdiction escalation。**

仍未证明的是：
> 这些机制单独能否制造爆款，以及哪种具体 delivery vehicle 在2026番茄最优。

本窗口不做该判断。
