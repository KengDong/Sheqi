# REBOOT-V4｜Fanqie Pool 03 诡异反猎杀 Deep Read

## 0. Scope / method

本报告只回答一个问题：

> **为什么有些“诡异降临 / 收容 / 吞噬 / 驾驭异常”作品，能持续把 Reader 从“怪物猎物”带到“连怪物都开始怕我”的体验，而同样承诺驾驭诡异的作品会停在求生、解谜、加技能或换副本？**

本轮不把“规则怪谈火”“悬疑脑洞有大盘”自动当作本 Reader Pool 成立的证据。

方法：
- 以 2026-09-26 已冻结番茄市场信号为 acquisition / performance 起点；
- 对 CORE HIT / CORE WEAK 实读 Ch1 / Ch3 / Ch7 / Ch10 / Ch20；
- 有条件继续抽查 Ch50 / Ch100 / 当前后段；
- 重点追踪四种东西是否永久留下并互相纠缠：**旧异常、旧能力、旧关系、危险身份**；
- 对 weak control 严格记录时代、完结状态、分类、索引漂移等混杂因素，不把“未满1000人在读”直接等同于“开篇写坏了”。

# 1. Exact Reader Pool definition

## 1.1 Reader Fantasy

本 Pool 的精确定义不是“看诡异故事”，也不是“会解规则”。

而是：

> **我先真实处于被猎杀的位置；随后我能把异常收进来、吃下来、养起来、驾驭起来，最终异常不再只是外部敌人，而成为我的身体、身份、能力组合、领地或资产。随着这种状态复利，人类系统与诡异本身都开始把我当成更危险的存在。**

因此必须同时具备两个方向：

1. **Fear line**：世界里仍有真正能威胁主角的异常，恐惧不能在第一次开挂后彻底蒸发；
2. **Dominance line**：主角不是只“活下来”，而是把原本猎他的东西转化成自己可调用、可复用、可继续变化的状态。

## 1.2 不属于精确 Pool 的替代体验

以下可以与本 Pool 共存，但单独出现不能证明它成立：

- 规则解谜；
- 副本生存；
- 单纯升级打怪；
- 系统送固定技能；
- 灵异案件 Case-of-Week；
- “别人震惊主角很强”的反应戏；
- 只有一次的宠物 / 道具收服；
- 单纯的怪物主角皮肤。

最关键的判别问题是：

> **旧异常进到主角一侧以后，后面还会不会继续工作、变形、组合，并改变别人如何对待主角？**

# 3. Core matched pairs

## Pair A

**HIT：**《什么叫我成了灭世级怪谈？》  
**WEAK：**《诡异时代，我无条件驾驭诡异》

共同基线：
- 主角处于诡异危机；
- 都有“异常可以归我使用”的明确商品承诺；
- 都存在规则、组织、人类处理体系；
- 都不是纯现实悬疑。

真正要比的不是“有没有能力”，而是：

> **异常从“外部威胁”跨进“主角永久状态”的速度与深度。**

## Pair B

**HIT：**《诡异世界，我的神通无限升级！》  
**WEAK：**《诡异时代，我无条件驾驭诡异》

共同基线：
- 都是诡异生态；
- 都有从异常获取力量；
- 都有组织 / 地区 / 更强威胁；
- 都能在长篇里继续换遭遇。

真正要比的是：

> **新异常是“新增一个槽位”，还是会继续改造旧身体、旧能力和社会位置。**

## Guardrail pair

**HIT 任一** vs **《诡异复苏：开局解锁八奇技！》**

这个 pair 只回答一个反例问题：

> **反杀足够快，是否已经足够？**

答案是：现有证据不支持。

《八奇技》Ch1–3 已经很快从诅咒猎物翻成强势控制者，甚至让机构忌惮；所以“弱书只是起效慢”不能作为通用解释。

# 4. Shelf / package analysis

## 4.1 《什么叫我成了灭世级怪谈？》

### Acquisition

标题本身就不是“我在怪谈里求生”，而是先把最终身份亮出来：

> 主角会成为“灭世级怪谈”。

简介继续兑现：
- 主角会收容怪谈并获得其能力；
- 主角自身会越来越不像普通人；
- 后期不只人怕他，部分怪谈也会怕他。

陌生 Reader 在开书前已经知道核心消费不是“解一个规则”，而是：

> **我正在从猎物变成怪谈分类里的危险存在。**

### First-screen conversion

第一章先让伪人把主角当猎物，再让主角反杀、拆解、测试。

章节末，异常不是掉一个普通奖励，而是直接进入身体：
- 获得伪人相关身体状态；
- 修复 / 模仿能力成为自己的一部分；
- 镜中形貌发生异常变化。

**Promise-to-payoff delay：Ch1 内完成。**

“谁猎谁”的第一次方向倒置，也在第一章完成。

---

## 4.2 《诡异世界，我的神通无限升级！》

### Acquisition

包材承诺非常直接：
- 杀诡；
- 吸收；
- 提取能力；
- 不断融合 / 进化；
- 最终站在诡异尸骸之上。

它卖的不是“知道诡异规则”，而是：

> **诡异本身就是我的成长材料。**

### First-screen conversion

Ch1 仍先交付脆弱：
- 主角伤重；
- 家庭 / 环境存在尸变恐惧；
- 世界不是安全区。

但 Ch1 末，“尸变力量”已经进入身体，肢体直接怪异强化。

**Promise-to-payoff delay：Ch1。**

它比 Hit A 更偏“肉身与战斗复利”，但同样不把首次收益做成脱离主角的外置奖励。

---

## 4.3 《诡异时代，我无条件驾驭诡异》

### Acquisition

标题和简介其实非常贴本 Pool：
- 别人驾驭诡异要付生命 / 情绪 / 肉身代价；
- 主角“无条件驾驭”；
- 已展示镜、刀等诡异物；
- 包材甚至暗示主角体内有比诡异更可怕的东西。

所以它的货架问题不是“不知道自己卖什么”。

### First-screen conversion

但正文 Ch1–7 的主体验仍是：
- 学校异常；
- 同学死亡；
- 判断杀人条件；
- 逃离 / 生存；
- 解释“只有诡异能对抗诡异”。

主角虽然持有异常物，但 Reader 很长一段时间首先吃到的是 **规则求生**。

到 Ch10，炎刀对主角没有反噬、主角开始确认自己可能拥有“无代价驾驭”的特殊性，核心商品才变得非常清晰。

**Promise-to-payoff delay：约 Ch10 才完成一次干净的 ownership 证明。**

这不是说前九章没有能力，而是：

> **“我已经从猎物变成能把异常稳定纳入自己体系的人”这一体感，形成得更晚。**

---

## 4.4 《诡异复苏：开局解锁八奇技！》作为反例

这本不能被拿来证明“起效慢导致弱”。

Ch1 系统就给出熟悉的强能力；Ch3 已把贞子类异常变成可调用的手下；Ch7 普通低阶诡异已难以构成威胁，机构也开始把主角视为潜在危险者。

即：

> **它的 fear inversion 很快。**

但其核心能力首先来自固定的“八奇技”工具箱，异常更像被克制 / 收服 / 使用的对象，而不是不断反向改造主角身份与旧能力的原料。

这提供一个重要 guardrail：

> **“反杀快”是必要候选机制之一，但不足以单独解释持续追读。**

# 5. Ch1–20 retention ledgers

## 5.1 CORE HIT A｜《什么叫我成了灭世级怪谈？》

| Checkpoint | 实际功能 | Reader Fantasy 交付 | 永久留下什么 |
|---|---|---|---|
| **Ch1** | 伪人先猎主角；主角反杀、拆解、测试并收容 | 第一次恐惧倒置；异常变成自己的身体能力 | 伪人之躯 / 模仿 / 修复；外貌与“人类身份”开始松动 |
| **Ch3** | 模仿不再只复制脸，开始服务潜入、表情与社会行动 | “怪谈能力不是战斗一次性奖励” | 旧能力扩展为社交 / 调查工具 |
| **Ch7** | 怨境成为可进入的异常空间；主角自己意识到越来越像怪谈；人类角色开始怕他的沉默与状态 | 支配感进入关系层 | 异常空间；徐妍静一类持续信息关系；家人保护动机仍在 |
| **Ch10** | 伪人能力支撑“苍白”式身份；强异常仍能威胁主角 | 危险身份形成，同时 Fear line 未消失 | 别名 / 地下身份 / 更高威胁认知 |
| **Ch20** | 清理局关系进入家庭与主角身份周边 | “我是什么”开始影响制度关系 | 机构注意、身份风险、关系约束 |

### Ch20 后复查

目录持续出现：
- 伪人身份被外界追问；
- 新形态并入身体；
- 群体 / 朝拜 / 感染等“怪谈化”尺度扩大；
- “苏远是谁 / 是不是人”逐渐从私域问题变成社会问题。

Ch50 附近已经不只是多一个技能，而出现“如何晋升更高怪谈层级”的明确长期方向。

**结论：** Ch1 的旧异常没有被扔掉。它先是身体能力，再变成潜入工具、社会身份、危险标签与机构问题。

- Ch50：击杀 / 吸收仍然是核心回路；

- 深渊教楼有回返；

## 5.4 SUPPORT HIT｜《诡异：我分身竟是副本灯笼怪》

这个样本证明另一条反猎杀交付路径，但不升为 CORE：

- Ch1：异常分身仍是低位鬼火，会被同类当作食物；
- Ch3：进入烛灵灯，获得明确的“让别人怕我”执念与异常能力；
- Ch10：真身进入副本时，主角已经比普通玩家多了一套副本内部资产 / 情报身份；
- Ch20：其他玩家面对其异常侧的实体与伴随威胁时，已经把它当作需要逃离的危险生态；
- Ch69：分身与进化后的灯笼继续融合；安魂林、蕴灵灯小弟等旧资产仍存在并形成资源生态。

它证明：

> 反猎杀不一定只靠“主角肉身吃怪”，也可以通过异常分身、领地、眷属与副本所有权形成长期支配感。

但因为主角真身与异常分身是双层结构，它只能作为 SUPPORT，不代替两本核心样本。

# 6. Repeatable Reader Fantasy loop

从两本 CORE HIT 与 SUPPORT 中反复出现的，不是：

> 新诡异 → 解规则 → 获奖励 → 下一只。

而更接近以下循环：

1. **可信的猎杀压力**  
   主角先确实可能死，或至少存在无法轻视的更高异常。

2. **主角主动碰异常**  
   观察、测试、反杀、吸收、收容、驯化，而不是全程被动解题。

3. **异常跨过边界**  
   敌人变成身体、能力、分身、领地、眷属或持续资产。

4. **旧状态发生二次用途 / 变形**  
   旧能力不只“伤害+10”，会转去潜入、伪装、威慑、组合、资源生产、关系控制等。

5. **旧关系重新评价主角**  
   家人、同伴、机构、对手对“他还是不是正常人 / 应不应该招惹他”产生持续变化。

6. **世界抬高 Fear ceiling**  
   更强异常、制度压力或系统性危险出现，使“我变怪了”不等于“以后没有恐怖”。

7. **新一轮不是 reset，而是在旧状态树上加复杂度**  
   Reader 追的是“这个人会变成什么”，不只是“下一只怪是什么”。

这就是本 Pool 与单纯规则副本的关键分界。

# 7. Character / relationship engine

## 7.1 HIT A

关系不是纯观众席。

- 家人保护动机让“变怪”带来义务，而不只是爽；
- 徐妍静一类关系从恐惧 / 被压制变成持续情报渠道；
- 清理局不是只负责发任务，它会因为主角身份越来越异常而改变接触方式；
- “苍白”等身份让旧的人际互动受到双重身份影响。

**关系的功能：** 把异常能力从战斗属性转化成信任、恐惧、利用与身份暴露问题。

## 7.2 HIT B

- 家庭成员很早就开始接受“越怪可能越能活”的现实；
- 地区 / 人群逐渐把主角当成能解决更大问题、同时也不能随便招惹的人；
- 后段制度职位与资源供给出现，说明力量改变了社会位置。

**关系的功能：** 怪异成长不仅升级肉体，也升级“别人必须如何与我相处”。

## 7.3 CORE WEAK

《无条件驾驭》并非无人际线：
- 同学 / 同行；
- 749 局；
- 任务关系；
- 新篇章人物。

但 Ch1–20 的人物关系更常承担“共同求生 / 提供信息 / 进入下一任务”的功能。

现有可验证文本里，较少看到：

> **旧关系因为主角越来越不像人，而被持续重新谈判。**

这不是说后文绝对没有，而是目前能够冻结的证据密度明显不足。

# 8. Compounding state

## 8.1 Compounding matrix

| 维度 | 《灭世级怪谈》 | 《神通无限升级》 | 《灯笼怪》SUPPORT | 《无条件驾驭》WEAK |
|---|---|---|---|---|
| 身体 | 伪人之躯及后续怪谈形态 | 尸变→铁僵→大成→乌金→更高怪体 | 真身 / 分身双层 | 主要是“无代价驾驭”的特殊体质线，前20章体感较弱 |
| 旧能力重用 | 模仿→潜入→社交身份→威慑 | 旧神通持续提取、组合、再融合 | 鬼火→灯灵→分身资产 | 镜 / 刀 / 红纱持续携带，但更偏并列资源 |
| 身份 | 人类身份越来越可疑；危险别名 | 从怪人到地区强者 / 危险人物 | 人类玩家 + 副本异常双身份 | 驾驭者 / 组织参与者 |
| 关系 | 家人、情报关系、清理局持续受异常身份影响 | 家庭、地区人群、机构持续重估 | 小弟 / 领地生态 | 同伴 / 机构存在，但复合改写证据较少 |
| 空间/资产 | 怨境等异常空间 | 地区、资源、后续职位 | 安魂林、福地、蕴灵灯小弟 | 异常物与任务资产 |
| 社会危险性 | “是不是人”逐步公开化 | “不要轻易招惹他”逐步稳定化 | 对普通玩家成为副本危险生态 | 有强者认知，但更多跟战力 / 驾驭物绑定 |

## 8.2 关键判别

“复合状态”不是简单数量多。

真正的复合是：

> **A 能力获得后，B 异常到来会改变 A 的用法；A+B 又改变人物关系 / 身份 / 领地；这些改变在 C 事件里继续产生后果。**

两本 CORE HIT 都能看到这种链式残留。

CORE WEAK 也有持续资产，但现有文本更容易观察到“多项资产并列”，而不是高频的跨层重组。

# 9. Pairwise HIT vs WEAK deltas

## 9.1 Pair A｜《灭世级怪谈》 vs 《无条件驾驭》

### 1) 两者都有
- 怪异危机；
- 人类处理体系；
- 主角拥有异常侧优势；
- 后续都能继续接触新诡异。

### 2) HIT 多做了什么
- Ch1 就把第一只猎手变成**自己的身体状态**；
- Ch3 已把旧异常用于非战斗社会行动；
- Ch7 已让异常状态反过来影响旧关系；
- 后续“我是不是人”本身成为持续悬念与社会事实。

### 3) Category baseline
- 血腥 / 怪异威胁；
- 规则；
- 组织；
- 新异常；
- 主角有特殊性。

这些都不能解释差异。

### 4) Execution premium
可观察到的 premium 是：
- **threat → ownership 延迟极短；**
- ownership 不是道具栏，而是**身份 / 肉身级别**；
- 旧能力很快出现二次用途；
- 社会关系会被异常身份改写；
- 后续升级回答的是“我会变成什么危险存在”。

### 5) Earliest divergence
**Ch1 末。**

HIT 已把猎手内化进身体。  
WEAK Ch1–7 的主要体感仍是规则求生，Ch10 才完成非常干净的“我能无代价驾驭”证明。

### 6) Ch20 是否持续
是。

HIT 到 Ch20 已把异常身份和清理局 / 家庭卷在一起。  
WEAK 到 Ch20 有持续镜、刀、红纱和机构入口，但结构更像“多个异常资源归我”。

### 7) Confounders
- WEAK 属于更早 cohort；
- 当前 metadata 检索存在缓存陈旧；
- 两书连载时期与推荐环境不同。

因此结论只能是：

> 上述差异与当前强弱信号一致，不能单凭本 pair 宣称单因果。

---

## 9.2 Pair B｜《神通无限升级》 vs 《无条件驾驭》

### 1) 两者都有
- 从诡异获得力量；
- 更强异常；
- 人类组织；
- 长篇连续遭遇。

### 2) HIT 多做了什么
- Ch1 就开始**肉身融合**；
- Ch3 的收益不是新卡，而是旧肉身继续进化；
- Ch20 仍在同一身体状态链上；
- 中后段多次出现“融合 / 再融合”，新神通会进入旧组合；
- 地位、区域资源、制度位置与个人怪异度一起增长。

### 3) Category baseline
“杀诡、变强、组织、地图升级”本身都只是品类常规。

### 4) Execution premium
- **旧能力可组合，而不是只有收藏；**
- **身体状态是一条连续演化链；**
- 力量会留下社会位置与资源后果；
- Ch50 / Ch100 / Ch132 仍能观察到同一循环，而非前20章噱头。

### 5) Earliest divergence
**Ch1–3。**

HIT 从一开始就让异常进入身体并继续变化；WEAK 的强 ownership 体感更晚。

### 6) Ch20 是否持续
是。

HIT 已进入同一“铁僵”路线的高阶状态。  
WEAK 有多个诡异物，但“新异常重写旧异常”的证据较稀。

### 7) Confounders
同 Pair A；另有叙事重心差异：HIT B 天生更偏战斗成长，WEAK 更偏规则 / 任务。

所以不能把所有差异都归因于单个技巧。

## 9.3 Guardrail delta｜为什么“反杀快”还不够

《八奇技》：
- Ch1 有强能力；
- Ch3 已有异常手下；
- Ch7 已经把低阶诡异当可碾压对象；
- 机构也开始忌惮主角。

所以它并没有“拖十章才爽”。

但 Reader 能辨认出的主要成长单位更接近：
- 熟悉IP能力菜单；
- 解锁更多招式；
- 收服 / 使用怪物；
- 快速压制。

这与“我被异常持续改造成更危险存在”不是同一种复利。

由于它：
- 2024 cohort；
- 已完结；
- 分类是都市高武；
- 依赖《一人之下》式熟悉技能名；

故只能作为 **反例控制**，不能当干净 matched failure。

# 10. Reader reaction evidence

只作定性佐证，不当代表性调查。

## 10.1 《当诡异降临世界，死亡即是终点》

读者评论中可见一种与本 Pool 不同、但同样成立的需求：

- 喜欢普通学生在诡异面前的无力；
- 喜欢主角光环弱、恐惧感不被快速抹掉；
- 也有人同时喜欢能力与兄弟关系。

这说明：

> **“恐惧本身”就能形成强消费。**

因此它不能被拿来证明“反猎杀”成立，反而是本轮的重要负控制。

## 10.2 《诡异时代，我无条件驾驭诡异》

可见评论抱怨集中在几类：
- 前段主角自保手段体感不足；
- 深渊教楼停留过久产生重复感；
- 有读者觉得人物群在灵异环境中过于吵闹，削弱驾驭者气质。

这些评论与正文观察一致：
- ownership payoff 形成较晚；
- 同一生存场域延续较久；
- 人物语气可能稀释危险身份感。

但样本评论数量有限，只能用作旁证。

## 10.3 《诡异复苏：开局解锁八奇技！》

可见评论同时出现：
- 认可融合题材、节奏快；
- 但认为八奇技与诡异世界存在违和；
- 技能过多难记；
- 推进过急，像把更长篇幅压缩进较短章节；
- 强度膨胀后需要不断换环境。

这些反馈支持一个更具体的风险：

> **固定工具箱越强，不一定越能形成“诡异反向改造我”的沉浸；也可能逼迫故事靠换地图 / 换更强敌续命。**

仍不作因果定论。

# 11. Failure signatures

本轮实际观察到的 failure signatures，不是预设清单照抄。

## 11.1 Fantasy substitution

包装说“驾驭诡异”，正文早段却主要交付：
- 规则解释；
- 求生；
- 跑图；
- 团队讨论。

不是这些内容不能写，而是它们若长时间占据第一消费位，会把 Reader 从“我要反猎杀”带回“我要过副本”。

## 11.2 Inventory growth instead of state growth

表面上能力越来越多，但结构是：
- 新镜；
- 新刀；
- 新纱；
- 新宠物；
- 新技能。

如果旧资产只继续存在、不改变新资产，也不改变身份 / 关系，那么它更像库存而不是复合状态。

## 11.3 Fear collapse

另一极端是 Ch1–3 就把普通诡异全部做成沙包。

《八奇技》证明“快爽”可以非常快，但当低阶怪迅速失去威胁，故事容易把压力转成：
- 更大地图；
- 更高等级；
- 新组织；
- 新BOSS。

如果没有持续的异常代价 / 身份危险 / 社会后果，恐怖线就会被升级线吃掉。

## 11.4 Reaction-shot replacement

旁人说“他太危险了”不等于危险身份成立。

强书里危险性会导致：
- 别人改变合作方式；
- 机构改变对待方式；
- 旧关系产生恐惧 / 依赖 / 试探；
- 主角必须管理身份暴露。

如果只有惊呼，状态并没有真正复利。

## 11.5 Modular arc handoff

“新副本→新规则→新奖励”不是天然失败。

真正的问题是：

> **上一个副本结束后，除了数值与一件新东西，还有什么会在下一个副本继续制造因果？**

CORE HIT 的答案很多。CORE WEAK 当前可验证答案相对少。

# 12. Newcomer execution burden

不做评分，只描述负担。

### Domain research burden
**中高。**

不一定非要写极复杂规则，但异常必须有可感知的一致性。只靠“作者想让它恐怖所以它恐怖”会让收容 / 驾驭失去可信度。

### Logic-consistency burden
**高。**

一旦异常成为主角资产，就必须记住：
- 触发条件；
- 限制；
- 代价；
- 旧能力之间的组合关系；
- 为什么某次能用、某次不能用。

复合状态越强，记忆负担越大。

### Scene-generation burden
**高。**

最容易偷懒成：
> 新怪 → 新能力 → 下一只。

真正难的是让旧异常在完全不同的场景重新产生价值。

### Character burden
**中高。**

核心配角不能永远只负责：
- 尖叫；
- 震惊；
- 解释组织；
- 发任务。

他们需要因为主角越来越异常而产生独立的恐惧、利益、信任与选择。

### Long-run escalation burden
**高。**

必须同时做两件相反的事：
1. 主角越来越支配；
2. 世界仍越来越值得怕。

只完成其中一边，都会离开本 Pool 的核心张力。

### Platform sensitivity
前段非常敏感。

如果包材明确承诺“收容 / 驾驭 / 吞噬”，但前7–10章主要还是普通规则求生，Reader 可能在核心商品第一次清晰兑现前就完成题材归类。

### 常见新手失败模式
- 先解释世界几十页，再让能力工作；
- 能力数量多，但没有旧能力回返；
- 每个诡异都是一次性 Case；
- 主角太快无敌，恐怖消失；
- 靠旁人震惊模拟危险身份；
- 强度失控后只能不断换地图；
- 配角不因主角怪异化而改变；
- 组织只负责发任务。

# 13. Substitution space

本节只谈 **market function**，不生成 Concept。

## 13.1 已高度重复的 delivery pattern

- 新诡异事件 → 找规律 → 击杀 / 收服 → 新物品；
- 系统面板再加一个命名技能；
- 新副本 / 新地图替换旧场景；
- 新组织做世界观扩张；
- 配角反复确认“主角很强”。

## 13.2 两本 HIT 反复证明的 reader function

- 开局必须先有可信的 prey pressure；
- 第一次 ownership reversal 不能太晚；
- 异常最好进入“我是谁”，而不只是“我有什么”；
- 旧异常需要二次、三次用途；
- 别人必须因为主角状态而改变行为；
- 中后段仍要有比主角更高的恐惧天花板；
- 新收益最好修改旧状态，而非平行加法。

## 13.3 当前证据中相对稀缺、但强书已经证明有效的 function

- **旧能力 × 旧关系**：同一个能力再次出现时，关系已经不同；
- **旧异常 × 新异常**：不是多一个槽位，而是产生融合 / 形态变化；
- **危险身份 × 制度**：机构不是单纯发任务，而是必须重新定义主角是什么；
- **支配感 × 恐惧感共存**：主角越来越像怪，但世界并没有因此变成无风险刷怪场。

这类“复合状态函数”比单纯新增怪物更难复制，因此也是本 Pool 最需要继续验证的长期能力。

# 15. Pool-only conclusions

本轮可以把“诡异反猎杀”与“规则怪谈”正式拆开。

## 已证明

### A. 当前番茄确实存在“反猎杀”直接样本，不只是规则大盘的影子

两本 2026 current/recent CORE HIT 都把核心商品写进前段正文，而不是只靠标题：
- 一条是“收容后自己越来越像怪谈”；
- 一条是“杀诡后把诡异持续融合进身体与神通”。

SUPPORT HIT 又证明异常分身 / 领地资产化也能交付相近幻想。

### B. 第一屏的关键不是马上无敌，而是尽快完成第一次“所有权变化”

强样本先让 Reader 感到威胁，然后很快让猎手跨过边界：
- 变成身体；
- 变成可调用能力；
- 变成持续资产。

这是“反猎杀”真正第一次付款。

### C. “复合状态”是现有强弱对切里最重要的持续差异之一

强样本不是：
> 今天多一个技能，明天再多一个。

而是：
> 旧异常继续工作 → 被新异常 / 新场景改变 → 又改变身份、关系、机构位置。

这使 Reader 追的是一个越来越复杂的危险存在，而不是一本异常图鉴。

### D. 恐惧不能被支配感吃掉

长程强样本始终保留更高威胁。

所以理想体验不是：
> 我无敌，所以怪都不可怕。

而是：
> **我已经成了怪物害怕的东西，但我知道这个世界还有能吃掉我的东西。**

### E. “快反杀”不是充分条件

《八奇技》提供了必要反例：
- 反杀很快；
- 收服很快；
- 机构忌惮也很快；
- 但当前弱信号仍然存在。

因此不能把方法论简化成“前三章更爽”。

更有解释力的差异是：
- 力量来源是否真来自当前诡异；
- 是否改写身体 / 身份；
- 旧能力是否组合；
- 旧关系是否因怪异化而变化；
- 中后期是否仍有 Fear line。

## 仍未证明

- 不能证明“复合状态”单独导致商业成功；样本规模太小且 cohort 有差异。
- 不能证明哪一种收容形式最适合新人；本轮禁止做跨 Pool / Concept 选择。
- 不能证明所有规则副本都弱；LONG CONTROL 反而说明纯恐惧 / 求生可以非常强。
- 不能证明“越怪越好”没有上限；如果人性关系完全消失，也可能失去持续情感锚。
- 不能证明两本 HIT 的中后期都已经过完整百万字压力测试；Hit A 当前仅66章，Hit B 133章。
- 不能把一个 under-1000 matched weak 当成普遍因果规律。

> 本轮最可靠的市场结论不是“诡异题材能写”，而是：  
> **当作品承诺“从猎物变成异常捕食者”时，Reader 需要尽早看到异常所有权发生变化；而真正支撑 Ch20 以后继续追的，是旧异常、旧能力、旧关系与危险身份不断发生复合，而不是单纯新增副本、规则或技能。**

**What is now proven about this Reader Pool, and what is still not proven?**

已证明的是：当前番茄存在可核验的直接反猎杀需求；强样本会把“恐惧→所有权→危险身份→复合状态”做成持续循环，并保留更高恐惧天花板。  
仍未证明的是：哪种具体包装或设定应被采用，以及上述机制各自的独立因果权重；这些问题不能由本 Pool 的有限样本越界回答。
