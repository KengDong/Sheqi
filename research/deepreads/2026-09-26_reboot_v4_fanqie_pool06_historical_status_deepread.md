# REBOOT-V4｜Fanqie Pool 06 Deep Read
## 古代身份困局：高压等级社会中的地位与自主权上升

> Author status remains **MAYBE**.  
> 本报告只回答 Pool 6 的市场与执行机制，不推荐作者选择，不与其他 Pool 排名，不生成 Concept。

# 0. Pool-only answer first

这个 Reader Pool **真正反复出售的核心，不是“历史感”本身，也不是“科举 / 升官 / 穿越古代”本身**。

更准确地说，它出售的是：

> **在一个身份会真实决定“谁可以命令我、羞辱我、打我、抓我、饿我、替我决定婚姻和去处”的高压等级社会里，主角把一份随时可能被剥夺的人生，一点点换成别人不能随便拿走的权利、关系、财产、社会承认和行动自由。**

历史感不是无关紧要的皮。

它的作用更像：

> **让“身份差一层，权利就差一层”这件事可信、具体、昂贵。**

强样本的关键不是“主角官越来越大”，而是每一次升级都改变一个 **permission matrix / 权利矩阵**：

- 谁还能直接命令他；
- 谁还能合法或半合法地惩罚他；
- 谁要对动他承担成本；
- 他能自己决定哪些事情；
- 他能保护哪些人；
- 他能支配哪些钱、住处、人手与公共资源；
- 哪些社会关系开始承认他；
- 哪些资产下一章不会自动清零。

因此，本池最重要的分析单位不是“官职名”，而是：

> **Status / Autonomy Asset：身份资产与自主权资产。**

# 1. Exact Reader Pool definition

## 1.1 INCLUDED

本池要求至少同时存在：

1. **具体的身份困局**  
   不是抽象“古代很压迫”，而是开局就能说清楚：谁能处置主角、主角为什么不能说走就走、拒绝会失去什么。

2. **身份 / 自主权可积累**  
   赢一次后必须留下东西，例如：
   - 户籍 / 身份合法性；
   - 宗族位置；
   - 独立门户；
   - 功名 / 官身；
   - 财产与住所；
   - 师承与政治庇护；
   - 婚姻决定权；
   - 家族话语权；
   - 被国家 / 地方制度承认的程序性保护；
   - 能保护亲近者的能力。

3. **升级改变别人对主角的权限**  
   “所有人震惊”不是身份升级。  
   “原来能随便抓，现在必须请；原来能随便饿，现在必须顾忌名声；原来父亲一句话可决定去留，现在宗法关系已被改写”才是。

4. **旧压力会回来测试新资产**  
   否则每次升级只是一次性打脸。

## 1.2 EXCLUDED / NEAR

以下都可能是 Vehicle，但不自动属于本池：

- 历史；
- 穿越；
- 科举；
- 权谋；
- 三国；
- 抄诗；
- 朝堂；
- 官场。

一个主角即便一路中状元、当大官，如果前后只是“更高头衔 + 更大舞台”，而不是读者能感知到生活控制权变化，也不能把它直接当作本池证明。

# 3. Core matched pairs

## Pair A
### 《冒姓琅琊》 vs 《科举之路从童生开始》

两者都有：
- 现代人进入古代；
- 历史知识；
- 无系统；
- 古代身份阶梯；
- 士人 / 科举 / 制度环境。

真正分叉在 Ch1 就出现：

> 《冒姓琅琊》：身份不存在 = 当下生存危机。  
> 《科举之路》：没有功名 = 未来生活质量问题。

前者的每一次制度知识都在回答：

> **我现在会不会被抓、被杀、被识破、被当成没有来历的人？**

后者前 20 章主要回答：

> **我怎么准备考试、改善家庭经济、进入考试流程？**

这是同 Vehicle 下完全不同的 reader pressure。

## Pair B
### 《魏家孽种成首辅，全族跪求我认祖》 vs 《穿越明朝考科举之穷山恶水出名臣》

两者更接近：

- 主角都处于受限的古代身份结构；
- 都把“读书 / 科举”当成逃离低位的路径；
- 都承诺长期身份上升；
- 都不是单纯战力升级。

但核心分叉是：

> 《魏家孽种》从 Ch1 就让“身份低 / 权利被压”以一个具体家庭权力结构作用在主角身体、食物、衣物、尊严和行动上。  
> 《穷山恶水》虽然简介明确说想用秀才换免役、见官礼法等权利，但前 17 章仍以农家生活、食物、节令、家庭事项为主，到 Ch18 才明确把“考科举”变成主角行动目标。

也就是说：

> 一个是 **先让 Reader 亲身欠下自主权，再不断偿还**；  
> 一个更像 **先描述生活，再告诉 Reader 未来某个功名会带来自主权**。

# 4. Shelf / Package analysis

## 4.1 《冒姓琅琊》

最强 package 信息不是南齐、门阀或文献量，而是连续三个零：

- 原主记忆：无；
- 身份：无；
- 物资：无。

随后马上把南方门阀写成“权力网络”。

这使陌生 Reader 在点开前就知道：

> 主角不是来“用现代知识碾压古人”的；他首先是一个在身份社会里连“自己是谁”都无法证明的人。

**Acquisition function：**
- 古代身份不是背景；
- “没有身份”就是危险源；
- 冒姓不是装逼桥段，而是第一件生存工具。

## 4.2 《魏家孽种成首辅，全族跪求我认祖》

简介把困局拆得极具体：

- 降生即被视为灾星；
- 父亲厌弃；
- 兄长 / 继母敌意；
- 十年偏院；
- 冬衣、灯火、资源都能被家庭权力控制。

然后直接给出主角的工具：

> 笔、规矩、礼、法、君恩、臣节。

这不是泛泛“科举逆袭”。

它在 shelf 上已经承诺：

> **我会用这个社会自己的规则，把这个社会施加在我身上的权力一点点反转。**

## 4.3 《我家世代提刀，到我这儿提笔了！》

它 package 很强，但不是最纯本池：

- 主角开局就是侯府世子；
- 真正低的是社会评价与政治安全；
- “买状元 + 武勋家庭厌文”制造死局；
- 第一轮翻盘是诗会里的名声重估。

因此它证明的是：

> “社会重新定价我”在历史古代里本身有强需求；

但它不能单独证明：

> “从没有权利到获得权利”是它的主要引擎。

## 4.4 《穿越明朝考科举之穷山恶水出名臣》

这是一个很重要的 weak lesson：

它的简介其实把本池承诺说得非常准确：

- 不想服劳役；
- 想考秀才；
- 见官礼法变化；
- 免役；
- 粮税变化；
- 可支配奴仆；
- 看到地方权力滥用后提高目标。

**问题不在“没有 Reader Fantasy”。**

问题在：

> 这份 Fantasy 在 package 里比在前 20 章里更早、更清楚。

## 4.5 《科举之路从童生开始》

package 的核心是：

> 农家子 + 科举史研究者 + “先考个童生”。

它承诺的是“功名进度”，不是“我要从谁手里拿回什么人生”。

这会把期待天然导向：

> 考试准备 → 考试 → 名次 → 下一次考试。

因此它是很好的 Vehicle negative control：

> **科举可以有状态增长，但不自动等于身份困局 Reader Fantasy。**

# 5. Ch1–20 retention ledgers

## 5.1 CORE HIT A｜《冒姓琅琊》

### Ch1
- 开局位置：现代人醒来，无原主记忆、无身份证明、无资源。
- 第一欲望：先判断时代与危险，不是先发财。
- 第一选择：不跟其他穿越者一起沉浸“抄诗就能成功”的幻想，而是先处理语言 / 身份 /生存逻辑。
- 屏末压力：眼前的人与武力体系能直接决定生死。
- Pool delivery：**身份空白第一次被 Reader 感到是致命缺陷。**

### Ch3｜“冒姓”
- 武装人员拥有即时拘押 / 伤害能力。
- 其他人的常规现代爽文办法不能解除这种权限。
- 主角抛出“琅琊王氏”身份主张后，对方立刻必须重新计算动手成本。
- 关键：身份还没被证实，但已经开始改变别人的行为。

**第一次身份改善不是“升官”，而是：**
> 从“可以直接处理的无名之人”，变成“处理错了可能惹上世族的高风险对象”。

### Ch7
- 士卒开始以“公子”规格照料 / 接待；
- 同时仍有人担心身份可能为假。
- 这是很重要的中间态：
  - 权利已经改善；
  - 合法性仍脆弱；
  - 因此 story pressure 没消失。

### Ch10
- 官吏 / 文书体系开始围绕身份真伪做风险判断。
- 他们并非被“主角气场震住”，而是担心真的得罪琅琊王氏会反噬自己。
- Pool delivery：
  > **主角的身份已经变成别人的职业风险。**

### Ch20
- 地方小权力人物听到“琅琊王氏公子”后态度明显改变；
- 旁人的传播与见证开始为身份提供社会证明。
- 但它仍非完整合法身份。
- Ch1→Ch20 非重置资产：
  - 一批见证者；
  - 已经发生过的优待与称呼；
  - 社会关系；
  - 主角对制度与人情的实际判断记录；
  - 一个越来越难被简单当成“无名黑户”处理的社会位置。

### Long-run check
**约 Ch50：**
- 户籍问题仍没有被魔法般解决；
- 主角需要通过学识、关系、谈判去处理“合法身份”。
- 说明最初的冒姓爽点没有被作者当成一次性 gimmick。

**约 Ch100：**
- 主角已经能推动地方案件 / 借用关系；
- 但更深的地方网络仍可能让对手迅速脱身。
- 说明身份资产是“增加筹码”，不是“获得无敌豁免”。

**Long-run survival：**
- 目录继续反复出现谱牒、核籍、真假琅琊、赐婚、封职等身份节点。
- 身份合法性、家族承认、国家承认没有在第一卷用完。

## 5.2 CORE HIT B｜《魏家孽种成首辅，全族跪求我认祖》

### Ch1｜“落地即罪”
- 正式身份：魏家嫡脉中的孩子。
- 实际权利：远低于这个名义身份本应拥有的水平。
- 父亲 / 家庭可以通过住处、食物、衣物、教育、召见等方式控制他。
- “灾星”叙事让这种剥夺被家庭合理化。
- 主角第一次反制，不是得到官职，而是利用清贵家族最怕的“名声 / 礼法成本”，逼出最低限度的生存待遇。

**第一笔 payoff：**
> 不是“全家跪了”，而是“他们不能完全按照想怎么养就怎么养的方式对待我”。

### Ch3–7
- 礼法开始从压主角的东西，变成主角反过来约束低层亲族 / 仆从越界的工具。
- Ch7 直接出现“我乃魏家嫡脉”式的边界声明。
- 关键不是台词强，而是：
  > 家族等级中某些人原本可以靠主人默许欺负他，现在这种行为可以被重新定义为“以下犯上 / 伤魏氏体面”。

### Ch10–13
- 冲突进入中堂 / 家族公开裁判空间；
- 告状、跪不跪、恶仆辱主应不应该受罚都变成“规则谁说了算”的争夺。
- 主角把私人受辱转写成魏氏自己也不能随便否认的礼法问题。

### Ch14–20
- “百年名声”“流言”“谁家烈子”“拜师宴”等把评价权从魏家内部移向外部公共网络。
- 到 Ch20，主角还没有完全脱离父亲 / 宗族；
- 但魏家已经不再能独占“这个孩子是什么人”的定义权。

**Ch1→Ch20 非重置资产：**
- 外部见证；
- “烈子 / 有才”类公共声望；
- 可进入更高社会关系的入口；
- 一套已经被他成功调用过的礼法武器；
- 忠诚旧仆关系没有消失。

### Formalization after Ch20
真正重要的第一轮 **永久性自主权跃迁** 不是“诗写得更好”，而是随后连续发生的：

- 过继；
- 开祠；
- 承祧；
- 分宗；
- 改命；
- 离家；
- 独立居所。

这批变化的共同效果是：

> **父亲 / 原家庭对他的直接支配权，被宗法程序重写。**

### Long-run check
后续状态不是只剩“再考一次”：

- 拜师：获得独立于魏家的知识与政治庇护网络；
- 皇帝赐字 / 赐物：国家最高权力形成显性信用；
- 功名：获得制度承认；
- Ch100 左右面对抓捕时，解元身份、君赐物、师门关系让执法者改变程序：从想直接上枷，到必须顾忌举人身份并以“请”处理；
- 婚姻与赐聘：婚姻选择也被拉入自主权资产；
- 授官：进入正式国家身份。

最重要的是：

> Ch100 的身份资产并没有让他“不能被抓”，而是让国家暴力不能再以 Ch1 那种任意方式落在他身上。

这就是 sticky but not invincible。

## 5.3 CORE WEAK A｜《穿越明朝考科举之穷山恶水出名臣》

### Package
它其实明确承诺：
- 秀才后见官礼法改变；
- 免役；
- 税负变化；
- 可支配仆役；
- 再通过举人 / 探花 / 官职继续扩大身份。

所以它不是“不懂 status asset”。

### Ch1–10
目录重心依次落在：
- 胎穿；
- 食物 / 山货；
- 家庭生活；
- 节令；
- 亲族；
- 地方见闻。

Ch7 有“设县告示”等制度背景，但仍未把主角本人置于一个必须立刻改变权限的身份死局。

### Ch11–17
继续是：
- 家事；
- 争水；
- 夏收；
- 税赋；
- 食物加工等。

其中税赋当然能表现底层制度压力，但 pressure 仍主要落在家庭 / 环境层，不是“某个具体权力关系现在就能处置主角”。

### Ch18
目录才出现：
> “陈远文要考科举”

也就是说，真正把“身份逃生路径”变成主角主动选择，已经到 Ch18。

### Ch20
仍处于家庭 / 亲族段落；
- 尚未出现一次正式身份变化；
- 也没有可确认的“某类人现在不能再这么对我”的权利变化。

### Later

> 最有价值的 Reader Fantasy 被推迟到了“未来会考上以后”。

# 7. Repeatable Reader Fantasy loop

强样本可抽象成下面这个循环：

> **身份压力具体落身 → 主角读懂规则 / 人心 → 做出行动 → 对方重新计算“还能不能这样对他” → 获得一份可留存的身份 / 关系 / 权利资产 → 旧权力换一种方式回来测试 → 主角用旧资产 + 新行动再扩一层。**

这个循环与“打脸”最大的差别是：

### 打脸循环
> 看不起 → 展示能力 → 震惊 → 下一批人继续看不起。

### Status / Autonomy 循环
> 对方原本真的拥有某种处置权限 → 主角改变条件 → 对方以后再行使该权限的成本 / 合法性 / 可行性永久改变。

所以强书可以反复写 20+ 次，而不只是换一批围观者。

# 8. Protagonist engine

## 《冒姓琅琊》
主角的重复性发动机不是“我要当大官”。

而是：

> **我必须不断判断：在当前制度和关系网里，我怎样才能先不被当成无主之人处理，再让临时身份变成越来越真实的社会位置。**

因此知识不是装饰：
- 语言；
- 文献；
- 门阀；
- 户籍；
- 士人评价；
- 地方行政；

都直接与“我是什么人”绑定。

## 《魏家孽种》
发动机也不是“我要把魏家都打脸”。

更接近：

> **我不接受别人单方面定义我是什么、我能得到什么；我要把他们自己宣称遵守的礼法规则变成我的边界。**

这让故事在离开魏家后仍然可以继续：
- 礼法；
- 功名；
- 师承；
- 君臣；
- 婚姻；
- 官身；

本质上都是新的“谁有资格决定什么”。

# 9. Character / relationship engine

本池强书有一个非常重要的关系特征：

> **配角不是围观主角身份上升的人；配角本身就是身份是否成立的执行者、见证者、受益者、威胁者。**

## HIT A
- 官兵决定是否按“普通可疑人”处理；
- 小吏决定是否冒险得罪可能的门阀公子；
- 收留者 / 同伴承担主角身份失败的外溢风险；
- 士人可以为合法身份提供新的通道；
- 地方势力会用自己的网络证明“你有身份也不是无敌”。

旧人回来时，Reader 能看到：

> 上一次之后，双方之间到底有什么永久改变。

## HIT B
- 父亲：最初是直接支配者；
- 兄长 / 继母 / 亲族：争夺家内资源与定义权；
- 老仆：主角最初能保护 / 被保护的关系资产；
- 外部士人 / 师者：把评价权从魏家内部搬出去；
- 皇帝 / 官府：把私人身份逐步变成公共制度身份。

“过继 / 分宗”之所以比一场打脸重要，就是因为：

> 它永久重写了父子 / 宗族关系里的权限。

## Weak difference
《科举之路》的家人本来就支持主角。

这不是人物写得差，而是它意味着：

> 家庭关系主要提供温情和资源，不持续制造“我能否自己决定人生”的冲突。

因此它天然更容易把主要进度压到考试。

# 10. Compounding state

本池不能只做单一“官阶经验条”。

至少要把状态拆成多个可累积轴：

1. **Legal / registry**：有没有合法身份、户籍、程序保护；
2. **Household / lineage**：谁是法律 / 宗法意义上的父、家、宗支；
3. **Property / residence**：有没有自己能控制的住所、钱、产业；
4. **Public reputation**：别人如何公开定义他；
5. **Patronage / network**：谁愿意为他承担成本；
6. **Credential / office**：功名、官身、国家承认；
7. **Marriage autonomy**：婚姻是谁决定；
8. **Protection radius**：他只能保自己，还是能保一个仆人、一家人、一批人。

强样本的复利不是：

> 童生 +1 → 秀才 +1 → 举人 +1。

而是：

> 一条轴的改善，让另一条轴有了可能；多条轴叠起来后，旧敌人即使仍比他强，也不能把他完全打回 Ch1。

# 12. Reader-reaction evidence

Reader reactions只作 qualitative support，不作代表性统计。

## 《冒姓琅琊》
番茄站内可见评论 / 推书帖里反复出现：
- 历史资料扎实；
- 制度 / 风俗真实；

- “无身份 / 冒姓 / 户籍”带来生存压力。

1. 历史质感；
2. 身份困局真实到足以让人担心主角活不下去。

不能据此说所有 57 万读者都因为“身份自主权”留下，但它支持：

> 历史研究与 Reader Fantasy 在强样本里不是分开的两个模块。

## 《魏家孽种》
可见站内评论中：
- 有读者明确说一口气读到最新、希望保持“爽文”；
- 也有读者批评后期人物性格割裂。

这至少提醒：

> status compounding 不能替代人物一致性；长程 Reader 仍会因为人物失真退出。

# 13. Failure signatures

本轮能较有把握识别的失败形态不是“科举不好看”，而是以下几类。

## F1｜Promise only in synopsis
简介说：
> 中秀才以后能免役 / 不跪 / 有特权。

正文却很久没有让 Reader 看到：
> 今天因为没有这个身份，具体失去了什么；今天争到一点以后，具体改变了什么。

结果是 Reader Fantasy 变成未来券。

## F2｜Status as noun, not permission matrix
只写：
- 童生；
- 秀才；
- 举人；
- 进士；
- 官职。

却不写：
- 谁因此不敢再打他；
- 谁必须改称呼 / 改程序；
- 他能否搬出去；
- 家产由谁控制；
- 婚姻由谁决定；
- 他能否保住某个人。

这会让“身份升级”退化成 UI 数字。

## F3｜Exam-gated progression
所有永久变化都只能等下一场考试发放。

后果是：
> 准备 → 考 → 榜单 → 反应 → 再准备。

中间的人物关系很难自产生新的 Reader 欲望。

## F4｜Reaction-shot inflation
围观者一次比一次震惊，但他们下一章对主角仍拥有和之前一样的权限。

这是 reputation theatre，不是 autonomy accumulation。

《我家世代提刀》前 10 章的诗会强烈依靠社会重估，因此它作为 SUPPORT HIT 反而提醒：

> 社会评价可以非常好看，但如果本池要长期成立，还必须继续把评价兑换成关系 / 权利 / 选择。

## F5｜Hierarchy disappears after first escape
一旦主角离家 / 中榜，旧家族、旧债、旧承诺彻底消失。

强样本相反：
- 《冒姓琅琊》冒姓后很久仍要解决户籍与合法性；
- 《魏家孽种》离开偏院后，宗法、师门、君臣、执法又不断产生新的身份压力。

## F6｜History encyclopedia substitutes for pressure
制度解释很多，但制度没有改变角色下一步能做什么。

历史知识只有在变成：
- 风险；
- 边界；
- 代价；
- 选择；
- 社会反应；

时，才服务本池 Fantasy。

---

# 14. Why HIT status upgrades remain reading assets

强书有三个共同点。

## 14.1 Sticky, not invincible
身份资产不会下一章清零，但也不是无敌证。

《魏家孽种》Ch100 的典型性就在这里：

> 功名 / 君恩 / 师门让执法者不能随便上枷，却没有让主角获得“法律免疫”。

所以 Reader 同时得到：
- “我真的比以前安全了”的满足；
- “更高权力仍能压我”的后续压力。

## 14.2 Old pressure returns with changed terms
旧人回来，不是重新打一遍同样的脸。

Reader 会比较：
- 上次他能让我跪；
- 这次还行不行？
- 上次我只能保自己；
- 这次我能不能保住身边人？

这种比较天然让旧关系拥有复利价值。

## 14.3 Upgrades cover different life domains
强样本不会只换更大的官。

可见升级包括：
- 身份真伪；
- 户籍；
- 宗法父子关系；
- 独立住所；
- 师承；
- 功名；
- 君恩；
- 执法程序；
- 婚姻；
- 官身；
- 保护范围。

因此 100 章后仍然可以是“同一种 Fantasy”，却不是同一件事重复。

# 15. Newcomer execution burden

本节只描述负担，不做跨 Pool 排名。

## 15.1 Domain research burden
**高。**

真正困难的不是背朝代年号，而是知道：
- 某个身份当时实际拥有什么权利；
- 宗族 / 家庭 / 地方官 / 士人之间谁能管谁；
- 户籍、功名、宗法、婚姻、财产、刑名的后果；
- 哪些礼法只是面子，哪些能实际限制行为。

错误一旦触及“谁能合法做什么”，会直接破坏本池核心爽感。

## 15.2 Logic-continuity burden
**高。**

必须长期维护 Status / Autonomy Ledger。

一旦 Ch40 已经分宗独立，Ch80 还让原父亲像 Ch1 一样一句话就能随意处置主角，却不给制度理由，Reader 会感到前 40 章白升级。

## 15.3 Scene-generation burden
需要不断生成：
- 家内；
- 乡里；
- 学校 / 师门；
- 官府；
- 士林；
- 婚姻；
- 财产；
- 公共声誉；

不同场域里的权限冲突。

只会写考场就很快线性化。

## 15.4 Character burden
配角必须拥有：
- 自己的身份；
- 自己能行使的权限；
- 自己承担的政治 / 家族 / 名誉成本。

否则所有人只会排队低估主角。

## 15.5 Long-run escalation burden
升级不能只靠“官越来越大”。

需要回答：
> 同样是拿回人生，为什么 Ch100 的问题比 Ch10 大，但又还是同一本书？

强样本给出的办法不是答案模板，而是一个市场函数：
> **扩大主角要控制的人生领域与保护半径。**

## 15.6 Platform sensitivity
番茄 shelf 很快。

如果 title / synopsis 只写“穿越某朝考科举”，陌生 Reader 很难在同类拥挤中立刻知道：
> 这一次我到底要从谁手里拿回什么。

# 16. Market substitution space
## 只写市场功能，不转成 Concept

## 16.1 Overused delivery patterns
当前历史古代常见且拥挤：
- 农家子科举；
- 庶子逆袭；
- 抄诗 / 诗会翻盘；
- 三国 / 大明熟 IP；
- “一路中榜一路升官”；
- 全场震惊式才名重估。

## 16.2 Repeated reader functions proven by HITs
市场已证明能反复消费的功能包括：

1. **身份压力必须可触摸**  
   不是“社会封建”，而是“这个人今天真能这样处置我”。

2. **主角要会读规则，而不只是背知识**  
   知道规则意味着能预测他人的成本与边界。

3. **第一笔身份改善要早于终极功名**  
   Reader 不必等到中秀才才吃到第一口 Fantasy。

4. **每次赢要留下新的权限结构**  
   下一次旧人回来，双方关系不是 reset。

5. **强身份也必须有上级压力**  
   升级以后仍有人 / 制度能限制主角，Fantasy 才能继续。

## 16.3 Weakly served functions
从当前样本看，相比“再中一个功名”，更少被充分利用的市场功能是：

- 身份合法性本身如何从临时变正式；
- 家族 / 宗法上的控制权变化；
- 财产与住所的自主权；
- 婚姻决定权；
- 法律程序上的保护；
- 主角身份资产如何真实保护身边人；
- 多个身份资产发生冲突时，哪一个更硬；
- 已获得的权利如何被旧制度反复测试而不是清零。

这里描述的是 **reader function gap**，不是题材提案。

## 16.4 Saturated packaging warning
“寒门 / 庶子 + 科举 + 一路中榜”本身不足以区分。

Pool 的 substitution space 不在于换一个朝代名，而在于：

> **把“身份升级”重新写成生活中具体权限的变化，而不是头衔替换。**

# 17. Evidence limitations

1. 番茄动态榜会变化。  
   本报告冻结的是 2026-09-25 榜单截止与 2026-09-26 抓取附近状态。

2. 《冒姓琅琊》《魏家孽种》早期章节并非每一章都能通过同一官方入口完整抓取。  
   本轮以官方作品页 / 官方目录为骨架，并对可访问的具体章节做文本核验；少量章节使用公开镜像 / 搜索抓取做交叉检查。

3. 《穷山恶水出名臣》是 **PARTIAL MATCH**。  
   当前 metadata 足够，但前 20 章逐章全文访问不足，部分判断来自目录与简介。因此不能把其低在读归因到“Ch18 才启动科举”。

4. 《科举之路从童生开始》不是同期 matched weak。  
   最后更新 2023-02-05，是严重 confounder。它只适合证明：
   > 同为科举 Vehicle，开局可以完全没有“压迫性身份困局”这个 Reader Fantasy。

5. 《穿越遇换亲，侯门庶子奋斗记》太新。  
   4.7–5.5 万级信号能说明当前入口存在，但不能说明 20 / 50 / 100 章 retention。

6. Reader comments 只作 qualitative support。  
   不能把几条评论当成几十万读者的统计代表。

7. 本轮没有做“历史质感被剥离”的 A/B 实验。  
   因此不能证明历史质感与身份自主权 Fantasy 各自独立贡献多少。

# 18. Pool-only conclusions

## 18.1 What the strong books actually do

强书没有把“身份”当成一个奖杯。

它们把身份当成：

> **一套会改变别人能不能对你做某件事的社会 API。**

Reader 吃到的不是：
> “我现在叫举人了。”

而是：
> “因为我是举人 / 因为我已分宗 / 因为我有师门 / 因为这个身份已被多人承认，所以你今天不能再像 Ch1 那样对我。”

## 18.2 Ch20 is a crucial balance-sheet gate

强书到 Ch20 不一定必须拿到完整官身。

但至少要让 Reader 能列出一份 **non-resetting balance sheet**：

- 多了谁的承认；
- 多了什么关系；
- 少了谁的一项支配权；
- 多了什么资源；
- 哪个旧危险以后必须换方式来。

如果 Ch20 主角和 Ch1 的唯一差别只是“围观者更震惊”，Pool 还没真正工作。

## 18.3 The hierarchy must remain alive

本池最反直觉的一点是：

> 主角升级得越成功，越不能让等级制度彻底失效。

如果身份升级后所有规则都拿主角没办法，Reader Fantasy 会失去参照物。

强书让制度继续压：
- 但压法变了；
- 主角的筹码变了；
- 能保护的人变多了；
- Reader 能感觉过去的积累在工作。

# 19. Final answer to the assigned highest question

## 这个 Reader Pool 真正卖的是“历史感”，还是“在压迫性的制度里一点点拿回自己的人生”？

就本轮样本而言，**更接近后者**：

> **核心 Reader Fantasy 是：在一个身份会实质决定人生边界的制度里，把“别人有权替我决定”一点点改造成“这部分现在必须由我决定”。**

但不能把“历史感”降成可有可无的皮。

更准确的关系是：

> **“拿回人生”是 Reader Fantasy；“可信的历史制度与社会规则”是这个 Fantasy 能产生重量、成本和复利感的关键兑现机制。**

如果没有压迫性制度的可信边界：
- 身份升级会变成标签；
- 礼法会变成嘴炮；
- 功名会变成等级数字；
- “自主权”也就没有真实参照。

如果只有历史感、没有持续变化的权利矩阵：
- 又容易变成制度百科、科举过程、朝堂知识展示。

因此强书真正持续拥有的阅读资产是：

> **制度压力 × 可积累身份资产 × 旧关系回返测试 × 多领域自主权扩张。**

Author status at this gate remains:

> **MAYBE.**

本报告不将其升格为 WANT，也不对是否选择该 Pool 作推荐。

# 20. What is now proven, and what is still not proven?

## Now proven
- 当前番茄存在至少两部高在读、长程 DIRECT 样本，把“身份 / 权利 / 自主权”持续做成剧情资产，而不只是一次科举或一次打脸。
- 强样本的身份升级会真实改变他人的行为权限。
- 强样本能让旧身份问题在 Ch50 / Ch100 继续回来，而不是开篇用完。
- “科举 / 历史” Vehicle 本身不足以保证这个 Reader Fantasy；弱对照能拥有相同 Vehicle，却在 Ch1–20 几乎没有 autonomy transaction。
- 最可重复的核心不是“升官”，而是 **rights-bundle compounding**。

## Still not proven
- 没有两个完全干净的 2026 同期 matched weak，因此不能做严格因果归因。
- 不能证明一个无作者信用的绝对新人仅靠本机制就能获得 HIT 表现。
- 不能证明历史研究深度与 status/autonomy Fantasy 的独立贡献比例。
- 当前新入口《穿越遇换亲…》尚不足以证明长程 durability。
- 本轮只研究 Pool 6，不能据此与任何其他 Pool 做优劣判断。
