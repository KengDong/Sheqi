# 2. Benchmark分三组

## A｜直接相邻Premise
至少：
- 《三日间的幸福》
- 《In Time》
- 中文“时间/寿命交易”网文若干

重点：
- 人的时间被估价后，什么情感/阶层/社会矛盾最有力；
- 哪些作品只是把“时间”当货币皮肤；
- 哪些作品很快退化成收购寿命→卖给富豪→神豪打脸。

直接相邻样本可以包含失败/中小样本。
**失败模式同样重要。**

## B｜商业成长 / 人生资产复利热门
至少：
- 《都重生了谁谈恋爱啊》
- 《亏成首富从游戏开始》
- 再选2—4本真实热门长篇

重点不学题材，学：
- 第一桶金以后为什么还想看；
- 企业/客户/关系/身份如何持续累积；
- 主角生活怎么随着事业变化；
- 怎么避免“再做一笔更大生意”。

## C｜社会机制型热门
选2—4本：
- 单一核心规则能不断进入不同社会领域；
- 但每进入一域，人物状态也会变化。

# 3. 先回答作者最尖锐的问题

## 3.1 为什么不是所有人都在套利？
时间市场既然成熟，明显价差为什么存在？

禁止答案：
- “主角聪明”
- “别人都没发现”
- “主角运气好”

需要建立真实市场摩擦。

至少研究/设计：
- 地点绑定；
- 技能绑定；
- 交割风险；
- 买方迟到/取消；
- 健康变化；
- 信用；
- 信息不透明；
- 隐私；
- 资格/牌照；
- 法律用途限制；
- 平台手续费；
- 资金占用；
- 转售次数限制；
- 时段不可复制；
- 本人身份/社会关系可否被使用；
- 非标准化商品导致流动性不足。

最终要回答：
> **沈桥的edge是什么？**

而且这个edge必须能成长：
> 生活经验 → 信息 → 客户 → 信用 → 货源 → 定价网络 → 市场地位。

不能是外挂。

# 4. 技术合理性

当前正文只用了：
> 卖出时段本人没有第一人称记忆。

本轮必须比较至少3套实现：

## T1｜主体挂起 / 执行权托管
本人自传体意识暂停，程序性技能可调用，身体状态连续。

## T2｜记忆写入隔离
本人保持某种低级意识，但交易期间记忆不写入长期自传体记忆。

## T3｜其它更强方案

每套必须回答：
- 谁在控制身体；
- 买家如何下达任务；
- 技能能不能用；
- 私人记忆能不能读；
- 身体损伤怎么赔；
- 性/生殖/器官等禁止权；
- 犯罪责任；
- 交割失败；
- 为什么技术能规模化；
- 为什么没有把社会变成“意识上传万能世界”。

最终只推荐一套：
> **最少规则、最大故事空间、最少漏洞。**

# 5. “更多新的东西”｜Novelty必须有层级

禁止把以下当Novelty：
> 新时间商品A / 新时间商品B / 更大金额 / 更长时段。

至少建立5类新鲜感发动机：

## N1｜角色位置变化
卖家 → 买家 → 经纪 → 市场 maker / 组织者 → 规则参与者

## N2｜关系变化
母亲 / 方栀 / 客户 / 对手 / 合伙人 / 被沈桥买过时间的人
必须随着市场位置变化而变化。

## N3｜权利形态变化
研究“时间所有权”到底可以拆哪些权：
- 劳动执行权；
- 出席权；
- 身体控制权；
- 地点绑定权；
- 技能调用权；
- 社会身份使用边界；
- 撤销权；
- 转授权权；
- 未来本人异议权。

不能全用，必须筛选最有小说价值的少数核心。

## N4｜市场结构变化
- 散户；
- 经纪；
- 企业采购；
- 保险；
- 抵押；
- 信用；
- 争议处置；
- 黑市；
- 大规模时间池。

## N5｜社会后果变化
家庭、教育、工作、医疗、婚恋、刑法、保险、阶层、城市生活。

# 6. “进入新领域”还不够｜每个Arc必须产生质变

作者明确：
> “每扩一个社会领域，都必须让沈桥的人生资产发生变化”仍感觉不够。

因此每个大Arc强制满足：

### A. 至少2种资产发生永久变化
从：
- 钱；
- 信用；
- 客户；
- 货源；
- 信息；
- 牌照；
- 团队；
- 住处；
- 家庭状态；
- 关系；
- 社会身份；
- 法律权利；
中选。

### B. 至少1条关系不可逆变化

### C. 至少1个“以前做不到、现在能做”的新动词

### D. 至少1个旧玩法永久失效
例如：
> 不能永远靠医院信息差。

### E. 至少1个世界认知被翻转
不是“原来还有另一个产品”，而是：
> 读者重新理解“时间所有权”本身。

# 7. 设计Novelty Ladder｜至少20个“质变级”新东西

不是章节梗。

每个候选必须说明：
- 为什么新；
- 改变谁的生活；
- 如何连接沈桥纵向成长；
- 为什么不会只用一次。

可探索但不限定：
- 企业批量购买员工未来休息日；
- 儿童未来时间处分权；
- “未来本人”是否拥有反悔权；
- 卖家死亡后的未交割时间；
- 时间合同继承；
- 专业技能时段溢价；
- 高危事故日保险；
- 多人同步时间包；
- 婚礼/考试/手术等“本人必须在场”的不可代理日；
- 信用不够的人只能卖不能买；
- 平台冻结未来；
- 时间债务；
- 城市级劳动力时间池；
- 买方只买“缺席”而不是劳动；
- 某些日子不能转售；
- 有人把一生最重要的日子全部抵押；
- 一个组织囤积某类人的关键未来；
- 合同到期时未来人格拒绝交割；
- 时间交易导致家庭成员之间的产权冲突；
- 时间黑市绕过主体挂起的安全边界。

要求：
> 不得把列表直接当未来Outline，先筛功能。

# 8. 长篇体量压力测试

分别测试：
- 100万；
- 160万；
- 220万+。

不要因为社会接口多就默认能写长。

至少设计6个阶段，每阶段回答：
- 沈桥现在是谁；
- 他最想得到什么；
- 主要收入结构；
- 关系网络；
- 新能力不是超能力，而是什么“社会动词”；
- 这一阶段最大不可逆变化；
- 下一阶段为什么不是重复放大。

必须回答：
> Ch50 / Ch100 / Ch200 / Ch400 / Ch700时，读者分别在追什么？

# 9. 负面对照必须认真做

至少深挖2—4个“时间/寿命交易但没有成为头部”的作品。

目的不是嘲笑。

要找：
- 为什么设定本身有点击，但人物/社会/长期发动机不够；
- 是否退化成神豪打脸；
- 是否只有交易对象变化；
- 是否主角太无敌；
- 是否技术规则随剧情变化；
- 是否关系不复利。

把这些失败点变成C01 Hard Gates。

---

# 10. Benchmark输出必须区分“可借”与“不能借”

例如：

《三日间的幸福》可借：
> 时间估值的情感重量。

不可借：
> 它是短篇式生命倒计时，不解决百万字长跑。

《In Time》可借：
> 时间资产化直接制造阶层、治安、金融与地理分层。

不可借：
> 直接照搬“时间=寿命货币”。

《都重生了谁谈恋爱啊》可借：
> 商业成长不断改变关系/组织/生活。

不可借：
> 重生信息差。

《亏成首富》可借：
> 单一商业母题扩进多个产业、群像与组织。

必须研究它后期的：
> 产业过多 / 套路重复造成的疲劳风险。
