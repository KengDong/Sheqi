# 正文执行｜叙事声音、幽默机制与热门文风借鉴研究

## 角色定位
> **正文执行研究员 / 文风机制拆解红队**

这不是模仿某位作者的独特文风。

目标是：

> **从热门男频作品中提取可迁移的叙事机制，再建立《舍弃》自己的正文声音。**

不得仿写、洗稿、复刻特定作者独特句式或连续表达。

## 核心问题

### 1. 《谁让他修仙的！》为什么“密集搞笑”仍能长篇运行？
重点拆：
- 笑点从哪里来：人物脑回路、信息差、一本正经的荒谬、反转、回调、身份错位、规则被过度认真执行；
- 笑点怎样嵌进事件，而不是停下来讲段子；
- 正经冲突时怎样避免笑点削弱代价；
- 配角如何拥有不同笑法；
- 一章内笑点密度与强弱如何起伏；
- 哪些机制适合《舍弃》，哪些会把本书变成纯沙雕仙侠。

### 2. 《没钱修什么仙？》
重点拆：
- 社会逻辑如何直接进入对白和日常动作；
- “钱 / 工作 / 修炼”怎样在一句话里同时成立；
- 冷面荒诞与现实压力怎样并存；
- 《舍弃》如何借“社会逻辑渗透”，但不照搬手机、贷款、平台、现代职场皮肤。

### 3. 《玄鉴仙族》
重点拆：
- 克制叙述；
- 人物关系和后果怎样产生重量；
- 群像人物如何拥有不同语气；
- 哪些场景应该少开玩笑，让损失真正落下。

### 4. 《赤心巡天》
重点拆：
- 重要对白如何体现人物立场；
- 情绪戏怎样控制抒情密度；
- 战斗 / 争论中如何保持句子清楚；
- 如何让“人物说话”而不是“作者借角色说主题”。

### 5. 《剑烛大荒》及1—2部当前高热作品
重点拆：
- 生活细节 / 百业 / 饮食 / 器物如何让世界有质感；
- 新设定怎样藏进动作；
- 场景空间怎样写得可见，而不是说明书。

## 必须输出《舍弃》的“文风机制矩阵”

至少给出：

### 基础叙事声线
- 叙事距离；
- 句长；
- 动作 / 对话 / 内心 / 说明比例；
- 场景细节优先级；
- 正经场与轻松场的切换原则。

### 幽默引擎
至少设计6类**只属于本书人物和世界**的笑点来源，例如：
- 陆野穷人式成本算法；
- 乔九时间=钱的过度实用；
- 石小庚过分精确；
- 唐禾的长期账；
- 舍弃文明的日常化反差；
- 回调型笑点。

但不要写成固定梗词库。

### 幽默禁区
必须明确：
- 第3章舍味 / 救人高潮哪些地方不能插笑点；
- 味觉永久失去后的第一轮生活冲击不能立刻被“新能力”抵消；
- 余灾与真实伤亡不能被段子化；
- 角色不能为了制造包袱突然降智。

### 角色对白指纹
为：
- 陆野
- 乔九
- 石小庚
- 罗槐
- 唐禾
- 周照
至少建立“说话决策原则”，不是口头禅。

## 正文生产流程设计

提出一套适合第一次长篇作者的流程，至少比较：

A. AI直接起草整章 -> 人工修改  
B. 人先写骨架 / 关键对白 -> AI协助扩写 -> 人深改  
C. AI先做多个微场景样稿 -> 选声线 -> 再写整章

重点回答：
- 怎样避免AI文味；
- 怎样保持人物长期语言一致；
- 怎样防止每章都“起承转合太标准”；
- 怎样建立可迭代的 prose bible；
- 每章写完后要做哪些检查。

## 校准实验
不要写正式正文。

只允许用已冻结前三章里的3个微场景做**短样稿实验**：
1. 坏货签夹；
2. 咸汤；
3. 事故后苦药无味。

每个场景可以给2—3种不同“机制组合”，但不模仿具体作者。

目的：
> 判断《舍弃》应该多轻、多幽默、多克制。

最后必须给：
1. 推荐的《舍弃》基础声线；
2. 幽默密度原则；
3. 角色对白指纹；
4. 情绪场禁区；
5. 正文生产SOP；
6. 第一章试写前应冻结的 prose bible 字段；
7. 自我红队至少15问。
