# REBOOT-V3 P0 Direct Opening Benchmark Deep Read

## Why this gate exists
A02 P0 exposed a process flaw:
> generic commercial-function checklists produced mechanically correct but undesirable prose.

Therefore before any new Commercial-Mirror P0:
> each candidate needs a NAMED Primary Benchmark whose actual First Screen / Ch1 has been deep-read and causally decomposed.

## ACTIVE candidates
- A01 《怪物死了，地盘还在》
- A02 《末日先修水电》
- A04 《冒险者公会救援队》
- B10 《灵气复苏，我开二手装备店》

## Research scope
For EACH candidate:

### 1. Find 3–5 plausible direct / near-direct benchmarks
Prefer:
- 2024–2026 current/recent commercial successes;
- unknown/new-generation author evidence when possible;
- same target reader pool or same cold-start problem.

May include one mature older control if it solves the opening problem unusually well.

### 2. Choose ONE Primary Opening Benchmark
Must explain:
- same reader acquisition problem;
- why its First Screen / Ch1 is causally relevant;
- what is NOT relevant / must not be transferred.

### 3. Deep-read actual opening
Study at least:
- first ~100 Chinese characters;
- ~300;
- ~800;
- ~1500 / First Screen;
- whole Ch1 if accessible.

Record FUNCTIONS, not copied text:
- first concrete image/problem;
- how much context arrives before action;
- first protagonist decision;
- first personality signal;
- premise activation point;
- first visible payoff/danger/status shift;
- recurring-person entry;
- information withholding;
- micro-question sequence;
- sentence/paragraph rhythm only at abstract level;
- screen/chapter end desire.

### 4. Negative control / ablation
Ask:
- if this beat were 500 chars later, what weakens?
- if protagonist did not choose here, what weakens?
- if relationship entered later, what weakens?
- what part is genre baseline rather than hit differentiator?

### 5. Difference Audit
For the Primary Benchmark:
- what did it do differently from ordinary same-category openings?
- what should NOT be mirrored because it is skin / signature / author-specific?

### 6. Project translation constraints
Produce a candidate-specific function card that says:
> what Reader functions our opening should accomplish

but does NOT prescribe:
- exact project scene;
- exact prop;
- exact conflict;
- exact event sequence;
- exact opening line.

Keep project scene selection free.

## A02 special question
Determine why a premise about:
> “末日里把水电修回来”

can become fiction desire rather than:
> facility-repair procedure + resource-allocation meeting.

Need benchmarks that teach:
- urgency;
- protagonist appetite/personality;
- visible survival payoff;
- social consequence;
without turning into engineering explanation.

## Evidence
Use current web evidence and actual accessible opening text/reviews where legally available.
Do not invent inaccessible content.

## Copyright hard
Do NOT reproduce long passages.
Do NOT output living-author style instructions.
Do NOT create rewritten scenes.
Only causal/function decomposition.
