# P0 Input Card｜B10《灵气复苏，我开二手装备店》

## Native Card｜READ FIRST
Title:
> 《灵气复苏，我开二手装备店》

Shelf promise:
> 他能看见超凡装备还剩多少次可靠使用机会，于是专收别人不敢碰的二手货，把破店做成冒险小队出门前必来的地方。

Protagonist:
> 梁序（provisional）

Core behavior:
> 不只看“值多少钱”，更看“这东西现在给谁用，会把什么风险转给谁”；愿意拒绝短期利润，但不能把自己写成万能道德裁判。

Recurring relationship seeds:
- 唐乔：维修判断与工艺权，不自动服从梁序的能力结论；
- 鲁震：固定行动小队使用者，会比价、隐瞒信息、绕开店铺，不是永久忠诚客户。

Near contract:
> Ch1–3内，第一件别人不敢碰的旧装备真正产生利润/使用价值，同时一个会回来的客户因梁序判断避开一次失效风险；留下使用记录和关系后果。

P0 must show:
- old equipment has concrete stakes;
- “remaining reliable uses” changes an immediate decision;
- a human can disagree with the commercial choice;
- the first screen is not just appraisal exposition;
- end with customer/equipment history beginning to matter.

Do not:
- expand into all-knowing appraisal;
- introduce a bizarre神器 solely for hook;
- write buy-low/sell-high as the whole scene;
- make customer permanently grateful.

## Mirror Function Card｜READ ONLY AFTER NATIVE FREEZE
Function benchmarks:
> concrete-work settlement fiction + fast commercial action loops.

Mirror only:
1. start with a transaction/work problem already in motion;
2. reveal the ability through a consequential decision, not a panel tutorial;
3. produce a tangible commercial/survival effect inside the screen;
4. make the decision alter a recurring relationship;
5. end on a reason the SAME person/item will matter again;
6. keep jargon and inventory count low.

Cadence target:
- first quarter: reader understands why this used item is risky/valuable now;
- middle: 梁序 uses reliable-use information to choose/refuse/reprice;
- second half: 唐乔 or 鲁震 pushes back with a legitimate interest;
- final beat: profit is not the only residue; trust/debt/record/return obligation changes.

Forbidden:
- “鉴定→震惊→捡漏→暴利” template;
- one-item one-customer disposable structure;
- benchmark scene copying;
- living-author voice imitation.
