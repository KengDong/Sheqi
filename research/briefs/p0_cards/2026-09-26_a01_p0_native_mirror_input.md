# P0 Input Card｜A01《怪物死了，地盘还在》

## Native Card｜READ FIRST
Title:
> 《怪物死了，地盘还在》

Shelf promise:
> 城里的怪物能杀，怪物留下的地盘、住户和债务却不会消失；他每赢一场，就得真接下一块地方，也真扛下一摊麻烦。

Protagonist:
> 周启（provisional）

Non-gimmick behavior:
> 一旦说“这事归我管”，就会把后果一起接过来；习惯追使用路线、野办法和自己过去的承诺。

Decision rule:
> 先保可撤退/可维修能力与明确承诺，再保长期可运行，最后才是当期利润和控制感。

Recurring relationship seed:
> 唐阿琴，老租户/小店主。她知道这块地方真正怎么被人使用，也能组织住户拒绝、议价、绕过管理。

Near contract:
> Ch1–3内，第一处怪物留下的空间必须真正变成能住/能用/能产生持续价值的地盘；同时周启被一个对住户不能随便反悔的承诺绑住。

P0 must show:
- monster victory is NOT the end;
- a concrete place/asset remains;
- a human already living/using it has standing;
- 周启 makes one consequential choice;
- screen ends with persistent obligation/value, not a new monster.

Do not:
- explain property law/world lore;
- make 唐阿琴 instantly loyal;
- turn scene into management meeting;
- add new core power/mechanic.

## Mirror Function Card｜READ ONLY AFTER NATIVE FREEZE
Function benchmarks:
> current fast-start commercial action/profession hits; Lane B primary/supported benchmark functions.

Mirror only these functions:
1. enter a concrete situation immediately, no preface;
2. protagonist must make a choice before the reader receives full explanation;
3. core premise becomes visible through consequence, not narration;
4. first tangible fruit appears inside the first screen;
5. one recurring person enters as friction/leverage, not audience;
6. end on changed state that creates next-screen desire.

Candidate-specific commercial cadence target:
- first 15–20%: the “fight is over but the problem remains” image is already concrete;
- by mid-screen: 周启 has to decide what he is actually taking responsibility for;
- before end: 唐阿琴 or equivalent old-state person forces a non-trivial condition;
- final beat: something now belongs/depends on him AND can hurt him later.

Forbidden:
- copying any benchmark opening situation;
- 749-like onboarding;
- renamed containment organization;
- same scene order as a hit;
- living-author voice imitation.
