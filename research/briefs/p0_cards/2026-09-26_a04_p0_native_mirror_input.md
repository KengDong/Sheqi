# P0 Input Card｜A04《冒险者公会救援队》

## Native Card｜READ FIRST
Title:
> 《冒险者公会救援队》

Shelf promise:
> 普通冒险者接的是“去杀什么”，救援队接的是“那支队伍失联两天了，把人活着带回来”。

Protagonist:
> 方岱（provisional）

Core behavior:
> 在危险现场优先判断“谁还能带回来、什么时候必须撤、什么战果必须放弃”，而不是把所有问题转成讨伐。

Recurring relationship seeds:
- 莉娅：医疗/伤员边界拥有真实判断权；
- 凯洛：第一批被救关系的重要一端，可能否认、抵触、保护名誉，不自动感恩。

Near contract:
> Ch1–3内，方岱从一个已经失败的现场把至少一个本来回不来的人活着带回，留下救援记录、事故信息和一段不能清零的被救关系。

P0 must show:
- this is a FAILED situation before rescue enters;
- protagonist behaves like rescuer, not ordinary adventurer;
- one decision sacrifices loot/追杀/面子/进度 for extraction;
- another professional voice has weight;
- screen creates urgent desire to see whether someone gets out alive.

Do not:
- start with guild history;
- turn rescue into generic dungeon fight;
- make survivor instantly grateful;
- add resurrection/time rewind/universal rescue power.

## Mirror Function Card｜READ ONLY AFTER NATIVE FREEZE
Function benchmarks:
> fast action/organization hits + mature professional-team fiction.

Mirror only:
1. cold open on concrete danger/failure evidence;
2. protagonist shows role through a decision before explanation;
3. professional competence produces a different choice, not just stronger combat;
4. recurring teammate enters as authority/friction, not cheerleader;
5. screen ends on a life-or-death extraction question or irreversible rescue consequence;
6. low glossary cost: reader understands the job before the world.

Cadence target:
- first 15%: reader knows another team already failed;
- first third: 方岱 chooses rescue logic over adventurer logic;
- middle: concrete obstacle makes that choice costly;
- before end: 莉娅/teammate constrains what is medically/operationally possible;
- final beat: a person might still be reachable, or one rescue choice permanently changes the situation.

Forbidden:
- 749-like agency/monster sequence;
- same failed-mission scene from any benchmark;
- iconic dialogue/heroic speech;
- living-author voice imitation.
