# Mission

为每本寻找最自然的平台版本，并在真实当前竞争环境中测试：

> **同屏20本左右，陌生目标Reader为什么先点我？**

这不是母盘重调研。

只允许：
> direct shelf snapshot + packaging competition。

# Stage 1｜Current Shelf Snapshot

必须使用当前真实外部证据。

## Qidian
对偏起点候选：
- 当前同频道/相邻频道强书；
- 新书榜/畅销/阅读指数/推荐可见样本；
- 标题、封面风格、标签、简介第一段。

## Fanqie
对偏番茄候选：
- 当前分类榜/相关强书；
- 标题、封面、标签、简介首屏；
- 当前阅读量级只作环境证据。

不要重新研究：
> 哪个题材是大盘。

# Stage 2｜Platform-Native Packaging

每本最多做：

## Qidian Candidate Pack
- title x 2
- one-line category promise
- tags
- synopsis first 120—180 Chinese chars
- first-screen promise
- cover direction (text description only at forge stage)

## Fanqie Candidate Pack
- title x 2
- one-line category promise
- tags
- synopsis first 120—180 Chinese chars
- first-screen promise
- cover direction

不是每本强制两个平台都适合。

如果一个平台明显不自然：
> mark PLATFORM MISMATCH，停止硬适配。

# Stage 3｜Shelf Strip

把候选与真实同类作品混排。

Reader只先看：
- title
- cover visual
- tags
- first synopsis lines

不得看到：
- 项目内部评分；
- Reservoir；
- Hit Gap；
- 哪本是旧候选；
- 总编偏好。

# Stage 4｜Fresh Shelf Reader

新 clean-room Reader。

问题不是评分。

让Reader：
1. 先自由浏览；
2. 选最想点开的3—5本；
3. 解释每次点击欲；
4. 指出完全不想点的；
5. 在自家候选中选出真正愿意打开第一章的；
6. 记录是题材熟悉、标题、封面、Premium还是情绪承诺导致点击。

必须允许：
> 我们的候选一个都不点。

# Core Evidence

最高：
> **spontaneous click choice against real competitors**

其次：
- title recall;
- one-line recall;
- expected reward correctness;
- platform fit.

禁止总编用：
> “但这本长篇结构更强”
替点击失败翻案。
