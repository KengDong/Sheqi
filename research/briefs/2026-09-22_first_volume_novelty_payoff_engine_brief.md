# 1. 外部Benchmark｜只研究“持续爽/持续新”的发动机

研究 **6—10部** 商业长篇。

至少覆盖：
- 高频横向组合；
- 收集/养成；
- 捡漏/价值发现；
- 明确收益循环；
- 中秘密到大秘密；
- 多发动机轮换。

优先候选：
- 《没钱修什么仙？》
- 《你们修仙，我种田》
- 《我有一座冒险屋》
- 《苟在初圣魔门当人材》
- 《亏成首富从游戏开始》
- 《修真聊天群》
- 《诡秘之主》
- 再补1—3部当前市场/功能邻近作品。

必须尽量依据实际公开正文、官方目录/简介与可验证资料。

每部只回答：
1. 高频新鲜感从哪里来；
2. 读者每个小弧拿到什么；
3. 资产/能力/关系怎样累计；
4. 中秘密怎么在大秘密前持续结算；
5. 如何避免重复模板；
6. 哪个功能适合《舍弃》，哪个不适合。

不要重新做开篇Hook大全。

# 2. 建立“横向新鲜感矩阵”

至少设计 **8个现实领域 × 4种冲突方式**。

现实领域至少从这些选：
- 工作；
- 钱/债务；
- 借载；
- 保险/工伤；
- 招聘/岗位；
- 宗门/家族资源；
- 家庭/关系；
- 黑市/交易；
- 法器/余器；
- 信用/责任。

四种冲突方式至少包括：
- 付钱；
- 失去机会；
- 获得收益；
- 价值观/关系冲突。

每格不是设定点子，而是要回答：
- 谁想要什么；
- 谁付钱/承担风险；
- 陆野为什么卷进去；
- 这次给读者的新鲜感是什么；
- 结算是什么。

最终筛出 **12—16个第一卷真正可用的场景/小弧原型**。

# 3. 设计中秘密 / 中大秘密梯

以 M0—M6 为起点，重新设计。

必须回答：
- 每层读者确认了什么；
- 陆野确认了什么；
- 旧理解被怎样修正；
- 这一层带来什么现实收益/危险/市场；
- 下一层为什么必须继续追；
- 与 `canon/10_mystery_ladder.md` 是否冲突。

强制：
> **至少一半秘密节点必须带来“可行动结论”，不能只带来谜题。**

例如：
- 能判断；
- 能规避；
- 能收集；
- 能卖；
- 能换资源；
- 能进入新市场；
- 能发现有人在利用。

若需要改当前Mystery Ladder：
> 只写 Proposal，不直接改Canon/正式文件。

# 4. 设计“价值回收 / 收集养成”循环

至少给出：
- 普通修复小循环；
- 第一次异常捡漏；
- 第一件窄用收藏；
- 第一次真实变现；
- 第一次旧收藏回用；
- 第一次判断错误/亏损；
- 第一次市场/监管冲突。

每个循环必须列：
- 入手成本；
- 验证成本；
- 风险；
- 最终价值；
- 是否收藏/变现；
- 读者爽点；
- 如何避免“每件垃圾都是宝”。

必须设计至少一次：
> **看走眼 / 信号真但价值判断错 / 买亏或害到别人。**

以保护世界可信度和现有误判主线。

# 5. 建立第一卷Payoff Ledger

按故事阶段，不要求先锁具体章数。

至少追踪：
- Action Payoff；
- Money Payoff；
- Collection Payoff；
- Knowledge Payoff；
- Status Payoff；
- Relationship Payoff；
- Reversal Payoff。

对现有第一卷每个骨干节点标：
- 当前有什么结算；
- 哪些只有过程没有结算；
- 哪些是“许可+1”；
- 哪些连续区间爽点真空。

然后提出修复。

软目标：
> 重要小弧至少结算一项可见收益；连续多个小弧不能都只给“知道更多/被认可”。

# 6. 重审现有Story Engine

重点审：
> 资格冻结 -> 限制复工 -> 恢复资格 -> 固定席位竞争

必须判断：
- 哪些值得保留；
- 哪些压缩；
- 哪些转成真实客户/路线/战斗任务；
- 哪些加入Money/Collection/Knowledge结算；
- 哪些加入舍弃文明横向场景；
- 哪些节点应该提前给中秘密。

要求给出：

## KEEP
继续保留的发动机。

## COMPRESS
必须压缩的手续/恢复流程。

## REPLACE
应该换成更有结果的真实任务。

## ADD
需要新增的爽点/秘密/资产成长节点。

不得直接覆盖Approved Outline。

输出Outline Change Proposal供总评审/作者批准。

# 7. 卷末必须有“资产台阶”

除了固定席位之外，至少设计两种候选组合：
- 小工具箱形成；
- 明显本金增长；
- 稳定副收入；
- 特殊市场入口；
- 一个可持续的信息/交易关系网。

要求：
> 卷末读者能明显感觉“陆野比开篇多拥有了一套东西”，而不是只升职。

# 8. 第一卷的“原来还能这么用”检查

按前段 / 中前段 / 中段 / 中后段 / 卷末，分别写：

> **这一阶段读者最新一次‘原来还能这么用’来自哪里？**

若两个连续阶段都来自同一类：
- 又一个舍项；
- 又一个异常物；
- 又一个职业手续；

判定重复。

必须轮换不同发动机。

# 9. 需要形成3套第一卷发动机方案

最终不要只交一个大杂烩。

至少形成3套：

### Option A｜收集/变现偏强
商业爽感最高，但风险是捡漏文。

### Option B｜文明横向偏强
世界每隔一段换新领域，但风险是制度百科。

### Option C｜均衡型
修炼 + 横向文明 + 收集资产 + 中秘密四轮驱动。

三套都必须保护：
- 正常修炼主轴；
- 余世长线；
- 主角不是鉴宝外挂；
- 第一卷不被纯物流锁死。

总评审再选择/融合。
