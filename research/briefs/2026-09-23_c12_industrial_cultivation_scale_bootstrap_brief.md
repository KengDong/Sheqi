# 2. Benchmark任务｜不要只看Ch1

在已读基础上，重点拆《没钱修什么仙》：

## A. 世界怎么从“学校”扩到200万字以上仍不散
至少抽：
- Ch1—20；
- Ch40—60；
- Ch90—110；
- Ch140—170；
- clean源允许时再抽Ch180—210。

每个区间只回答：
- 主角当前人生位置变了什么；
- 新社会系统为什么此刻自然出现；
- 钱 / 修炼 / 阶层 / 关系 / 笑点如何同场耦合；
- 老系统如何复利，而不是换一个新设定；
- 读者为什么会继续100章以上。

## B. 术语是怎么让第一次读者懂的
重点找：
- 新境界第一次出现；
- 新机构第一次出现；
- 新修炼商品第一次出现；
- 新职业/考试/保险/贷款等第一次出现。

总结：
> 什么必须先用熟悉现实容器承接，什么可以直接叫修仙名词。

## C. 幽默为什么可持续
区分：
- 人物性格笑点；
- 制度荒诞；
- 修仙+现代制度错位；
- 反复梗；
- 关系之间的喜剧。

C12不能只靠周野嘴贫。

# 3. C12世界底盘必须正式回答

不得默认Prototype临时词成立。

## 3.1 社会形态
必须明确选择并论证：
> **现代工业社会 + 修仙完整嵌入**
还是其它更强方案。

要回答：
- 银行卡、手机、诊所、电瓶车、App、保险、公司是否都是世界原生常识；
- 日常货币是否直接使用“元”；
- 灵石/灵气在经济里是什么：能源、原料、金融资产还是别的；
- 宗门、大学、公司、政府/行业机构分别是什么位置。

## 3.2 修炼境界
优先测试：
> 炼气 → 筑基 → 金丹 → 元婴 → 化神……

除非另起境界明显更好，否则不要浪费认知预算。

明确：
- 哪些境界有劫；
- 劫不是每一级都同一种；
- 普通人为什么经常会接触渡劫产业。

## 3.3 劫的底层
需要一套**3句话以内普通读者能懂**的底层机制。

至少比较：
- 天地回衡；
- 灵气结构跃迁；
- 其它更强方案。

硬要求：
> **劫可以被分流，但不能被凭空消灭。**

否则“替人渡劫”产业没有坚硬物理基础。

## 3.4 风险转移产业
定义：
- 客户本人最低必须承担什么；
- 劫工承担什么；
- 阵法/法器承担什么；
- 保险承担什么；
- 哪些风险不可合法转包；
- 为什么富人不能100%无风险渡劫。

# 5. 周野背景｜必须做Entry Duel

至少做3个背景卡：

## P1｜土著学生 / 休学生 + 劫工
例如：
> 21—22岁，修行安全/劫务工程相关专业，因钱休学做派遣劫工。

测试：
- 为什么自然懂一点理论；
- 为什么又不懂现场；
- 学校 / 工作 / 资格 / 同学 / 家庭是否能持续长线；
- 是否最适合黑色幽默。

## P2｜魂穿
测试：
- 降低世界理解成本是否明显；
- 会不会过度像《没钱修什么仙》；
- 会不会让周野失去“土著觉得荒诞制度很正常”的喜感；
- 穿越者具体能带来什么长期价值，不允许只是吐槽。

## P3｜第三种更强入口
开放设计，但必须有明确功能优势。

最终给：
> 推荐顺序 + 原因。

不要直接写完整新Ch1。

# 6. “个人劫”重构

重点压力测试：

> **职业劫荷残留 / 劫债 / 劫痕**
作为周野提前触发个人劫的来源。

问：
- 是否比“天命特殊”更强；
- 是否能把职业、工伤、保险、行业秘密、个人主线锁成一条；
- 是否会破坏“劫可转移但不能消失”的底层；
- 是否能成为中后期社会矛盾，而不是阴谋黑幕。

同时至少提出2个替代方案比较。

---

# 7. 纵向成长｜禁止“挨更大的雷”

设计至少8级人物位置变化，但不要游戏等级表。

核心方向可参考但不拘泥：
> 卖身体承担风险
> → 卖判断
> → 风险评估
> → 带班组
> → 独立接项目
> → 掌握客户/工友/保险资源
> → 风险池/大项目
> → 参与行业定价与规则

每一级必须回答：
- 新的钱从哪里来；
- 新选择权是什么；
- 新关系是什么；
- 新责任是什么；
- 读者得到什么新爽点；
- 与上一阶段玩法哪里质变。

# 9. 大体量压力测试

不要先锁死字数。

分别压力测试：
- 120万；
- 200万；
- 280万+。

要求：
> 如果要做到接近《没钱修什么仙》的大体量，具体靠什么“旧系统复利”而不是无限加设定。

至少设计6个长期阶段：
- 每阶段主欲望；
- 人生位置；
- 固定关系变化；
- 核心爽点；
- 世界新面；
- 阶段结束的不可逆结算。

必须给：
> **Ch50 / Ch100 / Ch200 / Ch400 / Ch700时，周野的人生分别在追什么。**

# 10. Anti-Clone Gate

必须列：
> **至少10条不能照搬《没钱修什么仙》的东西。**

例如：
- 不能复制债务学生底盘；
- 不能复制外挂逼卷；
- 不能复制面试式第一章；
- 不能复制学校作为长期唯一中心；
- 不能复制具体笑话/句法/制度事件。

我们要学的是：
> **高耦合社会底盘 + 熟悉现实容器 + 修仙工业化 + 生活复利。**
