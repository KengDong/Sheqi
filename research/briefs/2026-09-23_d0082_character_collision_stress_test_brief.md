# Mission

本轮不再问：
> 世界还能发生什么？

只问：
> **如果不再给作者任何新Case、新客户、新规则、新机构，这4—6个人自己还能不能继续制造故事？**

# Per Candidate

先冻结4—6个核心人物。

每人只写：
1. 当前最想得到什么；
2. 最怕失去什么；
3. 不愿付什么代价；
4. 与主角无关也会继续推进的生活；
5. 与至少另一个核心人物天然冲突的地方。

然后只靠这些人物和已经存在的规则，产出：
> **10—15个 Character Collision Events**

每个Event必须：
- 至少两个核心人物都有主动欲望；
- 不是“来了一个新客户/新任务”；
- 不是“出现一个新规则”；
- 事件之后至少一段关系永久改变；
- 最好留下债、秘密、资产、承诺、身份变化或共同历史。

# Hard Ban

禁止：
- 新客户救场；
- 新机构救场；
- 新世界规则；
- 新终极阴谋；
- 新核心人物超过1个；
- 用事故/袭击/突发灾难强行制造冲突；
- 排章节；
- 写正文；
- 选Primary；
- 修改Concept。

# Special Stress for R3 / R5

## R3 Borrowed Tribulations
禁止新增“新的历史来源劫”。

只准用已存在：
- 周野；
- 老承受者；
- 家人；
- 年轻风险卖家；
- 原雇主/旧强者关系；
- 主角自己的突破。

若10—15个Event无法成立：
> DROP。

## R5 This City I Have Routes
禁止新增任何新的路权。

只准用已获得路线、已有小店/医院/安保主管/老骑手/新骑手等关系。

若10—15个Event无法成立：
> DROP。

# Character Cut Questions

总编只问：

1. 这些人不靠新Case还会不会有事？
2. 有没有至少2个非主角让我真的想继续看？
3. 关系变化是否会反过来制造下一事件？
4. 主角消失一天，这个世界里是否仍有事情发生？
5. 是否出现真正难以逆转的关系代价？
6. 普通生活场面是否也能成立？
