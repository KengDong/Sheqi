# Task A｜Consumerize Project Copy

For each platform-facing project package:

- same core engine.

- title selection if necessary;
- one-line hook;
- 80–140 Chinese-character blurb.

## Banned internal / AI-R&D language

Do NOT use packaging copy like:
- 真正的爽点是……
- 持续复利
- 永久状态变化
- 旧人物回返
- 社会场域
- 消费承诺
- 不重置
- 关系发动机
- 读者会看到……
- 这本书……
- 核心是……
- 越做越像一张关系网
- “不是X，而是Y” repeated as thesis prose unless genuinely natural.

The copy should sound like:
> a novel on a shelf,

not:
> an editor explaining why a concept is structurally good.

## Consumer-copy test

After reading the blurb, a stranger should be able to picture:
- a person;
- an immediate situation;
- what they keep doing;
- what they might get / lose.

Prefer:
> concrete verbs / objects / people / danger / money / status / place.

Reduce:
> abstract nouns / framework language.
