# 二、本轮的核心判断

必须先检验：

> **当前第一卷“结构上很稳”，是否可能在阅读表层上仍然像“传统修仙职业文 + 特殊感知”。**

> “第一卷发动机不用推翻，但前三章的进入方式必须大幅改造。”

# 四、每部作品只拆“开篇阅读合同”

不要大篇幅复述剧情。

每部只回答：

1. **第一页 / 第一章，读者最先看到什么“只有这本书才会这样”的场景？**
2. 主角第一章最具体想得到什么？
3. 第一章结束时，读者最想知道什么？
4. 前三章兑现了什么独特承诺？
5. 前三章有没有直接让核心设定进入“日常行为”，而不是只做设定说明？
6. 主角的人格处理方式有没有变成辨识度？
7. 第一章的爽 / 怪 / 笑 / 压力，后面50—100章还能继续提供吗？
8. 哪些只是作者名气、文风或题材红利，不适合《舍弃》复制？
9. 如果把核心专有设定换成普通玄幻词，这个开头还成立吗？
10. 《舍弃》能借的到底是“功能”，还是只是表面噱头？

尤其要对比：

> **《没钱修什么仙？》为什么不是“传统修仙 + 金融设定”，而是从学校、工作、竞争、修炼方式开始就被核心逻辑重新组织。**

以及：

> **《玄鉴仙族》如何改变“读者到底在看谁”；**
>
> **《谁让他修仙的！》如何让人物处理问题的方式本身成为阅读辨识度；**
>
> **《剑烛大荒》如何让核心设定直接改变战斗 / 身体 / 行动语法。**

# 五、专项：判断《舍弃》现在到底缺什么

必须分别判断以下四层：

## 1. 世界设定是否不够新？
若不是，明确说：
> 问题不在底层世界。

## 2. 表层生活是否没被“舍弃文明”改造够？
检查：
- 求职 / 上岗；
- 修炼；
- 婚姻 / 家庭；
- 饮食；
- 医疗 / 保险；
- 高危岗位；
- 富人与穷人的破境选择；
- 社会对缺位者的普通态度。

注意：
> 本轮不要求继续扩制度百科。

只找：
> **前三章能看见的2—4个表层细节。**

## 3. 陆野的人格动作是否不够强？
重点测试：

> **“世界最会教人怎么舍，陆野偏偏最舍不得浪费。”**

把“惜物”从标签变成稳定动作习惯。

例如但不限于：
- 别人说扔，他先翻；
- 别人说坏了，他先问哪坏；
- 废绳、旧器壳、破工具先修；
- 便宜难吃的食物也能算性价比。

不要直接照抄这些例子，研究什么最自然。

## 4. 开篇承诺是否太晚兑现？
检查：
- 第1章能否见到“舍”；
- 第3章能否见到真正代价；
- 第3—5章是否出现“别人不要的东西上有味”的反常现象；
- 是否为了秘密梯把“舍弃文明”本身也藏得太深。

必须明确区分：

> **表层文明常识可以大胆给。**
>
> **余世深层真相必须慢慢藏。**

# 六、做三套完全不同的前三章“钩子架构”

不是正式章卡，不写正文。

三套方案都必须遵守已批准第一卷发动机，但“进入方式”要显著不同。

至少覆盖三种不同思路：

## 方案A｜社会荒诞 / 舍备选择先行
读者先看到：
> 一个普通穷修士很认真地计算“该舍掉自己哪部分最划算”。

重点测试：
- 舍备审核 / 上岗手续；
- 陆野的穷与惜物；
- 舍弃文明的日常化；
- 石小庚 / 乔九如何自然进入。

## 方案B｜行动事故先行
读者先被事故抓住，舍味与筑基快速落地。

重点测试：
- 是否太像普通“事故觉醒”；
- 怎么在动作中同时显示舍契是成熟社会制度，不是临时外挂；
- 事故后如何迅速把永久代价打进生活。

## 方案C｜生活反差 / 人格先行
先用陆野“最舍不得浪费”的普通生活或工作动作立人，再把他推到“必须舍一样自己”的现实选择。

重点测试：
- 会不会慢；
- 第一章末钩子够不够；
- 如何在不讲百科的情况下让世界显得不普通。

如果研究得到更优的三类，可以改，但必须保证三套不是同一方案换顺序。

# 七、每套方案必须给出“前三章承诺表”

不要写完整正文。

对每章回答：

### 第1章
- 陆野此刻具体想要什么？
- 第一屏 / 前1000字最独特的场景是什么？
- 读者第一次看到的“舍弃文明”细节是什么？
- 最后一个推动读者翻页的问题是什么？

### 第2章
- 目标怎么升级？
- 哪个人第一次真正改变陆野行动？
- 有什么修仙动作兑现？
- 有什么代价开始逼近？

### 第3章
- 哪个不可逆变化真正发生？
- 读者得到什么明确兑现？
- 新问题是什么？
- 是否出现“别人不要的东西上有味”的反常承诺；若不出现，说明为什么延后更强。

# 八、强制做“可移植测试”

这是本轮最重要的压力测试之一。

对每套方案：

> 把“舍破 / 味觉 / 尝余 / 缺位”全部替换成普通修仙词：
> “突破 / 灵根 / 神识 / 后遗症”。

然后问：

> **这三章是否还能80%成立？**

如果答案是“是”，说明辨识度不够。

必须指出：
- 哪个场景只有《舍弃》才能成立；
- 哪个笑点只有陆野和这个世界才能成立；
- 哪个冲突离开“舍弃文明”就会失去根。

---

# 九、再做“过度猎奇测试”

不能为了抓人把前三章变成：
> 每页一个舍弃奇观。

每套方案同时检查：

1. 是否有正常生活 / 正常工作；
2. 是否有陆野本人，而不只有设定；
3. 是否有真实修仙能力兑现；
4. 是否有现实目标；
5. 设定奇观是否服务人物选择；
6. 前三章之后是否还能维持同样阅读承诺。

如果必须不断发明更怪的舍项才能维持读者兴趣，方案失败。

# 十一、热门借鉴的边界

必须明确：

### 可以借
- 核心设定渗透日常；
- 第一章就建立独特行动语法；
- 主角人格本身制造场景；
- 现实目标与修仙设定绑死；
- 三章内完成一次真兑现。

### 不可以机械借
- 现代金融 / 手机 / 平台话术；
- 赛博修仙皮肤；
- 贷款 / KPI / 互联网梗；
- 把古典世界硬写成现代公司；
- 为了像热门书而毁掉本书的生活质感。

要说明：

> 《没钱修什么仙？》写的是“力量如何被社会资本化”；
>
> 《舍弃》更应该写“一个文明如何把自己的一部分变成破境成本”。
