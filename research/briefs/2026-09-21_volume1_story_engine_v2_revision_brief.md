# 一、本轮目标

不重新做12本小说大调研。

本轮只把独立审核提出的五个问题修到“可以冻结第一卷发动机”的程度：

1. 把“正式押货资格”升级成真正能撑一卷的**两级现实目标**；
2. 重做人物组，补上**非工作生活锚点**，并把周照从固定队伍移到外部常驻；
3. 把“旧中转库出问题”升级成**中转流程长期叠加风险**；
4. 重排第一卷故事单元，补足**传统修仙爽感**与**私人生活轴**；
5. 把尝余误判写成**感知真实、归因错误**，而不是能力突然不准。

不得修改 locked Canon。  
不得写正式正文。  
不得开始前10章章卡。

# 二、外部作品的使用方式

本轮不再广泛搜书。

如果确实需要外部复核，最多补查 **3—5部**，只解决一个具体争议，例如：
- 双层现实目标怎么自然换挡；
- 固定工作团队如何和私人生活轴并存；
- 配角如何避免功能卡化；
- 第一卷如何安排传统修炼的可见兑现。

优先从已经研究过的：
- 《诡秘之主》
- 《没钱修什么仙？》
- 《光阴之外》
- 《赤心巡天》
- 《玄鉴仙族》
- 《谁让他修仙的！》
中定向取证。

必须说明：
> 借的是叙事功能，不是职业/组织/情节表面。

不要为了证明审核GPT正确而搜证据；如果外部经验反而说明审核意见有问题，可以反驳。

# 三、两级现实目标必须重写

当前不再把第一卷写成“一张押货资格牌撑到底”。

## 一级目标｜恢复/拿到正式押货资格

功能：
- 第一章就能理解；
- 事故后被打断；
- 前半卷持续推进；
- 有明确里程碑。

至少设计这些状态：
> 候选资格 -> 事故冻结 -> 医疗/安全复核 -> 限制复工 -> 试岗 -> 正式恢复

不得把流程写成官僚手续流水账。

每一步必须伴随：
- 钱；
-任务；
- 人际；
- 修炼；
至少其中一项真实变化。

## 二级目标｜获得固定路线 / 固定小队席位

它必须比“有资格”更重要：

- 收入更稳定；
- 有分成或长期收益；
- 获得决策权；
- 不能被随时替换；
- 同时开始对别人负责。

本轮必须回答：

1. 一级目标大约在第一卷什么阶段完成最合适？
2. 完成后为什么故事不会泄气？
3. 哪个事件把目标自然切换到二级？
4. 卷末固定席位具体意味着什么现实收益与责任？
5. 为什么不是“主角凭外挂特批进队”？

# 四、第一卷主题暗线：不可替代的代价

本轮需要明确使用、但不能让角色讲成主题论文：

> **陆野原本只是想让自己不那么容易被替换。**
>
> **后来他真的变得难以替代，却部分是因为别人发现他的缺位有用。**

必须设计至少4次不同程度的兑现：

### 第一次
别人只是觉得：
> “这个后遗症可能有点用。”

### 第二次
尝余帮助陆野拿回现实机会。

### 第三次
管理/同伴开始把这项能力纳入任务安排。

### 第四次
陆野意识到：
> “我想卖的是本事，不是缺掉的那一块。”

要求：
- 不做大段伦理辩论；
- 不让陆野一开始就有成熟反制度意识；
- 他的态度应该从“能挣钱挺好”慢慢变复杂。

# 五、重做人物结构

## 固定货路人物优先保留

- 陆野
- 乔九
- 罗槐
- 唐禾
- 石小庚

## 周照

改为：
> **高频外部监管者 / 合作方 / 阻力方**

不进入固定小队。

必须保留他和货行的制度距离。

周照每次出场的信息必须服务现实决策：
- 封不封；
- 运不运；
- 复工不复工；
- 谁承担风险。

禁止把他写成余世百科。

---

## 新增：生活锚点人物

至少设计 **3个真正不同的候选**，再选1个首选。

候选不能只是换皮：
- “旧友A / 旧友B / 旧友C”不算三种。

可以考虑但不限于：
- 同住旧友/房东家人；
- 与陆野有长期饮食记忆的人；
- 家庭/亲属；
- 旧同乡；
- 与货行完全无关的小生意熟人。

每个候选必须回答：

1. 他/她自己想要什么？
2. 为什么即使没有余世剧情也会持续和陆野来往？
3. 与陆野最容易因什么现实问题冲突？
4. 怎样让“味觉永久消失”真正落进私人生活？
5. 是否会不小心变成情绪治疗NPC？
6. 第一卷卷末关系发生什么小而不可逆的变化？

### 硬约束
生活锚点不负责：
- 发任务；
- 讲世界观；
- 代表某种舍破伦理立场；
- 专门安慰陆野。

# 六、现有角色定向修订

## 乔九
保留“时间就是钱”的核心。
必须证明：
> 就算删掉舍眠，他仍是一个有商业野心、会主动压缩线路空转的人。

舍眠只是放大，不是全部人格。

## 罗槐
拒绝标准“冷酷 -> 学会善良”弧。

改成：
> 他始终相信整体安全优先，但对“该舍什么、什么时候舍、谁有资格替别人决定”判断变复杂。

至少设计一次：
- 他前期做出的“弃货/弃风险源”决定是对的；
- 后期类似问题中，表面相似但答案不同。

## 石小庚
必须在一种传统修炼能力上**明显强过陆野**。

候选可以是：
- 御器精度；
- 近战基本功；
- 身法；
- 对护运阵位的熟练度。

不要让他成为“明明什么都不如主角却硬争名额”的假竞争者。

## 唐禾
增加一条不依赖陆野的客户/经纪利益线。

至少写出一次：
> 她为了自己的长期经纪资格/客户信用，做出对小队短期不利但完全合理的决定。

卷末禁止用：
> “为了友情她不要钱了”
来完成成长。

她的成长仍应符合：
> 会算长期账，而不是突然不算账。

# 七、曹闻川与主要阻力

曹闻川型经营者继续保留。

硬规则：

> **不黑化。**

他不能在卷末被揭示为：
- 偷偷制造余灾；
- 明知必出事还故意隐瞒；
- 非法倒卖弃相的大黑手。

他与周照的差异主要是风险阈值：

### 曹闻川
> 没有证据证明存在系统性风险，就不能轻易让几十人停工。

### 周照
> 没证明安全，就不能继续把风险往下游送。

### 陆野
夹在中间：
- 他需要工作；
- 他也看见异常；
- 但自己的尝余又不是可靠证据。

至少给曹闻川2个明确的正面事实，证明他确实在承担经营责任。

---

# 八、把“旧仓库”改成“流程积累”

不要再用：

> 所有问题货碰巧都经过同一个有问题仓库。

改成：

> **一套局部合理的中转流程，在长期运行中不断叠加低水平残留风险，旧中转点只是最严重的聚焦节点。**

至少设计一条5—8环因果链。

每一环单独看都应该：
- 合法或近乎合法；
- 有现实理由；
- 不足以让任何一个普通人立刻判断“必须全面停运”。

候选因素可以包括但不限于：
- 事故货临时等待复核；
- 封存/转运耗材重复使用；
- 夜线缩短停留时间；
- 不同来源货物短期共处；
- 清理流程按单件而非累计环境判断；
- 老设施扩容后继续沿用旧阈值；
- 货损残值处理让部分物品重新进入中转。

但不要为了凑链条全部采用。

最终必须回答：

1. 为什么曹闻川不是坏人？
2. 为什么周照过去没提前发现？
3. 为什么唐禾/乔九的局部选择都“有道理”？
4. 为什么陆野的尝余可以发现异常，但不能直接给出流程因果？
5. 为什么卷末必须处理流程而不只是炸掉一个仓库？

---

# 九、尝余误判必须按“正确感知，错误归因”设计

至少给出 **3个误判机制候选**，例如：
- 共用封布/容器导致沾染；
- 同车运输导致来源混淆；
- 地点余痕附着在无辜货物；
- 多种余痕串味产生错误归因；
- 时间残留导致“曾经有问题”被理解成“现在有问题”。

从中选择1个最适合第一卷的。

硬约束：

- 感知本身不能撒谎；
- 陆野得到的是局部信号，不是标签；
- 错在经验模型、归因、证据边界；
- 必须造成真实经济/信誉损失；
- 第一次误判不建议死人；
- 误判后不能马上升级出一个“更准确模式”。

# 十、传统修仙爽感：三次明确兑现

第一卷必须明确安排：

## 兑现1｜筑基立刻有新动作
事故后不久就让读者看到：
> 稳定离体到底比炼气多了什么。

必须用于真实行动，不做境界说明书。

## 兑现2｜中段纯修仙护运/战斗
新增一个完整故事单元：

> **尝余完全帮不上忙。**

陆野主要依赖：
- 筑基能力；
- 普通法器；
- 战斗/护运技巧；
- 同伴配合。

石小庚至少在其中一项上明显强于陆野。

## 兑现3｜卷末
高混杂余灾中：
> 尝余接近失效。

最终解决仍靠：
- 正常修炼；
- 队伍；
- 货流/路线知识；
- 舍务封控。

本轮必须检查三次兑现是否互相重复。

# 十一、重排第一卷10—12个故事单元

基于 Top 1 重做，不再同时发展 Top 2 全卷方案。

Top 2只作为素材库抽取：
- 普通残货处理；
- 产权冲突；
- 没尝到不等于安全；
- 一件窄用途余器。

新故事单元必须至少覆盖：

1. 正式名额竞争；
2. 第一次事故 + 舍味筑基；
3. 私人生活/味觉缺失；
4. 限制复工 + 第一次外界异常确认；
5. 道路/护运中的正常安全决策；
6. 一次窄用途余器；
7. 纯传统修仙战斗/护运；
8. 完整续我/借载路线人物对照；
9. 尝余正确感知、错误归因并造成损失；
10. 流程风险逐渐浮出；
11. 人物/经营/监管三方冲突升级；
12. 卷末余灾与流程整改。

不要求最终一定12个，可以合并到10—12。

每个单元仍回答：
- 陆野想要什么；
- 谁阻止；
- 哪个角色主动制造变化；
- 陆野正常修炼是否有兑现；
- 尝余作用是0 / 辅助 / 误导 / 接近失效中的哪一种；
- 事件后新增什么不可逆状态；
- 删除余世后人物冲突是否仍成立。

# 十二、第一卷阶段节奏

不是正式章纲，但要给出4个功能阶段。

建议测试：

### Phase A｜想转正，事故把路打断
约全卷前20—25%。

### Phase B｜限制复工，能力从后遗症变成“有用”
约25—50%。

### Phase C｜拿回资格，但能力开始被定价并第一次害人
约50—75%。

### Phase D｜争固定席位，流程风险集中爆发
约75—100%。

可以修改比例，但必须满足：

> **一级目标不能拖到卷末才完成。**

否则两级目标没有意义。

# 十三、卷末奖励与第二卷发动机

卷末至少同时兑现：

1. 正式押货资格；
2. 固定小队/固定路线席位；
3. 小范围职业名声；
4. 第一卷人物关系里至少一处不可回退变化。

第二卷不能只变成：
> “更多怪货来找陆野。”

必须同时新增三层责任：

### 职业责任
陆野开始对路线、杂役、货主、风险决策负责。

### 组织责任
流程整改后，危险/异常货物需要新的分类、转运或护送方式。

### 人物责任
队伍内部第一次出现：
> 是否应该把陆野的尝余写进岗位职责、风险分成或报酬体系？

不要现在设计完整第二卷，只证明第一卷成功后发动机确实换挡。
