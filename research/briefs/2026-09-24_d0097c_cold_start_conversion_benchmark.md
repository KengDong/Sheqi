# Core Questions

For each selected work, inspect as much of:
- title;
- synopsis;
- first screen / free opening when legitimately accessible;
- chapter titles;
- early-reader/public evidence;
as evidence permits.

Explicitly label:
FULL/PARTIAL PROSE / SYNOPSIS / CATALOGUE / COMMUNITY.

Extract:

1. What does the reader know about the protagonist after 500 words?
2. Can the protagonist be described without mentioning the power/system?
3. What is the first behavior that only this protagonist would plausibly do?
4. What is the first memorable line / joke / attitude / social reversal?
5. Is humor character-generated, premise-generated, or narration-generated?
6. How quickly does a recurring relationship gain chemistry?
7. How oral / conversational is the prose?
8. How many paragraphs pass before an immediate fruit?
9. What is the title/synopsis/chapter-one promise alignment?
10. Why might a reader tell a friend about this opening in one sentence?
11. What looks "cheap" but actually improves conversion?
12. What tricks create short-term clicks but hurt long-run trust?
13. Which functions work for serious books without forcing comedy?

## Author Direction｜Do Not Penalize Successful Comedy / Madness

The author explicitly welcomes:
> strong comedy / deranged energy / exaggerated personality

IF it creates real addictive reading and still supports long-run compounding.

Therefore this benchmark must identify:
- which funny books are actually highly commercial rather than merely meme-heavy;
- how jokes arise from character/world logic;
- how serious stakes coexist with comedy;
- how high-conversion comic protagonists avoid becoming one-note;
- how humor survives 50/100+ chapters;
- when an intentionally outrageous opening is commercially superior to a restrained one.

Do not downgrade a route for being “不够高级” if reader pull is stronger.
