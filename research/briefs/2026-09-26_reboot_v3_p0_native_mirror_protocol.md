# REBOOT-V3 P0 First Screen｜Native vs Commercial Mirror

## Goal
For each ACTIVE candidate, produce two 800–1500 Chinese-character first-screen prototypes.

Test:
> does proven commercial cold-start function improve voluntary continuation for THIS original book?

## Variant N｜NATIVE
Writer may read only:
- this protocol;
- candidate-specific Native Input Card.

Write the strongest first screen from the candidate's own:
- package promise;
- protagonist;
- recurring relationship seed;
- Near horizon.

Then FREEZE it.

Before freeze, do NOT read:
- Mirror Function Card;
- benchmark prose;
- other candidate prose.

## Variant M｜COMMERCIAL MIRROR
Only after Variant N is frozen, read:
- candidate-specific Mirror Function Card.

Write a second first screen for the SAME original book.

May mirror only FUNCTIONS:
- how fast concrete situation starts;
- information order;
- premise activation timing;
- protagonist decision timing;
- payoff/danger timing;
- recurring-person entry timing;
- chapter/screen-end desire function.

Forbidden:
- copied wording;
- same scene sequence as a benchmark;
- benchmark character mapping;
- benchmark system/power;
- iconic conflict/reveal/joke;
- living-author prose voice;
- cosmetic renaming of a hit opening.

If the imagined first three beats map one-to-one onto a benchmark:
> reject and rewrite before output.

## Shared P0 hard
Length:
> 800–1500 Chinese characters per variant.

Only test:
- package promise兑现;
- protagonist presence/voice;
- premise-in-action;
- first-screen continuation.

Do NOT:
- finish Ch1;
- explain full world;
- execute Mid horizon;
- add new core mechanic;
- add a new major character;
- optimize toward later architecture.

## Output discipline
Each candidate writer outputs:
- Variant N;
- N freeze marker / commit;
- Variant M;
- selfcheck.

No writer sees competitor prose.

## Downstream evidence
First:
> blind pairwise reader chooses N or M for each premise, or neither.

Then:
> four selected P0 winners are anonymized and compared cross-candidate.

Reader may stop voluntarily.
No score-first protocol.

## Interpretation
Mirror wins:
> evidence that benchmark-guided cold-start execution helps this candidate.

Native wins:
> evidence that direct benchmark cadence was unnecessary or flattened this candidate's own premium.

Neither works:
> candidate receives P0 root warning regardless of strong design evidence.
