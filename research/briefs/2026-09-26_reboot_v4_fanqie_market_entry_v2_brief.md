# REBOOT-V4｜Fanqie Market Entry V2
## 审计后第一棒：只研究“新人值得进入哪个Reader Pool”

# 0. Authority

Read first:
1. `meta/RESTART_AUTHORITY_V1.md`
2. `reviews/2026-09-26_master_failure_postmortem_and_repo_reset.md`

Do NOT use old candidate PASS / ACTIVE / READY as current evidence.

# 1. Highest question

> **For an unknown first-time male web-fiction author launching on Fanqie in late 2026, which exact CURRENT reader pools are genuinely worth entering?**

This is NOT:
- “what genres are big?”
- “what structures are easy?”
- “what can AI serialize?”
- “which Sheqi concept should win?”

# 2. Platform scope

Primary:
> **Fanqie only.**

Use Qidian only when useful as:
- historical/control evidence;
- cross-platform contrast.

Qidian success may NOT validate a Fanqie lane by itself.

# 3. Evidence window

Prioritize:
- current / recent Fanqie official reading ranks;
- current / recent Fanqie new-book ranks;
- category rankings where useful;
- official work pages;
- official writer-platform rules / recommendation / quality-governance information;
- current public reader reaction when useful.

Refresh evidence during execution.
Do not reuse stale numbers uncritically.

# 4. Reader-pool resolution

Do NOT stop at:
- 玄幻;
- 都市;
- 历史;
- 末日.

Resolve to commercially meaningful pools such as:
- urban supernatural monster hunting;
- folk horror competence;
- rule survival;
- lord-building;
- family cultivation;
- historical high-martial court survival;
- campus male relationship reversal;
etc.

The pool must represent:
> readers competing for substantially the same fantasy.

# 5. Required sample per serious pool

Where evidence is available:
- 3–5 current/recent Fanqie strong direct comps;
- at least 1 current/recent new-book / newcomer / low-author-credit success;
- 2 ordinary/weaker matched controls;
- at least one work with enough length to show post-novelty retention.

If these cannot be found:
> mark evidence gap explicitly.

Do NOT pad with adjacent genres.

# 6. Required analysis fields

For every evidence-qualified pool:

1. **Exact Reader Pool**
2. **Current Strong Comps**
3. **Current New-Book Proof**
4. **Newcomer Access Proof**
5. **Primary Reader Fantasy**
6. **Secondary Fantasy Bundle**
7. **Protagonist Fantasy**
8. **Dominant Repeated Scene Pleasure**
9. **Ch1–3 Promise Delivery**
10. **What still works after novelty fades**
11. **Competition Density**
12. **Packaging Sameness / Commodity Risk**
13. **Trend Lifecycle**
   - rising;
   - durable;
   - late-cycle/saturated;
   - uncertain.
14. **Matched Weak Controls**
15. **Why weak controls fail despite fashionable features**
16. **Substitution Space**
   - what meaningful appetite is still open?
17. **Platform Fit**
   - why this works specifically on Fanqie.
18. **Quality / AI-pattern Risk**
19. **Compliance Risk**
20. **Evidence Confidence / Missing Evidence**

# 7. Hard distinction

For every strong work separate:

> **PRIMARY READER FANTASY**

from:

> **DELIVERY VEHICLE**

A profession / school / shop / organization / system / occupation is NOT automatically the fantasy.

# 8. Newcomer hard question

For every pool ask:

> **If the author name were blank, what lets the book earn Ch2/Ch3?**

Veteran-only evidence:
> HIGH ENTRY RISK.

# 9. Failure-corpus hard

Do NOT study only winners.

Matched controls must test:
- same/similar tags;
- similar package;
- similar opening promise;
- materially weaker current performance where public evidence is available.

Ask:
> what features both winner and loser share, therefore cannot explain the winner?

# 10. No cargo cult

Do not conclude:
> “X is hot, therefore copy X.”

Need distinguish:
- hygiene;
- causal fantasy;
- execution premium;
- current timing;
- author-brand effects.

# 11. Author-facing output

Create:

> `experiments/reboot_v4/author_choice/fanqie_market_entry_board_v2.md`

It must contain only evidence-qualified pools.

Per row:
- exact reader pool;
- what it FEELS like to read;
- 2–4 representative Fanqie hits;
- newcomer/new-book proof;
- repeated fantasy;
- competition / saturation risk;
- open substitution space;
- major execution burden.

Do NOT:
- score;
- rank;
- recommend #1;
- label winner.

AUTHOR will mark:
> WANT / MAYBE / NO.

If yes:
> CONDITIONAL / EXCLUDE FROM BOARD unless evidence remains sufficient.
