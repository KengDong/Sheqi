# D-0111｜Reality Character Magnet Lab
## 方岑 / 程小满现实人物吸引力实验

# 0. Why This Gate Exists

Current Ch1—8 source has just received a full Opening rewrite.

Before spending another clean voluntary-reader run on the complete package, the author identified a likely high-value remaining gap:

> Reality-side recurring characters are still carrying more plot function than reader-desire value.

Specific targets:
- 方岑
- 程小满

Both are intended to become recurring reality-world attractions.

Therefore:
> do NOT immediately send the current Ch1—8 package to the final voluntary reader.

First determine which characterization direction creates the strongest:
- recognition;
- affection;
- competence trust;
- desire to see the character again;
- desire to return to reality scenes after a Field.

External preference scan:
> `research/2026-09-25_reality_female_character_reader_preference_scan.md`

# 1. Hard Order of Operations

## Gate A｜Hard Continuity Check on Current Ch1—8
Owner:
> rule_reality_full_focus_successor

Purpose:
- logic only;
- R1 mechanic consistency;
- Ch4→Ch5 continuity;
- no character-style verdict;
- no broad prose rewriting.

If hard pass:

## Gate B｜Controlled Character Micro-Prototypes
New isolated writer:
> reality_character_magnet_lab_writer

No full-chapter rewrite.

Create compact variants using the SAME plot facts.

### 方岑
Create 3 directions:

A. 漂亮 + 职业稳 + 有边界
B. 漂亮 + 松弛/吐槽反差 + 瞬间职业化
C. 漂亮 + 夜班生活狼狈 + 高可靠

Each variant must cover TWO beats:
1. first police-booth appearance;
2. one later competence/boundary beat from the same-name test / Wei Pingzhou counter-use.

Must preserve:
- she does not expose Cheng Ye for thematic effect;
- she is not romantically interested by default;
- she has professional autonomy;
- she does not become an exposition machine.

### 程小满
Create 3 directions:

A. 哥哥失踪后的高粘度亲妹
B. 小太阳 / 嘴碎 / family-atmosphere engine
C. 可爱 + 小坏 + 护哥

Each variant must cover THREE beats:
1. freight-yard rescue / first physical reunion;
2. police-station pressure;
3. home breakfast / next-entry countdown.

Hard:
-亲妹关系 only;
- no pseudo-romance / sexualized possessiveness;
- she must still make independent choices;
- she cannot become a pure rescue button.

# 3. Character Reader Test

After variants are complete:

Create anonymous variant packages.

Use TWO clean-room readers.

Each reader evaluates both characters, but variant order must be randomized independently.

Do NOT ask:
> which is “best written”?

Ask behaviorally:

## 方岑
- which version do you most want to meet again?
- what exact behavior made you remember her?
- which version felt like a cliché “警花”?
- did beauty increase appeal or feel author-pushed?
- which version felt most professionally credible?
- would you want a reality chapter centered on her even if Cheng Ye were not present?

## 小满
- which version made you most want more sibling scenes?
- which version felt cute rather than childish?
- which version felt like a real person rather than “主角妹妹”?
- which version would make you look forward to Cheng Ye returning from a Field?
- which version, if any, felt too “兄控标签化”?
- did she make any choice that felt truly hers?
