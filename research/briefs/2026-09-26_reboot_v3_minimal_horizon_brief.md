# Task

For each ACTIVE candidate define exactly:

## Near｜Ch1–3
One concrete reader wait:
> what must happen soon enough that clicking feels rewarded?

It must:
- directly deliver the package promise;
- involve the protagonist;
- seed at least one recurring person;
- leave one permanent state change.

## Mid｜roughly Ch10–30
One named, visible outcome:
> what can the reader point to and say “the book has clearly moved forward”?

Examples of form only:
- a place becomes viable;
- a team earns a status;
- a relationship changes role;
- an operating loop becomes self-sustaining.

Do not invent a new core mechanic.

## Far｜100+ chapter shadow
One scale question / desire:
> what larger version of the SAME book naturally becomes imaginable?

It must grow from:
- accumulated people;
- assets;
- reputation;
- rights;
- obligations;
- old state.

Do NOT rely on:
- new universe;
- secret god system;
- sudden apocalypse escalation;
- entirely new profession;
- terminal mystery rescue.

# Required Desire Chain

Show:
> Near payoff creates Mid desire;
> Mid payoff creates Far desire.

If the chain only works by adding a new gimmick:
> WARNING.

# Character Integration

For each horizon:
- name which recurring relationship matters;
- show how old relationship state changes the next desire.

Do NOT add major new core characters.

# AI / Newcomer Check

For each candidate:
- does this horizon make the book easier or harder to serially produce?
- does Mid/Far increase human-only craft burden?
- does it create a research tax?
- does it preserve state compressibility?
