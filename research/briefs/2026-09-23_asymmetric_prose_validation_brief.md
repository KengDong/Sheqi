# 2. C01｜只写Ch11—20

目标：
> 把“顾经理可能复购”写成稳定客户，同时让罗晴从陌生人变成第一位真实长期协作人。

必须兑现：
- 顾经理真的先发需求；
- 沈桥因为一个人扛太多漏掉真人承诺，真赔 / 真失信；
- 罗晴先按次/按周进入，不直接高效入职；
- 罗晴至少一次拒绝替沈桥免费救火；
- 方栀轮岗结果兑现；
- 陈美兰Ch9挂牌真实完成；
- 到Ch20，沈桥第一次有一段可预期收入、第一长期协作人，并能一段时间不卖自己。

### C01 Anti-Cargo-Cult
每章写前问：
> 如果把“时间”换成普通劳务，这章是否几乎不变？

若是：
> 必须加入只有“本人真实缺席 / 时间权利边界 / 未来被出售”才能产生的摩擦。

但不要硬塞概念。

### Arc A 18:00交接
不是Hard Signature。

如果现场只是：
> A到点，B接班，
就简写。

只有当它真正写出：
> 工作能连续，但本人经历不连续；18:00以后客户没有权继续占用赵先生
的独特体验时才放大。

### C01 STOP
不写Ch21。
不提前写“罗晴赎回周日”。

# 3. C12｜只写Ch11—15

目标：
> 让读者先追周野、老薛、赵航的人生，再自然遇到职业风险。

必须兑现：
- 周野真的选机构 / 复评 / 交预约金 / 定日期；
- 老薛为了家庭现金需要考虑连续高风险夜班；
- 周野和老薛第一次真实利益/价值冲突；
- 老薛恢复异常只推进半步，不能确诊职业劫债；
- 老薛最终自己在接驳车前取消；
- 取消后真钱缺口立刻存在；
- 周野可以借钱，但只能桥接一部分；
- 赵航自然成为筑基恢复联系人 / 落脚处；
- Ch15周野自己的筑基必须有真实日期。

### 早餐铺Guard
不能写成：
> 刚好缺X元 = 三晚班刚好X元。

要有现实毛边：
- 家庭自己也在凑；
- 老薛三晚只能补大部分；
- 铺位选择此前已有生活背景；
- 周野不是唯一解。

### 借钱Guard
周野：
- 借，不送；
- 记账；
- 压自己的筑基预算；
- 只补部分；
- 老薛必须有接受难度。

### Secret Guard
不要写：
> 周野和老薛同一种异常。

只让：
> 两个人都开始无法相信“风险下班即清零”。

### C12 Anti-Cargo-Cult
Life-First不等于写成普通工人生活文。

必须保留只有C12能有的：
> 为了筑基 / 分劫 / 高暴露夜班才产生的人生冲突。

如果换成普通高危工种也完全一样：
> 独特性不足。

# 4. PROSE STANDARD

两本都：
- 场景先于解释；
- 人的利益先于主题；
- 不让角色说出完整作者结论；
- 少UI / 少状态页；
- 章尾优先具体动作或未完选择；
- 不连续“不是X，而是Y”总结。

C01保持：
> 冷一点、都市现实、钱和时间权利。

C12保持：
> 热一点、工友生活、修炼荒诞和身体风险。
