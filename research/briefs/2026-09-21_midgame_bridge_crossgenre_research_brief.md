# 二、为什么要单独研究中段

本项目已经解决：
- 核心设定；
- 开篇身份方向；
- 第一卷发动机强候选。

现在最大的未来风险不是“开头不够抓人”，而是：

1. 第一卷职业目标结束后故事重置；
2. 尝余变成每周破案工具；
3. 余器变成怪物卡牌；
4. 主角每卷只换一个更大对手；
5. 人物关系不积累；
6. 只靠余世秘密拖悬念；
7. 100章以后职业线、修炼线、主线互相脱节。

本研究只负责提前发现并堵这些结构风险。

# 三、样本不要只看最热门修仙

必须分四层研究。

## A层｜当前/长期头部仙侠男频
约6部。

用途：
> 研究当前读者已经接受的节奏、升级、卷间换挡、人物关系和主线扩张。

可从：
- 《玄鉴仙族》
- 《没钱修什么仙？》
- 《夜无疆》
- 《仙工开物》
- 《光阴之外》
- 《赤心巡天》
- 《诡秘之主》
等中选高相关样本。

## B层｜稳定次热门 / 腰部长期连载
约6—8部。

要求：
- 有持续读者；
- 不一定榜一、十万均订或超级IP；
- 最好有100万字以上或多个完整阶段；
- 重点看“普通作者可复制的结构能力”，而不是只靠大神个人文风/品牌。

必须解释：
> 为什么这个样本虽然不是最头部，却对新作者更有参考价值。

## C层｜跨题材高相关样本
约8—10部。

至少覆盖：

### 职场 / 商业 / 经营
研究：
- 资格 -> 岗位 -> 责任 -> 团队 -> 组织升级；
- 成功为什么会制造更多责任。

### 刑侦 / 悬疑 / Procedural
研究：
- 单元事件怎样不重复；
- 线索怎样跨单元积累；
- 如何避免“每周一个案子”。

### 公路 / 冒险 / 探索
研究：
- 路线变化怎样换空间、人物、利益和危险；
- 旅行如何不沦为打卡地图。

### 团队任务 / 盗宝 / 行动类
研究：
- 不同角色能力如何真正不可替代；
- 计划失败怎样改变关系与下次行动。

### 体育 / 电竞 / 竞技成长
研究：
- 技能进步怎样可见；
- 对手如何成为标尺而非一次性反派；
- 阶段目标如何持续换挡。

### 家族 / 群像
研究：
- 配角如何拥有自己的生活、利益和长期后果；
- 主角不在场时故事如何继续。

### 灾难 / 生存 / 系统风险
研究：
- 小问题怎样通过局部合理决策累积成大问题；
- 危机解决后制度/生活为什么不能完全恢复原状。

### 喜剧 / 日常 / 关系戏
研究：
- 如何给沉重主线呼吸；
- 重复人物怎样靠关系变化而不是新设定持续有趣。

可以补恋爱、医疗、律政、商战等，只要明确借的是结构功能。

## D层｜失速 / 中段疲软样本
至少3—5部。

不要求公开羞辱作品。

研究重点：
- 第一卷很好，100—300章为什么开始重复？
- 是敌人膨胀？
- 单元模板化？
- 人物工具化？
- 谜团只加不解？
- 社会位置不再变化？
- 世界扩大但生活感消失？

这一层非常重要，防止只做成功者偏差研究。

# 四、研究区间

不要研究前三章。

重点观察：

> **约50—300章 / 第一卷结束到第三、第四个完整阶段。**

如果作品卷制不同，按功能阶段而不是死章数。

每部重点找：
1. 第一目标完成在哪；
2. 完成后新目标怎么出现；
3. 中间有没有“故事泄气区”；
4. 哪个角色/组织/地点接手了下一发动机；
5. 旧人物是否继续产生后果；
6. 主角社会位置怎么升级；
7. 主线谜团释放多少；
8. 新地图是不是只是换皮；
9. 战力升级是否改变解题方式；
10. 第二、第三阶段结束后又留下什么债。

# 五、必须研究的核心问题

## 1. “阶段成功”怎样不等于故事清零

整理成熟作品最常见的：
- 成功增加责任；
- 成功招来新对手；
- 成功改变组织位置；
- 成功产生利益依赖；
- 成功暴露能力；
- 成功破坏旧平衡；
- 成功制造关系债。

不要只列，要找实际机制。

## 2. 中段怎样轮换发动机

至少区分：
- 职业发动机；
- 修炼发动机；
- 人物关系发动机；
- 组织/制度发动机；
- 地域/旅行发动机；
- 谜团发动机；
- 灾难/压力发动机。

研究强作品怎样：
> 一个发动机变弱时，另一个已经开始加速。

## 3. 怎样防单元剧疲劳

重点研究：
- 单元是否改变长期状态；
- 配角是否跨单元带债；
- 旧单元结果是否在后续反噬；
- 单元目标是否不断换种类；
- 有没有故意让主角核心能力无用的事件；
- 有无“私人生活”承接单元之间空隙。

## 4. 怎样扩世界而不换一本书

研究：
- 固定人物留下多少；
- 新地域与旧利益如何相连；
- 主角为什么非去不可；
- 旧职业/身份是否继续有价值；
- 世界扩大时生活细节是否仍在。

## 5. 修炼升级怎样改变故事方法

不是：
> 数字更大。

而是：
> 新境界让主角可以做以前不能做的事，因此事件结构也变化。

这一点要特别反馈给《舍弃》的六境行动动词。

# 六、专门针对《舍弃》的中段桥梁研究

不要写具体第二卷大纲。

只构建“桥梁状态”。

假设第一卷强候选大体成立：

> 临时杂役 -> 正式押手 / 固定路线成员  
> 漏舍异常被有限范围确认有实用价值  
> 小队形成  
> 一套中转流程暴露长期积累风险

请研究第一卷结束后至少需要留下哪些**状态变量**，才能自然进入100—300章。

至少考虑：

### 职业
陆野从“争资格”变成“开始对别人和任务负责”。

### 队伍
固定队伍内部：
- 分成；
- 风险；
- 任务选择；
- 是否利用尝余；
必须出现真实矛盾。

### 能力定价
别人开始给陆野的缺位估价、排班、定责任。

### 拾余
从偶然发现“某些残留有窄用途”，逐步发展到：
> 是否存在可重复的方法？

但禁止第一卷后立刻工业化。

### 余灾
从单点/节点风险扩展到：
> 不同地方为什么出现相似模式？

### 制度
舍务系统知道多少、货运/商贸系统如何应对，逐步进入主线。

### 修炼
约100章附近若安排一次真正完整续我/正破，其前后应如何改变陆野的社会评价和自我理解。

# 七、至少提出3种“中段发动机家族”

不是第二卷大纲，而是可轮换的发动机。

例如但不限于：

## 家族A｜职业升级
固定小队 -> 更复杂路线 -> 对人/货负责 -> 接触更多组织。

## 家族B｜拾余方法化
偶然拾到 -> 可验证 -> 小规模复用 -> 出现需求 -> 产生利益冲突。

## 家族C｜余灾治理
单点事故 -> 相似模式 -> 地区性治理 -> 制度与现实代价冲突。

每一种必须说明：
- 能撑多少阶段；
- 何时会疲劳；
- 哪个发动机应该接棒；
- 会不会把书变成另一种类型。

# 八、特别关注“中段衔接”，不是“中段填充”

严禁把中段理解成：
> 在主线揭秘之间塞20个任务。

必须研究：

> **上一阶段的结果怎样成为下一阶段的原因。**

输出至少10种“桥接机制”，例如：
- 资格变责任；
- 名声变邀约；
- 工具变产业需求；
- 同伴变利益共同体；
- 对手变合作方；
- 事故整改产生新岗位；
- 一次赔偿形成长期债；
- 一次救人形成关系债；
- 一次错误判断改变制度流程；
- 一次成功让主角进入新的定价体系。

这些只是示例，不得机械采用。

# 九、对“次热门”必须单独回答

最终报告必须有一节：

> **为什么新作者不能只学头部爆款？**

必须具体讨论：
- 大神品牌和读者耐心；
- 强文风掩盖结构问题；
- 极端高概念不可复制；
- 头部作品可能靠过去积累获得更长试错空间；
- 腰部稳定作品哪些结构反而更容易迁移到普通新作者。

同时也要防止：
> 因为“次热门更普通”就默认它更值得学。

只看功能适配。

# 十、为第一次写长篇小说的作者设计

本项目作者是第一次写小说。

因此最终建议不能只说“这样更高级”。

必须额外回答：

1. 哪些结构应该提前锁？
2. 哪些只需要知道方向，不要提前锁死？
3. 哪些内容最容易在真正写作时失控？
4. 每写完20—30章应检查什么？
5. 如何判断一个支线该继续、收束还是砍掉？
6. 如何避免研究/大纲做得很漂亮，正文却没有人物即时欲望？
7. 如何用简单工具维护人物状态、关系债和未兑现承诺？

目标是：
> 给第一次长篇作者一个能执行的中段控制方法，而不是文学理论。
