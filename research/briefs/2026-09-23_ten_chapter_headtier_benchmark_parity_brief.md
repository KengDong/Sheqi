# 2. BENCHMARK SET｜按功能对比，不按题材硬模仿

至少覆盖以下功能型Benchmark：

## 《没钱修什么仙》
主要看：
- 高耦合事件密度；
- 钱 / 修炼 / 阶层 /学校 / 关系同时推进；
- 现代生活与修仙天然融合；
- 小爽点连续性；
- 中段不靠单一Concept。

## 《十日终焉》
主要看：
- 近谜 -> 中谜 -> 大谜；
- 每次答案是否产生更大追读欲；
- 旧事件重解释；
- 群像与秘密是否互相喂养。

## 《天才俱乐部》
主要看：
- 长期未知量；
- 小异常如何持续放大；
- 终极秘密与人物命运绑定；
- “知道答案”是否改变行动。

## 《都重生了谁谈恋爱啊》
主要看：
- 事业 / 团队 / 关系复利；
- 日常生活本身是否值得看；
- 主角社会位置如何通过别人行为变化；
- 中距离果实。

## 《国民法医》
主要看：
- 专业判断 -> 现实结果 -> 认可 -> 资源 -> 更高位置；
- 单元事件如何不清零；
- 专业内容如何避免教材感。

## 《御兽从零分开始》或同类长期高黏性成长文
主要看：
- 非主角/伙伴黏性；
- 成长可视化；
- 高频小回报；
- 日常互动能否独立撑阅读。

注意：
> 只提取“为什么好看”的功能。
> 不复制具体情节、人物或表面皮肤。

# 3. 只比较九个真正影响追读的维度

禁止100项评分表。

## 3.1 First-10 Combustion
十章内是否：
- Hook强；
- 很快有第一次胜/负；
- 玩法发生变化；
- 人生位置明显改变。

## 3.2 Character Attachment
是否已经出现：
- 主角之外舍不得的人；
- 有自己欲望的人；
- 会记旧账的人；
- 能独立制造剧情的人。

## 3.3 Mid-Horizon Desire
读者是否明确在等：
> 10—30章内某件具体事情发生。

## 3.4 Reward Density
钱 / 地位 / 能力 / 关系 / 生活 /秘密：
> 是否轮换兑现。

## 3.5 Compounding
一次事件结束后是否留下：
- 人；
- 钱；
- 权限；
- 责任；
- 名声；
- 身体；
- 债；
- 下一次机会。

## 3.6 Signature Engine
是否有：
> **“只有这本书能稳定提供”的阅读体验。**

C01重点：
- 卖掉的是真实人生缺席；
- 未来本人权利。

C12重点：
- 工业修仙生活；
- 风险不会消失。

## 3.7 Long-Horizon Pull
100章以后为什么还追：
- 秘密；
- 终极问题；
- 人生目标；
是否已经从前十章自然萌芽。

## 3.8 Ordinary-Life Durability
没有更大奇观时：
> 人物吃饭、工作、赚钱、关系变化本身是否值得看。

## 3.9 Prose / Reading Friction
是否像成熟连载：
- 不卡；
- 不解释过量；
- 不像设计稿；
- 人物对白有各自利益；
- 章尾自然想点下一章。

# 6. Popular-Parity Red Flags

重点主动寻找：

- 头部热门前十章已经形成2—4个强人物资产，而我们还没有；
- 对手书每10—20章有明确“等着发生的大事”，我们没有；
- 对手书普通日常能看，我们只能靠Concept；
- 对手书一件事同时烧5个账本，我们是接口并排；
- 对手书升级通过别人行为可见，我们只发系统通知；
- 对手书每阶段有名场面，我们只有结构性正确；
- 对手书中距离爽点比我们更具体；
- 对手书秘密答案不断改变现实，我们只会继续埋。

发现即直说。

# 7. Exceed Test｜什么才算“有机会超过”

不是：
> Concept比别人新。

必须满足：

### 底盘
至少达到头部热门的：
- 人物黏性；
- 回报密度；
- 中距离期待；
- 普通生活耐看；
- 连续阅读摩擦低。

### 再有超额
C01至少证明：
> “未来人格权利 + 真实人生缺席”
能产出热门样本里较少见、但同样强的情绪/选择场面。

C12至少证明：
> “工业化渡劫 + 风险不消失”
能让工友生活、修炼和大秘密形成比普通职业文更高耦合的长期体验。

若只有超额Concept、底盘没齐：
> 不得称“超过”。
