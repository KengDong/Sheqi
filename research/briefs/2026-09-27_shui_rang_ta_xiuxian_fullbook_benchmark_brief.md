## Mission

对《谁让他修仙的！》做“整本长篇工程学”研究。

不是模仿文风。
不是摘抄金句。
不是统计笑话。
不是找可以换皮复用的桥段。

最高问题只有一个：

> 为什么这部作品不只是前几章轻松好笑，而是能把“人物认真做事 -> 事情自己越来越离谱/有趣 -> 后果继续影响下一步”的阅读快感维持到百万字长篇，并且在中后期还能承载世界观、人物关系和严肃主线？

研究结果最终必须服务于《全班绑定道种，我绑定的是异界活人》的长期创作，但只能迁移功能机制，不得迁移具体场景、人物配置、事件顺序、标志性桥段或作者语言风格。

---

# 1. Source discipline

优先使用：
1. 起点中文网官方书页、目录、可公开阅读章节；
2. 阅文官方渠道；
3. 作者公开采访 / 完结感言 / 创作谈；
4. 高质量长评、读者讨论，仅用于验证读者实际感受，不可代替正文证据。

若无法合法访问全部正文：
- 不得声称“逐章全文深读完成”；
- 必须明确哪些区间是 FULL READ；
- 哪些区间是 DENSE SAMPLE；
- 哪些区间只通过目录、公开摘要、读者讨论建立 ARC MAP。

如果项目后续获得用户合法提供的完整电子版：
> 再升级为逐章全覆盖审读。

禁止：
- 大段复制原文；
- 建立可复原原作的逐章剧情摘要；
- 输出连续详细情节复述；
- 仿写作者句式；
- 把原作标志性桥段换名搬进项目。

# 2. 全书研究层级

不要从第1章一路机械记到大结局。

必须分五层。

## Layer A｜Macro Arc Map
建立全书阶段图：

至少标出：
- 入宗 / 新手期；
- 宗门生活发动机成型；
- 陆阳 + 孟景舟固定搭档发动机；
- 不朽仙子进入后的关系变化；
- 任务 / 外出 / 秘境 / 城镇等场景轮换；
- 世界观扩大节点；
- 古代史 / 仙人线进入节点；
- 中期主线压力提升；
- 后期严肃线与喜剧线并存方式；
- 最终回收 / 结局阶段。

每一阶段只回答：
> Reader主要在等什么再次发生？

不要做流水账。

## Layer B｜20个 Representative Arc 深读
从全书挑至少20个功能不同的连续小篇章 / arc。

必须覆盖：
- 纯宗门日常；
- 陆阳孟景舟双人行动；
- 不朽仙子参与；
- 任务型剧情；
- 战斗型剧情；
- 查案 / 信息差剧情；
- 误会型剧情；
- 宗门长辈参与；
- 新地域；
- 历史 / 古代人物；
- 严肃危机；
- 中后期大主线；
- 结局回收。

每个 arc 深读连续章节，不允许只看一个梗。

## Layer C｜Comedy Causality Database
收集至少40个“删掉俏皮措辞以后仍然成立”的事件喜剧样本。

每个样本必须拆：
1. 正常前提；
2. 哪个人认真得出了什么判断；
3. 为什么这个判断对他本人合理；
4. 他实际做了什么；
5. 行动怎样改变现场；
6. 第二个人怎样被卷进来；
7. 是否继续改变第三个人 / 制度 / 后续剧情；
8. 有没有后续回收；
9. 如果删掉语言笑点，事情本身还剩多少趣味。

重点：
> 找“事件发动机”，不找段子。

## Layer D｜Long-form Engine
研究为什么相同模式没有50章就腻。

重点回答：
- 陆阳的核心人格发动机是什么；
- 孟景舟不是工具人的原因；
- 不朽仙子怎样改变原有双人发动机；
- 云芝为什么不会只是“强大师姐”功能卡；
- 为什么宗门里大量配角都能短时间形成辨识度；
- 同一类笑点怎样换场景、换关系、换后果；
- 为什么任务 / 秘境 / 战斗不会退化成单元副本流水线；
- 世界观真相怎样逐渐从“笑点背景”变成“主线压力”；
- 严肃线来了以后为什么不会感觉换了一本书；
- 早期荒诞信息怎样在后期被重新解释 / 回收；
- 主角成长以后，早期“歪脑筋”为什么还能继续工作。

## Layer E｜Reading Rhythm / Prose Function
不模仿句式，只研究镜头调度。

建立至少80个镜头样本：
- 一句话跳过普通过程；
- 多停几十到几百字的人物碰撞；
- 笑点前的必要铺垫长度；
- 笑点后作者什么时候不解释；
- 战斗什么时候只写结果；
- 什么时候愿意拍动作过程；
- 世界观解释怎样嵌入欲望 / 任务 / 误判；
- 普通生活动作什么时候值得保留；
- 章节末尾最常留下哪一种“下一步未完成”。

# 3. 必须专项研究的十二个问题

## Q1｜陆阳为什么第一章就能被认出来？
不能回答“聪明、搞笑、脑回路清奇”。
必须给重复行为结构。

## Q2｜陆阳与孟景舟为什么不会变成主角 + 捧哏？
研究两个人各自：
- 独立欲望；
- 独立判断；
- 独立犯错方式；
- 单独撑剧情能力；
- 互相改变决策的方式。

## Q3｜一个笑点怎样跑完整？
重点追：
> premise -> judgment -> action -> scene change -> reaction -> consequence -> callback

## Q4｜为什么NPC不是台词工具？
研究：
- NPC自己的目标；
- NPC如何反过来改变主角；
- 哪些NPC只出现几章却仍然有生命感。

## Q5｜为什么宗门日常可以一直写？
研究：
- 场景固定但冲突目标变化；
- 制度、师徒、同门怎样不断产生新组合。

## Q6｜为什么出了宗门仍然像同一本书？
研究人物发动机怎样迁移，而不是场景复制。

## Q7｜战斗为什么不会把轻喜剧掐死？
研究：
- 战前；
- 战中；
- 战后；
三处轻松与严肃的比例变化。

## Q8｜什么时候完全不搞笑？
明确作者在哪些风险等级下收掉笑点，以及如何恢复。

## Q9｜世界观为什么不是百科？
研究每个大设定第一次出现时：
> 它当场改变了谁的什么选择？

## Q10｜中后期为什么还能追？
把“Reader在等下一次好笑事件”与更大的：
- 关系；
- 真相；
- 成长；
- 世界危机
连接起来。

## Q11｜早期信息怎样复利？
至少找20个：
> 早期看似一次性信息 / 笑点 -> 后期变成关系 / 设定 / 主线资源
的案例。

## Q12｜结局为什么仍然属于这本书？
检查：
- 最后阶段是否还保留人物最早的行为发动机；
- 笑点与终局冲突是否仍然属于同一套人物逻辑。

# 4. 对本项目最重要的迁移问题

研究完成以后，必须单独回答：

## 4.1 程野可以学什么，不可以学什么？

禁止答案：
> 程野也要像陆阳一样搞笑。

必须拆成：
- 程野自己的稳定判断模式；
- 什么事件能被他拧歪；
- 他的“规则感 + 资源感 + 敢试”如何产生外部后果；
- 如何避免变成陆阳换皮。

## 4.2 季长庚如何避免工具人？
对照原作长期关系发动机，研究：
- 两边都要有自己的生活；
- 对方不在场时是否仍能撑剧情；
- 两边如何互相制造问题，而不只是互相送资源；
- 长期关系如何从“奇遇”变成“责任 / 误判 / 冲突 / 合作”。

## 4.3 双世界如何拥有事件喜剧？
重点不是写笑话，而是：
> 现代世界一个完全合理的行为，落到古界为什么会产生新的现实后果；
> 古界一个完全合理的行为，被现代程野理解以后为什么会产生新的现实后果。

## 4.4 如何建立可持续的“本书味道”？
最后必须提出：
- 3–5个可重复但可变形的事件发动机；
- 3–5个关系发动机；
- 3–5个世界差异发动机；
- 明确哪些东西每次必须变化，防止套路化。

# 5. Anti-copy boundary

最终结论不得包含：
- “照着问心山写一个XX测试”；
- “照着河灵写一个XX规则”；
- “给程野配一个孟景舟型角色”；
- “让季长庚相当于不朽仙子”；
- 任何一一对应换皮；
- 在世作者文风 imitation instruction。

允许迁移：
- 信息顺序；
- 因果密度；
- 行为发动机；
- 镜头长度原则；
- 关系独立性；
- 后果复利；
- 长篇升级方法。

# 7. Evidence standard

每个重要结论都必须标：
- chapter / arc range；
- FULL READ / DENSE SAMPLE / ARC MAP ONLY；
- 是正文证据还是读者讨论；
- 结论置信度：HIGH / MEDIUM / LOW。

同一结论优先要求：
> 至少两个不同阶段的正文证据。

防止把前30章规律误判成整本规律。
