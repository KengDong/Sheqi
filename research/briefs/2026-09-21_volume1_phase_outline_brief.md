# 三、本轮真正要解决的问题

## 1. 四阶段状态机

把 Phase A—D 细化成真正能写的阶段。

每阶段必须回答：

1. 陆野阶段开头处于什么职业 / 修炼 / 关系状态？
2. 他最具体想要什么？
3. 谁最直接阻止？
4. 哪一个配角有自己的目标在同时推进？
5. 这一阶段至少发生哪2—4个关键事件功能？
6. 阶段中陆野犯什么判断错误或付出什么成本？
7. 这一阶段结束时，哪些状态永久改变？
8. 为什么这个阶段的成功自然制造下一阶段目标？

不要写“推进人物关系”“展现世界观”这种作者语言。

必须写人物能行动的目标。

---

## 2. 八个骨干节点怎样落入阶段

批准的八个骨干功能节点：

1. 资格竞争
2. 事故 / 舍味 / 筑基
3. 私人生活损失落地
4. 限制复工 / 外界异常确认
5. 普通安全决策
6. 纯修仙护运 / 战斗，一级目标完成
7. 尝余进入现实价值 -> 误判造成损失
8. 流程风险爆发 -> 团队控灾 -> 固定席位

本轮必须：
- 给出顺序；
- 说明哪些可拆成2个事件；
- 哪些应该合并；
- 哪些节点之间需要呼吸段；
- 不要机械“一节点=十章”。

# 四、弹性单元筛选

从以下候选中选 **2—4个**：

- 窄用途余器
- 完整续我 / 借载客户对照
- 普通残货 / 产权冲突
- 唐禾客户线
- 乔九线路扩张独立事件
- 生活锚点第二次现实冲突
- “没尝到不等于安全”的普通危险事件

每个候选必须说明：

1. 加进去解决什么缺口？
2. 如果删除会损失什么？
3. 是否与现有骨干节点功能重复？
4. 会不会让第一卷过于职业化 / 余器化 / 伦理化？
5. 最终决定：保留 / 合并 / 暂缓。

# 五、第一次事故必须具体化，但不能写成正文

事故是第一卷最重要的开篇结构之一。

需要形成**动作链**，不是文学描写。

至少明确：

1. 陆野为什么当天在场？
2. 他原本在做什么普通工作？
3. 什么东西 / 哪个流程首先发生异常？
4. 为什么现场不是第一秒就能全员撤离？
5. 谁被困 / 什么任务只有筑基后才可能完成？
6. 陆野为什么必须在真实续关当场执行应急舍备？
7. 封位外环怎样被破坏？
8. 切离 / 导余主体为什么仍能工作？
9. 谁执行应急封余抢救？
10. 筑基后的稳定离体具体完成什么救援动作？
11. 事故后为什么陆野不是英雄式立刻升职，反而资格冻结？
12. 事故里哪些信息读者知道，哪些必须晚点解释？

至少提出 **2个事故动作链候选**，但只能在已锁事故机制里变化场景，不得改 Canon。

最后推荐1个。

# 六、开篇修籍 / 验章如何出现

当前仍是强候选，不得写成系统面板。

本轮要回答：

- 第1—3章是否需要出现？
- 谁看它？
- 为什么在当时非看不可？
- 它具体只显示什么？
- 怎样让读者理解“陆野已经修积、明悟，卡在续我”而不听一堂课？

至少比较：

A. 上岗/候选资格检查时顺手验章  
B. 应急舍备 / 高危岗位手续中出现  
C. 事故后复核才第一次正式出现

推荐一个主方案，可以混合，但禁止重复讲解。

# 七、生活锚点第一轮细化

当前首选：

> **合租旧友**

本轮不能只写功能。

需要至少提出 **2个具体人格版本**，不只是换行业。

每个版本回答：

- 性格；
- 当前生活目标；
- 和陆野为何合租这么久；
- 谁更会做饭 / 谁更爱占地方 / 谁欠过谁钱；
- 对陆野“穷、惜物、嘴贫”的真实反应；
- 陆野失味后第一处尴尬 / 冲突；
- 这人第一卷至少一次主动做出什么不为陆野服务的选择；
- 为什么不会变安慰NPC；
- 是否可能在卷末搬走 / 改变合租关系。

最后推荐一个“进入前三章/前10章候选”。

姓名和性别仍可暂缓。

# 八、主要人物首轮出场顺序

不要为了“核心五人”让所有人前三章报到。

本轮必须规划：

- 前3章最多真正让读者记住几个人；
- 前10章谁必须出现；
- 谁应该后出；
- 谁第一次出场必须带着自己的事情，而不是来介绍自己。

重点测试：
- 乔九
- 罗槐
- 石小庚
- 唐禾
- 周照
- 曹闻川
- 生活锚点

要求：
> 新角色出现必须改变陆野当下的行动选择，或暴露一个现实利益关系。

# 十、轻重节奏

四阶段中都必须有“呼吸段”。

至少设计：

- 工作后的吃饭 / 房租 / 修东西 / 练功；
- 队友之间分钱 / 排班 / 抱怨；
- 生活锚点场景；
- 不带新谜团的普通修炼；
- 一次纯粹的小胜利。

原则：

> 奖励不全是诅咒；成功必须允许读者开心。

---

# 十一、每阶段至少一次“成功制造新问题”

强制检查：

### Phase A
筑基成功以后，为什么现实反而更麻烦？

### Phase B
拿回资格以后，为什么故事不是结束？

### Phase C
变得有用以后，为什么能力定价和误判会产生新债？

### Phase D
拿到固定席位以后，下一阶段为什么自然出现责任？

如果某阶段只能靠“又来了一个事件”进入下一阶段，该阶段纲不通过。

# 十二、第一卷长度只给功能区间，不给100章死表

- 各 Phase 相对比例；

除非仅用于说明相对顺序，最终不得写成正式锁定章号。
