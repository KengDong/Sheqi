# Mission

D-0084A—D-0086已经证明：
- mother market；
- commercial fruit；
- visible compounding；
- story reservoir；
- Premium survival。

本Gate不重复这些研究。

只问：
> **除了商业增长，这本书有没有成为“人会爱、会记、会讨论、会追”的头部小说所需的生命力？**

# A｜Protagonist Magnetism

每本只提出一个主角核心版本。

回答：
- 这个人现在最想得到什么？
- 他最独特的处事方式是什么？
- 什么普通生活场面也能显示“只有他会这么做”？
- 他最容易犯的、会真实伤害自己的错误是什么？
- 如果暂时没有能力/资产升级，Reader还愿不愿看他处理一顿饭、一次争吵、一次失败？

Hard:
> 禁止用“善良/坚韧/聪明/冷静”这种抽象词代替行为。

# B｜Character Pull

每本只先保留4—6个核心人物。

至少证明：
- 2个非主角有自己的生活；
- 主角消失后仍会继续行动；
- 至少两人天然想要互不兼容的东西；
- 关系会因为共同做过事而永久改变。

目标不是Character Bible。
只回答：
> **除了Concept，Reader会想再见谁？**

# C｜Opponent Compounding

每本必须证明至少一个主要对手/对立结构会：
- 学习主角；
- 利用主角Premium的弱点；
- 改变策略；
- 自己积累资源/地位/关系；
- 不靠“下一只更强怪物”提供压力。

问题：
> 主角越强，对手为什么也会变得更难，而不是只提高数值？

# D｜Emotional Engine

不做配额。

自然检查这本书是否能持续产生不同类型情绪：
- 爽/赢；
- 紧张/怕；
- 惊奇；
- 好笑/荒诞；
- 心疼；
- 温暖；
- 解气；
- 羞耻/尴尬；
- 失去；
- 希望。

Hard:
> 如果最主要体验只有“升级爽”或“规则紧张”，标记EMOTIONAL MONOTONY。

重点：
> State Reward之外，Reader到底在情绪上吃什么？

# E｜Scene Ecology / Narrative Aperture

回看作者历史最高优先反馈：
> 不得重新写成“小型情景剧”。

每本回答：
- 这个Concept天然会把Reader带进哪些不同社会/空间接口？
- 场景变化是否会带来新信息、新人物、新阶层、新生活方式？
- 是否能自然产生“像电影一样”的认知扩张，而不是换地点继续解释机制？

禁止为了过Gate随机加地图。

# F｜Signature Memory

每本必须自然找到：
- 3—5个只有这本书会有的强画面；
- 1个主角标志性行为/习惯/选择模式；
- 至少1个有机会成为Reader主动讨论的非主角关系。

测试：
> 看完7章后，Reader闭眼30秒最可能记住什么？

# G｜Commentability / Social Spread

不是造争议。

回答：
- 哪些选择会让Reader自然站队？
- 哪些人物关系会让人讨论？
- 哪类场面容易被一句话复述/安利？
- 有没有自然的“下一章评论区问题”？

若读完只有：
> “写得不错”

但没有想说的话：
> SOCIAL SPREAD弱。

# H｜Tone / Relief

判断长篇是否有：
- 生活感；
- 幽默/荒诞；
- 呼吸段；
- 不靠主线压力也好看的互动。

不是要求搞笑。
是防止200万字一直高压导致疲劳。

# I｜Production Risk

针对AI协作特别检查：
- 是否需要Writer同时记几十条规则？
- 是否容易写成说明书？
- 是否需要每章发明新奇观？
- 是否高度依赖作者超强战斗智斗设计？
- 连写30章后最可能出现哪种AI机械化？

这不是淘汰“难写”的书。
而是判断：
> 当前团队能否稳定把Concept兑现，而不是只写出漂亮Prototype。
