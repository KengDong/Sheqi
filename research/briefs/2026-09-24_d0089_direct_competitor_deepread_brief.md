# Mission

每本只做：
> **3—5个直接竞品的深读/功能拆解。**

这不是Broad Market Scan。

问题不是：
> “这个竞品有什么设定？”

而是：
> **为什么同一Reader点进去以后，会在Ch1、Ch3、Ch7、Ch20继续留下？**

# Evidence Priority

优先：
1. 官方作品页 / 官方免费章节 / 官方可合法访问文本；
2. 平台官方荣誉/标签/简介；
3. 作者公开采访/平台公开课（若直接解释执行）；
4. 当前书架证据。

禁止：
- 盗版全文；
- 二手剧情梗概替代正文因果；
- 用榜单成绩反推“正文一定这么写”。

如果某竞品合法正文证据不足：
> 明确标记 EVIDENCE GAP，不要装成Deep Read。

# Per-Competitor Read Window

尽量覆盖：
- First Screen
- Ch1
- Ch1—3
- around Ch7
- around Ch20 / first major settlement

不要求机械同章节号。
核心是找到：
> 点击 -> 初留 -> 概念退潮 -> 第一阶段果实
四个功能节点。

# Shared Questions

## 1. Reader Contract
Reader点进来时以为什么会吃到？
正文多久兑现？

## 2. Protagonist Magnetism
如果暂时拿掉核心外挂/资产，主角本人还有什么持续可看？

## 3. Reward Cadence
第一次小果实在哪？
下一次果实之间隔多久？
果实是状态变化还是只揭信息？

## 4. Emotional Rhythm
爽 / 紧张 / 笑 / 温暖 / 心疼 / 惊奇如何切换？
是否存在长时间单一情绪？

## 5. Scene Ecology
前20章进入了多少种真正不同的生活/社会接口？
每次换场景是否扩大Reader认知？

## 6. Character Entry
重要非主角多早进入？
他们第一次出现就是功能角色，还是已经有自己的欲望？

## 7. Opponent Pressure
主要压力是否会学习、升级、改策略？
还是不断换更强的新对象？

## 8. Permanence
Ch20时有什么不可逆地留下：
- power
- asset
- relationship
- status
- debt
- territory
- identity
- mystery position

## 9. Serial Pull
Ch3在等什么？
Ch7在等什么？
Ch20后自然在等什么？

## 10. Function Clone / Do Not Copy
只允许总结：
> reader-level causal function.

禁止复制：
- 人物；
- 世界设定；
- 标志桥段；
- 事件顺序；
- 文本表达。

# Finalist-Specific Focus

最大问题：

最大问题：
