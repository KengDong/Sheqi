# D-0084｜P1 Isolated Prose Prototype
## 第一章只证明一件事：写成小说以后，我还想不想继续

status: active
date: 2026-09-24
role: p1_prototype_writer

# Mission

只写：
> **第一章。**

不要证明整本书。
不要解释完整世界观。
不要提前设计十章。

目标：
> **让一个不知道设计文档的陌生读者，在真实平台阅读状态下愿意继续下一章。**

# Input Boundary

每个Writer窗口只能读取：
1. 本brief；
2. 自己候选的P1 Writer Pack。

禁止读取：
- 其它三个候选；
- Reservoir；
- Character Collision全表；
- Total Editor reviews；
- Benchmark；
- old prose；
- Canon / Outline；
- Canopy；
- Five Curves；
- Macro Promise。

# Writing Principle

只保留三个问题：

1. **谁现在很想要什么？**
2. **为什么今天非发生不可？**
3. **这一章结束后，什么已经回不到原样？**

Near Horizon是读者眼前等待，不是“必须按卡点施工”的章节任务。

Writer可以自行选择：
- 从Near发生前一点进入；
- 直接从Near冲突进入；
- 或从最有生命力的同一日场面进入。

但第一章必须真正活在人物处境里，而不是先讲设定说明书。

# Style Boundary

- 中文商业小说可读性优先；
- 具体人、具体动作、具体空间优先于概念术语；
- 对话是人说话，不是规则FAQ；
- 能让物件、身体、工作、饭桌、手机、门、时间表等承载的信息，不让旁白替它解释；
- 不追求“金句密度”；
- 不为显得高级故意晦涩；
- 不把整章写成设定展示会。

长度：
> 自然完整的一章，通常约3000—4500汉字；不为字数注水。

# Chapter Ending

不要用随机事故或作者强塞的新谜团硬钩。

更希望：
> 因为人物刚做出的选择 / 得到的事实 / 改变的关系，Reader自然想知道下一步。

# Hard Ban

- no new core rule;
- no new core character;
- no terminal conspiracy;
- no chapter 2 prose;
- no outline;
- no author note inside prose;
- no self-explanation of “this scene demonstrates X”.

# Output

只写对应候选：
> `experiments/first_principles_forge/prototypes/p1/<candidate>_ch01.md`

另写极简边界自检：
> 是否新增规则 / 核心人物 / 越界读取 / 写了Ch2。

Selfcheck不评价“写得好不好”。

完成后更新自己的CURRENT/history并停止。
