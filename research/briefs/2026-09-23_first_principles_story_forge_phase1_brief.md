# Per-Concept Output

每个Concept严格只写：

1. **One-Line Promise**
   - 一句话让我想点。

2. **Protagonist Desire**
   - 主角现在最想要什么；
   - 必须普通人能理解。

3. **Unique Rule / Situation**
   - 世界里到底有什么独特之处。

4. **Five Must-See Situations**
   - 只写5个一句话场面；
   - 每个都应让人真的想点正文；
   - 不允许“功能正确但没欲望”的场面。

5. **One Character Pull**
   - 除主角外，谁天然值得追；
   - 他/她自己想要什么。

6. **Long Mutation**
   - 写到100章以后，这本书可以自然变成什么更大的东西。

7. **Non-Replaceability**
   - 如果换成普通都市/修仙/系统/创业模板，为什么会失效。

8. **Engine Hypothesis**
   - 它主要靠什么让Reader持续：
     - expansion；
     - recontextualization；
     - compounding；
     - relationship；
     - hybrid；
     - 其它。

# First-Pass Kill Rules

立即淘汰：
- 只能靠第一章高概念；
- 五个场面里已有3个明显同一种玩法；
- 主角欲望模糊；
- 非主角只是功能；
- 100章后只能“更大的同一件事”；
- 需要大量解释Concept才有趣；
- 和热门样本只是换皮；
- 最吸引人的点不是正文能持续兑现的东西。

# Total Editor Desire Cut

不做12项评分表。

总编只把每个候选分成：

- **PULL**：本能想看更多；
- **MAYBE**：有东西，但需要变异；
- **DROP**：理论不错，正文欲望弱。

目标：
> 留6—8个进入Story Reservoir。

必须保证：
- 至少1个C01变体；
- 至少1个C12变体；
- 至少2个Benchmark Function Clone；
- 至少2个Wild Concept；

只有它们本身真的达到PULL才保留。
不设保底名额。

# Copyright / Originality Guard

“仿热门”只允许：
- 仿抽象发动机；
- 仿reader-level causal function；
- 仿节奏功能；
- 仿复利机制。

禁止：
- 使用原作人物；
- 复刻原作核心世界规则；
- 改名重演标志性情节；
- 连续复制事件顺序；
- 模仿可识别文本风格；
- 以“同款某书”作为最终设计目标。

目标：
> **借它们证明过的因果机制，制造我们自己的Breakout Premium。**
