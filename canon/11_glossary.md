# 术语表 V1.0

- **修积**：大境突破前对法力、肉身、神魂、功法、资源与实战基础的积累。日常简称“积”。
- **明悟**：真正理解下一境、所修功法与自身道路。日常简称“悟”。
- **续我**：把当前主体稳定迁移到下一生命层级。日常简称“续”。
- **完整续我**：不主动切离自身结构，完整进入下一境；社会俗称可称“正破”。
- **正破**：完整续我的常见社会俗称/旧称，不代表作者认可其道德上“更正确”。
- **借载**：借法器、阵台、灵兽、秘地、地脉等外物托住部分续我压力，本人保持完整。
- **舍破**：通过舍契永久切离部分真实我相，以减少本次续我负担的常见称呼。
- **我相**：持续以第一人称参与主体感知、调节、行动、记忆、关系或身份运行，并已成为当前主体稳定结构的一部分。
- **定相**：围绕本人主动提出的候选，确认其是否真实存在、切界在哪里、与哪些邻近结构牵连，并为舍契做准备。
- **舍契**：执行有效舍弃的契约/术式。
- **舍备**：在尚未真正舍弃前，完成候选定相、续关适配与备用舍契登记的准备流程。
- **弃相**：被有效舍契真正切出的自我结构。
- **缺位**：原我相永久消失后，在本人留下的结构性缺失/形变；不是空槽、容器或可回填承载位。
- **定我**：舍后通过真实生活与选择重新形成稳定主体的过程。
- **散我**：主体连续性失稳，意愿、行动、记忆与责任不能稳定指向同一个“我”。
- **余世**：历代弃相长期积累、迁移与相互作用形成的现世背面余层。
- **余痕**：导余/封位不完整后留在现实中的余世残留。
- **余灾**：弃相、余痕或同类结构异常聚集后，对现实造成的区域性/群体性影响。
- **余器**：利用弃相/余痕形成的窄用途特殊器物。
- **漏舍者**：舍弃成功，但封位没有完全闭合、留下异常余缝的事故幸存者。
- **急舍 / 战舍**：已经处于真实续关、事前完成舍备的修士，在紧急或战斗场景中启用备用舍契的俗称。

## 未强制固定的对称术语

V1.0 不采用：
- 全续 / 借续 / 舍续
- 全渡 / 借渡 / 舍渡
- 余相器
- 舍渡台

世界里的真实语言可以不对称。

“舍弃续我”可用于解释性公文或说明，但不要求成为人物高频专名。
