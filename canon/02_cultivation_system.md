# 修炼与破境框架 V1.0

## 一、总结构：修积 -> 明悟 -> 续我

### 修积
积累法力、肉身、神魂、功法、资源与实战基础。修积不足，任何破境旁路都无效。

日常可简称“积”。

### 明悟
真正理解下一境、所修功法和自身道路。明悟不是玄学进度条，可以来自实战、推演、师承、炼器、生死经历与长期生活。

日常可简称“悟”。

### 续我
把当前主体稳定迁移到下一生命层级，使新获得的生命结构仍然属于“这个人”。

日常可简称“续”。

只有续我阶段存在不同实现：

- **完整续我**：不主动切掉自身结构，把当前自己完整带过去；社会常俗称“正破”。
- **借载**：借法器、阵台、灵兽、宗门秘地、地脉等外物托住部分尚未稳定接管的续我压力，本人保持完整。
- **舍破**：通过舍契切离部分真实我相，以减少本次必须重新承接的结构。

“舍弃续我”可以作为说明性表达，但不强制成为高频正式专名。

## 二、传统六境

> **炼气 -> 筑基 -> 金丹 -> 元神 -> 法相 -> 洞天**

使用传统名称是有意降低认知负担；原创性放在每一境真正改变了什么，而不是重新制造六个生僻名词。

### 炼气
**读者可见承诺：用灵气。**

修士能主动感知、吸纳、炼化灵气，用于强化肉身、灌注兵器、驱动低阶符箓与术法。稳定离体能力仍弱。

---

### 炼气 -> 筑基
**内部生命变化：灵力从主动调用变成常驻周天。**  
**读者可见新动词：稳定离体。**

续我难点：
- 原有感知、肉身反馈、动作习惯、神魂控制必须与持续运行的灵力结构重新协调。

完整续我为何耗时：
- 周天需要在日常、疲劳、战斗与情绪变化中反复暴露失配并逐步适应。

资源主要保护：
- 经脉、肉身、神魂，并在周天失控时把失败控制在可修复范围。

借载主要承担：
- 灵流校正、错误压力、外部稳定节律与肉身保护。

---

### 筑基 -> 金丹
**内部生命变化：持续周天形成稳定自循环核心。**  
**读者可见新动词：持久 / 自循环。**

续我难点：
- 旧有功法、术法调用、身体反馈与恢复节律必须重新接入新的自循环核心。

完整续我为何耗时：
- 需要经历成核、运行、校正和真实负荷验证，而非“一次凝成即完成”。

资源主要保护：
- 成核、灵压、心脉、经脉与神魂，并允许多轮调整。

借载主要承担：
- 外部缓冲、错误回流保护、部分核心节律稳定。

---

### 金丹 -> 元神
**内部生命变化：感知与行动主体可以脱离单一肉身而持续存在。**  
**读者可见新动词：离体 / 多线控制。**

续我难点：
- 离身以后仍保持主体归属、记忆归属、感知归属与行动连续；肉身和元神仍被本人认作同一主体。

完整续我为何耗时：
- 必须多次离体、回归、对照，并逐渐扩大距离与时长。

资源主要保护：
- 神魂、肉身、离体通道、回归条件与外界信息冲击。

借载主要承担：
- 稳定回归坐标、肉身保护、神魂外显边界与感知过载过滤。

---

### 元神 -> 法相
**内部生命变化：个人修炼道路形成稳定外在力量结构。**  
**读者可见新动词：显道 / 道路外显。**

续我难点：
- 外显道路必须和真实本人、功法、术法习惯、长期选择保持连续，不能只是一次临时口号或自我欺骗。

完整续我为何耗时：
- 必须反复显相、使用、撤相、生活与实战，证明它能长期成立并能稳定收放。

资源主要保护：
- 元神承压、显相失败后的修复与多轮试错。

借载主要承担：
- 与某类功法传统相容的外框、能量支撑和回收保护。

---

### 法相 -> 洞天
**内部生命变化：个人道路与真实天地形成稳定、可收放的规则边界。**  
**读者可见新动词：立界 / 改变战场环境。**

续我难点：
- 领域、主体与外部天地之间必须形成稳定接口；展开、维持与收回都不能破坏主体连续性。

完整续我为何耗时：
- 必须在真实环境中反复展开、承压、收回，并经历不同地脉、环境和敌对压力。

资源主要保护：
- 空间、地脉、法相、元神以及现实对领域的反压。

借载主要承担：
- 秘地、地脉、洞天胚地、大型阵法等对环境反压、边界与空间震荡的承托。

## 三、禁止“境界—人格最佳舍项”攻略

以上只规定每一境正在重构什么生命功能。

**不得固定：**
- 筑基最适合舍感官；
- 金丹最适合舍睡眠；
- 元神最适合舍关系；
- 法相最适合舍身份；
- 洞天最适合舍文明归属。

任何具体舍项，都必须先回答：
1. 这个人的当前续关具体卡在哪里；
2. 该我相怎样真实参与这部分结构；
3. 切掉以后减少了哪一部分承接工作；
4. 为什么对这个人、这套功法、这一次续关足够。

不能先决定要舍什么，再倒推境界理由。

## 四、借载可以规模化

成熟宗门、家族或公共机构可以规模化建设借载设施。

这不是漏洞，而是阶层与组织优势的一部分。

其成本主要来自：
- 设施建设；
- 阵位与使用时间；
- 个体和功法校准；
- 操作人员；
- 消耗性保护材料；
- 高境所需稀缺地脉、秘地、承载介质。

不设置统一“每用一次必冷却”的万能限制。

规模化不等于无限、免费、无差异。

## 五、Build 五轴

- 功法 = 发动机
- 术法 = 动作
- 肉身 = 底盘
- 神魂 = 控制带宽
- 法器 = 外部模块

境界决定基本权限；Build、经验、装备和判断决定同境强弱。

## 六、越境原则

跨一个大境正面对战通常明显劣势，但情报、针对法器、特殊地形、多人配合、对方受伤/定我、限制高境独有能力等，可以制造少量越境事件。

越境胜利必须是“事件”，不能成为陆野日常。
