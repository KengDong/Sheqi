# 修炼与破境框架

## 总结构：积—悟—续

### 积
积累法力、肉身、神魂、功法、资源与实战基础。积累不足，任何破境技巧都无效。

### 悟
理解下一境、所修功法和自身道路。卡在“悟”的修士即使舍掉重要人格部分，也只会失去东西而不会突破。

“悟”不是单独的玄学进度条，可以来自实战、功法推演、师父点拨、炼器、生死经历与长期生活。

### 续
将“现在完整的自己”稳定迁移到下一生命层级。正破、借载、舍破只在这里分流。

- **正破：**完整续我。最完整、最慢，需要时间、稳定与对应境界资源。
- **借载：**借法器、阵台、灵兽、宗门秘地等外物托住续我压力。人格完整，但设施/资源门槛最高。
- **舍破：**主动让某一部分自我不再续入下一境。窗口短、眼前资源成本低，但永久失去自身一部分，并强制定我。

## 传统境界首选候选
当前推荐：

> **炼气 -> 筑基 -> 金丹 -> 元神 -> 法相 -> 洞天**

选择理由：本书真正需要读者记忆的新名词已经集中在舍破、余世、弃相、定我、余器；主修体系应降低理解门槛。

但旧名字不能等于旧体验照搬。

### 炼气｜新动词：用灵气
主动感知、吸纳、炼化灵气；强化肉身、灌注兵器、驱动低阶符箓与术法。稳定离体能力仍弱。

### 筑基｜新动词：稳定离体
建立个人稳定周天。剑气、火法、御器、护体、隔空操控等真正成为常规战斗手段。

### 金丹｜新动词：自循环 / 持续运行
形成高稳定力量核心。长时间飞行、持续复杂术法、本命法器、丹火炼器炼药、单人维持复杂阵法成为可能。

### 元神｜新动词：神魂脱身 / 多线控制
神识外放、多法器精细控制、远距传讯、精神对抗、短暂元神离体等进入主流。

### 法相｜新动词：道路外显
修士所悟道路第一次形成明显外在结构。同境差异被放大，功法与人生选择真正进入战斗风格。

### 洞天｜新动词：改变战场环境
一定范围开始按修士自身修炼逻辑运行。高阶战斗从“更大术法”升级为不同领域争夺战场。

## Build 五轴
- 功法 = 发动机
- 术法 = 动作
- 肉身 = 底盘
- 神魂 = 控制带宽
- 法器 = 外部模块

境界决定基本权限；Build、经验、装备和判断决定同境强弱。

## 越境原则
跨一个大境正面对战通常明显劣势，但准备情报、针对法器、特殊地形、多人配合、对方受伤/定我、限制高境独有能力等可以创造少量越境事件。

越境胜利必须是“事件”，不能成为陆野日常。

## V1.0前仍需补
**正破成本具体化。**
必须为关键大境界解释“完整续我到底难在哪里、资源消耗在哪里”，否则正破会显得被作者人为抬价。
