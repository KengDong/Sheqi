# INTERNAL VISUAL REFERENCE SPEC｜Opening V0

> 仅供内部空间与动作一致性。
>
> 不自动进入正文，不升级Canon。

## 1. 固定中转台
- NORMAL / A'必须同一底图
- F正常沿固定方向进入
- 主承重轮承担重量
- 小导向轮只限制横向跑偏
- W处于正常合法工作口袋
- O/S位于正常货路外的内凹舍台区域
- O在前，S更后缩
- R固定在F右端独立区域
- 正常小偏差不能撞到O
- A'由导向轮脱槽后的端部扫掠越界
- S不是第一接触面

## 2. B工作默认
采用：
> 固定牵引绞盘/卷轮 + 摩擦制动/张力控制机构。

机械结构承担载荷。

事故时需要的是：
> 在副支撑尚未接管之前，持续维持/微调一个中间控制状态，限制架体继续吃角或回摆。

陆野承担：
- 控制
- 持续
- 稳定

不承担几吨重载。

禁止画成：
> 一个成熟安全刹车，人一松手就把重货完全放开。

## 3. 第一章普通器物
- 小夹具：两片短木/硬竹 + 可拆小金属弹性件
- 不需要正式专名
- 货牌普通
- 绑扎绳/扣普通
- 工具卷普通
- 废料筐普通
- 夜班热食位有锅、碗、热水

## 4. 凭证
- 小薄册/折页方向
- 可快速翻到当前记录
- 无UI
- 无完整人格扫描
- “修籍”是否正式名OPEN

## 5. 合租屋
- 一个多用途共用长桌
- 同时承担吃饭与部分手艺工作
- 陆野零件有限、分类、可收纳
- 生活锚点工作面保持职业中性
- 第4章通过桌面/调料小篮的微变化体现边界变化
- 不锁房间总数、性别、正式职业

## 6. 当前禁止
- 正式人物脸
- 漏舍固定可见特效
- 余世/弃相终极形态
- 根据V0反改故事
- 把本场景布局外推成全国规范
