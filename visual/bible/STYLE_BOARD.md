# STYLE BOARD｜全局视觉方向字段 V1

> 本文件只锁方向字段，不锁最终美术图与色号。

## 主候选
> **克制的半写实国风插画。**

## 世界正常态
- 正常人间环境先成立；
- 修仙设施是生活系统；
- 不每个角落仙气缭绕；
- 低阶修士劳动有重量。

## 材质
优先探索：
- 木；
- 石；
- 金属；
- 织物；
- 纸 / 册；
- 普通低阶炼器材料；
- 修补痕迹；
- 使用痕迹。

不锁材料配方。

## 穷但不脏
允许：
- 旧；
- 补；
- 磨损；
- 复用；
- 空间紧。

禁止：
- 用长期脏污表示底层；
- 用破衣烂衫替代职业 / 阶层设计。

## 舍务
应呈现：
- 正规；
- 可操作；
- 可维护；
- 有工具区；
- 有安全边界；
- 有防护。

避免：
- 血祭；
- 邪阵；
- 人骨；
- 宗教祭坛；
- 大量不可解释符号。

## 修仙
境界差异优先视觉化：
- 动作距离；
- 控制持续性；
- 站位；
- 法器关系；
- 工作空间。

禁止：
> 升境 = 换发光颜色。

## 角色差异
优先：
- 轮廓；
- 体型；
- 穿法；
- 工具位置；
- 动作习惯。

不优先：
- 彩发；
- 异瞳；
- 夸张疤痕。

## 光照字段
未来分别建立：
- 白班；
- 夜班货场；
- 合租屋夜间；
- 舍台服务位；
- 应急照明；
- 后期异常光（暂不定稿）。

原则：
> 正常光源先稳定，异常光才有意义。
