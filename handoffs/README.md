# Handoffs

本目录是《舍弃》各长期GPT窗口的**接班入口**。

正式规则：
> `meta/HANDOFF_PROTOCOL.md`

目录：

- `editor_in_chief/`：总评审 / 总编
- `opening_writer/`：开头 / 主作者
- `mid_continuity/`：中段+衔接 / 研究红队编辑
- `visual/`：视觉
- `blind_reader/`：盲读

新窗口不要从聊天历史猜项目状态。

普通窗口优先读取：
> AGENTS -> STATE -> HANDOFF_PROTOCOL -> 自己的CURRENT。

正式盲读窗口遵守 clean-room 例外。
