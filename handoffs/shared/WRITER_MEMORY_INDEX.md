# Authority
Task-specific CURRENT / brief controls:
- hard input boundary;
- exact files allowed;
- chapter assignment;
- current baseline.

Shared memory controls:
- prose behavior;
- character continuity;
- learned author preferences.

If conflict:
> task CURRENT wins for task boundary;
> stable shared file wins over older dated notes on the same style/character topic.

# Important
Do NOT infer permission to read this index under an isolation benchmark.

The active window's CURRENT must explicitly say:
> shared writer memory is allowed.

# New-window success condition
A new prose window should be able to answer before writing:
1. What kind of prose is forbidden?
2. How does Cheng Ye usually make decisions?
3. What does Cheng Ye know right now?
4. What author corrections must not recur?
5. Which world/rule/chapter files am I allowed to use?
6. What is my current prose baseline?

If any answer is missing:
> do not invent continuity from old chat memory.
