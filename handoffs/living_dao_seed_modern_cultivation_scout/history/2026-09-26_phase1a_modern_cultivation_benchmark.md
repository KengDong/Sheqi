## Highest evidence conclusions

1. Modern cultivation is not created by phones, livestreams, companies, schools or “spirit currency” as nouns.
2. The strongest evidence uses a conversion chain:
   cultivation capability → recognized metric → credential / rank → resource / income / access → social position → next cultivation opportunity.
3. Ordinary-life friction is the cleanest worldbuilding interface:
   interviews, meals, jobs, hospital tests, certificates, contracts, taxes, queues, courses, media costs.
4. Social revaluation matters only when it changes later allocation of resources / permissions / relationships / obligations.
5. A mature long-run control proves institutions must continue upgrading after the protagonist grows stronger.
6. Public revaluation does not have to happen immediately if private accumulation is already pleasurable.
7. Current hot references and direct references are not the same thing; classify by function, not keywords.
