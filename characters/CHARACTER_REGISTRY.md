# Character-bible minimum schema
Every major recurring character bible should include:
1. identity / social position;
2. independent desire;
3. fear / pressure;
4. resources and leverage;
5. default decision pattern;
6. speech texture;
7. humor / emotional texture if any;
8. relation to Cheng Ye;
9. what they do when Cheng Ye is absent;
10. how they react to success / failure / humiliation / danger;
11. anti-drift rules;
12. mutable state file if long-term state changes matter.

# Hard rule
Do not create a recurring character as:
> protagonist utility with a name.

If they are important enough to recur:
> they need their own engine.
