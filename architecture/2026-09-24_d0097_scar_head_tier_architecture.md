# 《劫痕道途》｜Head-Tier Long-Run Architecture V1

# 0. One-Sentence Book Contract

> **别人渡劫后想尽办法把代价洗掉、转走、埋掉；周野却能看见这些代价走过的路，并把别人不要的“成长成本”一点点编进自己的修行，最终从一个带伤临工，走成一条谁也复制不了的新道。**

Reader food:
> 修炼升级 + 工作赚钱 + 身体代价 + 阮青禾关系化学 + 劫务产业 + 宗门/城市/区域竞争。

# 1. Core Pleasure

不是：
> 查旧事故。

而是：
> **看周野如何把“别人眼里的伤/废料/风险”转化为越来越值钱的修行资产，同时承受真实身体、职业、关系成本。**

# 2. Universal Conversion Layer

本书只保留两条Reader秒懂的转换桥。

## Bridge A｜资格 -> 工作 -> 钱/资源 -> 修炼
更高劫务资格：
> 能接更危险/更贵任务
> -> 钱/资源更多
> -> 医疗/修炼选择更大
> -> 境界与身体结构进一步升级。

## Bridge B｜劫痕结构 -> 能承受的任务/战斗 -> 地位
周野不是“痕越多越强”。

是：
> **同一批旧痕被理解、重排、组合后，能够承担更复杂的劫压与战斗。**

# 3. Cold-Start / Personality Lane

周野当前最强不是搞笑，而是：
> **疼痛耐受 + 很会算成本 + 不愿拿别人去试自己没弄懂的风险。**

人格需要在Voice Lab进一步放大成：
- 自己受伤可以精确算；
- 别人要替他承担风险时反而异常较真；
- 和阮青禾的冲突天然发生在“这伤到底该不该治”；
- dry pain humor：越疼越会说人话，不靠网络梗。

Reader不提劫痕也应能描述：
> “那个自己可以拿命算账，但不肯让别人替他糊涂买单的人。”

# 4. Book Contract Horizons

## Near｜Opening之后
> 七日内完成临时观察员转正式承劫辅助资格的实操评级，并第一次靠这份本事真正拿到钱。

## Mid｜Ch20–100
Reader等待：
1. 周野第一次把旧痕真正接进自己的周天；
2. 第一次正式破境；
3. 第一次成为别人点名要的承劫人；
4. 阮青禾拿到独立净痕/康复资格；
5. 两人第一次在“治掉一条痕还是保住它”上发生职业冲突；
6. 东堤旧账第一次从个人事故变成产业事实；
7. 周野第一次公开证明：带着代价修，也能比“干净修士”更强。

## Far｜100+
> 周野所走的不是异常体质，而是一条会逼整个修行文明重新回答“成长代价应该由谁承担”的修行道路。

# 5. Opening Arc KEEP / PATCH / DEFER

## KEEP
- 劫灰场/底层劳动开局；
- 右肩旧雷痕；
- 阮青禾医疗关系；
- 净痕可治但可能抹掉价值；
- 行修/考试；
- 旧承劫路线高潮；
- 程雁/韩系权威作为职业世界入口；
- 永久成本：环指功能受损；
- 临时观察身份。

## PATCH BEFORE NEXT PROSE
高潮后增加三个可见Handoff：
1. **日期**：七日后承劫辅助资格实操评级；
2. **钱**：第一次观察/协助报酬到账，同时净痕/康复费用明确；
3. **大世界物证**：劫务司公开任务墙/城市劫路图，让Reader一眼看到数十条正在运行的渡劫/承劫任务。

不解释产业。
只让周野和Reader看见：
> “原来刚才那件事只是这张图上的一个点。”

## DEFER
- 东堤全部真相；
- 全国劫务体系；
- 黑市；
- 区域标准；
- 谁当年把劫转给周野。

# 6. Ch5–20｜从“异常”到“吃饭的本事”

Dominant mode:
> 职业进入 + 修炼果实。

## Main Arc
周野以临时观察身份参与一场**正在发生的正式渡劫保障任务**。

这次不查旧路。
这是一个活生生的人今天必须突破，否则错过宗门/工作机会。

多系统同时上线：
- 客户付费；
- 劫务资格；
- 医疗预案；
- 宗门利益；
- 周野的身体；
- 阮青禾的判断。

周野发现自己的旧痕能做的不只是“感知”：
> 它能在极短时间内辨认劫压最容易走的身体/器物路径。

他仍不能免费吸收。
每次强行利用都会让旧痕加深或某处功能变差。

## First Social Opponent
一个正规承劫师并不坏。
他的立场：
> 周野这种未标准化身体不能成为公共安全方案。

他第一次见识周野有效。
第二次开始记录其恢复窗口。
第三次会主动逼周野在“伤没养好”时失去作用。

建立：
> 对手会学习。

## 阮青禾
她不跟着周野跑任务当医药包。

独立线：
- 她争取净痕/康复方向资格；
- 她第一次独立判断一名伤者“不该马上洗痕”；
- 因此和上级标准发生小冲突；
- 她获得一个具体职业机会，而不是“更懂周野”。

## Ch20 Permanent State
周野拥有：
- 第一笔稳定职业收入来源；
- 临时/初级正式资格；
- 一个真正能复用的专业动作；
- 一条被接入周天的旧雷痕“半成品结构”；
- 与阮青禾形成职业互相依赖但立场不完全一致；
- 一个会研究他的正规同行对手。

Reader能回答：
> 他比Ch4更强、更有钱、更有身份，而且知道下一次资格/破境目标。

# 7. Ch21–50｜从“能干活”到“这是不是一条道”

Dominant mode:
> 修炼创造 + 职业竞争。

## Main Shift
周野不再主要接“事故”。

他开始面对：
- 正常修士突破；
- 标准承劫方案；
- 正常治疗；
- 正常合同。

这让“带着代价修”的路线和主流路线正面对比。

## Power Arc
目标：
> 把右肩雷痕正式接进自己的修炼周天。

不是多一条痕。
而是同一条旧痕从：
> 伤 -> 感知器 -> 导路 -> 周天结构。

形成第一个读者可命名的长期资产：
> **第一段稳定劫路。**

不要新技能菜单。

表现：
- 更快识别雷法/劫压；
- 能把自身一部分受力导向已知路径；
- 战斗时能主动利用，但会累积恢复成本。

## Money / Status
周野开始被点名。

社会行为变化：
- 以前求任务；
- 现在有人问“周野在不在班”；
- 一位客户愿意为他额外付费；
- 劫务司仍限制其高危权限。

## 东堤部分答案
发现：
> 当年的“干净处理”并不是阴谋，而是一套曾经合法、后来淘汰的成本转移办法。

旧城区/下游承担了本应由突破者处理的一部分劫压残留。

这比“坏人害我”更大：
> 正常制度也会留下旧债。

## Ch50 Permanent State
- 真正完成一次修行境界突破；
- 第一段稳定劫路；
- 初级正式资格；
- 可见收入改善；
- 阮青禾拿到独立职业资格/岗位；
- 一个旧制度答案；
- 一个更高层区域任务/评级入口；
- 正规对手已能针对周野恢复周期。

# 8. Ch51–100｜从城市临工到区域“非标准修士”

Dominant mode:
> 公开竞争 + 区域产业 + 战斗。

真正换挡。

## New Social System
区域层面存在：
- 大宗门突破保障；
- 城市劫务外包；
- 医疗机构；
- 商业保险/赔付；
- 高危修炼资源供应；
- 非标准身体审查。

周野进入的不是更大地图。
是：
> **一整个区域都靠“谁来承担突破风险”做生意。**

## Public Stage
用一个强可见、非纯擂台的公共场面：
> 区域高阶渡劫保障资格/合同竞标 + 实操事故。

同时有：
- 公开排名；
- 钱；
- 宗门客户；
- 医疗；
- 战斗；
- 职业信誉。

让Reader获得“比赛/考试/工作/修炼”同时燃烧的《没钱》式多系统总线。

## Rival Nonstandard Path
出现一个不是“干净标准修士”的对手。

他也利用代价，但方法是：
> 把成本外接到器物/他人/合同。

周野第一次面对：
> 同一问题的另一种合理答案。

## Ch100 Major Fruit
周野公开证明：
> “劫痕不是事故残留，而可以成为稳定修行结构。”

得到：
- 区域级身份；
- 一支小型固定协作组；
- 更高资源渠道；
- 第二段结构不是“新痕”，而是旧痕与正常经脉的组合升级；
- 一个会主动选择他的客户/宗门；
- 一个主动研究并克制他的长期对手。

Book expands:
> city worker story -> regional cultivation economy.

# 9. Ch101–200｜从个人异类到可复制/不可复制之争

Dominant modes:
1. 团队经营；
2. 修行方法争议；
3. 区域危机。

Question:
> 周野这条路到底只能他一个人走，还是别人也能用“自己的旧代价”修？

不是教所有人长劫痕。
而是：
> 每个人都可能有无法抹去的成长成本。

周野与阮青禾第一次共同做“非标准身体长期方案”。

关系升级不是表白任务。
而是：
> 她必须决定是否把自己的职业声誉压在这条路上；
> 他必须允许她否掉自己想保留的某些伤。

## Ch200
- 周野拥有一个被承认的新修行分支雏形；
- 阮青禾拥有自己的专业名声；
- 固定团队能在他缺席时运行一部分；
- 区域同行开始复制/反对/改进；
- 一次大事件证明标准体系也有无法处理的情况。

# 10. Ch201–400｜从区域方法到宗门/产业冲突

Mode changes:
- individual path -> institution/industry;
- job contract -> sect strategy;
- city risk -> multi-region allocation.

核心不是开会。
用：
- 大宗门集体突破；
- 资源争夺；
- 战争前批量晋升；
- 城市公共承压；
- 医疗容量不足

让“谁承担成长代价”变成现实资源问题。

周野开始有拒绝某些高价工作的权力。

Status payoff:
> 从被审查者 -> 被争夺的方案提供者 -> 能反过来定条件的人。

# 11. Ch401–700｜从新道到文明级“成本去向”

Mode:
> 高阶修行 + 大规模因果 + 终极历史重估。

终极问题不是：
> 谁害了周野？

而是：
> **修行文明为什么越来越“干净”？被排除出去的代价到底堆到了哪里？**

答案必须重估：
- 东堤；
- 净痕；
- 城市劫路；
- 宗门突破；
- 周野本人。

最终仍通过：
- 破境；
- 战斗；
- 城市/宗门选择；
- 阮青禾的医疗判断；
- 谁站在哪个危险位置

来表达，不写哲学会议。

# 13. Five Growth Curves

## Power
旧痕感知 -> 接入周天 -> 稳定劫路 -> 组合结构 -> 新道雏形 -> 高阶承劫/战斗体系.

## Money/Resource
临工 -> paid observer -> licensed work -> named contracts -> team income -> regional resources -> condition-setting power.

## Status
伤员/临工 -> 观察员 -> 初级资格 -> 点名承劫人 -> 区域非标准专家 -> 新路代表人物.

## Relationship/Team
阮青禾私人照看 -> 职业冲突合作 -> 双方各自资格 -> 固定协作组 -> 共同方法但不同权力 -> 可互相否决.

## Knowledge/Institution
个人旧痕 -> 城市旧路 -> 历史制度 -> 区域成本产业 -> 宗门标准 -> 文明成本去向.
