# R1｜真名追踪规则锁
## 后续所有 Writer / Editor / Reader continuity checks 以此为准

# 0. Reader-Facing Compression

最短读者理解：

> **名字得先对得上人。**

规则认的不是姓名字符串。

规则认的是：
> **“这个真名，此刻明确指向的这个人。”**

---

# 1. Active Window

Confirmed:
> 天黑后生效。

Daylight:
> no tracking effect.

The exact astronomical/legal threshold does NOT need further technicalization in prose unless later story requires it.

---

# 2. Valid Trigger

A spoken TRUE NAME triggers only when the speaker has a clear specific-person referent.

Valid ways to establish that referent include:

1. personal acquaintance;
2. directly seeing / interacting with the person;
3. a photo clearly mapped to the person's true name;
4. video clearly mapped to the person's true name;
5. ID / school / company / official or private real-name material that unambiguously binds name to person;
6. a prior successful R1 trigger that already taught the listener which person that name meant.

Examples:
- mother says her son's real name -> valid;
- collector holding the debtor's ID photo + records says her real name -> valid;
- police show Cheng Ye Wei Pingzhou's confirmed photo and identity -> valid;
- Tang Ji says her own true name -> valid because self-reference is unambiguous.

---

# 3. Same-Name Rule

A bare name string does NOT scan everyone with that name.

Example:
> someone who only sees “张伟” on a random list and has no idea which Zhang Wei it refers to says “张伟”.

Result:
> NO trigger.

If the speaker is looking at Zhang Wei A's confirmed photo and says “张伟”:
> only Zhang Wei A triggers.

If later the speaker switches to Zhang Wei B's confirmed photo and says the same two characters:
> only Zhang Wei B triggers.

Therefore:
> same-name people never light up together merely because the spoken characters match.

---

# 4. Listener Effect

On a valid trigger:

> every person who HEARS the successfully spoken true name receives an intuitive sense of the TARGET PERSON'S current location.

Important:
- target = person whose name was spoken;
- NOT the speaker;
- NOT the listener.

Location sense:
- intuitive direction / relative position / movement;
- not a GPS coordinate UI.

This corrects the old mistaken prose behavior where Cheng Ye heard his own name and somehow learned the speaker's location.

---

# 5. Identity Propagation

A valid trigger also gives listeners a stable referent:

> they now know “the name just spoken referred to THAT specific person.”

They may not know biography or legal details.

But if they later speak the same true name while intending that same person:
> they can trigger R1 again.

This is why one successful livestream exposure is dangerous:
> audience members who originally did not know the target can become future re-triggers.

The location line disappears in daylight.
The learned person-name referent does NOT automatically vanish just because daylight returns.

---

# 6. Transmission Medium

Confirmed working:
- face-to-face speech;
- phone call;
- live radio / police channel;
- live voice chat;
- livestream audio;
- loudspeaker / public-address live voice.

Hard:
> physical distance between speaker and listener does not block a valid audible trigger.

Not yet canonized:
> prerecorded playback / synthetic voice / text-to-speech edge cases.

Do NOT invent these until a later story actually needs them.

---

# 7. What Does NOT Trigger

By current lock:

- written name alone;
- text message alone;
- name displayed on screen alone;
- nickname;
- online handle;
- work number;
- family title;
- a bare same-name string with no specific-person binding.

However:
> written/photo/ID material CAN establish the speaker's identity binding,
> after which SPEAKING the true name can trigger.

---

# 8. Self-Name

A person saying their own true name at night is a valid trigger.

Reason:
> no identity ambiguity exists for the speaker.

All listeners can then locate that speaker.

This supports Field #2 Tang Ji's rescue use.

---

# 9. Social Consequence

The scarce/dangerous asset is NOT merely:
> knowing a name.

It is:
> **having a reliable name-person binding.**

Therefore high-value / high-risk assets naturally include:
- ID photos;
- employee directories with photos;
- school rosters with faces;
- medical/official real-name systems;
- debtor files;
- livestream face + real name;
- social profiles that cleanly bind legal identity.

This is the intended reality-side engine.
