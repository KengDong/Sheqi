### S12｜老板一门心思想亏钱，做出来的项目偏偏有人追捧 〔C15〕
- **原作/讨论**：《亏成首富从游戏开始》；[章节目录：第3—8章](https://m.zongheng.com/chapter/list/1501670/93331529)
- **场面或线索**：围绕《孤独的沙漠公路》出现反向立项、下载、意外成绩与结算，主角本愿和市场反馈背道而驰。
- **引人想看的功能**：反目标让普通商业执行不断从‘失败计划’长出‘别人视角的成功’，理论上可迁移到不同产业。
- **真实性**：本轮仅独立核验到具体章节目录标题；**没有实读完整项目arc**，不能据此宣称连载稳定性已核。
- **独立创作边界**：作品原有亏钱系统和特定游戏案例不可直接换皮；必须真正检验多轮不同结局。
- **作者选择**：〔 WANT / MAYBE / NO / 深读 〕

### S13｜神秘会议的献祭仪式，竟然可能变成跨地域物流 〔C20〕
- **原作/讨论**：《诡秘之主》；[研究员单章指针](https://www.hetushu.com/book/4917/3663434.html)、[起点作品资料](https://book.qidian.com/booklist/detail/646806/)
- **场面或线索**：会众本来通过神秘空间交换信息，却尝试用献祭把实物送到其他地方；参与者误把主持者的试错也解读成大能威严。
- **引人想看的功能**：一个旧机制升级为物流，使金钱/物资/信息/身份四条线同时变得可写。
- **真实性**：研究员阅读的是第三方单章，未独立确认起点相应章节与完整交易成败。
- **独立创作边界**：不复刻塔罗会/愚者和献祭流程，借的是‘仪式用途转变引发制度后果’。
- **作者选择**：〔 WANT / MAYBE / NO / 深读 〕

### S14｜小孩乱续成语逗笑客人，却让远方亲人立刻察觉家里出事 〔C26〕
- **原作/讨论**：《大王饶命》；[研究员单章指针](https://loying.org/book/dawangraoming/59756.html)、[起点书单资料](https://book.qidian.com/booklist/detail/646704/)
- **场面或线索**：小女孩一本正经把来客成语续成危险的词，现场高手动怒产生系统负面情绪；远处主角通过系统收益知道家中异常。
- **引人想看的功能**：一句好笑误答不是终点，还变成资源回报和远程危险通知，角色关系得到回应。
- **真实性**：研究员第三方第84章单章；curator未独立核对官方原文/前后章节。
- **独立创作边界**：不能直接复制特定成语和远程情报的独特情节；可研究‘笑点改变亲属的行动’。
- **作者选择**：〔 WANT / MAYBE / NO / 深读 〕

### S15｜现代医生和修仙怪人互称对方是幻觉，真假争执竟成肉搏 〔C29〕
- **原作/讨论**：《道诡异仙》；[起点官方作品页](https://www.qidian.com/book/1031794030/)、[研究员第171/174章指针](https://www.hetushu.com/book/7625/5325770.html)
- **场面或线索**：现代诊疗体系与另一套修仙身份相互否定，其中一方有自洽解释；研究员记录后来两方身体层面的冲突。
- **引人想看的功能**：悬疑不是猜谁说了谎，而是两套认知同时真实地伤害人物，甚至影响身体。
- **真实性**：起点官方确定本书真假/精神困境设定；具体171与174来自第三方单章且不连续。
- **独立创作边界**：受强IP识别的两界/精神病/丹阳子细节不可贴皮；持续性与因果需连读。
- **作者选择**：〔 WANT / MAYBE / NO / 深读 〕

### S16｜以为逃出恐怖任务，系统却只给7%完成度 〔C34〕
- **原作/讨论**：《我有一座冒险屋》；[研究员单章指针](https://www.hetushu.com/book/5214/3915559.html)、[起点书单作品介绍](https://book.qidian.com/booklist/detail/349910/)
- **场面或线索**：幸存者退出后发现任务仅低比例完成；外部组织横插一脚，迫使主人公在救人与按规则完美结算间纠结。
- **引人想看的功能**：任务失败不是‘重来一次’，而是把遗漏转成真实后续责任；恐怖经营也因此带缺口成长。
- **真实性**：起点公开简介证实惊悚经营基础；7%关键细节只来自研究员第三方单章，后续未追。
- **独立创作边界**：不是套一个完成率提示框就有效，关键是未完成让人承担代价。
- **作者选择**：〔 WANT / MAYBE / NO / 深读 〕

- **真实性**：curator确实复核到公开论坛讨论；**不是原著桥段、也不是市场整体偏好调查**。
- **独立创作边界**：不能把粉丝假设直接写成原著已有的效果；仍需查真正的章内能力上限。
- **作者选择**：〔 WANT / MAYBE / NO / 深读 〕
