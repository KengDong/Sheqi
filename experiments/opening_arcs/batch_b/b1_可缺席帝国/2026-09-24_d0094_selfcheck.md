# B1《可缺席帝国》Opening Arc｜Selfcheck

status: COMPLETE
decision: D-0094
scope: Ch1—Ch4, stops at first natural mini-climax.

## Core result

The arc proves the frozen premium through on-page events rather than management exposition:

- 章栩在公司遭遇真实危机时被强制执行一张七年前卖掉的“未来出席权”；
- 缺席直接伤到公司控制链，也让他错过女儿第一次登台；
- 程雁获得一级调度权后，没有“替章栩执行”，而是做了章栩大概率不会做的决定：调用北鲸专属车辆、开放站点、开启区域自治；
- 组织在章栩缺席期间真正完成危机处置，并获得新的公共协同入口；
- 胜利有真实成本：北鲸终止年度合同、站点边界被打开、章栩失去对公司的绝对中心感；
- 章栩回归后没有把权力收回，而是主动取消“创始人单人接管”，将一次临时缺席转化成不可即时撤销的结构变化；
- 私人层没有被事业胜利覆盖：女儿的演出只能看录像，未来还有一张无法回购的生日出席权。

## D-0094 Required Reader Experience

1. Core promise on-page: PASS  
   “过去卖掉未来日期→今天被强制带走→公司必须在本人缺席时继续运转”已在第一章兑现。

2. Protagonist concrete desire: PASS  
   当下欲望是保住雨天危机中的闪渡与关键合同；更深层欲望逐步转为“让事业不再被本人缺席掐住”。

3. First meaningful fruit: PASS  
   程雁拿到真实一级调度权，区域站点获得自治，组织第一次独立解决大危机。

4. Fruit creates cost: PASS  
   北鲸年度合同终止、站点被对手看见、章栩的单人控制权被永久削弱。

5. Relationship changes: PASS  
   程雁从“执行章栩决定的人”变成有权做出不同决定的共同经营者；章栩必须接受她不是替身。

6. World/social interface expands: PASS  
   未来出席权执行中心、二级市场、公共应急协同、同行共享站点均进入故事，但未转为设定说明。

7. Pressure learns/intensifies: PASS  
   章栩的公开缺席事件反而抬高剩余未来出席权估值，意味着他的成功会持续放大旧未来的价值与威胁。

8. Protagonist real choice: PASS  
   他没有在回来后恢复旧控制，而是取消创始人单人接管权。

9. First mini-climax/payoff lands: PASS  
   公司在他缺席时赢下危机；他回来承认这种胜利的合法性，并付出中心权力不可即时收回的代价。

10. Specific larger desire remains: PASS  
   工作侧：让剩余二十三个缺席日都不再成为公司单点故障。  
   私人侧：2027-04-17女儿生日的出席权已转让且拒绝报价，他必须想办法“把自己留下来”。

## B1 Must Prove

- 第一次强制缺席真的伤到事业/关系：PASS
- 团队不是替身；有人因真实权力做出主角未必会做的决定：PASS
- 组织在主角缺席时真的赢一次：PASS
- 胜利让主角失去控制/中心感：PASS
- 家庭/亲密层证明“公司可代理，人不能完全代理”：PASS

## Hard Watch

- 商业管理说明书：CONTROLLED  
  权限/调度均服务于当场冲突；没有列制度、流程图或抽象经营课。

- 授权表/流程图式爽点：CONTROLLED  
  授权只作为“谁能在章栩不在时做不同决定”的戏剧工具；主要果实来自雨中车辆、站点与人的行动。

- 旧合同持有人纸片反派：AVOIDED  
  当前权利人保持匿名，不承担脸谱化反派功能；压力来自合法旧合同本身与章栩过去的选择。

- 事业成功但私人层完全不痛：AVOIDED  
  女儿演出是不可补拍的缺席，且未来生日日期留下具体长期私人压力。
