# X19｜现代线 / 古界线命名分层 V1

date: 2026-09-27
status: AUTHOR REVIEW

## Goal
Names should act as instant scene labels.

Modern line:
> ordinary contemporary Chinese names; easy, realistic, student / workplace feel.

Ancient line:
> older classical naming texture; readers should immediately read them as source-era people.

Avoid:
- everyone having ornate "AI-literary" names;
- modern people named like ancient sect heirs;
- ancient people named like current university classmates;
- overuse of 玄 / 尘 / 仙 / 无双 / 凌天.

### Ancient naming pool principles
Use families such as:
> 季 / 谢 / 崔 / 裴 / 温 / 顾 / 陆 / 沈

Use given names with older literary / historical texture:
> 长庚 / 无咎 / 元直 / 知白 / 景行 / 怀真 / 守拙 / 子衡

Do NOT make every ancient actor similarly elegant.
Some should have plain old-style names:
> 陈三郎 / 赵老七 / 孙二娘-type social texture where appropriate.
