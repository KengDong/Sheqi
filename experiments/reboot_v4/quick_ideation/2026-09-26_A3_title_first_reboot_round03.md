# Why Round 02 failed

AUTHOR:
> R4勉强看得过去，其他3个都不行，直接和《我正经学生，每天只吃九种魔药》对比，标题就差很多，总觉得差了很多。

Diagnosis:
- too many titles describe macro setting;
- protagonist often only "knows / sees";
- abstract nouns dominate: 仙道 / 历史 / 三千年 / 天道;
- title does not show a repeatable strange behavior.

# Current hit-title anatomy

## 《我正经学生，每天只吃九种魔药》
Functions:
- relatable identity: 正经学生;
- contradiction: 正经 vs 魔药;
- repeated frequency: 每天;
- countable concrete object: 九种;
- implied engine: new drugs / new effects;
- title reads like an opening scene.

## 《你的技能很好，现在我也有了》
Functions:
- direct speech;
- action / appropriation;
- instantly understandable power fantasy;
- repeated engine implied.

## 《这个地下城长蘑菇了》
Functions:
- familiar place + absurd physical change;
- visual;
- growth / spread implied.

## 《我都成超人了，灵气才复苏？》
Functions:
- colloquial timing mismatch;
- protagonist already ahead of the world;
- immediate status superiority.

## 《没钱修什么仙？》
Functions:
- colloquial;
- one human pain point;
- one contradiction;
- no lore homework.

# New hard gate

A3 title should preferably have:
1. I / protagonist;
2. concrete action;
3. concrete object / place;
4. contradiction or impossible result;
5. repeatable engine implied;
6. no more than one large abstract cosmology term.

Avoid titles whose main verbs are:
> 知道 / 看见 / 发现.

Prefer:
> 捡 / 埋 / 送 / 还 / 拆 / 收 / 救 / 吃 / 挖 / 养 / 开.

- implies serialization;
- hides lore rather than explaining it.
