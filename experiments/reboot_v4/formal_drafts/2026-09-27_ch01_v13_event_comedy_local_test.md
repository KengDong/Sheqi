# Ch01 V13｜Event-Comedy Local Test
## Scope
> arrival -> first round -> rule setup -> second round reward/injury collision
> Not a full chapter replacement.

邵教练核对资料的时候，程野正在把测试法衣往身上套。

“陪测十二单？”

“十一单半。”

邵教练抬头看了他一眼：“平台还能算半单？”

“能。上一单打到第三分钟，对面腿抽筋了。后面九分钟我陪他去了医务室，平台说医疗陪同不属于身法陪测，最后双方各让一步，算了半单。”

邵教练低头翻了翻记录。

页面上还真有一条：【买方突发肌肉痉挛，订单异常中止】。

“行，至少医务室路线你熟。”

“最好今天用不上。”

周航已经在场里等了，听见这句回头看了一眼，没问。他今天花钱不是来听别人工作履历的。

三个人把规则过完，很快开打。

第一轮程野按订单要求盯着周航右侧压。前两次都没抓住，第三次周航被逼得提前起第四式，右肩那口护体灵力先散，脚下才跟着乱。

邵教练当场喊停。

场边屏幕同时弹出两条记录。

【买方目标样本：有效】

下面还有一条灰的。

【陪测方动作异常：掠云→回风衔接延迟0.11秒】

周航已经走到大屏前看自己的回放了。

程野却低头点开了那条灰色记录。

能保存。

他顺手保存了一份。

邵教练注意到他的动作：“你这也是老问题？”

“五年了。”

“做过动态联测没有？”

“基础的做过。”

“那查不出这种实战里的气机延迟。想找原因得做动态的。”

程野问：“你们馆里多少？”

“一千二。”

“跟我问到的一样。”

他说完又低头看了一眼刚保存下来的0.11秒。

虽然只有一个异常点，离完整诊断差得远，但这条数据没收钱。

程野把文件名从系统默认的日期改成“回风卡顿”，存进自己的训练记录。

周航这时也看完了。

“再来一轮。”他活动了一下右肩，“刚才那一下还不够明显，压狠一点。”

程野正要进场，走到感应线旁边又停了。

程野走到感应线旁边又停了下来：“邵教练，我问个事。订单上那个八百，陪测方的动作也算？”

邵教练看了眼订单：“只要是在正常对抗里自然出现的平台未收录动作，哪边出的都算。”

程野又确认了一句：“要是我自己故意做一个呢？”

“那就不算，平台会按骗奖励处理。”

程野这才点头：“行，那我心里有数了。”

邵教练看了他一眼：“你问这么细干什么？”

“上次少了半单以后，我对结算规则比较尊重。”

邵教练没说什么，只把护场阵的状态重新确认了一遍。

第二轮开始。

周航知道程野会抢右边，比第一轮防得更紧。前两次换位都没给机会，第三次两个人已经贴到很近，程野用掠云从正面斜出去，前脚刚落，腿里那口熟悉的滞涩便顶了上来。

0.11秒又来了。

以前到了这里，他会提前把距离拉开，等灵息归稳再起回风。

这一次没有。

刚才那个问题他已经问清楚了。

不能故意做一个假的。

但老毛病是真的。

周航要的高压也是真的。

程野索性没替自己把问题藏回去。

周航已经追到身侧。

就在这时，他听见了雨声。

最初只有几滴，像落在瓦上。

程野没有时间抬头。眼前周航的掌还在往里压，白色场墙却在余光里一点点泛出湿痕。

雨幕之后，一个灰衣年轻人抱着木匣冲进石院。

法剑紧跟着封死前路。

程野看见那人也用了掠云。

前脚落地以后，没有等第三式残下的灵息归稳，直接强起回风。

右腿狠狠一颤。

人却早了半拍。

程野只看了一眼就明白了。

自己五年来每次都在等的，就是这一口气。

周航的掌已经到了。

程野照着那个人的动作，把还没收回去的灵息直接压进第四式。

腿侧骤然一疼。

人却真的折了回来。

周航按前两次的节奏追进来，正好被他从侧面切过，一掌拍中后背的测试区。

法衣亮起。

腕表随后震了两下。

程野低头。

第一条：

【检测到未收录身法衔接】
【额外奖励：800元｜待核验】

第二条：

【检测到右腿经脉压力异常】
【建议立即停止测试】

两条消息一上一下。

程野看了半秒。

上一次是买方抽筋，订单只算了半单。

这一次换成陪测方。

他还没来得及研究平台准备怎么算，雨声仍在继续。

石院里的灰衣年轻人忽然回过了头。
