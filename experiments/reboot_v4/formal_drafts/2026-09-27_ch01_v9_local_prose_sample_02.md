# Ch01 V9｜Local Prose Sample 02
## Scope
> 训练馆见面 -> 第一轮 -> 第二轮起手
> 只测真人对话与《流云步》动作可读性。

七号场的门刚开，里面的热气就扑了出来。

周航刚停下动作，训练服后背湿了一片，正低头看刚才那段回放。邵教练坐在场边，听见门响，抬头问了一句：“程野？”

“嗯。”

“东西都存了？”

“存了。”

“那进来吧。”

程野跨过阵线，测试法衣自己亮了一下。邵教练在终端上点了确认，又问：“规则看过没有？”

“只测身法，不放术法。”

“对。十二分钟，你负责给他压力。别陪他走套路，真卡。”

周航这才把回放关掉，拿毛巾擦了把脸。

“等会儿盯我右边。”他说，“第四式一起来，你就往里抢。”

程野看了眼他刚才反复看的那段录像：“一直是这儿？”

“教练说有问题，我自己练看不出来。”

“行。”

周航把毛巾扔回椅子上：“别收着。”

“知道了。”

邵教练抬手，场边阵纹转绿。

周航先压了上来。

两个人用的都是《流云步》。

周航一掌逼到面前，程野用第三式·掠云斜着让出去。前脚一落，紧接着就该起第四式·回风，折身抢回周航侧面。

可脚已经落稳，腿里那口气没跟上，人就在该回来的地方多停了半拍。

周航没管他为什么停，转身一掌，结结实实拍在测试法衣上。

红光亮起。

“停。”

邵教练先朝周航招手：“过来。”

周航快步走到屏幕前。

“看右肩。”邵教练把刚才那一下倒回去，“他一从左边抢进来，你这里先松了。脚还没乱，气先散了。”

周航盯着那段慢放：“就是这一下？”

“嗯。再打一轮看看。”

“行。”

程野站在后面揉了揉胸口。法衣卸了大半力，不疼，就是腕表上多了一条自己的提示。

【掠云 -> 回风：衔接延迟 0.11秒】

邵教练余光扫到：“你也卡这儿？”

“老毛病。”

“多久了？”

“高二就有。”

“查过没？”

“基础检查做过，没伤。”

邵教练点点头，没再问：“先把这单打完。”

周航已经重新走回场中，边走边说：“还是刚才那边。”

程野跟了过去。

“你右边？”

“嗯。再压狠一点。”

“行。”

两人重新站定。

这一次程野没提前给自己留位置。

周航一动，他就跟着往里压。

第一遍掠出去，回风接上了。第二遍也没出问题。

到第三遍，两个人已经贴得很近。程野刚斜着让开，前脚落地，腿里那口气又堵住了，身体没能马上折回来。

周航已经追上来。

程野没有退。

耳边却忽然多了一阵雨声。
