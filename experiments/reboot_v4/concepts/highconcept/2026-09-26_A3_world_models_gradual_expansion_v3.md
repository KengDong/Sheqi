# 0. Benchmark gradient

## 《没钱修什么仙？》
Functional expansion:
> personal future / school / work / money / competition
→ basic cultivation and practical gains
→ larger institutions and class differences
→ deeper civilization rules.

Key:
> world is learned by living inside it.

## 《原来我是仙道天骄》
Functional expansion:
> one crossing
→ small difference between two worlds
→ practical cultivation / resources
→ repeated crossing
→ status gradually rises
→ only later does "天骄" fully pay off.

Key:
> second world is immediately useful before it becomes cosmologically important.

## 《我正经学生，每天只吃九种魔药》
Functional expansion:
> one medicine → immediate reversed benefit → seek next medicine
before high-level identity / cosmic scale.

Key:
> the early engine must be smaller than the shelf fantasy.

## 《从水猴子开始成神》
Functional expansion:
> one underpriced domain → one resource → one pet / ability → wider water territory → water-god endpoint.

Key:
> reader wants the next slightly bigger version of the same pleasure.

# 1. World A｜现代全民修真文明

Reference core:
> 《没钱修什么仙？》's lived cultivation civilization.

Do NOT copy:
- finance-loan vocabulary as main gimmick;
- exact school / platform / corporate structure.

## 1.1 Surface world

Cultivation is ordinary civilization:
- basic cultivation taught widely;
- standardized low-level techniques;
- public cultivation facilities;
- second-hand spiritual goods;
- certification / admission / employment tied to cultivation level;
- clinics, transit, agriculture and industry use spiritual systems.

The opening should feel:
> "this is a society I can imagine living in."

Not:
> "look at this author's worldbuilding."

## 1.2 Best early A3 lane

A3's equivalent of "one medicine":

> **主角能看出修行物品真正的“寿尽状态”，并让一件真正寿尽之物完成最后一次完整作用。**

Working early rule:
- broken ≠ dead;
- old ≠ dead;
- working ≠ alive;
- only true terminal state can trigger protagonist's special handling.

For a true terminal object:
> protagonist can complete its "last use / last return".

Immediate benefit:
- cheap or discarded cultivation assets become useful to him;
- he saves money / gets practice resources / solves a small problem;
- after true ending, a tiny return residue can help his own cultivation.

Important:
> this is not generic recycling.
> the pleasure is "everyone else evaluates remaining function; I evaluate remaining lifespan."

## 1.3 Ch1–3

No Heaven.

Choose one personal pressure:
- cannot afford a new cultivation tool;
- training / certification requires equipment;
- family cannot keep paying cultivation costs;
- first job / admission depends on one concrete performance.

He obtains / encounters a discarded low-grade item.

Example function:
> a practice sword / qi condenser / protective talisman judged worthless.

He sees:
> not "broken".
> **one final complete use remains.**

He uses that last complete state to solve his immediate problem.

Then the item truly ends.

A tiny visible return happens:
> nearby qi steadies / one residue forms / his cultivation cycle moves.

Reader learns only:
> this weird ability is useful.

## 1.4 Ch4–20

Life-scale loop:
> save money → find terminal item → use it correctly → immediate gain → need a slightly better item.

Locations:
- campus / training hall if student;
- second-hand cultivation market;
- neighborhood repair shop;
- public practice rooms;
- low-grade workplace.

Not every item gives combat power.

Examples:
- expired practice talisman gives one last flawless activation;
- almost-dead meditation pad gives one last peak cultivation session;
- old pill furnace can complete one final stable batch;
- a worn spirit-pet contract has one unresolved final command.

Personal goals:
- pass certification;
- reach next small realm;
- earn money;
- help family / friend;
- beat one fair competition.

This is where reader attachment forms.

## 1.5 Ch20–50

First complication:
> protagonist finds an item everyone says is dead, but he sees **未死，可救**.

This prevents "everything old = protagonist loot."

Second complication:
> an item still works normally, but he sees **已死 / forced operation**.

Now the ability becomes more than bargain hunting.

The reader starts asking:
> why are terminal states becoming weird?

Still no global answer.

Social result:
- one teacher / shop owner / technician / senior starts trusting his judgment;
- protagonist gains access to better circles because results matter.

## 1.6 Ch50–100

First shared asset:
- a small public training array;
- neighborhood spirit well;
- local clinic array;
- small company / school facility.

Thousands do not depend on it yet.
Maybe dozens / hundreds.

The system is still functioning.
Protagonist sees:
> it has already entered terminal operation.

Now "use one last time" is no longer enough.

He must choose:
- keep it running for immediate benefit;
- replace / transition;
- close it properly.

This is the first time the reader feels:
> the same ability that helped him save money may matter to other people.

Only around this stage should multiple cases suggest:
> modern cultivation assets are reaching terminal state earlier than old records say.

## 1.7 100+

Scale can rise:
> personal item → facility → field / animal → infrastructure → vein.

Only now:
- institutions care;
- data comparison appears;
- bigger cycle mystery begins.

The eventual Heaven line grows from the same question:
> why is the entire civilization's lifespan shortening?

## 1.8 Why A works

It preserves the thing 《没钱修什么仙？》 does well:
> the strange world is experienced through ordinary life pressure.

A3's uniqueness is not:
> modern cultivation.

It is:
> the civilization has developed a giant market / infrastructure around "how long things can keep functioning", while protagonist sees "how long they are truly alive."

# 2. World D｜现代修真文明 + 古老传统修仙界

Reference core:
> 《原来我是仙道天骄》 proves that two worlds can begin with small practical difference before high-level identity payoff.

Similarity danger:
> modern low-talent youth + magic bead + free cross + ancient world calls him genius + commodity arbitrage.

Therefore D must keep the useful gradient but change the core geometry.

## 2.1 World A surface

Use the same modern mass-cultivation civilization as World A above.

Opening advantage:
> protagonist first discovers terminal-state perception HERE.

He is not required to be a student.
He only needs one understandable immediate pressure.

## 2.2 Why crossing happens

Do NOT start with a generic "破界珠".

Working rule:

> **真正完成一件“来历不属于本界 / 归处缺失”的寿尽之物后，它的“归路”会短暂显现。**

The first object is an old cultivation object with unknown provenance.

The protagonist completes its terminal use / proper ending.

Its remaining causal flow cannot return locally.

A temporary "return path" opens to:
> the world / cultivation ecology it originally belongs to.

The protagonist is accidentally carried across because:
> he is the handler who completed the return.

Early understanding:
> he thinks this is just another cultivation world.

No "two halves of Heaven" explanation.

## 2.3 Crossing limits

Early:
- only after a real terminal completion;
- opens briefly;
- fixed destination near the object's origin;
- cannot choose coordinates;
- cannot freely ship cargo;
- next crossing requires another completed return or a stable anchor.

This creates a small goal:
> if I want to go back / go again, I need another suitable terminal object.

That is the D equivalent of:
> "I need another medicine"
or
> "I need another useful two-world exchange."

## 2.4 What is immediately useful in ancient world

Do NOT make protagonist a heavenly genius.

The two worlds value METHODS differently.

Modern world:
- good at standardization;
- repair;
- extending function;
- cheap mass production;
- measurement.

Ancient world:
- better at natural cultivation;
- reading the "life" of artifacts / veins;
- older end-of-life rites;
- high-quality but scarce raw resources;
- craft knowledge not industrialized.

First ancient-world gain:
> protagonist learns one very small natural "收尾 / 归息" technique that modern civilization no longer teaches.

This technique makes his modern terminal-state ability actually usable.

First modern contribution to ancient world:
> he uses modern diagnostic / repair thinking to prove that something locals want to retire / bury is actually not dead.

Thus:
- ancient world teaches him how to end correctly;
- modern world teaches him how to distinguish repairable from terminal.

Both sides are useful.
Neither is a stupid museum.

## 2.5 Ch1–20 slope

Ch1–3:
> modern pressure + first terminal object + first accidental crossing.

Ch4–8:
> survive / understand one small ancient location;
> meet 2–3 recurring people, not a whole cosmic sect.

Ch9–15:
> use one ancient technique back in modern world;
> get immediate cultivation / money / status benefit.

Ch16–20:
> solve one small ancient problem using modern knowledge;
> establish first stable relationship / anchor.

Reader pleasure:
> each world gives the other world one practical edge.

No Heaven.
No ancient-world chosen-one status.

## 2.6 Ch20–50

Crossing becomes predictable but still costly.

Modern:
> protagonist searches terminal objects partly because they fuel / locate return paths.

Ancient:
> one family / workshop / small sect begins trusting him.

The two worlds slowly reveal different assumptions:
- modern asks: "how long can this keep running?"
- ancient asks: "has its life-cycle completed?"

The protagonist becomes valuable because he can compare both systems.

Status in ancient world:
> useful outsider / strange craftsman / reliable cultivator,
not天骄.

Status in modern world:
> person with unusually effective handling methods,
not cosmic savior.

## 2.7 Ch50–100

First cross-world causal mystery:
> a modern mass-produced cultivation technique / item turns out to descend from something ancient, but the terminal behavior is different.

Or:
> an ancient natural method disappears in modern history after industrialization.

The protagonist realizes:
> the worlds are not merely unrelated resource maps.

But DO NOT answer relation yet.

This is the first long mystery hook.

## 2.8 100+

Only now can we test deeper relations:
- parallel worlds?
- diverged branches?
- same cosmological root?
- old exchange once existed?

The original A3 Heaven / return crisis can grow from comparative evidence:
> one world over-extends life;
> one world knows endings better;
> both show different forms of depletion.

The ultimate relation is reserved.

## 2.9 Why D works

It preserves the best function from 《原来我是仙道天骄》:
> every crossing produces a practical new option.

But differs in:
- crossing trigger;
- no free portal;
- no "here low talent / there top talent" geometry;
- no bulk commodity trader as main engine;
- protagonist's value comes from combining two cultivation philosophies.

# 3. Previously retained World 4｜仙朝 / state cultivation

Reassessment after gradient correction:

This is weaker as A3's opening **premise chassis**,
but strong as a later institutional layer.

Best use:
> embed it inside World 8 or use it as a region / state encountered after Ch50–100.

Why:
- A3 early pleasure needs personal useful advantage;
- official authority only becomes exciting after reader has already seen protagonist prove competence.

Recommended progression:
> local life / market / family
→ one county public problem
→ local authority recognizes protagonist
→ then "handling right" matters.

Do NOT open with:
> “I am a low-ranked spiritual-infrastructure inspector.”

That repeats the job-first failure.

# 4. Previously retained World 8｜classical-looking but mass-infrastructure cultivation civilization

This remains valuable.

It can be treated as:
> **World A's core logic wearing a more traditional xianxia skin.**

Surface:
- immortal towns;
- sect academies;
- public spirit wells;
- flying boats;
- mass talismans;
- rented cultivation rooms;
- sect-operated fields and transport.

But no smartphones / corporations required.

## Early loop

Same as World A:
> end-of-life cultivation objects are everywhere.

But locations become:
-坊市 old-artifact stall;
- sect practice hall;
- rented cave dwelling;
- public spirit well;
- ferry formation;
- small clan workshop.

This can borrow:
- 《从水猴子开始成神》 underpriced-resource pleasure;
- 《苟在初圣魔门当人材》 familiar dangerous cultivation society;
- 《玄鉴仙族》 persistent family / land / lineage consequences.

## Expansion

Ch1–20:
> one town / sect / market.

Ch20–50:
> old tools / fields / beasts / caves.

Ch50–100:
> one sect or immortal town depends on a terminal system.

100+:
> regional veins / old Dao lines.

Advantage:
> stronger xianxia flavor than modern A.

Risk:
> without modern society's familiar pressure, protagonist's day-to-day desire must be supplied by family / sect / money / cultivation resources very clearly.
