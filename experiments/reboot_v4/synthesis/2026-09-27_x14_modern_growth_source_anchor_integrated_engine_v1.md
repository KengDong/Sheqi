# 0. First-principle

Modern growth is the spine.

Ancient/source interaction is NOT:
> a separate second map protagonist visits whenever plot needs a solution.

It is:
> a deeper layer of reality that modern growth progressively grants access to.

Core loop:
> modern need / modern action
> → protagonist gains real access to a source-bearing thing
> → world-scar resonates
> → source overlap / source-body entry
> → ancient relationship / knowledge / layout
> → return with leverage, not automatic victory
> → protagonist digests leverage through modern training / work / institution
> → modern status rises
> → new social access exposes new classes of anchors.

# 1. Recovered travel mechanism

## Public world substrate
Modern cyber-cultivation society already uses:
- source-lineage authentication;
- Dao-trace / creator-signature analysis;
- version lineage;
- relic provenance;
- compatibility diagnostics.

This is normal infrastructure.

## Protagonist anomaly
Because his first Earth→cultivation-world crossing left a world-scar,
deep synchronization with a strong surviving source can pull him beyond:
> recorded data / residual image

into:
> the source-era causal node itself.

He cannot select a famous historical person from a menu.

He must first:
> genuinely touch / practice / use / obtain access to something that still carries the cause.

# 2. Two-stage entry solves "hard cut"

Early travel should have two levels.

## Level 1｜source bleed / overlap
Trigger:
> brief high-pressure resonance.

Experience:
- modern scene and source-era scene overlap;
- protagonist may see / hear / copy one motion / detail;
- source-side person may sometimes notice him.

Use:
> Fanqie Ch1 immediate payoff without hard map cut.

## Level 2｜deep source-body entry
Trigger:
> protagonist intentionally recreates the resonance / reaches deeper synchronization.

Experience:
- consciousness projects upstream;
- temporary local source-body forms;
- can speak, touch, practice, be injured;
- modern body remains in low-response state.

Use:
> real relationship / ancient plot.

Progression:
> Ch1 overlap
> → Ch2/3 reciprocal contact
> → later first full source-body visit.

This is more natural than:
> fight ends → suddenly full ancient chapter.

# 3. Anchor taxonomy｜NOT ONLY TECHNIQUES

## A. Technique anchor
Modern contact:
- practicing a method;
- technique stress test;
- version analysis.

Ancient source:
- creator;
- practitioner;
- failed branch;
- technique birth event.

Potential returns:
- source logic;
- lost branch;
- future failure information;
- creator relationship.

Opening can use this because combat-data gig naturally supplies it.

But it is ONLY the first anchor class.

## B. Artifact / equipment anchor
Modern contact:
- protagonist repairs / stress-tests / authenticates an old tool;
- enters a company / school lab;
- gains permission to handle a relic.

Ancient source:
- craftsman;
- original owner;
- battlefield / event where object gained its significance;
- creator before fame.

Potential returns:
- craft logic;
- hidden use;
- material-preservation layout;
- relationship with craftspeople / owner network.

## C. Medicine / body anchor
Modern contact:
- recovery cost;
- injury;
- compatibility scan;
- medicine trial;
- rare pathology.

Ancient source:
- healer;
- alchemist;
- patient zero / original failure;
- source herb cultivation.

Potential returns:
- cheaper recovery;
- diagnostic logic;
- medicinal strain planted for the future;
- medical lineage.

This naturally follows protagonist's increased training load.

## D. Institution / lineage anchor
Modern contact:
- school gains access to a restricted archive;
- protagonist earns internship;
- passes a qualification;
- enters a major sect / company / public agency;
- handles founder token / charter / old contract.

Ancient source:
- founding meeting;
- young founders before status;
- split between factions;
- forgotten co-founder;
- original institutional bargain.

Potential returns:
- private founder instruction;
- archive access;
- institutional obligation;
- hidden branch / alternative founding principle.

This is where "my background is in history" becomes large.

## E. Location / event anchor
Extension consistent with surviving-cause rule.

Modern contact:
- ancient training site;
- battlefield;
- sealed ruin;
- city infrastructure built over an old event.

Requirement:
> protagonist must be physically / institutionally inside the surviving trace,
not simply know a historical location.

Ancient source:
- event itself;
- ordinary people inside it;
- not necessarily a famous figure.

Potential returns:
- event truth;
- unknown survivors;
- hidden resource / route;
- fate / convergence evidence.

Useful for moving beyond famous-person collection.

## F. Relationship anchor
Unlocked only AFTER real source relationship exists.

Ancient actor deliberately leaves:
- phrase;
- token;
- specific technique mark;
- personal Dao-signature;
- promise.

Modern protagonist can use that surviving relationship trace to reconnect.

This changes travel from:
> object finds person

to:
> relationship itself becomes a road.

## G. Network anchor
Later:
> one trusted ancient actor refers protagonist to another.

The source network itself carries causal continuity.

Now protagonist can reach:
- collaborator;
- enemy;
- student;
- institution;
without every contact requiring a random modern relic.

Still bounded:
> referral / surviving trace required.

## H. Active summon anchor
Mid-book upgrade.

An ancient ally learns roughly how protagonist appears and deliberately creates:
> a trace intended specifically for him.

Modern protagonist later encounters the trace and feels:
> someone on the ancient side is calling him.

This is the first time ancient world INITIATES plot.

Very important for making ancient side feel alive.

# 4. Time is not fixed

No "300 years ago" rule.

The reachable era is determined by:
> the source of the anchor.

Early:
- common modern techniques / recent institutional origins:
  roughly tens to hundreds of years.

Mid:
- restricted relics / old lineages:
  hundreds to 1000+ years.

Late:
- civilization-foundational objects / events:
  much deeper eras.

Therefore:
> modern social climb = historical-depth progression.

# 5. How modern growth unlocks anchor diversity

## Stage 1｜ordinary university / gig work
Access:
- common techniques;
- public combat data;
- low-end equipment;
- standard recovery products.

Ancient anchors:
- technique;
- low-status practitioner;
- small craft / medical source.

## Stage 2｜core team / city training / better gig rating
Access:
- uncommon technique versions;
- specialized gear;
- more expensive medicine / diagnostics;
- municipal / university archives.

Ancient anchors:
- forgotten branches;
- healer / craftsman;
- local organization / minor event.

## Stage 3｜internship / company / sect partnership
Access:
- proprietary techniques;
- relics;
- founder material;
- high-value source databases.

Ancient anchors:
- institution origins;
- future major figures;
- hidden co-founders;
- early industry / sect conflicts.

## Stage 4｜major lineage / national institution
Access:
- founder relics;
- sealed archives;
- national ruins;
- civilization-class source objects.

Ancient anchors:
- major wars;
- foundational events;
- deep-era people / networks.

This ensures:
> protagonist doesn't travel deeper because "level 20 unlocked map";
> he travels deeper because he climbed into places ordinary people cannot touch.

# 6. Integrating the real-combat data crowdsourcing opening

## Modern infrastructure
A campus/city combat platform aggregates:
- paid sparring;
- real-combat data collection;
- training-credit settlement;
- injury insurance;
- official practical records;
- optional personalized analysis.

Protagonist takes data gigs for:
- cash;
- training credits;
- access to better diagnostics.

## Ch1
Order:
> pressure-test / rare-edge-case combat sample.

During a recurring movement transition:
> technique anchor reaches resonance threshold.

Source bleed:
- protagonist sees source-era practitioner;
- copies one movement;
- reverses one exchange;
- ancient person looks back.

Modern platform flags:
> unregistered / unmatched source action.

Immediate payoff:
- rare-data bonus;
- public / official anomaly;
- coach attention.

Important:
> Ch1 does NOT imply all future travel is about techniques.

It only demonstrates:
> "modern contact with a strong surviving source can make another era leak through."

## Ch2
Platform freezes / reviews abnormal data.

Protagonist intentionally recreates resonance.

Second overlap:
> first reciprocal communication.

He realizes:
> the ancient person is not a recording.

## Ch3–5
Modern retest / training yields:
- payout;
- higher data-contributor rating;
- better training access.

Meanwhile protagonist follows the trace deeper.

Only after Reader already wants the encounter:
> first true source-body entry.

This avoids abrupt world switch.

# 7. First five source-contact arcs should deliberately vary anchor class

Do NOT do:
> technique founder
> → another technique founder
> → another technique founder.

Recommended early diversity:

## Arc 1｜Technique anchor
Modern problem:
> combat efficiency / paid data gig.

Ancient:
> future movement reformer / practitioner.

Return:
> source understanding + first relationship.

## Arc 2｜Medicine/body anchor
Modern problem:
> higher training load makes recovery expensive.

Ancient:
> obscure recovery practitioner, not known founder.

Return:
> cheaper recovery logic + first uncertain investment.

## Arc 3｜Artifact anchor
Modern problem:
> protagonist takes equipment / technique stress-test gig or gains lab access.

Ancient:
> unknown craftsman / original owner.

Return:
> object history + first material preservation plan.

## Arc 4｜Institution anchor
Modern problem:
> internship / qualification / restricted archive.

Ancient:
> organization before it became powerful;
> multiple founders / conflicting interests.

Return:
> relationship capital / future access / first real political choice.

## Arc 5｜Event/location anchor
Modern problem:
> city-level or national current issue connected to an old site / event.

Ancient:
> protagonist enters a historical event, not a single person.

Return:
> first proof that major events have causal inertia / convergence.

This is where Package E can begin moving:
> closed-loop hidden history
> → local change
> → trunk resists.

# 8. Ancient return categories remain diverse

Immediate:
- source reasoning;
- local information;
- experiment;
- referral.

Deferred material:
- planted medicine;
- sealed tool;
- preserved manuscript;
- hidden location.

Deferred relationship:
- token;
- phrase;
- promise;
- future hearing right.

Deferred institution:
- private founder note;
- charter clause;
- old contract;
- hidden co-founder record.

Failure:
- actor rejects protagonist;
- advice mutates;
- promised return disappears;
- branch becomes hostile.

# 9. Travel constraints retained

Early:
- one deep source-body trip per recovery cycle;
- forcing another causes cognitive / cultivation impairment.

Matter:
> no direct nonliving matter transfer.

Ancient material must:
> survive through history.

Intervention:
> the harder protagonist changes the source,
> the faster that current anchor destabilizes.

This naturally pushes:
> one anchor → downstream residue → new anchor.

Modern body:
> remains vulnerable / low-response during deep trip.

# 10. Package E compatibility

Early:
> source interactions often appear to have always existed in hidden history.

Mid:
> protagonist proves local people / branches can genuinely change.

Later:
> event anchors reveal some large outcomes converge despite intervention.

Late:
> only accumulated multi-era network + modern power allows trunk-level fate breaking.

Travel mechanism therefore scales with Reader fantasy:
> growth → access → agency.

# 11. One-sentence integrated engine

> **他不是想去哪段历史就去哪，而是在现代一路往上爬的过程中，不断获得接触更深“源头”的资格；功法、药物、法器、遗迹、组织乃至人与人的关系，都可能成为通往某个古界时刻的门。**

And:
> **第一次门从一场实战数据单里打开；以后真正决定他能看见什么过去的，是他在现代已经爬到了哪里。**

# 12. Opening's true promise

Ch1 should NOT promise:
> "I can visit technique founders."

It should promise:
> **"The modern cultivation world is full of things with a past, and somehow I can touch that past back."**

Then Ch10–50 reveal:
> the "past" contains people, resources, organizations and hidden history,
not only techniques.
