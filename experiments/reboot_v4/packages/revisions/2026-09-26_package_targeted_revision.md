# Pool 1｜方案四｜《出事以后，他们先来问我》

## 最终测试书名

**《民俗先生：出事以后，他们先来问我》**

## 30字内一句话钩子

**别人都按常理往下做，我先看出哪一步因果不对。**

## 测试简介

我跟着外公学过民俗，却最烦什么事都往玄学上扯。能由医生、警察、工程人员解释的，我从不抢着说成邪事。

直到一次公共事故，我在现场发现：事故顺序和痕迹对不上，所有人准备先动的那样东西，反而不能先碰。我没说“有鬼”，只把普通原因、解释不了的地方，以及继续动下去会发生什么讲清楚。

现场最不信玄学的人当场反对。可现实很快出现了我提前说过的变化，他最终把原来的处理顺序停了下来。从那以后，他仍不信鬼神，却不会再因为“民俗判断”四个字直接否掉我的话。

真正跟着我回来的，也不是一桩桩公共怪案。第一次事件留下的旧当事人家庭还要继续过日子，亲戚邻里会在搬家、白事和旧事上来问，家里和师门要算责任，外公过去的人情也会重新找上门。

有人信我，有人拿我的话压别人。我越被相信，就越不敢乱说——因为以后要负责的，不只是自己看没看对，还有别人听完以后会怎么做。

## 前三章承诺

**前三章内完成“先排普通原因 → 看出处理顺序里的因果错位 → 最不信的人反对 → 现实验证风险 → 对方真的改变处理方式”。**

## 包装自检

- 一眼认题材：PASS。书名直接出现“民俗先生”。
- 一眼认核心爽点：PASS。钩子直接写“先看出哪一步因果不对”。
- 是否新增 Concept 不存在的身份、系统、关系或外挂：NO。
- 是否把公共怪案 / 调查人员重新包装成长期主发动机：NO。
- 是否保留主角先排普通原因：YES。
- 是否保留第一次现实验证与最不信者改变真实行动：YES。
- 是否保留旧当事人家庭、熟人社会、家庭 / 师门、外公旧人情和过去后果：YES。
- 是否保留“越被信任越不敢乱说”的责任上升：YES。
- 简介信息量：已从原约 503 字压缩到约 360 字级，回到统一测试的正常区间。

## 与质检问题逐条对应的修正说明

1. **标题 / 钩子重心修正**：不再用“最不信玄学的人”占据书名中心；书名回到“民俗先生 + 他们会来问”，钩子直接呈现主角能看出别人没看出的因果错位。
2. **长期预期修正**：简介明确写出“真正跟着我回来的，不是一桩桩公共怪案”，后续入口落在旧当事人家庭、亲戚邻里、家庭、师门与外公旧人情。
3. **信息量修正**：压缩公共事故过程，只保留“先排普通原因—看出顺序不对—现实验证—行为改变”四个必要节点。
4. **核心保留**：保住现实派怀疑者、第一次事实验证、行为改变、熟人社会长期后果，以及主角越被信任越谨慎的责任线。
5. **调查人员降权**：包装中不把固定调查人员塑造成任务来源；这里只保留“最不信玄学的人被事实迫使改变处理方式”这一首次社会重估功能。

# Pool 2｜方案一｜《下山神医回城》

## 最终测试书名

**《神医下山：回城先救我妈》**

## 30字内一句话钩子

**他们叫我没出息，真出事只有我能救，后来我的名字越来越有分量。**

## 测试简介

离家多年后，陆沉回到城里时，没有工作，没有人脉，母亲却已经病到最危险的时候。

亲戚怨他这些年不在，旧同学觉得他早混废了，医院里更没人愿意听一个来历不明的年轻人指手画脚。可母亲病情突然恶化时，所有人都没看出来的问题，偏偏被他一眼抓住。

他没有让全院下跪，只让现实先改了一件事：原本拦着他的医生，开始主动问他的判断；原本不信他的家人，把接下来的决定交到他手里。

从那以后，变化没有清零。医生遇到难题会想到他，早期被他救过的人会回来还人情，旧同学重新判断他，小小的会诊入口也一点点变成真正属于他的社会位置。

他下山回城，最先要救的是母亲；再往后，他要让这座曾经只记得“那个没出息的儿子”的城市，真正记住他的名字。

## 前三章承诺

**前三章内，读者会看到主角以“多年失联、没正经工作的儿子”身份被合理看低，并在母亲急变时完成第一次只有他能解决的救命反转；医生和家人的后续行为当场改变。**

## 包装自检

- 一眼认题材：PASS。
- 一眼认核心爽点：PASS。
- 是否新增豪门、顶级机构、神秘后台、无敌师门或更夸张身份：NO。
- 是否保留“低身份被误判 → 真出事只有他能解决 → 名字和社会位置越来越有分量”：YES。
- 是否继续承诺“全城所有人看病都先找他”：NO。
- 是否加长简介补点击力：NO。简介保持原包装不变。

## 与质检问题逐条对应的修正说明

1. **绝对化承诺修正**：删除“全城看病先问我在不在”，不再承诺主角成为整座城市唯一看病入口。
2. **核心爽点保留**：新钩子仍完整保留“被叫没出息 → 真出事只有他能救 → 名字越来越有分量”的身份上升链。
3. **不补额外身份**：没有新增豪门、机构、神秘后台、师门资源或其它更夸张卖点。
4. **其余包装不动**：原标题忠实，继续保留；简介、前三章承诺均沿用原包装，不借返修修改 Concept。
