# Correction

V2 was accurate but not explosive enough.

Current naming target:
> do NOT explain "past capital" abstractly.
> state an outrageous action/result that lets the reader instantly imagine scenes.

Observed current Fanqie pattern:
- title exposes anomaly / result directly;
- "别人...我..." contrast remains readable;
- "开局 / 只有我 / 全..." structures trade elegance for immediate promise.

For X8, the broad long-form fantasy is:
> I can go into the past and actively create the resources / relationships / methods / institutional advantages that my low-status modern self lacks.

Therefore use:
> **造家底 / 改命 / 埋后手 / 攒底蕴 / 改过去**
rather than only:
> 背景在过去.

# Pool A｜造家底
A1｜《全民修仙：别人拼家底，我回过去造家底》
A2｜《修仙大学：别人拼家底，我回过去自己攒》
A3｜《别人修仙继承家底，我的家底自己去过去造》
A4｜《全民修仙：没家底？我回过去给自己攒》
A5｜《现代修仙：我的家底，是我回过去攒出来的》

Why strong:
- "家底" is broad:
  techniques / resources / connections / institutions / inheritance.
- active rather than passive.
- naturally connects bottom-up modern climb.

# Pool B｜过去改命 → 现代兑现
B1｜《全民修仙：我回过去改命，现代开始兑现》
B2｜《我在过去改一次命，现代就多一张底牌》
B3｜《现代修仙：我改过的过去，全成了现在的底牌》
B4｜《全民修仙：我在过去改人命，在现代改自己命》
B5｜《我回过去改了一次，整个现代都变了》

Why strong:
- shows cause → result.
- broad enough for people / methods / institutions.

Risk:
- "改命" can sound fortune-telling if blurb is weak.

# Pool C｜埋后手，回来炸
