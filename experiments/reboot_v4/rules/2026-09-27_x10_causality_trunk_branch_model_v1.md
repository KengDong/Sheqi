status: AUTHOR REVIEW / CAUSALITY REWORK

# 0. Correction

Do NOT make the book:
> modern problem → go to past → rewrite past → modern automatically becomes favorable.

This trivializes:
- modern crisis;
- current-world growth;
- long-run catastrophe;
- "fate" / inevitability.

New priority:
> modern growth is the MAIN AXIS.
> ancient/source interactions are unlocked by growth and create long-horizon layout / leverage.

# 1. Core causality model

History has three practical layers.

## Layer A｜主干史 / causal trunk
Large outcomes supported by many causes:
- major wars;
- rise / fall of civilization-scale institutions;
- large disasters;
- formation of mainstream cultivation order;
- protagonist's present existence.

These have strong causal inertia.

Early protagonist cannot erase them by changing one person / one event.

## Layer B｜支线史 / mutable branches
Local outcomes:
- who survives;
- who meets whom;
- a technique branch;
- a hidden disciple;
- a preserved resource;
- a private founder instruction;
- an organization sub-line.

These can be changed much more easily.

## Layer C｜隐史 / undocumented layer
Events modern public history never fully knew:
- aliases;
- hidden collaborations;
- secret lineages;
- buried resources;
- private agreements.

This is the BEST early playground.

The protagonist's actions can often become:
> "what always secretly happened"
rather than obvious textbook rewrites.

# 2. Early-book rule

Ch1–100:
> most ancient interventions should resolve into Layer B / C.

Reader pleasure:
- protagonist discovers his own words in old private notes;
- a supposedly dead minor person survived under another identity;
- a hidden lineage / resource exists because of protagonist;
- modern public history remains mostly stable.

This creates:
> destiny / closed-loop flavor
without removing agency.

# 3. "History changed" becomes rarer and heavier

Visible modern-history rewrite should be:
- uncommon;
- high-cost;
- associated with crossing a causal threshold.

When it happens:
> protagonist knows he has touched the trunk.

Consequences:
-界痕 pain / instability;
- source anchor breaks;
- old downstream data becomes unreliable;
- current relationships / institutions may shift.

This prevents every chapter from treating reality like a save file.

# 4. Causal attractors / inevitable events

Some major crises are:
> convergence events.

Meaning:
- many independent causes push toward the same result;
- removing one cause changes the route, not the destination.

Example:
protagonist prevents Founder A from joining a war.
Result:
> the war still happens through another alliance.

He kills / saves one key actor.
Result:
> a different actor fills the structural role.

Reader conclusion:
> this is not one bad person causing history.
> the era itself is pushing toward the event.

This creates "命中注定" feeling.

# 5. How fate can still be defeated

Not by:
> changing one node.

But by:
> changing enough underlying conditions across eras.

The protagonist eventually learns:
- one person is not enough;
- one sect is not enough;
- one technique is not enough.

To truly move a causal attractor,
he must accumulate:
- people;
- institutions;
- resources;
- methods;
- contingency plans
across multiple eras.

Thus X8's layout becomes NECESSARY,
not decorative.

# 6. Modern mainline relationship

Ancient contact is triggered by modern growth.

Recommended loop:

1. protagonist advances in modern school / work / institution;
2. gains access to a higher-level technique / relic / source object;
3. that object opens a new source-era relationship;
4. ancient interaction creates:
   - knowledge;
   - relationship;
   - hidden branch;
   - deferred layout;
5. protagonist returns and must solve the current modern problem largely with his OWN digested growth;
6. the resulting modern rise grants access to the next deeper anchor.

Therefore:
> modern climb unlocks ancient layout,
> ancient layout amplifies modern climb,
> but neither replaces the other.

# 7. Ratio / emphasis

Early 100 chapters:
> approximately 65–75% modern current-life progression
> 25–35% ancient/source interaction

Ancient scenes should be high-density:
- relationship shift;
- source knowledge;
- one layout seed.

Do not spend long tourist arcs in the past.

Midbook can widen ancient politics / networks once relationships are strong.

# 8. First 50-chapter implication

Do NOT:
> Ch3 changes the public national manual overnight.

Instead:

First ancient founder interaction creates:
> a lost / hidden branch that always remained outside the standardized public version.

Modern protagonist returns:
- the public manual is unchanged;
- but he now knows a source branch and its logic;
- later he discovers an obscure private note / archive already contains an ambiguous mention of an unnamed collaborator.

This feels more fate-like:
> he was not rewriting a PDF;
> he was always one of the reasons the hidden branch existed.

# 9. Second actor implication

Old history says:
> obscure healer died early.

Protagonist saves them.

Modern public record may still say:
> died / disappeared.

But reality:
> healer survived under alias / hidden location,
> creating a lineage / preserved method unknown to mainstream history.

Thus:
> no cheap textbook rewrite,
> but a new hidden asset now exists for protagonist to discover.

# 10. First true "trunk rewrite" milestone

Do not spend in Ch1–20.

Potential around:
> Ch80–150.

Protagonist intentionally tries to prevent a historically major event.

He succeeds at the immediate node.

Returns modern.

Shock:
> major event STILL occurred,
> but through a different chain.

This is the first proof of causal attractor.

Later:
> repeated cross-era layout gradually changes the event's severity / form.

Endgame:
> only after protagonist has enough cross-era infrastructure can he truly break one major attractor.

# 11. Current catastrophe integration

The future / endgame catastrophe should be:
> a trunk-level convergence event.

This prevents:
> "just go back and stop it."

Every attempt to remove one historical cause:
- reveals another;
- changes manifestation;
- may worsen another branch.

The protagonist must prepare civilization-level redundancy.

This supports:
> fate pressure + earned defiance.

# 12. Fate tone

Early feeling:
> "Some things seem to have always included me."

Mid feeling:
> "I can change people, but history is harder to move than I thought."

Late feeling:
> "The future is not fixed because of prophecy; it is fixed because too many causes all point the same way."

End:
> "To defy fate, I have to change the conditions that make fate inevitable."

This is stronger than:
> a divine prophecy says disaster must happen.

# 13. Relationship to X9 mastermind

The future civilization may have known:
> trunk-level collapse is hard to alter because local memories update.

They need an outsider memory anchor.

But they cannot simply tell protagonist:
> change event X.

Because:
- changing X may not matter;
- the attractor may route around it.

They need protagonist to:
> learn the system,
> build relationships,
> create redundancy,
> discover which conditions actually matter.

This preserves protagonist agency.

# 14. Hard rules

1. Public present does NOT visibly rewrite after every source interaction.
2. Early payoffs prefer hidden-history / private-branch / preserved-resource effects.
3. Major present crises are solved mainly by protagonist's current strength + allies.
4. Ancient layouts create leverage / options, not automatic victory.
5. Major historical events require multi-era structural changes to truly alter.
6. First obvious trunk-rewrite attempt should fail partially, proving fate pressure.

# 15. Current recommendation

Use:
> **主干锁定 + 支线可变 + 隐史最自由 + 大事件有因果吸引子**

This best balances:
- growth;
- layout;
- history interaction;
- fate;
- crisis weight;
- long-form escalation.
