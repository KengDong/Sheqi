# 1. A01｜《怪物死了，地盘还在》
## HORIZON STRONG

### Near｜Ch1–3
**Reader唯一等待：**
> 周启解决第一处怪物后，这块“战利品”能不能立刻变成一块真的能住、能用、能产生持续价值，同时也必须对里面的人负责的地盘？

必须兑现：
- 第一处可长期使用的据点；
- 收入 / 通行权 / 安全空间至少一项持续果实；
- 唐阿琴作为旧住户不自动服从，并让周启留下一个不能随便反悔的租住 / 通行 / 维修承诺。

**永久状态：**
> 周启第一次真正“拥有地方”，也第一次被地方里的人和承诺绑住。

### Near -> Mid
Near 后 Reader 自然问：
> 拿到不算本事，这块地方能不能不靠周启天天亲自救火也活下去？

唐阿琴把“拥有”变成“守承诺”；贺梁把“守住”变成维护、授权和成本。

### Mid｜Ch10–30
**唯一可命名成果：**
> **第一片老街实现最低自运转。**

可见标准：
- 既有收入能承担部分持续维护；
- 贺梁拥有明确日常调度权；
- 唐阿琴/住户拥有稳定使用边界；
- 旧通道/仓库/安全空间至少一次二次复用，证明旧地盘会改变新问题。

Reader能说：
> 周启已经不是“杀掉怪物的人”，而是“真的养活了一块地方的人”。

### Mid -> Far
一块地方能活以后，自然问题变成：
> 多块旧地盘能不能彼此供血，而不是每块都成为新的负担？

### Far｜100+
**唯一规模影子：**
> 周启能不能把多块已经有人生活、背着旧债和旧承诺的地盘连成一张城市安全 / 通行 / 经营网络，同时不让自己成为所有问题唯一接口？

规模只来自旧状态：
- 贺梁的维护体系扩大；
- 唐阿琴代表的居民议价变强；
- 许楠要求更正式的公共责任；
- 罗骁可利用旧债 / 流动性攻击连接点。

**关系传递：**
Near 唐阿琴的第一条承诺 -> Mid 住户与维修权真正分出去 -> Far 主角成功反而让居民、维修、监管拥有更大杠杆。

### AI / Newcomer
- 连载难度：MEDIUM；固定地盘与旧状态很好压缩。
- Human craft：MEDIUM-HIGH；防止人物变治理功能。
- Research tax：LOW-MEDIUM；避免法律/地产教材化。
- State compressibility：HIGH（地盘 / 通路 / 住户 / 债 / 承诺 / 权限）。

# 2. A02｜《末日先修水电》
## HORIZON STRONG

### Near｜Ch1–3
**Reader唯一等待：**
> 所有人都在抢水抢电时，林湛能不能先把第一栋楼最关键的水泵 / 应急电真正修回来，并让“今晚能用”变成“明天不会立刻又崩”？

必须兑现：
- 水与必要电力真实恢复；
- 不是技术演示，而是居民生活立刻改变；
- 孙雯介入谁先用、谁承担停机；
- 赵梁作为第二个懂技术的人出现，避免“主角科普所有人”。

**永久状态：**
> 第一套恢复系统从此成为公共资产：有人维护、有人使用、有人记得谁第一次被优先/被延后。

### Near -> Mid
修回来以后 Reader 自然问：
> 谁值班？谁维护？林湛不在时谁敢决定？

因此欲望从“修好”自然变成“持续运行”。

### Mid｜Ch10–30
**唯一可命名成果：**
> **第一栋楼连续稳定运行一周，而且不是林湛全天亲自盯着。**

可见标准：
- 水 / 电 / 医疗关键负载形成最低维护节律；
- 赵梁或新人能独立处理一部分旧系统；
- 孙雯代表居民拥有可执行的分配/轮值权；
- 顾岚的医疗边界、段成的交换活动开始建立在稳定基础设施上。

Reader能说：
> 这栋楼已经不只是幸存，而是重新开始生活。

### Mid -> Far
一栋楼稳定后，它自然拥有：
- 水；
- 维修；
- 医疗；
- 交换；
可对外换取别的东西。

Reader自然想看：
> 多个孤岛能不能接起来？

### Far｜100+
**唯一规模影子：**
> 林湛能不能让多个已恢复社区通过旧管线、维修队、交易欠账和公共服务互相连接，形成即使他不在某一栋楼也会继续运转的文明节点网络？

不靠新灾难升级。
只靠：
- 赵梁的维修能力复制；
- 孙雯式自治扩展；
- 顾岚的医疗稳定；
- 段成的交换网络；
- 旧欠账和旧分配决定累积。

**关系传递：**
Near 孙雯让技术第一次接受社会条件 -> Mid 赵梁/居民得到真实授权 -> Far 技术权与社区权力必须在多个节点间重新分配。

### AI / Newcomer
- 连载难度：EASY-MEDIUM；固定系统可稳定生场景。
- Human craft：MEDIUM；难点是公平、尊严、私人财产，不是工程术语。
- Research tax：MEDIUM but controllable；限制在少数可重复系统。
- State compressibility：VERY HIGH（设施 / 容量 / 备件 / 班组 / 分配 / 欠账）。

# 3. A04｜《冒险者公会救援队》
## HORIZON STRONG

### Near｜Ch1–3
**Reader唯一等待：**
> 方岱面对一支已经失败、已经失联的冒险队，能不能用“救援员而不是讨伐者”的决策，把至少一个本来回不来的人活着带回公会？

必须兑现：
- 一个本应死亡/失踪的人活着回来；
- 第一笔救援信用 / 报酬成立；
- 旧路线/事故信息因幸存者永久变完整；
- 凯洛或其队伍成为第一段不能清零的“被救关系”，且不自动感恩；
- 莉娅的伤员判断对行动有真实权重。

**永久状态：**
> 公会第一次留下“这支队真的从失败现场把人带回来”的职业记录，方岱与凯洛以后不能再像陌生人一样重新开始。

### Near -> Mid
Reader马上会问：
> 这是方岱个人厉害，还是“救援队”真的能成为稳定职业能力？

凯洛的名誉、莉娅的医疗边界、米拉的费用/记录都会把“再救一个人”推成“救援有没有正式位置”。

### Mid｜Ch10–30
**唯一可命名成果：**
> **公会正式救援席位成立。**

可见标准：
- 救援不再是临时怪活；
- 公会承认固定响应 / 收费 / 事故记录位置；
- 罗安能独立承担部分训练或低风险响应；
- 凯洛等旧冒险队能真实支持、反对、付费、监督这项服务。

Reader能说：
> 救援队已经成为公会生态里所有冒险者都必须考虑的正式角色。

### Mid -> Far
正式席位建立后，旧幸存者、旧地图、旧事故、训练过的人越来越多。

自然问题是：
> 救援能不能脱离方岱单点？

### Far｜100+
**唯一规模影子：**
> 方岱能不能把多年累积的旧幸存者、训练节点、路线资料和公会权利连成一张多点救援网络，让“有人能回来”成为冒险生态的一部分，而不是只靠一个英雄赶到现场？

规模来自：
- 罗安可独立带响应；
- 莉娅掌握医疗/复出边界；
- 米拉用旧事故改变制度；
- 凯洛代表的冒险者群体持续反向制衡救援规则。

**关系传递：**
Near 凯洛因被救而产生债/怨/名誉变化 -> Mid 被救关系进入费用与职业规则 -> Far 冒险者群体既依赖救援，又反对救援过度干涉自主。

### AI / Newcomer
- 连载难度：MEDIUM -> MEDIUM-HIGH。
- Human craft：HIGH（四本最高）；羞耻、恐惧、复出、自主不能写成程序化煽情。
- Research tax：MEDIUM；保持西幻救援可信，不做现实急救教材。
- State compressibility：HIGH（人员 / 伤势 / 地图 / 事故 / 资格 / 预算 / 权限）。

# 4. B10｜《灵气复苏，我开二手装备店》
## HORIZON WARNING

### Near｜Ch1–3
**Reader唯一等待：**
> 梁序能不能靠“可靠使用次数”，让第一件别人不敢碰的二手装备真正产生价值：店里赚到钱，同时一个会回来的客户因他的判断避开一次装备失效？

必须兑现：
- 第一笔旧货利润 / 租赁回报；
- 梁序因知道风险做一次会影响客户关系的选择；
- 鲁震成为可回返的真实使用者；
- 唐乔让“看见价值”与“值不值得修”出现专业分工。

**永久状态：**
> 店里留下第一笔旧货利润 + 第一段固定客户关系 + 一件拥有真实使用记录、以后还能回来的旧装备/记录。

### Near -> Mid
Near 后自然问题不是：
> 下一件神器是什么？

而是：
> 鲁震带着使用结果回来、唐乔维修、钱烈供货以后，这间店能不能不靠梁序每次重新捡漏也转起来？

### Mid｜Ch10–30
**唯一可命名成果：**
> **第一条固定装备周转闭环跑通：破店成为一支固定小队的长期装备周转站。**

可见标准：
- 鲁震小队形成持续检查/维修/租赁/回收关系；
- 至少一件旧装备完成“进店 -> 使用 -> 带新历史回来 -> 再次产生价值”；
- 唐乔拥有真实维修/排队权限；
- 收入不再完全依赖下一件新奇货。

Reader能说：
> 这家店已经从会捡漏，变成会让旧装备和旧客户不断回来。

### Mid -> Far
固定循环成立后，越来越多旧装备带着维修史、使用史和信用回来。

自然问题是：
> 这些记录能不能从“本店经验”变成市场信用？

### Far｜100+
**唯一规模影子：**
> 梁序能不能把旧装备历史、维修记录、固定战队、供货账期和客户互换关系沉淀成区域性的二手装备信用 / 回收 / 租赁网络，而这张网络不再要求每一笔交易都经过他本人？

规模只来自：
- 唐乔的维修信誉；
- 鲁震的真实使用数据；
- 林澄的客户互换网络；
- 钱烈的渠道与账期；
- 店铺多年旧记录。

**关系传递：**
Near 鲁震第一次回返 + 唐乔第一次分担判断 -> Mid 固定客户与维修端拥有议价权 -> Far 店越成功，梁序越必须接受信用属于整个关系网络，而不只属于他的能力。

### Why WARNING
链条本身不靠新 gimmick，结构 PASS。

但 Near / Mid / Far 在页面动作上仍可能被读成：
> inspect / repair / value / trade 的规模升级。

因此：
> 不再靠设计继续“救”；P0/P1 必须直接验证梁序和固定人物是否能让 Reader 忘记“这又是一笔装备生意”。

### AI / Newcomer
- 连载难度：EASY-MEDIUM；旧客户/旧装备非常适合稳定生产。
- Human craft：MEDIUM-HIGH；真正风险是人物变账本节点。
- Research tax：LOW-MEDIUM；少数装备类型即可反复复用。
- State compressibility：VERY HIGH（装备ID / 所有人史 / 维修史 / 租赁史 / 信用 / 账期 / 现金）。
