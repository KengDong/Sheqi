# Anonymous P0 Pair｜A02

Title:
> 《末日先修水电》

Premise:
> 别人抢粮抢枪时，他先抢修水泵、配电和门禁——只要一栋楼重新出水亮灯，就能让一群人真正活下来。

Below are two first-screen versions for the SAME unknown-author book.

You may prefer X, Y, both, or neither.

# Version X

十七楼的水龙头先吐出一口带铁锈味的气，随后彻底哑了。

孙雯把塑料盆倒过来，盆底只滚出三颗水珠。

“楼下储水箱还有水。”她说，“可十八层往上已经六个小时没一滴。二十三楼那个术后老人，家里连冲药的水都快没了。”

林湛没接话，拎着工具包往地下二层走。

泵房门一开，闷热和柴油味一起扑出来。两台增压泵都安静着，控制柜却还亮着一盏红灯。外面的城市停电已经一天半，这栋楼靠地下那台应急发电机吊着消防、门禁、几盏走廊灯和一部电梯。

林湛蹲下看了不到半分钟，伸手碰了碰柜门，又去看压力表。

“泵没烧。”他说。

孙雯跟在后面：“那为什么不开？”

“它在等一个已经死掉的压力信号。手动能起。”

“那就起。”

林湛没有动。他指了指墙上的负载表。

“电也不够。”

孙雯看见指针已经贴近红区，脸色沉下来。

“你要停什么？”

“电梯。”

“现在？”

“现在。”

孙雯盯着他。上午开始，整栋楼就靠这一部电梯往上送桶装水、药和行动不便的人。停了它，楼里不是少一点方便，而是立刻有人要多爬十几层。

“先送完二十三楼那趟。”她说。

“再启动泵，可能就得等发电机歇下来。”林湛把一只扳手放到地上，“油温已经高了。今晚如果它趴窝，门禁、消防控制和照明一起没。”

“那你保证泵一开就有水？”

“不能。”林湛说，“我只能保证现在是最值得试的时候。”

孙雯骂了句很轻的脏话，转身按住对讲机。

“三分钟。电梯停运。谁还在里面，先出来。”

楼上立刻有人问为什么。

她没解释，只回了一句：“想要水，就先别坐电梯。”

林湛切掉电梯负载，把增压泵改到手动，先点了一下启动。

电机闷响一声。

整间泵房的灯暗了半秒。

孙雯下意识抬头。

发电机没有熄火。

林湛等了两秒，才把泵真正压上去。压力表的指针从零慢慢抬起，先到一格，又爬过第二格。管道深处传来一阵很长的震动，像一头饿了很久的东西终于吞下第一口水。

“七楼，开一下水龙头。”林湛对着对讲机说。

没人回答。

三秒后，对讲机里炸出一个女人的声音。

“有了！等一下——黄的，先是黄的……现在清了！”

泵房外有人笑了一声。

孙雯没有笑。她低头看着地下储水箱的液位尺。

“还剩多少？”

林湛顺着她的目光看过去。

“按现在这个量，如果所有人听见来水就一起开，两个小时都撑不到。”

楼上的消息已经传开了。对讲机里开始同时响起声音——十九楼要接水，二十六楼问什么时候轮到，十一楼说家里有两个孩子，三楼有人抱怨自己已经提了四趟桶，凭什么还要等。

孙雯慢慢把对讲机从耳边拿开。

“你把水修回来了。”

“只是把泵修回来了。”林湛说。

“有区别？”

林湛看着仍在往上爬的压力表。

“很大。泵可以按按钮，水不行。”

孙雯沉默两秒，从墙边撕下一块快递纸箱，翻到背面，又摸出笔。

“行。”她把纸箱按在控制柜上，“那先定第一轮。老人、病人、有婴幼儿的先？”

林湛却看向那部已经停掉的电梯。

“还得有人值泵。没人盯负载，谁都别想开第二轮。”

孙雯笔尖停住。

泵房里第一次真正有了水流声。

而门外，已经有人在问——

第一桶水，凭什么不是给我？

# Version Y

城市停电第四天，十八楼已经有人拿矿泉水瓶去接消防管里的锈水。街口最后一家超市昨晚被撬空，手机信号也只剩下偶尔跳出来的一格。

林湛把阀门重新拧死时，身后立刻有人骂了出来。

“你家还有水是不是？”

“那是消防水。”林湛没回头，“真起火的时候，你拿什么灭？”

“不起火我们先渴死了！”

地下泵房又闷又热。应急灯把一张张脸照得发青。孙雯从人群里挤进来，把登记本卷成筒，敲了敲门框。

“别吵。”她看向林湛，“你说能恢复生活用水，到底还差什么？”

林湛指了指墙上的配电柜。

“电。”

“楼里不是有发电机？”

“现在带着一部电梯、走廊应急灯，还有一楼给大家充手机的插排。泵一启动，电梯还挂着，整个楼一起跳。”

孙雯皱起眉。

这不是一道‘懂不懂技术’的题。

电梯现在每小时开十分钟，专门把桶装水送上楼，也给腿脚不便的人上下。昨天十七楼一个老太太，就是靠那十分钟去一楼换药。

“停多久？”孙雯问。

“先停二十分钟。充电也拔掉。”

旁边立刻有人说：“手机没电，外面什么消息都收不到。”

另一个人更急：“那水谁往楼上送？”

林湛蹲下，把泵前那只压力表擦干净。指针趴在零上。

“所以才修它。”

他没说‘相信我’。这几天最没用的就是这三个字。

他只抬头对孙雯说：“二十分钟，发电机只给泵和应急灯。如果起不来，今天这一轮柴油算我浪费的。要是起来了，先别让一到六楼接水。”

孙雯愣了一下。

“为什么？”

“低楼层一开，压力全泄在下面。上面还是一滴没有。”

“下面一百多人也等着水。”

“他们至少还能下楼。”林湛说，“十八楼的人已经搬了三天。”

泵房外一下安静了。

这回连刚才骂得最凶的人都没接话。

孙雯盯着他看了两秒：“先高层，就一定公平？”

“不一定。”

林湛站起来，手已经搭上电梯回路的开关。

“但继续平均等，楼上一定先撑不住。”

他把开关压了下去。

整栋楼像被掐掉一口气。远处电梯运行的嗡鸣停了，一楼随后传来一片不满的叫声。

林湛没有等那些声音平息。

他合上水泵回路。

第一下，发电机猛地一沉。

灯闪了两次。

第二下，泵体里传出一声闷响，像什么东西在黑暗里翻了个身。

压力表的指针，从零刻度抖着爬了起来。

泵房里没人说话。

三秒后，对讲机突然炸响。

“六楼！六楼有水了！”

外面瞬间欢呼。

孙雯也松了口气，刚要转身，林湛却先拧上了低区总阀。

对讲机里的欢呼戛然而止。

“六楼怎么又没了？”

“谁关的？”

“刚来水你们就关？！”

孙雯看着他的手：“现在后悔还来得及。”

林湛没松。

压力表继续往上爬。

一格。

又一格。

楼上的水还没来，楼下的骂声已经先顺着楼梯灌进了泵房。
