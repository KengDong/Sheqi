# A02《末日先修水电》｜P0 Native V2

## First Screen

城市停电第四天，十八楼已经有人拿矿泉水瓶去接消防管里的锈水。街口最后一家超市昨晚被撬空，手机信号也只剩下偶尔跳出来的一格。

林湛把阀门重新拧死时，身后立刻有人骂了出来。

“你家还有水是不是？”

“那是消防水。”林湛没回头，“真起火的时候，你拿什么灭？”

“不起火我们先渴死了！”

地下泵房又闷又热。应急灯把一张张脸照得发青。孙雯从人群里挤进来，把登记本卷成筒，敲了敲门框。

“别吵。”她看向林湛，“你说能恢复生活用水，到底还差什么？”

林湛指了指墙上的配电柜。

“电。”

“楼里不是有发电机？”

“现在带着一部电梯、走廊应急灯，还有一楼给大家充手机的插排。泵一启动，电梯还挂着，整个楼一起跳。”

孙雯皱起眉。

这不是一道‘懂不懂技术’的题。

电梯现在每小时开十分钟，专门把桶装水送上楼，也给腿脚不便的人上下。昨天十七楼一个老太太，就是靠那十分钟去一楼换药。

“停多久？”孙雯问。

“先停二十分钟。充电也拔掉。”

旁边立刻有人说：“手机没电，外面什么消息都收不到。”

另一个人更急：“那水谁往楼上送？”

林湛蹲下，把泵前那只压力表擦干净。指针趴在零上。

“所以才修它。”

他没说‘相信我’。这几天最没用的就是这三个字。

他只抬头对孙雯说：“二十分钟，发电机只给泵和应急灯。如果起不来，今天这一轮柴油算我浪费的。要是起来了，先别让一到六楼接水。”

孙雯愣了一下。

“为什么？”

“低楼层一开，压力全泄在下面。上面还是一滴没有。”

“下面一百多人也等着水。”

“他们至少还能下楼。”林湛说，“十八楼的人已经搬了三天。”

泵房外一下安静了。

这回连刚才骂得最凶的人都没接话。

孙雯盯着他看了两秒：“先高层，就一定公平？”

“不一定。”

林湛站起来，手已经搭上电梯回路的开关。

“但继续平均等，楼上一定先撑不住。”

他把开关压了下去。

整栋楼像被掐掉一口气。远处电梯运行的嗡鸣停了，一楼随后传来一片不满的叫声。

林湛没有等那些声音平息。

他合上水泵回路。

第一下，发电机猛地一沉。

灯闪了两次。

第二下，泵体里传出一声闷响，像什么东西在黑暗里翻了个身。

压力表的指针，从零刻度抖着爬了起来。

泵房里没人说话。

三秒后，对讲机突然炸响。

“六楼！六楼有水了！”

外面瞬间欢呼。

孙雯也松了口气，刚要转身，林湛却先拧上了低区总阀。

对讲机里的欢呼戛然而止。

“六楼怎么又没了？”

“谁关的？”

“刚来水你们就关？！”

孙雯看着他的手：“现在后悔还来得及。”

林湛没松。

压力表继续往上爬。

一格。

又一格。

楼上的水还没来，楼下的骂声已经先顺着楼梯灌进了泵房。

## Selfcheck

- First Screen 正文约 1018 汉字，处于 800–1500 汉字要求内。
- Physical lack 已可见：断水第四天、居民试图取消防锈水、外部物资与通信同时恶化。
- Premise 已在页内启动：林湛不是“计划以后修”，而是实际重分配应急负载并让生活水泵重新起压。
- Technical action 有直接人类后果：为水泵停电梯、停充电；为高层建立压力又主动切断低层刚恢复的水。
- Competing priority 合理存在：孙雯关心电梯、通信、低层百余人的即时需求，并非为了让主角显得聪明而反对。
- 林湛做出有成本的选择：承担柴油浪费风险与居民即时不满，不把技术正确包装成天然的社会正确。
- 未新增核心机制、未引入新的重大常驻角色、未执行 Mid Horizon、未完成 Ch1；屏末仍悬着“高层能否真正来水 / 这套分配是否站得住”的下一屏欲望。
