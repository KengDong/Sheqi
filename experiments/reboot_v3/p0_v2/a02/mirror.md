# A02《末日先修水电》P0 Commercial-Mirror V2

## First Screen

十七楼的水龙头先吐出一口带铁锈味的气，随后彻底哑了。

孙雯把塑料盆倒过来，盆底只滚出三颗水珠。

“楼下储水箱还有水。”她说，“可十八层往上已经六个小时没一滴。二十三楼那个术后老人，家里连冲药的水都快没了。”

林湛没接话，拎着工具包往地下二层走。

泵房门一开，闷热和柴油味一起扑出来。两台增压泵都安静着，控制柜却还亮着一盏红灯。外面的城市停电已经一天半，这栋楼靠地下那台应急发电机吊着消防、门禁、几盏走廊灯和一部电梯。

林湛蹲下看了不到半分钟，伸手碰了碰柜门，又去看压力表。

“泵没烧。”他说。

孙雯跟在后面：“那为什么不开？”

“它在等一个已经死掉的压力信号。手动能起。”

“那就起。”

林湛没有动。他指了指墙上的负载表。

“电也不够。”

孙雯看见指针已经贴近红区，脸色沉下来。

“你要停什么？”

“电梯。”

“现在？”

“现在。”

孙雯盯着他。上午开始，整栋楼就靠这一部电梯往上送桶装水、药和行动不便的人。停了它，楼里不是少一点方便，而是立刻有人要多爬十几层。

“先送完二十三楼那趟。”她说。

“再启动泵，可能就得等发电机歇下来。”林湛把一只扳手放到地上，“油温已经高了。今晚如果它趴窝，门禁、消防控制和照明一起没。”

“那你保证泵一开就有水？”

“不能。”林湛说，“我只能保证现在是最值得试的时候。”

孙雯骂了句很轻的脏话，转身按住对讲机。

“三分钟。电梯停运。谁还在里面，先出来。”

楼上立刻有人问为什么。

她没解释，只回了一句：“想要水，就先别坐电梯。”

林湛切掉电梯负载，把增压泵改到手动，先点了一下启动。

电机闷响一声。

整间泵房的灯暗了半秒。

孙雯下意识抬头。

发电机没有熄火。

林湛等了两秒，才把泵真正压上去。压力表的指针从零慢慢抬起，先到一格，又爬过第二格。管道深处传来一阵很长的震动，像一头饿了很久的东西终于吞下第一口水。

“七楼，开一下水龙头。”林湛对着对讲机说。

没人回答。

三秒后，对讲机里炸出一个女人的声音。

“有了！等一下——黄的，先是黄的……现在清了！”

泵房外有人笑了一声。

孙雯没有笑。她低头看着地下储水箱的液位尺。

“还剩多少？”

林湛顺着她的目光看过去。

“按现在这个量，如果所有人听见来水就一起开，两个小时都撑不到。”

楼上的消息已经传开了。对讲机里开始同时响起声音——十九楼要接水，二十六楼问什么时候轮到，十一楼说家里有两个孩子，三楼有人抱怨自己已经提了四趟桶，凭什么还要等。

孙雯慢慢把对讲机从耳边拿开。

“你把水修回来了。”

“只是把泵修回来了。”林湛说。

“有区别？”

林湛看着仍在往上爬的压力表。

“很大。泵可以按按钮，水不行。”

孙雯沉默两秒，从墙边撕下一块快递纸箱，翻到背面，又摸出笔。

“行。”她把纸箱按在控制柜上，“那先定第一轮。老人、病人、有婴幼儿的先？”

林湛却看向那部已经停掉的电梯。

“还得有人值泵。没人盯负载，谁都别想开第二轮。”

孙雯笔尖停住。

泵房里第一次真正有了水流声。

而门外，已经有人在问——

第一桶水，凭什么不是给我？
