# R1｜Future Holdings

Frozen Premium:
> 过去穷时出售未来本人；今天越成功，旧未来越升值、越侵入现在人生。

Known stress signal:
- Existing engine has strong compounding life and no natural short-run exhaustion.
- Commercial deficit is not story supply; it is visible positive settlement and a clearer long-growth axis.

## R1-M1｜可缺席帝国 / The Absence-Proof Empire

### 1. Mother Market
都市事业成长 / 创业组织成长 / 资产复利。

### 2. One-Line Hook
沈峥过去卖掉了若干“未来本人必须在场”的日期；他决定把事业做成一个即使本人被旧合同带走也不会停摆的帝国——每消灭一个“必须沈峥亲自在”的事业瓶颈，他就永久拿回一块现实自由，但越成功，他本人在家庭与公共身份上的在场反而越贵。

### 3. Protagonist Fantasy
Reader陪主角完成：
个人关键员工 → 有可信代理人 → 独立团队 → 可脱离本人运转的公司 → 多业务资产。
爽点不是回购所有合同，而是：
> 别人还能控制我的身体在哪，但不能再控制我的事业结果。

### 4. 5–15 Chapter Fruit
每个小周期至少稳定结算两项：
- 消灭一个“本人不在就会失败”的事业单点；
- 新增永久资产：代理人、团队、流程、客户关系、股权、现金流、品牌信用之一；
- 某个旧持仓对事业的真实杀伤力永久下降；
- 同时凸显一件仍不能代理的人生：伴侣、孩子、病床、葬礼、承诺。

重复果实：
> 又一块事业脱离本人肉身依赖；又一件真正只能本人承担的人生被照亮。

### 5. 20-Chapter Ledger
- 1个可脱离沈峥全天候运转的核心业务；
- 2—3名有独立决策权的长期角色；
- 1笔持续现金流或股权资产；
- 至少1次“旧合同日撞上事业节点，但事业没有被夺走”的硬结算；
- 至少1个无法被组织替代的私人未来日继续作为主债；
- “可自主时间”通过真实组织能力增加。

### 6. 100-Chapter Escalator
欲望升级：
- 别让一次缺席毁掉项目；
- 别让任何单点依赖绑住团队；
- 建成长期不依赖本人在线的公司 / 资产群；
- 当事业越来越可代理，主角本人出现反而变成更稀缺的身份信号；
- 最终追问：事业可以交给团队，那唯一不可复制的本人要留给谁？

### 7. 2M-Character Runway
不靠新买家：
- 组织规模持续复利；
- 去单点依赖能力持续增强；
- 财富 / 股权 / 现金流增长；
- 合伙人形成独立利益；
- 同一批旧持仓随身份变化反复重新定价；
- 家庭持续追问“事业能代理，爱能不能代理”；
- 本人在场从劳动价值升级为象征与亲密价值。

旧合同负责施压与重估，不负责一集一个新故事。

### 8. Three Must-See Scenes
1. 最重要发布撞上已售日；沈峥被迫离场，自己搭出的团队第一次在没有他的情况下赢。
2. 关键旧买家为保护未来持仓价值主动替沈峥挡事业风险；沈峥接受帮助，却把这次帮助转化成“去本人依赖”的组织资本。
3. 全行业都等“沈峥本人”的公开节点，事业端已完全不需要他；同一天家庭只要那个无法被任何代理人代替的真人。

### 9. Replacement Test
普通创业文没有：
- 每次组织升级都在直接削弱“未来本人在场权”的事业勒索；
- 同时成功又让旧持仓在象征 / 亲密层面升值；
- “事业自由增加、私人本人更稀缺”这条反向曲线。

### 10. Commercial Kill Risk
- 退化成普通创业文；
- 代理人强到主角失去主角性；
- 为制造冲突又新增买家 / 新日期。
硬防线：每次事业成长都必须改变旧持仓真实杠杆；每次可代理化都必须同步凸显一件不可代理的人生。

### 11. What Original Premium Is Preserved
完整保留：
> 过去低价买到的是未来版本本人；沈峥越成功，旧合同越值钱。

### 12. What Commercial Engine Changed
从“关系 / 伦理复利”为主，改成：
> 可视组织资产复利 + 去个人依赖成长 + 不可代理人生反向升值。

## R1-M2｜越贵越自由 / Appreciation as Leverage

### 1. Mother Market
都市职场 / 商业上升 / 身份跃迁 / 人脉资源复利。

### 2. One-Line Hook
沈峥不再为了让旧持仓贬值而活得更差；他反而拼命让未来的自己越来越贵——因为当旧买家持有一项持续升值的“未来本人资产”时，他们也开始怕他受伤、失业、失信、被毁掉，而沈峥要把这种保护欲变成自己的机会与谈判权。

### 3. Protagonist Fantasy
被合同支配的普通人 → 有人维护他的价值 → 关键持有人必须长期协商 → 能利用持有人利益分歧换取资源 / 保护 / 时间 → 最终仍不按“持有人收益最大化”去活。
爽点：
> 同一份合同既是锁链，也是别人不得不保护我的长期多头仓位。

### 4. 5–15 Chapter Fruit
- 一次可见身份跃迁：职位、收入、行业信用、影响力、关键资源之一；
- 一个旧持有人因升值被迫给出真实保护 / 资源 / 让步；
- 一项执行边界被双方重新协商得更可控；
- 一段长期关系永久重估。
重复回报：
> “我变贵了”会立即改变别人对我的行为。

### 5. 20-Chapter Ledger
- 职位 / 收入 / 行业信用明确跃迁；
- 1—2个能调动的资源型长期关系；
- 至少一份旧持仓从“单向命令”变成“必须谈判”；
- 至少一个关键未来日获得更清楚的自主边界；
- 证明不靠自毁、不靠一次性全额回购，也能扩大未来控制权。

### 6. 100-Chapter Escalator
- 让一个买家不能随意安排自己；
- 让几个关键持有人都必须考虑沈峥长期价值；
- 身份进入行业 / 公共视野后，旧持仓影响公司、家庭、媒体与合作方；
- 主角开始反向选择哪些“保护”可以接受、哪些其实在塑造他；
- 最终问题：当所有人都希望他继续升值，他能否不为任何持有人收益最大化而活？

### 7. 2M-Character Runway
- 职位 / 财富 / 声誉 / 公共身份持续上升；
- 同一批关键持有人因收益目标不同稳定博弈；
- 保护与塑造边界持续变化；
- 伴侣 / 家庭持续追问“今天的选择到底是谁的”；
- 每次身份跃迁都重新定义旧持仓价值和风险；
- 强制权逐步减少，关系债 / 恩情债 / 共同历史增加。

### 8. Three Must-See Scenes
1. 职业声誉危机中，最先保住沈峥名声的不是亲友，而是持有他多年后一天的旧买家。
2. 一次重大晋升让某份旧持仓暴涨；沈峥没有拒绝晋升，反而用“你比我更怕我掉价”逼持有人重谈边界。
3. 买家依法拥有“本人必须在场”，却发现这从不等于“本人意志所有权”；沈峥完全履约却做出不利于持有人利益、属于自己的公开选择。

### 9. Replacement Test
普通职场文的贵人帮助只是资源爽点；这里每一次帮助都同时是资产保值，每一次升职都同时是锁链升值与谈判权升值。

### 10. Commercial Kill Risk
- 变成“债主都是贵人”的软饭资源文；
- 合同谈判过多，像法律说明书；
- 身价上涨只有口头估值。
硬防线：每次身份升级必须落到账面职位 / 钱 / 资源 / 未来日边界，同时增加一层塑造欲或关系债。

### 11. What Original Premium Is Preserved
完整保留并强化：
> 今天越成功，过去买走的未来本人越值钱。

### 12. What Commercial Engine Changed
从“成功制造更贵旧债”，改成：
> 升值 → 持有人保护与约束同时增强 → 主角获得资源与议价 → 再升值。

# R3｜Borrowed Tribulations

Frozen Premium:
> 修仙 / 渡劫；风险不能消失，只能改变承担者；普通人身体保存强者成长的外部化成本历史。

Known stress signal:
- Reservoir around Seed 34 begins to slide toward “another source tribulation”.
- Mutation must make own cultivation the main dish and forbid new-source tribulations as runway fuel.

## R3-M1｜劫痕道途 / Scar-Cultivation Path

### 1. Mother Market
东方玄幻 / 修仙 / 炼体 / 功法演化 / 境界成长。

### 2. One-Line Hook
旧劫成熟时，如果周野不再把风险转走，而是在自己的突破中真正承受、理解并走完它，身体会留下可重复调用的“劫痕”——别人外包给他的成长成本，终于能被炼成只有他拥有的修行结构，但每多一道劫痕，他未来的混合天劫也更复杂。

### 3. Protagonist Fantasy
“替别人扛劫的耗材” → 能识别和稳定旧劫 → 每解决一段成本就永久多一项能力 / 抗性 / 运转路径 → 多道劫痕形成独有功法 → 自己的突破不再模仿任何强者。
核心爽感：
> 强者当年丢掉的代价，最后全长在我身上，变成我自己的本事。

### 4. 5–15 Chapter Fruit
每周期必须落账：
- 一段既有旧劫被真正承受 / 稳定；
- 一个永久劫痕资产：抗性、感知、运转路径、爆发方式、身体结构之一；
- 明确修为推进；
- 一个永久代价：旧伤加深、身体冲突、触发变敏感、下一次混合劫更难之一。
禁止只得到历史真相。

### 5. 20-Chapter Ledger
- 完成一次真正属于周野的境界推进；
- 2—3道有明确用途且互相存在冲突的永久劫痕；
- 一张“身体风险结构”而不是“历史人物名单”；
- 一项只有周野能复现的战斗 / 生存 / 渡劫手段；
- 明确知道继续变强会让哪些既有劫痕组合更危险。

### 6. 100-Chapter Escalator
- 先活下一块旧风险；
- 让劫痕为自己的突破服务；
- 把互相冲突的劫痕组织成完整修行路径；
- 开始主动选择突破方式；
- 最后面对：当独道越来越强，他是否还能坚持力量成本由自己承担？

### 7. 2M-Character Runway
不新增来源劫：
- 有限既有劫痕在不同境界产生新组合；
- 同一劫痕从抗伤 → 运功 → 战斗 → 突破底层结构持续升级；
- 周野自己的正常天劫逐境出现，与旧劫痕组合；
- 劫痕兼容 / 冲突形成长期功法构筑；
- 修为、战力、资源效率、社会地位自然增长；
- 老承受者、家人、年轻卖家围绕“你变强是否值得继续伤自己”持续复利。

### 8. Three Must-See Scenes
1. 传奇强者独有劫象在周野体内成熟；所有人以为只是旧伤，他第一次把它稳定成自己的永久能力。
2. 两道互相排斥的旧劫痕被同时调用，形成任何“干净修士”都不可能练出的混合手段。
3. 周野真正渡自己的天劫时，所有旧成本都在，但他第一次既不替别人受，也不让别人替自己受，而是用自己的劫痕结构完成突破。

### 9. Replacement Test
不是“吞伤害变强”：
- 每一道力量都对应某位强者外部化的真实成本；
- 力量与历史责任是同一枚硬币；
- 独道来自“别人不愿承担的成长代价”；
- 来源永远洗不掉。

### 10. Commercial Kill Risk
- 退化成技能图鉴；
- 为了新能力不断新增来源劫；
- 代价口头化。
硬防线：冻结来源库；后续优先复用 / 组合既有劫痕；每项永久能力绑定永久身体成本。

### 11. What Original Premium Is Preserved
风险不消失；强者安全成长与普通承受者身体代价同因果；来源指纹永久保留；周野身体仍是活的强者成本档案。

### 12. What Commercial Engine Changed
从：
> 自己升级 → 旧风险醒 → 追索历史
改成：
> 自己升级 → 既有风险成熟 → 承受并炼成永久劫痕 → 获得修为 / 战力资产 → 下一境组合成本更高。

## R3-M2｜劫债杠杆 / Tribulation Leverage

### 1. Mother Market
东方玄幻 / 快速成长 / 高风险高回报修行 / 资源策略突破。

### 2. One-Line Hook
旧劫本会在对应境界被动成熟；周野学会主动调整修炼状态，把某一段“未来迟早要还的劫债”提前拉到今天，以承受它换取一次更快、更深的突破——他修得越快，未来安全余量越少。

### 3. Protagonist Fantasy
被动等债到期 → 看懂既有劫债成熟条件 → 主动选择何时提前触发 → 用提前承受换修为 / 时间 / 资源优势 → 最终证明可以高速变强却不把账单卖给下一个穷人。
核心爽感：
> 别人把我变成负债表，我把负债表变成修炼杠杆。

### 4. 5–15 Chapter Fruit
每周期同时落账：
- 主动提前成熟一段既有风险，或主动推迟另一段；
- 境界推进、修炼时间缩短、资源消耗下降、战斗窗口提升之一；
- “安全余量”永久恶化一项；
- 家人 / 老承受者 / 年轻卖家围绕这种成长方式发生现实冲突。
果实必须是：
> 我更强了，而且账单真的更近了。

### 5. 20-Chapter Ledger
- 至少一次主动完成的自我突破；
- 一套个人劫债优先级；
- 明确领先同阶段修士的时间 / 资源优势；
- 一个过度使用杠杆留下的永久身体缺口；
- 至少一次本可以把风险卖给别人、但主动拒绝的硬选择。

### 6. 100-Chapter Escalator
- 不让旧劫随机决定人生；
- 主动安排劫债争取突破窗口；
- 用风险时序形成成长速度优势；
- 速度优势诱惑他持续拿未来安全换现在境界；
- 当终于有财富 / 地位把风险转出去时，他还会不会继续自己还？

### 7. 2M-Character Runway
- 既有风险作为有限初始负债池，不再新增来源；
- 每个新境界都有周野自己的正常修炼风险与天劫；
- 旧劫只改变自有突破的时序、难度、组合；
- 钱、药、器物、盟友只能改善承受能力，不能抹掉风险；
- 社会地位从廉价承受者 → 高风险修士 → 有选择权的人；
- 长篇主曲线是修为资产增长 vs 风险负债恶化。

### 8. Three Must-See Scenes
1. 别人断定周野几年不能突破，他主动把一段迟早到期的旧劫拉来，当场用一次高风险结算换境界跃迁。
2. 家人第一次看清他的“修得快”不是天赋，而是在不断搬运未来恢复期和死亡风险。
3. 周野后来有钱、有地位，也有人愿意合法替他承受；最快突破方案重新变成“把债卖出去”。

### 9. Replacement Test
不是普通“燃寿换战力”：
- 烧掉的是别人过去转给他的具体成长成本；
- 来源仍保留但不再靠来源人物供给剧情；
- 高速修行来自对同一负债的时序操作；
- 变富后“继续自己还还是重新外包”会反咬成长爽点。

### 10. Commercial Kill Risk
- 退化成纯数值负债表；
- 每次机械“再赌一次”；
- 风险长期不兑现。
硬防线：每次加杠杆留下永久身体 / 关系 / 资源后果；必须存在主动减杠杆、恢复、错过突破的周期。

### 11. What Original Premium Is Preserved
风险只能转移不能消失；今天的负债来自强者过去外部化的成本；来源可追溯；当周野有能力把风险再卖给穷人时，核心伦理反噬仍在。

### 12. What Commercial Engine Changed
从“风险被动成熟、历史醒来”，改成：
> 主角主动安排既有风险成熟时序，以负债换修为速度与资源效率；每周期同时增长修为资产与风险负债。

# R8｜Missing Day List

Frozen Premium:
> 上榜日人人看得见你，却无法把你对应回原身份；身份系统同步失效。

Known stress signal:
- Existing relationship / social compounding is strong.
- Biggest danger is sliding into “today another missing-day job”.
- Every missing day must leave permanent settlement.

## R8-M1｜无身份资产 / Stateless Assets

### 1. Mother Market
都市异常 / 规则生存 / 据点与组织成长 / 资源积累。

### 2. One-Line Hook
主角开始专门积累“无需任何系统认出我是谁也能使用”的永久资产——现金、钥匙、实体据点、预先协议、可信伙伴、纸面流程、可脱离单一身份运转的业务——直到拥有一套不会随身份失效而清零的第二基础设施。

### 3. Protagonist Fantasy
第一次上榜连门都进不了 → 有应急包 / 现金 / 物理钥匙 → 有长期互保伙伴 → 固定据点与稳定收入 → 身份失效时仍能工作的团队 → 普通机构反过来借用他的连续性能力。
核心爽感：
> 规则每次都拿走我的身份，但拿不走我已经建好的东西。

### 4. 5–15 Chapter Fruit
每周期永久新增至少一项：
- 物理资产：据点、钥匙、现金储备、设备；
- 关系资产：互认协议、可信伙伴、家庭安全协议；
- 业务资产：稳定收入、固定合作、流程、品牌信用；
- 行动资产：不依赖数字身份的可复用能力。
并永久改变普通日的职位、收入、住房、关系边界、职业路径之一。
禁止“一单做完赚一笔，下次重置”。

### 5. 20-Chapter Ledger
- 1个身份失效时仍可使用的固定据点；
- 1套家庭 / 伴侣可执行但不过度程序化的互认协议；
- 1条不依赖单次客户的持续收入线；
- 2—3个长期角色形成明确分工和利益；
- 一笔专门用于失踪日的长期资源储备；
- 普通职业 / 社会身份已有不可逆变化。

### 6. 100-Chapter Escalator
- 先解决上榜时的生存；
- 让家庭和工作不再每次从零应急；
- 让几个人的连续性网络自运转；
- 从保护自己人升级为能承受更大身份失效范围的基础设施；
- 当无身份网络比普通系统更可靠时，主角到底还想不想完全回到正常生活？

### 7. 2M-Character Runway
- 据点、现金流、设备、流程、伙伴、覆盖持续复利；
- 伴侣 / 父亲 / 自由女人 / 同行围绕“治理失踪日还是保留自由”持续冲突；
- 普通日职业与无身份事业双轨；
- 组织越可靠，越可能侵蚀失踪日本来的自由；
- 基础设施从个人应急 → 家庭 → 团队 → 社区级连续性。
名单机制无需解释。

### 8. Three Must-See Scenes
1. 所有数字权限失效，但一点点积累的实体钥匙、现金、据点与协议第一次完整接管一天。
2. 伴侣完全认不出他，却按长期最低安全协议让这个陌生人进入共同生活空间。
3. 一次更大范围身份失效使普通数字流程停摆，主角的小型无身份网络反而持续工作，异常职业第一次变成真实社会地位。

### 9. Replacement Test
普通末日囤货 / 据点文没有：
- 敌人是“社会拒绝承认你是你”；
- 所有资产都必须专门适配身份不可用；
- 最亲近的人看得见主角却不能识别他；
- 组织成功持续触碰“失踪日是自由还是应该被治理”。

### 10. Commercial Kill Risk
- 变成失踪者公会接任务；
- 新客户 / 委托取代资产成长；
- 组织吞掉亲密Premium；
- 新技术轻易恢复身份。
硬防线：主要结算单位是永久资产与长期角色；任何基础设施只能绕开身份依赖，不能修复识别断裂。

### 11. What Original Premium Is Preserved
人可见；熟人无法对应回身份；制度身份同步失效；最亲近的人仍需面对“眼前是陌生人，但我是否选择相信他”。

### 12. What Commercial Engine Changed
从“失踪日行动 / 关系冲击”为主，改成：
> 每次失踪日永久留下资产 / 协议 / 组织能力；Case只做压力测试，基础设施复利才是主食。

## R8-M2｜世界忘记，我记得 / Memory Capital

### 1. Mother Market
规则悬疑 / 都市异常 / 信息差成长 / 职场社会博弈。

### 2. One-Line Hook
失踪日结束后，别人对那天的经历记忆极其模糊，主角却完整记得；他开始把这种不对称从痛苦秘密变成可积累的信息资本——长期看见同一批人、同一家公司、同一段关系在“认不出我时”会做出什么真实选择。

### 3. Protagonist Fantasy
唯一记得的人 → 最难被话术欺骗的人 → 能看见公开身份与陌生人状态差异的人 → 掌握固定组织真实运行方式 → 用信息优势改善职业、收入、联盟、风控 → 最终拥有力量同时建立不滥用记忆的边界。
核心爽感：
> 世界每次遗忘，都给我留下只有我拥有的长期地图。

### 4. 5–15 Chapter Fruit
每周期双结算：
A. 信息资产：一个经过重复验证的长期事实 / 行为模式 / 关系真相 / 组织漏洞；
B. 普通日落账：职位变化、收入改善、提前避险、联盟形成、关系边界改变、证据保存、决策优势之一。
同时留下代价：
- 使用信息制造信任债；
- 不使用可能承担现实损失。
禁止只结算“又知道一个秘密”。

### 5. 20-Chapter Ledger
- 一套可核验而非纯脑补的个人真相账本 / 证据库；
- 对2—3个固定核心人物的重复行为模式认识；
- 对一个固定组织 / 职场的真实运行图；
- 一次利用信息差完成的职位 / 收入 / 资源跃迁；
- 与伴侣明确“哪些失踪日记忆可使用、哪些应尊重遗忘”的边界；
- 至少一条因使用或隐瞒记忆永久改变的关系。

### 6. 100-Chapter Escalator
- 先搞清昨天发生什么；
- 用反复积累的真相避免工作与关系反复受伤；
- 看见组织在身份真空下真正依赖谁、谁推责、谁救人；
- 从单点秘密变成行为模式与机构预测能力；
- 当主角可以持续靠“别人忘记、我记得”获利，他会不会反而开始期待自己上榜？

### 7. 2M-Character Runway
- 同一批核心人物的普通日 / 失踪日反应持续叠加；
- 同一家公司 / 家庭 / 社区的身份真空运行规律越来越完整；
- 信息资产转化为职位、收入、联盟、风控、公共地位；
- 伴侣持续质疑“你是不是拥有一个连我自己都没有的我”；
- 自由女人持续挑战“为什么一定把失踪日真相带回普通日审判”；
- 信息图谱越强，主角越难拥有无负担的亲密关系。
靠固定人物与机构深化，不靠每天换秘密对象。

### 8. Three Must-See Scenes
1. 伴侣认不出主角时，对陌生人说出次日自己几乎不记得的真话；主角必须决定完整记忆是权利、负担还是越界。
2. 原单位上司在失踪日把主角当陌生人，暴露团队真实权力结构；主角次日无法解释信息来源，却据此完成职业位置反转。
3. 同一批角色经历多次失踪日后，主角发现“他们忘的是事件，不是行为倾向”；他用长期模式提前阻止组织级崩盘，也因此暴露自己掌握了太多别人不记得的历史。

### 9. Replacement Test
普通读心 / 侦探文没有：
- 主角没有实时读心，只看到“社会识别断裂时的真实选择”；
- 信息价值来自他是唯一稳定记忆者；
- 最强场面仍是熟人面对他时把他当陌生人；
- 每条信息优势都携带亲密伦理：我知道一个你自己已经不记得的你。

### 10. Commercial Kill Risk
- 黑mail / secret-of-the-week；
- 主角变全知挂；
- 只积累信息、不积累现实资产；
- 悬疑被廉价引向幕后控制者。
硬防线：重点观察固定人物与固定机构；信息必须重复验证；每5—15章必须兑换成职位 / 钱 / 联盟 / 风控 / 关系变化。

### 11. What Original Premium Is Preserved
完整保留：
> 人仍在眼前，但别人无法把他识别成原来的那个人；主角完整记得，非失踪者记忆模糊。

### 12. What Commercial Engine Changed
从“一次性行动自由 + 关系冲击”，改成：
> 遗忘 → 记忆资本 → 现实上升 / 关系代价 → 下一次观察更深。
