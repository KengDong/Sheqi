## Frozen Premium

> 过去穷时卖掉若干“未来本人必须在场”的日期；今天越成功，旧未来越升值、越侵入现在人生。主角不靠买回全部合同，而是把事业做成即使本人被旧合同带走也不会停摆的帝国。事业越可代理，真正只能“本人在场”的家庭、承诺与公共身份反而越稀缺。

## Situation Seeds

### S01｜第一次被强制缺席，项目没有死
- **Situation：** 既有旧合同撞上核心客户交付日，沈峥必须离开现场。
- **Who wants what：** 沈峥要项目按期落地；客户要“老板本人负责”；副手要第一次获得真实决策权。
- **Collision：** 沈峥留下的流程与授权足以运行，但客户把“本人不在”理解成失信，副手必须在没有老板背书时做高风险取舍。
- **Why only this book：** “本人被合法拿走”直接把创业中的单点依赖变成可见生死题。
- **Reader reward：** status / relationship / reversal。
- **Permanent residue：** 副手获得一块不可收回的决策权；客户关系从“认老板”转向“认团队”。

### S02｜为防下一次缺席，主动拆掉自己的权力
- **Situation：** 沈峥发现三个审批都只能由自己签。
- **Who wants what：** 他要消灭单点；老员工要保住熟悉流程；财务负责人担心放权失控。
- **Collision：** 去本人依赖必须真实让别人能否决沈峥，而不是写一份“授权”文件。
- **Why only this book：** 主角每放掉一块权力，就减少旧合同对事业的杀伤力。
- **Reader reward：** asset / status / decision。
- **Permanent residue：** 双签与替代审批制度成立，沈峥永久失去一部分随意插手权。

### S03｜旧买家第一次发现“带走人”不等于带走公司
- **Situation：** 合同持有人故意在融资路演日执行在场权，想证明自己仍能左右沈峥。
- **Who wants what：** 持有人要维持控制价值；团队要完成融资；沈峥要验证组织独立性。
- **Collision：** 路演由副手完成且效果更好，持有人得到沈峥本人，却失去对事业结果的杠杆。
- **Why only this book：** 成功会反过来让旧合同从“事业控制权”降级为“本人占用权”。
- **Reader reward：** reversal / status / asset。
- **Permanent residue：** 投资方正式接受非创始人代表；旧持仓的事业杀伤力永久下降。

### S04｜团队赢了，创始人反而第一次嫉妒
- **Situation：** 沈峥缺席期间团队完成一次漂亮危机处理。
- **Who wants what：** 团队要庆祝独立；沈峥理性上想去依赖，情感上又想证明“没有我不行”。
- **Collision：** 他若夺回话语权，就亲手恢复旧合同的价值；若不夺回，就必须接受自己不再是每个胜利的中心。
- **Why only this book：** “变自由”的代价是主角主动让出主角式控制感。
- **Reader reward：** relationship / character reversal。
- **Permanent residue：** 团队第一次拥有不署沈峥名字的成功履历；沈峥与核心副手关系从上下级变成真正合伙。

### S05｜第一份不靠本人劳动的持续现金流
- **Situation：** 一条已经标准化的业务线连续一个月在沈峥低参与下盈利。
- **Who wants what：** 沈峥要把利润继续投入去单点；家庭希望他兑现“以后会有时间”。
- **Collision：** 现金流证明事业能脱身，也让家人要求他把脱出来的时间真的交还生活，而不是再开一条线。
- **Why only this book：** 组织复利立即把“自由”从商业成果变成私人债务。
- **Reader reward：** asset / life improvement / relationship。
- **Permanent residue：** 第一条独立现金流；家庭对“可自主时间”形成可追责承诺。

### S06｜旧合同撞上病床
- **Situation：** 某个既有强制在场日与至亲手术重叠。
- **Who wants what：** 持有人要合法执行；家人只要沈峥本人；团队表示事业端完全不需要他。
- **Collision：** 他第一次发现最痛的已不是公司会不会垮，而是公司已能替代他、家庭却不能。
- **Why only this book：** 事业去本人依赖越成功，私人“本人不可替代性”越昂贵。
- **Reader reward：** relationship / emotional pressure。
- **Permanent residue：** 家庭信任出现不可抹平裂痕；沈峥开始把私人不可代理日列为最高风险资产。

### S07｜关键客户要求创始人亲自承诺
- **Situation：** 大客户只接受“沈峥本人签字并全程负责”。
- **Who wants what：** 销售要拿单；客户要创始人信用；沈峥要避免重新制造本人单点。
- **Collision：** 最大订单恰好要求他回到最危险的商业模式。
- **Why only this book：** “创始人溢价”既是商业优势，又会直接抬高旧未来持仓价值。
- **Reader reward：** decision / status / tension。
- **Permanent residue：** 公司建立“组织信用替代创始人信用”的新合同模板，即便因此放弃部分收入。

### S08｜副手失误：去依赖不是永远正确
- **Situation：** 获授权的副手做出错误判断，造成真实损失。
- **Who wants what：** 董事与员工要求收回授权；沈峥要判断是制度错还是个体错。
- **Collision：** 最简单的止损是“以后还是老板拍板”，却会把全部事业重新绑回他的肉身。
- **Why only this book：** 组织容错本身就是对抗未来在场合同的核心战斗。
- **Reader reward：** failure / decision / relationship。
- **Permanent residue：** 权限没有被收回，但增加复盘与替补机制；团队承担过一次真实代价。

### S09｜旧买家开始保护沈峥的事业价值
- **Situation：** 外部竞争者试图毁掉沈峥声誉，某旧持有人出手压下证据污染。
- **Who wants what：** 持有人要保住未来持仓升值；沈峥要接受保护但不欠回控制权。
- **Collision：** 对方的帮助越有效，越可能把“保值”包装成新的支配资格。
- **Why only this book：** 同一份锁链同时制造保护与束缚。
- **Reader reward：** reversal / status / relationship。
- **Permanent residue：** 一笔无法抹去的人情债；双方从单向强制进入必须协商的关系。

### S10｜团队第一次故意不等老板
- **Situation：** 突发事件中，沈峥手机可接通，但团队按制度直接决策。
- **Who wants what：** 团队要证明机制是真机制；沈峥本能想介入；客户只要结果。
- **Collision：** 只要沈峥一句“我来”，此前所有授权都可能退回表演。
- **Why only this book：** 对抗旧合同需要的不只是“老板不在”，还要“老板在也不必成为唯一节点”。
- **Reader reward：** asset / character growth / status。
- **Permanent residue：** “无需等待创始人”成为组织惯例。

### S11｜本人出席反而成了稀缺资源
- **Situation：** 公司不再依赖沈峥日常在线后，他的公开出席开始被业务线争抢。
- **Who wants what：** 各负责人都想拿创始人露面为自己加成；沈峥要把在场用在真正不可替代处。
- **Collision：** 他必须拒绝大多数“有他更好”的请求，否则自由重新被内部吞掉。
- **Why only this book：** 去本人依赖会把“在场”从劳动必需品变成稀缺品牌资产。
- **Reader reward：** status / decision / asset。
- **Permanent residue：** 创始人出席预算与优先级制度形成；业务线开始学会不用他也能赢。

### S12｜旧合同持有人要求“本人”，公司却只派团队
- **Situation：** 持有人同时也是商业合作方，试图把私人在场权扩张成公司资源调用权。
- **Who wants what：** 对方要沈峥带团队替自己办事；沈峥要严格区分“你买的是我，不是我的组织”。
- **Collision：** 拒绝会伤商业合作，接受则让旧合同重新获得组织杠杆。
- **Why only this book：** “本人所有权边界”与“组织所有权边界”天然冲突。
- **Reader reward：** reversal / boundary / status。
- **Permanent residue：** 公司章程明确私人义务不得自动绑定组织资源。

### S13｜核心员工想离开
- **Situation：** 最可靠副手得到外部高薪邀约。
- **Who wants what：** 副手要个人成长；沈峥需要他维持去本人依赖；其他员工不愿公司把自由建立在另一个单点上。
- **Collision：** 若靠感情绑住副手，沈峥只是把“本人单点”换成“副手单点”。
- **Why only this book：** 对抗缺席风险逼组织不断消灭新的关键人依赖。
- **Reader reward：** relationship / organization / decision。
- **Permanent residue：** 第二梯队被真正培养；副手即使留下，也不再是唯一替代者。

### S14｜成功越大，旧日期越贵
- **Situation：** 沈峥进入公众视野后，某普通旧日期突然因颁奖/发布/舆论价值暴涨。
- **Who wants what：** 持有人要最大化稀缺出席价值；公司公关要他现身；沈峥要避免人生被所有人围绕“本人露面”定价。
- **Collision：** 事业已经不怕缺席，公共身份却开始依赖“真人出现”。
- **Why only this book：** Premium从事业层自然迁移到象征价值层，而不是消失。
- **Reader reward：** status / spectacle / pressure。
- **Permanent residue：** 沈峥的公共在场被市场化；旧合同价值结构发生永久升级。

### S15｜一次主动缺席实验
- **Situation：** 没有合同强迫，沈峥主动在重要节点不出现。
- **Who wants what：** 他要测真实独立性；团队担心被当成不重视；客户想见最终负责人。
- **Collision：** 主动缺席比被迫缺席更难，因为失败不能怪合同。
- **Why only this book：** 主角把灾难条件反过来变成组织压力测试。
- **Reader reward：** asset / discovery / reversal。
- **Permanent residue：** 找出两个仍隐形依赖沈峥的流程漏洞并永久修补。

### S16｜家庭开始拒绝“代理式陪伴”
- **Situation：** 沈峥用助理、礼物、安排替代自己参加家庭事件。
- **Who wants what：** 他以为自己在履约；伴侣/家人要的是本人而非资源。
- **Collision：** 事业上有效的代理逻辑在亲密关系里直接失效。
- **Why only this book：** 全书最核心反向命题被生活层验证：可代理不是普遍美德。
- **Reader reward：** relationship / emotional reversal。
- **Permanent residue：** 家庭明确一组不可代理承诺；沈峥不能再用“组织效率”逃避亲密。

### S17｜一个业务因过度标准化失去灵魂
- **Situation：** 团队按流程完美运转，却让老客户觉得公司变得冷、机械。
- **Who wants what：** 运营要可复制；老客户要过去那种“沈峥亲自解决”的信任感。
- **Collision：** 去本人依赖不能等于去人格化。
- **Why only this book：** 主角必须把自己的判断方式变成组织文化，而不是复制本人肉身。
- **Reader reward：** discovery / relationship / asset。
- **Permanent residue：** 团队形成一条不依赖沈峥但保留价值观的客户处理原则。

### S18｜旧买家彼此利益冲突
- **Situation：** 两个既有持有人都希望沈峥长期升值，却对他下一步事业选择有相反利益。
- **Who wants what：** A要稳健保值；B要他冒险扩张；沈峥要利用分歧拿回决策空间。
- **Collision：** 他们都“为他好”，但都是从持仓价值出发。
- **Why only this book：** 主角身价越高，旧债主越像互相制衡的股东，却又没有公司股权。
- **Reader reward：** reversal / decision / status。
- **Permanent residue：** 持有人无法再形成单一控制联盟；沈峥获得一项协商先例。

### S19｜公司第一次在他失联时完成并购/大交易
- **Situation：** 一笔需要快速决断的资产机会恰逢合同日。
- **Who wants what：** 团队要抓窗口；沈峥无法沟通；交易对手想拖到创始人出现。
- **Collision：** 若组织没有真正授权，这种机会永远必须等本人。
- **Why only this book：** “缺席仍能完成不可逆大决策”是帝国化的硬证明。
- **Reader reward：** asset / status / spectacle。
- **Permanent residue：** 公司多一项长期资产；团队获得历史级独立决策记录。

### S20｜代理人开始拥有自己的利益
- **Situation：** 核心代理人对某业务方向与沈峥公开不同意见。
- **Who wants what：** 代理人要按自己负责的长期结果行事；沈峥要保战略方向；员工要知道到底谁说了算。
- **Collision：** 真代理人必然会有独立意志；没有冲突的代理只是遥控器。
- **Why only this book：** 去本人依赖天然把配角从工具人变成权力主体。
- **Reader reward：** relationship / status / decision。
- **Permanent residue：** 权力边界经过一次真实冲突后更清晰，双方留下政治资本与旧账。

### S21｜最赚钱的业务反而必须砍掉
- **Situation：** 某高利润业务严重依赖沈峥个人关系。
- **Who wants what：** 财务要保利润；沈峥要降低未来在场风险；负责人想证明可以改造。
- **Collision：** 短期赚钱与长期自由直接对立。
- **Why only this book：** 估值不是唯一胜利条件，“可脱离本人”本身是核心资产质量。
- **Reader reward：** decision / asset / sacrifice。
- **Permanent residue：** 公司收入短期下降，但本人依赖率永久降低，资源转投可复制业务。

### S22｜老员工反抗“老板不需要我、也不需要自己”
- **Situation：** 去单点改革让一批靠亲近沈峥获得价值的人失去位置。
- **Who wants what：** 老员工要保身份与特权；新体系要按职责而非亲疏运行。
- **Collision：** 组织升级会伤害旧关系，并非无痛“科学管理”。
- **Why only this book：** 主角对抗自己肉身依赖，也在拆自己曾建立的人情结构。
- **Reader reward：** relationship / status / failure。
- **Permanent residue：** 一位旧臣离开或转岗；组织文化从“跟老板”转向“守职责”。

### S23｜一次真正失败的缺席
- **Situation：** 合同日撞上危机，团队没扛住，公司丢掉重要机会。
- **Who wants what：** 董事要证明必须恢复创始人兜底；团队要保住授权；沈峥要接受去依赖并不保证每次赢。
- **Collision：** 他不能用一次失败否定整个方向，也不能假装损失不存在。
- **Why only this book：** 自由是用真实商业风险买来的，不是系统奖励。
- **Reader reward：** failure / character / decision。
- **Permanent residue：** 失去一个机会或客户；新增灾备角色与权限，但不恢复本人单点。

### S24｜旧合同突然变成对手保护公司的理由
- **Situation：** 有人试图恶意收购/夺走公司，旧持有人发现这会大幅降低自己未来持仓价值。
- **Who wants what：** 外部对手要控制资产；持有人要保值；沈峥不愿被“救命恩人”换取新支配。
- **Collision：** 最讨厌的人短期与主角利益完全一致。
- **Why only this book：** 债权式在场权会随着事业成长形成反常保护联盟。
- **Reader reward：** reversal / status / asset。
- **Permanent residue：** 公司度过危机，但沈峥欠下一次可被未来关系反复调用的共同历史。

### S25｜第一条业务线可以卖掉，但自由要不要卖
- **Situation：** 有人高价收购一条完全去本人依赖的业务。
- **Who wants what：** 股东想兑现；沈峥既想拿现金，又看重它证明“没有我也能长”的象征。
- **Collision：** 他第一次面对“可缺席资产”本身成为可交易财富。
- **Why only this book：** 主角建设的不只是公司规模，而是脱离本人肉身的资产质量。
- **Reader reward：** asset / decision / status。
- **Permanent residue：** 无论卖或不卖，资产组合与“自由如何计价”的原则永久变化。

### S26｜事业已经不需要他，媒体却只认他
- **Situation：** 公司遭遇公共危机，内部完全能处理，但舆论只接受沈峥本人回应。
- **Who wants what：** 团队要建立机构信用；公众要真人承担；持有人看到“本人出现”价值再次暴涨。
- **Collision：** 企业去个人化与公众责任之间不能简单二选一。
- **Why only this book：** Premium从运营层升级到公共象征层。
- **Reader reward：** status / relationship / public consequence。
- **Permanent residue：** 公司建立非创始人发言体系，但沈峥仍保留少数无法代理的公共责任。

### S27｜伴侣要求他把一项“可缺席成果”兑换成真实共同生活
- **Situation：** 事业自由时间已明显增加，但沈峥习惯把空出来的时间继续投入扩张。
- **Who wants what：** 伴侣要兑现共同生活；沈峥害怕停下来后面对旧合同与自我价值空洞。
- **Collision：** 他不能再用“公司还离不开我”作为借口。
- **Why only this book：** 事业成功会移除主角逃避亲密的结构性借口。
- **Reader reward：** relationship / character discovery。
- **Permanent residue：** 一项固定生活安排成为不可代理长期承诺。

### S28｜下一代负责人拒绝成为“第二个沈峥”
- **Situation：** 公司准备提拔业务负责人，候选人拒绝24小时待命式岗位。
- **Who wants what：** 公司要可靠负责人；候选人要可持续生活；沈峥想复制自己早年的拼命模型。
- **Collision：** 若新负责人也成为肉身单点，帝国只是把病复制给别人。
- **Why only this book：** 主角必须证明“可缺席”是组织属性，不只是老板个人自由。
- **Reader reward：** organization / relationship / thematic reversal。
- **Permanent residue：** 负责人岗位被重新设计为多人互备结构。

### S29｜旧合同日变成公司的一次公开压力测试
- **Situation：** 市场知道沈峥某天一定无法在场，竞争者故意当天发起攻击。
- **Who wants what：** 竞争者要证明公司离不开老板；团队要反证；沈峥只能旁观。
- **Collision：** 缺席从隐秘弱点变成所有人可利用的公开时钟。
- **Why only this book：** 旧未来合同与公司组织能力直接形成公开对赌。
- **Reader reward：** spectacle / status / reversal。
- **Permanent residue：** 团队若赢，机构信用跃升；竞争者以后不能再把“老板不在”当廉价攻击点。

### S30｜公司越成功，旧合同执行本身越有安保/舆论成本
- **Situation：** 持有人想按旧方式带走沈峥，却因其公众身份造成大量外部关注。
- **Who wants what：** 持有人要执行合同；沈峥要保护私人边界；公众/团队要知道发生了什么。
- **Collision：** 合法权利没有消失，但执行方式必须重新谈判。
- **Why only this book：** 成功让旧合同升值，也让控制成本同步上升。
- **Reader reward：** status / reversal / negotiation。
- **Permanent residue：** 执行边界从“单方带走”变为有明确隐私、安全和时间规则的长期协议。

### S31｜一次战略分裂：组织能否做出沈峥不喜欢的正确决定
- **Situation：** 沈峥缺席时管理层放弃他本人偏爱的项目。
- **Who wants what：** 管理层要保整体资源；沈峥想保个人执念；团队要证明授权不是只在顺从时有效。
- **Collision：** 他若事后翻案，所有代理权都会被证明是假的。
- **Why only this book：** 真正脱离本人依赖必然要求组织有权违背本人即时偏好。
- **Reader reward：** decision / relationship / status。
- **Permanent residue：** 公司确立一条“创始人也不能事后无条件翻案”的治理边界。

### S32｜旧买家持仓价值和家庭价值第一次正面冲突
- **Situation：** 一个私人重要日因沈峥社会地位上升而成为旧持有人最想执行的日期。
- **Who wants what：** 持有人要最大化象征价值；家人要他守承诺；公司反而完全无所谓他在哪。
- **Collision：** 主角已经解决事业问题，却无法用事业能力解开人生问题。
- **Why only this book：** Premium越到后期越集中在“本人不可复制”的核心。
- **Reader reward：** relationship / emotional stakes。
- **Permanent residue：** 一段关系可能加深或永久受损；主角对旧合同的终局目标重新定义。

### S33｜团队要求沈峥真正休假
- **Situation：** 公司已经具备无他运行能力，团队反而发现他持续在线会破坏机制。
- **Who wants what：** 团队要他离开以验证系统；沈峥害怕失去存在感。
- **Collision：** 他第一次从“被迫缺席”走到“必须学会自愿缺席”。
- **Why only this book：** 外部强制曾是诅咒，如今组织成长把同一状态改写成自由。
- **Reader reward：** relationship / character reversal / life improvement。
- **Permanent residue：** 沈峥建立真正不在线周期；团队权力不再依附他的随时可达。

### S34｜一条旧业务因为太依赖“创始人神话”而无法传承
- **Situation：** 公司准备跨区域复制业务，却发现外地客户只认沈峥故事。
- **Who wants what：** 扩张团队要可复制品牌；市场部想继续放大个人神话。
- **Collision：** 个人品牌最能赚钱，却是未来在场债的放大器。
- **Why only this book：** 品牌策略直接决定旧合同杠杆，而非纯营销问题。
- **Reader reward：** asset / status / decision。
- **Permanent residue：** 品牌从“沈峥本人”迁移到机构价值，短期损失一部分溢价。

### S35｜组织第一次保护沈峥不被自己的责任感绑回去
- **Situation：** 灾难发生，沈峥明明可以插手，但团队认定他介入会破坏既定指挥。
- **Who wants what：** 沈峥要亲自救火；负责人要守职责；员工要一个不被创始人临时夺权的体系。
- **Collision：** “我能帮”不等于“我应该接管”。
- **Why only this book：** 帝国成长最终反过来约束创始人本人。
- **Reader reward：** relationship / status / reversal。
- **Permanent residue：** 团队拥有一次成功对沈峥说“不”的共同历史。

### S36｜最早那条小业务重新改变大局
- **Situation：** 早期建立的低利润独立现金流，在大公司遭遇融资冻结时成为唯一稳定现金来源。
- **Who wants what：** 新业务想砍旧线；财务突然需要它活命；沈峥看到“老资产可复利”的价值。
- **Collision：** 看似过时的去本人依赖资产反而托住后来更大的帝国。
- **Why only this book：** 早期自由资产不是升级后丢弃的装备，而能在大规模局面重新定价。
- **Reader reward：** asset / reversal / survival。
- **Permanent residue：** 老业务从边缘资产升为战略安全垫，组织资产组合发生永久调整。

### S37｜如果事业完全可缺席，沈峥还凭什么是主角
- **Situation：** 公司进入稳定期，沈峥面临“继续扩张证明价值”还是把时间投向只有本人能做的关系与选择。
- **Who wants what：** 董事希望他开启新增长；家人希望他兑现过去承诺；沈峥要重新定义自我。
- **Collision：** 他不能靠“公司离不开我”保持中心位置。
- **Why only this book：** 成功本身会制造主角身份危机，而不是故事结束。
- **Reader reward：** character / relationship / decision。
- **Permanent residue：** 沈峥的身份从“不可替代执行者”转向“选择把本人留给什么的人”。

### S38｜终局级压力：公司毫发无损，人生却仍必须亲自付款
- **Situation：** 最昂贵的一次既有在场权执行时，帝国完全自主运转。
- **Who wants what：** 持有人要兑现最值钱的旧未来；沈峥要守住一个不能代理的人生承诺；团队只能旁观。
- **Collision：** 所有商业升级都已把事业从合同手里救出来，却无法把“本人”从过去交易里自动赎回。
- **Why only this book：** 规模越大，Premium越从“公司会不会死”聚焦到“我到底把自己卖掉了什么”。
- **Reader reward：** relationship / status / thematic payoff。
- **Permanent residue：** 事业自由成为已完成资产；剩余主债彻底转向本人、家庭与公共身份的稀缺性。

## Stress Findings

### Reward Sameness
**PASS。**
38个Seed并非重复“又一次缺席成功”。自然出现：
- 组织资产与现金流；
- 权力让渡与代理人独立；
- 失败与真实商业损失；
- 客户、品牌、融资、并购、舆论；
- 家庭与亲密不可代理；
- 旧持有人从控制者变成保护者/谈判者；
- 主角身份危机。
核心果实从“项目没垮”逐步迁移为“组织能违背我仍然正确”“本人在场成为稀缺资源”“事业自由无法替代亲密自由”。

### Premium Survival
**STRONG PASS。**
Seed 1—10：Premium是“缺席会不会毁掉事业”。
Seed 11—25：Premium升级成“本人在场的品牌/控制/治理价值如何被重新定价”。
Seed 26—38：事业端越成功，Premium越集中到公众象征与亲密关系中“本人不可复制”的价值。
规模增长没有稀释Premium，反而把它从运营层推到更贵的身份层。

### Old-Asset / Old-State Compounding
**VERY STRONG PASS。**
- S02的授权结构在S19、S29、S31重新改变大局；
- S05的早期独立现金流在S36变成战略安全垫；
- S13形成的第二梯队让后续不再把副手当新单点；
- 旧持有人关系从S09的人情债持续演化为S18、S24、S30的长期博弈；
- 家庭不可代理承诺从S16反复重估S27、S32、S38。

### Case-Supply Dependency
**LOW。**
不需要持续新增客户、买家或新合同才能续航。主要故事由同一批：
- 既有旧合同；
- 核心管理层；
- 家庭；
- 公司资产；
- 公共身份
不断升值、互相反咬产生。外部业务事件只是压力源，不是发动机。

### Natural Stop
在38个Seed后继续扩写仍有空间，但新增内容开始更多进入具体行业业务而非检验Root Engine，因此本轮主动停止，不以“换行业Case”凑到50。

## Qualifier Verdict

> **REVIVAL OPENING-ARC ELIGIBLE**

理由：
- reservoir足够深；
- Reward不单一；
- 早期组织资产能在后期复利；
- Premium随事业规模增长反而更贵；
- 低Case-Supply依赖；
- 无需新增第二系统或新增合同池来续命。
