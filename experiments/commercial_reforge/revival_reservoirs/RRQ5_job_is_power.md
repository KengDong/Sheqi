## Frozen Premium

> 这个世界大部分超凡能力由组织“岗位”授予现实权限；主角能把两个相邻岗位的闲置权限重组成一个从未存在过的新岗位。成长既是战力增长，也是职位、辖区、团队与制度设计增长。

## Situation Seeds

### S01｜临时工第一次碰到权限缝隙
- **Situation：** 两个部门互相等批示，异常正在扩大。
- **Who wants what：** 主角要救现场；两部门都不愿越权背责。
- **Collision：** 他用各自闲置的一小块权限拼出临时“疏散封锁员”。
- **Why only this book：** 超能力不是天赋，而是岗位权责的现实化。
- **Reader reward：** power / reversal / status。
- **Permanent residue：** 第一个新岗位原型与一次违规/立功记录同时留下。

### S02｜临时新岗位真的要有人负责
- **Situation：** 危机结束后，上级追责“谁授权了不存在的岗位”。
- **Who wants what：** 主角想保住成果；老部门要切割责任；被救者要证明它有效。
- **Collision：** 战斗胜利不能自动换制度承认。
- **Why only this book：** 能力合法性与组织位置是同一件事。
- **Reader reward：** status / organization / tension。
- **Permanent residue：** 新岗位进入试点审查，主角获得有限正式权限。

### S03｜正式岗位比临时组合弱，却更稳定
- **Situation：** 主角获得最低级正式岗位。
- **Who wants what：** 他想要更强组合；组织要求先履行基础职责。
- **Collision：** 自创权限不能取代母盘中的真正职业成长。
- **Why only this book：** “升职就是变强”需要同时兑现日常职责与战力。
- **Reader reward：** status / power / life change。
- **Permanent residue：** 正式身份、薪酬、装备与稳定权限。

### S04｜第一次因为岗位边界救不了人
- **Situation：** 异常发生在自己辖区外几米。
- **Who wants what：** 主角要出手；邻区负责人怕他越权；现场群众只关心活命。
- **Collision：** 能力规则把官僚边界变成可见战斗边界。
- **Why only this book：** “辖区”不是纸面，而直接决定超凡能力是否生效。
- **Reader reward：** tension / frustration / spectacle。
- **Permanent residue：** 主角开始争取跨区协同权限，和邻区负责人结下长期关系。

### S05｜第一名真正需要的新岗位成员
- **Situation：** 主角的组合权限只有具备特定基础岗位的人才能承接。
- **Who wants what：** 他要组队；候选人担心加入一个没有前途的新岗。
- **Collision：** 新岗位不是技能卡，必须有人愿意把职业生涯押进去。
- **Why only this book：** 组织设计直接塑造角色关系。
- **Reader reward：** relationship / organization / status。
- **Permanent residue：** 第一名长期成员加入，自创岗位不再只属于主角。

### S06｜跨岗位组合抢了老部门的权
- **Situation：** 新岗位开始处理过去由两个科室分别掌握的权限。
- **Who wants what：** 主角要效率；老部门要保预算、编制与权威。
- **Collision：** 解决问题会伤害既得组织利益。
- **Why only this book：** 能力重组天然等于权力重组。
- **Reader reward：** organization / status / conflict。
- **Permanent residue：** 部门政治成为长期压力，某位老负责人转为固定对手/盟友。

### S07｜队员立功，却岗位等级没跟上
- **Situation：** 队员实战贡献远超其低级岗位授权。
- **Who wants what：** 主角要替他争权限；上级要按资历流程走。
- **Collision：** 能力由职位授予，组织晋升公平性直接影响战力。
- **Why only this book：** “升职”不是背景奖励，而是角色能力上限。
- **Reader reward：** relationship / status / injustice tension。
- **Permanent residue：** 队员获得临时授权或因此对组织产生裂痕。

### S08｜第一次发现一个“空岗位”比新能力更值钱
- **Situation：** 组织里有无人愿意接的低声望岗位，却握着关键权限。
- **Who wants what：** 主角想把它纳入组合；别人觉得降职/冷门。
- **Collision：** 最强路线不一定是最高职级直升。
- **Why only this book：** 权限结构允许“冷门岗位资产”被重新定价。
- **Reader reward：** reversal / power / status。
- **Permanent residue：** 团队获得一项长期稀缺权限，角色配置改变。

### S09｜上级给升职，但要求放弃自创岗位
- **Situation：** 主角被邀请进入传统精英部门。
- **Who wants what：** 他想更高战力与资源；现有队员需要他继续把新岗位做实。
- **Collision：** 个人晋升与组织创造第一次正面冲突。
- **Why only this book：** “职位越高越强”会诱惑主角背叛自己建立的结构。
- **Reader reward：** decision / relationship / status。
- **Permanent residue：** 主角选择路线后，团队与旧组织关系永久变化。

### S10｜新岗位第一次被正式写进编制
- **Situation：** 经过数次实战，试点岗位获得官方代码与职责。
- **Who wants what：** 主角要制度承认；老部门要求削掉部分权限。
- **Collision：** 正式化意味着稳定，也意味着被规训。
- **Why only this book：** 一个“能力组合”可以成长成真正社会职业。
- **Reader reward：** status / asset / organization。
- **Permanent residue：** 岗位从个人技巧变成可持续制度资产。

### S11｜标准化以后，主角不再是唯一能用的人
- **Situation：** 第二个新人按规范获得同类岗位。
- **Who wants what：** 组织要复制成功；主角本能担心失去独特性。
- **Collision：** 他究竟想要个人外挂，还是更好的组织？
- **Why only this book：** 成功会主动削弱主角技能垄断。
- **Reader reward：** character / organization / reversal。
- **Permanent residue：** 岗位形成传承，主角身份从使用者升级为设计者。

### S12｜复制失败：同岗不同人并不等于同能力
- **Situation：** 新人照抄岗位结构却在现场失败。
- **Who wants what：** 上级怀疑岗位本身；主角要找出训练/人格/职责差异。
- **Collision：** 制度不能把人变成功能件。
- **Why only this book：** “岗位授能”仍需真实人承担职责与判断。
- **Reader reward：** discovery / relationship / failure。
- **Permanent residue：** 岗位培训标准和人员筛选原则形成。

### S13｜一次辖区扩大，战力瞬间可见提升
- **Situation：** 主角的小组从一条街获得正式跨街区权限。
- **Who wants what：** 团队要更大行动范围；其他小组怕资源被抢。
- **Collision：** 地盘与超凡能力范围完全重合。
- **Why only this book：** 组织地位增长直接兑现成可视战力。
- **Reader reward：** power / status / spectacle。
- **Permanent residue：** 固定辖区扩大，新增长期居民/设施责任。

### S14｜有权限却没人力
- **Situation：** 辖区扩张后，理论能力很强，实际没有足够人巡查。
- **Who wants what：** 主角想守住新地盘；队员不愿无限加班；上级只看结果。
- **Collision：** 组织成长必须真实供养成员，不能只升级面板。
- **Why only this book：** 战力上限被人力、排班、训练等现实组织能力约束。
- **Reader reward：** organization / life realism / decision。
- **Permanent residue：** 招募、轮班和后备制度形成。

### S15｜岗位之间第一次出现“职业歧视”
- **Situation：** 战斗岗看不起后勤岗，但一次危机只有后勤权限能维持区域能力。
- **Who wants what：** 战斗员要功绩；后勤成员要被当作真正核心。
- **Collision：** 谁算“强者”由组织结构重新定义。
- **Why only this book：** 岗位能力能把不起眼职业变成关键超凡节点。
- **Reader reward：** relationship / reversal / status。
- **Permanent residue：** 后勤岗位地位提高，团队权力结构改变。

### S16｜主角创造的岗位被别的部门抢先注册
- **Situation：** 竞争部门吸收其设计思路，抢先申请正式权限。
- **Who wants what：** 对方要制度所有权；主角要证明岗位不是论文署名，而是运行成果。
- **Collision：** 创新开始产生组织产权冲突。
- **Why only this book：** 新岗位本身是可争夺的长期资产。
- **Reader reward：** status / reversal / organization。
- **Permanent residue：** 岗位命名/归属/复制权形成制度先例。

### S17｜一个老岗位因新体系被淘汰
- **Situation：** 新岗位组合让某传统岗位几乎失去作用。
- **Who wants what：** 老员工要保职业与尊严；主角要提高效率。
- **Collision：** 创新会真实伤人，不能把旧组织全写成纸片阻力。
- **Why only this book：** 权限重组等于职业生态重组。
- **Reader reward：** relationship / decision / social consequence。
- **Permanent residue：** 一部分人转岗、一部分离开；主角背上改革历史。

### S18｜敌对异常学会攻击岗位链条
- **Situation：** 敌人不再正面对抗，而是先让通讯/认证岗位失效。
- **Who wants what：** 敌人要让整套权限系统瘫痪；主角要保持最低可运行链。
- **Collision：** 组织越复杂，链条弱点越多。
- **Why only this book：** 敌人能针对“岗位依赖图”而非单一英雄。
- **Reader reward：** survival / strategy / spectacle。
- **Permanent residue：** 团队建立离线/替补职责，早期小岗位重新变重要。

### S19｜临时工时期的旧权限在大危机中救场
- **Situation：** 高级系统失效，只有最早的低阶人工巡查权限还能使用。
- **Who wants what：** 高层要恢复控制；主角记得底层岗位实际怎么运转。
- **Collision：** 旧资产不是被高职级淘汰。
- **Why only this book：** 职业阶梯能产生向下兼容的复利。
- **Reader reward：** compounding / reversal / competence。
- **Permanent residue：** 低级岗位被重新纳入核心灾备体系。

### S20｜队员想自己创岗位，不想永远在主角树下
- **Situation：** 核心成员提出完全不同的岗位组合。
- **Who wants what：** 队员要自主职业路线；主角既想支持又担心团队分裂。
- **Collision：** 真正强组织必然长出不受主角控制的创新。
- **Why only this book：** “设计岗位”的能力会催生独立人格与组织分叉。
- **Reader reward：** relationship / organization / status。
- **Permanent residue：** 团队出现第二条岗位分支，主角不再是唯一中心。

### S21｜一纸调令能让主角瞬间变弱
- **Situation：** 政治冲突中，上级试图把主角调离辖区。
- **Who wants what：** 对手要合法削弱他；主角要保职责而非靠私斗抗命。
- **Collision：** 组织权力能直接改变超凡战力。
- **Why only this book：** 职场斗争不是装饰，而具有战斗后果。
- **Reader reward：** status / tension / reversal。
- **Permanent residue：** 主角开始争取制度性任命保护与团队自治。

### S22｜职位更高后，不能再亲自抢所有功劳
- **Situation：** 主角升到小组负责人，亲自出手最稳，但会让下属永远长不起来。
- **Who wants what：** 他要任务成功；队员要真实责任；组织要培养梯队。
- **Collision：** “主角更强”与“组织更强”开始分离。
- **Why only this book：** 职位成长会强迫主角改变行动方式。
- **Reader reward：** relationship / status / character growth。
- **Permanent residue：** 队员独立负责区域，主角放弃部分一线功绩。

### S23｜居民开始依赖某个岗位而不是某个人
- **Situation：** 辖区群众遇到异常，会主动找“某岗”而不是点名主角。
- **Who wants what：** 主角想建立可持续公共服务；个人粉丝仍只认他。
- **Collision：** 个人英雄信用与制度信用竞争。
- **Why only this book：** 新岗位可以真正成为社会基础设施。
- **Reader reward：** status / life improvement / organization。
- **Permanent residue：** 岗位品牌形成，主角个人缺席时系统仍可运行。

### S24｜一次岗位合并制造意料外的权力过大
- **Situation：** 两项权限组合后，新岗位既能发现异常又能直接封锁区域。
- **Who wants what：** 主角要效率；监督者担心缺乏制衡。
- **Collision：** 最有效设计不一定最安全。
- **Why only this book：** 能力设计天然是制度设计。
- **Reader reward：** decision / organization / discovery。
- **Permanent residue：** 新岗位被拆出监督/复核职责，组织制衡机制升级。

### S25｜队伍内部第一次争“谁定义岗位”
- **Situation：** 新一轮扩编时，不同核心成员提出相反组织结构。
- **Who wants what：** 各自都认为自己的方案最有效；主角不能靠个人能力压服。
- **Collision：** 组织升级进入真正政治，而不是主角一个人点科技树。
- **Why only this book：** 权限结构决定所有人力量分配。
- **Reader reward：** relationship / organization / decision。
- **Permanent residue：** 形成岗位委员会/协商规则，主角权力被制度化约束。

### S26｜高层异常要求跨城协同，地方权限互不兼容
- **Situation：** 两座城市岗位体系不同，能力接口冲突。
- **Who wants what：** 主角要完成救援；外城不愿接受本地临时岗。
- **Collision：** “制度不同”直接变成超凡协同问题。
- **Why only this book：** 世界扩张来自组织制度差异，而不仅是换地图怪物。
- **Reader reward：** spectacle / discovery / organization。
- **Permanent residue：** 第一套跨城岗位兼容协议形成。

### S27｜老对手部门在危机中必须和新岗位互相授权
- **Situation：** 早期抢权的老部门握有主角缺少的唯一权限。
- **Who wants what：** 双方都想保自主；危机要求真正共享。
- **Collision：** 多年的组织旧账不能一句“大局为重”消失。
- **Why only this book：** Old-State中的部门关系能在后期重新定价。
- **Reader reward：** relationship / reversal / compounding。
- **Permanent residue：** 形成长期互授权机制，旧敌关系转为复杂合作。

### S28｜主角的岗位体系太成功，出现“只想进这个岗”的年轻人
- **Situation：** 招聘涌入，但其他基础岗位被抽空。
- **Who wants what：** 年轻人要强权限与前途；组织需要完整生态；主角不想制造新失衡。
- **Collision：** 成功的岗位创新开始伤害整个系统的人才分布。
- **Why only this book：** 主角的成长成果会改变社会职业选择。
- **Reader reward：** status / social consequence / decision。
- **Permanent residue：** 招募配额与轮岗制度形成，主角承担更大组织责任。

### S29｜一次“降职”反而提升任务战力
- **Situation：** 特殊区域只有某基层岗位权限有效，高职级通用权反而被屏蔽。
- **Who wants what：** 主角要完成任务；身份自尊与组织规则冲突。
- **Collision：** 他主动临时回到低阶岗位职责。
- **Why only this book：** 职位不是简单等级数字，不同岗具有不可替代权限。
- **Reader reward：** reversal / competence / character。
- **Permanent residue：** 组织承认岗位横向价值，晋升不再意味着抛弃旧职业技能。

### S30｜辖区居民开始要求参与岗位设计
- **Situation：** 某新岗位权限会影响日常通行、隐私或经营。
- **Who wants what：** 主角团队追求安全效率；居民要被治理者有发言权。
- **Collision：** 战斗设计进入公共治理。
- **Why only this book：** 岗位超凡权限直接作用现实社会。
- **Reader reward：** organization / relationship / decision。
- **Permanent residue：** 新岗位建立公开边界与民众反馈机制。

### S31｜主角获得区域指挥席，但能力变成“让别人变强”
- **Situation：** 晋升后，他可调度整片城区岗位权限，个人一线权限反而减少。
- **Who wants what：** 他怀念亲自解决；区域需要他做分配与设计。
- **Collision：** 更高等级不是更大的拳，而是更大的责任和间接力量。
- **Why only this book：** 升职=变强可以自然从个人技能升级为组织调度。
- **Reader reward：** status / spectacle / organization。
- **Permanent residue：** 主角进入区域级权力层，老队员各自成为独立节点。

### S32｜有人利用岗位制度制造合法暴力
- **Situation：** 另一组织设计出效率极高、制衡极少的强力岗位。
- **Who wants what：** 对方要快速稳定秩序；主角要证明“有效”不能替代责任边界。
- **Collision：** 两套岗位哲学在真实危机中竞争。
- **Why only this book：** 反派不必新外挂，只需设计不同制度即可构成强对手。
- **Reader reward：** conflict / discovery / organization。
- **Permanent residue：** 主角的组织原则被公开检验，成员立场分化。

### S33｜最早的新岗位在主角不在时独立救下一城
- **Situation：** 主角被困别处，S01起源的岗位体系由后辈独立运转。
- **Who wants what：** 老体系怀疑离开创始人就会崩；后辈要证明岗位已不是个人技巧。
- **Collision：** 主角必须接受自己的作品可以在没有他时成为主角。
- **Why only this book：** “创造职业”最强复利是职业脱离创造者持续存在。
- **Reader reward：** status / relationship / compounding / spectacle。
- **Permanent residue：** 新岗位成为真正社会制度资产。

### S34｜最高层问题：谁有资格定义“什么工作能获得现实权限”
- **Situation：** 主角进入更高层后发现岗位目录本身决定社会力量分配。
- **Who wants what：** 旧体系要维持既有职业秩序；新岗位群体要求进入；主角要建立可验证而非任意授能的标准。
- **Collision：** 个人创新自然升级成制度入口权之争。
- **Why only this book：** Premium越到后期越重要，因为“职位就是力量”的定义权本身就是世界级权力。
- **Reader reward：** macro promise / status / organization。
- **Permanent residue：** 岗位创新从一支小队的优势升级为改变整个超凡社会结构的长期问题。

## Stress Findings

### Reward Sameness
**STRONG PASS。**
并非反复“又造一个岗位”。自然果实包括：
- 正式身份与生活改善；
- 辖区扩张；
- 队员职业成长；
- 部门权力冲突；
- 组织产权；
- 低级岗位复利；
- 制度复制与失真；
- 公共服务与治理；
- 跨城兼容；
- 主角从一线战斗者变成组织设计者。
岗位新品只是其中一部分。

### Premium Survival
**VERY STRONG PASS。**
规模越大，“岗位授予现实权限”越关键：从个人能力到团队、辖区、城市，再到谁有资格定义岗位目录。Premium没有被普通都市异能吞没，反而成为世界结构。

### Old-Asset / Old-State Compounding
**VERY STRONG PASS。**
- S01的最低级新岗位在S10制度化、S11复制、S33脱离主角独立运行；
- S04邻区关系在S27成为跨部门互授权；
- S08冷门岗位与S19低级权限在后期灾备中重新升值；
- 早期队员在S20以后长出自己的岗位分支。

### Case-Supply Dependency
**LOW。**
不需要持续新增怪物。固定组织、岗位、辖区、队员、旧部门与制度本身即可持续产生故事。异常事件只提供压力，不是主要水库燃料。

### Natural Stop
34个Seed后仍有显著制度扩张空间；继续列会开始进入更多城市/行业细节。本轮证据已足够，停止。

## Qualifier Verdict

> **REVIVAL OPENING-ARC ELIGIBLE**

Opening Arc硬验证：
- 必须让“岗位=超能力”第一章就有现场可视结果；
- 至少一位加入新岗位的人有自己的职业欲望，不是权限插件；
- 第一轮高潮必须留下一个真正被组织承认或拒绝承认的永久岗位状态。
