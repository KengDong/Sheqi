## Frozen Premium

> 所有人个人等级都在10级封顶；想获得第二阶段力量，必须加入一个真正能持续供养成员、占据资源点的组织。主角拥有创建并选择组织职业树的资格。个人变强与组织真实生存能力绑定。

## Situation Seeds

### S01｜全世界第一次卡死10级
- **Situation：** 所有人都发现经验不再增长。
- **Who wants what：** 散人想继续升级；大势力开始收人；主角得到第一枚建团核心。
- **Collision：** 加入别人能立刻继续变强，自建组织却要先承担供养责任。
- **Why only this book：** 个人成长墙直接把“组织”从可选社交变成生存刚需。
- **Reader reward：** discovery / power / decision。
- **Permanent residue：** 主角选择自建，放弃最快个人升级路线。

### S02｜第一批成员不是最强的人
- **Situation：** 建团条件要求连续七日供养五人。
- **Who wants what：** 主角需要稳定成员；强者只想短期蹭升级；普通人愿意共同生产。
- **Collision：** 最强战斗卡不一定能让组织活过七天。
- **Why only this book：** 组织升级取决于真实供养而非凑人数。
- **Reader reward：** relationship / organization / reversal。
- **Permanent residue：** 第一批核心成员形成，技能互补而非战力排序。

### S03｜第一条稳定食物线比BOSS装备更值钱
- **Situation：** 小队可以去打高收益怪，也可以守住低收益食物点。
- **Who wants what：** 战斗员要装备；生活成员要稳定供给；主角要满足组织升级条件。
- **Collision：** 个人爽点与集体升级条件冲突。
- **Why only this book：** 食物产出直接决定所有人能否突破等级墙。
- **Reader reward：** asset / decision / survival。
- **Permanent residue：** 第一处稳定资源点。

### S04｜七日自给，五个人同时解锁
- **Situation：** 组织完成第一项真实运营条件。
- **Who wants what：** 所有人都等着突破；外部散人开始想加入。
- **Collision：** 成果不是主角独享，而是全员上限同时改变。
- **Why only this book：** “我建立的东西让大家一起变强”是核心幻想。
- **Reader reward：** power / spectacle / relationship。
- **Permanent residue：** 第一组织等级与第一条职业树解锁。

### S05｜职业树第一次逼出价值选择
- **Situation：** 只能在“更强战斗”与“更稳生产”中选一条组织路线。
- **Who wants what：** 战斗组要火力；生产组要供养更多人口。
- **Collision：** 选择不可轻易回退，会塑造长期组织性格。
- **Why only this book：** 组织成长不是简单数值，而是共同力量方向。
- **Reader reward：** decision / organization / anticipation。
- **Permanent residue：** 第一条不可逆组织职业分支。

### S06｜新成员加入会稀释现有资源
- **Situation：** 一群幸存者求加入。
- **Who wants what：** 主角想扩张；老成员怕口粮和升级资源被分薄；新人需要庇护。
- **Collision：** “招人=变强”并不总成立。
- **Why only this book：** 人口既是组织能力也是供养负担。
- **Reader reward：** relationship / decision / survival。
- **Permanent residue：** 组织建立第一套入团与供养标准。

### S07｜一个战斗强者不愿履行组织职责

- **Collision：** 组织资格不能只是战斗力租赁。
- **Why only this book：** “组织让你升级”天然产生成员义务。
- **Reader reward：** relationship / status / organization。
- **Permanent residue：** 成员职责和退出规则被明确。

### S08｜第一次有人退出，等级怎么办
- **Situation：** 核心成员想离开组织。
- **Who wants what：** 他要自由；组织怕带走已解锁力量；主角不能把人关住。
- **Collision：** 个人力量与组织归属的绑定边界必须被验证。
- **Why only this book：** 升级来源是组织资格，退出天然有真实后果。
- **Reader reward：** discovery / relationship / tension。
- **Permanent residue：** 退出机制明确，成员自由与组织安全形成长期规则。

### S09｜资源点被抢，不只是少一块地

- **Collision：** 地盘损失会直接影响组织等级条件。
- **Why only this book：** 领地、供养与个人力量强绑定。

### S10｜弱者岗位第一次让全队变强

### S11｜大势力挖角：一个人走，整棵职业树受影响

- **Who wants what：** 对方要破坏组织条件；成员想获得更好待遇；主角不能靠道德绑架。

- **Why only this book：** 组织能力由真实成员承载。

### S15｜主角个人已经很强，却必须等组织

### S17｜组织名声开始自己吸引人

- **Why only this book：** 组织等级是对外可见的生存与成长承诺。

- **Why only this book：** 根规则要求真正能供养成员的组织，不是公会标签。

### S19｜旧食物点在大型封锁中救命

- **Why only this book：** 组织条件让旧生产资产长期有价值。

- **Permanent residue：** 老资源点升级为战略储备核心。

### S20｜组织升级要求“成员平均状态”，不能只堆精英

- **Who wants what：** 精英想把资源继续投自己；普通成员第一次拥有结构性话语权。
- **Collision：** 精英路线与共同成长正面冲突。
- **Why only this book：** 组织上限把弱者发展转成所有人的利益。
- **Reader reward：** relationship / power / organization。
- **Permanent residue：** 培训、公共装备与最低保障形成。

### S21｜成员有了孩子/家属，供养条件变重
- **Situation：** 组织人口出现非战斗家庭成员。
- **Who wants what：** 家庭要长期安全；战斗派认为他们拖慢升级。
- **Collision：** “组织”究竟是战队还是社会。
- **Why only this book：** 供养能力决定力量，因此家庭人口也会进入成长模型。
- **Reader reward：** relationship / worldbuilding / decision。
- **Permanent residue：** 学习、医疗、照护等非战斗机构出现。

### S22｜第一条组织职业树产生内部阶层
- **Situation：** 某分支成员获得更稀缺能力与资源。
- **Who wants what：** 特殊职业想更多话语权；其他成员认为贡献不只看战斗。
- **Collision：** 组织升级会制造新不平等。
- **Why only this book：** 职业树既是战力系统也是社会分工。
- **Reader reward：** status / relationship / organization。
- **Permanent residue：** 分配制度、代表权或长期派系形成。

### S23｜对手不攻基地，专门破坏供养指标
- **Situation：** 敌对势力烧毁生产、截断物流、诱拐专业人员。
- **Who wants what：** 对手要让组织自动掉级；主角要保住运营。
- **Collision：** 战争目标从“杀人”变成“让你不再是合格组织”。
- **Why only this book：** 根规则让经营能力成为可攻击的战力基础。
- **Reader reward：** strategy / survival / organization。
- **Permanent residue：** 冗余供应、备份职业与多点资源网络形成。

### S24｜掉级真的发生一次
- **Situation：** 组织短期失去关键条件，部分能力上限被锁回。
- **Who wants what：** 成员恐慌；有人想跳槽；主角要在弱化状态下保住共同体。
- **Collision：** 成长不是只升不降。
- **Why only this book：** 组织真实运行状态直接决定个人力量。
- **Reader reward：** failure / survival / relationship。
- **Permanent residue：** 一批人离开/一批人留下，共同历史与忠诚重新定义。

### S25｜恢复等级时，不是打BOSS而是把生活修回来
- **Situation：** 掉级后最优路径是修水、复耕、救回维修人员。
- **Who wants what：** 部分人只想找敌人报仇；主角必须重建供养。
- **Collision：** 爽点从战斗反转到组织恢复。
- **Why only this book：** 真正力量来源是“我们能持续活着”。
- **Reader reward：** asset / life improvement / power payoff。
- **Permanent residue：** 组织恢复且比此前更有韧性。

### S26｜小组织联盟能不能算一个更大组织
- **Situation：** 多个小团体想合作解锁区域级升级。
- **Who wants what：** 主角要联盟但保自治；大团体想吞并；系统只承认满足真实共同条件的结构。
- **Collision：** 联盟必须从口头变成资源、责任和决策共享。
- **Why only this book：** 组织层级扩张直接关系所有成员上限。
- **Reader reward：** organization / status / decision。
- **Permanent residue：** 第一套联盟治理与互保资源网。

### S27｜早期离队者带着不同组织回来
- **Situation：** S08离开的成员已成为另一组织核心。
- **Who wants what：** 双方都想合作又保独立；旧感情与新利益并存。
- **Collision：** 个人关系跨组织复利。
- **Why only this book：** 离开不是角色清零，组织归属会改变力量与立场。
- **Reader reward：** relationship / reversal / compounding。
- **Permanent residue：** 两个组织建立或破裂长期联盟。

### S28｜区域事件只允许高等级组织参与
- **Situation：** 世界事件开启，个人强者无资格，组织等级成为门票。

- **Collision：** 组织成长带来新地图，也带来更大责任。
- **Why only this book：** “组织等级”直接决定世界参与权。
- **Reader reward：** status / spectacle / macro expansion。
- **Permanent residue：** 组织进入区域级舞台，名声与敌友网络扩大。

### S29｜大势力只救精英，主角组织是否保普通居民
- **Situation：** 区域灾难逼近，撤离资源有限。
- **Who wants what：** 大势力要保高级成员；主角团因长期供养体系拥有不同选择。
- **Collision：** 救更多人会增加负担，甚至威胁等级条件。
- **Why only this book：** 组织力量来自供养，因此“我能养多少人”就是道德与战力同题。
- **Reader reward：** decision / spectacle / relationship。
- **Permanent residue：** 人口激增、资源压力与区域声望同时留下。

### S30｜主角个人十级封顶规则反而让新人追得上
- **Situation：** 新成员起点很低，但组织基础设施能让其快速达到个人封顶。
- **Who wants what：** 老成员担心资历价值下降；新人第一次拥有成长希望。
- **Collision：** 封顶压缩个人差距，组织质量决定第二阶段。
- **Why only this book：** “个人上限低、组织上限高”会重塑社会流动。
- **Reader reward：** relationship / status / worldbuilding。
- **Permanent residue：** 组织成为人才培养地，内部晋升规则必须更新。

### S31｜主角必须把建团核心权力交出去一部分
- **Situation：** 组织大到一人决策成为瓶颈。
- **Who wants what：** 主角想保方向；核心成员要真正治理权。
- **Collision：** 如果组织升级只靠主角点按钮，就违背自身主题。
- **Why only this book：** 组织成为力量源后，治理本身就是力量分配。
- **Reader reward：** relationship / status / organization。
- **Permanent residue：** 分权机构、负责人和不可逆治理结构形成。

### S32｜一个组织分裂，双方上限都受影响
- **Situation：** 内部路线冲突导致部分成员要另建组织。
- **Who wants what：** 两派都认为自己能活得更好；共同资产无法简单切割。
- **Collision：** 分家不是情绪戏，而会重新计算所有人的成长上限。
- **Why only this book：** 组织归属与个人力量硬绑定。
- **Reader reward：** relationship / status / consequence。
- **Permanent residue：** 领地、职业树、成员与资源被永久重分配。

### S33｜旧职业树的“错误选择”在区域战中意外成优势
- **Situation：** S14曾被嫌弃的分支恰好克制区域灾害。
- **Who wants what：** 过去主张洗点的人重新评价；主角要利用旧路线赢局。
- **Collision：** 早期错误并非简单垃圾资产。
- **Why only this book：** Old-State可因环境改变重新估值。
- **Reader reward：** reversal / compounding / spectacle。
- **Permanent residue：** 组织获得独特区域定位与新盟友。

### S34｜大型组织邀请整体并入
- **Situation：** 对方提供更高上限、更安全资源，但要求放弃独立职业树。
- **Who wants what：** 一部分成员要更快变强；另一部分要保共同历史和制度。
- **Collision：** “加入强者”再次出现，和S01形成大规模镜像。
- **Why only this book：** 组织越成功，仍必须回答“我们为什么不加入更大的组织”。
- **Reader reward：** decision / relationship / status。
- **Permanent residue：** 无论选择，组织身份与成员关系永久重塑。

### S35｜组织强到能保一片城区
- **Situation：** 区域灾难来临，主角团拥有足够等级把整片城区纳入供养/防御范围。
- **Who wants what：** 居民要活；核心成员担心规模过大导致系统崩溃。
- **Collision：** 从“让我们升级”变成“我们能不能承担别人也依赖我们的升级”。
- **Why only this book：** 力量与供养责任同步扩张。
- **Reader reward：** spectacle / status / organization / relationship。
- **Permanent residue：** 主角组织从公会变成区域秩序节点。

### S36｜后期核心：个人再强也不能替代组织活着
- **Situation：** 主角已是顶级强者，却遭遇只有完整生产、医疗、后勤、治理网络才能撑过的长期灾害。
- **Who wants what：** 敌人赌主角英雄式爆发；团队要靠多年积累慢慢扛住。
- **Collision：** 最终胜负不由一拳决定。
- **Why only this book：** Premium在规模增长后反而更强：真正上限是组织能否持续供养并行动。
- **Reader reward：** macro payoff / spectacle / compounding。
- **Permanent residue：** 多年旧成员、基地、职业树、资源点全部进入同一场结算，组织本身成为最强“能力”。

## Stress Findings

### Reward Sameness
**STRONG PASS。**
奖励并非“又升一级组织”。自然出现：
- 食物/能源/基地资产；
- 全员等级突破；
- 职业树选择；
- 退出、挖角、分裂；
- 家庭生活与普通成员；
- 掉级与恢复；
- 联盟、辖区、区域责任；
- 主角分权。
个人力量、生活改善、关系、治理、战争、公共责任交替出现。

### Premium Survival
**VERY STRONG PASS。**
后期个人等级越高，越无法脱离组织条件；从5人小队到城区，Premium持续扩大。没有滑回普通末日“主角一个人无限升级”。

### Old-Asset / Old-State Compounding
**VERY STRONG PASS。**
- S03食物点在S19救命；
- S14旧职业树在S33翻转价值；
- S08离队者在S27以另一组织身份回归；
- 基地、成员、供养规则、职业树都能跨长周期反复改变局势。

### Case-Supply Dependency
**LOW。**
怪物/新地图不是主要燃料。固定成员、资源点、基地、职业树、组织制度、人口与旧敌即可持续制造故事。世界事件主要用于放大已有组织状态。

### Natural Stop
36个Seed后仍有明显长篇空间；继续列会进入更多区域治理细节。本轮停止。

## Qualifier Verdict

> **REVIVAL OPENING-ARC ELIGIBLE**

Opening Arc硬验证：
- 十级墙必须极快兑现；
- 第一轮高潮不能只是“建团成功弹提示”，必须让供养、成员欲望和共同生活一起结算；
- 至少一名弱战斗/高生活价值成员必须真实改变全队成长。
