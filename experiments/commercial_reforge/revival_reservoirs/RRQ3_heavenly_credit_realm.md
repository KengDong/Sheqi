## Frozen Premium

> 所有修士都能向天道“赊”一个暂时境界，但会生成必须偿还的天债；主角能看见每笔天债的真实成本、隐藏利息、担保关系与可转移条件。借来的力量必须最终沉淀成真实境界、资源、地位或控制权，否则不算结算。

## Situation Seeds

### S01｜第一笔看似必死的便宜债
- **Situation：** 主角资源不足，被迫在擂台前选择一笔人人避之不及的赊境。
- **Who wants what：** 主角要赢下资源资格；对手认定他借了“死债”；旁观修士想看他何时暴毙。
- **Collision：** 他看见真正昂贵的是隐藏担保条件，不是表面还款方式。
- **Why only this book：** 胜负来自读懂天债真实结构，而非普通越阶外挂。
- **Reader reward：** power / reversal / discovery。
- **Permanent residue：** 赢得第一份修炼资源；留下第一笔真实天债履约记录与信用。

### S02｜借来的境界必须赶紧变成自己的
- **Situation：** 临时境界即将回落。
- **Who wants what：** 主角要在回落前抢到能支撑真实突破的灵药；别人想趁他债后虚弱夺走战利品。
- **Collision：** 赊境本身不算成长，必须把窗口转成永久资产。
- **Why only this book：** “借境→抢资源→还债→真实变强”是该书独有闭环。
- **Reader reward：** asset / power / survival。
- **Permanent residue：** 真境界推进，临时力量没有白借。

### S03｜第一次提前还债
- **Situation：** 一笔小债继续持有会累积隐藏利息。
- **Who wants what：** 主角想保信用；同伴建议把资源留给修炼。
- **Collision：** 现在还债会损失短期成长，拖延则未来成本变高。
- **Why only this book：** 还债本身是成长节奏的一部分，不是战后自动清零。
- **Reader reward：** decision / asset management。
- **Permanent residue：** 信用提高；资源减少；后续可借条件改变。

### S04｜别人爆债成为战斗弱点
- **Situation：** 对手以高境界碾压众人，但主角看见其一笔天债临近触发点。
- **Who wants what：** 对手要迅速结束战斗；主角要逼其提前爆债。
- **Collision：** 主角不需要正面打赢，只要制造符合催债条件的局势。
- **Why only this book：** 敌人的“借来的强”自带可识别债务结构。
- **Reader reward：** reversal / combat / discovery。
- **Permanent residue：** 主角建立“看债战斗”的声誉；对手因爆债失去长期资源或境界。

### S05｜第一位想让他看债的人
- **Situation：** 同门发现主角能判断天债，主动求他评估一笔赊境。
- **Who wants what：** 同门想安全借境；主角想换资源但不想变成一次性咨询师。
- **Collision：** 如果只是“新客户来问一笔债”，发动机会迅速Case化。
- **Why only this book：** 主角把判断能力转成长期互保而非单次收费。
- **Reader reward：** relationship / asset / status。
- **Permanent residue：** 建立第一份长期互保关系，对方未来成为固定合作角色。

### S06｜担保不是友情，是硬风险
- **Situation：** 固定伙伴的债需要担保人。
- **Who wants what：** 伙伴要借境救家人；主角知道担保会降低自己的信用额度。
- **Collision：** 关系第一次直接进入天道账本。
- **Why only this book：** “我信你”可以变成世界规则认可的真实负债。
- **Reader reward：** relationship / decision。
- **Permanent residue：** 双方形成可追责担保关系；主角可借额度永久受影响一段时间。

### S07｜一笔便宜债的真正代价是失去一件旧资产
- **Situation：** 主角看见某赊境利息极低，但抵押品会自动指向自己已有法器。
- **Who wants what：** 他要越阶；又不愿牺牲刚积累的核心资产。
- **Collision：** “便宜”与“适合”不是同一回事。
- **Why only this book：** 债务结构能直接重估旧资产。
- **Reader reward：** decision / asset tension。
- **Permanent residue：** 主角放弃或重配法器，资产组合发生真实变化。

### S08｜第一次坏账
- **Situation：** 一个固定盟友赊境失败，无力按原条件偿还。
- **Who wants what：** 盟友想活；债权规则要执行；主角不想自己被担保拖垮。
- **Collision：** 他必须决定是承担损失、重组债务还是让对方付出重代价。
- **Why only this book：** 人际关系与天道信用是同一张网。
- **Reader reward：** relationship / failure / decision。
- **Permanent residue：** 联盟信用结构改变；主角第一次留下实际坏账损失。

### S09｜信用上升后，反而能借更危险的债
- **Situation：** 主角连续履约后得到更高额度。
- **Who wants what：** 他想用信用抢更大资源；旁人把“能借更多”视为纯好事。
- **Collision：** 更高信用同时意味着能把自己推入更大风险。
- **Why only this book：** 成长轴天然含诱惑，不是单向加点。
- **Reader reward：** power / tension / status。
- **Permanent residue：** 借贷上限提高，同时进入更高风险债池。

### S10｜第一次不用借境也赢
- **Situation：** 对手故意逼主角借债，以便研究他的债务结构。
- **Who wants what：** 对手要看穿他；主角要证明自己真实境界已成长。
- **Collision：** 如果每场都赊境，Premium会吞掉母盘修仙。
- **Why only this book：** 最强反差是“靠过去借来的窗口，终于长出不借也能打的自己”。
- **Reader reward：** power / reversal。
- **Permanent residue：** 真实战力获得认可，信用能力从唯一依赖降为战略工具。

### S11｜宗门要求统一担保
- **Situation：** 小宗门为冲击秘境，要求成员统一赊境并由宗门担保。
- **Who wants what：** 宗门要整体战力；主角看见担保结构会把底层弟子损失转嫁给少数人。
- **Collision：** 集体融资能变强，也可能制造系统性坏账。
- **Why only this book：** 个人债自然扩张成组织信用问题。
- **Reader reward：** organization / discovery / decision。
- **Permanent residue：** 主角在宗门内获得债务设计话语权或因此结怨。

### S12｜破产道统的债比山门值钱
- **Situation：** 一个小宗门濒临解散，所有人只想低价买它的地。
- **Who wants what：** 买家要资产；债主怕坏账；主角看见某些天债绑定着灵脉收益权。
- **Collision：** 接债看似接烂摊子，却可能拿到长期资源控制权。
- **Why only this book：** “负债”本身可成为资产入口。
- **Reader reward：** asset / reversal / status。
- **Permanent residue：** 主角取得灵脉份额或道统资源权，正式进入组织资产层。

### S13｜接债以后才发现人也要养
- **Situation：** 主角拿到破产道统的资源权，却附带一批无法简单清退的弟子/家属。
- **Who wants what：** 主角要让资产盈利；旧弟子要生存与尊严。
- **Collision：** 债务收购从财务爽点变成真实治理责任。
- **Why only this book：** 通过接债得到的资产必然携带原债务关系。
- **Reader reward：** relationship / organization / asset。
- **Permanent residue：** 固定人口与组织责任加入主角长期盘面。

### S14｜旧坏账突然因主角成长变成好资产
- **Situation：** 早期接下的一笔不良债，在主角境界/信用上升后有能力低成本重组。
- **Who wants what：** 主角要盘活旧资产；反对者想趁其尚未修复时夺走。
- **Collision：** 过去承担的烂账开始产生复利。
- **Why only this book：** 旧债不会用完即丢，而会随信用与资源变化重新定价。
- **Reader reward：** asset / compounding / reversal。
- **Permanent residue：** 旧负担转成持续收益或控制权。

### S15｜敌人故意制造“统一催债”
- **Situation：** 对手选择一个能同时触发多名修士债务条件的时间点。
- **Who wants what：** 对手要让主角阵营集体跌境；主角要拆开触发链。
- **Collision：** 个体债务组合成群体脆弱性。
- **Why only this book：** 战场可以围绕债务成熟条件而设计。
- **Reader reward：** spectacle / survival / strategy。
- **Permanent residue：** 队伍建立分散债务结构的长期规则。

### S16｜一位高手信用极好，却没有任何自由
- **Situation：** 主角遇到长期依赖赊境的强者，对方从不违约，却所有未来资源都已被债务锁死。
- **Who wants what：** 强者要继续维持地位；主角想知道“完美信用”是不是陷阱。
- **Collision：** 偿债成功不等于健康成长。
- **Why only this book：** 信用成长可以反向制造“债务奴役”。
- **Reader reward：** discovery / character foil。
- **Permanent residue：** 主角建立“真实资产增长必须快于债务扩张”的长期原则。

### S17｜伙伴想借一笔主角认为“数学上合理、人生上不值”的债
- **Situation：** 条件上可承受，但代价是失去几年某项修炼选择。
- **Who wants what：** 伙伴急于追上队伍；主角想阻止；伙伴不愿永远被保护。
- **Collision：** 主角的看债能力不能变成替别人决定人生。
- **Why only this book：** “看见成本”与“有权替人选择”发生冲突。
- **Reader reward：** relationship / decision。
- **Permanent residue：** 伙伴拥有自主借债边界，关系从保护/被保护转向平等。

### S18｜主角自己的债被竞争者买到影响权
- **Situation：** 一笔天债允许债权关系在特定条件下转移。
- **Who wants what：** 对手要获得对主角未来资源的控制；主角要阻断。
- **Collision：** 主角不是只读别人的账，自己的债也会成为可争夺资产。
- **Why only this book：** 债务网络能把战斗延伸到资产和身份控制。
- **Reader reward：** tension / reversal / asset。
- **Permanent residue：** 主角以后更谨慎设计债权归属，旧敌关系进入长期账本。

### S19｜第一次用债务组合而非单笔赊境
- **Situation：** 单笔大债太危险，主角把目标拆成数个不同期限/担保结构。
- **Who wants what：** 他要完成大突破；同伴担心复杂结构一旦连锁会更危险。
- **Collision：** 组合降低单点风险，却创造联动风险。
- **Why only this book：** 后期玩法来自旧债组合，而不是无限发明新债种。
- **Reader reward：** power / strategy / discovery。
- **Permanent residue：** 形成可复用的个人债务结构，同时增加长期管理复杂度。

### S20｜债务结构影响宗门内部权力
- **Situation：** 掌握大量担保关系的人实际拥有比职位更大的影响力。
- **Who wants what：** 名义掌门要维持秩序；担保人集团要政策倾斜；主角要避免宗门被债务关系架空。
- **Collision：** 修行金融开始改变组织政治。
- **Why only this book：** 天债不是背景设定，而能真实重排权力。
- **Reader reward：** status / organization / discovery。
- **Permanent residue：** 宗门治理规则改变；主角获得或失去制度性权力。

### S21｜早期互保伙伴替主角挡下一次信用崩塌
- **Situation：** 主角因连续大动作信用骤降，无法取得关键资源。
- **Who wants what：** 他要撑过短期；S05建立的伙伴愿意用自己的信用担保。
- **Collision：** 早期关系资产第一次在更大局面反向救主角。
- **Why only this book：** “信用”让关系可跨几十个Seed复利，而不是友情口号。
- **Reader reward：** relationship / compounding / survival。
- **Permanent residue：** 双方债务绑定更深，也留下未来必须偿还的人情与信用成本。

### S22｜一笔债的成本不是掉境，而是失去某段记忆/感知
- **Situation：** 主角看见一种非常诱人的赊境方案，代价不伤修为却伤人生能力。
- **Who wants what：** 他需要短期力量；亲近者反对拿不可逆个人部分交换。
- **Collision：** “能承受”与“愿不愿支付”被区分。
- **Why only this book：** 天债真实成本可以让主角价值排序显形，但仍属于同一赊境规则。
- **Reader reward：** decision / relationship / discovery。
- **Permanent residue：** 主角建立不可抵押清单，限制未来选择。

### S23｜区域资源价格因集体赊境上涨
- **Situation：** 大量修士同时借境争同一秘境，后续偿债所需药材价格暴涨。
- **Who wants what：** 众人要先借先抢；主角要提前锁资源或避开拥挤债务。
- **Collision：** 个体行为形成市场级后果。
- **Why only this book：** 天债会真实影响灵药、法器、劳力与资源周期。
- **Reader reward：** asset / discovery / status。
- **Permanent residue：** 主角建立第一条长期资源储备/供应关系。

### S24｜敌对宗门把债务转嫁给附庸
- **Situation：** 大宗门维持高境界战力，实际靠附庸承担担保与偿债。
- **Who wants what：** 大宗要维持霸权；附庸要活；主角看到一套系统性外部化结构。
- **Collision：** 击败高手不是关键，切断债务转嫁链才会改变格局。
- **Why only this book：** 强者资源优势与弱者负债是同一因果。
- **Reader reward：** discovery / organization / reversal。
- **Permanent residue：** 主角与附庸群体形成长期联盟；区域信用秩序开始松动。

### S25｜主角有能力成为别人最想找的担保人
- **Situation：** 信用与资产增长后，大量人想借他的担保。
- **Who wants what：** 别人想借他的信用上杠杆；主角想扩大网络又避免变成人形银行。
- **Collision：** 每多一份担保都可能带来关系、收益与连锁风险。
- **Why only this book：** 地位成长自然转化为“信用资源分配权”。
- **Reader reward：** status / asset / decision。
- **Permanent residue：** 主角建立有限担保规则与固定圈层，长期关系网络成形。

### S26｜一次集体违约迫使主角选谁救
- **Situation：** 区域灾害让多个固定伙伴同时触发债务。
- **Who wants what：** 每个人都想保住境界/生命；主角资源不足以全部重组。
- **Collision：** 过去建立的担保网络第一次成为残酷选择，而非纯资产。
- **Why only this book：** Old-State越深，系统性风险越真实。
- **Reader reward：** relationship / tragedy / decision。
- **Permanent residue：** 至少一段关系或资产永久损失，幸存者对主角的信任重新分层。

### S27｜城市级统一催债
- **Situation：** 一座修士城在某天大量债务同时到期，战力、交通、阵法与生产一起跌落。
- **Who wants what：** 城主想保核心；商会想保资产；普通修士要活；主角被要求提供信用方案。
- **Collision：** 主角不能靠一人借境解决系统性信用危机。
- **Why only this book：** 个人Premium自然放大到城市基础设施与社会秩序。
- **Reader reward：** spectacle / organization / status。
- **Permanent residue：** 主角若参与担保，将获得城市级资源权/政治责任，且承担长期信用负担。

### S28｜早期破产宗门资源在城市危机中成为缓冲池
- **Situation：** S12得到的灵脉/道统资产成为少数无债资源。
- **Who wants what：** 城市想征用；旧弟子要保家底；主角要决定是否拿长期资产救眼前危机。
- **Collision：** 早期资产真正回到后期改变大局。
- **Why only this book：** “接烂债换来的无债资产”在系统性催债中价值暴涨。
- **Reader reward：** compounding / asset / decision。
- **Permanent residue：** 资产地位永久升级，同时主角背上公共承诺。

### S29｜真实境界终于超过曾经最常借到的临时境界
- **Situation：** 主角靠多年资源沉淀，真实修为走到过去只能赊来的高度。
- **Who wants what：** 他要证明自己不是永远靠信用活着；旧敌仍把他看成“借来的强者”。
- **Collision：** 一场不借境的硬战成为身份结算。
- **Why only this book：** Premium最满足的果实之一是把“借来的未来”真正变成自己的现在。
- **Reader reward：** power / status / payoff。
- **Permanent residue：** 社会身份从投机赊境者变为真正强者，债务工具进入更高层。

### S30｜越强越难找到“没人负责”的债
- **Situation：** 主角进入高层后发现每笔大额天债都牵连宗门、城池或血脉。
- **Who wants what：** 他想继续借力；又不愿把成本隐形转给弱者。
- **Collision：** 高层赊境的“便宜”往往只是有人替你付。
- **Why only this book：** 看见真实成本让主角越强越难装作不知道。
- **Reader reward：** discovery / moral pressure。
- **Permanent residue：** 高阶借境策略转向更高自担比例，成长速度与责任同步改变。

### S31｜敌人不再和他比境界，开始攻击信用
- **Situation：** 对手通过造谣、违约诱导、资源封锁让市场怀疑主角的偿债能力。
- **Who wants what：** 对手要让他拿不到赊境；主角要证明信用不是舆论数字。
- **Collision：** 战斗从拳头扩张到长期履约记录与资产稳定性。
- **Why only this book：** 信用本身就是力量入口。
- **Reader reward：** status / reversal / asset defense。
- **Permanent residue：** 主角的资产透明度、盟友担保和公众信用形成新防线。

### S32｜一笔“绝对划算”的债要求抵押团队自主权
- **Situation：** 天债条件允许主角获得巨大力量，但失败时团队某项资源自动被接管。
- **Who wants what：** 主角想赢大局；团队不愿被当成他的抵押物。
- **Collision：** 主角个人信用成长碰到组织所有权边界。
- **Why only this book：** 天债可把个人决策外溢成真实组织风险。
- **Reader reward：** relationship / decision / organization。
- **Permanent residue：** 团队确立“哪些集体资产任何个人都无权抵押”的制度。

### S33｜上界势力把整个下界当担保品
- **Situation：** 主角第一次看见更高层的境界融资，其抵押不是个人资源而是一整片区域未来产出。
- **Who wants what：** 上界势力要维持突破；下界只感到资源越来越少；主角要判断是否介入。
- **Collision：** Premium从个人债扩张到世界资源分配，但根规则不变。
- **Why only this book：** 世界规模越大，“谁在享受借来的境界、谁在支付真实成本”越尖锐。
- **Reader reward：** spectacle / discovery / macro promise。
- **Permanent residue：** 主角进入更高债权结构，旧区域资产与关系被重新定价。

### S34｜主角第一次拒绝最高额度
- **Situation：** 天道给出远超以往的赊境额度，足以让他一步登天。
- **Who wants what：** 外界期待他继续借；主角已经拥有足够真实资产。
- **Collision：** 最高额度不再等于最大机会。
- **Why only this book：** 长篇成长让“能借多少”与“要不要借”彻底分离。
- **Reader reward：** character / status / reversal。
- **Permanent residue：** 信用从生存工具变成主角可主动放弃的选择权。

### S35｜真正的大结算：一座秩序不再靠永续滚债维持
- **Situation：** 主角控制的区域能够靠真实灵脉、生产与修士成长支撑，不必不断赊新境补旧债。
- **Who wants what：** 旧利益集团靠滚债获利；普通修士想稳定；主角要证明“借”可以是工具而非生存常态。
- **Collision：** 最终挑战不是消灭天债，而是建立不用永远借未来才能活的修行资产结构。
- **Why only this book：** Premium完成从个人套利到制度级信用选择，仍然围绕同一根机制。
- **Reader reward：** asset / organization / thematic payoff。
- **Permanent residue：** 一套长期可持续的修行资源秩序，且主角仍保留赊境作为高风险战略工具。

## Stress Findings

### Reward Sameness
**PASS WITH WARNING。**
前段容易出现“看见一笔更划算的债→借境→赢”的重复风险；但自然扩展后能产生：
- 真实境界沉淀；
- 担保关系；
- 坏账与重组；
- 破产资产收购；
- 团队/宗门治理；
- 资源市场波动；
- 城市级系统性催债；
- 个人信用与公共责任。
只要坚持“借境必须沉淀永久资产”，奖励不会只剩聪明套利。

### Premium Survival
**STRONG PASS。**
Seed 1—10以个人赊境为核心；11—25进入宗门/担保/资产；26—35进入区域与上界资源秩序。规模越大，Premium越重要而非稀释。

### Old-Asset / Old-State Compounding
**VERY STRONG PASS。**
- S05伙伴在S21成为信用救命资产；
- S12破产道统在S28成为城市危机缓冲池；
- S06/S08担保与坏账持续改变后续关系；
- 主角早期信用记录持续决定S25以后可调动的资源和责任。

### Case-Supply Dependency
**LOW–MEDIUM。**
单笔债天然有“新金融Case”诱惑，但发动机不必依赖不断新增陌生债种。固定人物、既有债务、资产、信用网络与组织层级足以复利。执行时若每5章只换一笔奇怪债，会退化成Case-of-Week。

### Natural Stop
35个Seed后概念仍可扩展，但继续生成会更多依赖新地区具体债务产品。已有足够证据验证长篇发动机，因此停止。

## Qualifier Verdict

> **REVIVAL OPENING-ARC ELIGIBLE**

硬警告：
- 不要写成金融术语课；
- Opening Arc必须让“借来的境界→永久果实”快速兑现；
- 至少有一个固定伙伴/固定资产进入第一轮复利，避免连续陌生人问债。
