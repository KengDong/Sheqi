## Frozen Premium

> 主角可以给自己的异能追加公开、不可撤销的使用限制；限制越苛刻，能力的强度、范围或精度越高。敌人知道限制后也能针对。成长不是“解除限制”，而是在永久自缚与现实责任之间设计更强的自己。

## Situation Seeds

### S01｜第一条限制真的永久生效
- **Situation：** 主角为救人公开追加“十秒只能出一拳”。
- **Who wants what：** 他要在低等级时打穿强敌；队友怕他把能力永久废掉。
- **Collision：** 限制一旦说出口就不可撤销，胜利也不能收回。
- **Why only this book：** 爽点与永久自残是同一动作。
- **Reader reward：** power / spectacle / tension。
- **Permanent residue：** 核心异能威力跃升；攻击节奏永久改变。

### S02｜第一次发现限制也影响日常
- **Situation：** 战后主角在普通训练/工作中也必须遵守S01。
- **Who wants what：** 教官要他提高基础输出；主角发现“十秒一拳”让常规流程变难。
- **Collision：** 战斗爽点留下生活成本。
- **Why only this book：** 限制不是副本BUFF，现实持续生效。
- **Reader reward：** humor / consequence / character。
- **Permanent residue：** 主角重新训练移动、格挡与队友协同。

### S03｜敌人第一次卡他的十秒窗
- **Situation：** 对手精确计算出手间隔。
- **Who wants what：** 对手要逼他在错误时机用拳；主角要不用新增限制也破局。
- **Collision：** 公开规则让外挂变成可反制结构。
- **Why only this book：** 敌人能研究主角自己写下的“说明书”。
- **Reader reward：** combat / reversal。
- **Permanent residue：** 主角形成非攻击动作的稳定战斗体系。

### S04｜第二条限制不是更狠，而是改变用途
- **Situation：** 主角需要保护大群平民而非单杀。
- **Who wants what：** 他要扩大防护能力；组织希望他选通用增幅。
- **Collision：** 他追加“只为保护非战斗人员时生效”，获得巨大守护范围，却永久排除大量场景。
- **Why only this book：** 新能力来自价值取舍，不是技能树点数。
- **Reader reward：** power / relationship / spectacle。
- **Permanent residue：** 守护型能力永久成形，战斗定位被重写。

### S05｜一条限制让他错失简单胜利
- **Situation：** 敌人故意把战场清空平民，使S04无法触发。
- **Who wants what：** 主角想赢；队友希望他不要临场再加条款。
- **Collision：** 旧限制真正制造失败风险。
- **Why only this book：** 永久限制若只带来好处就不是Premium。
- **Reader reward：** failure / tension。
- **Permanent residue：** 团队开始围绕“如何创造合法触发条件”制定协同。

### S06｜限制第一次改变队友选择
- **Situation：** 新队员擅长快速连击，和主角节奏冲突。
- **Who wants what：** 组织想塞最强个人；主角要找能填十秒空窗的人。
- **Collision：** “最强队友”不等于“最适合限制结构的队友”。
- **Why only this book：** 限制会塑造关系与编队，而非只是个人数值。
- **Reader reward：** relationship / organization。
- **Permanent residue：** 第一位真正互补的长期队友加入。

### S07｜公众开始模仿他的限制
- **Situation：** 主角公开视频后，年轻异能者觉得“加限制就能变强”。
- **Who wants what：** 模仿者要捷径；主角要阻止不可逆误伤。
- **Collision：** 他的成功制造社会示范风险。
- **Why only this book：** 成长方式本身可以成为公共争议。
- **Reader reward：** status / consequence。
- **Permanent residue：** 主角形成公开解释责任；组织制定限制登记与冷静期。

### S08｜一条限制绑定了错误对象
- **Situation：** 主角为提升追踪精度，限制能力只能追“自己亲眼见过的人”。
- **Who wants what：** 他要解决当前危机；之后却发现陌生威胁完全无法追踪。
- **Collision：** 当场合理的永久选择在后续地图变成硬短板。
- **Why only this book：** 早期能力设计会长期锁定未来。
- **Reader reward：** discovery / consequence。
- **Permanent residue：** 追踪能力强但窄，后续必须靠队伍而非修改规则补洞。

### S09｜对手伪造触发条件
- **Situation：** 敌人利用“保护陌生人”限制，伪装无辜者骗出主角最强防护。
- **Who wants what：** 敌人要耗掉窗口；主角要判断而不能违反公开定义。
- **Collision：** 善意限制被对手当作攻击面。
- **Why only this book：** 条款语义直接进入战斗。
- **Reader reward：** reversal / tension / discovery。
- **Permanent residue：** 主角团队建立身份核验流程，但不能改变既有限制。

### S10｜第一次靠旧限制组合，而不是再加新限制
- **Situation：** 面对高阶敌人，主角没有新条款可安全承担。
- **Who wants what：** 他要越级；队友担心他上瘾式追加限制。
- **Collision：** 他用“十秒一拳”与“保护陌生人”组合出新的战场节奏。
- **Why only this book：** 长篇必须证明旧限制能组合复利。
- **Reader reward：** combat / reversal / mastery。
- **Permanent residue：** 一套组合打法成熟，减少对“新限制果实”的依赖。

### S11｜组织要求他追加一种“工作限制”
- **Situation：** 上级认为某条新限制能让任务效率大增。
- **Who wants what：** 组织想把主角当可定制武器；主角要保留身体与人生自主权。
- **Collision：** 谁有资格决定不可撤销限制成为权力问题。
- **Why only this book：** 升职/任务会直接诱惑机构侵入主角的永久能力设计。
- **Reader reward：** status / decision / relationship。
- **Permanent residue：** 主角取得“限制只能本人自愿追加”的制度先例。

### S12｜限制和私人承诺撞车
- **Situation：** 某条限制要求能力只在“退无可退”时启动，家人却希望他别总把自己逼到绝境。

### S13｜一次任务因为限制无法完成
- **Situation：** 目标必须活捉，而主角最强一击过于致命。

- **Collision：** 越强的限制构筑越可能在某些任务里不适配。
- **Why only this book：** 能力升级不是全面上位替代。

- **Who wants what：** 对手要诱导自残式升级；公众想看更强场面；主角要拒绝被期待操纵。

- **Why only this book：** Premium本身能形成粉丝与舆论压力。
- **Reader reward：** status / character / reversal。

### S15｜一条旧限制在救援中意外变成巨大优势

### S16｜队友主动给自己设协同约束

- **Who wants what：** 队友想形成固定节奏；主角不愿别人复制不可逆风险。
- **Collision：** 他们只能用训练纪律而非超凡永久限制来适配。
- **Why only this book：** 主角规则影响整个团队，但不能把第二核心系统扩给所有人。

- **Reader reward：** discovery / failure。
- **Permanent residue：** 团队建立限制组合审计，主角不能只看单条收益。

- **Why only this book：** 公共可验证性决定智斗公信力。
- **Reader reward：** reversal / discovery / status。
- **Permanent residue：** 限制登记标准更严格，主角以后无法模糊措辞套利。

### S20｜一次无法追加限制的长周期
- **Situation：** 主角发现身体/能力结构已接近复杂度极限。
- **Who wants what：** 他要继续成长；组织期待新招；敌人研究旧规则。
- **Collision：** 只能靠训练、队伍、职位和旧组合继续，而不能靠“再加一条”续命。
- **Why only this book：** 对Premium进行反压力测试：没有新收藏品时故事是否仍活。

- **Permanent residue：** 旧限制进入深度组合期，成长轴从数量转向运用质量。

- **Who wants what：** 市民愿意跟随疏散；敌人想利用这种信任制造人盾。

### S22｜队友因主角限制受伤，要求重新分工

### S23｜限制让升职变得复杂

- **Who wants what：** 主角要更高权限；评审要可靠通用性。
- **Collision：** 战力强不自动等于组织地位高。

- **Permanent residue：** 主角第一次明确自己的限制设计原则，后续不再只看倍率。

### S25｜旧限制使主角在城市级灾害中成为唯一可用的人

### S27｜公开限制被城市敌人做成教材

### S28｜无法用最强能力保护最亲近的人

### S30｜旧限制成为训练新人的教材
- **Situation：** 主角开始带新人，不能让他们学“越狠越好”。
- **Who wants what：** 新人崇拜极端限制；主角要教判断与承担。

### S31｜城市规则要求限制者公开注册

- **Who wants what：** 社会要安全；主角本来就依赖公开，但不愿所有战术细节被强制集中。

- **Reader reward：** status / organization / decision。
- **Permanent residue：** 主角参与建立兼顾公开可验证与安全的制度，公共身份升级。

### S32｜后期证明：最早的限制仍在决定终局
- **Situation：** 大规模危机中，所有高阶能力都被干扰，主角最早那条简单“十秒一拳”仍可靠生效。
- **Who wants what：** 主角要用多年围绕它形成的节奏带队；敌人以为老限制已过时。
- **Collision：** 最早资产没有被新能力淘汰，而成为整套体系的节拍器。
- **Why only this book：** Old-State复利而非技能替换。
- **Reader reward：** spectacle / compounding / payoff。
- **Permanent residue：** 主角的限制体系完成从“自缚换倍率”到“塑造战斗者、团队与公共身份”的长期闭环。

## Stress Findings

### Reward Sameness
**PASS WITH MEDIUM WARNING。**
最明显危险是“再加一条更酷限制”。但S10、S20以后即使冻结新增限制，旧限制仍能自然产生：
- 敌人反制；
- 队伍重组；
- 公共信任；
- 职业路径；
- 关系代价；
- 法规治理；
- 旧限制组合与重估。
因此Root Engine并不依赖无穷新限制，但正文必须主动避免收藏癖。

### Premium Survival
**STRONG PASS。**
后期限制不只是战斗倍率，而成为主角的人格、公众信用、职业结构和组织治理问题。规模越大，公开且不可撤销的Premium越难绕开。

### Old-Asset / Old-State Compounding
**VERY STRONG PASS。**
S01的十秒限制持续影响S03、S06、S15、S22、S32；S04的陌生人保护限制在S09、S21、S28持续重估。早期选择无法洗点，天然复利。

### Case-Supply Dependency
**LOW。**
新怪物/新任务并非必须燃料。固定队友、公众、组织、旧限制和对手学习就能持续产生冲突。执行层若每次靠“新限制打新怪”则会人为退化。

### Natural Stop
32个Seed后，已经验证“新增限制”和“冻结限制”两种阶段都能继续。再扩更多主要会进入具体城市事件，因此停止。

## Qualifier Verdict

> **REVIVAL OPENING-ARC ELIGIBLE**

Opening Arc硬验证：
- 第一条限制必须立即留下生活/战斗两面的永久成本；
- 第一轮高潮前必须出现敌人或现实利用限制反制；
- 不允许靠连续追加三条限制制造爽感。
