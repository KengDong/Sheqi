## Frozen Premium

> 主角是维修高手，但不把修好的旧设备一次性卖掉；他低价收下报废或闲置的商用设备，修复后租给小商户，逐台积累长期现金流资产。成长单位不是“又接一单维修”，而是设备资产、租金、客户网络、维修能力、仓储与服务体系。

## Situation Seeds

### S01｜第一台冰柜：修好但不卖
- **Situation：** 主角低价收下一台被判废的商用冰柜，修复后有人愿意高价一次性买走。
- **Who wants what：** 主角缺现金；买家要便宜设备；他却想测试租赁现金流。
- **Collision：** 卖掉立刻回血，出租要承担故障、违约和回本周期。
- **Why only this book：** 核心选择是把维修技能变成长期资产，而非工钱。
- **Reader reward：** asset / decision / life improvement。
- **Permanent residue：** 第一台可出租设备与第一份月租合同。

### S02｜第一笔“没干活也到账”的租金
- **Situation：** 主角当天没有维修订单，租金却按时到账。
- **Who wants what：** 他想证明模式成立；家人更关心这点钱够不够生活。
- **Collision：** 小额现金流的心理意义大于金额。
- **Why only this book：** 爽点不是一次赚大钱，而是劳动被沉淀成会继续赚钱的资产。
- **Reader reward：** life improvement / asset / emotional payoff。
- **Permanent residue：** 第一条稳定月现金流被确认。

### S03｜租客生意差，设备没坏也收不到钱
- **Situation：** 第一位客户营业不佳，开始拖租。
- **Who wants what：** 主角要回款；客户要继续用设备翻身。
- **Collision：** 设备租赁把“客户经营状态”变成主角资产风险。
- **Why only this book：** 修好机器只是开始，长期现金流要承担真实经营关系。
- **Reader reward：** relationship / tension / realism。
- **Permanent residue：** 第一笔坏账/展期经验，租赁条款改变。

### S04｜把坏账客户救活，比收走机器更划算
- **Situation：** 主角可以直接拉走设备，也可以帮客户调整设备配置和营业流程。
- **Who wants what：** 主角要长期租金；客户要店活下去。
- **Collision：** 维修工开始被迫理解客户生意。
- **Why only this book：** 资产出租自然把主角从技术工推向商户基础设施伙伴。
- **Reader reward：** relationship / asset / competence。
- **Permanent residue：** 客户稳定下来，形成长期推荐来源。

### S05｜第二台设备不能只是复制第一台
- **Situation：** 主角有机会收一台烤箱或再收冰柜。
- **Who wants what：** 他要扩大资产池；资金有限。
- **Collision：** 同类设备维护简单但客户集中，异类设备能拓客却提高维修复杂度。
- **Why only this book：** 设备组合本身是经营策略。
- **Reader reward：** asset / decision / anticipation。
- **Permanent residue：** 资产池出现第二品类，维修备件结构改变。

### S06｜旧零件第一次反过来救资产
- **Situation：** 第一台冰柜故障，原厂零件停产。
- **Who wants what：** 租客要马上恢复营业；主角不想换整机。
- **Collision：** 早期收下的一堆拆机件第一次变成高价值库存。
- **Why only this book：** 旧设备、旧零件可长期复利而非一次性垃圾。
- **Reader reward：** competence / compounding / asset defense。
- **Permanent residue：** 建立拆件库存与兼容件数据库。

### S07｜设备坏一次，主角赔的不只是维修费

- **Collision：** 长期租赁把可靠性责任变成真实商业风险。
- **Why only this book：** 资产所有权意味着故障后果不会甩给买家。
- **Reader reward：** failure / relationship / realism。
- **Permanent residue：** 维修响应、赔付上限、备用机制度建立。

### S08｜第一台备用机看似不赚钱

- **Who wants what：** 家人觉得资金压死；主角要降低停机损失。
- **Collision：** 闲置资产短期降低收益率。
- **Why only this book：** 资产池规模开始产生“冗余也有价值”的运营逻辑。
- **Reader reward：** asset / decision。
- **Permanent residue：** 第一台战略备用设备。

### S09｜备用机第一次救下老客户

- **Collision：** 过去看似闲置的资产突然兑现价值。
- **Why only this book：** Old-Asset能通过服务网络重新定价。
- **Reader reward：** compounding / relationship / competence。
- **Permanent residue：** 客户续签更长期合同，主角服务信誉上升。

### S10｜客户从租一台变成租一套

- **Why only this book：** 旧客户不是完成的Case，会随着生意成长带来新资产关系。
- **Reader reward：** asset / status / relationship。

### S11｜客户倒闭，机器被锁在店里

- **Collision：** 所有权、占有与现实执行发生冲突。
- **Why only this book：** 租赁资产会产生与二手买卖完全不同的法律/运营问题。

### S12｜一台老机器账面早回本，却仍然是最好资产

- **Who wants what：** 商户要尽快复业；员工要守住服务承诺；主角必须调动仓储、备件、备用机、维修队、客户网络共同工作。
- **Collision：** 如果长篇只剩“再修更贵设备”，Premium就失败；真正升级是旧资产组合成为区域基础设施。
- **Why only this book：** “修旧设备不卖”最终复利成会持续运转的设备服务网络。
- **Reader reward：** macro payoff / status / asset / relationship。
- **Permanent residue：** 主角身份从维修工/出租人升级为一片区域的小商户设备基础设施提供者。

## Stress Findings

### Reward Sameness
**PASS WITH MEDIUM WARNING。**
最明显重复风险是“低价收一台→修好→出租→收租”。但从S03开始自然出现：
- 坏账与客户经营；
- 备用资产；
- 旧零件库存；
- 成套设备；
- 资产取回；
- 员工与质检；
- 仓储；
- 利用率/淘汰；
- 区域集中风险；
- 客户成长与买断；
- 服务合同与网络。
只要正文把“机器”当长期资产和关系节点，而不是每章换新品，水库不单一。

### Premium Survival
**STRONG PASS。**
早期是“维修变资产”，中期是“资产池变现金流与服务”，后期是“旧设备网络变小商户基础设施”。规模越大，持有而非卖出的意义越强。

### Old-Asset / Old-State Compounding
**VERY STRONG PASS。**
- S01第一台冰柜在S12、S27持续重估；
- S06拆件库存持续降低后续维修风险；
- S08备用机在S09、S22、S32多次改变局势；
- S04老客户在S10、S19、S24持续成长；
- 仓库、团队、维修记录、客户网络全部是复利资产。

### Case-Supply Dependency
**LOW–MEDIUM。**
设备/客户天然可以形成新Case，但并非必须。固定老客户、旧设备池、员工、仓库、现金流、备件与区域风险足以产生大量后续故事。若正文只靠“今天又收到一台奇怪机器”，会退化成维修Case-of-Week。

### Natural Stop
34个Seed后，长篇升级已从单机跨到服务网络；再扩会更多进入具体行业设备种类，边际验证价值下降，因此停止。

## Qualifier Verdict

> **REVIVAL OPENING-ARC ELIGIBLE**

Opening Arc硬验证：
- 第一台设备必须很快落成长期资产，而不是修好就结束；
- 第一轮高潮前至少让同一台设备/同一客户二次回返，证明“旧资产会复利”；
- 不能用连续新设备奇观顶替人物、现金流和责任增长。
