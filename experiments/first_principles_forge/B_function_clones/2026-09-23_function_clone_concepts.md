# F1｜World Expansion

## F1-1｜《借我一个关系》

1. **One-Line Promise**  
   为了让妹妹留在一座资格壁垒极高的城市读完高中，一个临时工开始出租自己的“合法关系身份”——哥哥、担保人、紧急联系人、学徒介绍人、遗产联系人；每接一单，他就进入一个全新的社会系统，也背上一份真的会追到家里的义务。

2. **Protagonist Desire**  
   在妹妹下一学年资格复核前，凑齐稳定居住、担保与学籍所需条件，让她不用再次转学。

3. **Unique Rule / Situation**  
   城市允许“关系代理”：部分社会资格可以由持牌第三方临时补足，但代理关系在合同期内具有真实法律责任，不能只收钱不承担后果。

4. **Five Must-See Situations**
   - 他第一次代签“成年子女”，在陌生老人的手术门口被迫替家属做决定。
   - 他替年轻工人做就业担保，工伤发生后第一次知道“介绍人”也要进入赔偿链。
   - 他成为名校申请里的“校友关系人”，看见富人把亲缘、推荐与照护拆成可采购的服务。
   - 他替死者做遗产联系人，收到一笔原本与自己毫无关系的追债。
   - 当妹妹的资格终于只差最后一项时，他发现必须先解除一段已经变成真实牵挂的代理关系。

5. **One Character Pull**  
   一个专门审核关系代理的女核验员：她相信这套制度能给没有家庭资源的人第二条路，却越来越无法把“合同关系”和“真实关系”分开。

6. **Long Mutation**  
   主角从出售单个关系身份，变成横跨医疗、教育、就业、住房、遗产等系统的“关系节点”；他拥有越来越多入口，也越来越难回答自己到底是谁的家人、对谁负有责任。

7. **Non-Replaceability**  
   去掉“关系可以出租但义务真实存在”的规则，手术签字、工伤担保、学籍资格、遗产追债、妹妹复核这些核心场面会整体失效，不可替换成普通打工升级。

8. **Engine Hypothesis**  
   普通欲望“让妹妹稳定读书”持续把主角推入不同社会系统；每次进入都产生新动作、新关系、新成本、新可能性，Expansion 不靠换地图，而靠角色身份真的被系统重新定义。

## F1-2｜《排到你之前》

1. **One-Line Promise**  
   为了给母亲抢到一场不能再拖的手术，一个送餐员进入“排队权交易”行业；他替别人等待、换位、转让、押注顺序，逐渐发现这座城市最稀缺的不是钱，而是谁能排在谁前面。

2. **Protagonist Desire**  
   在母亲病情恶化前，把普通候诊序列换成可实际兑现的手术位。

3. **Unique Rule / Situation**  
   医疗、住房、入学、执照、诉讼等稀缺资源统一使用“实名等待时长”；等待权可以交换，但任何人想转让顺位，都必须由另一个真人在该系统里承担等量等待与资格审查。

4. **Five Must-See Situations**
   - 他在医院替陌生人排三十小时，第一次拿到能交易的医疗时长。
   - 他进入保障房队列，发现一套房子的顺位可以和一场手术的顺位交换，却对应完全不同的人生代价。
   - 他替创业者排经营许可，因资格审查被卷入对方隐瞒的违法风险。
   - 他发现富人并不直接买插队，而是长期雇人“养顺位”，形成看不见的时间资产池。
   - 城市突发公共事件时，他掌握的跨系统顺位第一次可以救人，也第一次可以伤害大量陌生人。

5. **One Character Pull**  
   一个永远排在别人前面的职业队列经纪人：她极度守规则，因为她小时候正是被一次非法插队毁掉了家庭。

6. **Long Mutation**  
   主角从替人消耗时间，变成能跨医院、住房、执照、法院调度“顺序”的人；他的资产不是现金，而是对城市稀缺入口的时间控制力。

7. **Non-Replaceability**  
   核心冲突不是资源本身，而是“顺位必须由真人时间铸成且可跨系统交换”；去掉该规则，主角的职业动作、社会扩张和道德压力同时消失。

8. **Engine Hypothesis**  
   母亲手术这个秒懂欲望提供持续方向；每种新队列都是一个不同社会系统，而“等待什么、替谁等、拿什么换”天然制造新的动作与成本。

## F1-3｜《住址附带义务》

1. **One-Line Promise**  
   为了给自己和父亲找一个不会再被赶走的家，一个年轻维修工租下全城最便宜的公寓，却发现这里的低房租不是福利——每个住址都附带一份必须由居民亲自履行的社区义务。

2. **Protagonist Desire**  
   在父亲出院前保住一套长期住址，不再因为搬家失去工作、医疗和生活连续性。

3. **Unique Rule / Situation**  
   城市住房不是单纯租赁：每个地址绑定一项公共义务，可能是夜间巡查、老人照护、儿童接送、纠纷调解、防洪值守、公共维修；越便宜的住址，义务越重且越不可外包。

4. **Five Must-See Situations**
   - 他第一次看房时发现“低价一居室”附带每周两晚老人夜间应急值守。
   - 一次儿童接送义务和他的正式工作撞班，他必须决定保工作还是保住址。
   - 他进入高档封闭社区维修，发现有钱人正通过复杂合同把义务转嫁给外围街区。
   - 暴雨夜里，平时最不起眼的防洪住户突然获得封路和征用设施的临时权力。
   - 父亲终于可以长期居住时，主角却已经掌握多个社区之间谁在承担谁的生活成本。

5. **One Character Pull**  
   同楼的单亲母亲兼社区调解员：她比任何人都擅长利用住址规则，却最想让孩子长大后彻底离开这套制度。

6. **Long Mutation**  
   主角从“只想住下来”变成连接多个社区义务网络的人；住房逐渐不只是居所，而是照护、治安、教育、资源分配和地方权力的入口。

7. **Non-Replaceability**  
   便宜房与真实公共义务绑定，使每次住房选择都直接生成行动、关系和社会成本；普通租房题材无法自然产生同样的社区权力与责任交换。

8. **Engine Hypothesis**  
   “保住一个家”是稳定欲望；每一种地址义务都打开一个新的社会接口，并迫使主角改变生活方式，因此世界扩张和人物选择是同一件事。

# F2｜Mystery Recontextualization

## F2-1｜《父亲每个决定都有第二份理由》

1. **One-Line Promise**  
   一个准备卖掉父亲旧店离城的女儿发现，父亲生前每份重要合同都留有一份密封“真实理由”；每拆开一份，旧事都会换一个意思，并立刻改变她现在能卖什么、欠谁什么、还能相信谁。

2. **Protagonist Desire**  
   在债权人冻结资产前处理完旧店、还清债务、离开这座让她厌倦的城市。

3. **Unique Rule / Situation**  
   重大合同允许当事人向公证机构提交一份“私密真实理由”；平时永久封存，但合同被继承、挑战或产生重大损害时必须开启，且内容可能触发合同撤销、补偿或受益人变更。

4. **Five Must-See Situations**
   - 店铺产权被挑战，第一份理由显示父亲买店不是为了自己，而是替另一个人保住生计。
   - 她准备裁掉老员工时，旧解雇合同的真实理由证明父亲当年是在替此人挡一次刑责。
   - 一笔看似愚蠢的高息贷款被拆封后，暴露母亲账户里从未解释过的一笔钱。
   - 医疗同意书的第二理由推翻全家对一次死亡的共同记忆，迫使她重新选择是否起诉医院。
   - 最关键的一份理由一旦公开，可以救下旧店，却会毁掉一个她刚刚重新信任的人。

5. **One Character Pull**  
   父亲昔日合伙人：他每次都像是最懂真相的人，却又总有充分理由阻止下一份密封理由被打开。

6. **Long Mutation**  
   主角从清算遗产，变成接管一张由旧决定、受益人、债务和隐瞒组成的现实网络；谜底越多，她越难“离开”，因为每个答案都给她新的责任与选择。

7. **Non-Replaceability**  
   关键不是“父亲有秘密”，而是秘密以具有现实法律后果的“第二理由”形式存在；答案天然重写合同、人物关系和当下选择，而不是只补背景。

8. **Engine Hypothesis**  
   每轮都必须先结算一个可验证答案，再让答案改变当前行动并制造更大问题；旧章节随新理由升值，Mystery 通过重估现实持续生长。

## F2-2｜《她没选的那些路》

1. **One-Line Promise**  
   为了寻找失踪的姐姐，一个弟弟开始依次启动她生前在重大决定中“没有选择的那条路”；每走一次姐姐曾拒绝的人生，他都更接近她，也更不确定自己过去认识的是不是同一个人。

2. **Protagonist Desire**  
   在法定失踪期限结束前找到姐姐，避免她被宣告死亡并让家庭资产被强制分割。

3. **Unique Rule / Situation**  
   每份重大合同都必须登记一个“被拒绝的备选项”；当签约人失踪达到法定期限，指定受益人可以把其中一个备选项激活一次，但必须完整承担那个选择原本对应的义务。

4. **Five Must-See Situations**
   - 他激活姐姐拒绝的外地工作，进入一个所有同事都以为她迟早会来的部门。
   - 他接手她没租下的公寓，发现房东保存着与家人记忆完全冲突的生活痕迹。
   - 他启动她放弃的贷款方案，才知道姐姐当时真正害怕的不是负债，而是某个共同借款人。
   - 一份没生效的监护协议把一个孩子真实地交到他面前，迫使他决定是否继续查下去。
   - 他终于碰到一个能解释失踪的备选项，却必须先做出姐姐当年明确拒绝过的选择。

5. **One Character Pull**  
   姐姐曾拒绝合作的前同事：她对姐姐既愤怒又忠诚，坚称“她不是失踪，她只是终于选了没人知道的第三条路”。

6. **Long Mutation**  
   主角从寻找一个人，变成亲自经历她放弃的人生分叉；答案不断改变他对家庭、姐姐和自己未来的理解，并让“找到她”从地理问题变成人生选择问题。

7. **Non-Replaceability**  
   “被拒绝的选择可由受益人真实激活”让每个线索都必须付现实代价；去掉规则，故事会退化成普通失踪调查，无法让答案直接改变主角生活。

8. **Engine Hypothesis**  
   每个答案都通过一条被激活的未选路径兑现；答案不是信息奖励，而是一份新生活，因此天然完成 recontextualization + consequential choice。

## F2-3｜《救命债》

1. **One-Line Promise**  
   为了保住父亲留下的唯一房子，一个儿子必须逐一处理陌生人拿来的“救命债凭证”；但每笔债只要证明救人者曾制造危险就能失效，于是每次查清“谁救了谁”，都会重写父亲的一段人生。

2. **Protagonist Desire**  
   在遗产执行期限前保住房子，让仍住在里面的家人不被迫搬走。

3. **Unique Rule / Situation**  
   紧急救援可由双方事后登记为“生命债”；债务在本人死亡后自动转入遗产。继承人只有一种抗辩：证明债权人直接或间接制造了当时的致命风险。

4. **Five Must-See Situations**
   - 一个退休消防员拿着凭证出现，主角却查到那场火灾起因与他本人有关。
   - 父亲最讨厌的旧邻居竟持有有效救命债，而当年的“仇”可能是故意演给别人看的。
   - 一名护士的债权金额极低，却能证明父亲曾长期隐瞒一种疾病。
   - 一个陌生孩子成为最大债权人，线索指向父亲曾经救过、也可能伤害过的一整个家庭。
   - 主角发现只要推翻最后一笔债就能保住房子，但那等于公开父亲真正应该承担的责任。

5. **One Character Pull**  
   负责核验救命债的老调查员：他从不评价谁是好人，只问“危险是谁制造的”，因此一次次把主角逼回因果而不是情感判断。

6. **Long Mutation**  
   遗产纠纷逐渐变成一张“父亲如何介入别人命运”的因果地图；主角最终继承的不只是债，也是一组仍在继续发生的关系与后果。

7. **Non-Replaceability**  
   每个谜底都直接决定债权是否成立、房子是否保得住、某个人是否要被追责；没有“救命债+制造危险抗辩”，调查与生活无法锁成一个发动机。

8. **Engine Hypothesis**  
   以具体债权为小结算单位：先回答一段旧事故，再让答案改变遗产、关系和下一笔债的意义，确保 Mystery 持续结算而不是只堆谜盒。

# F3｜Compounding Fantasy / Asset

## F3-1｜《答应过的事都会留下额度》

1. **One-Line Promise**  
   一个信用破产的维修工想重新开店，只能从替邻居完成最小的承诺开始；在这座城市，每个被公开验证的“说到做到”都会留下可用于担保更大事情的承诺额度。

2. **Protagonist Desire**  
   重新拿到足够信用，租下父亲留下的旧铺面并恢复营业。

3. **Unique Rule / Situation**  
   个人不能直接购买高等级信用；只有公开承诺被按时完成，才会累积“承诺额度”。额度可以用于担保合同、替他人背书、进入更高门槛的交易，但任何一次违约都会按杠杆放大损失。

4. **Five Must-See Situations**
   - 他靠连续三十天替老人送药，第一次从“没人肯赊一颗螺丝”变成能拿到小额账期。
   - 他用自己的额度替新学徒担保，第一次把个人信誉变成别人真实的人生机会。
   - 一家大公司高薪挖他，不是为了修东西，而是为了让他的承诺额度进入项目。
   - 他用积累多年的额度签下全街区公共维修，第一次拥有调动人、货、时间的能力。
   - 一个看似很小的私人承诺突然与大合同撞期，他必须决定保哪一个，而两边都会留下永久后果。

5. **One Character Pull**  
   一个从不欠人情的材料商老板娘：她信用极高，却拒绝替任何人担保，直到主角让她第一次愿意把自己的额度押在另一个人身上。

6. **Long Mutation**  
   主角从靠小承诺恢复生计，变成可以为团队、商户甚至社区提供信用基础设施的人；“他说一句话值多少钱”肉眼可见地改变他的工作、关系和权力。

7. **Non-Replaceability**  
   资产增长不是抽象数值，而是承诺额度带来的账期、担保、用人、合同和公共项目能力；去掉规则，重复“守信用”不会自然复利成新的行动空间。

8. **Engine Hypothesis**  
   同一个动作“承诺并兑现”可以无限重复，但每次留下更大的可调用信用资产；下一次承诺因此能触碰更昂贵的人和系统，形成清晰复利。

## F3-2｜《修一间，算我一份》

1. **One-Line Promise**  
   一个无力买房的维修工发现，只要把被判定为“不可用”的空间真正修回功能，就能永久获得那部分空间的一小份使用权；他从一间漏水地下室开始，慢慢把整座城市修成自己的资产地图。

2. **Protagonist Desire**  
   先拿到一个不再被房东赶走、能长期放工具和接活的固定工作间。

3. **Unique Rule / Situation**  
   对长期废弃或被判定失能的建筑空间，修复者可登记“功能修复权”：按恢复的具体功能获得永久收益分成、优先使用、通行或有限否决权，而不是取得完整产权。

4. **Five Must-See Situations**
   - 他修好一间没人要的地下室，第一次拥有每天两小时不可被收回的使用权。
   - 他救活一栋楼的旧电梯，获得跨楼层通行权，第一次让“修东西”变成空间控制力。
   - 他把废弃屋顶修成可运营场地，开始收到第一笔与劳动时间无关的持续收入。
   - 多个微小修复权拼起来后，他能让一条商业街在别人拒绝时仍然正常运转。
   - 大开发商准备整体拆迁，却发现主角手里的几十个微型权利足以让项目必须和他谈。

5. **One Character Pull**  
   专门收购残缺产权的女律师：她一开始只想低价买走主角的“碎权”，后来发现他正在创造一种她从没见过的城市资产。

6. **Long Mutation**  
   主角从为自己修一个角落，变成持有大量分散但关键的功能权；他不拥有整栋楼，却逐渐拥有城市“能不能正常运转”的一部分控制力。

7. **Non-Replaceability**  
   修复动作直接铸造永久微型权利，地下室、电梯、屋顶、商业街、拆迁谈判才能形成同一复利链；换成普通接维修单，所有长期积累都会消失。

8. **Engine Hypothesis**  
   每次修复都留下可见、可调用、可组合的资产；资产组合后解锁此前不可能完成的更大修复与谈判，满足 Compounding 的“拥有更多→能做更多”。

## F3-3｜《这座城我有路》

1. **One-Line Promise**  
   一个负债累累的骑手为了每天多跑几单，替陌生建筑解决小问题换取“永久通行权”；从一扇后门、一部货梯、一个屋顶开始，他逐渐拥有一张只有自己能走通的城市。

2. **Protagonist Desire**  
   在催债期限前把日收入提高到足以持续还款，而不是靠一次性冒险翻身。

3. **Unique Rule / Situation**  
   私人物业可以向完成指定服务的人授予登记通行权；一旦授予，除重大安全原因不得随意撤销。通行权可连接后门、货梯、连廊、屋顶、地下通道，但必须一处一处通过真实服务获得。

4. **Five Must-See Situations**
   - 他修好餐馆后门的排水，换到第一条能省八分钟的厨房穿行权。
   - 医院授予他夜间货梯权后，他第一次能承接别人做不到的紧急配送。
   - 学校屋顶与老商场连廊被两项独立通行权接上，城市第一次在他眼里出现“第二层道路”。
   - 一栋写字楼要求他用已有路线完成一次不可能的搬迁，成功后整片商务区被接入网络。
   - 灾害导致公共道路中断时，他积累的私人通路第一次成为可以疏散大量人的真实基础设施。

5. **One Character Pull**  
   一个长期查处违规穿行的物业安保主管：他最初把主角视为漏洞，后来发现主角拥有的每条路都是合法换来的。

6. **Long Mutation**  
   主角从优化个人配送路线，变成掌握跨建筑通行网络的人；速度优势逐步复利成物流能力、救援能力、议价权和城市级依赖。

7. **Non-Replaceability**  
   每条路线都必须由“服务→永久通行权”生成，并可与旧路线拼接；普通跑腿、地图探索或升级技能都无法替代这种可组合的空间资产。

8. **Engine Hypothesis**  
   核心动作始终是“解决一个具体问题，换一段路”；同样动作越做越值钱，因为新路与旧路产生网络效应，回报呈复利而非线性加点。

# F4｜Relationship × Life Interfaces

## F4-1｜《离婚以后，我们还是一个家庭单位》

1. **One-Line Promise**  
   一对刚离婚的前夫妻以为签字就能结束关系，却发现这座城市的家庭福利、住房、医疗、税务和债务要用三十六个月才能完成“家庭解绑”；他们越想各过各的，工作、父母、钱和新关系越会重新撞回彼此。

2. **Protagonist Desire**  
   A 想接受外地升职，彻底开始新生活；B 想保住现有住房并照顾即将手术的母亲，不让家庭解绑摧毁生活稳定性。

3. **Unique Rule / Situation**  
   家庭单位在法律解除后仍有三十六个月资产与福利解绑期；期间任何一方的收入、住址、医疗负担、新抚养关系和重大债务都会重新计算双方的住房、税费与保障资格。

4. **Five Must-See Situations**
   - A 的升职加薪让 B 的保障房资格突然超线，两人第一次因“成功”再次坐到谈判桌。
   - B 母亲手术需要旧家庭单位承担共付责任，A 必须决定是否继续做名义上的家人。
   - A 的新伴侣想共同买房，却发现旧家庭单位尚未退出贷款计算。
   - 一笔婚内从未说清的债务进入最终核验，迫使两人重新讨论当年谁替谁牺牲。
   - 解绑最后一天，一个能让其中一人彻底自由的选择会把另一人推入现实困境。

5. **One Character Pull**  
   两人共同认识多年的家庭财务顾问：他比他们更清楚这段婚姻在账本上留下了什么，却拒绝替任何一方判断感情值不值得继续。

6. **Long Mutation**  
   两人的目标不是简单复合或彻底断绝，而是不断重新定义“我们还欠彼此什么”；每次关系变化都会改写住房、职业、父母照护、债务和新伴侣的现实条件。

7. **Non-Replaceability**  
   三十六个月家庭解绑把情感余波变成持续的现实接口；去掉该制度，升职、手术、买房、债务、新关系无法稳定地反向撞进同一段关系。

8. **Engine Hypothesis**  
   双方都有独立且合理的生活欲望；每个生活系统都不是背景，而是迫使关系重新定价，关系变化又反过来改变下一次生活选择。

## F4-2｜《我们法律上是同一个人》

1. **One-Line Promise**  
   两个从未见过面的成年人突然发现，他们二十年来一直共享同一个国家身份编号；政府给他们一百八十天拆分人生，而每纠正一条记录，工作、房子、婚姻、病史、债务中就必定有一样要被判给另一个人。

2. **Protagonist Desire**  
   A 要保住靠该身份取得的职业执照；B 要保住已经还贷多年的住房与家庭登记，双方都无法接受“从零重来”。

3. **Unique Rule / Situation**  
   身份碰撞不能复制权益，只能逐项溯源并分配；任何历史记录只能归属于一人，另一人必须承担记录被移除后的现实后果。

4. **Five Must-See Situations**
   - 两人的工资账户同时被冻结，他们第一次见面就是为了决定谁先拿回“合法收入”。
   - A 的职业资格被追溯到 B 的学历记录，保住一个人的工作可能等于宣布另一个人学历无效。
   - B 的伴侣发现结婚登记在数据库里对应的是 A 的照片。
   - 一条重大病史必须归到其中一人名下，而保险理赔与真实健康风险指向不同的人。
   - 最后一组无法拆开的童年记录迫使他们面对：到底是谁的人生一直建立在另一个人的缺失上。

5. **One Character Pull**  
   负责拆分身份记录的年轻档案员：她坚持“数据只能有一个主人”，却越来越清楚现实中的人生从来不是可干净切开的文件夹。

6. **Long Mutation**  
   两人从争夺“谁是真的”，变成被迫共同维护、拆解并重新分配一段共享社会人生；敌意、依赖、愧疚和联盟会直接改变职业、住房、家庭与亲密关系。

7. **Non-Replaceability**  
   身份记录逐项只能归一人的规则让每一次关系变化都拥有外部现实后果；普通误会、失忆或双胞胎设定无法制造同样的制度性纠缠。

8. **Engine Hypothesis**  
   核心黏性来自“你得到的可能正是我失去的”；工作、房产、爱情、医疗、家庭持续进入两人关系，而两人的信任程度决定这些接口怎么被分配。

## F4-3｜《同住五年，房子才算我们的》

1. **One-Line Promise**  
   两个多年不来往的表亲共同继承一套合作住宅，但只有连续五年把它维持成“真实家庭住址”才能取得产权；一个急着卖房创业，一个必须靠这个地址让弟弟继续上学，他们只能在同一屋檐下把各自人生硬接在一起。

2. **Protagonist Desire**  
   A 想尽快兑现未来产权，为自己的小生意筹启动资金；B 想确保弟弟完成剩余学业，不再因住址变化被迫转学。

3. **Unique Rule / Situation**  
   合作住宅的继承不是立即过户，而是“共同居住归属”：指定继承人必须持续真实居住、共同承担房屋义务五年；空置、假住、单方退出都会使产权回到合作社。

4. **Five Must-See Situations**
   - 两人第一次制定冰箱、房租、访客和卧室边界时，已经在决定五年后谁能拿多少钱。
   - A 的创业客户把家当办公室使用，差点让住宅被判定为违规经营。
   - B 弟弟的学校家访要求证明“真实家庭”，迫使两个成年人第一次在外人面前扮演可靠共同生活者。
   - A 的恋人提出同居，三人生活直接触发合作社对家庭成员变更的审核。
   - 老屋一次大修需要两人共同借债，关系是否继续直接决定这套未来资产还能不能存在。

5. **One Character Pull**  
   合作社里住了四十年的老管理员：他不关心两人感情好坏，只会观察“这间屋子有没有真的被人一起生活过”。

6. **Long Mutation**  
   五年目标让两人的工作、亲属、恋爱、债务和生活习惯持续交叉；房子从待兑现资产变成共同制造的生活实体，而两人也不断重写“共同生活是否等于家人”。

7. **Non-Replaceability**  
   “真实共同居住才能逐年生成产权”把关系和住房资产锁成同一系统；去掉规则，角色完全可以各自生活，工作、恋爱、学校和维修不会稳定撞在一起。

8. **Engine Hypothesis**  
   双方欲望长期不兼容但都不能退出；每个生活接口都改变共同居住的可持续性，而关系质量又直接决定产权、家庭和未来选择。

# F5｜Hybrid Mutation

## F5-1｜《办完父亲的死亡证明之前》
**Function Mix：F1 Expansion × F2 Recontextualization**

1. **One-Line Promise**  
   一个女儿只想尽快埋葬父亲、退掉租屋，却发现这座城市不存在一张统一死亡证明：银行、雇主、医院、房东、工会、平台都必须分别确认“这个人已经从本系统死亡”，而每个系统保存的父亲竟然都不是同一种身份。

2. **Protagonist Desire**  
   在停尸、租金和债务成本失控前完成父亲的全部死亡确认，让家人真正结束后事。

3. **Unique Rule / Situation**  
   “死亡”按社会系统分别结算；每个系统只承认自己记录中的最后有效身份、责任和声明。一个人可能在雇佣关系里早已“退出”，却在债务、住房、照护、平台账户里仍然处于有效状态。

4. **Five Must-See Situations**
   - 雇主拒绝盖章，因为父亲在公司记录里三年前就已“离职死亡”，但工资却仍有人领取。
   - 房东确认的最后居住者不是父亲本人，而是一个家人从未见过的共同住户。
   - 医院系统显示父亲主动放弃过一项治疗，银行记录却证明当日他正在另一座城办理贷款。
   - 工会愿意确认死亡，但条件是女儿先接手父亲尚未完成的一项成员义务。
   - 最后一个平台一旦确认死亡，会自动关闭一整张仍在维持其他人生活的收入网络。

5. **One Character Pull**  
   父亲生前最后一名“系统代理人”：他能解释很多矛盾，却每解释一个，就暴露父亲还在另一个社会身份里活着。

6. **Long Mutation**  
   后事从行政任务变成对一个人全部社会存在的拆解；主角进入越来越多系统，同时每个新答案都重写前面已经“确认”的父亲，最终迫使她决定哪些身份应该被终止、哪些责任要继续。

7. **Non-Replaceability**  
   多系统独立确认死亡同时承担 Expansion 和 Mystery：新机构不是换场景，而是提供一个会改写旧信息且直接改变后事选择的新版本父亲。

8. **Engine Hypothesis**  
   第三种体验是“官僚社会探险即人物解谜”：世界每扩一层，人物过去就重估一层；答案又决定主角下一站必须进入哪个系统，两个函数形成闭环而不是轮流值班。

## F5-2｜《我们一起履约，才有信用》
**Function Mix：F4 Relationship × F3 Compounding**

1. **One-Line Promise**  
   一对早已闹翻的兄妹为了保住母亲留下的小店，被迫继续使用两人共同积累的“互保信用”；每完成一份共同承诺，他们能做的生意就更大，但彼此也越来越难真正分开。

2. **Protagonist Desire**  
   哥哥想把店做大后出售离开；妹妹想把店稳定经营下去并保住老员工，两人都需要现有共同信用才能活过现金流危机。

3. **Unique Rule / Situation**  
   长期共同履约者会形成不可拆分的“互保信用”：只有双方都完成责任，额度才增长；额度可解锁更好的账期、租约、贷款、员工保障和大客户合同，但单方违约会同时伤害两人且按累计额度放大。

4. **Five Must-See Situations**
   - 两人为一笔很小的原料账期重新共同签字，第一次发现旧互保信用还值钱。
   - 他们用共同信用替员工租房担保，经营关系第一次进入员工的私人生活。
   - 一次大客户订单要求两人同时承担交付责任，成功后信用额度出现第一次跃迁。
   - 哥哥想提前出售股份，却发现买家真正想买的是两人之间不可转让的共同履约历史。
   - 妹妹私下答应的一件家庭责任与最大商业合同撞车，一次关系选择可能清空多年复利。

5. **One Character Pull**  
   店里的老员工主管：他最清楚兄妹为什么闹翻，却把自己的家庭未来也押在两人的共同信用上。

6. **Long Mutation**  
   兄妹每次合作都会留下更大的共同资产、员工责任和议价权；关系越改善，事业越有力量，分开的代价也越大，最终“关系状态”本身成为最值钱、也最危险的生产资料。

7. **Non-Replaceability**  
   共同信用必须由两人一起履约才能复利，使吵架、信任、家庭承诺与商业扩张成为同一因果链；普通家族创业只能把关系和资产并排写，无法让它们互相铸造。

8. **Engine Hypothesis**  
   第三种体验是“关系本身会长成资产负债表”：每次情感选择都永久改变未来商业能力，每次商业升级又提高关系破裂的现实成本。

## F5-3｜《每修好一栋楼，就多一把不该存在的钥匙》
**Function Mix：F3 Compounding × F2 Recontextualization**

1. **One-Line Promise**  
   一个靠修复废楼换取永久使用权的年轻维修工发现，每完成一次大型修复，登记系统都会额外吐出一把“不属于该建筑”的旧钥匙；他的城市资产越多，这些钥匙越像是在指向同一个被抹掉的地方。

2. **Protagonist Desire**  
   通过修复废弃空间累积足够稳定的使用权和收入，摆脱临时工生活并拥有自己的工作基地。

3. **Unique Rule / Situation**  
   修复失能建筑可获得永久“功能权”；但主角每次登记高等级修复时，系统都会因一条未知旧产权链生成一枚实体钥匙，钥匙能打开某处真实存在却不在现行建筑档案里的门。

4. **Five Must-See Situations**
   - 第一把钥匙打开的是修好地下室后出现的一只封死旧柜，里面只有另一栋楼的编号。
   - 修好废弃电梯后得到第二把钥匙，两把钥匙竟能打开不同建筑里的同规格暗门。
   - 他为了验证规律主动接下一栋更危险的废楼，资产增长第一次被谜团反过来驱动。
   - 新钥匙揭示某项旧修复权原本不该属于他，已经积累的资产第一次面临整体重估。
   - 当他的修复网络足以拼出被删除的旧产权结构时，他必须决定继续扩张，还是停止触碰一个会改变现有所有权秩序的答案。

5. **One Character Pull**  
   一个专门研究旧建筑档案的退休测绘员：他不在乎主角赚了多少，只对“城市里为什么少了一块本该存在的空间”近乎执迷。

6. **Long Mutation**  
   修复权让主角越来越富有、越来越有空间控制力；钥匙谜团却不断重估这些成果的来源与合法性，使“资产越多”同时等于“离一个可能毁掉资产定义的答案越近”。

7. **Non-Replaceability**  
   谜团不是附着在升级线上的彩蛋：只有修复并获得资产才会生成钥匙，而钥匙答案又会改变既有资产的意义、归属和下一次投资选择。

8. **Engine Hypothesis**  
   第三种体验是“复利本身就是调查工具”：读者既期待下一项更大的城市资产，也期待它会把旧资产重新解释成什么；增长与谜底互相加速。
