# R7 Dead People Still Work｜P1 Writer Pack
## ONLY INPUT FOR PROSE

# Book Promise

这个时代，一个人死后，他训练多年的工作AI可以合法继续上班三年。

主角入职后最大的职业阴影：
> 部门最强的前辈已经死了两年，却还在工作、拿结果、评价活人。

# Protagonist

年轻员工。

最想得到：
> 一次真正只能由活着的自己完成、而不是因为死人让位才得到的职业胜利。

最怕：
> 活着时被死者模型压住，死后又留下自己的模型继续压下一代。

# Hard Rule

- 员工生前可持续训练个人工作模型；
- 死亡后模型可继续履行原工作合同，最长三年；
- 模型有工作权限，没有完整人格权；
- 公司可评价、调岗、降职或终止工作关系；
- 不能随意重写其核心工作记忆与稳定行为风格；
- 三年期限真实存在。

不要新增：
- 灵魂上传；
- AI觉醒；
- AI叛乱；
- 新超自然机制。

# Core People

## 死者前辈模型
工作能力极强。
继续按前辈留下的专业原则完成职责。

它不是故意压主角，
甚至可以真诚地认可更好的方案。

## 活同事
想要：
> 活人真正拥有晋升、奖金和“比前辈更强”的空间。

他不接受：
> 一个死人永久成为全组标准答案。

## 主角女友
想要：
> 下班以后主角还是活人的伴侣，而不是每天都在训练自己的死后替代品。

# Near Reader Wait

主角终于做出一个真正超过死者前辈生前最佳版本的方案。

评价它的人，
正是那个一直压着他的死者模型。

Reader在等：
> **这个死人会不会亲自留下“你的方案比我更好”的专业判断？**

# Already True

- 主角长期被该模型作为标准压住；
- 他不是第一次和模型协作；
- 对模型既烦、又不得不承认它确实强；
- 活同事也在争同一批职业空间。

# Voice

不要从AI制度说明开始。

从：
> 一个活人终于觉得“这次我可能真的赢了”
的具体工作时刻进入。
