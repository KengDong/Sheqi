# R1 Future Holdings｜P1 Writer Pack
## ONLY INPUT FOR PROSE

# Book Promise

一个年轻时穷到出售未来“本人真实在场权”的人，终于把人生过好了；但他今天变得越重要、越被人需要，当年别人低价买下的那些未来日期就越值钱，也越能摧毁他现在真正想守住的人生。

# Protagonist

沈峥。

现在最想得到：
> 能像普通人一样，对重要的人说一句“那天我一定会在”，并且这句话真的由现在的自己决定。

最怕：
> 为了让旧持仓贬值，最后主动把自己的人生活差。

# Hard Rule

过去可以出售未来某段时间的：
> **真实本人在场权。**

买家买到的不是出售时那个版本，
而是执行日已经成长、改变、拥有新关系的未来本人。

合同执行时：
- 必须是本人真实到场；
- 普通代理不能替代；
- 今天的成长、身份、关系会抬高旧持仓实际价值；
- 旧合同合法存在，不因“现在后悔”自动作废。

不要新增其它金融规则。

# Core People

## 伴侣
想要：
> 一段可以真正规划的共同未来。

她不愿：
> 婚姻靠不断花钱赎回沈峥的旧日期维持。

她最怕：
> 自己永远只拥有沈峥“卖剩下的时间”。

## 关键旧买家
当年那笔钱真实救过沈峥。

他想要：
> 自己与沈峥的历史不被今天简单改写成“趁穷剥削”，并保住合法买下的日期。

他不是纯反派。
他甚至有结构性理由希望沈峥健康、成功、长寿。

# Near Reader Wait

伴侣要求沈峥对一个重要未来日给一句可信的：
> “我会在。”

沈峥发现：
> 那一天仍合法属于关键旧买家。

Reader在等：
> **沈峥能不能不撒谎、不默认花钱赎回，也仍然给伴侣一个可以相信的答案？**

# Already True

- 沈峥年轻时确实靠卖未来活下来过；
- 伴侣知道他卖过未来，但并不知道所有日期；
- 关键旧买家并不是陌生的一次性客户；
- 三者之间没有预设善恶答案。

# Voice

不要先解释“未来持仓市场”。
先让Reader看到：
> 一个成年人为什么突然不敢承诺一个很普通的未来日。
