# R2 Second Autobiography｜P1 Writer Pack
## ONLY INPUT FOR PROSE

# Book Promise

沈峥发现，自己所有被出售的未来时段并非彻底空白：那些时段里的“他”形成了一条只在合同时间里连续存在的第二自传。

于是同一具身体里，
真的活着两个人生。

# Protagonist Structure

## 日常沈峥
拥有所有未出售时段的连续记忆。

想要：
> 保住工作、伴侣、家人与作为“默认人生”的连续性。

但已经无法把另一个自己简单当异常。

## 出售时段沈峥
只记得历次出售时段，却同样拥有连续人生。

想要：
> 被承认为有权拥有朋友、工作、爱情、钱、身体痕迹和未来的人。

不愿：
> 靠伤害共同身体让自己多活。

# Hard Rule

- 同一具身体；
- 同一法律身份；
- 两条互相隔离但各自连续的自传体记忆；
- 日常沈峥记未出售时间；
- 出售时段沈峥记所有合同执行时间；
- 身体后果、法律财产、社会身份全部共享；
- 同一时刻只能有一条自传在场。

不要新增：
- 第三人格；
- 人格法庭；
- 意识网络；
- 新人格机制。

# Core People

## 日常伴侣
爱日常沈峥。
不愿否认另一条人生是人，
但也不接受自己的共同未来无限被陌生第二人生改写。

## 共同老朋友
同时认识两条自传。
最不想做的事：
> 被迫替他们选谁才是真的。

# Near Reader Wait

两个沈峥都想参加同一个老朋友的婚礼。

同一具身体不可能同时让两条人生到场，
老朋友也拒绝替他们选谁更重要。

Reader在等：
> **最后谁去？谁主动放弃？缺席的人又会托另一个自己带去什么？**

# Already True

- 两条自传已经确认彼此真实存在；
- 彼此可以通过交接日志留下信息；
- 两人不是正邪关系；
- 老朋友对两人都存在真实共同历史。

# Voice

最重要的不是解释人格机制。

第一章要让Reader很快意识到：
> **“今天谁活着”会直接决定一个朋友到底见到谁。**
