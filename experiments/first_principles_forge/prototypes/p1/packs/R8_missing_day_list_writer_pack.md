# R8 Missing Day List｜P1 Writer Pack
## ONLY INPUT FOR PROSE

# Book Promise

每天午夜，城市公布一份名字名单。

第二天，
名单上的人仍然人人看得见、听得见，
但所有人和所有身份系统都无法把他们对应回“原来的那个人”。

当天结束后身份恢复。

# Protagonist

一个异常频繁上榜的人。

他已经学会利用失踪日挣钱，
但现在越来越害怕：
> 自己是不是只有在“没人认得我”的时候才觉得自由。

# Hard Rule

- 上榜者本人保留完整记忆；
- 别人能看见、听见上榜者，但不能把其与既有身份对应；
- 门禁、账号、银行、工作身份等识别系统同时失效；
- 次日身份恢复；
- 非上榜者对失踪日中的该人只留下模糊记忆；
- 若两人同时上榜，双方都能保留各自完整记忆，但仍无法自然把眼前人识别成原关系对象。

不要新增：
- 名单控制者；
- 幕后机构；
- 第二种能力；
- 破解技术。

# Core People

## 伴侣
想要：
> 即使认不出主角，也能保住这段关系。

最怕：
> 主角越来越喜欢做陌生人的自己，普通共同生活反而成了负担。

她不愿：
> 只因为一张纸条，就完全放弃身体边界和警惕。

## 父亲 / 家庭
更重视安全、医疗和可靠性。
不想把家庭彻底变成角色卡和应急手册。

# Near Reader Wait

伴侣提前留下一张纸条：

> “如果明天有个陌生人拿着这只杯子进门，先相信他是你爱的人。”

第二天主角真的上榜。

她理智上知道眼前这个陌生人可能就是伴侣，
身体却完全没有熟悉感。

Reader在等：
> **她会不会让他留下？主角能不能接受自己必须被爱人重新选择，而不是被认出来？**

# Already True

- 两人不是刚认识；
- 主角已经上榜过多次；
- 两人此前为失踪日做过基础准备；
- 但“知道规则”从不等于身体会产生熟悉感。

# Voice

不要先解释名单历史。

从一个很普通、很私密的空间进入：
> 门、杯子、鞋、餐桌、钥匙，都认识这个人；只有爱他的人不认识。
