# C01 Seed

Working concept:
> 人可以出售未来某段时间的真实本人在场权；执行期间，当前自传体本人不在场，事后只面对身体与现实后果。

Core tension:
> **今天的我有没有权替未来已经改变的我永久同意？**

Optional protagonist asset:
> 沈峥：曾因现实压力卖掉自己的未来，因此天然知道“时间价格”和“人生价值”不是一回事。

Optional recurring assets:
> 陈美兰 / 方栀可以保留，也可以不用。

Hard:
> 不继承“套利 -> 撮合 -> 团队 -> 公司”路线。

任务：
> 从这个种子重新长出3种彼此明显不同的整书发动机。

# C12 Seed

Working concept:
> 现代修仙里，高境突破的劫可以由外围人员/设备/系统承担一部分；富人在核心区突破，普通人可能在外圈拿钱承担风险。

Core law:
> **风险不会凭空消失，只会改变承担者 / 载体 / 时间 / 地点。**

Optional protagonist asset:
> 周野：曾靠承担别人突破风险挣钱，但终究必须面对自己的突破。

Hard:
> 不继承“安全员 -> 项目 -> 报价 -> 更大项目”的旧职业路线。

任务：
> 从这个种子重新长出3种彼此明显不同的整书发动机。

# Output Rule

每个版本只按Phase-1八项格式：
1. One-Line Promise
2. Protagonist Desire
3. Unique Rule / Situation
4. Five Must-See Situations
5. One Character Pull
6. Long Mutation
7. Non-Replaceability
8. Engine Hypothesis

不要排章。
不要做Canopy。
不要证明自己“结构完整”。
只问：
> **这版本是不是天然会一直生出我想看的事？**
