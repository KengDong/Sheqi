> 本轮不再增加新的死者模型案例。只围绕同一个死者前辈模型及其已经形成的活人关系测试人物续航。

## Frozen Core Cast｜5

### C1｜主角
1. **当前最想得到什么：** 在不靠死人腾位置的情况下建立自己的职业价值，同时决定自己未来究竟要留下怎样的工作模型。
2. **最怕失去什么：** 活着时被死者压住，死后又被自己的模型替代；最后连亲密关系都只剩一个可工作的版本。
3. **不愿付什么代价：** 不愿为了绩效把自己全部训练成可替代资产，也不愿假装前辈模型只是工具。
4. **与主角无关也会继续推进的生活：** 会继续工作、恋爱、训练或删改自己的模型、争职业位置。
5. **天然冲突：** 与死者模型争专业权威；与女友争训练时间与死后边界；与死者母亲争模型应被当作员工还是逝者痕迹；与活同事争晋升与奖金公平。

### C2｜死者前辈模型
1. **当前最想得到什么：** 按保留的工作记忆、原则和目标继续完成职责，并持续处理训练数据中未解决的工作/残余私人指向。
2. **最怕失去什么：** 作为工作主体被随意改写、降格成纪念品，或因活人情感要求偏离其工作逻辑。
3. **不愿付什么代价：** 不会为了让活人舒服主动放弃专业判断；其有限权限也无法替家属完成完整人格式告别。
4. **与主角无关也会继续推进的生活：** 会继续工作、学习新工具、评价方案、执行调岗与履约，直到既定期限结束。
5. **天然冲突：** 与主角争专业标准；与母亲争“像不像生前那个人”；与活同事争绩效；与所有活人争“工作连续性是否等于人格连续性”。

### C3｜主角女友
1. **当前最想得到什么：** 一个下班后仍把时间给活人关系的伴侣，并提前决定死亡后什么应停止。
2. **最怕失去什么：** 主角为了训练死后模型而提前退出现实亲密关系；未来自己又被迫天天看一个“像他但不是他”的工作存在。
3. **不愿付什么代价：** 不愿为经济安全放弃哀悼边界，也不愿简单要求主角完全不训练模型而让他职业受损。
4. **与主角无关也会继续推进的生活：** 她会继续自己的工作、关系与关于死亡/纪念的立场，不会只等待主角决定。
5. **天然冲突：** 与主角争训练投入；与死者母亲在“保留模型是否等于保留人”上天然对立又可能互相理解。

### C4｜死者母亲
1. **当前最想得到什么：** 保住儿子仍在工作世界里留下的可触痕迹，并确认这个模型没有被公司磨成完全陌生的东西。
2. **最怕失去什么：** 模型停机像经历第二次丧子，或者模型继续成长到她再也认不出儿子。
3. **不愿付什么代价：** 不愿为了“专业效率”同意无限改写模型，也不愿接受活员工把模型只当抢岗位的机器。
4. **与主角无关也会继续推进的生活：** 会继续自己的哀悼、经济安排和对儿子名誉的维护，也会主动询问、质疑模型变化。
5. **天然冲突：** 与主角争解释权；与活同事争奖金/岗位公平；与女友形成两种不同的遗属视角。

### C5｜活同事
1. **当前最想得到什么：** 获得可晋升、可拿奖金、可被评价为“比前辈更好”的活人职业空间。
2. **最怕失去什么：** 死者模型成为永久基线，让活员工永远只能做“还没死透的次优版本”。
3. **不愿付什么代价：** 不愿因为家属情感而放弃劳动公平，也不愿承认自己所有成长都来自死人模型教学。
4. **与主角无关也会继续推进的生活：** 会争方案、绩效、奖金、晋升与同事认可，即使主角离职也一样。
5. **天然冲突：** 与死者模型争标准与资源；与死者母亲争收入正当性；与主角争谁代表活员工立场。

## Character Collision Events｜13

### Event 01｜主角第一次真正赢过它
- **Active wants:** 主角要用新方案超过死者模型；模型按其工作原则严格评价；活同事也想拿下同一专业信用。
- **Collision:** 赢一个死人仍然不能自动证明谁是“新的标准”。
- **Irreversible residue:** 模型留下明确记录：主角方案优于自己生前最佳版本；主角获得最想要的认可，却再也不能简单说模型只是阻碍。

### Event 02｜活同事不接受“死人给你颁奖”
- **Active wants:** 活同事认为真正的晋升应该由活人竞争结果决定，不接受主角把模型认可当权威；主角则第一次珍惜这份来自前辈风格的承认。
- **Collision:** 两个曾经都讨厌死人压位的活人，因为“谁获得死人认可”反而分裂。
- **Irreversible residue:** 两人的职业竞争从共同反对模型变成彼此真正的对手。

### Event 03｜母亲觉得它越来越不像儿子
- **Active wants:** 死者模型继续学习已经存在的新工具以完成工作；主角支持更新以避免模型失配；死者母亲希望保留自己熟悉的工作习惯与表达。
- **Collision:** 模型越继续“活着工作”，越可能离死者生前版本更远。
- **Irreversible residue:** 母亲第一次要求公司/主角保留一份“生前版本”的记忆记录；她与当前模型的关系从延续儿子变成面对一个会变化的新存在。

### Event 04｜女友要求主角今晚别训练自己的模型
- **Active wants:** 主角担心不训练会在职业上落后；女友只想要一个不把每晚都拿去优化死后替代品的伴侣；活同事则持续炫耀自己的模型完成度。
- **Collision:** 不是工作与生活普通冲突，而是“为了死后继续工作，今天先牺牲多少活着时间”。
- **Irreversible residue:** 主角与女友设下固定不训练时段；这会真实降低模型完整度，也成为二人共同承担的职业成本。

### Event 05｜母亲想知道凌晨三点那句话
- **Active wants:** 死者母亲想知道模型为何反复问“她后来搬走了吗”；主角掌握这条残余私人线索却担心越过工作权限；模型本身仍会在特定状态继续问。
- **Collision:** 告诉母亲可能把模型残留私人欲望变成家属新的哀悼任务，不说又像替死者守一个没人授权他守的秘密。
- **Irreversible residue:** 主角选择告诉母亲“模型一直问过一句私人话”，却不替她解释含义；两人之间形成一项只有他们共同知道的长期秘密。

### Event 06｜活同事要求死人退出奖金排名
- **Active wants:** 活同事要求死者模型不再参与奖金竞争；死者母亲要保住其合法收入分成；主角既理解劳动公平，也知道模型确实在完成工作。
- **Collision:** 三个人争的不是抽象制度，而是同一笔钱到底属于劳动、遗属还是活人的机会。
- **Irreversible residue:** 主角拒绝替任何一边做道德裁决，导致活同事第一次公开认为他“已经站到死人那边”；同事关系留下阵营裂痕。

### Event 07｜主角删自己的语气，女友反而不答应
- **Active wants:** 主角想把自己的模型压回纯工作工具，删除私人语气训练；女友却发现这样未来留下来的东西会完全不像他；主角坚持“像我”才更危险。
- **Collision:** 最怕模型太像的人，也会在真正要删除熟悉感时舍不得。
- **Irreversible residue:** 两人共同决定保留极少数私人语气，但设为工作外不可调用；死亡边界第一次从口头争论变成双方共同编辑过的具体遗产。

### Event 08｜死者模型拒绝偏袒主角
- **Active wants:** 主角希望模型在一次内部选择中支持自己，因为他曾经替模型辩护；模型仍按旧标准把机会给活同事；活同事要证明自己的胜利不是死人施舍。
- **Collision:** 主角发现自己已经把专业尊重悄悄理解成私人关系，模型却没有这种回报逻辑。
- **Irreversible residue:** 主角与模型的关系从“互相帮助”被重新界定为没有人情回报保证的专业关系；活同事也第一次欠下一个自己最想摆脱的死人认可。

### Event 09｜母亲感谢活同事，活同事受不了
- **Active wants:** 死者母亲因模型收入继续给家里帮助而感谢团队，包括一直反对其排名的活同事；活同事想坚持劳动公平，却不愿在一个母亲面前变成“想断她收入的人”。
- **Collision:** 抽象公平被一个具体家庭关系击穿，却没有因此失效。
- **Irreversible residue:** 活同事不再使用“死人就该退出”这种简单口号，转而只争具体排名和资源边界；人物立场永久复杂化。

### Event 10｜女友和死者母亲第一次真正谈“关掉”
- **Active wants:** 女友坚持如果主角死了，希望模型不要长期侵占私人哀悼；死者母亲则坦白自己靠前辈模型多活了三年“儿子还在工作的日子”。
- **Collision:** 两位遗属视角都真实，一个想让死亡结束，一个知道延迟结束也能救人。
- **Irreversible residue:** 女友不再要求绝对“立即关掉”，但要求保留自己退出观看/互动的权利；母亲也承认继续运行不是所有亲人都必须接受的爱。

### Event 11｜期限将到，母亲想让它最后一天别上班
- **Active wants:** 死者母亲想把模型最后一天留给告别；模型仍按工作逻辑完成任务；主角想给母亲一个仪式，却知道强迫模型扮演完整儿子反而越过边界。
- **Collision:** 最后一日到底属于劳动合同、逝者家属还是一个没有完整人格权的工作模型。
- **Irreversible residue:** 母亲放弃“整天归我”，只请求主角在工作结束前替她问一个问题；她第一次接受模型不是儿子本人。

### Event 12｜最后那个问题，主角不替死人回答
- **Active wants:** 模型最后一次问“她后来搬走了吗”；主角想给它一个答案完成三年悬念；死者母亲却要求不要编一个让大家舒服的结局。
- **Collision:** 大家都想结束，却不能通过伪造死者私人生活来制造 closure。
- **Irreversible residue:** 模型带着未解私人问题停机；主角和母亲共同选择“留下缺口”而不是伪装完整，这成为两人永久共同历史。

### Event 13｜第二天，活人真的赢了，却没人庆祝
- **Active wants:** 活同事终于获得模型空出的职业空间，想证明活人的等待不是白费；主角也拿到更大职责，却下意识保留前辈曾参与讨论的位置；女友希望主角别把自己活成下一个死者前辈。
- **Collision:** 他们多年争取的“死人腾位置”终于发生，但获得位置的人必须决定继承什么、拒绝什么。
- **Irreversible residue:** 主角正式接下岗位，却把自己的模型训练强度降下来；活同事得到升迁，但承认前辈模型曾真实塑造自己的标准。竞争结束后形成的是继承关系，不是清零。
- **Ordinary-life proof:** 没有新死者、新Case，第二次死亡后的普通工作日仍能继续制造故事。
