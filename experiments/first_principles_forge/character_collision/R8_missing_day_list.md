## Frozen Core Cast｜6

### C1｜主角
1. **当前最想得到什么：** 既保住普通身份生活与亲密关系，又承认失踪日已经成为自己的工作能力和喘息空间。
2. **最怕失去什么：** 最终只在“别人认不出自己”时才觉得自由，普通日反而无法生活。
3. **不愿付什么代价：** 不愿把高价灰色任务当唯一生计，也不愿用自己独占的失踪日记忆操控亲密关系。
4. **与主角无关也会继续推进的生活：** 会继续普通工作/收入安排、家庭、伴侣关系和失踪日准备；即使没有新任务，身份切换仍会改变生活。
5. **天然冲突：** 与伴侣争秘密与正常生活；与自由女人争“失踪日是病还是自由”；与同行争职业伦理和收入方式；与父亲/家庭争协议是否把亲情变程序。

### C2｜伴侣
1. **当前最想得到什么：** 在认不出主角的日子也能保住关系，同时不让两人的爱情被失踪日职业彻底吞掉。
2. **最怕失去什么：** 主角越来越喜欢“作为陌生人”的自己，最后普通日的共同生活只剩负担。
3. **不愿付什么代价：** 不愿为了信任一个失踪日陌生人就放弃身体边界和怀疑，也不愿接受主角永远保留她说过而自己不记得的秘密。
4. **与主角无关也会继续推进的生活：** 会继续自己的工作、家庭与社交，并主动制定或修改自己能接受的失踪日边界。
5. **天然冲突：** 与主角争记忆权与职业边界；与自由女人争“自由是否值得以关系断裂为代价”。

### C3｜把失踪当自由的女人
1. **当前最想得到什么：** 保住失踪日作为唯一不被工作、家庭、熟人期待定义的一天。
2. **最怕失去什么：** 主角查明或社会适应后，这种匿名自由被彻底“治好”。
3. **不愿付什么代价：** 不愿把失踪日里的自己交给普通日关系审判，也不愿承诺所有重大决定都必须在身份恢复后才算数。
4. **与主角无关也会继续推进的生活：** 她会继续普通日被各种身份包围，也会继续在失踪日做只属于自己的选择。
5. **天然冲突：** 与主角争正常性；与伴侣争失踪日是否应服务于关系连续性；与同行争失踪日是否必须被职业化、规范化。

### C4｜父亲 / 家庭代表
1. **当前最想得到什么：** 家里任何人上榜时都能安全、可操作地度过一天，尤其在医疗与紧急事项上不再失序。
2. **最怕失去什么：** 主角因为迷恋失踪日自由或高收入工作而忽视家庭可靠性。
3. **不愿付什么代价：** 不愿让亲情完全退化成口令、角色卡和机械钥匙，也不愿永远依赖主角一个人的记忆。
4. **与主角无关也会继续推进的生活：** 会继续自己的身体、家庭和日常安排，并维护家庭协议。
5. **天然冲突：** 与主角争可靠性；与自由女人的“别把失踪日管起来”立场天然相反。

### C5｜合法服务同行
1. **当前最想得到什么：** 把帮助失踪者的工作做成可持续、可证明结果、不过度侵入隐私的职业。
2. **最怕失去什么：** 当自己长期不上榜时收入消失，或整个行业被高价灰色任务定义。
3. **不愿付什么代价：** 不愿为了收入滑向监听、盯梢等灰色工作，也不愿一直靠灾难窗口吃饭。
4. **与主角无关也会继续推进的生活：** 会维护自己的工作、纸质流程、收入与普通日生活，即使主角不在也会继续服务已有关系。
5. **天然冲突：** 与主角争职业边界与资源；与自由女人争失踪日应否被组织成服务体系。

### C6｜原单位上司
1. **当前最想得到什么：** 保住团队工作的连续性，不把关键职责交给一个可能随机失去组织身份的人。
2. **最怕失去什么：** 因主角频繁上榜让项目、账号和责任链失效，最终由别人替他的异常承担风险。
3. **不愿付什么代价：** 不愿因为同情就假装随机不可用不影响职业资格，也不愿完全放弃一个有能力的员工。
4. **与主角无关也会继续推进的生活：** 会继续分配工作、培养替代人员、追求组织可靠性。
5. **天然冲突：** 与主角争“能力 vs 可验证可用性”；与同行的职业化失踪服务也代表两套完全不同的劳动道路。

## Character Collision Events｜13

### Event 01｜伴侣要求知道那句伤人的原话
- **Active wants:** 主角一直只说“那天我发现你很累”，不肯复述失踪日里伴侣对陌生人的伤人真话；伴侣要求完整知道，因为她不接受一个自己无法共享的事件长期支配关系。
- **Collision:** 主角认为保留原话是在保护她；伴侣认为这是他单方面编辑共同历史。
- **Irreversible residue:** 主角最终复述原话，伴侣第一次真正为一个自己只模糊记得的事件承担关系后果；“谁记得更多，谁就有更多解释权”的问题再也不能藏起来。

### Event 02｜她不想再把失踪日让给工作
- **Active wants:** 伴侣要求主角下一次上榜不要接任何工作，只陪她度过一天；主角担心放弃高收入窗口；合法服务同行也认为稳定职业不能靠每次临时停工。
- **Collision:** 爱情、收入与职业可靠性第一次围绕同一个已存在的失踪日直接争资源。
- **Irreversible residue:** 主角承诺每若干次上榜至少留一次纯生活日；失踪日第一次不再默认属于工作。

### Event 03｜自由女人觉得“留一把椅子”很可怕
- **Active wants:** 伴侣想完善陌生人协议，让失踪日关系尽量连续；自由女人认为这种做法是在把普通日身份追进唯一自由日；主角既羡慕她又想保住伴侣。
- **Collision:** 两个非主角直接争“爱一个人是否包括在他认不出你时仍要求他扮演原来的关系”。
- **Irreversible residue:** 伴侣不再追求完全复刻正常恋爱，只保留最低安全协议；自由女人也第一次承认别人的失踪日可以选择关系而不必选择逃离。

### Event 04｜父亲拒绝把家变成应急手册
- **Active wants:** 主角想把家庭陌生人协议写得更细，降低医疗和生活风险；父亲认为再细下去家人会只剩角色卡；伴侣支持更严格的安全流程。
- **Collision:** 三个人都想安全，却争“程序化到什么程度还算家庭”。
- **Irreversible residue:** 家庭协议被拆成“必须执行的安全底线”和“绝不预设的亲密行为”；家人第一次为失踪日保留不可程序化空间。

### Event 05｜普通日里，他越来越像想逃的人
- **Active wants:** 连续普通日让主角感到窒息，他主动去找自由女人；她希望他承认自己已经需要失踪日；伴侣则要求他别把关系压力都解释成“身份太多”。
- **Collision:** 主角以为自由女人最懂自己，真正最不愿他把失踪日当药的反而可能是她，因为那会把她的生活哲学变成逃避模板。
- **Irreversible residue:** 主角第一次承认自己对上榜有依赖感；伴侣也知道“恢复正常”不等于问题自动消失。

### Event 06｜同行不上榜了，反而快活不下去
- **Active wants:** 合法服务同行连续很久不上榜，想接手两人既有服务里普通日的准备、托管确认与纸质交接工作，换取更稳定的收入份额；主角自己也需要这些普通日收入，不愿因为同情就长期让利。
- **Collision:** 两个人都曾把失踪变现，现在必须面对“能力窗口不来时，既有工作里的钱和劳动怎么分”。
- **Irreversible residue:** 两人把既有服务明确拆成失踪日执行与普通日准备两类职责，按实际劳动分收入；关系从模糊同行互助变成有账可算的长期合作。

### Event 07｜自由女人拒绝加入他们的职业体系
- **Active wants:** 同行想把自由女人多年上榜经验整理成可帮助他人的流程；自由女人拒绝把自己最私人的自由日职业化；主角觉得这些经验确实能救人。
- **Collision:** “把经验公共化”既可能帮助人，也可能夺走一个人唯一不被利用的生活。
- **Irreversible residue:** 同行承诺不记录她的私人方法；主角第一次在职业价值面前选择保护别人的不可利用空间。

### Event 08｜上司给他一份更稳定、但更小的职责
- **Active wants:** 原单位上司愿意保留主角，但只给不会因失踪日中断的边缘职责；主角要回到核心项目；伴侣却认为稳定而小的工作可能比高价失踪日职业更适合共同生活。
- **Collision:** “回归正常”并不等于回到原来的职业位置，伴侣也未必站在主角的野心一边。
- **Irreversible residue:** 主角接受部分稳定职责，却不再把原单位视为唯一职业身份；他的工作人生正式成为双轨，而不是等待恢复原状。

### Event 09｜伴侣第一次去找自由女人，不经过主角
- **Active wants:** 伴侣想知道如何与一个越来越享受失踪日的人相处；自由女人不想被当作“坏未来的样板”或心理顾问；主角则不希望两人私下讨论自己。
- **Collision:** 三个人的关系第一次脱离主角控制，两个女人都拒绝只作为他的价值观两端。
- **Irreversible residue:** 伴侣与自由女人形成直接联系方式；以后她们可以互相校正，也可以联合反对主角，这个关系网不再以主角为唯一中心。

### Event 10｜主角不愿把完整记忆交出来
- **Active wants:** 一次与伴侣共同上榜后，两人都完整记得当天；伴侣要求互换各自事先记录，核对彼此如何选择对方；主角却想保留其中一段自己曾犹豫的时刻。
- **Collision:** 过去一直是“一个记得、一个不记得”，现在双方都记得，反而第一次出现真正对等的隐私权问题。
- **Irreversible residue:** 两人明确约定“同时上榜也不等于彼此拥有全部记忆”；亲密关系从补偿识别缺失进入承认独立私人空间。

### Event 11｜父亲更相信角色卡，主角反而受不了
- **Active wants:** 父亲发现按角色卡与口令处理上榜日最安全，开始高度依赖流程；主角却希望父亲至少保留一些“即使认不出也会凭关系选择我”的东西。
- **Collision:** 过去主角要求家人理性相信协议，现在真正被理性流程照顾时又觉得亲情被抽空。
- **Irreversible residue:** 主角接受“可靠不等于熟悉感”；父亲则主动留下一个非必要、纯私人习惯作为双方失踪日里的关系暗号。

### Event 12｜同行要公开职业底线，主角怕砸掉收入
- **Active wants:** 合法服务同行想公开拒绝监听、盯梢和灰色传递，建立行业边界；主角知道高价灰活正是自己最难舍弃的收入来源；自由女人则认为任何“行业规范”都可能进一步社会化失踪日。
- **Collision:** 三个人分别从劳动伦理、生存收入和个人自由反对/支持同一件事。
- **Irreversible residue:** 主角签下同行的最低边界并放弃一类高价工作；普通日收入压力永久上升，但职业身份第一次不是由“什么最赚钱”定义。

### Event 13｜两个人同时上榜的普通一天
- **Active wants:** 主角和伴侣同时上榜，两人都知道对方是谁却无法自然识别彼此；主角想按协议完成“一次成功的关系实验”，伴侣却拒绝把一天变成考试，只想和眼前这个陌生人重新认识。
- **Collision:** 主角想证明多年准备有效，伴侣想证明爱情不应只剩程序正确。
- **Irreversible residue:** 两人最后没有按预设恋爱流程走，而是各自重新选择是否靠近；次日双方都完整记得这段“第二次认识”。关系从“如何撑过失踪日”变成拥有一段只有规则才能生成的共同历史。
- **Ordinary-life proof:** 无客户、无任务、无幕后、无灾害，只靠两个人吃饭、散步、重新选择彼此仍成立。
