# R2｜Second Autobiography｜Character Collision Stress Test

status: STRESS-TESTED  
decision: D-0082  
source_boundary: D-0081 survivor only  
concept_mutation: none

> 本轮不靠新增买家续命。两条自传以及已经形成的亲密、家庭、友情、工作关系必须自己制造故事。

## Frozen Core Cast｜6

### C1｜日常沈峥
1. **当前最想得到什么：** 保住自己作为默认人生的连续性，同时又不再把另一条自传当异常或寄生者。
2. **最怕失去什么：** 工作、伴侣、家人和身体主权被另一条人生逐步接管。
3. **不愿付什么代价：** 不愿为了伦理上承认对方是人，就默认自己必须无限让出未来时间。
4. **与主角无关也会继续推进的生活：** 他会继续自己的职业、爱情、家庭义务和普通日常，即使另一条自传短期没有出现。
5. **天然冲突：** 与出售时段沈峥争时间、身体与法律身份；与日常伴侣争“承认另一个人需要付到什么程度”。

### C2｜出售时段沈峥
1. **当前最想得到什么：** 被承认为有权决定自己未来、财产、爱情和身体痕迹的独立人生，而非日常沈峥偶尔施舍出的时间。
2. **最怕失去什么：** 日常沈峥通过工作、日程、关系安排把自己未来全部挤掉。
3. **不愿付什么代价：** 不愿为了多活而伤害共同身体或摧毁另一条人生珍惜的人。
4. **与主角无关也会继续推进的生活：** 他已有自己的工作、同事、朋友、爱人、收入和承诺，会在每次出现时主动维护它们。
5. **天然冲突：** 与日常沈峥争默认主权；与两位伴侣都存在身体与法律身份冲突；与共同朋友争“被当作同一个人还是不同人”。

### C3｜日常伴侣
1. **当前最想得到什么：** 与自己熟悉的沈峥拥有可规划的共同未来，不被一个永远无法同时见面的第二人生无限改写。
2. **最怕失去什么：** 自己在爱情里变成“其中一个时段的伴侣”，身体边界和共同未来被陌生人参与决定。
3. **不愿付什么代价：** 不愿以否认出售时段沈峥人格的方式维持安全感，也不愿默认所有牺牲都由自己承担。
4. **与主角无关也会继续推进的生活：** 她会继续自己的工作、关系和对共同生活的判断，不会只作为主角的伦理裁判存在。
5. **天然冲突：** 与出售时段伴侣争同一法律身份与身体边界；与日常沈峥争“善待另一个自己是否正在伤害我们的生活”。

### C4｜出售时段伴侣
1. **当前最想得到什么：** 让自己与出售时段沈峥的关系被当作真实爱情，而不是合同时间里的幻觉或出轨副产品。
2. **最怕失去什么：** 自己爱的人因为日常沈峥的一次职业或日程决定被永久压缩到几乎不存在。
3. **不愿付什么代价：** 不愿通过强占共同身体、羞辱日常伴侣来证明关系合法。
4. **与主角无关也会继续推进的生活：** 她有自己的生活，也会独立决定是否继续等待一个只在特定时段出现的人。
5. **天然冲突：** 与日常伴侣争关系资格；与日常沈峥争时间分配；也会与出售时段沈峥争“爱情是否值得用更高身体成本维持”。

### C5｜共同老朋友
1. **当前最想得到什么：** 不被迫在两个沈峥之间站队，保住一段能同时容纳两条自传的友情。
2. **最怕失去什么：** 自己的每个邀请都变成“选择谁活一天”的政治动作。
3. **不愿付什么代价：** 不愿把两人当半个人拼成一个，也不愿假装两者没有差异。
4. **与主角无关也会继续推进的生活：** 会结婚、工作、经营自己的朋友关系，不会停下来等两个沈峥解决身份问题。
5. **天然冲突：** 与两个沈峥都冲突——他越想一视同仁，两人越可能觉得自己没有被单独看见。

### C6｜共同亲人
1. **当前最想得到什么：** 让家庭关系能持续，不必每天先判断“今天是哪一个沈峥”。
2. **最怕失去什么：** 家庭成员彼此喜欢不同版本，最终把家变成人格投票场。
3. **不愿付什么代价：** 不愿为了和平假装两条记忆人生完全相同。
4. **与主角无关也会继续推进的生活：** 会继续自己的家庭、身体和生活安排，也会主动邀请自己更亲近的那个版本出现。
5. **天然冲突：** 与日常沈峥在“为什么家人更喜欢另一个你”上冲突；与出售时段沈峥也会因期待他承担家庭义务而冲突。

## Character Collision Events｜15

### Event 01｜空白日不是施舍
- **Active wants:** 日常沈峥主动留出一整天空白给出售时段沈峥，想证明自己承认对方；出售时段沈峥拒绝，要求先承认“未出售时间不是你的天然私产”。
- **Collision:** 善意本身仍携带所有权前提。
- **Irreversible residue:** 两人第一次把“默认主权”写进交接日志，之后所有时间讨论都无法退回“我偶尔让你一天”。

### Event 02｜两份工资，一笔房租
- **Active wants:** 出售时段沈峥要保留自己赚的钱用于自己的关系和生活；日常沈峥坚持共同身体的房租、债务和医疗应优先。
- **Collision:** 两条劳动人生共用一个法律账户，却没有共同财政观。
- **Irreversible residue:** 两人建立不可撤销的双账本与最低共同支出线；第一次形成真正的“共同财产/个人财产”历史。

### Event 03｜谁去参加老朋友的婚礼
- **Active wants:** 两个沈峥都要参加同一位老朋友的婚礼；老朋友拒绝替他们选谁更重要，也拒绝把仪式切成两个“半场”。
- **Collision:** 友情第一次要求他们自己承担时间排他性的代价。
- **Irreversible residue:** 其中一人主动放弃并要求另一人替自己带一句私人祝福；两人的关系第一次留下“我替你活过一个共同朋友的重要日子”的债。

### Event 04｜祝福说错了
- **Active wants:** 获得婚礼时段的沈峥想同时转达另一个自己的祝福；老朋友只想听眼前这个人的话，不愿每次相处都面对一个缺席者。
- **Collision:** 代理善意反而让当下关系失去独立性。
- **Irreversible residue:** 老朋友明确建立边界：以后邀请会写清“今天我想见谁”；友情从含糊共享变成承认两条独立关系。

### Event 05｜两个伴侣第一次不通过沈峥谈判
- **Active wants:** 日常伴侣要确保共同身体不接受高风险工作、永久改动或重大医疗决定；出售时段伴侣要确保日常一方不能单方面决定避孕、手术和身体生活。
- **Collision:** 两个女人都在保护自己爱的人，却保护的是同一具身体上的不同人生。
- **Irreversible residue:** 她们共同写出一份身体边界清单；从此双方建立不依赖沈峥转述的直接联系，也因此真正进入彼此生活。

### Event 06｜他偷偷留下一个永久痕迹
- **Active wants:** 出售时段沈峥想通过一个小纹身证明自己不是随时会被抹掉的时段；日常沈峥要洗掉以维护身体控制；出售时段伴侣坚持保留。
- **Collision:** 删除一个图案同时像是在删除另一个人的人生凭证。
- **Irreversible residue:** 日常沈峥最终不洗；纹身成为双方第一次共同承担的永久身体历史，也成为以后每次身体主权争执都绕不过去的先例。

### Event 07｜家人更想见“另一个他”
- **Active wants:** 共同亲人把家庭聚会安排到出售时段，因为他更愿意回家；日常沈峥要求恢复原来的家庭节奏；出售时段沈峥又不愿自己只因“更好用”而被家人偏爱。
- **Collision:** 三方都想要真实亲情，却把时间安排变成人格投票。
- **Irreversible residue:** 家人公开承认自己确实更亲近其中一版；日常沈峥再也无法把这种差异解释成误会。

### Event 08｜升职等于削掉另一个人的寿命
- **Active wants:** 日常沈峥要接受一个占据大量未来时间的升职；出售时段沈峥要求他换成更灵活的职业；日常伴侣支持升职，因为那也是两人的共同未来。
- **Collision:** 一个人的成功就是另一个人的生存压缩，伴侣利益又与人格伦理不一致。
- **Irreversible residue:** 日常沈峥接受升职，但主动保留一块不可被工作占用的固定时间；出售时段沈峥得到“生存底线”，却失去继续要求全部职业重构的道德高地。

### Event 09｜出售时段伴侣拒绝被“固定探视”
- **Active wants:** 日常沈峥认为固定保留时间已经足够公平；出售时段伴侣拒绝把爱情降成固定探视；出售时段沈峥也不愿自己的生活只剩被保护出来的一块窗口。
- **Collision:** 稳定保障与完整人生不是一回事。
- **Irreversible residue:** 三方第一次承认固定时间只是最低保障而非最终方案，关系从“时间配额”进入真正共同决策。

### Event 10｜一方替另一方修好了家庭关系
- **Active wants:** 出售时段沈峥主动去修复与共同亲人的矛盾；日常沈峥回来后既想享受改善，又拒绝让家人把功劳算给另一个自己；亲人则坚持这段和解只属于他们共同经历过的人。
- **Collision:** 好事也会重新分配“谁才是家里真正那个人”的位置。
- **Irreversible residue:** 日常沈峥第一次当面向另一个自己写下“谢谢”；两人之间产生不能用权利争夺解释的感情债。

### Event 11｜日常伴侣要求停止互相牺牲
- **Active wants:** 日常沈峥准备再次放弃一个利益机会保护另一条自传的时间；日常伴侣要求他停止，因为每一次“伦理正确”都在改写两人的共同生活；出售时段沈峥反而支持她，不愿永远靠对方牺牲活着。
- **Collision:** 两个沈峥短暂站在一起，反对把第二人生建立在第一人生的持续自损上。
- **Irreversible residue:** 三人约定以后任何重大让渡都必须同时写明谁承担现实成本；“牺牲”不再能自动获得道德豁免。

### Event 12｜同一个朋友，不同秘密
- **Active wants:** 老朋友分别从两个沈峥那里听到互相矛盾的私密信息，想保住两段独立友情；两个沈峥又都想知道对方是否在借同一张脸影响自己的朋友关系。
- **Collision:** 老朋友第一次真正拥有“只属于其中一人的秘密”，拒绝做两条自传的共享数据库。
- **Irreversible residue:** 双方承认朋友有权分别保密；两条人生在社会关系上第一次拥有明确不可互查的私人区。

### Event 13｜共同亲人病床前，没人能躲回“另一个我”
- **Active wants:** 共同亲人希望两个沈峥都参与长期照护；日常沈峥认为出售时段承担太少，出售时段沈峥则指出自己能出现的时间本就由日常一方掌握更多。
- **Collision:** 家庭劳动把抽象时间主权变成谁真正付出多少小时。
- **Irreversible residue:** 两人建立第一份跨时段照护交接，且共同亲人开始分别向两人提出不同要求；家庭正式把他们当两名责任主体。

### Event 14｜“如果只能留一个，不许替我决定”
- **Active wants:** 两个沈峥分别写下同一句声明，想阻止伴侣和家人在极端情况下替他们决定谁更值得留下；两位伴侣却都坚持自己不可能完全放弃参与影响共同身体未来的决定。
- **Collision:** 两个自我第一次拥有共同政治立场，却同时与最爱他们的人冲突。
- **Irreversible residue:** 四个人承认“爱不等于有权替代本人作人格价值排序”；这是一个会反过来约束未来所有决策的共同承诺。

### Event 15｜普通星期天到底是谁活着
- **Active wants:** 一个没有任何合同安排的普通星期天自然属于日常沈峥；他想和伴侣过正常日子；日常伴侣却发现他整天在替缺席的另一人内疚，要求他真正待在眼前；出售时段伴侣则提前留下一封信，要求他们不要把自己的不存在变成整天的悼念。
- **Collision:** 没有任务、没有买家、没有危机，仍然有三个人争“如何尊重一个今天不存在的人”。
- **Irreversible residue:** 日常沈峥第一次选择不把空白日让出去，也不把它过成负罪日；他与另一个自我的关系从纯资源争夺进入允许彼此“有时不在”的阶段。
- **Ordinary-life proof:** 纯生活场面仍能形成强冲突。

## Stress Result

- **Natural count:** 15
- **Premature exhaustion:** no
- **New buyer/client used:** no
- **New rule / new institution used:** no
- **At least two independently active characters per event:** yes
- **Irreversible residue:** 15/15
- **Two non-protagonists with continued pull:** 日常伴侣、出售时段伴侣；共同老朋友与共同亲人也能独立制造事件。
- **Protagonist-offscreen test:** 强通过。即使某一版沈峥一天不出现，另一版、两位伴侣、朋友和亲人仍会继续谈判时间、身体、秘密和家庭责任。
- **Character-engine note:** R2 已经不需要“再来一个买家”。真正发动机是两个拥有连续人生的人被迫共用法律身份、身体与关系网络。
