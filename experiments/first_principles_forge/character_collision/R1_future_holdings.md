> 本轮关闭新客户、新机构、新规则、新合同救场。只使用 Reservoir 已经长出的核心人物、既有持仓与既有生活关系。

## Frozen Core Cast｜5

### C1｜沈峥
1. **当前最想得到什么：** 能真正向伴侣、工作和自己承诺未来，而不是先查那一天是否仍属于自己。
2. **最怕失去什么：** 把人生过好的能力；尤其怕自己为了让旧持仓贬值而主动缩小人生。
3. **不愿付什么代价：** 不愿用彻底否定穷困时期自己的方式换自由，也不愿再把亲密关系翻译成纯交易。
4. **与主角无关也会继续推进的生活：** 他会继续工作、成长、照顾家庭、处理健康与职业选择；这些生活越正常，旧持仓越被重新定价。
5. **天然冲突：** 与伴侣争“共同未来是否可承诺”；与关键旧买家争“过去的合法同意能占今天多少”；与老卖家朋友争“赎回是否等于否定过去”；与同事竞争者争“谁更可靠可用”。

### C2｜伴侣
1. **当前最想得到什么：** 一段不用每逢重要日期先向旧合同让位的共同生活，以及沈峥对所有已售日期的彻底透明。
2. **最怕失去什么：** 自己在沈峥人生里的优先级被证明只是“剩余时段”。
3. **不愿付什么代价：** 不愿让婚姻靠不断花钱买回日期维持，也不愿永远迁就沈峥过去的生存选择。
4. **与主角无关也会继续推进的生活：** 她会规划自己的工作、家庭节奏和长期安排；不会把整个人生冻结到沈峥的合同表上。
5. **天然冲突：** 与沈峥争透明与承诺；与关键旧买家争未来时段的意义；与同事竞争者在“沈峥应优先家庭还是职业”上存在结构性冲突。

### C3｜关键旧买家
1. **当前最想得到什么：** 让当年那笔真实救过沈峥的交易被承认为一段复杂而非纯掠夺的共同历史，并保住仍合法持有的日期。
2. **最怕失去什么：** 自己被沈峥今天的成功彻底改写成一个只会趁穷占便宜的人；也怕沈峥再次出售未来。
3. **不愿付什么代价：** 不愿用无条件放弃全部持仓来换道德清白，也不愿接受双方后来长出的感情全是假的。
4. **与主角无关也会继续推进的生活：** 他会处理自己的家庭、晚年、名誉和死亡安排；会继续决定持仓何时执行、何时延期、是否放弃。
5. **天然冲突：** 与沈峥争解释权与未来在场；与伴侣争“谁有资格要求沈峥某天出现”；与老卖家朋友在交易是否值得上也并不同路。

### C4｜老卖家朋友
1. **当前最想得到什么：** 保住对贫困时期自己的尊重，不让今天较富足的人把当年“卖未来活下去”简单定义成羞耻。
2. **最怕失去什么：** 自己过去作出的选择被别人替他宣布为错误，从而把那个曾经拼命活下来的自己一并抹掉。
3. **不愿付什么代价：** 不愿为了获得“完全自由”的漂亮答案而回购所有日期。
4. **与主角无关也会继续推进的生活：** 他会继续过自己的工作、家庭与旧持仓生活，并主动选择保留某些合同作为人生历史的一部分。
5. **天然冲突：** 与沈峥争“赎回是不是天然正确”；与伴侣的“共同未来必须可控”立场也天然不合。

### C5｜同事竞争者
1. **当前最想得到什么：** 成为团队里那个更稳定、可预测、关键时刻一定在场的人，并取得沈峥正在上升的职业位置。
2. **最怕失去什么：** 自己长期承担稳定性却仍被更有能力但未来不可支配的沈峥压住。
3. **不愿付什么代价：** 不愿为沈峥的私人旧债长期兜底，也不愿把职业竞争伪装成友情。
4. **与主角无关也会继续推进的生活：** 他会争项目、争职责、积累信用；即便沈峥离开，他仍会争取关键岗位。
5. **天然冲突：** 与沈峥争“能力 vs 可用性”；与伴侣在时间优先级上偶尔同向、在职业机会归属上又相反。

## Character Collision Events｜13

### Event 01｜把未来摊在桌上
- **Active wants:** 伴侣要求沈峥把所有已售日期一次性整理清楚，才能继续做长期家庭计划；沈峥想坦白，却想保留几笔自己都羞于解释的旧合同。
- **Collision:** 这不是“要不要说秘密”，而是共同生活是否有资格建立在一张残缺日历上。
- **Irreversible residue:** 两人共同建立一份“家庭可承诺日历”；伴侣第一次知道至少一段过去沈峥主动隐瞒过，信任从默认变为需要维护的资产。
- **Why it compounds:** 此后每次职业、家庭、买家冲突都会先撞上这份共同日历，而非重新从零解释设定。

### Event 02｜不要替我赎回
- **Active wants:** 沈峥准备高价回购一个对伴侣重要的旧日期；伴侣明确要求他不要买，想确认他能不能在仍有约束的情况下成为可靠的人；关键旧买家也不愿出售。
- **Collision:** 三个人分别把“同一天”理解成爱、自由和共同历史。
- **Irreversible residue:** 沈峥第一次承诺“不再把回购当作默认解决方案”；伴侣与旧买家之间形成第一次直接、彼此都不喜欢却必须承认的长期关系。

### Event 03｜最讨厌的人替他保住职位
- **Active wants:** 同事竞争者抓住沈峥某个既有合同日无法到场的事实争取关键职责；关键旧买家却用自己多年积累的人脉为沈峥压住这次职业损失，因为他不想自己的未来持仓贬值。
- **Collision:** 同事的竞争是正当职业欲望，买家的帮助也既真诚又自利，沈峥无法选择一个干净立场。
- **Irreversible residue:** 沈峥欠旧买家一笔不是合同写明的人情债；同事从“普通竞争者”变成知道沈峥未来缺口并会持续利用的人。

### Event 04｜你越成功，我越值钱
- **Active wants:** 沈峥想接受一次重要职业上升；伴侣希望他别再为了旧合同缩小人生；关键旧买家坦率表示支持，因为现有持仓会随之升值；同事竞争者则希望他拒绝，好让职位腾出来。
- **Collision:** 四个人第一次都主动希望沈峥“做不同的人生选择”，而且没有谁纯粹为他好或纯粹害他。
- **Irreversible residue:** 沈峥接受机会；旧买家随后那句“恭喜”永久改变沈峥对成功的感受，同事竞争也从岗位之争升级为对其可持续性的长期质疑。

### Event 05｜老卖家拒绝被拯救
- **Active wants:** 沈峥想说服老卖家朋友回购一个仍可回购的关键日期，把他当作“自由可以拿回来”的证明；老卖家坚持保留，因为那是穷困时期的自己合法换来的生路。
- **Collision:** 沈峥想从朋友身上验证自己的救赎路径，朋友却拒绝成为他的答案。
- **Irreversible residue:** 两人的友谊第一次出现价值裂缝；老卖家明确要求沈峥以后不要再替他定义“被害者”，这成为长期边界。

### Event 06｜旧买家和伴侣暂时站在同一边
- **Active wants:** 沈峥面对家庭资金压力，认真考虑再次出售一个仍属于自己的未来日期；伴侣要阻止他重启循环；关键旧买家也反对，因为他比任何人都清楚沈峥今天卖掉的已经不是当年的穷青年。
- **Collision:** 沈峥发现最坚持“过去交易有效”的两个人，此刻都要求他不要再交易。
- **Irreversible residue:** 伴侣第一次承认旧买家不是单纯敌人；旧买家则失去“只关心自己资产”的安全位置，成为会干预沈峥未来选择的人。

### Event 07｜同事不再替他遮空缺
- **Active wants:** 沈峥希望同事竞争者在一个既有合同日替自己承担关键工作，日后再回报；同事拒绝，明确表示自己要的不是人情，而是让组织承认“稳定可用”本身就是能力。
- **Collision:** 沈峥习惯用能力补回缺席，同事要逼他承认缺席会重新分配权力。
- **Irreversible residue:** 一项核心职责正式从沈峥手中转到同事名下；两人以后不再能回到“只是互相帮忙的同事”关系。

### Event 08｜合同结束，关系不结束
- **Active wants:** 关键旧买家的一个重要持仓终于执行完，沈峥想把双方关系停在“债务结清”；旧买家则要求以后仍能以朋友身份联系，不再靠合同召他出现。
- **Collision:** 沈峥曾经最想要的“执行完就自由”真的出现时，反而要亲手决定是否删掉已经长成的人。
- **Irreversible residue:** 沈峥把旧买家留在私人通讯录中；从此两人之间再没有强制权，却多了一段更难否认的自愿关系。

### Event 09｜伴侣发现那个人还在通讯录
- **Active wants:** 伴侣想确认旧买家退出合同后是否也退出家庭边界；沈峥坚持保留这段朋友关系；旧买家主动提出不再进入家庭重要日期，却不愿假装彼此毫无关系。
- **Collision:** 伴侣过去一直要求“合同结束”，现在发现真正难处理的是合同结束后的感情残留。
- **Irreversible residue:** 三方约定一条新的私人边界：旧买家不再以持仓身份进入家庭安排，但可以作为沈峥个人朋友存在；伴侣不再拥有“一刀切删除”的位置。

### Event 10｜老卖家站到伴侣那边
- **Active wants:** 沈峥因为旧合同再次想主动放弃一个职业机会以降低未来持仓价值；老卖家朋友认为这不是尊重过去，而是在让过去继续支配现在；伴侣同样要求他接受机会。
- **Collision:** 最反对“赎回崇拜”的老卖家，反而最不能接受沈峥为了合同自我贬值。
- **Irreversible residue:** 沈峥被迫承认“保留过去选择”和“让过去继续决定未来”不是一回事；老卖家从观点对手变成可以在关键时刻制止他自毁的人。

### Event 11｜同事把秘密变成公开资格问题
- **Active wants:** 同事竞争者要求团队以后所有关键岗位都提前披露不可自主到场的日期，以确保公平；沈峥认为这会把私人旧史永久职业化；伴侣却认为彻底披露反而能结束长期隐瞒。
- **Collision:** 同一项透明措施既可能是职业歧视，也可能是沈峥一直逃避的诚实。
- **Irreversible residue:** 沈峥主动披露一部分关键不可用日期，职业上失去若干排他性机会，却也第一次不再靠临时遮掩维持形象。

### Event 12｜谁有权解释那笔救命钱
- **Active wants:** 关键旧买家想让沈峥公开承认当年那笔钱确实救过命；沈峥愿意承认事实，却拒绝因此把今天的持有关系包装成天然正当；老卖家朋友则坚持“接受那笔钱的人不能后来替穷时的自己道歉”。
- **Collision:** 三个人都在争同一段过去的叙述权，而没有一个版本能独占事实。
- **Irreversible residue:** 沈峥第一次形成公开的复杂表述：既不否认救命，也不把救命等同于永久道德豁免；旧买家得到部分承认，却失去要求“感恩=服从”的可能。

### Event 13｜完全自由的一天，没人知道怎么过
- **Active wants:** 沈峥难得拥有一整段无合同切口的普通时间，想证明自己终于会生活；伴侣只想把它浪费掉，不做任何“纪念自由”的仪式；老卖家朋友临时约他见面，认为真正的自由包括随时改变计划。
- **Collision:** 三个人都赞成自由，却对“自由是不是应该被精心使用”完全不同。
- **Irreversible residue:** 沈峥最终取消自己准备好的“自由日清单”，选择跟伴侣过最普通的一天；他第一次主动放弃把未来时间继续资产化、优化和证明的冲动。
- **Ordinary-life proof:** 没有新合同、新客户、危机或制度动作，人物关系本身仍成立。

## Stress Result

- **Natural count:** 13
- **Premature exhaustion:** no
- **New Case / new client used:** no
- **New rule / new institution used:** no
- **At least two independently active characters per event:** yes
- **Irreversible residue:** 13/13
- **Two non-protagonists with continued pull:** 伴侣、关键旧买家；老卖家朋友与同事竞争者也具备持续发动能力。
- **Protagonist-offscreen test:** 通过。即使沈峥消失一天，伴侣与旧买家仍会围绕边界与承诺发生冲突；同事会继续争岗位；老卖家仍会坚持自己的合同观。
- **Character-engine note:** R1 的强点不是“还有多少旧日期”，而是旧持仓把伴侣、买家、朋友、竞争者变成彼此会长期重写关系的人。
