# R5｜This City I Have Routes｜Character Collision Stress Test

status: STRESS-TESTED  
decision: D-0082  
source_boundary: D-0081 survivor only  
concept_mutation: none

> **Special hard ban:** 不新增任何路权，不以“再修一处 → 再拿一条路”续命。只使用已获得路线、已有小店/医院/既有物业关系、安保主管、老骑手、新骑手等已经形成的关系。

## Frozen Core Cast｜6

### C1｜主角骑手
1. **当前最想得到什么：** 让多年换来的既有路线真正改善生活，并确认债务压力下降后这些路对自己还意味着什么。
2. **最怕失去什么：** 已有路线因关系断裂、建筑变化或被人利用而从“自己的第二座城市”重新变成普通地图。
3. **不愿付什么代价：** 不愿把所有关系都降成维护节点的工具，也不愿重新变成只追分钟数和单量的人。
4. **与主角无关也会继续推进的生活：** 会继续配送、还债、维护已有路线与沿线关系；即使不再获得一条新路，已有网络仍需使用、协作和维护。
5. **天然冲突：** 与安保主管争效率与安全；与老骑手争公平和经验位置；与新骑手争网络是否必须围绕自己；与老店主争店铺去留；与老人争路线时间到底先给收入还是责任。

### C2｜安保主管
1. **当前最想得到什么：** 让既有穿行权在可审计、安全、不会被无限外推的边界内运行。
2. **最怕失去什么：** 一堆“每段都合法”的个人路线组合成无人真正负责的灰色基础设施。
3. **不愿付什么代价：** 不愿因为主角曾经有公共价值就放弃规则，也不愿把安全例外变成私人恩情。
4. **与主角无关也会继续推进的生活：** 会继续守建筑、处理安全、维护秩序；即使主角不出现，他也会与其他使用者发生规则摩擦。
5. **天然冲突：** 与主角争速度边界；与新骑手争扩张欲；与老店主在“私人钥匙/熟人便利”上也天然不合。

### C3｜老骑手
1. **当前最想得到什么：** 保住自己的饭碗、尊严和多年城市经验，不被主角与新骑手的私路线网络淘汰。
2. **最怕失去什么：** 自己从“懂这座城的人”变成只能跟着别人走的落伍者。
3. **不愿付什么代价：** 不愿接受只有复制主角路线才算进步，也不愿长期免费替别人兜底。
4. **与主角无关也会继续推进的生活：** 会继续跑单、维护自己的既有入口和客户关系、判断何时退休或转向更稳定节奏。
5. **天然冲突：** 与主角争优势是否公平；与新骑手争谁代表下一代骑手；与安保主管在经验便利和规章上经常冲突。

### C4｜新骑手
1. **当前最想得到什么：** 证明自己不是主角的附属，依靠已经获得的独立路权形成自己的第二张城市地图。
2. **最怕失去什么：** 所有成功都被解释成“主角带出来的”，最终只能在别人网络里当节点。
3. **不愿付什么代价：** 不愿把自己的路线无条件共享，也不愿永远按主角的维护优先级行动。
4. **与主角无关也会继续推进的生活：** 会继续跑单、使用自己已有路权、建立自己的工作节奏和城市关系。
5. **天然冲突：** 与主角争去中心化；与老骑手争新旧经验；与安保主管争年轻人更激进的组合使用方式。

### C5｜老店主
1. **当前最想得到什么：** 决定自己的店是继续开、缩小还是退出，而不是因为主角需要屋顶节点就被迫维持亏损。
2. **最怕失去什么：** 自己多年经营的店最后只被别人记成一段捷径。
3. **不愿付什么代价：** 不愿为了主角的路线价值继续无止境亏钱，也不愿把私人信任完全变成制度手续。
4. **与主角无关也会继续推进的生活：** 会继续经营或准备退出、处理店员与家庭现实；路线只是其中一项关系。
5. **天然冲突：** 与主角争“店是生活还是节点”；与安保主管争私人钥匙和正式登记边界。

### C6｜沿线老人
1. **当前最想得到什么：** 稳定获得日常药物与帮助，而不是每次都因为骑手今天有没有大单而重新赌一次。
2. **最怕失去什么：** 主角网络越成功，自己这种低收益、无订单价值的日常关系越先被挤掉。
3. **不愿付什么代价：** 不愿把情分变成正式付费大单，也不愿成为主角证明“我有温情”的道具。
4. **与主角无关也会继续推进的生活：** 会继续看病、拿药、安排自己的日常，也会主动寻找更稳定的照护方式。
5. **天然冲突：** 与主角争时间优先级；与新骑手/老骑手争“谁愿意承担不赚钱的路线责任”。

## Character Collision Events｜12

### Event 01｜老店主真的想关门
- **Active wants:** 老店主想止损关店；主角想保住经过该店的既有关键节点，主动提出继续帮店找生意；店主拒绝让自己的去留继续被别人的路线价值绑架。
- **Collision:** 主角越在乎这家店，越暴露最初的在乎来自自己的资产利益。
- **Irreversible residue:** 老店主明确给出一个退出期限；主角第一次必须面对“关系不是因为我需要就必须持续”。

### Event 02｜那把钥匙到底算信任还是违规便利
- **Active wants:** 老店主坚持让主角保留私人钥匙，视为“自己人”；安保主管要求所有既有穿行继续按登记规则走；主角既珍惜信任又怕破坏路权合法性。
- **Collision:** 私人关系升级与制度边界直接冲突，没有任何新路可争。
- **Irreversible residue:** 主角把钥匙还回去，但与老店主约定他仍可在非路线事务上来店里；两人的关系第一次从“通行便利”中被剥离出来。

### Event 03｜老骑手不再替他跑低收益关系单
- **Active wants:** 主角希望老骑手在自己忙时替沿线老人送药；老骑手拒绝，认为主角不能一边独享高效率路线，一边把低收益责任社会化给别人。
- **Collision:** 路线复利带来的“关系债”到底属于个人还是整个骑手网络。
- **Irreversible residue:** 老骑手与主角停止默认互相兜底，之后所有帮助都必须明确交换；友情从模糊同行情分变成有边界的合作关系。

### Event 04｜新骑手愿意送药，但不是替主角还债
- **Active wants:** 新骑手主动愿意帮老人，却要求老人以后直接联系自己；主角担心一段自己多年形成的关系被“接走”；老人只想要更稳定的人。
- **Collision:** 主角第一次发现自己也会把“照护关系”当成路线资产的一部分。
- **Irreversible residue:** 老人把新骑手加入固定联系人；主角失去对这段关系的独占感，新骑手获得第一个不依赖主角的长期责任。

### Event 05｜安保主管按最严格边界执行，老骑手却支持他
- **Active wants:** 主角要恢复已有路线的最高效率；安保主管坚持所有安全例外都按最严格标准；老骑手反而支持安保，因为他不想私路优势继续拉大同行差距。
- **Collision:** 主角发现过去最懂骑手辛苦的人，也可能反对自己的效率优势。
- **Irreversible residue:** 老骑手与主角的价值冲突公开化；安保主管不再是孤立对手，而成为其他角色可以主动结盟的规则方。

### Event 06｜新骑手拒绝把自己的路并进“你的网络”
- **Active wants:** 主角希望统一协调双方已经拥有的路线与订单，让组合效率最大化；新骑手只愿临时协作，拒绝把自己的路线称为主角网络的一部分。
- **Collision:** 主角嘴上支持别人拥有自己的城市，真正发生去中心化时却失去控制感。
- **Irreversible residue:** 两人建立“路线各自所有、只按次协作”的明确边界；主角第一次接受网络可以存在而不属于他。

### Event 07｜老骑手要求一次公平交换
- **Active wants:** 老骑手要用自己已经拥有的入口与主角交换一次路线协作，而不是继续以“你带我见过第二城市”的人情身份求帮；主角习惯把自己视为先行者。
- **Collision:** 两人争的不是一条新路，而是谁有资格作为平等资产持有人谈合作。
- **Irreversible residue:** 主角第一次按平等条件交换，不再把老骑手当被自己带入系统的人；老骑手从追随者位置退出。

### Event 08｜店如果留下，不许只为你那几分钟
- **Active wants:** 主角继续帮助老店主维持经营；老店主同意再试一段时间，但要求主角不要再把“保住节点”当主要理由，而要承认如果店最终仍不值得开，他会接受关闭。
- **Collision:** 主角必须证明关系能够承受资产消失的可能。
- **Irreversible residue:** 主角明确承诺店关了也不会因此结束往来；老店主第一次把主角视为可能超出路线利益的朋友。

### Event 09｜老人不愿再欠“顺路人情”
- **Active wants:** 老人想给主角、新骑手固定一点报酬，让帮助不再全靠情分；主角坚持只是顺路；新骑手支持老人，因为他不想低收益责任永远靠个人善意维持。
- **Collision:** 三个人争“照护是关系、劳动还是交易”。
- **Irreversible residue:** 老人开始象征性付费并拥有明确联系人安排；关系从模糊恩情转成可持续的长期承诺。

### Event 10｜债务安全以后，老骑手问他为什么还这么拼
- **Active wants:** 主角仍持续维护路线；老骑手希望他既然债务已到安全线就减少工作、别把所有人拖入一张永远扩张的效率网；新骑手却想把现有路线组合出更高收益。
- **Collision:** 三代式位置同时出现：一个想慢下来，一个不知道为什么停不下，一个正想加速。
- **Irreversible residue:** 主角第一次拒绝以“还债”解释自己，承认维护路线已经是身份选择；老骑手也第一次把退出/减速当成自己的正当选择。

### Event 11｜不接单的夜里，三个人走同一座不同的城
- **Active wants:** 主角想沿自己的既有路线走一遍，确认它脱离赚钱后是否仍有意义；新骑手故意用自己的既有路线先到终点，想证明自己已有独立城市；老骑手选择走公共道路，拒绝参加“谁的地图更强”的竞赛。
- **Collision:** 三个人对“懂这座城”拥有三种互不服从的定义。
- **Irreversible residue:** 主角承认新骑手不再是学徒，老骑手也不再需要进入私人路线体系证明价值；三人关系从师徒/新旧竞争变成并列的城市生活者。
- **Ordinary-life proof:** 无订单、无新路、无危机，仍能成立。

### Event 12｜谁来维护已经有的那张网
- **Active wants:** 主角希望老骑手、新骑手和自己轮流处理已有路线节点的日常维护与关系沟通；新骑手坚持只为自己真正拥有的路负责，不愿替“主角的城市”做免费劳动；老骑手则要求先把过去那些默认互相兜底的人情账说清；安保主管只认各人原有通行依据，不接受主角替所有人统一承诺。
- **Collision:** 没有一条新路，冲突仍会出现：资产一旦长期存在，谁享受组合收益、谁承担维护成本就必须重新谈。
- **Irreversible residue:** 四人把既有路线从“主角默认统筹”拆成各自负责、协作另议；主角永久失去把整个网络当作自己单一资产管理的默认位置。
