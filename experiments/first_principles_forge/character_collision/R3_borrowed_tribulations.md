# R3｜Borrowed Tribulations｜Character Collision Stress Test

status: STRESS-TESTED  
decision: D-0082  
source_boundary: D-0081 survivor only  
concept_mutation: none

> **Special hard ban:** 本文件不新增任何历史来源劫，不新增强者旧账，不新增承受者。只使用周野体内已经存在的旧风险、老承受者、家人、年轻风险卖家、原雇主/旧强者关系，以及周野自己的突破。

## Frozen Core Cast｜5

### C1｜周野
1. **当前最想得到什么：** 完成真正属于自己的修行与突破，同时不再把旧风险转嫁给下一人。
2. **最怕失去什么：** 一生靠停止成长换安全，或在死亡压力下最终变成自己一直反对的风险买家。
3. **不愿付什么代价：** 不愿把贫穷者的“自愿”当作道德清白，也不愿让家人永远替自己的原则承担照护成本。
4. **与主角无关也会继续推进的生活：** 他会继续修行、赚钱、照顾家人、管理已知旧风险；自己的突破本身会持续改变关系。
5. **天然冲突：** 与家人争“活着 vs 继续修行”；与年轻卖家争“谁有资格替穷人拒绝交易”；与原雇主争责任与历史叙述；与老承受者争交易是否值得。

### C2｜老承受者
1. **当前最想得到什么：** 活下去，也要保住“当年卖风险值得”的判断，不让今天的痛苦羞辱当年的自己。
2. **最怕失去什么：** 被周野或外界重新定义成一个需要被拯救、被纠正的受害者。
3. **不愿付什么代价：** 不愿以否认过去选择来换周野的认同。
4. **与主角无关也会继续推进的生活：** 他会管理自己已经存在的风险、工作、吃饭、继续决定是否求助以及如何理解当年交易。
5. **天然冲突：** 与周野争价值判断；与家人代表争“活命是否可以再次转移风险”；与年轻卖家既可能共鸣也会冲突。

### C3｜家人代表
1. **当前最想得到什么：** 周野活着、身体稳定，家庭不再被每次突破拖入长期照护与经济风险。
2. **最怕失去什么：** 因周野坚持“不转嫁”与继续修行，家人最终成为没有签过任何合同的实际承受者。
3. **不愿付什么代价：** 不愿为了尊重周野的道德底线就被要求接受他可能死去。
4. **与主角无关也会继续推进的生活：** 会继续家庭经济、照护安排与自己的日常，不会只作为“劝退修行”的声音存在。
5. **天然冲突：** 与周野争风险选择；与年轻卖家可能私下达成“付钱换命”的现实联盟；与老承受者在交易伦理上也可能更接近。

### C4｜年轻风险卖家
1. **当前最想得到什么：** 获得足以改变现实处境的钱与选择权，而不是被前辈用道德理由替自己决定什么不能卖。
2. **最怕失去什么：** 因为周野的愧疚而被当成一个没有判断力、只需被救的穷人样本。
3. **不愿付什么代价：** 不愿免费承担别人风险，也不愿把自己整个人生献给一次买卖。
4. **与主角无关也会继续推进的生活：** 会继续挣钱、寻找出路、衡量风险与现实机会；是否接单只是其生活的一部分。
5. **天然冲突：** 与周野争“知情自愿是否足够”；与家人代表在救周野这件事上利益可能一致、价值却不同；与老承受者对“卖命值不值”也会互相照镜子。

### C5｜原雇主 / 旧强者
1. **当前最想得到什么：** 保住自己今天的生活与名誉，同时不再被几十年前已经付清的交易无限追索。
2. **最怕失去什么：** 自己过去靠转移风险活下来的事实吞掉今天全部成就，也怕再次接触旧劫会反噬自己。
3. **不愿付什么代价：** 不愿承认“付过钱=永远欠周野一条命”，也不愿把所有荣耀都让给历史债务解释。
4. **与主角无关也会继续推进的生活：** 会继续自己的修行、名誉与家庭/社会关系，并主动决定是否帮助、赔偿、公开承认或保持距离。
5. **天然冲突：** 与周野争责任边界；与老承受者争“交易结束后还有没有道德债”；与年轻卖家对当年的交易逻辑可能产生刺眼共鸣。

## Character Collision Events｜12

### Event 01｜家人背着他再次联系年轻卖家
- **Active wants:** 家人代表想在周野既有风险下一次成熟前留下可执行的转移方案；年轻卖家要一笔足够高的钱；周野坚持不转。
- **Collision:** 家人和年轻人都在做理性的现实选择，周野反而成了唯一试图阻止双方自愿交易的人。
- **Irreversible residue:** 周野发现家人已经为交易准备过钱，家庭信任出现真实裂痕；年轻卖家也不再把周野视为天然站在自己一边的人。

### Event 02｜“你不让我卖命，却让家里替你扛”
- **Active wants:** 年轻卖家要求周野正面回答为什么他的贫困不算合法理由，而周野自己的修行欲望却能让家人承担照护；周野想守住“不复制链条”的底线。
- **Collision:** 主角的道德立场第一次被另一个穷人从内部反驳，而不是被强者嘲笑。
- **Irreversible residue:** 周野停止用“我是为你好”劝年轻人；两人关系从救助者/被救者变成可以互相质问的成年人。

### Event 03｜老承受者站在家人一边
- **Active wants:** 老承受者认为周野应该在必要时把一部分既有风险合法转给年轻卖家，因为活下来才有资格谈原则；家人代表同意；周野拒绝。
- **Collision:** 最理解承受痛苦的人并没有因此得出和周野相同的伦理答案。
- **Irreversible residue:** 周野与老承受者第一次真正翻脸，互助关系不再建立在“我们终究是一边”的幻觉上。

### Event 04｜原雇主必须再陪他一夜
- **Active wants:** 周野需要原雇主在场稳定一块**已经存在**的来源风险；原雇主想维持距离，只愿付钱不愿再进入身体风险现场。
- **Collision:** 钱已经不能替代那个人本人，而原雇主最想结束的关系恰好被旧风险继续维系。
- **Irreversible residue:** 原雇主最终留下并共同熬过一夜；两人从纯交易旧识变成拥有一段新的、无法用旧合同结清的共同经历。

### Event 05｜陪完这一夜，不等于我欠你一辈子
- **Active wants:** 周野把原雇主那一夜视为责任终于开始被承担；原雇主坚持这只是一次主动帮助，不接受“终于还债”的定义。
- **Collision:** 两个人连善意应该被记成什么都无法一致。
- **Irreversible residue:** 原雇主明确拒绝“债主/欠债人”关系框架；周野被迫把他当一个会再次主动选择的人，而不是只会还历史账的来源者。

### Event 06｜赔偿钱该不该用
- **Active wants:** 原雇主愿意为既有风险造成的长期后果支付补偿；家人代表想立刻接受并改善家庭生活；周野担心钱会换走以后追问责任的资格。
- **Collision:** 家人要的是眼下可用的生活，周野要的是不被钱重新结清的历史。
- **Irreversible residue:** 补偿进入家庭并被真正使用；周野以后再也不能站在“我们没拿过你的钱”的纯粹位置上，家人与原雇主也因此形成直接利益联系。

### Event 07｜年轻卖家不要周野的“替代人生”
- **Active wants:** 周野尝试帮年轻人寻找别的挣钱方式，想证明风险不是唯一资产；年轻人接受帮助，却拒绝成为周野的徒弟或道德成果，要求自己决定何时离开。
- **Collision:** 周野把“不让他卖风险”逐渐变成另一种控制，年轻人要回选择权。
- **Irreversible residue:** 两人约定任何帮助都不能附带“不许再卖风险”的条件；周野失去把对方未来当成自己原则证明的资格。

### Event 08｜老承受者第一次真的怕了
- **Active wants:** 老承受者因自己**已存在**的一块风险临近成熟而请求周野帮助；周野想救他，也期待对方终于承认当年交易不值；老承受者只要活下来，不愿改口。
- **Collision:** 周野把救人和价值观胜利绑在一起，对方拒绝用认错支付帮助。
- **Irreversible residue:** 周野仍然帮；之后老承受者继续坚持“当年值得”。两人的互助关系从“等待对方被说服”变成接受长期不一致。

### Event 09｜自己的突破，还是朋友的窗口
- **Active wants:** 周野准备抓住自己的突破窗口；老承受者在同一时段需要他协助压住既有风险，并直接请求他留下；家人代表反而希望周野优先自己，因为错过机会会延长整个家庭的悬置。
- **Collision:** 这次没有新劫、新强者，只有两条已经建立的人生关系争同一段不可逆时间。
- **Irreversible residue:** 周野选择救老承受者并错过突破；老承受者因此欠下不是钱能清的关系债，家人也第一次因周野“把别人放在自己与家庭前面”留下怨。

### Event 10｜老承受者想替他承担一点
- **Active wants:** 为偿还 Event 09 的债，老承受者主动提出利用**既有可转移规则**替周野接下一小部分当前风险；周野拒绝复制链条；老承受者坚持这是成年人之间的主动互助，不是买卖。
- **Collision:** 同一个动作若没有钱，还是不是周野反对的“转嫁”？
- **Irreversible residue:** 周野最终仍不转，但承认自己过去把“任何由别人承担”都简单归为恶；两人的价值关系发生永久细化，却没有消除冲突。

### Event 11｜年轻卖家反过来质问他的突破
- **Active wants:** 周野再次准备突破；家人代表要求停止；年轻卖家则支持他继续，因为“你不能一边说我的命由我定，一边不让自己的命由你定”。
- **Collision:** 年轻人把周野曾给予自己的自主原则反过来用在周野身上，而家人承担的成本又真实存在。
- **Irreversible residue:** 家人不再接受“原则”作为结束争论的万能词；周野必须在突破前明确安排照护与经济代价，个人修行正式变成家庭共同协商事项。

### Event 12｜成了传奇以后，谁的名字必须被留下
- **Active wants:** 周野突破后不愿被塑造成“独自扛过一切”的传奇，坚持公开念出老承受者、家人、年轻卖家与原雇主在自己人生里留下的真实作用；原雇主不愿自己被永久钉成旧风险来源；老承受者则要求别把自己包装成被周野救赎的受害者。
- **Collision:** 每个人都要求被记住，却要求以不同身份被记住。
- **Irreversible residue:** 周野公开采用一套不统一价值判断、只承认共同历史的叙述；从此他的公共身份不再能建立在“一个人扛过”的神话上，也不能把其他人压成配角。
- **Ordinary-life carryover:** 事件后的关系债会继续回到家庭饭桌、钱、照护与下一次个人选择，不需任何新来源劫。
