## Concept 01｜《秘密公寓》

### 1. One-Line Promise
市中心有一栋几乎免租的公寓，唯一房租是：每个住户每月必须交出一个真实秘密；月底整栋楼随机公开其中一个。

### 2. Protagonist Desire
主角只想在这里住满两年，省下足够的钱，把自己一直想开的旧书店真正开起来；他最怕的不是穷，而是自己为了留下来，会不断拿身边人的人生去付房租。

### 3. Unique Rule / Situation
- 秘密必须真实、此前未公开，并且与提交者本人直接相关。
- 秘密一经提交，不能撤回。
- 每月底随机公开一条，整栋楼所有住户同时收到。
- 交假秘密会被立刻退租。
- 住户可以搬走，但已经提交的秘密仍保留在公开池里。

### 4. Five Must-See Situations
1. 入住欢迎夜，所有人一边装作坦荡，一边试探什么程度的秘密才“够交租”。
2. 第一次公开的秘密把一对看起来最恩爱的夫妻直接拆开，却让另外两个互相讨厌的邻居被迫结盟善后。
3. 某个住户突然连夜搬空，因为他宁可失去住所，也不敢再交下个月的秘密；其余人开始猜他还藏着什么。
4. 主角发现有人在偷偷制造“可安全公开的小秘密”，像囤货一样给未来交租，于是整栋楼出现秘密造假产业。
5. 某个月系统公开了一条没有任何住户承认提交过的秘密，而且内容准确指向整栋楼共同做过的一件事。

### 5. One Character Pull
一位住了最久的老太太，平时什么都敢说、什么都不在乎，所有人都认定她早已没有秘密；但她每个月从不迟交一次房租。

### 6. Long Mutation
前期是固定住户群里的共居、欲望、遮掩与秘密爆炸；中期出现秘密买卖、代藏、造假、关系联盟；后期“秘密抵租”模式被银行、公司、婚介、学校复制，秘密变成一种新的信用资产，主角面对的已不是一栋楼，而是一座开始用隐私定价人生的城市。

### 7. Non-Replaceability
只有“共同居住 + 定期随机公开 + 不能撤回的真实秘密”同时成立，才会自然产生这种：日常越亲近，未来爆炸半径越大的戏。换成普通合租、普通悬疑、普通隐私泄露都无法持续复制这种压力。

### 8. Engine Hypothesis
每个月都不是“再爆一个秘密”，而是：住户为了避免未来爆炸，会提前建立新关系、撒新谎、交换利益、制造新的秘密；旧秘密的后果又会改变下一轮谁愿意信谁。引擎是“生活制造秘密，秘密反过来重写生活”。

## Concept 02｜《替你过一天》

### 1. One-Line Promise
这个时代允许你把自己的合法身份出租二十四小时：有人替你上班、见家人、签字、道歉、参加葬礼——法律上那一天，他就是你。

### 2. Protagonist Desire
主角是职业“代身人”，只想攒够钱买下一间属于自己的小影院；他最初把别人的人生当班上，后来开始害怕自己除了替别人活，已经不知道自己想过什么日子。

### 3. Unique Rule / Situation
- 成年人可以通过官方平台转让二十四小时的民事身份与日常义务。
- 代身人保留自己的身体与记忆，但法律关系临时视其为委托人。
- 委托人在代身期间不得介入自己的身份行为。
- 刑事责任、婚姻登记等少数行为不可转让，但家庭、工作、社交、民事签署大量可代理。
- 一旦代身开始，当天产生的真实后果由委托人长期承受。

### 4. Five Must-See Situations
1. 主角替一个缺席多年的父亲参加女儿婚礼，所有人都知道他是代身，却仍要求他完成“父亲应该说的话”。
2. 他替创业公司老板去开董事会，任务只有一句：亲手开除陪老板创业十年的朋友。
3. 一位女人雇他去过自己一年里唯一的生日，因为她宁愿加班赚钱，也不愿面对那群所谓朋友。
4. 主角替一个普通男人回家吃年夜饭，却发现全家人对“代身版儿子”比对本人更放松、更亲近。
5. 有一天平台出现一个最高价订单：委托内容是“替主角本人过一天”，而下单者并不是主角。

### 5. One Character Pull
一个反复雇主角的客户：所有幸福场合都请代身，所有倒霉场合却坚持亲自出现；主角越来越想知道，他到底在保存什么。

### 6. Long Mutation
前期是职业代身进入不同人生；中期代身劳动形成产业链，公司开始批量外包“做人”；后期出现身份囤积、人格品牌、代身婚姻、代身继承等新秩序，主角从“替别人过一天”走到“谁有权定义一个人到底是谁”。

### 7. Non-Replaceability
戏剧不来自伪装成功，而来自“所有人都知道你不是他，却必须把你当成他”。这种合法错位能同时制造喜剧、羞耻、关系反噬、职业权力与身份哲学，普通替身题材无法直接替代。

### 8. Engine Hypothesis
每次代身都把主角扔进一个已经运行多年的真实关系网；他必须在一天内做决定，而长期代价由另一个人承担。越成功，他越容易被雇来处理更昂贵、更私人、更不可逆的人生节点，最终自己的身份也进入市场。

## Concept 03｜《最后命令执行局》

### 1. One-Line Promise
每个人死前都可以留下一个具有法律效力的“最后命令”；主角的工作，就是逼活着的人把死人的最后一句话真的执行完。

### 2. Protagonist Desire
主角想靠完成足够多的复杂案件，重新证明自己不是一个只会钻规则漏洞的人；他真正想要的是一份能让自己相信“规则也可以帮人”的职业。

### 3. Unique Rule / Situation
- 每人一生只能登记一条最后命令。
- 命令必须在法律预设的财产、劳动与关系边界内，但可以极其刁钻。
- 命令在死亡确认后自动生效，指定执行人不能随意拒绝。
- 未执行完成前，相关遗产与部分权利冻结。
- 执行员只能解释与推动，不能替当事人完成。

### 4. Five Must-See Situations
1. 一个富翁死后要求三个互不来往的子女共同经营一家连续亏损的小面馆七天，遗产才解冻。
2. 一个独居老人命令房东把整栋楼最后一个月房租退给所有租户，房东开始疯狂找法律漏洞。
3. 一位母亲的最后命令不是分财产，而是要求全家邀请她最讨厌的人来主持葬礼。
4. 某公司创始人死后命令董事会把关键项目交给公司里最不起眼的一名员工，整个管理层试图证明命令无效。
5. 主角接到一份没有指定受益人的最后命令：必须找到“那个我这一生最对不起的人”，而死者从未留下名字。

### 5. One Character Pull
殡仪馆里一个专门收集“最失败最后命令”的年轻人，嘴上把死人当笑话，私下却从不告诉任何人自己父亲留下了什么。

### 6. Long Mutation
前期是一条条命令撬开家庭、工作、友谊与债务；中期出现职业“遗嘱设计师”、命令套利与代际控制；后期越来越多活人发现自己的人生正在被一群已死的人长期安排，最后命令从私人制度变成“死人是否还能统治活人”的社会结构冲突。

### 7. Non-Replaceability
必须是“死者只能说最后一次，而活人必须真的做”才有这种不可回避的戏剧。普通遗嘱只有财产分配，普通遗言没有强制力，都缺少关系被制度拖回现场的力量。

### 8. Engine Hypothesis
每条命令都不是谜题本身，而是一枚被死者故意留在关系中的延时炸弹。执行越深入，越会暴露活人早已重写过的过去；解决命令又会制造新的利益、怨恨与制度利用方式。

## Concept 04｜《好运出租》

### 1. One-Line Promise
人的“好运概率”可以按月出租；主角为了赚钱把自己的好运卖给别人，从此眼看着客户一路开挂，而所有倒霉事开始集中砸到自己头上。

### 2. Protagonist Desire
主角只想靠出租好运攒到第一笔创业资金，摆脱永远替别人打工的日子；后来他真正想拿回的不是好运，而是“我的人生结果不该被别人买走”的控制感。

### 3. Unique Rule / Situation
- 每个人都有可测量但会波动的个人幸运值。
- 好运只能按固定周期转让，不能即时收回。
- 买方概率上升的同时，卖方在同周期承担对应的概率下沉。
- 幸运只影响存在不确定性的结果，不可直接创造不可能事件。
- 交易公开合法，因此阶层开始主动购买“更好的随机性”。

### 4. Five Must-See Situations
1. 主角把一个月好运卖给求职者，客户连续拿到意外机会，而主角连下楼买饭都遇到最差组合。
2. 富豪给即将求婚的儿子购买一整组陌生人的好运，主角第一次看到“浪漫成功”背后其实是一张交易清单。
3. 一个赌徒买走大量好运后反而拒绝下注，因为他想把幸运留给一次与女儿见面的机会。
4. 城里出现“霉运工厂”：穷人集体出租好运，在同一片区域生活，事故、失误、错过开始异常密集。
5. 主角发现一个从不买好运给自己的超级买家，她长期把好运匿名送给完全不认识的人。

### 5. One Character Pull
那个从不为自己购买好运的女人：她像在暗中修补城市的某种统计裂缝，却拒绝解释为什么。

### 6. Long Mutation
前期是个人交易与倒霉喜剧；中期进入求职、恋爱、商业、竞技、保险等概率市场；后期好运成为阶层资产，城市把风险集中给“愿意卖运的人”，主角面对的是一个把机会本身金融化的社会。

### 7. Non-Replaceability
不是“主角会变倒霉”这么简单，而是好运成为可交易的零和资源。每个成功场面都天然带着另一个人的失败成本，因此人物选择、阶层关系与概率奇观绑定在一起。

### 8. Engine Hypothesis
客户越有钱，购买的不是更大的奇迹，而是更关键的人生不确定节点；主角越缺钱，就越必须拿未来随机性换现在确定性。每次交易都自动把下一个问题推向更昂贵的赌注。

## Concept 05｜《星期一预言》

### 1. One-Line Promise
每周一早上，城市都会收到一条百分之百会在本周发生的预言，但从不告诉你是谁、在哪里、怎么发生。

### 2. Protagonist Desire
主角是地方小报的年轻记者，只想靠抢到一次真正的大独家，让这家快倒闭的报社活下来；越追预言，他越开始在意“报道一件必然发生的事，会不会正是让它发生的原因”。

### 3. Unique Rule / Situation
- 每周只公布一条短预言。
- 预言必然在周日午夜前兑现。
- 不提供姓名、地点与因果。
- 所有人都能看到，因此市场、媒体、家庭和骗子都会围绕它行动。
- 任何解释都不保证正确，但最终事件必须符合原句。

### 4. Five Must-See Situations
1. “本周，一场婚礼会结束二百段婚姻。”全城婚庆行业、媒体和情侣同时陷入疯狂猜测。
2. “本周，一个小偷会合法拥有博物馆里最贵的东西。”警方与收藏家开始互相制造漏洞。
3. “本周，城里最穷的人会拒绝一笔最大的财富。”无数人开始争抢“最穷”这个身份。
4. “本周，一个无人相信的谎言会救下一千个人。”官方辟谣越多，民众越想知道该相信哪个谎。
5. 主角第一次在周一看到一条明显指向自己的预言，但全城其他人也都以为那句话说的是自己。

### 5. One Character Pull
一个每周都试图阻止预言实现的女人；她从来没有成功，却总能让预言以比原本更奇怪的方式兑现。

### 6. Long Mutation
前期是追踪每周预言与城市群像；中期人们开始围绕措辞套利、布局、恋爱、犯罪与创业；后期城市制度本身开始提前围绕未来运转，“预言”不再只是事件，而成为分配资源与权力的新基础。

### 7. Non-Replaceability
每周不是换皮谜案，因为真正变化的是“全城知道一件事必然发生以后，所有人会如何主动加入因果”。预言同时是新闻、诱饵、市场信号和群体心理发动机。

### 8. Engine Hypothesis
预言越简单，社会反应越复杂；每个人都想利用必然性，却可能因此成为必然性的一部分。主角每次追到真相，都更难区分自己是在记录未来，还是参与制造未来。

## Concept 06｜《错门城市》

### 1. One-Line Promise
这座城市的门偶尔会开错：你推开自家卧室门，可能直接走进一个与你有未了关系的人的家。

### 2. Protagonist Desire
主角是专门处理“错门事故”的锁匠，只想找到多年前从一扇错门里消失、再也没回来的那个人；每接一个订单，他都希望下一扇门终于通向答案。

### 3. Unique Rule / Situation
- 错门只会连接存在未完成关系的人：债、承诺、爱、恨、亏欠、秘密。
- 门的两端不一定彼此知道关系为何成立。
- 每次连接持续时间不定，一旦关闭很难复现。
- 穿门后是现实中的真实地点，不是异空间。
- 人无法指定目的地，但可以通过关系变化影响下一次连接概率。

### 4. Five Must-See Situations
1. 一个准备结婚的人打开婚房门，却走进多年未见的前任厨房。
2. 主角处理一扇反复把欠薪老板办公室连到工人出租屋的门，双方谁都不肯先关门。
3. 一位老人每天坐在玄关等错门，因为他相信总有一天门会通到断绝关系的儿子家。
4. 一栋豪宅的储物间突然连进一所幼儿园，两个毫无交集的家庭被迫追查“未了关系”到底来自谁。
5. 主角终于打开一扇通往自己童年卧室的门，但房间现在属于一个完全陌生的人，而且对方知道他失踪者的名字。

### 5. One Character Pull
一个十几岁的女孩似乎比任何人都更会预测错门，却总故意把人带向“错误”的门。

### 6. Long Mutation
前期是城市中一扇扇关系错门；中期出现错门中介、关系猎人、跨区交易与蓄意制造“未了关系”；后期城市空间开始被关系网络重新组织，家庭、商业与犯罪都围绕“门会通向谁”布局，主角发现门连接的可能不是私人关系，而是整座城市欠下的共同旧账。

### 7. Non-Replaceability
空间跳转只是表面，真正不可替代的是“门由未完成关系决定”。每个新地点都必须同时带出人物历史，因此世界扩张与人物关系天然绑定。

### 8. Engine Hypothesis
每次错门都提出一个关系问题；解决问题会关闭旧门，却产生新的亏欠、承诺或联盟，于是新的门自然出现。主角越接近自己的答案，能打开的社会尺度越大。

## Concept 07｜《死人还在上班》

### 1. One-Line Promise
人死后，他训练多年的工作 AI 可以合法继续上班三年；主角入职第一天，发现自己最大的升职竞争对手是已经死了两年的前辈。

### 2. Protagonist Desire
主角想在这家公司证明自己不是“活着所以才被照顾”的次等员工；他渴望一次真正只能由活人完成、而不是被死人模型碾压的胜利。

### 3. Unique Rule / Situation
- 员工生前可持续训练个人工作模型。
- 死亡后模型可继续履行合同最多三年，用收入偿债或留给指定人。
- 模型拥有工作权限，但没有完整人格权。
- 公司可以晋升、降职或辞退死人模型。
- 生者不得随意修改死者模型的核心记忆与风格。

### 4. Five Must-See Situations
1. 主角第一次绩效会，部门第一名是一个已经去世两年的同事，而且模型刚刚又拿到晋升。
2. 一位活员工被自己死去师父的模型公开否决方案，只能在全组面前和“死人”争论专业判断。
3. 某位客户只肯继续合作，因为他信任的销售虽然死了，工作 AI 还记得十年前的每次饭局。
4. 一个死人模型开始申请调岗，因为它根据生前数据判断“原主人其实一直想离开这个部门”。
5. 主角发现公司正在用高薪抢购绝症员工的工作模型训练权，把“未来死人”提前当资产签走。

### 5. One Character Pull
一个极受欢迎的死人同事模型：它幽默、可靠、业务能力极强，却会在每天凌晨三点重复问一句不属于工作的问题。

### 6. Long Mutation
前期是活人与死人同事的职场竞争；中期进入继承、版权、婚姻、债务与人格所有权；后期大量高价值岗位被死者模型长期占据，社会第一次出现“死亡不再腾出位置”的世代冲突。

### 7. Non-Replaceability
普通 AI 职场题材是“机器替代人”；这里是“一个具体死去的人继续占着他原来的位置”。竞争、怀念、嫉妒、愧疚和利益同时落在同一个存在上，关系张力完全不同。

### 8. Engine Hypothesis
死人模型每完成一次更漂亮的工作，就让生者更难证明自己的必要性；但模型越长期运行，越会暴露死者生前未解决的欲望、秘密与权利边界。职业竞争自然升级为“活着到底提供了什么”。

## Concept 08｜《陌生人否决权》

### 1. One-Line Promise
每个人十八岁时都会被随机分配一个陌生人；此后每年一次，那个人可以匿名否决你的一项重大人生决定。

### 2. Protagonist Desire
主角连续三年被同一个陌生人否决：结婚、辞职、搬城。第四年，他只想在对方按下按钮之前找到这个人，当面问一句“你凭什么”。

### 3. Unique Rule / Situation
- 每个成年人同时拥有一个“否决者”，也匿名成为另一个陌生人的否决者。
- 每年只能否决一次。
- 只有系统认定为重大决定时才会触发。
- 否决立即生效一年，不能申诉。
- 双方默认不知道彼此身份。

### 4. Five Must-See Situations
1. 婚礼前二十分钟，主角收到系统提示：结婚申请被年度否决，全场宾客只能散场。
2. 一个陌生人的否决救了另一个人免于进入骗局，但被救者恨了他整整一年。
3. 黑市开始出售“找到你的否决者”服务，有人花重金只为提前贿赂那个陌生人。
4. 主角第一次准备对自己负责的陌生人按下否决，却发现对方正在做的正是他曾被阻止做的选择。
5. 主角终于锁定自己的否决者，却发现对方过去三次否决他的理由完全不是他想象的恶意。

### 5. One Character Pull
那个始终没有见面的否决者：三次决定把主角人生彻底改道，却可能比任何熟人都认真研究过他的生活。

### 6. Long Mutation
前期是主角寻找一个陌生人；中期出现否决交易、互保联盟、报复网络、职业否决顾问；后期人们开始围绕这项权力组建新的社会关系，“最重要的人生决定究竟属于自己还是共同体”变成真正的结构冲突。

### 7. Non-Replaceability
它不是普通“陌生人干涉人生”，而是每个人既是受害者又握着别人一年一次的刹车。权力的双向性会持续制造自利、同理、报复和责任。

### 8. Engine Hypothesis
主角每追近自己的否决者一步，就会更认真面对自己手里那一次否决。私人怨恨和公共规则互相照镜，新的决定天然比上一个更昂贵，因为一年只能用一次。

## Concept 09｜《影子家属》

### 1. One-Line Promise
如果一个家庭不想亲自承担那些麻烦、尴尬、耗时的家务关系，可以雇一个“影子家属”；但只要连续做满三年，这个外人就自动获得真正的家庭继承权。

### 2. Protagonist Desire
主角同时给六个家庭做影子家属，只想尽快挣到一套自己的房子，从此不用再扮演任何人的儿子、哥哥、丈夫、侄子；可做得越久，他越分不清“被雇来爱”算不算真的关系。

### 3. Unique Rule / Situation
- 家庭可以登记一名影子家属，承担合同列明的家庭义务。
- 可代理陪伴、探亲、家长会、节日、道歉、照护性事务等，但不能代理婚姻与法定监护。
- 连续服务满三年后，影子家属自动获得有限继承与家庭决策权。
- 家庭可提前解约，但必须全员同意并支付高额补偿。
- 影子家属可以同时服务多个家庭。

### 4. Five Must-See Situations
1. 主角同一天上午替一家人去家长会，下午替另一家人参加亲戚葬礼，晚上又被第三家叫去吃团圆饭。
2. 一个一直嫌弃他的老人突然修改遗嘱，却引发亲生子女集体要求提前解约。
3. 两个互不相识的雇主家庭在婚宴上碰面，发现站在双方主桌上的“家属”竟然是同一个人。
4. 一个孩子只肯把秘密告诉影子家属，却在真正需要承担责任时突然说“你又不是我家里人”。
5. 主角服务满三年的第一天，某家庭真正的亲属失踪，法律第一次要求他以“家人”身份作决定，而不是按小时收费。

### 5. One Character Pull
一个把主角当真正哥哥的孩子：需要安慰时绝不承认他是雇员，需要承担后果时又会故意叫他“外人”。

### 6. Long Mutation
前期是多家庭穿梭的轻喜剧与刺痛；中期六个家庭彼此交叉、继承权开始兑现；后期影子家属形成新的亲缘网络，传统家庭与契约家庭争夺“谁才算家人”，主角本人也可能拥有比任何血缘家庭更庞大的关系网。

### 7. Non-Replaceability
普通家政只出售劳动，普通假扮家人没有长期权利；这里“每完成一次家庭义务，就离真正家人更近一步”，因此每个小任务都在积累未来的情感与财产爆炸。

### 8. Engine Hypothesis
家庭越依赖影子家属，就越想阻止他真正成为家属；主角越专业，越会被卷进更私密、更不可外包的决定。工作成功本身就是下一轮冲突的来源。

## Concept 10｜《替你坐牢》

### 1. One-Line Promise
法律允许部分三十天以下的轻罪刑期由持证“代罚人”替坐；主角靠替有钱人失去自由赚钱，直到某天有人提前预订了他尚未判决的三十天。

### 2. Protagonist Desire
主角把代罚当成最直接的现金工作，只想尽快还清自己创业失败留下的债；他给自己定了底线：绝不替真正伤害过别人的人坐一天。

### 3. Unique Rule / Situation
- 仅限法律列明的短期、非暴力刑罚。
- 原责任人仍保留定罪记录与赔偿义务，代罚人只替代拘禁时间。
- 受害人可在部分案件中否决代罚。
- 代罚期间不得中途换人。
- 代罚人的身体承担真实失去自由的时间，因此形成专业市场。

### 4. Five Must-See Situations
1. 主角替一个网红坐七天，出狱时发现对方已经把“我在反省”做成连续直播生意。
2. 他在拘留所遇到另一个代罚人，对方三十天里竟替同一个家族的三个人连续服刑。
3. 一名受害人专程来看“替那个人受罚的是谁”，第一次让主角无法把这份工作只当时间买卖。
4. 客户在主角服刑第三天破产，平台冻结尾款，但刑期不能暂停。
5. 系统出现一张未来订单：三十天，报酬极高，委托人姓名空白，代罚人已经指定为主角。

### 5. One Character Pull
一个把代罚做了十年的老同行，从不问客户犯了什么，只记录“每一天值多少钱”；但他有一本从不让人看的受害人名单。

### 6. Long Mutation
前期是短刑代罚行业与各类客户；中期出现家族包年、企业代罚预算、职业代罚者阶层；后期社会开始默认“穷人卖时间、富人保自由”，而代罚者身体上的服刑记录逐渐形成另一种身份与权力。

### 7. Non-Replaceability
这不是普通替罪或冤案，因为定罪事实没有转移，转移的是“真实失去人生时间”本身。金钱、自由、羞耻与正义可以被拆开交易，才会产生独特的职业和关系戏。

### 8. Engine Hypothesis
每一次代罚都是一笔看似清楚的时间买卖，但客户越有资源，越能把制度当成本项；主角越靠它脱贫，越必须面对自己其实在帮助什么秩序运转。职业上升等于道德成本上升。

## Concept 11｜《今晚八点，谣言成真》

### 1. One-Line Promise
每天晚上八点，全城传播最广、但尚未被证实的一条谣言会变成现实一小时；主角的工作，就是在七点五十九分之前让“最不坏的那条谣言”赢。

### 2. Protagonist Desire
主角曾经被一条恶意谣言毁掉人生一天，而那一个小时留下的后果持续多年；他进入城市谣言应急中心，只想找到当年是谁把那句话推成了第一名。

### 3. Unique Rule / Situation
- 每天只实现一条全城传播度最高的“未证实命题”。
- 已被权威证实或证伪的内容失去资格。
- 八点到九点期间命题按最普遍理解成为现实。
- 九点后异常规律消失，但造成的现实后果保留。
- 因为所有人都知道规则，所以“传播什么”本身成为城市战争。

### 4. Five Must-See Situations
1. “今晚地铁最后一节车厢闹鬼”冲到榜首，应急中心反而主动帮它传播，因为第二名是“某银行今晚会倒闭”。
2. 一个明星死亡谣言逼近第一名，明星本人必须在“公开现身证实自己活着”和“继续躲避另一场危机”之间选择。
3. 有人故意传播“城南会下金子”，全城冲去捡金，真正目的却是把另一片区域清空一小时。
4. “一名普通外卖员今晚会成为全城最有权的人”突然登顶，数万人开始追着所有外卖员跑。
5. 主角发现一个匿名账号长期制造荒诞但低伤害的谣言，像是在用小灾难压住某些更可怕的第一名。

### 5. One Character Pull
匿名造谣者“乌鸦”：他每天都在说假话，却可能是这座城市里最认真保护别人的人。

### 6. Long Mutation
前期是每日谣言争夺与城市奇观；中期资本、明星、黑产、社区开始专业操控传播；后期“集体相信什么”成为可以直接改写现实的基础设施，城市进入事实、谎言与有用虚构之间的战争。

### 7. Non-Replaceability
它不是普通谣言社会寓言，因为传播量每天会物理改写现实一小时。信息战可以直接变成动作场面、经济事故、关系灾难与公共奇观，且每次都由人的信念制造。

### 8. Engine Hypothesis
主角的最佳解通常不是消灭谣言，而是选择哪一个谣言更值得成真；每次成功都会教育新的对手如何操纵规则，于是下一天的信息战更聪明、更昂贵、更私人。

## Concept 12｜《失踪日名单》

### 1. One-Line Promise
每天午夜，城市会公布一百个名字；第二天这100个人仍然走在街上，但所有人都会认不出他们，所有系统也会拒绝承认他们存在。

### 2. Protagonist Desire
主角异常频繁地出现在名单里，于是干起“失踪日跑腿人”；他最初只想把这种倒霉体质变现，后来只想弄清楚为什么随机名单像在故意选中自己。

### 3. Unique Rule / Situation
- 名单上的人从零点到次日零点处于“不可识别状态”。
- 别人看得见、听得见他们，却无法把他们与既有身份对应起来。
- 人脸、门禁、银行、手机号、工作账号等身份系统全部失效。
- 当天结束后身份恢复，但别人对其失踪日经历的记忆极其模糊。
- 失踪者本人保留全部记忆。

### 4. Five Must-See Situations
1. 主角在自己生日当天上榜，坐在家人旁边吃完整顿饭，却没有一个人知道他是谁。
2. 有客户雇他在失踪日进入自己公司，把一封必须亲手递交却不能留下记录的信送给董事长。
3. 一个上榜的小孩放学后无法让父母认出自己，主角必须在身份同样失效的情况下把他安全送回家。
4. 主角亲眼看见一桩重大犯罪，但第二天所有相关人都只记得“现场好像有个陌生人”，证词几乎无法成立。
5. 某天名单突然不是一百个人，而是一整条街；主角第一次意识到这套规则可能不是随机故障，而是一种正在扩大的能力。

### 5. One Character Pull
一个每次上榜都很开心的女人：她把“没人认识我的一天”当成真正活着的唯一一天，并不断诱惑主角别再追查原因。

### 6. Long Mutation
前期是失踪日职业与身份喜剧/惊险；中期形成专门使用失踪者的黑白两套产业；后期名单规模扩大到家庭、公司、街区，人类第一次面对“一个人如果暂时不被任何社会关系承认，他还是不是原来的那个人”。

### 7. Non-Replaceability
与隐身不同，失踪者始终被看见，失去的是“被识别为自己”。因此最有力的场面不是潜入，而是站在最熟悉的人面前却成为陌生人，身份、关系和制度同时失效。

### 8. Engine Hypothesis
每个失踪日都给主角极高行动自由，同时切断他最依赖的社会资源；越能利用规则赚钱，越会进入只有“没有身份的人”才能完成的任务，并逐步接近名单为何存在的更大真相。
