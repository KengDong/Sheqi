# D-0088 Platform Candidate Packs

原则：
- 只改包装，不改冻结 Concept。
- 每个平台最多两个标题候选。
- 简介首屏控制在约 120—180 个汉字。
- First-Screen Promise 必须是 Reader 真能在正文得到的东西。
- ST5 与其它四本同等待遇；其 D-0087 human-layer 条件只在包尾 carry-forward，不进入匿名书架。

# ST1｜《劫痕道途》

## Natural Platform
Qidian PRIMARY-NATURAL

## Fanqie
PLATFORM MISMATCH（本轮不硬适配）

理由不是“ST1不商业”，而是当前番茄直给句法很容易把它压扁成“越受伤越强”。冻结 Premium 实际是：

> 真实承受过的永久成本 → 留在身体里 → 旧痕互相兼容/冲突 → 最后炼成独道。

如果标题承诺“受伤=加点”，就是 Concept mutation。

### Qidian Title Candidates
1. 《劫痕道途》
2. 《劫痕成道》

### One-Line Category Promise
代价流修仙：别人想把伤治掉，周野却必须判断哪些旧伤该留，因为它们正在变成只有他能走的修行结构。

### Suggested Tags
修真文明 / 代价修行 / 越阶 / 独道 / 身体构筑

### Synopsis Front 120—180
周野没有能抹平代价的仙宝。他真正留下的，是一次次活下来后长进身体里的劫痕：雷火灼过的经脉、风劫磨坏的肺腑、再也回不到原样的旧伤。别人治伤，他先问一句——治好以后，这道劫还能不能用？当一道道旧痕开始彼此咬合，他才发现，自己正把一具残破身体，炼成世上从未有过的道途。

### First-Screen Promise
> 治好一处旧伤，可能等于亲手废掉一块已经长进身体里的力量。

### Cover Direction
- 起点向，非番茄式巨大系统字框。
- 主视觉：青年侧身/背身，衣下与手臂可见数道不同质感的劫痕，痕迹不是血腥伤口，而像雷纹、灼痕、风蚀裂纹在身体上形成一套互相咬合的结构。
- 背景只留一次被劫雷照亮的山门/荒野，不堆十种特效。
- 书名应占清晰识别区；“劫痕”两字视觉权重大于“道途”。
- 禁止：把他画成主动自残、遍体鲜血、纯黑暗虐主文。

# ST2｜《养一条会跟我走的灵脉》

## Natural Platform
DUAL-PLATFORM VIABLE

## Qidian Version

### Title Candidates
1. 《养一条会跟我走的灵脉》
2. 《灵脉随我行》

### One-Line Category Promise
散修从一条被判死的断脉开始，养出会迁徙、会成长、最终能带着灵田坊市一起走的修炼地盘。

### Suggested Tags
幻想修仙 / 种田 / 宗门经营 / 灵脉 / 移动领地

### Synopsis Front 120—180
天下灵脉会迁徙、衰亡、改道，宗门再大，也得追着灵气搬家。他只是个连洞府都租不起的散修，却捡到一条被所有人判死的断脉。喂灵石、找水源、抢迁徙路，直到那条细得快断的灵脉第一次抬头，跟在他身后一起走。后来跟着它走的，不只有他，还有灵田、坊市、房屋和一群终于有了家的修士。

### First-Screen Promise
> 别人追着灵脉搬宗门；他的灵脉第一次自己追上了他。

### Cover Direction
- 山水仙侠底色，但核心不是名山大川，而是一条发光地脉正在离开山体，沿主角脚下延伸。
- 远处可见少量跟随地脉移动的灵田、灯火或建筑，预告地盘也会一起长。
- 不把灵脉拟人成龙宠物，避免误导成御兽文。

## Fanqie Version

### Title Candidates
1. 《修仙：我养的灵脉会自己搬家》
2. 《别人追灵脉，我的灵脉跟着我走》

### One-Line Category Promise
别人抢山头，他把一条快死的断脉养成会跟着人走、能驮着整个宗门迁徙的活灵脉。

### Suggested Tags
玄幻脑洞 / 修仙 / 种田 / 宗门建设 / 经营 / 领地成长

### Synopsis Front 120—180
修仙界最贵的不是功法，是灵地。别人为了灵脉抢山头、守宗门，他却捡到一条快死的断脉。第一次喂活它时，谁都没想到，这条灵脉会自己跟着他走。灵田、洞府、坊市、宗门，一样样长在它身上；强敌封山？那就连山一起搬走。可当所有人都把这里当成家，他第一次发现，有些东西不能靠搬家解决。

### First-Screen Promise
> 强敌封山时，主角不是守山——而是准备把自己的修炼地整体搬走。

### Cover Direction
- 大标题必须一眼看出“灵脉会移动”。
- 前景主角行走；地表发光灵脉像河流般追随，后方小型山门/灵田被同一地脉托起或牵引。
- 画面重点是“资产跟着我走”，不是单人御剑。

# ST3｜《把整座城市当成超能力》

## Natural Platform
DUAL-PLATFORM VIABLE；Fanqie first-read 更直给，Qidian 适合品牌化标题。

## Qidian Version

### Title Candidates
1. 《城市即神通》
2. 《我以一城为神通》

### One-Line Category Promise
都市超凡：他的能力不是一团火，而是让已登记的公共设施在灾害中短暂“醒来”；权限升一级，能回应他的城市就大一圈。

### Suggested Tags
都市异能 / 超凡 / 官方组织 / 城市系统 / 权限成长

### Synopsis Front 120—180
灾害发生时，城市里已经登记的公共设施会在他手里短暂“醒来”。路灯成为眼睛，消防栓成为武器，地铁线成为封锁。最初他只是应急维修队里最不起眼的一员，只能碰一盏灯、一道闸门；权限升高后，一条街、一个区、整座城都能回应他。可每一次调用，也都在改变普通人的真实生活。

### First-Screen Promise
> 一排路灯同时转向黑暗里的同一个怪物。

### Cover Direction
- 夜城市俯视/街区透视，路灯、电网、地铁线形成一张真实基础设施网络，而非赛博电路板。
- 主角应带一线应急/维修职业气质，位置小于城市。
- 让“城市是主体、主角是调用者”一眼成立。

## Fanqie Version

### Title Candidates
1. 《都市高武：我把整座城市当成超能力》
2. 《别人觉醒异能，我觉醒了一座城》

### One-Line Category Promise
别人升级个人异能，他从一盏路灯开始升级城市权限，最后能让整座城市一起对异常出手。

### Suggested Tags
都市高武 / 都市异能 / 超凡 / 官方组织 / 升级 / 城市权限

### Synopsis Front 120—180
别人觉醒火焰、雷电，他的能力却写在城市公共系统里。停电街区，一排路灯同时转向怪物；消防栓能压住异潮，地铁线能封锁异常。作为最底层的应急维修人员，他能调用的只有一盏灯、一道闸门。直到权限一级级升高，他才发现：自己真正要学会控制的，不是异能，而是一整座仍有人生活的城市。

### First-Screen Promise
> 从一盏灯，到一条街，再到整座城——权限就是他的升级条。

### Cover Direction
- 大标题+现代城市夜景。
- 视觉锚点至少三种设施：路灯、地铁/轨道线、消防/供水节点；但不要画成设施图鉴。
- 城市某一片区被同时点亮，形成整城响应的巨大动作。
- 不要纯机甲、纯赛博朋克，以免换母盘。

# ST4｜《别人抢物资，我抢整栋楼》

## Natural Platform
Fanqie PRIMARY-NATURAL

## Qidian
PLATFORM MISMATCH（本轮不硬适配）

当前起点公开同屏证据中，末日基地/建筑收集的直接标题环境不如番茄强；强行收短书名会损失这本最值钱的资源差。

### Fanqie Title Candidates
1. 《别人抢物资，我抢整栋楼》
2. 《末日：我把废墟拼成移动城》

### One-Line Category Promise
怪潮摧毁的建筑会留下建筑核心；别人捡装备，他把医院、超市、发电站、学校和桥梁一块块装进自己的移动基地。

### Suggested Tags
科幻末世 / 末日求生 / 基地建设 / 经营 / 组织成长 / 资源流

### Synopsis Front 120—180
怪潮过后，别人冲进医院抢药，他盯上的却是废墟里正在凝结的“医院核心”。只要装进自己的主控核心，医院、超市、发电站、学校甚至桥梁，都能变成移动基地的一部分。可楼越多，耗电、重量、接口和专业人员越紧张。末日里真正的选择不是抢不抢得到，而是这座会移动的城，最后要让谁活下来。

### First-Screen Promise
> 别人把药装上车，他准备把医院本身装上车。

### Cover Direction
- 大标题；移动基地必须不是一辆普通房车，而能一眼看出“医院/超市/住宅/电力模块拼接”的异质城市结构。
- 背景是刚被怪潮摧毁的固定城市，前景移动城正在离开。
- 可以让一座医院模块正在接入，强化动作。
- 禁止：只画卡车+囤货箱，否则 Premium 被打回普通基地车末日文。

# ST5｜《万人炼我一法》

## Natural Platform
DUAL-PLATFORM VIABLE

Shelf treatment 与 ST1—ST4 完全相同。D-0087 的 HUMAN-LAYER GAP 不参与本轮包装裁判。

## Qidian Version

### Title Candidates
1. 《万人炼我一法》
2. 《众生为我演法》

### One-Line Category Promise
他想让自己的功法进化，就必须先让真实修士愿意练；任何被别人真正验证有效的新解，都会永久回流到他身上。

### Suggested Tags
幻想修仙 / 创法 / 功法演化 / 传播 / 宗门成长

### Synopsis Front 120—180
他买不起名门真传，只能从一门最便宜的基础法开始改。第一次把功法发给陌生散修后，一个他自己都没想过的练法被人误打误撞练成，而那条被真实验证的改良，也永久落回他身上。从此，他想变强，就必须让更多人愿意练他的法。别人抄走一份，他反而多一批试炼者；当一万人同时开练，一门小法开始长成整个修行世界的新路。

### First-Screen Promise
> 功法被人抄走不是损失——抄得越多人练，替他提交的新版本越多。

### Cover Direction
- 主角只占中下部；核心视觉是一页功法/一组经脉路线向外分裂成成百上千条不同修炼路径，最后又有有效分支回流到主角。
- 避免万人整齐盘坐的廉价大场面；要画出“分支→验证→回流”的版本树。
- 书名四字应像可记忆品牌，不加系统视觉符号。

## Fanqie Version

### Title Candidates
1. 《修仙：我把功法发给一万人一起练》
2. 《别人闭关炼功，我让万人替我改功法》

### One-Line Category Promise
别人自己闭关试错，他把一门基础法撒出去，让成千上万真实修士替自己验证分支，练成的改良全都回流。

### Suggested Tags
玄幻脑洞 / 修仙 / 功法 / 升级 / 宗门 / 群体成长

### Synopsis Front 120—180
穷到只练得起最便宜的基础法，他干脆把自己改过的版本发给所有散修。很快他发现：只要别人真正练成、验证出的改良有效，自己就能永久继承。有人误打误撞练出新分支，他变强；大宗门整门抄走，数万弟子替他继续试错。别人闭关百年磨一法，他要做的，是让全天下都来替这门功法进化。

### First-Screen Promise
> 大宗门整门抄走他的功法后，他收到的不是损失，而是一整宗弟子的测试结果。

### Cover Direction
- 大标题重点写“万人/一起练/替我改”中的一组，不要所有信息都抢。
- 画面用大量不同修士的经脉/术式分支汇成一棵巨大功法树，主角处于回流核心。
- 禁止把所有人画成傀儡或吸功，避免误导成吞噬流。
