# 0. 一句话故事

> **穷杂役陆野在一次货运事故中真正执行舍味、完成筑基并发生漏舍，原本快到手的职业路径因此被冻结；为了不坐等许可，他一边靠正常筑基本事和驿货团队重新挣钱，一边把“多验证一步”的习惯变成现实价值——先修普通废件赚钱，再用有限尝余从合法低端旧物里筛出值得自费验证的对象，逐渐得到第一件窄用途收藏、本金和市场入口。等这项缺位价值开始被别人定价时，他却因一次“感知真、归因错”造成真实损失，才付钱学会信号不等于源头；最终，职业路线、工具资产、验证方法和团队关系在流程级复合余灾中合流，而他也第一次看到：这个文明所谓“处理掉”的东西，并不是简单消失，而是在被导向同一类去处。**

# 1. 第一卷上位目标

旧版上位目标过度等同于：
> 正式资格 -> 固定席位。

V2 保留两级职业状态，但不再把它们当成第一卷全部成长的同义词。

第一卷真正上位目标：

> **陆野要从“只能等别人排日结活的人”，变成一个即使某天没人给他排班，也有修为、工具、现金、客户、团队关系和判断能力给自己找活的人。**

因此第一卷同时推进四条成长轨：

## Career Track
- 从事故冻结状态恢复真实工作；
- 拿回 / 取得正式押货资格；
- 争固定路线 / 固定队位置；
- 获得稳定任务源与责任。

## Cultivation Track
- 筑基真正提供“稳定离体”新行动权限；
- 普通法器与职业基本功持续进步；
- 中段纯传统修仙任务证明特殊性不是战力主轴；
- 卷末个人修炼进入团队系统。

## Asset Track
- 普通修复第一次赚钱；
- 第一件合法低端异常物；
- 第一件重点窄用途收藏；
- 小本金；
- 后续市场入口；
- 工具与方法可回用。

## Knowledge Track
- 异常来自外界；
- 异常存在稳定行为差异；
- 少数对象有窄用途；
- 官方 / 市场早已部分分类；
- 大误判后才学会“信号位置≠源头”；
- 共享物 / 地点可以长期积累；
- 卷末只确认“部分利用 + 共同导走逻辑”。

# 2. 社会入口｜驿货行继续作为 BASE

正式保留：

> **驿货行短途杂役 / 押货杂役。**

但定位由：
> 第一卷故事本体

调整为：
> **第一阶段 BASE / 稳定人际关系基地 / 普通 Action 任务源 / 路线资产 / Finale 因果基地。**

保留原因：
- 能自然接不同客户、阶层、路线与普通旧件；
- 有持续真钱与现实职业目标；
- 有固定工作圈，避免资产线把全书写成单人捡漏；
- 长期共享货具、车具、中转位天然能承接流程级余灾；
- 陆野是制度使用者 / 被监管者，不是一开始就站进舍务核心。

硬约束：
1. 普通工作 / 普通货仍是现实底色；
2. 不连续三个主要单元都靠异常旧物驱动；
3. 至少一半重要冲突删除尝余后仍能成立；
4. 驿货行不能退化成主角私人“进货仓”；
5. 卷末若乔九暂时不给班，陆野也不能完全失去所有收入 / 价值入口。

# 3. 四台商业发动机

## Engine A｜正常修炼 / 行动【底盘】
负责：
- 第一次事故中的筑基新权限；
- 低风险工作中稳定离体变成生产力；
- 中段纯传统修仙押运 / 战斗；
- 普通法器；
- 团队配合；
- 卷末高混杂余灾主解。

硬原则：
> **尝余与余器不能替正常修炼解决主危机。**

## Engine B｜职业 / 团队【长篇关系底盘】
固定工作核心继续采用：
- 陆野
- 乔九
- 罗槐
- 唐禾
- 石小庚

高频外部：
- 周照
- 曹闻川

私人生活：
> 必须保留1名高频非任务型生活锚点。

职业线负责：
- 钱；
- 路线；
- 任务；
- 客户；
- 人情；
- 安全责任；
- 团队位置。

但不再负责：
> 每个阶段唯一奖杯。

## Engine C｜价值回收 / 资产飞轮【早期提速】

主角算法：

> **发现可能被低估的价值  
> -> 愿意付验证成本  
> -> 修 / 试 / 查  
> -> 决定买 / 留 / 卖 / 隔离  
> -> 为判断结果负责。**

早期顺序：
1. 普通修复先赚钱，证明没有外挂也能产生价值；
2. 尝余只降低“哪里值得多查一步”的筛查成本；
3. 第一件异常物来自合法低端旧物池；
4. 第一重点收藏真正落袋；
5. 后续先回用，再小额变现；
6. 更成熟市场入口放到中段打开。

禁止：
- 垃圾全是宝；
- 一看就知道价格；
- 一尝就知道来源；
- 高风险受控物低价漏出；
- 前10章进入成熟余器交易；
- 第一件收藏暴利。

## Engine D｜中秘密【不断改变行动意义】

第一卷采用 Secret Ladder V3 的读者侧时序：

> S0 舍后仍需处理  
> -> S1 异常部分来自外界  
> -> S2 异常有稳定行为差异，但来源不清  
> -> S3 少数对象有窄用途  
> -> S4 官方 / 市场早已部分分类  
> -> S5 大误判后才确认“信号位置≠源头”  
> -> S6 共享物 / 地点可长期积累  
> -> S7 部分受控利用 + 更大处理流存在共同导走逻辑  
> -> S8 “导去哪 / 利用与安全到底是什么关系”留给后续。

硬保护：
> **S5以前不得让陆野正式学会“载体≠源头”。**

第一卷仍不解释完整余世。

# 6. 第一重点收藏｜第一卷必须存在

正式新增第一卷硬资产节点：

> outline/assets/volume1_first_collection.md

当前设计：
> **旧护角皮带（工作俗称：咬手带）。**

读者可记功能：
> 一条三道白线的旧皮带；当它自身遭到局部尖锐夹压时，直接持有者会出现一下假的“被夹痛”。

它的价值非常窄：
> 只能作为狭窄位置“有没有局部夹点”的辅助探针。

不能：
- 测总载荷；
- 判断结构安全；
- 扫描设备；
- 找余痕源头；
- 替代普通测具；
- 替代修炼。

合法来源：
> 已完成常规安全放行、所有权人明确低价处置的普通旧护角 / 旧皮料混批。

为什么被低估：
> 风险低、单价低、用途长尾极窄，逐件深检不经济。

陆野优势：
> 尝余只把“值得多试的一条”从低价混批里筛出来。

第一次回用：
> 在低风险空返架的非关键维修里帮助缩小隐藏夹点范围；最终修复和安全确认仍靠普通拆检 / 工具。

第一卷早中段：
> **留，不急着卖。**

它是：
> **陆野工具箱第一格。**

不是神器。

# 7. 低端市场现实约束

第一卷资产线正式采用：

> research/design/2026-09-22_low_end_residual_market_model.md

作为现实层约束。

## 绝不能进入陆野早期捡漏池
- 高风险对象；
- 明确高价值对象；
- 已知受控残留；
- 正规舍务核心物；
- 异常强度已触发受控阈值的对象。

## 早期唯一合理机会池
> **低风险 / 低强度 / 来源混杂 / 单件深检不经济 / 用途极窄 / 可合法普通处置的旧物。**

陆野能降低的只是：
> 哪件值得继续查？

他仍要支付：
- 验证成本；
- 合规成本；
- 找买家成本；
- 库存成本；
- 判断错误成本。

所以：
> **他赚的是低端长尾的筛查成本差，不是整个文明的制度漏洞。**

# 10. 人物结构

## A圈｜固定货路核心

### 陆野
核心持续算法：
> **多验证一步，但不是舍不得扔。**

长期成长：
> **发现 -> 验证 -> 利用 / 隔离 / 放弃。**

### 乔九
驱动力：
> 时间就是钱，空转就是损失。

必须有自己的线路扩张 / 周转目标。

### 罗槐
原则：
> 整体安全优先。

必须有：
- 一次该扔就扔且事实证明正确；
- 一次不能因为看起来有风险就随便丢出的更复杂判断。

### 唐禾
必须有不依赖陆野的：
- 客户；
- 经纪信用；
- 长期利益。

大误判真正伤到：
> 她长期积累的客户信用。

### 石小庚
必须至少在一项传统修炼 / 操作基本功上明显强于陆野。

当前首选：
> 御器 / 精细控制稳定性。

他不能变小弟。

## B圈｜外部常驻

### 周照
定位：
> 舍务 / 安全监管常驻接口。

不做余世百科。

### 曹闻川
定位：
> 经营合作方 / 风险阈值对手。

必须不黑化。

## C圈｜私人生活

功能：

- 共享空间；
- 陆野挣钱后生活怎么变化；
- 不发任务；
- 不做主题镜子；
- 自己有独立目标。

# 11. 第一卷核心误判｜感知真，归因错

继续正式保留。

前置保护：
> S5以前陆野不能正式知道“信号位置≠源头”。

中后段：
> 复用衬垫 / 绑具 / 共享物上确实有真实余痕，陆野却把“信号现在在哪里”解释成“当前货物就是源头”。

结果必须造成：
- 无辜货延误 / 被扣；
- 真金白银损失；
- 唐禾或货行客户信用受伤；
- 陆野的任务判断价值下降；
- 团队明确：尝余不能独立作证。

这次之后才建立：
> **信号 -> 接触链 -> 对照 -> 控制变量 -> 再归因**

方法资产。

# 12. 正常修炼必须持续有行动价值

旧版“三次硬兑现”继续保留，但不能理解成只有三次。

## 第一次｜Opening
筑基稳定离体让陆野能在安全线外持续操作原有机械控制。

## 第二次｜Early-Mid
必须有一次：
> **尝余完全无用的纯传统修仙护运 / 战斗。**

这次成为正式资格的重要依据。

## 第三次｜Finale
高混杂环境中尝余接近失效。

主解：
- 正常修炼；
- 普通法器；
- 团队；
- 货流 / 路线知识；
- 舍务封控。

第一重点收藏最多只在局部辅助。

# 13. 第一卷主要阻力

不设置幕后邪恶大反派作为因果中心。

三层阻力继续保留：

## 经营
- 周转；
- 合同；
- 饭碗；
- 停工损失；
- 市场成本。

## 安全 / 证据
- 漏舍者能不能上高风险任务；
- 一件异常物是否可持有 / 使用；
- 尝余能不能作证；
- 哪里必须封控。

## 流程 / 环境
长期共享衬垫、绑具、车辆、中转位、多批货流出现低水平混杂积累。

# 14. Finale｜流程级余灾

卷末不是：
> 更大一件怪货。

而是：
> **共享物、车辆、地点在跨批次、跨时间接触中累积并形成高混杂流程级余灾。**

高混杂环境：
> 到处都是“味”。

尝余接近失效。

三线必须合流：

## Career
路线、人手、客户、周转、风险阈值全部进入。

## Asset
前期至少一部分工具 / 普通法器 / 第一收藏 / 本金换来的准备资源真正回用。

## Knowledge
S5后的验证方法阻止团队再次把：
> “哪里有信号”
直接等同：
> “哪里是源头”。

## Cultivation
真正主解仍是：
> 正常筑基 + 团队系统。

## Secret
卷末只确认：
> **一部分残留被受控利用；更多被处理掉的东西并非简单消失，而存在共同导走逻辑。**

不解释完整余世。

# 15. 卷末状态

陆野至少应真实拥有：
- 筑基修为；
- 正式职业资格；
- 固定路线 / 小队位置或等价稳定职业资产；
- 一件读者记得且回用过的重点收藏；
- 一笔能支付小额验证成本的本金；
- 至少知道一扇真实市场 / 交易入口；
- 一套不成熟但可复用的验证方法；
- 未清的客户信用债；
- 团队信任与利益分歧；
- 对自己缺位被现实定价的第一次不适。

不设机械“全部逐项打卡”。

但卷末必须让读者清楚：
