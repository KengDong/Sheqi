# 第一卷故事发动机｜已批准

> 本文件冻结的是第一卷的**故事发动机、人物结构、目标链、卷末状态和结构边界**。
>
> 不等于冻结100章章序，不等于冻结全部人物细节，也不等于允许直接开始正文。

## 一句话故事

> **穷杂役陆野为了从日结搬货工变成真正能独立押货的正式修士，在一次货运事故中舍掉味觉完成筑基，却因漏舍与安全调查失去原本快到手的资格；他在限制复工中靠正常筑基本事和只能提供局部信号的尝余重新赢回资格，又卷入固定路线 / 固定小队席位竞争——直到一次“感知没错、归因错了”的判断造成真实损失，逼出一套长期中转流程累积的余灾。卷末尝余在高混杂环境中接近失效，陆野只能和整支队伍靠修炼、职业经验与封控解决事故，最终得到固定席位，也第一次发现：别人开始给他永久缺掉的那一块定价。**

---

# 1. 开篇社会入口

正式采用：

> **驿货行短途杂役 / 押货杂役。**

功能：
- 陆野的穷、惜物、会修、先算损耗都能自然表现；
- 能接触普通货、不同阶层、不同路线与少量异常物流；
- 陆野是制度使用者 / 被监管者，而不是一开始就进入舍务核心机构；
- 职业提供稳定人物与现实目标，同时允许空间移动。

硬约束：

1. 前40章绝大多数货物必须是普通货。
2. 至少一半重要冲突即使删除余世/余器仍能成立。
3. 驿货行是第一阶段发动机，不是永久把全书锁成物流文。

# 1A. 开篇阅读合同｜2026-09-21专项批准

本节冻结的是**开篇策略与阅读承诺**，不是三章正文，也不是精确章卡。

## 主策略

正式采用：

> **方案C主结构 + 方案A的一次轻量舍备核验。**

核心不是“事故更炸”，而是：

> **陆野不接受别人用一个“废”字替代判断；可轮到自己，他早期却把味觉算成了相对舍得起的应急成本。**

因此开篇必须同时立住：

1. **人：**陆野先用一个普通、低风险、无主线价值的惜物动作证明自己不是随手丢东西的人；
2. **文明：**读者自然看到“陆野事前已办好的味觉舍备”属于成熟社会现实；
3. **现实目标：**陆野当下是在争真实的押货机会 / 资格，不是参加世界观展示；
4. **真兑现：**前三章左右完成主动舍味、筑基新权限与永久代价。

## 舍备核验边界

开篇只能表现为：

> **陆野为了争高风险 / 高价值班次，自己已经在正规舍务体系办过合法应急舍备；货行上岗前只核验这份既有舍备是否仍有效。**

不得据此推出：
- 公司替员工选择舍项；
- 所有高危岗位都强制交出一块人格；
- 货行扫描完整人格；
- 货行重新做定相；
- 公司拥有陆野的“舍项使用权”。

这些制度细节如章卡确有需要，再单独讨论。

## 第一件普通破物

第一章用于证明“惜物”的普通破物必须：

- 是真实货场工作中的廉价小件；
- 陆野处理它首先是为了省损耗 / 顺手 / 还能安全二用；
- 不成为事故原因；
- 不在后面突然变宝；
- 不救命；
- 不成为余器；
- 不承担主线伏笔。

它只负责让读者在作者形容之前，先看见陆野会多判断一步。

## 三章默认硬测试

正式进入章卡时，默认先按以下功能设计：

### 第1章
> **人 + 文明 + 现实目标**

至少完成：
- 陆野的真实惜物动作；
- 正式押货机会 / 候选位置成立；
- 一次非常轻的味觉舍备核验。

不讲完整：
- 修积 / 明悟 / 续我的理论说明；
- 三问模型；
- 舍台技术；
- 余世；
- 多种猎奇舍项。

### 第2章
> **普通工作先成立，事故再打断**

必须先让读者看到：
- 陆野确实会干活；
- 正常炼气与货运基本功存在；
- 至少一个竞争 / 同伴种子真实存在。

事故与第一章被陆野留下的普通破件无关。

### 第3章
> **主动舍味 + 筑基新权限 + 永久代价**

必须视觉上分清：

> **舍味 = 降低本次续我负担。**  
> **筑基 = 获得稳定离体。**  
> **漏舍异常 = 尚未解释的问题，不是舍味奖励。**

“三章内完成舍味”是**章卡默认硬测试，不是Canon**。

若未来3章事件卡与盲读证明第4章明显更强，可以申请微调；优先先删解释、压角色报到和手续，不默认拖到第6—8章。

## 味觉代价基线

舍味前必须至少有一个极短、自然的正常味觉基线。

不做“最后一顿美食”式煽情。

只需要让读者知道：

> **以前有，现在没有。**

## 异常味边界

第3—5章最多允许：

> 一次短促、不可控、可被解释为漏舍幻感的异常味。

此时不能：
- 与某件旧物建立稳定空间关联；
- 靠近 / 离开做控制变量；
- 确认来自外界；
- 暗示“被舍掉的味觉在外面”；
- 推出“弃相没有消失”。

真正的外界确认与后续结论继续严格服从 `canon/10_mystery_ladder.md`。

## 事故后三条债

前三章结束后至少留下：

1. **工作债：**筑基成功，资格却被冻结；
2. **生活债：**味觉永久消失；
3. **异常债：**漏舍后出现解释不清的异常感受。

Phase B不能退化成纯手续连续剧。

事故后1—2章内必须重新建立陆野主动目标，例如“尽快恢复能挣钱的限制性工作 / 证明自己仍能干活”。

每个复工 / 复核节点若不能同时改变钱、任务、人际、修炼、安全责任或异常认知中的至少一项，就应压缩。

## 惜物的反作用力

前30章必须至少一次明确证明：

> **有些东西就该舍。**

罗槐或同类角色做出一次“弃货 / 弃风险源”的判断，并由事实证明正确。

陆野的长期成长方向不是：

> 什么都留下。

而是：

> **发现 -> 验证 -> 决定利用 / 隔离 / 放弃。**

这才是未来拾余方法化应该继承的主角算法。

## 不因点击率修改的长期结构

开篇优化不得牺牲：

- 驿货行社会入口；
- 两级现实目标；
- 味觉是事故前已正规备案的舍备；
- 陆野主动选择；
- 舍破不生产力量；
- 前100章原则上不第二舍；
- 尝余无UI、无来源标签、不能独立作证；
- “感知真实、归因错误”的第一卷实际损失；
- 中段纯修仙护运；
- 曹闻川不黑化；
- 流程长期风险叠加；
- 卷末尝余接近失效、团队与正常修炼主解；
- mystery ladder 的秘密释放速度。

# 2. 第一卷两级现实目标

## 一级｜恢复 / 拿到正式押货资格

它回答：

> **我有没有资格靠这个职业吃饭？**

状态链：

> 候选资格  
> -> 事故冻结  
> -> 医疗 / 安全复核  
> -> 限制复工  
> -> 试岗  
> -> 正式恢复

一级目标必须在**第一卷中点附近**完成。

不锁死48%或精确章数。

建议区间：

> **约40%—55%，以状态条件是否完成为准。**

允许换挡的条件：

1. 停岗与漏舍后果已经真实存在；
2. 陆野已经用正常筑基本事证明自己；
3. 石小庚形成真实职业竞争；
4. 尝余只帮助陆野重新获得机会，没有替他通过考核；
5. 乔九扩线 / 固定席位的价值已经提前进入读者视野。

## 二级｜获得固定路线 / 固定小队席位

它回答：

> **我是不是仍然能被任何一个同境修士随时替掉？**

固定席位应真实带来：

- 稳定收入或保底；
- 固定趟次 / 路线分成；
- 可预测排班；
- 固定训练和普通法器资源；
- 风险决策话语权；
- 对临时杂役、货主和路线安全承担责任。

所以：

> **资格 = 能做。**
>
> **固定席位 = 有位置，也开始对别人负责。**

固定席位不能靠“尝余特批”获得。

正常筑基能力、路线经验、团队配合、安全判断、事故后的信用恢复必须占主要权重。

# 3. 第一卷暗主题

第一卷不由人物公开总结，但必须通过行动逐步兑现：

> **陆野原本只想变得不那么容易被替换。**
>
> **后来他真的难以替代，却部分因为别人发现他的缺位有用。**

至少有四级递进：

1. **后遗症好像有用。**  
   同伴只是顺手问：旧货经过你时能不能帮忙看看？

2. **尝余帮助他重新获得机会。**  
   能力打开门，但正式资格靠正常工作能力拿回来。

3. **能力开始进入任务安排。**  
   某些旧货 / 事故货任务更愿意排陆野，甚至出现小额风险补贴。

4. **缺位开始被当作岗位价值。**  
   别人说“至少这点别人替不了”，陆野第一次不舒服。

第一卷只到：

> **缺位开始被现实定价。**

不提前发展完整行业制度、使用权立法或大规模伦理运动。

# 4. 人物结构

冻结的是**三圈结构与长期驱动力**，不是所有姓名和细节永久不改。

## A圈｜固定货路核心

当前工作名：

- 陆野
- 乔九
- 罗槐
- 唐禾
- 石小庚

### 乔九
底层驱动力：

> **时间就是钱，空转就是损失。**

舍眠只是放大器，不是全部人格。

他自己的线路扩张 / 商业目标必须主动推进，并自然制造第一卷二级目标的固定席位。

### 罗槐
原则：

> **整体安全优先。**

不走“冷酷 -> 学会善良”。

第一卷应有：
- 一次他主动弃货 / 弃风险源且事实证明正确；
- 一次表面相似，但他反而判断“不能随便丢出去”，证明判断模型变复杂。

### 唐禾
必须有不依赖陆野的：
- 客户；
- 经纪信用；
- 长期利益。

她可以做对小队短期不利、对自己长期信用有利的选择。

成长不是“为了友情不算钱”，而是：

> 从算一单，升级到算几年。

### 石小庚
必须在至少一项传统修炼基本功上**明显强于陆野**。

当前首选：

> 御器精度。

卷末即使进入同一固定队，也继续存在训练、分成、风险判断和位置竞争，不降格成小弟。

## B圈｜高频外部行动者

### 周照
定位：

> **舍务 / 安全监管的外部常驻人物。**

组织上始终不属于陆野固定小队。

可以高频共同在场，甚至参与卷末封控，但：
- 不跟队分钱；
- 不参与固定排班；
- 不成为饭局常客；
- 不承担余世百科解释功能。

### 曹闻川
定位：

> **经营对手 / 合作方。**

必须不黑化。

他的冲突来自风险阈值：

> 没有证据证明存在系统性风险，就不能让几十人和整条线轻易停工。

他必须有真实正面经营事实，证明并非“为了钱不要命”。

## C圈｜私人生活锚点

第一卷**必须存在一个高频但非任务型生活人物**。

当前首选：

> **合租旧友。**

但暂不冻结：
- 姓名；
- 性别；
- 具体手艺行业；
- “同屋各灶”是否一定成为最终关系结果。

硬要求：

1. 即使没有余世剧情，也会持续与陆野发生生活关系；
2. 不发任务；
3. 不讲世界观；
4. 不专门负责安慰陆野；
5. 味觉永久消失必须真实改变至少一项普通生活习惯；
6. 不要与陆野形成过于工整的“不可替代”主题镜像。

# 5. 第一卷主要阻力

第一卷不设置“幕后邪恶大反派”作为主要因果中心。

采用三层叠加：

## 人物 / 经营
曹闻川式经营者：
- 合同；
- 饭碗；
- 停工损失；
- 风险证据阈值。

## 制度 / 安全
周照代表的监管逻辑：

> 没证明安全，就不能继续把未知风险往下游送。

## 环境 / 系统风险
一套长期中转流程把低水平残留风险逐渐叠加，旧中转节点只是最严重的聚焦点。

卷末解决的是：
- 正在发生的余灾；
- 人员与货物流；
- 隔离与封控；
- 路线和设施处置。

流程根因是因果答案，不是“审计通关式高潮”。

# 6. 中转流程因果边界

作者层可以知道完整因果，但正文不得一次讲完。

当前批准的因果骨架：

1. 低风险事故货 / 旧件可进入普通外围转运；
2. 普通运输衬垫、捆扎物、车具清理后允许复用；
3. 夜线 / 高周转提高共享物接触不同来源货物的频率；
4. 旧节点逐步扩容，但清理规则仍以单批 / 单件为基本对象；
5. 监管擅长处理明确单件风险，不擅长跨批次、跨时间的低水平混杂积累；
6. 残留逐渐从“货”迁移到共享物、车辆和地点；
7. 多来源残留在高周转节点形成复合余灾。

第一卷读者只需要通过少量证据逐步拼出：

> **问题不在某一件货。**

不要求理解全部七环。

卷末必须留下真实流程整改成本，不能第二天恢复原样。

# 7. 尝余在第一卷的叙事边界

第一卷必须兑现：

> **感知真实，归因可能错误。**

推荐误判：

> 复用运输衬垫 / 捆扎物本身沾有真实余痕，陆野把“接触物有余痕”错误归因成“当前货物本身是源头”。

结果至少造成：

- 无辜货被封 / 延误；
- 真金白银损失；
- 唐禾或货行信用受损；
- 陆野信誉下降；
- 周照 / 队友明确要求：尝余不能直接等于风险结论。

误判后禁止立刻升级出：
> “现在我能区分货物味和衬垫味了。”

成长只能是：

> **学会证据边界。**

# 8. 正常修炼必须三次硬兑现

## 第一次｜新权限
第一次事故中：

> 筑基后的稳定离体让陆野完成炼气阶段做不到的持续救援 / 控制。

力量来自筑基，不来自失味。

## 第二次｜基本功
第一卷中段必须有一场：

> **尝余完全无用的纯传统修仙护运 / 战斗。**

陆野靠：
- 筑基；
- 普通法器；
- 路线经验；
- 队友配合。

石小庚至少一次明显比陆野强。

该单元应成为拿回正式押货资格的重要依据。

## 第三次｜团队系统
卷末高混杂余灾中：

> 尝余接近失效。

最终主要靠：
- 正常修炼；
- 普通法器；
- 团队分工；
- 货流 / 路线知识；
- 舍务封控。

# 9. 第一卷故事单元冻结策略

**不冻结12个精确顺序。**

冻结：

> **8个骨干功能节点 + 2—4个弹性单元。**

## 八个骨干功能节点

1. **资格竞争**  
   陆野从普通杂役进入正式押货资格候选，石小庚构成真实竞争。

2. **事故 / 舍味 / 筑基**  
   主动执行已备案舍备；筑基救援；味觉永久失去；漏舍；资格冻结。

3. **私人生活损失落地**  
   味觉缺失真正改变下班后的普通生活。

4. **限制复工 / 外界异常确认**  
   周照与罗槐形成安全限制；尝余第一次被确认并非纯幻觉。

5. **普通安全决策**  
   罗槐做一次“该舍就舍”的正确现实判断，陆野的惜物受到挑战。

6. **纯修仙护运 / 战斗**  
   尝余为0；石小庚传统基本功强于陆野；陆野靠正常筑基本事完成试岗；一级目标完成。

7. **尝余进入现实价值 -> 误判造成损失**  
   二级目标启动；能力进入任务安排；陆野“感知真、归因错”，产生赔偿 / 信用债。

8. **流程风险爆发 -> 团队控灾 -> 固定席位**  
   尝余接近失效；团队与正常修炼主解；余灾受控；流程整改；固定席位与真实责任成立。

## 弹性单元池

根据阶段纲和章卡手感选择2—4个：

- 一件窄用途余器；
- 完整续我 / 借载客户对照；
- 普通残货 / 产权冲突；
- 唐禾客户线；
- 乔九线路扩张的独立事件；
- 生活锚点第二次现实冲突；
- “没尝到不等于安全”的普通危险事件。

如果弹性单元实际不好写，可以删，不需要为了“结构完整”硬保。

# 10. 第一卷四阶段

只锁功能，不锁精确章数。

## Phase A｜想转正，事故把路打断
约前20%上下。

完成：
> 候选杂役 -> 舍味筑基 -> 漏舍 / 停岗 / 资格冻结。

## Phase B｜限制复工，解决“我还能不能做这份工作”
延续到全卷中点附近。

完成：
- 外界异常初步确认；
- 普通安全判断；
- 纯修仙试岗；
- 正式押货资格恢复。

## Phase C｜有资格还不够，我要有自己的位置
中后段。

完成：
- 乔九扩线 / 固定席位出现；
- 石小庚继续竞争；
- 尝余逐渐被纳入任务价值；
- 唐禾客户线产生现实利益；
- 误判发生并留下债。

## Phase D｜固定席位意味着责任
后段到卷末。

完成：
- 人物 / 经营 / 监管冲突升级；
- 确认问题不是单件货；
- 复合余灾爆发；
- 团队控灾；
- 流程整改；
- 固定席位确定。

# 11. 卷末必须留下的状态

至少做到：

1. 陆野已获得正式押货资格；
2. 陆野进入固定路线 / 固定小队；
3. 小范围职业名声形成，但不是全城天才；
4. 石小庚从单纯名额竞争者变成长期竞争伙伴；
5. 队伍信任形成，但风险、分成和判断分歧没有清零；
6. 尝余被证明有价值，但不能独立构成证据；
7. 误判的赔偿可以处理，信用债不能瞬间消失；
8. 中转流程被迫整改，危机不能恢复成旧状态；
9. 私人生活因味觉缺失留下至少一处不可逆变化；
10. 陆野第一次意识到：自己的缺位开始被别人作为现实价值使用。

# 12. 中段接口

第一卷只需要留下接口，不写第二卷详细剧情。

必须保留：

1. **固定席位 = 收益 + 对他人负责**
2. **队伍 = 信任 + 未解决利益分歧**
3. **尝余 = 有价值 + 不能独立作证**
4. **误判 = 钱可赔 + 信用债未清**
5. **流程整改 = 风险压住 + 新成本出现**
6. **生活锚点 = 工作成功继续改变私人生活**

中段可轮换的发动机家族：

- 职业责任；
- 拾余方法化；
- 余灾 / 系统风险；
- 固定队利益关系；
- 修炼方法换挡。

当前只允许记录地图，不提前锁第二卷12个事件或100—300章详细章纲。
