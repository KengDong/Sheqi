# 0. 第一卷真正冻结的六次状态换挡

第一卷首先冻结状态，而不是事件库存：

> **我快有资格了**  
> -> **我主动舍味、筑基，却失去资格**  
> -> **我靠正常本事拿回资格**  
> -> **我发现有资格仍然没有自己的位置**  
> -> **我的缺位开始值钱，也第一次因为错误解释伤到别人**  
> -> **我拿到固定位置，同时开始为别人负责。**

只要这六次状态换挡成立，具体事件可以在章卡阶段伸缩。

# 1. Phase A｜想转正，事故把路打断

## 阶段边界

Phase A **不锁0%—18%**。

它从第一章开始，到以下状态全部成立后立即结束：

1. 陆野主动启用味觉舍备；
2. 筑基成功；
3. 漏舍与资格冻结明确；
4. 味觉永久损失第一次落入普通生活；
5. 陆野重新建立主动目标：
   > **尽快恢复能挣钱的工作 / 证明自己还能干。**

因此 Phase A 默认很短，大约只占全卷前 **8%—12%上下或更短**，但仍以状态条件为准，不锁精确比例。

## 开头状态

### 职业
- 驿货行短途杂役 / 押货杂役；
- 已进入正式押货资格候选；
- 石小庚构成真实同层竞争。

### 修炼
陆野已经：
- 完成修积；
- 完成明悟；
- 进入真实炼气 -> 筑基续关；
- 在正规舍务体系主动办理过味觉舍备；
- 尚未真正舍味。

### 事故前为什么不直接舍味筑基

正式冻结人物决策阈值：

> **舍备是陆野的应急保险，不是升职快捷键。**

事故前：
- 他仍优先希望通过完整续我 / 持续适应完成筑基；
- 味觉虽然是当前可安全登记且足够的候选中，他认为最能承受的永久损失之一，但永久损失仍然是损失；
- 多挣一些工钱、快一点转正，不足以让他平时主动切掉味觉；
- 真正跨过阈值的是：
  > **现场有人等不起，而只有他筑基后才可能完成救援。**

第一章只需让读者知道：
> 他有这份预案，但正常情况下并不打算今天使用。

不做完整续我理论讲解。

## 第1章功能｜人 + 文明 + 现实目标

必须同时立住：

### 人
陆野用一个真实、普通、低风险、无主线价值的惜物动作证明：

> **他不接受一个“废”字替代判断。**

第一件普通破物：
- 只用于立人；
- 不成为事故原因；
- 不变宝；
- 不救命；
- 不成为余器；
- 不承担后续伏笔。

### 文明
乔九或同等自然工作角色顺手核验：

> 陆野**本人事前已在正规舍务流程办好的味觉舍备**仍对他当前这一次筑基续关有效。

读者必须隐约明白其局部性：

> **对这个人、这套功法、这一次续关有效。**

不能被写成：
> “味觉值一个筑基”。

货行：
- 只核验；
- 不替陆野选舍项；
- 不扫描人格；
- 不重新定相；
- 不拥有“调用陆野人格”的权力。

### 现实目标
陆野今天在争：
- 更高价值班次；
- 正式候选评价；
- 更高工钱。

### 味觉基线
舍味前至少有一个极短、自然的正常味觉基线。

不做“最后一顿美食”式预告。

## 第2章功能｜普通工作成立后事故打断

事故前必须先看见：

1. 陆野确实会做普通货运；
2. 正常炼气在职业里如何使用；
3. 石小庚至少一项正常基本功明显优于陆野；
4. 乔九的排班 / 周转目标正在现实推进；
5. 被困者在事故前已经作为一个普通劳动者被读者看见一次。

被困者不需要长期人物线，也不一定需要名字。

## 第3章功能｜主动舍味 + 筑基新权限 + 永久代价

必须视觉上分清：

> **舍味 = 降低本次续我承接负担。**  
> **筑基 = 获得稳定离体。**  
> **漏舍异常 = 后续问题，不是舍味奖励。**

默认三章内完成：
- 陆野明知风险，主动启用味觉舍备；
- 舍味成功；
- 筑基成功；
- 筑基稳定离体完成炼气无法持续完成的救援；
- 封位外环受损；
- 漏舍成立；
- 资格冻结；
- 永久失味开始落地。

“三章内舍味”是章卡默认硬测试，不是Canon。若3章事件卡与盲读实测证明第4章更强，可单独申请微调；优先先删解释、压角色和手续。

## 事故优先方案｜A' 单一几何因果版

章卡优先采用固定中转台 / 重载转运单元事故，但必须满足：

> **一个主物理失效链，同时产生三类后果。**

理想几何：

> 同一台重载转运架 / 吊运单元发生导向失效或侧摆  
> -> 一侧夹住装卸工  
> -> 同一载荷中的低风险封存退件受冲击泄漏  
> -> 失控单元另一侧 / 摆臂撞伤紧邻的应急舍台封位外环。

不是：
> A坏 -> 撞B -> B炸C -> C再碰D。

章卡前必须画极简空间图。

若空间图无法让：
- 失控单元；
- 被困者；
- 封存退件；
- 舍台外环

自然同处一个真实作业区域，立即切换候选B“坡道车架侧倾”。

不要为了保住A硬凑空间。

## 第3—5章异常味边界

最多允许一次：

> 短促、不可控、可解释为漏舍幻感的异常味。

禁止：
- 与某旧物建立稳定对应；
- 靠近 / 离远做控制变量；
- 确认来自外界；
- 暗示“被舍掉的味觉跑到外面”；
- 提前推出“弃相没有消失”。

Phase 与 mystery ladder 是两套坐标。

# 2. Phase B｜限制复工，证明“我还能做”

## 阶段开头

- 正式资格被冻结；
- 陆野是新筑基、漏舍者；
- 味觉已永久失去；
- 主动目标已经建立：
  > **恢复能挣钱的限制性工作 -> 通过真实试岗拿回正式押货资格。**

Phase B 不得写成“等审批”。

## 主要阻力

### 周照
安全条件不到，不能放。

### 罗槐
制度允许，不代表他愿意带一个刚漏舍的新筑基跑高风险线。

### 石小庚
用正常基本功证明：

> 没有陆野的特殊性，货行也有可靠候选。

## 骨干功能

### 1. 限制复工
任何复核 / 手续节点只有在同时改变至少一项时才值得占戏：
- 钱；
- 可接任务；
- 谁愿意带他；
- 安全责任；
- 修炼机会；
- 异常认知。

否则压缩。

### 2. “该舍就舍”必须在前30章成立一次
罗槐或同类现实人物做一次：

> 弃货 / 弃风险源。

而且事实证明：

> **他是对的。**

这不是打脸陆野，而是冻结陆野真正的长期成长方向：

> **发现 -> 验证 -> 决定利用 / 隔离 / 放弃。**

“惜物”绝不等于“什么都留下”。

### 3. 外界异常确认必须按秘密梯慢慢来
Phase B 提前开始，不代表 mystery ladder 前移。

早期动力优先来自：
- 钱；
- 复工；
- 生活；
- 新筑基适应；
- 人际。

只有到秘密梯允许窗口，才逐步通过重复、换位等方法确认：

> 少数外界旧物 / 区域确实能触发异常味。

此时仍可误解为：
> 舍务污染 / 外界残留。

不能直接确认人的弃相。

### 4. 纯传统修仙试岗
必须有一次：

> **尝余 = 0。**

靠：
- 筑基稳定离体；
- 普通法器；
- 路线经验；
- 队伍配合；
- 安全判断。

石小庚至少一项正常修仙基本功明显强于陆野。

当前首选“御器精度”，但不锁死，等具体危险确定后再选最自然的基本功。

这次任务成为陆野拿回正式押货资格的主要证据。

## 阶段终点

- 正式押货资格恢复；
- 陆野已证明正常筑基本事能支撑真实工作；
- 尝余仍只是有限信息，不是职业判定器；
- 罗槐认可“能做”；
- 石小庚成为长期标尺；
- 周照成为可重复碰到的外部监管接口。

## 成功制造下一问题

乔九自己的线路扩张成功，出现有限的：

> 固定路线 / 固定小队席位。

陆野第一次真正理解：

> **有牌，只代表能做；不代表有自己的位置。**

# 3. Phase C｜有资格还不够，我要有自己的位置

## 阶段目标

> **拿到固定路线 / 固定小队席位。**

它意味着：
- 收入更稳定；
- 排班可预测；
- 固定资源；
- 风险决策话语权；
- 不再随时被替换。

## 主要阻力

### 石小庚
正常基本功更稳。

### 乔九
他选择的是对线路最合适的人，不照顾主角。

### 陆野自己的特殊性
尝余开始变得有现实价值，也开始让陆野被缩写成：

> 那个漏舍后能尝异常的人。

## 骨干功能

### 1. 尝余先带来真实甜头
可表现为：
- 某些事故旧货 / 退货任务更愿意排陆野；
- 小额特殊风险加钱；
- 他因此真实高兴。

必须让读者感受：

> **努力和特殊性确实暂时让生活变好。**

### 2. 唐禾客户信用进入主线
唐禾必须有不依赖陆野的长期客户 / 经纪信用。

误判真正伤到的不是抽象“公司钱”，而是她几年积累的信用。

### 3. 感知真实、归因错误
推荐误判：

> 复用普通运输衬垫 / 捆扎物上确实有余痕，陆野却把“余痕现在在哪里”误解成“眼前货物就是源头”。

信号真实。

错的是证据意义。

现实代价至少包含：
- 无辜时效货被封 / 延误；
- 货主损失；
- 唐禾客户信用受伤；
- 货行赔偿；
- 陆野职业信誉下降。

误判后绝不能升级新扫描模式。

成长只能是：

> **发现 ≠ 证明。**

## 弹性功能

正式锁三项：
1. 乔九线路扩张；
2. 唐禾客户信用；
3. 生活锚点第二次现实冲突。

另留一个：

> **窄用途异常旧物 / 余器可删槽。**

它不是第一卷必选。

只有同时完成至少两个功能时才允许进入：
- 推进人物关系；
- 改变职业状态；
- 建立产权 / 风险问题；
- 为误判 / 流程因果留下后果。

如果只是展示“余器设定很好玩”，直接砍。

## 阶段终点

- 尝余从“有用特殊信息”变成“必须验证的信息”；
- 唐禾与陆野形成未清信用债；
- 组织明确：尝余不能独立作证；
- 陆野第一次明显感到自己的缺位开始被现实定价；
- “为什么普通共享运输材料也会有异常残留”成为现实问题。

# 4. Phase D｜固定位置意味着责任

## 阶段目标

前半：
> 别让一次误判彻底毁掉固定席位机会。

余灾真正爆发后：
> 先把人和这条线安全处理掉。

此时不再只算升职得失。

## 三层阻力

### 曹闻川
证据不足时反对整线停运。

### 周照
没证明安全时反对继续把风险往下游送。

### 环境 / 流程
异常残留已经在本次中转流程的：
- 共用材料；
- 多批货流；
- 载具；
- 高周转旧节点

之间出现混杂与积累。

## 骨干功能

### 1. 确认问题不是单件货
正文只需给3—4类现实证据。

不要把完整流程因果写成事故分析报告。

### 2. 风险阈值冲突
曹闻川与周照都必须至少一次：

> 从自己的责任出发说得通。

尝余只能证明：
> 这里确实有异常信号。

不能证明：
- 整条线必须停；
- 哪个环节一定是源头；
- 风险等级到底多高。

### 3. 复合余灾
高混杂环境中：

> **到处都是味。**

尝余接近失效。

最终主要依靠：
- 陆野正常筑基；
- 普通法器；
- 石小庚基本功；
- 罗槐风险判断；
- 乔九人车调度；
- 唐禾货流记录；
- 周照封控；
- 曹闻川设备与人手

共同解决。

这是正常修炼第三次硬兑现：

> **个人修炼进入团队系统。**

### 4. 流程整改
危机后至少一项：
- 复用；
- 暂存；
- 混运；
- 待检

发生真实变化。

同时留下：
- 效率下降；
- 成本上升；
- 谁承担成本仍有分歧。

### 5. 秘密结论必须收紧
第一卷卷末只强制确认：

> **本次中转事故相关的异常残留，确实出现在多个共享材料 / 载具 / 节点上，并发生混杂、积累与现实影响。**

这足以支持：
- 封控；
- 流程整改；
- 重新理解误判。

但不强制推出：

> “所有有效弃相都具有统一迁移 / 聚集规律。”

更不能提前推出：
- 统一去向；
- 完整弃相理论；
- 余世。

若第一卷最终长度自然抵达 mystery ladder 约120章窗口，再由章卡阶段决定认知是否升级。

## 阶段终点

陆野获得固定席位。

这个位置真实带来：
- 钱；
- 稳定；
- 资源；
- 认可；
- 话语权。

同时也第一次意味着：
- 别人依赖他的判断；
- 他承担安全责任；
- 他承担误判责任；
- 尝余是否属于岗位能力成为现实问题；
- 未清客户信用债仍存在；
- 流程整改成本不会消失。

卷末奖励必须是真的，新增责任不能把奖励写成假奖励。

# 5. 八个骨干节点｜正式顺序

不锁章数，只锁功能顺序：

1. **资格竞争**
2. **事故 / 舍味 / 筑基**
3. **私人生活损失**
4. **限制复工 / 外界确认**
5. **“该舍就舍”正确判断**
6. **纯修仙试岗 -> 一级目标完成**
7. **尝余进入现实价值 -> 误判**
8. **流程风险 -> 团队控灾 -> 固定席位**

其中三组必须强制拆拍：

### 节点4
> 复工 ≠ 外界确认。

先让工作生活继续，再逐步确认异常来自外界。

### 节点7
> 尝余有用 ≠ 立刻误判。

中间必须有真实甜头和正常生活改善。

### 节点8
> 发现流程问题 ≠ 解决余灾 ≠ 奖励结算。

必须至少分成三拍。

# 6. 人物首轮出场节奏

## 前3章长期记忆位最多
- 陆野
- 乔九
- 石小庚

事故被困者与当班舍务 / 安全值守不抢长期人物位。

## 前10章第二批
优先：
- 生活锚点；
- 周照；
- 唐禾；
- 罗槐。

曹闻川不要求前10章正式出场。

第一次出场都必须改变：
- 陆野的行动；
- 现实利益；
- 或安全决策。

不能来做自我介绍。

# 7. 私人生活锚点｜正式方向

采用强候选：

> **规整、重生活边界、有独立手艺目标的合租旧友。**

稳定功能：
- 自己有工作 / 手艺 / 工具目标；
- 穷也不代表所有东西都该凑合；
- 与陆野“能用就行、别浪费”自然冲突；
- 味觉永久消失会改变共食、买菜或做饭习惯；
- 至少一次为了自己的工作空间 / 工具 / 钱做出不为陆野服务的决定；
- 不做安慰NPC。

暂不冻结：
- 姓名；
- 性别；
- 具体手艺；
- 是否“同屋各灶”；
- 是否卷末搬走。

# 8. 第一卷写作保护

## 每个Phase只盯3件事

### Phase A
1. 资格；
2. 主动舍味的现实选择；
3. 永久损失进入生活。

### Phase B
1. 复工 / 拿回资格；
2. 正常筑基本事；
3. 尝余只是一条有限信息。

### Phase C
1. 固定席位；
2. 配角自己的利益线；
3. 特殊能力从有用走到误判有代价。

### Phase D
1. 单件问题变流程问题；
2. 正常修炼 + 团队主解余灾；
3. 真奖励带来责任，但不清空旧债。

## 20—30章复盘至少问

1. 陆野现在具体想得到什么？
2. 社会位置真实变化了吗？
3. 新增责任了吗？
4. 哪个旧结果回来影响现在？
5. 至少一个配角自己的目标推进了吗？
6. 如果尝余连续10章不能用，故事还能动吗？
7. 正常修炼改变过解法吗？
8. 最近一个谜团有没有给真答案？
9. 私人生活显示变化了吗？
10. 接下来3章有没有即时欲望？
11. 惜物有没有退化成“什么都不扔”？
12. 异常味有没有超过秘密梯允许的信息量？

## 砍支线条件

弹性单元若多数满足：
- 不改变人物关系；
- 不改变职业 / 组织状态；
- 不改变陆野做事方法；
- 不留下钱、信用、责任或承诺；
- 只展示新余器；
- 删除后下一阶段完全不受影响；

直接砍。
