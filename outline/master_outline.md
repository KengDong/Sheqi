# 全书中央主线

**状态：reviewed-proposal，尚未作者最终冻结。**

目前不再把A/B/C视为互斥三选一，而是优先采用**三线合流**。

## 明线：C｜拾余路线
这是陆野自己的行动因果链，也是最重要的“状态繁殖”发动机。

生存舍破  
-> 发现少量余痕/怪旧物  
-> 学会辨识、收容、利用极窄用途余器  
-> 靠拾余救人、赚钱、完成任务  
-> 逐渐形成可复制的方法/手艺  
-> 其他人、商号、军队开始学习和复制  
-> 市场开始需要特定弃相  
-> 社会从“利用别人不要的东西”走向“为了可利用余物主动制造舍弃”  
-> 陆野必须面对：自己原本只是想把废物捡起来，为什么成功反而让世界更擅长拆人？

**优点：**主角是因果发动机，而不是一路被NPC告知世界秘密。  
**风险：**容易滑成捡漏鉴宝/创业工业文，所以必须由余灾、战斗、关系和修炼不断打断纯经营节奏。

## 压力线：B｜余灾治理 / 余世生态
文明并非完全不知道舍弃副产物，但对余世理解长期不足。

个人余痕  
-> 小型余器事故  
-> 区域余灾  
-> 战争/产业/宗门造成不同弃相沉积  
-> 正规舍台被发现不仅是服务机构，也是导余基础设施  
-> 现有导余体系开始无法处理越来越复杂的弃相生态  
-> 相容弃相出现结构化趋势。

**作用：**给明线持续制造不可回避的外部压力和奇观，不让拾余只剩生意。

## 暗线：A｜制度秘密
不从“高层邪恶隐瞒”开局，而是让陆野自己的行动逐渐撞上。

弃相没有消失  
-> 正规舍台显然早知道部分余痕规律  
-> 部分弃相被合法/非法截流  
-> 用于人工余器、某些借载设施与大型阵法  
-> 陆野一度以为“穷人舍掉的东西被有钱人拿走”  
-> 进一步发现截流设施也在缓冲余灾、稳定边界  
-> 真相从剥削叙事升级为文明如何处理自己主动丢弃的那一部分。

**原则：**正规舍台必须有真实安全价值；不能简单写成邪恶机构。

个人生存
