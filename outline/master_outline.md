## 明线：C｜拾余路线
这是陆野自己的行动因果链，也是最重要的“状态繁殖”发动机。

生存舍破  
-> 发现少量余痕/怪旧物  
-> 学会辨识、收容、利用极窄用途余器  
-> 靠拾余救人、赚钱、完成任务  
-> 逐渐形成可复制的方法/手艺  
-> 其他人、商号、军队开始学习和复制  
-> 市场开始需要特定弃相  
-> 社会从“利用别人不要的东西”走向“为了可利用余物主动制造舍弃”  
-> 陆野必须面对：自己原本只是想把废物捡起来，为什么成功反而让世界更擅长拆人？

**优点：**主角是因果发动机，而不是一路被NPC告知世界秘密。  
**风险：**容易滑成捡漏鉴宝/创业工业文，所以必须由余灾、战斗、关系和修炼不断打断纯经营节奏。

## 压力线：B｜余灾治理 / 余世生态
文明并非完全不知道舍弃副产物，但对余世理解长期不足。

个人余痕  
-> 小型余器事故  
-> 区域余灾  
-> 战争/产业/宗门造成不同弃相沉积  
-> 正规舍台被发现不仅是服务机构，也是导余基础设施  
-> 现有导余体系开始无法处理越来越复杂的弃相生态  
-> 相容弃相出现结构化趋势。

**作用：**给明线持续制造不可回避的外部压力和奇观，不让拾余只剩生意。

## 暗线：A｜制度秘密
不从“高层邪恶隐瞒”开局，而是让陆野自己的行动逐渐撞上。

弃相没有消失  
-> 正规舍台显然早知道部分余痕规律  
-> 部分弃相被合法/非法截流  
-> 用于人工余器、某些借载设施与大型阵法  
-> 陆野一度以为“穷人舍掉的东西被有钱人拿走”  
-> 进一步发现截流设施也在缓冲余灾、稳定边界  
-> 真相从剥削叙事升级为文明如何处理自己主动丢弃的那一部分。

**原则：**正规舍台必须有真实安全价值；不能简单写成邪恶机构。

## 长篇升级方向
个人生存  
-> 小队与任务  
-> 拾余方法  
-> 组织/行业复制  
-> 余灾与制度冲突  
-> 国家/宗门级利用  
-> 余世结构化  
-> 文明与“被舍掉的另一面”应该建立什么关系。

# 第一卷｜已批准故事发动机

详细权威文件：

> `outline/volume1_story_engine.md`

## 社会入口
> 驿货行短途杂役 / 押货杂役。

## 两级现实目标
> 正式押货资格  
> -> 固定路线 / 固定小队席位。

一级目标在第一卷中点附近完成，原则上约40%—55%，以状态是否完成为准，不锁精确章数。

## 第一卷暗主题
> 陆野想变得不那么容易被替换；后来他真的难以替代，却部分因为别人发现他的缺位有用。

## 人物结构
- 固定货路核心：陆野、乔九、罗槐、唐禾、石小庚
- 高频外部：周照、曹闻川
- 私人生活：必须有1名高频生活锚点；当前首选合租旧友，但身份细节未冻结

## 第一卷主要因果
- 事故后陆野舍味筑基并漏舍，资格被冻结；
- 限制复工与普通护运让他重新证明正常筑基本事；
- 尝余开始从后遗症变成可利用信息；
- 一次“感知真实、归因错误”的误判造成实际钱与信用损失；
- 问题逐渐从单件货转向长期中转流程的低水平风险叠加；
- 卷末高混杂余灾中尝余接近失效，主要依靠正常修炼、团队、路线知识与舍务封控解决；
- 陆野获得固定席位，同时第一次发现自己的缺位开始被现实定价。

## 单元冻结策略
不冻结完整12单元精确顺序。

采用：
> **8个骨干功能节点 + 2—4个弹性单元。**

具体见第一卷发动机文件。

## 卷末必须留下的中段接口
- 固定席位 = 收益 + 对他人负责
- 队伍 = 信任 + 未解决利益分歧
- 尝余 = 有价值 + 不能独立作证
- 误判 = 钱可赔 + 信用债未清
- 流程整改 = 风险压住 + 新成本出现
- 私人生活 = 工作成功继续影响下班后的生活

这些接口用于保证100—300章自然换挡，但**不等于已经批准第二卷详细剧情**。
