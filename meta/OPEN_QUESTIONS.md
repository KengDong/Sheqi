# 未决问题 / Backlog

## P0｜V1.0 冻结阻塞

### [ ] 我相真实性与牵连深度
“味觉”“恐惧”“亲缘”“名字”等为何是可舍的真实我相？
舍台如何证明它长期参与塑造本人，而不是临时装出来？
当前方向：使用**记忆牵连、行为牵连、关系牵连、身份/长期选择牵连**等质性证据，不做点数面板。

### [ ] 深层我相切割边界
“爱某人”“夫妻身份”“亲缘责任”“关于家庭的记忆”高度交织时，能否单独切？
需要建立：
- 可分离我相
- 高耦合我相
- 强切连带损伤
的逻辑，但避免变成外科菜单。

### [ ] 睡眠 / 梦 / 静息
若“舍眠”存在，必须拆清：
- 身体恢复
- 神魂整理
- 梦
- 意识中断
并解释无眠者为什么仍需付出恢复时间、不能24小时无成本工作/修炼。

### [ ] 正破成本在六境中的具体来源
不能只写“完整续我很难所以贵”。
至少为筑基、金丹、元神等关键境界解释：
- 完整续我最难稳定的结构是什么
- 为什么需要时间/资源/设施
- 为什么借载更贵但更快
- 为什么舍破只省“续”的成本
