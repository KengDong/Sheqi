# Bible V1.0 Freeze Record

作者已批准最终独立审核的三项关键选择：

1. **余位 -> 缺位**。
2. 第三路线不强行固定“舍弃续我”为高频专名；社会继续自然使用“舍破”，完整说明按语境表达。
3. **我相采用第一人称整合边界**：
   > 我相，是持续以第一人称参与主体感知、调节、行动、记忆、关系或身份运行，并已成为当前主体稳定结构的一部分。

## Freeze Result

Bible V1.0 的系统级 P0 已全部关闭。

冻结范围包括：
- 修积 / 明悟 / 续我；
- 六境与五次大境跃迁的生命结构变化；
- 完整续我、借载、舍破的功能边界；
- 三问模型；
- 定相 / 定我 / 散我；
- 急舍 / 战舍边界；
- 舍眠恢复债；
- 弃相 / 缺位 / 余世 / 余痕 / 余灾；
- 余器基础语法；
- 陆野第一次舍味与漏舍的系统闭环。

## Not Frozen

以下故意留给后续故事研发：
- 陆野职业与开篇具体场景最终版；
- 第一卷核心人物；
- 第一卷对手与因果链；
- 具体宗门、城市、机构；
- 余世终极真相；
- 余我/主体性；
- 弃相截流的最终规模与用途；
- “异世记忆者 / 系统型余器”是否正式进入剧情。
