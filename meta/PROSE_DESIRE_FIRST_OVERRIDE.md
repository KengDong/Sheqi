# PROSE DESIRE FIRST OVERRIDE
## 先证明好看，再花资源证明能写长

This document overrides the old stage ordering in the current V3 pipeline wherever they conflict.

# 1. Future candidate order

1. Market evidence
2. Concept + honest packaging
3. Direct Opening Benchmark
4. P-1 internal micro-prose
5. P0 First Screen
6. Internal clean-reader behavior gate
7. Author exposure only for top internally surviving 1–2
8. Story Reservoir
9. Character Engine / Collision
10. Minimal Horizon
11. P1
12. P3
13. Opening Arc
14. P7 / P20
15. production + long-run architecture

# 2. P-1

Purpose:
> kill procedural/AI/mechanical openings before full P0.

For each candidate generate 2–3 isolated 300–600 Chinese-character opening attempts with genuinely different scene choices.

Internal only.

Reject if no variant creates:
- immediate curiosity/desire;
- protagonist attitude/personality;
- premise-in-action;
- one non-obvious human beat;
- next-screen pull.

# 3. P0 internal gate

P0 is 800–1500 Chinese characters.

Before author sees it:
- at least two clean readers;
- voluntary stop/continue;
- exact stop point;
- spontaneous recall;
- expected next screen;
- compare against named benchmark's reader function.

No weighted score.

# 4. Structural gates moved later

Reservoir / Character / Horizon now answer:
> “this enjoyable thing can continue?”

They no longer answer:
> “this deserves to be enjoyable.”

# 5. AI production suitability

AI suitability is:
> veto / warning only before P0.

It may kill:
- impossible daily research;
- catastrophic continuity;
- bespoke-puzzle dependence.

It may NOT positively advance a concept merely because:
- state is compressible;
- job loop is stable;
- scene grammar is reusable.

# 6. Author exposure

Author is NOT the first QA layer.

Default:
> author sees 1–2 internally strongest P0s only.

If author rejects:
> ROOT REOPEN immediately.

# 7. One sentence

> **不再让“理论上能写长”排在“这一页好不好看”前面。**
