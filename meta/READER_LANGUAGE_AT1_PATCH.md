# READER LANGUAGE AT1 PATCH｜A-T1商业正文自然化补丁 V1

> 本补丁不写新正文。
>
> 它只规定下一版A-T1如何把：
>
> **作者工程模型 -> 读者第一次能看懂、能看见、像正常小说的语言。**

---

# 0. 总补丁

A-T1下一版不允许只做：
> 同义词替换。

必须同时修四层：

1. **Scene Order**：先三锚，再零件；
2. **Information Ownership**：核心规则由叙述清一次，不让对白当QA；
3. **Reader Naming**：物件先类别/形状/功能，后行业短称；
4. **Texture / Rhythm**：允许一点真实工作与身体纹理，不让每段都证明设计。

---

# 1. 开场三锚

A-T1前300—500字只优先让读者知道：

1. **一副运重货的长架正在继续偏/压；**
2. **老秦被它卡住，再动会伤得更重；**
3. **陆野正在守着一处能暂时拖住局面的闸/控制。**

禁止第一屏同时要求读者理解：
- 长架正式类型；
- 导向柱；
- 短钩；
- 封箱；
- 舍务处；
- 应急舍台；
- 外环；
- 绞盘；
- 铁齿；
- 控制扣。

# 2. 物件首见Patch

| 当前词/写法 | 下一版第一次读者语言 | 后续允许简称 | 处理 |
|---|---|---|---|
| 长架 | 一副运重货、贴地移动的长货架/重货架（具体形态以Visual为准） | 架子/货架 | 第一句必须给类别，不直接只说“长架” |
| 导向柱 | 固定在旁边、限制货架跑偏/保护工位的柱或护柱 | 柱子/护柱 | 正式工程名后置 |
| 铁柄 | 手边能暂时刹住/拖住架体的闸柄 | 闸柄 | 先功能后材质 |
| 制动 | 刹住/闸住的动作与结果 | 闸/制动 | 第一次优先动词 |
| 木撑 | 工人塞进去临时顶住的木撑/木楔 | 木撑 | 可保留，必须交代从哪边塞、顶哪里 |
| 短钩 | 普通搬货用的小钩/短钩 | 短钩 | 只做人际/工作纹理，不当空间锚 |
| 封箱 | 若非当前因果必要，首段推迟；若必须出现，先“正要退回去的一只封匣/封着的箱” | 封匣 | 不同时引入“舍务处” |
| 应急舍台 | 墙边凹进去的一处应急台位；真正进入选择时再知道它是舍台 | 舍台 | 不在事故总图阶段抢注意力 |
| 外圈/封位外环 | 台边最外一圈受损的封环/保护环（若必须） | 外环/封环 | 第一次只说后果：后续安全收尾可能出问题 |
| 绳轮 | Writer/Visual知道即可 | — | A-T1第一见默认删出Reader Layer |
| 控制扣 | 远处需要持续压住/咬住的那道闸或控制 | 闸/扣（若高频） | 首见不要把“控制扣”当定义 |
| 铁齿 | 闸真正咬住时的可见/可听结果 | — | 默认不作为新名词进入 |
| 控制位 | 不使用抽象岗位词；写“远处那道闸/需要一直压住的地方” | — | 禁止首见 |
| 舍务处 | 本场若无人物关系需要，可不落正式机构名 | — | 不为解释封匣来源而多造认知负担 |

# 3. “舍味”第一次说明｜Core Premise Exposition Patch

## 当前问题
现A-T1把核心规则拆成：

- 值守提醒；
- 陆野“知道”；
- 值守再解释；
- 陆野再“知道”；
- 旁白再说明；
- 后面又用舍台对话确认。

结果：
> 核心信息齐全，但像项目QA。

## 下一版主要解释渠道
优先：

> **第三人称近距离叙述，贴陆野当前判断。**

只说明当前选择真正需要的事实。

### 必须读懂的5件事
1. 陆野早已练到筑基最后一步；
2. 舍味这份准备早就办过，不是现场临时发明；
3. 真执行后，酸甜苦辣这一类味觉永久消失；
4. 它本身不会增加灵力、力量或机械控制能力；
5. 它只会让陆野这次过最后一关时少带一部分“自己”，能否筑基仍取决于他此前已经完成的修炼。

## 本场不讲
- 修积；
- 明悟；
- 三问；
- 我相；
- 定相；
- 定我；
- 余世；
- 为什么味觉对所有人是否都够。

## 对白只做什么
现场值守只需要确认：
- 预案是否仍是那份；
- 本人是否决定执行；
- 舍台受损后的额外风险是否接受。

不再让值守负责给读者上“舍弃不产力量”课。

---

# 4. “借载”第一次说明Patch

## 当前
> “临时借载呢？”
> “接不上。人没配过，东西也不在这儿。”

问题：
读者第一次不知道：
- 借什么；
- 载什么；
- 为什么能替代舍味。

## 下一版Reader Function
第一次只需要读懂：

> **有没有一种不用永久舍掉自己、靠外部帮助把这最后一步跨过去的办法？有，但那东西必须提前按人准备，现场现在接不上。**

是否立刻落正式词“借载”：
> 可选。

若只出现一次，
可以先功能、后词，甚至本原型不要求读者记词。

## 禁止
- 解释基础设施；
- 解释价格；
- 解释三条续我路径；
- 讲阶层。

甲辅只是一拍：
> 世界并非只有“舍自己”。

# 5. 舍台 / Y1.5前置风险Patch

A-T1此时还没执行舍味，
不应提前把“封位/余世后处理”讲成专业课程。

## 决定前只允许
读者知道：

> **事故把应急台的一处保护结构擦坏了；它还能完成切离，但事后的安全收尾比正常情况更冒险。**

## 不允许
在决定前完整说：
- 外圈；
- 封位；
- 封不完整；
- 漏舍；
- 余痕。

这些后果应在后续真正发生时逐层落名。

# 6. 事故对白人话化

# 6.1 普通工人
对白职责：
> 下一步做什么。

允许：
- 别松；
- 往哪顶；
- 抬不了；
- 腿卡着；
- 再等多久。

不说：
- 制度；
- 系统原因；
- 全部受力解释。

---

# 6.2 值守 / 安全人员
对白职责：
- 当前是否还能执行；
- 哪个风险不能保证；
- 本人是否确认。

他可以比普通工人正式，
但不能变公文接口。

### 检查
每句问：
> 一个第一次读者能不能用一句普通话复述？

若不能：
> 叙述先翻译，或者改对白。

---

# 6.3 陆野
陆野专业，但此刻最重要的是：
> 做决策。

他不需要用工程词证明自己专业。

专业性通过：
- 知道不能往哪抬；
- 知道炼气能碰到但稳不住；
- 知道哪个普通方案已经来不及
体现。

---

# 7. 老秦动机Patch

## 当前风险
“五分钟前踢短钩”的回忆太精准承担：
> W不是路人。

## 下一版原则
不需要加惨。

只需要让读者自然感觉：

> **这是一个陆野今天一直在一起干活、知道怎么说话、会互相报动作的人。**

可通过当前时态做到：
- 老秦知道陆野动作习惯；
- 陆野听得懂老秦“腿卡哪”的短话；
- 两人高压中有一句熟人式打断；
- 旁边的人直接叫名字而非“伤员”。

旧短钩细节：
> 可保留，也可删。

不能把它当唯一关系证明。

# 8. 正常味觉基线Patch

血腥味是当前A-T1最合适的基线。

理由：
- 已在救援动作中；
- 不新增吃饭场；
- 不煽情；
- 切味以后天然可回调。

保留原则：

> 一拍足够。

不要连续：
- 舌根血；
- 想到以后没有；
- 再回忆食物；
把它扩成“最后的味道”。

---

# 9. 机械控制Patch

## Reader版本只需要一条因果

### 炼气
> 灵力能碰到远处那道控制，但留不住。

### 筑基
> 同样的灵力可以稳定留在身外，持续把那道控制稳住。

这就是全部阅读合同。

## Writer/Visual仍保留
- 绞盘；
- 卷轮；
- 摩擦制动；
- 张力；
- 副支撑；
- 真实机械载荷。

正文不需要第一次全部展示。

# 10. Explanation Ownership Map

下一版每类信息只设一个主要owner。

| 信息 | 主要owner | 次要owner禁止重复什么 |
|---|---|---|
| 老秦为什么危险 | 动作/空间 | 旁白不再总结一次“时间窗口” |
| 陆野炼气为什么不够 | 失败动作 + 一句近距叙述 | 值守不再解释境界课 |
| 陆野已到筑基最后一步 | 近距叙述 | 多人不再重复 |
| 舍味永久 | 近距叙述 | 值守不再再说一遍 |
| 舍味不产力量 | 近距叙述 + 后续动作证明 | 对白不再QA |
| 借载为什么不行 | 一句现场答复 + 必要叙述翻译 | 不讲制度 |
| 舍台受损风险 | 值守一句人话 | 不提前讲漏舍机制 |
| 本人确认 | 正式现场对白 | 旁白不解释这是流程 |

# 11. Paragraph Texture Patch

下一版必须主动打破A-T1现有模板。

## 可连续出现
- 2—4句现场口令；
- 一小段陆野近距判断；
- 一段直接核心解释；
- 一串短动作；
- 一拍身体感官。

## 禁止模板循环
> 动作  
> -> 对白  
> -> 解释  
> -> 防误读  
> -> 动作  
> -> 对白  
> -> 解释。

尤其在核心舍味解释后：
> 让场景自己证明，不再补“这说明舍味没给力量”。

---

# 12. Lived Texture最低要求

不是加装饰。

只检查：
> 场景里是否至少有2—3个属于“人在干活/受伤/互相熟悉”的真实细节，而非Canon/事故设计节点。

当前可保留候选：
- 掌心汗；
- 嘴唇破、血味；
- 老秦说话习惯；
- 脚边普通工具；
- 木撑被压矮的视觉/声音。

禁止为了纹理新增：
- 童年回忆；
- 家庭悲情；
- 风景抒情。

# 14. 下一版禁止新增的东西

- 新事故原因；
- 新救援工具；
- 新Canon术语；
- 新舍项；
- 老秦家庭惨史；
- 余世；
- 尝余；
- 漏舍解释；
- 新的世界观对照；
- 为“人味”加大量闲聊。

目标不是加内容。

是：
> **让同一内容真正按成熟小说的读者顺序发生。**

# 15. 商业正文验收句

A-T1 V2写完后，
不先问：

> “Canon解释完整吗？”

先问：

> **“一个第一次读者，是不是先看见人和事，再自然知道规则？”**

如果答案仍然是否定：
> 不送作者亲读。
