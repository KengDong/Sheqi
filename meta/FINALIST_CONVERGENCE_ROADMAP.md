# FINALIST CONVERGENCE ROADMAP｜从架构走向真正小说

## North Star

> **Good Novel First。**

目标不是完成最多设计文件。
目标是：
> **尽快用足够可靠的结构准备，换取高质量正文，然后让真实阅读体验决定。**

---

# Phase A｜NOW｜Dual Canopy

## C01
ACTIVE：
> Longform Canopy Architecture

必须证明：
- 140—170万健康体量；
- 枝叶足够；
- 中小弧不是订单合集；
- 固定人物网能自己生故事；
- “未来属于谁”能形成远景；
- Ch50/100/200/400/700真的不同。

## C12
ACTIVE：
> Longform Canopy Architecture

First-10已Total Editor PASS。

必须证明：
- 180—220万核心体量；
- 不靠更大雷；
- 职业/修炼/劫债/资格/关系/幽默同时复利；
- 固定人物网足够厚；

- Ch50/100/200/400/700真的不同。

### Stop Rule
Canopy做完即停。
不继续自行加研究。

# Phase B｜Dual Canopy Total-Editor Shelf-Parity Audit

总编只问六件事：

1. 如果删掉漂亮术语，这是不是仍然有很多好故事？
2. 中小弧是不是会留下永久变化？
3. 固定人物是不是能自己制造故事？
4. 爽点 / 情绪 / 关系 / 秘密是不是持续有不同回报？
5. Long-Horizon是不是从第一章长出来而非后贴？
6. 和真实头部热门长篇相比，读者欲望供给是否明显掉档？

### Outputs
只允许：
- PASS TO PROSE；
- TARGETED PATCH；
- FAIL/HOLD。

不默认再开研究。

# Phase E｜Six-Chapter Decision

真正依据：
> **正文读感。**

重点：
- 第6章是否更想点第7章；
- 是否在追人而非追Concept；
- 是否持续有不同类型回报；
- 是否有固定关系开始让人想跟；
- 是否能感觉未来很大但当前仍好看；
- Long-Horizon是否只轻轻拉着，不抢戏。

可能：
- Primary / Reserve；
- 双PASS继续短期双轨；
- 双FAIL回最小故障修复。

# Phase G｜Production

默认：
> **写、读、改。**

大研究只在有证据问题时重开。

里程碑：
- Ch10；
- Ch30；
- Medium Arc；
- Stage 1 end；
- Ch100。

每个里程碑只审：
> 读欲有没有掉、人物有没有变薄、回报有没有重复、秘密有没有拖、世界有没有变成说明书。

---

# Anti-Process Rule

如果一个任务不能清楚回答：
> **“它如何提高小说真实好看程度？”**

不做。

如果一个设计文档很好看、正文不好看：
> 设计文档失败。

如果正文真实更好：
> 允许推翻设计。

这就是后续所有任务的最高执行规则。


# Phase E2｜Head-Tier Benchmark Parity

在Fresh Ten-Chapter Blind完成后，必须立刻执行：

> `research/briefs/2026-09-23_ten_chapter_headtier_benchmark_parity_brief.md`

目的：
> 不是问“我自己觉得好不好看”，而是问“放到真实头部热门旁边，持续追读发动机还差什么”。

执行顺序不可逆：
1. Fresh Reader先给无污染读欲证据；
2. 再做Benchmark Parity；
3. Total Editor合流两类证据；
4. 才决定Ch11—30 / Primary / Targeted Gap Patch。

Benchmark不用于：
- 模仿具体情节；
- 推翻真实Reader喜欢的东西；
- 机械打分。

Benchmark只用于：
> 发现我们自己没意识到的追读短板。
