# PROSE BIBLE｜《修仙先舍一件人间事》正文声线与生产规则 V1

> 这是正文执行层规则，不是世界 Canon。
>
> 与 manuscript / Canon / approved Outline / approved chapter cards 冲突时，本文件让位。

## 0. 一句话总规

> **第三人称近距离限知，动作与具体物优先；人物认真做事时自然产生轻微幽默，真正代价出现时主动收声。**

四条最高优先级：

1. **旁白不是第二个段子手。**
2. **人物“算法”只是先注意什么，不是每场必触发的笑点按钮。**
3. **设定优先通过动作、钱、器物、工作和后果显出来。**
4. **重大事故、永久损失、真实信用重创时，文字宁可少说，不替角色总结主题。**

---

# 1. 视角与叙事距离

## 1.1 默认视角

> **第三人称近距离限知。**

默认跟随：
> **陆野。**

读者通常只直接获得：
- 陆野当前看见的；
- 陆野当前听见的；
- 陆野当前会注意的；
- 陆野当前真实会想到的。

禁止突然进入：
- 乔九完整内心；
- 唐禾完整内心；
- 周照秘密判断；
- 作者全知解释。

## 1.2 叙事距离

默认：
> **中近景。**

允许拉近：
- 关键决定；
- 突然发现；
- 身体体验；
- 永久缺位第一次落地；
- 误判真正落到钱 / 信用时。

允许短暂拉远：
- 多人工作协作；
- 事故空间；
- 需要看清多人动作。

拉远只为了：
> **看清发生了什么。**

不是为了讲世界史。

---

# 2. 动作 / 具体物优先

正文细节优先级：

1. **会改变动作**
2. **体现职业 / 阶层**
3. **气氛**
4. **纯漂亮**

优先写：
- 坏在哪里；
- 人站在哪里；
- 哪个工具够不到；
- 谁挡路；
- 谁付钱；
- 谁被允许；
- 谁被停；
- 哪件东西必须换；
- 哪个动作来不及。

若一段说明只因为：
> “读者应该知道世界观”

而当前没人需要它，
优先不写。

---

# 3. 设定进入正文

## 3.1 先功能，后名字

新术语第一次出现：

> **先让读者理解它做什么，再要求读者记名字。**

## 3.2 一次只给当前动作需要的层级

例如第一章修籍核验只需要：
> 筑基续关在册；本人应急舍备有效。

不同时解释：
- 修积；
- 明悟；
- 三问；
- 定相；
- 舍台原理；
- 为什么别人不一定适用。

## 3.3 说明动作化

优先改成：
- 看一眼；
- 盖印；
- 收回；
- 拒绝；
- 停机；
- 换件；
- 赔钱；
- 被排除；
- 被允许。

现实后果比制度讲解更有记忆力。

---

# 4. 旁白红线

旁白职责：
- 让动作看清；
- 让空间看清；
- 贴近陆野当前理解；
- 补最少必要事实；
- 偶尔非常轻的干性观察。

旁白不得：
- 连续吐槽；
- 玩网络梗；
- 用现代职场类比；
- 提醒读者“这多荒唐”；
- 替人物讲主题；
- 替世界下价值判断；
- 每逢轻松场抢最后一句。

硬检查：

> 如果一个笑点把人物删掉以后，旁白自己仍能完整讲出来，优先删。

---

# 5. 幽默档位

只使用：

> **轻 / 中 / 收声**

不设置：
- 每千字笑点数；
- 每章包袱数；
- 强笑点 KPI。

## 5.1 轻

适合：
- 普通工作；
- 熟人配合；
- 小钱；
- 吃饭；
- 工具；
- 日常排班；
- 无真实伤害的小摩擦。

允许：
- 人物认真逻辑造成错位；
- 一句短嘴贫；
- 熟人顺手拆台；
- 行动本身好笑；
- 旧行为回调。

禁止：
- 连续抖包袱；
- 旁白接第二层梗；
- 全员接梗；
- 角色降智；
- 把职业行为写成小品。

## 5.2 中

不是“更好笑”。

表示：
> 场景仍可有轻微幽默，但冲突 / 利益更实。

适合：
- 资格竞争；
- 低风险任务；
- 客户小损失；
- 生活边界；
- 小队磨合。

幽默必须服从：
> 立场、钱、责任、行动。

## 5.3 收声

默认进入收声：
- 舍味决定；
- 舍契执行；
- 第三章救援；
- 漏舍确认；
- 苦药无味；
- 真正伤亡；
- 客户信用重创；
- 卷末余灾；
- 重大关系断裂；
- 永久缺位第一次明显改变生活的核心瞬间。

收声意味着：
- 不主动找包袱；
- 旁白不机灵；
- 比喻减少；
- 台词只保留必要信息；
- 允许沉默；
- 允许没有主题总结。

---

# 6. 第一轮正式声线校准｜已批准

## 6.1 坏货签夹

> **A-lite**

标准：
- A的动作密度；
- B的克制上限；
- 可以有一个短促嘴贫；
- 不允许陆野完整总结自己的人设。

类似：
> “所以我扔了。”

可以。

类似：
> “坏的是夹子，不是里面每一件都坏。”

不作为固定基准。

## 6.2 咸汤

> **A-lite**

标准：
- 太咸 -> 兑水 -> 乔九轻碰一下 -> 出班；
- 只保留一轮人物碰撞；
- 不发展成小相声。

## 6.3 苦药无味

> **A**

作为“收声”基准：
- 温度存在；
- 质地存在；
- 苦味不存在；
- 第二次确认仍不存在；
- 不哲学；
- 不自嘲；
- 不发现好处；
- 不出现异常味。

## 6.4 总参数

陆野嘴贫：
> **低到中，偏低。**

旁白存在：
> **低。**

工作场对白：
> **中低密度。**

重场：
> **身体事实先成立，意义后置。**

# 7. 角色注意力优先级

> 这些是“通常先看什么”，不是台词按钮，也不是每场必须触发。

| 角色 | 通常先注意 |
|---|---|
| 陆野 | 用途、还能不能用、损耗 / 钱、风险、现实后果 |
| 乔九 | 时间、人手、空转、线路、哪里会堵 |
| 石小庚 | 准确、受力、稳定、影响结果的小误差 |
| 罗槐 | 最坏后果、承载边界、什么该退出关键用途、责任落谁 |
| 唐禾 | 谁付钱、谁留记录、长期客户、今天省的小钱未来会不会放大 |
| 周照 | 当前证据支持到哪、什么只是异常、什么已经能判、立即生效的安全边界 |
| 曹闻川 | 停线代价、工人饭碗、证据是否配得上处置等级、经营能否承受 |
| 生活锚点 | 空间、工具、自己的工作进度、共同资源与共同支出 |

禁止写成固定口头禅库。

任何角色都允许：
- 某场不触发默认注意点；
- 做短期冲动选择；
- 在事实变化后改判断。

---

# 8. 陆野内心规则

## 8.1 常态

通常优先：
> **用途 -> 损耗 / 钱 -> 风险 -> 人际后果。**

## 8.2 危险

危险出现后立即切换：
> **人命 / 风险 -> 能不能做 -> 损耗。**

必须证明：
> 陆野惜物，但不会拿人命换小钱。

## 8.3 抽象问题现实化

早期不想：
> “文明把自我异化成成本。”

更可能想：
> 这事会不会让我不能上班？

不想：
> “缺位改变了我的主体性。”

更可能想：
> 以后吃饭真就全一样了？

不想：
> “我的特殊性正在被资本定价。”

更可能想：
> 为什么这趟特意排我？多给钱吗？出了错算谁的？

## 8.4 什么时候会嘴贫

- 熟人；
- 小损失；
- 他仍能掌控；
- 想掩饰自己在意；
- 对方接得住。

## 8.5 什么时候沉默

- 真正永久损失第一次确认；
- 自己真实伤到别人；
- 别人的损失无法靠一句话补；
- 他意识到自己判断错；
- 别人把“缺位”当岗位价值而他还没想明白。

---

# 9. 对白

每句对白优先有现实目的：
- 让人动；
- 让人停；
- 改条件；
- 拿信息；
- 拒绝；
- 争责任；
- 缓和关系；
- 掩饰情绪。

不要求完整句。

允许：
- 省主语；
- 半句；
- 被打断；
- 只回答一半。

禁止：
> 每个人都能精确概括自己的立场和主题。

若一个争论连续三轮只是换说法表达同一立场：
> 压缩。

# 10. 人物声线防漂移

## 陆野
不是：
- 反制度思想家；
- 贫嘴喜剧主角；
- 天才侦探；
- 垃圾都是宝信徒；
- 因穷没安全底线的人。

## 乔九
不是：
- KPI老板；
- 黑心资本家；
- 永远催人。

## 石小庚
不是：
- 阴阳怪气竞争者；
- 强迫症笑话；
- 嫉妒主角外挂的人。

## 罗槐
不是：
- “一遇风险就扔”的舍弃派；
- 冷酷队长。

## 唐禾
不是：
- 财务机器人；
- 性别化“精明女人”；
- 每句话都算钱。

## 周照
不是：
- 官腔；
- 神秘组织百科；
- 永远只会说“不能证明”。

## 曹闻川
不是：
- 奸商；
- 黑心老板；
- 风险再大都不停。

## 生活锚点
不是：
- 情绪治疗 NPC；
- 主题镜像；
- 主线情报员；
- 永远正确的生活导师。

---

# 11. 重场禁区

## 舍味 / 救援
禁止：
- 自嘲味觉；
- “以后省饭钱”；
- 主题金句；
- 大段哲学；
- 机灵对白；
- 炫技感。

## 苦药无味
禁止：
- “以后苦药赚了”；
- “人生从此无味”；
- “这便是舍弃的代价”；
- 异常味。

## 真正伤亡
禁止：
- 黑色幽默；
- 用尸体做气氛道具；
- 立刻借死亡输出主题。

## 客户信用重创
禁止：
- 下一次救人立刻抵消；
- “大家都理解你了”清零；
- 笑赔偿金额。

## 卷末余灾
禁止：
- 用怪异美学盖过撤离；
- 尝余突然增强解决一切；
- 过度诗化。

# 12. 章节非标准化

AI不得机械套：

> 小目标 -> 小冲突 -> 小反转 -> 金句章尾。

允许：
- 无反转章；
- 现实通知章尾；
- 动作未完章尾；
- 关系状态变化；
- 一章只有一个强场景；
- 奖励章；
- 无异常 / 无谜团推进的普通工作章。

章尾优先：
1. 状态变化；
2. 新决定；
3. 现实通知；
4. 新条件；
5. 未完成动作；
6. 真正问题。

尽量少用：
> “他不知道的是……”

# 13. 正文生产 SOP

## Step 1｜场景脊柱

冻结：
- 欲望；
- 阻力；
- 空间；
- 决定；
- 状态变化。

不先写主题。

## Step 2｜锁少量关键动作 / 对白

只锁：
- 不能丢的角色行为；
- 状态转折；
- 必须准确的规则边界。

## Step 3｜写作AI场景级草稿

原则：
> **按单场景 / 单局部目标扩写。**

600—1500字只是常用工作区间，**不是硬配额**。

真正硬约束：
- 一次只解决一个主要局部目标；
- 不自动扩剧情边界；
- 不自动加人物 / 规则 / 主题句 / 强笑点。

## Step 4｜独立 Prose Editor

必须知道：
- 当前章卡结果状态；
- 相关人物关系；
- 当前幽默档位；
- 必要 Canon 边界。

尽量不知道：
- 作者想表达什么哲学；
- 想让读者感动 / 好笑到什么程度。

只审：
- AI味；
- 声线；
- 解释重复；
- 句式工整；
- 金句过密；
- 对话过完整；
- 幽默过度；
- 旁白抢戏；
- 场景接缝。

## Step 5｜整章接缝修订

删：
- 每场重新介绍地点；
- 每场重新立目标；
- 重复人物入场；
- 上场刚说过的信息再解释；
- 模块拼装式过渡。

## Step 6｜遮名测试

把主要对白人名遮掉。

若所有句子可随便换人：
> 声线失败。

## Step 7｜双盲读

结构盲读：
- 当前想要什么？
- 为什么翻页？
- 状态变了吗？

文本盲读：
- 哪里像AI？
- 哪里像作者在解释？
- 哪个人说话不像人？
- 哪里太会写？

## Step 8｜作者批准关键位置

重点看：
- 第一段；
- 长期人物首次对白；
- 重场；
- 章尾；
- 整体“像不像这本书”。

不要求作者逐字重写全文。

---

# 14. 每章硬红线

正文AI不得：
- 新增剧情转折；
- 新增角色；
- 新增设定；
- 新增神秘线索；
- 为追读强化章卡未批准的钩子；
- 把研究术语写进人物嘴里；
- 用总结句替读者解释人物；
- 为了幽默让人物降智；
- 为了文学性让工作动作失真；
- 把未冻结视觉细节写成世界事实。

---

# 15. 使用方式

每次正文生产默认读取本文件。

详细编辑清单、模板和扩展说明放在：

> `meta/PROSE_PLAYBOOK.md`

写作模型：
> 优先读本文件。

编辑模型：
> 本文件 + Playbook 按需读取。

本文件不因某一章好笑 / 不好笑而频繁改动。
