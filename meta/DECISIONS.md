# 关键决策记录

## D-0001 舍弃不直接产生战斗能力
**状态：已批准**  
舍破只降低“续我”成本。真正战力来自正常修为、功法、术法、肉身、神魂、法器与经验。

**否决：**“舍恐惧=获得无畏神通/攻击加成”式Build。  
**原因：**会把小说游戏化，并诱发无限优化攻略。

## D-0002 破境采用“修积—明悟—续我”
**状态：已批准（Bible V1.0）**  
日常仍可简称“积—悟—续”。修积与明悟无法被舍破替代；正破/借载/舍破只在续我阶段分流。

## D-0003 已舍不可恢复
**状态：已批准**  
外物、人工记忆、伙伴、余器只能代偿；第一人称体验不可还原。

## D-0004 余世只接收有效舍契产生的弃相
**状态：已批准**  
普通遗忘、自然衰退、普通失恋与情绪变化不会自动进入余世。

## D-0005 急舍不是连续爆种技能
**状态：已批准**  
必须事前定相、已达真实续关；首次舍弃后旧契失效、进入新境初段并开始定我。

## D-0006 陆野不是“最会舍”的主角
**状态：已批准方向**  
他的特别之处应更多来自：异常感知、惜物性格、研究和利用别人不要的东西。

## D-0007 余器不是万能神器库存
**状态：已批准方向**  
一器一奇用，功能窄、条件明确、余性风险明确。

## D-0008 “未来可能”暂不进入硬规则
**状态：暂缓**  
保留为高境理论/争议，不在V1.0提前锁死。

## D-0009 《七成同意》暂停
**状态：已批准**  
当前研发资源集中到《舍弃》。

## D-0010 传统修炼首选经典六境
**状态：已批准（Bible V1.0）**  
首选：炼气 -> 筑基 -> 金丹 -> 元神 -> 法相 -> 洞天。

**理由：**本书的新鲜认知预算已经集中在舍破、余世、弃相、定我、余器；主修体系应易懂但体验不照搬。

**必须保留的新动词：**
- 炼气：用灵气
- 筑基：力量稳定离体
- 金丹：自循环、持续运行
- 元神：神魂脱身、多线控制
- 法相：自身道路外显
- 洞天：改变战场环境

## D-0011 余器效果语法采用“回声 / 反位 / 共鸣”
**状态：已批准（Bible V1.0）**  
余器能力必须能从原弃相解释出来，不允许从“失去味觉”跳到无关雷电权柄。

同时保留：
- 余扰叠加
- 同类共鸣可能形成小型余灾
- 安全封存状态不能使用
- 使用后需要退余

15件测试余器目前只属于压力测试样本，不自动进入正式道具Canon。

## D-0012 陆野职业首选驿货行底层杂役
**状态：已批准（第一卷Outline）；由 D-0024 扩展**  
主业：短途脚夫/押货杂役/跑腿。  
保留：穷人式自行修补工具与小法器能力。

**理由：**移动性、阶层接触、货物流动、怪旧物接触都自然，又不会从第一章把陆野写成余器专家或捡漏鉴宝主角。

## D-0013 中央主线采用“三线合流”而非单线阴谋
**状态：强候选**  
- C“拾余路线”：主角明面行动因果链，负责状态繁殖。
- B“余灾治理”：世界外部压力，避免故事只剩创业/捡漏。
- A“制度秘密”：中后期真相层，避免开局就变成“高层隐藏一切”的阴谋揭露文。

## D-0014 漏舍事故应是可解释的职业/基础设施事故
**状态：系统机制已批准（Bible V1.0）；具体场景仍待第一卷确定**  
不采用“天降雷劈刚好坏一半”。
推荐结构：应急舍备 -> 与舍务废件/余痕物流相关的事故 -> 封位环损坏 -> 主角主动承担风险 -> 应急封余抢救 -> 留下余缝。

## D-0015 暂不发布 Bible V1.0
**状态：已被 D-0018 superseded**  
当前架构无需再大规模推翻，但仍有四个底层P0阻塞：
1. 我相真实性/牵连深度的判定机制。
2. 深层我相的可切边界与连带损伤。
3. 睡眠/梦/静息的结构。
4. 六境中正破为何具体昂贵/困难。

解决后再做V1.0 Freeze。

## D-0016 开篇身份优先采用“土著陆野 + 轻量修籍”
**状态：已批准（第一卷开篇）；由 D-0026 / D-0027 细化**  
当前最优组合不是系统主角，也不是地球穿越者，而是：
- 陆野为本世界土著；
- 社会身份首先是驿货行底层杂役；
- 世界内存在轻量的修籍/验章，用于证明积、悟、续资格；
- 修籍只承担制度信息，不提供战力、我相价值、隐藏天赋或下一步提示。

**理由：**
1. 舍弃制度对陆野来说必须首先是“正常社会常识”，才能保留价值灰度。
2. 漏舍后的尝余已经承担陌生化视角，不需要再叠加穿越者身份。
3. 驿货工作可以自然带出不同阶层、货物、舍修与危险。
4. 修籍只用来快速降低开篇理解成本，不成为系统面板。

## D-0017 穿越 / 系统保留为后期故事素材，不作为主角底座
**状态：实验性提案**  
可以考虑把常见网文套路反过来纳入《舍弃》的世界：
- 某角色拥有“前世/异世记忆”，用来压力测试“前世记忆是否属于我相”；
- 某角色坚称自己有“系统”，但实际可能是任务型余器、弃相回声或其他世界内机制。

**约束：**
- 不在开篇使用，避免抢走《舍弃》核心辨识度；
- 不做纯元叙事玩梗；
- 必须服务“什么算我”“外部意志能否塑造我”这一主题；
- 最好等读者已经理解舍弃、余器和我相后再出现。


## D-0018 Bible V1.0 Frozen
**状态：已批准，2026-09-20生效**  

V0.95 阶段的P0系统阻塞已经解决。自本决策起：
- 底层修炼、舍破、余世核心规则、余器基础规则与核心术语进入 Bible V1.0 Frozen；
- 新点子不能直接覆盖 Canon；
- 底层变更必须走 Proposal -> 独立审核 -> 作者确认；
- 项目重心转入人物与第一卷故事研发。

“Frozen”不代表所有世界历史、宗门、人物、终极真相已经锁死。

## D-0019 有效舍破采用“三问”底层模型
**状态：已批准（Bible V1.0）**  

作者侧必须分别回答：
> 真不真？切不切得开？切了够不够？

对应：
1. 候选是否为当前主体真实我相；
2. 是否存在可执行切界；
3. 实际切离后是否足以降低当前续我负担。

三者不可合并为单一“舍值”，不得数值面板化。

同时批准我相定义：
> **我相，是持续以第一人称参与主体感知、调节、行动、记忆、关系或身份运行，并已成为当前主体稳定结构的一部分。**

这一定义用于防止“所有人体机能都自动成为可舍模块”。

## D-0020 深层切割遵守真实牵连
**状态：已批准（Bible V1.0）**  

人格不是插件。正规舍契只能沿真实存在的切界工作。

强切副损伤必须由原有共享结构推出；不得为了惩罚角色随机追加失忆、疯癫等效果。

舍台只能对本人主动提出并配合唤起的候选做局部确认，不能无目标扫描完整人格，也不能自动推荐“最佳舍项”。

## D-0021 舍眠保留清醒连续性，但恢复债不可消失
**状态：已批准（Bible V1.0）**  

舍眠不等于免休：
- 肉身恢复与神魂归整仍存在；
- 恢复债可以延后、拆分，但不能消失；
- 有效神魂归整期间不能同时正常工作、警戒、悟法或高负荷修炼。

舍眠的优势是关键时段清醒连续性与休息调度，而不是每天白得八小时。

## D-0022 借载允许规模化
**状态：已批准（Bible V1.0）**  

成熟宗门、家族与机构可以规模化建设借载设施。

成本来自：
- 设施建设；
- 阵位与占用时间；
- 个体/功法校准；
- 操作人员；
- 消耗性保护材料；
- 高境稀缺地脉、秘地、承载介质。

不使用“每次必有抽象结构疲劳”作为万能堵漏洞限制。

## D-0023 V1.0术语冻结
**状态：已批准**  

冻结：
- 修积 / 明悟 / 续我；
- 日常简称积 / 悟 / 续；
- 完整续我；
- 借载；
- 舍破；
- 我相 / 定相 / 舍契 / 舍备 / 弃相 / 缺位 / 定我 / 散我；
- 余世 / 余痕 / 余灾 / 余器 / 漏舍者；
- 急舍 / 战舍。

**“余位”正式替换为“缺位”。**

“缺位”必须定义为原结构永久消失后的结构性缺失/形变，不是空槽。

不采用：
- 全续 / 借续 / 舍续；
- 全渡 / 借渡 / 舍渡；
- 余相器；
- 舍渡台。

“舍弃续我”仅可作为解释性表达，不强制成为第三路线高频专名。


## D-0024 第一卷故事发动机冻结
**状态：已批准，2026-09-21生效**

第一卷正式采用以下结构：

### 社会入口
> **驿货行短途杂役 / 押货杂役。**

### 两级现实目标
> **正式押货资格 -> 固定路线 / 固定小队席位。**

一级目标在第一卷中点附近完成，原则上约40%—55%，以实际状态条件为准，不锁死48%或精确章数。

### 人物结构
- 固定工作核心：陆野、乔九、罗槐、唐禾、石小庚；
- 高频外部行动者：周照、曹闻川；
- 必须存在一名非任务型私人生活锚点。

生活锚点当前首选“合租旧友”，但姓名、性别、行业与具体生活结局暂不冻结。

### 第一卷主题暗线
> **陆野想变得不那么容易被替换；后来他真的难以替代，却部分因为别人发现他的缺位有用。**

第一卷只推进到“缺位开始被现实定价”，不提前建立完整岗位制度或社会运动。

### 关键因果
- 尝余必须发生一次**感知真实、归因错误**的实际误判；
- 误判造成真实金钱、信用与关系代价；
- 卷末根因不是邪恶仓库，而是一套长期中转流程的低水平风险叠加；
- 曹闻川不黑化，主要冲突来自经营与安全监管的风险阈值差异；
- 卷末高混杂余灾中尝余接近失效，正常修炼、团队、路线知识与舍务封控共同解决危机。

### 正常修炼
第一卷必须有三次功能不同的兑现：
1. 筑基带来的新行动权限；
2. 尝余完全无用的普通护运/战斗基本功；
3. 卷末个人修炼进入团队系统。

### 故事单元
不冻结12个精确顺序。

采用：
> **8个骨干功能节点 + 2—4个弹性单元。**

详细内容见：
`outline/volume1_story_engine.md`。

## D-0025 第一卷后只冻结中段接口，不预排100—300章事件
**状态：已批准方向**

中段研究的用途是保证第一卷成功后能自然繁殖新责任，不是提前写第二卷详细大纲。

第一卷卷末至少留下：
- 固定席位 = 收益 + 对他人负责；
- 队伍 = 信任 + 未解决利益分歧；
- 尝余 = 有价值 + 不能独立作证；
- 误判 = 钱可赔 + 信用债未清；
- 流程整改 = 风险压住 + 新成本出现；
- 私人生活 = 工作成功继续影响下班后的生活。

当前允许记录的中段发动机家族：
- 职业责任；
- 拾余方法化；
- 余灾 / 系统风险；
- 固定队利益关系；
- 修炼方法换挡。

暂不批准：
- 第二卷12个具体故事单元；
- 100—300章详细章纲；
- 拾余立即产业化；
- 第一卷后立刻换大地图；
- 每境绑定一次舍弃。


## D-0026 开篇辨识度策略
**状态：已批准，2026-09-21生效**

开篇正式采用：

> **方案C主结构 + 方案A的一次轻量舍备核验。**

核心阅读合同：
- 陆野第一章必须用行动证明“惜物”，而不是靠作者标签；
- 舍破必须作为成熟社会现实进入普通工作流程，但不写成制度展览；
- 陆野已有的味觉舍备由货行轻量核验，货行不替他选舍项、不扫描人格；
- 第一件普通破物只立人，不变宝、不救命、不成为事故源或余器；
- “前三章内完成舍味”作为章卡默认硬测试，不升级为Canon；
- 舍味前必须有极短、自然的正常味觉基线；
- 第3—5章最多出现未确认、不可控、可被解释为漏舍幻感的异常味；
- 外界来源确认、“人的残留”与“被舍掉的东西没有消失”继续严格服从秘密释放梯；
- 前30章必须至少一次由事实证明“该舍就舍”是正确判断，防止“惜物”退化成捡漏正确答案。

开篇优化不得修改已批准的第一卷发动机、两级目标、正常修炼主轴、前100章不第二舍原则、尝余证据边界与卷末中段接口。


## D-0027 第一卷功能级阶段纲冻结
**状态：已批准，2026-09-21生效**

第一卷正式采用四阶段功能结构：

1. **Phase A｜想转正，事故把路打断**
2. **Phase B｜限制复工，证明“我还能做”**
3. **Phase C｜有资格还不够，我要有自己的位置**
4. **Phase D｜固定位置意味着责任**

### Phase A边界
不锁0%—18%。

Phase A在以下状态全部成立后立即结束：
- 主动舍味；
- 筑基成功；
- 漏舍与资格冻结明确；
- 永久失味第一次落入普通生活；
- 陆野重新建立主动复工目标。

### 为什么事故前不舍味
> **舍备是应急保险，不是升职快捷键。**

陆野事故前仍优先完整续我 / 持续适应完成筑基；多挣工钱、快一点转正不足以让他主动永久失去味觉。真正跨过阈值的是：现场有人等不起，而只有筑基后的陆野才可能完成救援。

### 第一场事故
事故A保留为章卡首选，但只能采用：

> **单一几何因果版。**

必须由一个主物理失效链自然同时产生：
- 被困者；
- 低风险封存退件受损 / 泄漏；
- 舍台封位外环受损。

章卡前必须先画极简空间图；空间图不自然就切候选B坡道车架侧倾。

### 秘密边界
第一卷卷末只强制确认：

> 本次中转事故相关异常残留确实出现在多个共享材料 / 载具 / 节点上，并发生混杂、积累与现实影响。

不强制升级成普遍“有效弃相迁移规律”，更不提前推出统一去向、完整弃相理论或余世。

### 弹性单元
正式锁三项弹性功能：
- 乔九线路扩张；
- 唐禾客户信用；
- 生活锚点第二次现实冲突。

“窄用途异常旧物 / 余器”只保留**第一优先可删槽**，不承诺第一卷一定使用。

### 人物方向
生活锚点采用强候选：

> **规整、重生活边界、有独立手艺目标的合租旧友。**

姓名、性别、具体手艺、同屋各灶与搬家结局留到章卡。

石小庚只冻结：
> 至少一项正常修仙基本功明显强于陆野。

“御器精度”为当前首选，不锁死。

### 八骨干节点顺序
1. 资格竞争
2. 事故 / 舍味 / 筑基
3. 私人生活损失
4. 限制复工 / 外界确认
5. “该舍就舍”正确判断
6. 纯修仙试岗 -> 一级目标完成
7. 尝余进入现实价值 -> 误判
8. 流程风险 -> 团队控灾 -> 固定席位

节点4、7、8必须分拍，不得把多个状态变化压成一个事件。

详细权威文件：
`outline/volume1_phase_outline.md`。
