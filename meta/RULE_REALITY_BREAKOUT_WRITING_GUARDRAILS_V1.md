# RULE-REALITY BREAKOUT WRITING GUARDRAILS V1

# 0. Mandatory Benchmark-First Gate

Before ANY substantive creative change in this project:
> read and execute `meta/FIRST_PRINCIPLES_FICTION_RND_OS.md` Section 2.

Hard:
> **search and break down directly comparable popular/head-tier fiction BEFORE designing the Sheqi change.**

Do not use this file as permission to skip benchmark research.


Purpose:
> prevent future writers/controllers from protecting the framework so aggressively that the prose loses pleasure, danger, character contrast and breakout energy.

# 1. Pleasure Before Explanation

Before proposing a mechanism or scene, answer FIRST:

> **Reader具体爽在哪里？**
> **Reader具体怕在哪里？**
> **Reader为什么会想点下一章？**

If those answers are weak:
> do not rescue the idea with more logic.

Logic must support a strong story effect.
Logic is not itself the effect.

# 2. Never Default to the Safest Version

When reopening a major story problem, generate at least:
- one commercially aggressive option;
- one structurally conservative option;
- one strange/high-upside option.

Then compare.

Do NOT silently converge to the least disruptive idea merely because it preserves existing architecture.

# 3. Framework Is a Servant

Existing architecture is not sacred.

If a framework choice repeatedly suppresses:
- pleasure;
- fear;
- character desire;
- visual spectacle;
- reader anticipation;

then reopen the framework.

Do NOT say:
> “这个更安全，所以更适合本书。”

Ask:
> “这个版本读起来更想看吗？”

# 4. Difference Must Be On Page

Do not claim:
> “Returner has survived hell.”

Show a scene where ordinary people visibly operate one level below him.

Do not claim:
> “Cheng Ye is warm to family.”

Show Xiaoman treating him like a brother rather than a protagonist.

Do not claim:
> “Cheng Ye is ruthless to enemies.”

Show a confirmed enemy losing options because Cheng Ye planned for their counterattack.

# 5. Character = Relationship-Dependent Behavior

Do NOT reduce a character to 3 adjectives.

For every major character define:
- enemy mode;
- ally mode;
- family/intimate mode if relevant;
- pressure mode;
- shame/failure mode.

Character magnetism comes from contrast and switching.

# 6. Cheng Ye Mandatory Duality

Current author-approved direction:

## Enemy / true threat
> cold, cautious, ruthless, decisive.

## Family / teammates
> humorous, reliable, warm, relaxed, funny.

Hard:
> do not flatten both modes into “calm responsible man.”

# 7. Intelligence Must Create Spectacle

“Smart” cannot mean:
> better paperwork;
> recording evidence;
> generic preparedness.

A smart scene should produce one or more:
- enemy believes game is A; Cheng Ye is actually playing B;
- strange ordinary tools become devastating because of rule knowledge;
- an earlier preparation returns with a satisfying payoff;
- Cheng Ye exploits a mature rule interaction reality has not discovered yet;
- plan survives one wrong assumption;
- opponent learns and forces Cheng Ye to improvise again.

# 8. Rule Experience Gap

Preferred early dimensional advantage:

> **现实第一次遇到某条Returned Rule；程野已经在其成熟生态里活过。**

Therefore:
- he knows mature exploit/counter patterns;
- he can build surprising human-world countermeasures;
- his lead is temporary because society learns.

This is stronger than:
> generic combat buff.

# 9. Scene Escalation Rule

A major early scene should normally contain:
1. normal-world problem;
2. Cheng Ye demonstrates clear advantage;
3. reader receives payoff;
4. Returned Rule / Field logic changes the game;
5. old advantage becomes insufficient;
6. Cheng Ye must recombine knowledge in a new way.

Avoid one-note dominance.

# 10. Anti-Project-Manager Test

If Cheng Ye mostly:
- assigns roles;
- asks who bears cost;
- leaves fallback;
- stays calm;

without:
- humor;
- ruthlessness;
- affection;
- surprising tactics;
- personal appetite;
- visible anger/joy/embarrassment;

then FAIL.

# 11. Anti-AI-Smell Test

Cut or rewrite if scenes contain:
- repeated slogan dialogue;
- every character speaking in thesis statements;
- symmetrical debate;
- perfect “character philosophy” exposition;
- one polished quip every few paragraphs;
- obvious checklist fulfillment.

# 12. Unknown-Author Commercial Test

For every rewritten chapter ask:

> **If this author were unknown, what is the one thing in THIS chapter that makes a reader think “这本不普通”?**

If answer is only:
> “设定挺聪明。”

Not enough.

Need at least one:
- image;
- character behavior;
- reversal;
- emotional hit;
- tactical payoff;
- terrifying implication.

# 13. Reopen Trigger

Immediately reopen a design if the author says:
- 平淡;
- 太收敛;
- 不爽;
- 没有降维感;
- 人物没魅力;
- 像项目经理;
- 只是逻辑正确.

Do NOT defend the existing solution.
Do NOT patch around it.
Re-examine the desired reader emotion first.
