**当前唯一重点项目：**《舍弃》；《七成同意，法令生效》暂停开发。

## 已基本锁定的底层
- 传统修炼是唯一稳定生产战力的主轴。
- 所有大境突破统一拆为：**积 -> 悟 -> 续**。
- 正破、借载、舍破只发生在“续”阶段。
- 舍弃不生产力量，只降低续我成本。
- 已舍之物不可真正恢复。
- 有效舍弃会产生弃相，进入余世；本人留下永久余位。
- 一舍之后需要定我；未稳定而强行再舍会导致散我。
- 急舍/战舍必须事前定相、已达真实续关；首次成功后旧契立即失效。
- 余世只接收通过有效舍契真正切离人格连续性的弃相。
- 余器只能代偿/外置利用，不等于恢复。
- 漏舍者是一类罕见事故幸存者，不是血统或唯一外挂。
- 陆野第一舍为味觉；前100章原则上不再次舍弃，正常修炼必须占主要成长来源。
- 主角气质方向：**穷、嘴贫、惜物、行动力强**；世界沉重，但叙述不必苦大仇深。

## 本轮专项研究已经验证
1. 传统修炼三方案已完成；当前首选：
   **炼气 -> 筑基 -> 金丹 -> 元神 -> 法相 -> 洞天**。
   选择理由不是“最原创”，而是它不与舍破、余世、余器争夺认知预算。
2. 大境界体验原则已形成：
   **炼气=用灵气；筑基=稳定离体；金丹=自循环/持久；元神=神魂脱身/多线控制；法相=道路外显；洞天=改变战场环境。**
3. 15件余器压力测试已完成，证明“一器一奇用”可以覆盖战斗、侦查、逃生、生活与社会用途。
4. 六种舍弃人生模拟已完成，证明“舍弃”能自然长出职业、钱、家庭、身体、婚姻、法律与阶层，而不只是伦理讨论。
5. 陆野职业三方案已比较；当前首选：
   **驿货行短途脚夫/押货杂役**，保留少量自行修补工具的能力，不做职业旧器专家。
6. 第一次漏舍事故已有较完整因果链：
   事前应急舍备 -> 运输/舍务废件事故 -> 封位外环损坏 -> 陆野明知风险仍主动使用 -> 切离成功但封位不全 -> 应急封余把大裂口压成极细余缝 -> 官方按已知漏舍事故登记。
7. 中央主线已形成更强的“三线合流”候选：
   - **C：拾余路线**作为主角明面因果发动机；
   - **B：余灾治理/余世压力**作为世界外部压力；
   - **A：舍台/截流/借载设施真相**作为中后期暗线真相。
8. 秘密释放梯已完成第一版：前120章最多确认“被舍掉的东西没有真正消失”。

## V1.0 冻结仍有硬阻塞
### P0-A 我相判定
必须解决“某个东西到底是否真正构成自我、牵连多深”如何判断，且不能变成数值面板。

### P0-B 深层切割边界
必须解决“爱妻子/夫妻身份/亲缘/责任”等高度交织我相能否单独切、怎样判定连带损伤。

### P0-C 正破成本具体化
必须让六个大境界具体说明：完整续我到底难在哪里、资源为什么贵，而不是为了让舍破有市场强行抬价。

### P0-D 睡眠/梦/静息拆分
若保留“舍眠”，必须区分身体恢复、神魂整理、梦，并解释为什么无眠者不能24小时无成本修炼。

## 可留给剧情而非V1.0硬锁
- 人工余器原料的产权与法律归属。
- 漏舍者社会体感的具体稀有度。
- 正规舍台与余世的最终真相。
- 余世是否已经形成完整主体。
- 高境“舍未来人格道路”继续作为争议理论，不进硬规则。
