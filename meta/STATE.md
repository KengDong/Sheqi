## 已基本锁定
- 传统修炼是唯一稳定生产战力的主轴。
- 破境分为：积 -> 悟 -> 续。
- 正破、借载、舍破只发生在“续”阶段。
- 舍弃不生产力量，只降低续我成本。
- 已舍之物不可真正恢复。
- 有效舍弃会产生弃相，进入余世；本人留下永久余位。
- 一舍之后需要定我；未稳定而强行再舍会导致散我。
- 急舍/战舍必须事前定相、已达真实瓶颈，首次成功后旧契立即失效。
- 余器只能代偿/外置利用，不等于恢复。
- 漏舍者是一类事故幸存者，不是血统或唯一外挂。
- 陆野第一舍为味觉；前100章原则上不再次舍弃，正常修炼必须占主要成长来源。
- 主角气质方向：穷、嘴贫、惜物、行动力强；世界沉重但叙述不必苦大仇深。

## 当前最强候选
- 陆野职业：旧器铺/二手法器修补学徒。
- 主角异常：切离成功但封位失败，因此人间食物永久无味，却能模糊“尝余”。
- 余器设计原则：强效果 + 窄用途 + 明确条件 + 明确余性风险；一器一奇用。
- 主线候选：个人生存 -> 余痕 -> 余世 -> 舍台秘密 -> 弃相截流/借载设施 -> 文明维持成本 -> 余世主体性。
