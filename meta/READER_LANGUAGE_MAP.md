# READER LANGUAGE MAP｜正文语言转换 V1

## 0. 总规

> **作者工程语 != 世界正式语 != 行业口语 != 人物日常语 != 读者第一次体验语言。**

正文优先顺序：
> 先看见/听见/摸到 -> 知道当前为什么重要 -> 人物怎么叫 -> 必要时再落正式名。

---

# 1. 核心术语

## 保留Canon，但先体验后正式名
- 舍备
- 舍契
- 漏舍
- 修积
- 明悟
- 续我
- 我相
- 缺位
- 弃相
- 余痕
- 余灾
- 余器
- 余世

前三章优先真正进入读者认知的只有：
> **舍备 / 舍契 / 漏舍**

其余尽量先让机制事实成立。

---

# 2. 开篇职业 / 制度词

## 修籍
状态：
> **DOWNGRADE**

前三章不要求落正式名。

正文优先：
- 册子
- 薄册
- 记录

后续若制度频繁复用，再决定“修籍”是否成为正式名。

## 押手
状态：
> **行业短称候选**

读者先理解：
> 押货 / 跟货走 / 负责货路的人。

语境建立后才允许自然出现“押手”。

## 受监督额外手
状态：
> **DOWNGRADE**

正文：
> “能跟。只搭手，不算押货的。”

不作为岗位专名。

## 低风险线
状态：
> **DOWNGRADE**

正文用：
- 空架
- 普通货
- 这几趟
- 这些活

不要凭空造业务“线”。

# 3. 前三章普通物件

## Ch1
- 货签夹 -> **夹货牌的旧木夹** -> 木夹/夹子
- 簧针 -> **小铁簧 / 里面那根铁簧**
- 便宜热汤 -> **咸菜豆腐汤**（第一章Working Default）
- 修籍凭证 -> **小薄册 / 册子**

## Ch2
- 长型重载转运架 -> **重货架 / 长架**
- 导向轮脱槽 -> 先写**导轮蹿出槽 / 偏出槽**
- 固定导向柱 -> **护柱 / 柱子**
- 已验低风险封存退件 -> **一只待退回舍务处的封匣**
- 凹入式应急舍台服务位 -> **墙里凹进去的应急舍台**
- 封位外环 -> 读者/现场先用**封环 / 外环 / 最外面那圈**
- 正式实现名继续OPEN
- 辅助制动/牵引结构 -> **固定牵引绞盘/卷轮 + 摩擦制动/张力控制机构**
- 操作部件 -> **闸 / 闸柄**

## Ch3
- 稳定药 -> **一碗本来就苦的常规药汤**
- 临时封具 -> 写前必须具体成可拿/压/扣的实物
- 封余针 / 隔余布 -> 首次先动作，正式名不急

# 4. 作者工程词｜正文禁用

包括但不限于：
- 正常安全包络
- 续我承接负担
- 低阶可控范围
- 低风险受监督路径
- 当前时间窗口
- 生产价值
- 完成岗位适应
- 社会位置变化
- 信息预算
- 三线并行
- 稳定离体权限
- 远端控制点
- 高危候选资格冻结（作为整句制度字段）

遇到这类词：
> 改成可见动作、现实后果或人物短句。

---

# 5. “舍味 -> 筑基”硬门

在事故发生前，读者必须已经知道：

> **陆野本来就到了筑基最后阶段；该练的早已练到这里，只差最后一关。**

不要求前三章教：
- 修积
- 明悟
- 续我

三个正式词。

第三章体验顺序固定：

1. 舍契先造成**缺失**；
2. 这一拍没有力量奖励；
3. 原本卡住的修炼随后继续；
4. 筑基成立；
5. 同一机械控制动作由“碰得到但留不住”变成“能持续留住”；
6. 能力来自筑基；
7. 漏舍由受损封环与值守封闭失败单独表现。

---

# 6. 事故语言

作者工程层可以精确。

正文层必须优先：
> 轮出槽 -> 架横甩 -> 人被卡 -> 右头撞裂封匣/封环 -> 架体仍在吃角 -> 绞盘/闸需要持续控制 -> 炼气留不住 -> 筑基后能持续维持。

现场人只说下一步动作，不讲制度。

---

# 7. 普通物件规则

若章卡只写：
- 普通
- 便宜
- 低风险
- 常用
- 某种
- 某类

则仍是占位状态。

正式草稿前必须回答：
> 到底是什么东西？

一次性普通器物不要为了仙侠感造专名。

---

# 8. 使用方式

每章正式草稿前：
1. 读取本文件；
2. 读取该章Reader-Language Sheet；
3. 若出现未解决的PLACEHOLDER，先解决；
4. 再进入Scene Spine和正文。
