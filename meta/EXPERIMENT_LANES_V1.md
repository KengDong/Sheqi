# STORY FORGE EXPERIMENT LANES V1
## 不押一条路线，同时制造真正不同的候选

# 0. Git Strategy

创意阶段不创建大量Git branches。

统一写入：
> `experiments/first_principles_forge/<lane_id>/`

原因：
- 所有证据在main可见；
- 不产生authority分叉；
- Total Editor可同架比较；
- clean-room Reader只读匿名导出包。

只有候选通过：
> P10 Voluntary Stop Gate + Total Editor Promotion

才允许建立正式长篇分支/升级为authority资产。

# 1. Lane A｜Native Rebuild

## A1 C01-Free
保留最少不可替代资产：
- 卖掉本人真实缺席的未来；
- 沈峥；
- 陈美兰 / 方栀可作为候选；
- “现在的我能否拥有未来的我”。

禁止继承：
- 旧Ch4—20章节顺序；
- 创业成长路线；
- 现有Early20 map作为施工图。

目标：
> 看C01在没有旧职业惯性时，能自然长出什么好戏。

## A2 C12-Free
保留：
- 富人在内、劫工在外；
- 周野；
- 风险可转移但不会消失；
- 自己终究要渡劫。

禁止继承：
- 安全职业案例顺序；
- 现有Early20 map施工化。

目标：
> 看现代修仙文明本身能否自然持续产事。

# 2. Lane B｜Benchmark Function Clones

注意：
> **仿发动机，不仿作品。**

## B1 World Expansion
函数：
> 普通欲望稳定 + 每几章撞入新社会系统 + 每次产生新的独特成本。

至少产出3个完全不同Concept。

## B2 Mystery Recontextualization
函数：
> 每次答案改变旧信息价值，并打开更大的问题。

至少3个Concept。

## B3 Compounding Fantasy / Asset
函数：
> 核心动作可重复，但每次留下明显更大的资产/控制力/幻想兑现。

至少3个Concept。

## B4 Relationship × Life Interfaces
函数：
> 核心关系非常强，生活接口持续扩张。

至少3个Concept。

## B5 Hybrid Mutation
从B1—B4中任取两个功能组合，
但必须产生新的独特体验，不能拼盘。

至少3个Concept。

# 3. Lane C｜Wild Concepts

完全不读C01/C12资产。

目标：
> 至少10个与现有两本无关的高欲望Concept。

允许：
- 都市；
- 科幻；
- 奇幻；
- 现实异化；
- 悬疑；
- 轻喜剧；
- 社会寓言；
- 混合类型。

唯一要求：
> 一句话想点 + 能自然生成大量好戏。

# 4. Phase-1 Funnel

第一轮不写长报告。

每个Concept只给：
1. 一句话Promise；
2. 主角现在最想要什么；
3. 世界独特规则；
4. 5个“我真的想看”的场面；
5. 一个非主角为什么值得追；
6. 100章后可能变成什么；
7. 为什么换皮成普通同类就不成立。

Total Editor只做：
> **DESIRE CUT**

不是打12项分数。

留下约6—8个。

# 5. Phase-2 Story Reservoir

每个晋级候选：
> 30—50个Scene/Situation Seeds。

不排章节。
不均匀覆盖。

每个Seed只有：
- 一句话场面；
- 谁想要什么；
- 谁/什么阻止；
- 独特规则怎样把冲突变得不可替代；
- 为什么我想看。

如果20个以后明显枯竭：
> DROP / MUTATE。

# 6. Phase-3 Character Collision

每个候选：
- 4—6核心人物；
- 每人独立欲望；
- 10—15个因欲望碰撞自然产生的事件；
- 至少一半事件不是主角接任务触发。

# 7. Phase-4 Minimal Horizon

只写：
- Near；
- Mid；
- Far。

最多一页。

# 8. Phase-5 Prose Duel

统一Writer，控制变量。

先：
> P1 / Ch1

再：
> P3 / Ch1—3

通过才：
> P7 / Ch1—7

禁止一开始写20章。

# 9. Phase-6 Voluntary Reader

匿名。
不知道候选来源。
不知道Benchmark模仿线。
不知道目标读几章。

允许任意时刻停。

# 10. Promotion Rule

一个候选只有同时满足：
- P7无明显同区间自愿弃读；
- 至少一个非主角自然黏住Reader；
- Reader能说出具体Mid等待；
- 至少2个独有场面被主动记住；
- Story Reservoir仍有明显剩余；

才允许进入P10。

P10通过后才讨论：
> Longform branch / Bible / Canon / Outline。

# 11. Why This Is Not Random Brainstorming

多路线不是“多想点子碰运气”。

每条Lane验证一个不同因果假设：

- A：现有Concept本身是否足够，只是旧流程写坏了？
- B1：World Expansion能否成为我们的强发动机？
- B2：Recontextualization是否更适合长追？
- B3：Compounding是否提供更稳定爽感？
- B4：人物/关系是否能成为主要留存？
- B5：混合是否产生超额Premium？
- C：是否存在比C01/C12更强的新书方向？

最终不是选“最符合理论”的。
是选：
> **真实读者最舍不得停的。**
