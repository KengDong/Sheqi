# READER EVIDENCE HIERARCHY
## 谁能推翻谁

# Level 1｜Behavioral Truth
最高权重：
- 作者真实自愿停读；
- clean-room Reader exact voluntary stop；
- Reader主动索要下一章；
- Reader在不知道任务终点时自然继续。

**Level 1可推翻所有低层PASS。**

# Level 2｜Continuous Prose Experience
- 实际连续正文；
- 无设计文档提示；
- 不强制读完整包。

# Level 3｜Unprompted Reader Memory / Desire
- 最想再见谁；
- 正在等什么；
- 最记得哪一幕；
- 用一句话怎么描述这本书。

必须先自由回答，再做结构化追问。

# Level 4｜Story Desire Proof
- Scene/Situation Reservoir；
- “这场我想不想看”；
- 章节菜单欲望。

# Level 5｜External Benchmark Evidence
- 热门作品的Reader机制；
- 市场/平台数据；
- Difference Audit。

# Level 6｜Architecture Diagnostics
- Canopy；
- Five Curves；
- Macro Promise；
- Scene Ecology；
- Rolling-3；
- Character Maps。

# Level 7｜Selfcheck
最低：
- Writer Selfcheck；
- Architect Selfcheck；
- 自动评分表。

# Hard Rule

> **低层证据永远不能以“更完整、更专业、更系统”为理由覆盖高层真实阅读行为。**

例如：
> D-0067 STRONG PASS + Head-Tier Ready
不能推翻：
> D-0075 作者Ch7真实弃读。

# Reader Prompt Hygiene

Fresh Reader不得预先看到：
- 目标章节数；
- 设计意图；
- Benchmark映射；
- 总编关注的问题；
- 哪本更被看好。

Reader只知道：
> “从这里开始读；如果你真实情况下会停，就停。”

停止后才进入访谈。
